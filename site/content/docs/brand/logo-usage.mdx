## Variants

| Variant | File | Use case |
|---|---|---|
| Mark, light surface | `assets/logo.svg` | README header, site hero, diagrams, light backgrounds |
| Mark, dark surface | `assets/logo-dark.svg` | Site hero and dark backgrounds |
| Wordmark, light surface | `assets/logo-wordmark.svg` | Wide lockups where the brand name must travel with the mark |
| Wordmark, dark surface | `assets/logo-wordmark-dark.svg` | Wide lockups on dark surfaces |
| Browser favicon | `assets/favicon.svg`, `assets/favicon.ico`, `assets/favicon-16x16.png`, `assets/favicon-32x32.png` | Browser tabs and ICO fallback consumers |
| Apple touch icon | `assets/apple-touch-icon-180.png` | iOS bookmark |
| Social cards | `assets/og-banner-1200x630.png`, `assets/twitter-card.png`, `assets/social-preview.svg` | Open Graph, Twitter/X, and GitHub repository preview surfaces |

## Raster sizes

Pre-generated mark rasters are available at 16, 32, 64, 128, 192, 256, 512, and 1024px.
Both light and dark variants are provided, except the 192px raster, which is
light-only (the PWA `purpose: "any"` install icon). The favicon uses a simplified
monogram, not the full weave mark, so it remains legible at browser-tab sizes.

## Clear space

Maintain a minimum clear space of 1/4 logo height on all sides.
Do not place the logo on backgrounds that make it illegible.
Use the favicon monogram only for small square surfaces; use the full mark or
wordmark everywhere the mark has enough room to breathe.

## Permitted uses

- Linking to the Apothem website or repository
- Integration documentation and blog posts about Apothem
- Presentations that reference Apothem

## Prohibited uses

- Modifying the logo shape, proportions, or weave motif
- Using the logo to imply official endorsement without permission
- Combining the logo with other marks in a way that creates a new composite mark
