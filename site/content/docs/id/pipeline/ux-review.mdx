**Peran:** Peninjau UX
**Posisi pipeline:** benteng

Tinjauan pengalaman pengembang atas ergonomi CLI, dokumentasi, dan orientasi awal.

## Pemanggilan kanonis

```bash
/ux-review
```

Dengan argumen:

```bash
/ux-review [path/to/repo/] [--focus SURFACE] [--dry-run]
```

## Masukan

Repositori host yang sudah di-deploy dengan README, skrip pemasangan, dan titik masuk CLI

## Keluaran

Temuan UX di `_inputs/ux-review-findings.md`

## Hilir

Tahap tinjauan UX dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase: penyerapan masukan, penelusuran ergonomi CLI, audit alur pemasangan dan pemulihan galat, sapuan keterjangkauan dokumentasi, dan emisi temuan dengan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Prasyarat belum lengkap | Fase dependen belum selesai | Selesaikan dulu fase hulu |
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Target belum di-deploy | Target tidak memiliki permukaan yang menghadap operator | Berikan root repositori yang sudah di-deploy |

## Contoh

```bash
# Dry-run to preview what would happen
/ux-review --dry-run

# Execute against a host repository
/ux-review path/to/repo/
```
