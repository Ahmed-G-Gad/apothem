**Peran:** Peninjau
**Posisi pipeline:** benteng

Pass tinjauan kualitas kode per-file yang digerakkan operator di seluruh src/, scripts/, dan tools/.

## Pemanggilan kanonik

```bash
/code-review
```

Dengan argumen:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Masukan

Repositori host dalam keadaan siklus hidup apa pun

## Keluaran

Temuan per-berkas di `_inputs/code-review-findings.md`

## Hilir

Tahap tinjauan baris-demi-baris dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase: penyerapan masukan, penelusuran per-berkas, triase per-temuan, emisi temuan, dan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Berkas masukan hilang | Repositori tidak memiliki satu pun dari `src/`, `scripts/`, atau `tools/` | Berikan root repositori yang berisi setidaknya salah satu dari direktori tersebut |

## Contoh

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
