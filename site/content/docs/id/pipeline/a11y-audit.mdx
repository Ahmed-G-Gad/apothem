**Peran:** Auditor aksesibilitas
**Posisi pipeline:** benteng

Audit aksesibilitas terhadap WCAG 2.2 AA untuk setiap halaman yang dirender.

## Pemanggilan kanonik

```bash
/a11y-audit
```

Dengan argumen:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## Masukan

Situs web proyek yang di-deploy atau disajikan secara lokal

## Keluaran

Temuan aksesibilitas di `_inputs/a11y-audit-findings.md`

## Hilir

Tahap audit aksesibilitas dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase audit: penyerapan masukan, audit per-halaman, triase per-temuan, emisi temuan, dan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| File masukan hilang | Jalur situs atau URL tidak dapat di-resolve | Berikan direktori situs yang sudah dibangun atau URL yang dapat dijangkau |

## Contoh

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
