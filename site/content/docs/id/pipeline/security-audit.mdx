**Peran:** Auditor keamanan
**Posisi pipeline:** benteng

Audit postur keamanan menyeluruh terhadap OWASP ASVS 4.0 atau versi yang lebih baru dan OWASP Top 10.

Batas minimum perintah ini adalah rilis patch ASVS 4.0 terakhir. Perintah ini tidak mencari sendiri rilis ASVS yang lebih baru. Temuan mengutip bab ASVS dengan nomor dan judul singkat, seperti V5 (Validation, Sanitization, Encoding), V12 (File and Resources), dan V14 (Configuration).

## Pemanggilan kanonik

```bash
/security-audit
```

Dengan argumen:

```bash
/security-audit [path/to/repo/] [--focus CATEGORY] [--dry-run]
```

## Masukan

Repositori host pada commit git yang dipatok

## Keluaran

Temuan keamanan di `_inputs/security-audit-findings.md`

## Hilir

Tahap security-audit dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan enam fase audit: penyerapan masukan, rahasia dan izin, validasi masukan dan injeksi, deserialisasi dan path traversal, CVE dependensi dan CodeQL, serta emisi temuan dengan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Prasyarat belum lengkap | Fase dependen belum selesai | Selesaikan dulu fase hulu |
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Target ditolak | Jalur bukan working tree git | Berikan root repositori sebagai jalur |

## Contoh

```bash
# Dry-run to preview what would happen
/security-audit --dry-run

# Execute against a host repository
/security-audit path/to/repo/
```
