**Peran:** Peninjau arsitektur
**Posisi pipeline:** benteng

Tinjauan integritas arsitektur terhadap artefak desain di `_inputs/design.md`.

## Pemanggilan kanonik

```bash
/architecture-review
```

Dengan argumen:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Masukan

Repositori host + `_inputs/design.md`

## Keluaran

Temuan arsitektur di `_inputs/architecture-review-findings.md`

## Hilir

Tahap tinjauan arsitektur dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase audit: penyerapan masukan, penelusuran keterlacakan desain-ke-kode, audit integritas batas-lapisan, sapuan kopling lintas-paket, dan emisi temuan dengan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| File masukan hilang | Artefak desain `_inputs/design.md` tidak ada | Jalankan `/plan-design` untuk membuatnya |

## Contoh

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
