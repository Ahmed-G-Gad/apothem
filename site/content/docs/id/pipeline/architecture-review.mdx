**Peran:** Peninjau arsitektur
**Posisi pipeline:** benteng

Tinjauan integritas arsitektur terhadap artefak desain di `_inputs/design.md`.

## Pemanggilan kanonik

```bash
/architecture-review
```

Dengan argumen:

```bash
/architecture-review [path/to/plan-suite/] [phase-id] [--dry-run]
```

## Masukan

Repositori host + `_inputs/design.md`

## Keluaran

Temuan arsitektur + REPORT.md

## Hilir

Tahap tinjauan arsitektur dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini mengikuti alur kerja pipeline `/plan` standar:

1. **Memuat konteks** — Membaca suite plan, aturan, dan Kontrak Pelanjutan.
2. **Memverifikasi prasyarat** — Memastikan fase dependensi telah selesai.
3. **Mengeksekusi tugas** — Menjalankan misi perintah.
4. **Memverifikasi keluaran** — Memastikan semua keluaran yang dideklarasikan ada dan lulus gerbang kualitas.
5. **Memperbarui PROGRESS.md** — Mencatat keluaran terverifikasi di Registri Keluaran Fase.
6. **Memancarkan REPORT.md** — Bukti rilis gerbang pra-emisi dicatat.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Prasyarat tidak lengkap | Fase dependen belum selesai | Selesaikan dulu fase hulu |
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| File masukan hilang | File suite plan tidak ada | Jalankan `/plan-generate` untuk membuatnya |

## Contoh

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a named plan suite
/architecture-review path/to/plan-suite/
```
