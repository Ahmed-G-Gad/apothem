**Peran:** Eksekutor
**Posisi pipeline:** terminal

Mengeksekusi fase tertentu dari Master Plan Suite dengan pemeriksaan konformitas.

## Pemanggilan kanonik

```bash
/plan-execute
```

Dengan argumen:

```bash
/plan-execute [path/to/plan-suite/] [phase-id] [--dry-run]
```

## Masukan

Suite rencana yang dihasilkan + ditinjau; `_inputs/handoff-manifest.yml` yang ditinjau

## Keluaran

File REPORT.md per fase, artefak basis kode, COMPLETION.md

## Hilir

`/code-review` — titik masuk kanonik dari urutan benteng audit sebelas perintah. `/plan-execute` adalah tahap terminal dari pipeline *plan*; ketika fase akhir selesai, kode yang dibangun diserahkan ke benteng audit untuk ditinjau.

## Fase alur kerja

Perintah ini mengikuti alur kerja pipeline `/plan` standar:

1. **Memuat konteks** — Membaca suite rencana, aturan, dan Kontrak Pelanjutan.
2. **Memverifikasi prasyarat** — Memastikan fase dependensi telah selesai.
3. **Menjalankan tugas** — Menjalankan misi perintah.
4. **Memverifikasi keluaran** — Memastikan semua keluaran yang dideklarasikan ada dan lulus gerbang kualitas.
5. **Memancarkan REPORT.md** — Hasil gerbang pra-emisi tercatat.
6. **Memperbarui PROGRESS.md** — Mencatat keluaran terverifikasi dalam Registri Keluaran Fase.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Prasyarat tidak lengkap | Fase dependen belum selesai | Selesaikan dulu fase hulu |
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| File masukan hilang | File suite rencana tidak ada | Jalankan `/plan-generate` untuk membuatnya |

## Contoh

```bash
# Dry-run to preview what would happen
/plan-execute --dry-run

# Execute against a named plan suite
/plan-execute path/to/plan-suite/
```
