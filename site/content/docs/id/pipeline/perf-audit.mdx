**Peran:** Auditor kinerja
**Posisi pipeline:** benteng

Mengaudit terhadap anggaran kinerja per kelas (runtime hook, verify-ecosystem, gerbang konformitas, tes, pekerja yang didelegasikan, shell, lint), menggunakan metode USE.

## Pemanggilan kanonik

```bash
/perf-audit
```

Dengan argumen:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## Masukan

Repositori host yang berisi `hooks/`, `src/apothem/benchmarks/`, `tests/`, dan stub bootstrap hook `hooks/lib/bootstrap.{sh,ps1}`

## Keluaran

Temuan kinerja di `_inputs/perf-audit-findings.md`

## Hilir

Tahap audit kinerja dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase audit: penyerapan masukan, penemuan anggaran per-kelas, eksekusi benchmark, identifikasi jalur panas dengan metode USE, dan emisi temuan dengan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| File masukan hilang | Repositori tidak memiliki `src/apothem/benchmarks/` | Tambahkan driver benchmark, lalu jalankan ulang; perintah menolak berjalan hingga driver tersebut ada |

## Contoh

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
