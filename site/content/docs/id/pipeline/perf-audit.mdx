- **Peran:** Auditor kinerja
- **Posisi pipeline:** benteng

Mengaudit terhadap anggaran kinerja per kelas (runtime hook, verify-ecosystem, gerbang konformitas, tes, pekerja terdelegasi, shell, lint), menggunakan metode USE.

## Pemanggilan kanonik

```bash
/perf-audit
```

Dengan argumen:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## Masukan

Salinan repositori Apothem yang berisi `src/apothem/hooks/`, `src/apothem/benchmarks/`, `tests/`, dan stub bootstrap hook `src/apothem/hooks/lib/bootstrap.{sh,ps1}`

## Keluaran

Temuan kinerja di `_inputs/perf-audit-findings.md`

## Hilir

Tahap audit kinerja dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase audit: penyerapan masukan, penemuan anggaran per-kelas, eksekusi benchmark, identifikasi jalur panas dengan metode USE, dan emisi temuan dengan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Bukan salinan repositori Apothem | Repositori tidak memiliki `src/apothem/benchmarks/` | Tidak ada yang perlu diperbaiki: perintah melaporkan dimensi ini sebagai tidak berlaku, dan `/audit` melewatinya |

## Contoh

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
