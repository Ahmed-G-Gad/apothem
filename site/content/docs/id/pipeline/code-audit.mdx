**Peran:** Auditor
**Posisi pipeline:** benteng

Audit kode forensik lintas-berkas pada skala korpus repositori.

## Pemanggilan kanonis

```bash
/code-audit
```

Dengan argumen:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## Masukan

Repositori host dengan tata letak sumber yang disetujui, baseline cakupan tes, dan (pada SHARED+) gerbang CI yang lulus

## Keluaran

Temuan tingkat-korpus di `_inputs/code-audit-findings.md`

## Hilir

Tahap audit kode forensik dari Urutan Audit Tinjauan

## Fase alur kerja

Perintah ini menjalankan enam fase forensik: penyerapan masukan, penelusuran dependensi lintas-berkas, audit type-hint dan cakupan, deteksi kode mati dan duplikasi, audit integritas arsitektural, dan emisi temuan dengan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Berkas masukan hilang | Belum ada eksekusi gerbang CI atau baseline cakupan tes pada SHARED+ | Jalankan pipeline CI host lebih dulu, lalu jalankan ulang |

## Contoh

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
