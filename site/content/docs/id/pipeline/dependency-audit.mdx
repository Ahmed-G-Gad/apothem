**Peran:** Auditor dependensi
**Posisi pipeline:** benteng

Pass audit per-dependensi (langsung + transitif) untuk lisensi, CVE, dan kesegaran.

## Pemanggilan kanonik

```bash
/dependency-audit
```

Dengan argumen:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## Masukan

Manifes dependensi repositori host

## Keluaran

Temuan dependensi di `_inputs/dependency-audit-findings.md`

## Hilir

Tahap dependency-audit dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase: penyerapan masukan, penelusuran per-dependensi, triase per-temuan, emisi temuan, dan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Berkas masukan hilang | Tidak ada manifest dependensi yang ter-resolve di root repositori | Berikan root repositori yang berisi manifest dependensi |

## Contoh

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
