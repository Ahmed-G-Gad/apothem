**Peran:** Auditor rantai pasok
**Posisi pipeline:** benteng

Audit rantai pasok terhadap standar SLSA + Sigstore + SBOM.

## Pemanggilan kanonik

```bash
/supply-chain-audit
```

Dengan argumen:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## Masukan

Pipeline rilis repositori host

## Keluaran

Temuan rantai pasok di `_inputs/supply-chain-audit-findings.md`

## Hilir

Tahap supply-chain-audit dari Urutan Tinjauan Audit

## Fase alur kerja

Perintah ini menjalankan lima fase audit: penyerapan masukan, penelusuran per-sumbu, triase per-temuan, emisi temuan, dan gerbang validasi.

## Mode kegagalan

| Gejala | Penyebab | Pemulihan |
|---------|-------|----------|
| Prasyarat belum lengkap | Fase dependen belum selesai | Selesaikan dulu fase hulu |
| Gerbang kualitas FAIL | Keluaran tidak memenuhi standar | Perbaiki keluaran dan jalankan ulang |
| Target ditolak | Target tidak memiliki permukaan rilis | Berikan root repositori yang berisi .github/workflows/, skrip rilis, atau manifest build |

## Contoh

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
