Open-Claw membaca `~/.openclaw/openclaw.json`. Apothem memasang kohor perintah
dan skill bersama di bawah `~/.openclaw/.apothem/support/skills/` dan menyunting
dua tempat di `~/.openclaw/openclaw.json`. Apothem menambahkan direktori itu ke
`skills.load.extraDirs`, agar OpenClaw memuat skill tersebut. Apothem menambahkan
jalur `apothem/AGENTS.md` ke daftar jalur entri hook
`hooks.internal.entries.bootstrap-extra-files`, dan membuat entri itu dengan `enabled: true`
bila belum ada, agar OpenClaw memuat berkas aturan Apothem yang ditulisnya ke setiap
workspace. `agents.defaults.skills`-nya adalah daftar nama
yang diizinkan milik Anda dan MCP adalah permukaan CLI, jadi Apothem tidak
menulis keduanya.

## Status

**Pratinjau.** Adaptor Open-Claw menyasar berkas konfigurasi yang
terdokumentasi saat ini, permukaan direktori skill tambahan, dan hook
`bootstrap-extra-files` bawaan. Aturan dimuat melalui berkas workspace
`apothem/AGENTS.md`; templat, agents, dan materi hook tetap menjadi materi
pendukung Apothem.

## Perbandingan upaya

| Tugas | Config tangan mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis skill yang dapat dipakai ulang | Menyunting tangan config dan direktori skill | Menulis sekali di korpus bersama |
| Menjaga kohor selaras dengan lingkungan lain | Manual, per alat | Otomatis saat `apothem update` |
| Memasang / menghapus config | Manual | `apothem install` / `apothem uninstall` |
| Memverifikasi config sudah benar | Inspeksi manual | `apothem verify --harness open-claw` |

## Apa yang dikelola Apothem

Adaptor Open-Claw menulis `openclaw.json`, membungkus perintah garis miring
Apothem sebagai skill, menyalin skill Apothem ke direktori pendukung yang
direferensikan, dan menjaga aturan, templat, agents, dan materi hook di bawah
pohon pendukung Apothem. Adaptor ini juga menulis `apothem/AGENTS.md` ke setiap
workspace dan mendaftarkannya pada hook `bootstrap-extra-files` bawaan, agar
OpenClaw memuat aturan Apothem tanpa mengubah `AGENTS.md` milik workspace itu sendiri.
OpenClaw membaca `skills.load.extraDirs` setelah sumber workspace-nya, `~/.agents/skills`,
dan `~/.openclaw/skills`, sehingga skill dengan nama yang sama di salah satunya
digunakan sebagai ganti salinan Apothem.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum
   melakukannya.
2. Pindahkan skill atau prompt perintah Open-Claw yang dapat dipakai ulang ke
   korpus bersama.
3. Jalankan `apothem install --harness open-claw` untuk merender konfigurasi
   native dan direktori skill pendukung.
4. Jalankan `apothem verify --harness open-claw` untuk mengonfirmasi bahwa
   konfigurasi sudah mendarat.
