Kimi Code reads project-root `AGENTS.md` as its instruction file and keeps
project configuration under `<project>/.kimi-code/`, including the
operator-owned `.kimi-code/mcp.json` MCP surface. You can author that
instruction file and its supporting cohorts by hand, per project, forever.
Apothem's kimi-code adapter renders the governance surface into `AGENTS.md` as a
managed block from the shared profile and keeps it consistent across every
harness and every project. This page contrasts hand-maintaining that config
against managing it with Apothem.

## Effort comparison

| Tugas | Konfigurasi manual | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis permukaan instruksi `AGENTS.md` | Tulis dengan tangan dan sinkronkan ulang per proyek | Satu blok terkelola yang dirender dari profil bersama |
| Menjaga aturan, command, skill, agen tetap tersinkron | Salin manual per proyek | Dimaterialisasi di bawah `<project>/.kimi-code/.apothem/support/` pada setiap pemasangan |
| Mempertahankan prosa operator saat penyegaran | Penggabungan manual | Blok dibatasi sentinel; prosa operator di luarnya dipertahankan |
| Menjaga aturan selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness kimi-code --project <path>` |

## What Apothem manages

The kimi-code adapter renders the shared rules and governance surface into the
project-root `AGENTS.md` managed block and installs the commands, skills, hooks,
agents, rules, and templates cohorts under `.kimi-code/.apothem/support/`. It does not
author `.kimi-code/mcp.json`; the MCP surface stays operator-owned. The rendered
instruction surface drives the project directly. Every change to the shared
rules re-renders the files on the next `apothem update`.

## Migration path

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan aturan dari `AGENTS.md` yang sudah ada ke korpus bersama.
3. Jalankan `apothem install --harness kimi-code --project <path>` untuk merender permukaan instruksi `AGENTS.md` dan subtree pendukung `.kimi-code/.apothem/support/`.
4. Jalankan `apothem verify --harness kimi-code --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness kimi-code --project <path>` untuk setiap perubahan berikutnya.
