Kimi Code membaca `AGENTS.md` di akar proyek sebagai berkas instruksinya dan
menyimpan konfigurasi proyek di bawah `<project>/.kimi-code/`, termasuk
permukaan MCP `.kimi-code/mcp.json` yang dimiliki operator. Anda dapat menulis
berkas instruksi itu beserta kohor pendukungnya dengan tangan, per proyek,
selamanya. Adapter kimi-code dari Apothem merender permukaan tata kelola ke
dalam `AGENTS.md` sebagai blok terkelola dari profil bersama dan menjaganya
tetap konsisten di setiap harness dan setiap proyek. Halaman ini membandingkan
memelihara konfigurasi tersebut dengan tangan terhadap mengelolanya dengan
Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis permukaan instruksi `AGENTS.md` | Menulis dengan tangan dan menyinkronkan ulang per proyek | Satu blok terkelola yang dirender dari profil bersama |
| Menjaga aturan, command, skill, agen tetap tersinkron | Salin manual per proyek | Dimaterialisasi di bawah `<project>/.kimi-code/.apothem/support/` pada setiap pemasangan |
| Mempertahankan prosa operator saat penyegaran | Penggabungan manual | Blok dibatasi sentinel; prosa operator di luarnya dipertahankan |
| Menjaga aturan selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness kimi-code --project <path>` |

## Apa yang dikelola Apothem

Adapter kimi-code merender aturan bersama dan permukaan tata kelola ke dalam
blok terkelola `AGENTS.md` di akar proyek, dan memasang kohor command, skill,
hook, agen, aturan, dan templat di bawah `.kimi-code/.apothem/support/`. Adapter
ini tidak menulis `.kimi-code/mcp.json`; permukaan MCP tetap dimiliki operator.
Kimi Code membaca instruksi proyek dari `AGENTS.md` atau
`.kimi-code/AGENTS.md`; adapter hanya menulis `AGENTS.md` di akar proyek, dan
dokumentasi Kimi Code tidak menyebutkan berkas mana dari keduanya yang
diutamakan ketika keduanya ada. Setiap perubahan pada aturan bersama merender
ulang berkas pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan aturan dari `AGENTS.md` yang sudah ada ke korpus bersama.
3. Jalankan `apothem install --harness kimi-code --project <path>` untuk merender
   permukaan instruksi `AGENTS.md` dan pohon pendukung `.kimi-code/.apothem/support/`.
4. Jalankan `apothem verify --harness kimi-code --project <path>` untuk memastikan konfigurasi
   sudah terpasang.
5. Gunakan `apothem update --harness kimi-code --project <path>` untuk setiap perubahan
   berikutnya.
