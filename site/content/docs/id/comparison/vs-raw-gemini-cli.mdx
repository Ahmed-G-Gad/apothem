Gemini CLI membaca satu berkas aturan `GEMINI.md`. Adaptor gemini-cli milik
Apothem merendernya dari profil bersama. Halaman ini mengontraskan pemeliharaan
konfigurasi itu secara manual dengan mengelolanya menggunakan Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis aturan | Menyunting satu `GEMINI.md` dengan tangan | Dirender: panduan untuk seluruh proyek di `GEMINI.md`; aturan di `.gemini/.apothem/support/` |
| Menjaga aturan selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memasang / menghapus konfigurasi | Menulis dan menghapus `GEMINI.md` dengan tangan | `apothem install` / `apothem uninstall` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness gemini-cli --project <path>` |

## Apa yang dikelola Apothem

Adapter gemini-cli menulis blok Apothem yang dibatasi sentinel ke dalam `<project>/GEMINI.md` yang memuat panduan untuk seluruh proyek dan menunjuk ke materi Apothem. Aturan, templat, dan hook mendarat sebagai berkas pendukung di bawah `<project>/.gemini/.apothem/support/`, sedangkan command, skill, dan agen mendarat di bawah `<project>/.gemini/`. Gemini CLI mendokumentasikan objek `hooks` di `settings.json`, yang tetap dimiliki operator, sehingga adapter tidak mendaftarkan hook dan maksud pagar pengaman diekspresikan dalam prosa aturan, bukan sebagai titik intersepsi pemanggilan alat. Setiap perubahan pada aturan bersama merender ulang `GEMINI.md` pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan aturan dari `GEMINI.md` yang sudah ada ke korpus bersama.
3. Jalankan `apothem install --harness gemini-cli --project <path>` untuk merender dan menulis `GEMINI.md`.
4. Jalankan `apothem verify --harness gemini-cli --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness gemini-cli --project <path>` untuk setiap perubahan berikutnya.
