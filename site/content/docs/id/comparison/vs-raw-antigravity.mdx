Antigravity adalah harness propagasi-manifest Kelas I: Apothem menulis jangkar konteks global `~/.gemini/GEMINI.md` dan memasang plugin Apothem di bawah `~/.gemini/antigravity-cli/plugins/apothem/`. Halaman ini membandingkan pemeliharaan tata letak tersebut secara manual dengan pengelolaannya memakai Apothem.

## Status

**Pratinjau.** Adapter Antigravity menargetkan jangkar konteks `GEMINI.md` dan permukaan plugin Antigravity CLI yang terdokumentasi saat ini. Kohor tanpa permukaan native tetap berupa materi pendukung Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis aturan | Tulis setiap berkas aturan plugin secara manual | Tulis sekali di korpus bersama |
| Mempertahankan prompt yang dapat digunakan ulang | Salin prompt command dan skill secara manual ke berkas plugin | Dikonversi atau disalin menjadi skill plugin |
| Mempertahankan materi pendukung hook | Salin referensi hook secara manual tanpa pengkabelan aktif | Disalin di bawah pohon pendukung plugin Apothem |
| Menjaga aturan tetap selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memasang / menghapus konfigurasi | Salin dan hapus berkas secara manual | `apothem install` / `apothem uninstall` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness antigravity` |

## Apa yang dikelola Apothem

Apothem mengelola berkas konteks global Antigravity, metadata plugin, skill command yang dikonversi, skill yang dapat digunakan ulang, agen yang dikonversi, aturan, templat, dan materi pendukung hook. Berkas hook dipertahankan sebagai materi pendukung; Apothem tidak mendaftarkan event hook Antigravity yang aktif sampai adapter memiliki lapisan terjemahan skema untuk `hooks.json` Antigravity.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum melakukannya.
2. Pindahkan aturan Antigravity yang sudah ada dan ditulis tangan ke dalam korpus bersama.
3. Jalankan `apothem install --harness antigravity` untuk menyebarkan korpus.
4. Jalankan `apothem verify --harness antigravity` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness antigravity` untuk setiap perubahan berikutnya.
