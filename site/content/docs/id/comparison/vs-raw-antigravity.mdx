Antigravity adalah lingkungan propagasi manifes Kelas I: Apothem menulis jangkar
konteks global `~/.gemini/GEMINI.md` dan memasang plugin Apothem di bawah
`~/.gemini/antigravity-cli/plugins/apothem/`. Halaman ini mempertentangkan
pemeliharaan tata letak itu dengan tangan terhadap pengelolaannya dengan Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis aturan | Menulis tiap file aturan plugin dengan tangan | Menulis sekali di korpus bersama |
| Mempertahankan prompt yang dapat dipakai ulang | Menyalin prompt perintah dan skill ke file plugin dengan tangan | Dikonversi atau disalin sebagai skill plugin |
| Mempertahankan materi pendukung hook | Menyalin referensi hook tanpa penyambungan aktif dengan tangan | Disalin di bawah pohon pendukung plugin Apothem |
| Menjaga aturan selaras dengan lingkungan lain | Manual, per alat | Otomatis saat `apothem update` |
| Memasang / menghapus konfigurasi | Menyalin dan menghapus file dengan tangan | `apothem install` / `apothem uninstall` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness antigravity` |

## Apa yang dikelola Apothem

Apothem mengelola file konteks global Antigravity, metadata plugin, skill
perintah yang dikonversi, skill yang dapat dipakai ulang, agen yang dikonversi,
aturan, templat, dan materi pendukung hook. File hook dipertahankan sebagai
materi pendukung; Apothem tidak mendaftarkan event hook Antigravity yang aktif
sampai adapter memiliki lapisan penerjemahan skema untuk `hooks.json`
Antigravity.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum
   memilikinya.
2. Pindahkan aturan Antigravity tulisan-tangan Anda ke korpus bersama.
3. Jalankan `apothem install --harness antigravity` untuk menyebarkan korpus.
4. Jalankan `apothem verify --harness antigravity` untuk memastikan konfigurasi
   sudah terpasang.
5. Gunakan `apothem update --harness antigravity` untuk setiap perubahan
   berikutnya.
