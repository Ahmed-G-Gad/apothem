Hermes membaca `~/.hermes/config.yaml`. Apothem menulis konfigurasi YAML native
(memproyeksikan inventaris MCP milik profil ke dalam `mcp_servers`) dan
memasang kohor command dan skill bersama di bawah
`~/.hermes/.apothem/support/skills/`. `skills.config` milik Hermes sendiri
adalah daftar paket registry, sehingga Apothem tidak menyusunnya.

## Status

**Pratinjau.** Adapter Hermes menargetkan berkas konfigurasi dan permukaan
penemuan skill yang terdokumentasi saat ini. Kohor non-skill tetap menjadi
materi pendukung Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menyusun skill yang dapat digunakan ulang | Menyunting konfigurasi dan direktori skill secara manual | Tulis sekali di korpus bersama |
| Menjaga kohor tetap selaras dengan harness lain | Manual, per alat | Otomatis saat `apothem update` |
| Memasang / menghapus konfigurasi | Manual | `apothem install` / `apothem uninstall` |
| Memverifikasi bahwa konfigurasi benar | Inspeksi manual | `apothem verify --harness hermes` |

## Apa yang dikelola Apothem

Adapter Hermes menulis `config.yaml`, membungkus slash command Apothem sebagai
skill, menyalin skill Apothem ke direktori pendukung yang dirujuk, dan
menyimpan aturan, templat, agen, serta materi hook di bawah support subtree
Apothem.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum
   melakukannya.
2. Pindahkan skill atau prompt command Hermes yang dapat digunakan ulang ke
   dalam korpus bersama.
3. Jalankan `apothem install --harness hermes` untuk merender konfigurasi
   native dan direktori skill pendukung.
4. Jalankan `apothem verify --harness hermes` untuk mengonfirmasi bahwa
   konfigurasi telah mendarat.
