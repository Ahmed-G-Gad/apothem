Hermes membaca `~/.hermes/config.yaml`. Apothem menulis konfigurasi YAML native
(memproyeksikan inventaris MCP profil ke `auxiliary.mcp`) dan memasang kohort
perintah dan skill bersama di bawah `~/.hermes/.apothem/support/skills/`. `skills.config`
milik Hermes sendiri adalah daftar paket registry, jadi Apothem tidak
menulisnya.

## Status

**Pratinjau.** Adaptor Hermes menyasar berkas konfigurasi yang terdokumentasi
saat ini dan permukaan penemuan skill. Kohort non-skill tetap menjadi materi
pendukung Apothem.

## Perbandingan upaya

| Tugas | Config tangan mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis skill yang dapat dipakai ulang | Menyunting tangan config dan direktori skill | Menulis sekali di korpus bersama |
| Menjaga kohort selaras dengan lingkungan lain | Manual, per alat | Otomatis saat `apothem update` |
| Memasang / menghapus config | Manual | `apothem install` / `apothem uninstall` |
| Memverifikasi config sudah benar | Inspeksi manual | `apothem verify --harness hermes` |

## Apa yang dikelola Apothem

Adaptor Hermes menulis `config.yaml`, membungkus perintah garis miring Apothem
sebagai skill, menyalin skill Apothem ke direktori pendukung yang direferensikan,
dan menjaga aturan, templat, agents, dan materi hook di bawah subpohon pendukung
Apothem.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum
   melakukannya.
2. Pindahkan skill atau prompt perintah Hermes yang dapat dipakai ulang ke korpus
   bersama.
3. Jalankan `apothem install --harness hermes` untuk merender konfigurasi native
   dan direktori skill pendukung.
4. Jalankan `apothem verify --harness hermes` untuk mengonfirmasi bahwa
   konfigurasi sudah mendarat.
