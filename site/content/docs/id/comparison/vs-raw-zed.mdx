Zed membaca instruksi agen dari satu file datar `.rules` di akar proyek
(berdampingan dengan keluarga `AGENTS.md` / `CLAUDE.md`). Adapter zed Apothem
merender file itu dari profil bersama. Halaman ini mempertentangkan pemeliharaan
konfigurasi itu dengan tangan terhadap pengelolaannya dengan Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis instruksi | Menulis berkas `.rules` dengan tangan | Dirender dari korpus bersama |
| Mempertahankan `.rules` sebelumnya | Ingat untuk menyalinnya ke samping sendiri | Adapter mencadangkan berkas yang ada sebelum menggantinya |
| Menjaga aturan selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness zed --project <path>` |

## Apa yang dikelola Apothem

Adapter zed merender aturan bersama ke dalam file datar `.rules` di akar proyek.
Zed tidak memiliki hook PreToolUse, jadi maksud pagar pengaman hidup di dalam
prosa aturan alih-alih di titik penyergapan panggilan alat. File instruksi global
`~/.config/zed/AGENTS.md` dan blok server konteks MCP dari `.zed/settings.json`
dimiliki operator dan dibiarkan tak tersentuh. Setiap perubahan pada aturan
bersama merender ulang file pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan instruksi dari `.rules` yang sudah ada (dan konten `AGENTS.md` khusus proyek yang ingin Anda bagikan) ke korpus bersama.
3. Jalankan `apothem install --harness zed --project <path>` untuk merender berkas `.rules`. `.rules` Anda sebelumnya dicadangkan terlebih dahulu.
4. Jalankan `apothem verify --harness zed --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness zed --project <path>` untuk setiap perubahan berikutnya.
