CodeBuddy membaca aturan proyek dari `.codebuddy/rules/*.md`. Anda dapat menulis berkas-berkas itu dengan tangan, per proyek, selamanya. Adapter codebuddy Apothem merender salah satunya dari profil bersama dan menjaganya tetap konsisten di setiap harness dan setiap proyek. Halaman ini membandingkan pemeliharaan konfigurasi itu secara manual dengan pengelolaannya memakai Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis aturan | Salin-tempel disiplin yang sama ke `.codebuddy/rules/` per proyek | Dirender dari satu korpus bersama |
| Sumber kebenaran | Berkas milik setiap proyek | Satu kohor kanonis |
| Menjaga aturan tetap selaras lintas harness | Derivasi ulang per alat | Diproyeksikan otomatis |
| Memperbarui aturan | Sunting tangan di setiap proyek | `apothem update --harness codebuddy --project <path>` |
| Menghapus konfigurasi | Hapus manual | `apothem uninstall` dengan cadangan berstempel waktu |

## Apa yang dikelola Apothem

Adapter codebuddy merender aturan bersama ke dalam berkas khusus `<project>/.codebuddy/rules/apothem-rules.md` dan tidak menulis apa pun selain itu. Berkas memori `CODEBUDDY.md` Anda, izin dan server MCP di `.codebuddy/settings.json`, serta berkas aturan lain yang Anda tulis tetap sepenuhnya milik operator — adapter mengenali permukaan tersebut tetapi tidak pernah menyuntingnya. Setiap perubahan pada aturan bersama merender ulang berkas pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum melakukannya.
2. Pindahkan disiplin dari berkas `.codebuddy/rules/` yang sudah ada ke dalam korpus bersama.
3. Jalankan `apothem install --harness codebuddy --project <path>` untuk merender berkas `apothem-rules.md` berdampingan dengan aturan Anda yang tidak tersentuh.
4. Jalankan `apothem verify --harness codebuddy --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness codebuddy --project <path>` untuk setiap perubahan berikutnya.
