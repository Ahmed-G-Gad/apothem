GitHub Copilot membaca instruksinya dari `.github/copilot-instructions.md`.
Adaptor github-copilot Apothem merender berkas itu dari profil bersama. Halaman
ini mengontraskan pemeliharaan manual konfigurasi tersebut dengan mengelolanya
melalui Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis instruksi | Menyunting `.github/copilot-instructions.md` dengan tangan | Dirender: aturan bersama disematkan ke dalam berkas |
| Menjaga instruksi selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memasang / menghapus konfigurasi | Menulis dan menghapus berkas dengan tangan | `apothem install` / `apothem uninstall` |
| Berbagi skill dan command yang dapat digunakan ulang | Menyalin tiap folder skill ke `~/.agents/skills/` dengan tangan dan menjaga salinannya tetap mutakhir | Ditulis ke `~/.agents/skills/` oleh adapter, satu salinan untuk semua proyek, dan disegarkan pada `apothem update` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness github-copilot --project <path>` |

## Apa yang dikelola Apothem

Adaptor github-copilot menyematkan aturan bersama ke
`.github/copilot-instructions.md`. Copilot mendokumentasikan hook di
`.github/hooks/*.json`, yang tidak ditulis oleh adaptor, jadi maksud pagar pengaman dibawa
sepenuhnya di dalam instruksi yang dirender. Setiap perubahan pada aturan bersama
merender ulang berkas pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan isi `.github/copilot-instructions.md` yang sudah ada ke korpus bersama.
3. Jalankan `apothem install --harness github-copilot --project <path>` untuk merender berkas instruksi.
4. Jalankan `apothem verify --harness github-copilot --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness github-copilot --project <path>` untuk setiap perubahan berikutnya.
