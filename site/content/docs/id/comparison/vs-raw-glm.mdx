GLM (Z.ai) adalah backend model yang diarahkan oleh harness yang kompatibel
dengan menyetel base URL dan sebuah kunci. Anda dapat mengekspor variabel
lingkungan tersebut dengan tangan, per proyek, per mesin, selamanya. Adapter glm
milik Apothem mencatat endpoint backend dan placeholder yang dapat dikonfigurasi
operator dalam satu berkas penyedia dan menulis templat yang sama ke setiap
proyek. Halaman ini membandingkan penyambungan manual backend tersebut dengan
mengelolanya melalui Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Mencatat URL backend | Menghafal dan mengekspor ulang per proyek | Ditulis ke dalam satu berkas penyedia |
| Sumber kebenaran | Ekspor milik masing-masing shell | Satu berkas penyedia kanonis |
| Menjaga backend tetap selaras antarproyek | Menyambungkan ulang per proyek | Templat yang sama ditulis ke setiap proyek |
| Memulihkan konfigurasi | Mengekspor ulang di setiap proyek | `apothem update --harness glm --project <path>` menulis berkas itu lagi hanya ketika berkas tersebut hilang |
| Menghapus konfigurasi | Hapus manual | `apothem uninstall` dengan cadangan |

## Apa yang dikelola Apothem

Adapter glm merender satu berkas penyedia di
`<project>/.apothem/providers/glm.toml` dan tidak menulis apa pun selain itu.
Adapter ini mencatat base URL yang kompatibel dengan Anthropic
(`https://api.z.ai/api/anthropic`), base URL yang kompatibel dengan OpenAI
(`https://api.z.ai/api/coding/paas/v4`), sebuah placeholder token autentikasi,
dan placeholder pemetaan model. Kunci Z.ai Anda dan pilihan ID model Anda tetap
menjadi milik operator — Apothem tidak pernah menulis rahasia sungguhan dan
tidak mematok ID model yang mudah berubah antarversi.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum
   melakukannya.
2. Jalankan `apothem install --harness glm --project <path>` untuk merender
   berkas penyedia `glm.toml`.
3. Isi kunci Z.ai Anda dan ID model yang Anda inginkan dari
   [dokumentasi Z.ai](https://docs.z.ai/devpack/tool/claude) yang terkini.
4. Jalankan `apothem verify --harness glm --project <path>` untuk mengonfirmasi
   bahwa konfigurasi telah mendarat.
5. Sunting `.apothem/providers/glm.toml` untuk setiap perubahan berikutnya.
   Apothem tidak pernah menulis ulang berkas penyedia yang sudah ada;
   `apothem update --harness glm --project
   <path>` menulisnya lagi hanya ketika berkas itu hilang.
