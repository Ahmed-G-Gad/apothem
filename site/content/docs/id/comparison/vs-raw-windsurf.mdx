Windsurf membaca aturan dari direktori `.devin/rules/`. Adaptor windsurf
Apothem merender aturan berbasis direktori dari profil bersama. Halaman ini
mengontraskan pemeliharaan manual konfigurasi tersebut dengan mengelolanya
melalui apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual mentah | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis aturan | Menulis dengan tangan setiap berkas di bawah `.windsurf/rules/` | Dirender dari korpus bersama |
| Menjaga satu format aturan | Memilih dengan tangan antara `.windsurf/rules/` dan satu berkas `.windsurfrules` | Adapter hanya menulis `.devin/rules/` |
| Menjaga aturan selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness windsurf --project <path>` |

## Apa yang dikelola apothem

Adaptor windsurf merender aturan bersama ke direktori `.devin/rules/`; ia
tidak menulis berkas tunggal `.windsurfrules`. Windsurf tidak memiliki hook
PreToolUse, jadi maksud pagar pengaman berada di dalam prosa aturan, bukan pada
titik intersepsi panggilan alat. Setiap perubahan pada aturan bersama merender
ulang direktori pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan aturan dari `.windsurf/rules/` yang sudah ada (dan `.windsurfrules` berkas-tunggal apa pun) ke korpus bersama.
3. Jalankan `apothem install --harness windsurf --project <path>` untuk merender direktori `.devin/rules/`.
4. Jalankan `apothem verify --harness windsurf --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness windsurf --project <path>` untuk setiap perubahan berikutnya.
