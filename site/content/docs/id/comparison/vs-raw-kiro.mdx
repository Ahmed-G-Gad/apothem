Kiro membaca pengarah dari direktori `.kiro/steering/` berisi file Markdown. Adapter
kiro milik Apothem merender file pengarah `apothem-rules.md` khusus dari profil
bersama. Halaman ini mempertentangkan pemeliharaan konfigurasi itu dengan tangan
terhadap pengelolaannya dengan Apothem.

## Perbandingan upaya

| Tugas | Konfigurasi manual | Dikelola Apothem |
| ---- | --------------- | --------------- |
| Menulis aturan pengarah | Menulis tiap file di bawah `.kiro/steering/` dengan tangan | Dirender dari korpus bersama |
| Menjaga file fondasi tetap utuh | Ingat untuk tidak menimpa `product.md` / `tech.md` / `structure.md` | Adapter hanya menulis `apothem-rules.md` |
| Menjaga aturan selaras dengan harness lain | Manual, per alat | Otomatis pada `apothem update` |
| Berbagi skill dan command yang dapat digunakan ulang | Menyalin tiap folder skill ke `~/.kiro/skills/` dengan tangan dan menjaga salinannya tetap mutakhir | Ditulis ke `~/.kiro/skills/` oleh adapter, satu salinan untuk semua proyek, dan disegarkan pada `apothem update` |
| Menjaga helper yang dapat digunakan ulang tetap tersinkron | Menulis tiap file agen kustom di bawah `.kiro/agents/` dengan tangan dan melacak kategori alat Kiro | Empat belas helper ditulis ke `.kiro/agents/` dengan alatnya diterjemahkan, dan disegarkan pada `apothem update` |
| Memverifikasi konfigurasi sudah benar | Inspeksi manual | `apothem verify --harness kiro --project <path>` |

## Apa yang dikelola Apothem

Adapter kiro merender aturan bersama menjadi file pengarah `apothem-rules.md` khusus
dengan front matter `inclusion: always` dan tidak menyentuh file fondasi yang ditulis
operator milik Kiro. Adapter juga menulis empat belas helper Apothem sebagai agen kustom
Kiro di `<project>/.kiro/agents/`, untuk Kiro IDE 1.0 dan Kiro CLI V3. Kiro
mendokumentasikan hook agen, yang tidak ditulis oleh adapter, sehingga niat pagar pengaman
berdiam di dalam prosa aturan alih-alih di titik penyadapan panggilan alat. Setiap
perubahan pada aturan bersama merender ulang file pada `apothem update` berikutnya.

## Jalur migrasi

1. Jalankan `apothem profile init` untuk membuat profil bersama jika Anda belum memilikinya.
2. Pindahkan aturan dari `.kiro/steering/` yang sudah ada ke korpus bersama.
3. Jalankan `apothem install --harness kiro --project <path>` untuk merender berkas pengarah `apothem-rules.md`.
4. Jalankan `apothem verify --harness kiro --project <path>` untuk memastikan konfigurasi sudah terpasang.
5. Gunakan `apothem update --harness kiro --project <path>` untuk setiap perubahan berikutnya.
