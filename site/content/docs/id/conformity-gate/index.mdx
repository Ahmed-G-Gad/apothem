## Tangga tingkat keparahan

| Tingkat keparahan | Efek pada gerbang |
|---|---|
| **Kritis** | Gerbang FAIL — emisi diblokir tanpa syarat |
| **Penting** | Gerbang FAIL ketika 2+ bar Penting gagal secara bersamaan |
| **Anjuran** | Gerbang WARN — dicatat dalam catatan bertanda tangan; tidak memblokir emisi |

Sebagian besar pencocok bagian mekanis secara default bertingkat **Penting**. M5 (otoritas — rahasia, endpoint yang dikarang) dan M12 (keluaran yatim) bertingkat **Kritis**.

## Validator

Bagian mekanis berada di [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity), diorkestrasi oleh [`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py).
Gerbang menjalankan setiap validator dengan salah satu dari tiga cara:

- **per-write**: pada setiap penulisan yang tertunda (`--hook`), atau pada setiap berkas yang dilacak dengan `--all-perwrite`.
- **standalone**: di seluruh repositori dengan `--all`, atau satu per satu dengan `--check <name>`.
- **change-set**: terhadap diff yang di-stage, di luar sapuan gerbang.

## Menjalankan gerbang

Pada harness yang terpasang, gerbang berjalan secara otomatis: `settings.json`
milik Claude Code merangkainya sebagai hook `PreToolUse` yang memanggil salinan
termaterialisasi di `~/.claude/.apothem/support/conformity/gate.py` sebelum
setiap Write/Edit. Dari checkout sumber, bentuk modul menjalankan kode yang
sama. Gerbang bersifat anjuran secara default: gerbang melaporkan temuan dan
keluar dengan `0`. Tambahkan `--strict` untuk keluar dengan `2` pada temuan yang
memblokir. Nama validator yang tidak dikenal keluar dengan `3`.

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help` mencetak ringkasan penggunaan.
Lihat [Menjalankan gerbang konformitas](/docs/usage/conformity-gate) untuk prosedur lengkapnya.
