Mencantumkan dan memeriksa adapter harness yang terdaftar.

`harnesses` adalah grup perintah dengan dua subperintah: `list` dan `show`.

## Ringkasan

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## Subperintah

### `harnesses list`

Mencantumkan semua adapter harness yang terdaftar.

| Opsi | Deskripsi |
|---|---|
| `--quiet`, `-q` | Menekan keluaran informatif; hanya galat yang dipancarkan. |
| `--verbose`, `-v` | Memancarkan keluaran diagnostik tambahan. |
| `--format plain\|json` | Format keluaran (default: `plain`). |
| `--json` | Singkatan untuk `--format json`. |
| `--no-color` | Menonaktifkan kode warna ANSI dalam keluaran. |
| `-h`, `--help` | Menampilkan bantuan dan keluar. |

### `harnesses show NAME`

Menampilkan detail untuk adapter harness tertentu. `NAME` adalah pengidentifikasi
harness dalam kebab-case; jalankan `apothem harnesses list` untuk melihat
pengidentifikasi yang tersedia.

| Opsi | Deskripsi |
|---|---|
| `NAME` | Adapter harness yang akan diperiksa (argumen posisional wajib). |
| `--quiet`, `-q` | Menekan keluaran informatif; hanya galat yang dipancarkan. |
| `--verbose`, `-v` | Memancarkan keluaran diagnostik tambahan. |
| `--format plain\|json` | Format keluaran (default: `plain`). |
| `--json` | Singkatan untuk `--format json`. |
| `--no-color` | Menonaktifkan kode warna ANSI dalam keluaran. |
| `-h`, `--help` | Menampilkan bantuan dan keluar. |

## Contoh

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

ID harness yang terdaftar adalah:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

## Kode keluar

| Kode | Arti |
|---|---|
| 0 | Berhasil |
| 1 | Harness tidak ditemukan (`harnesses show` dengan `NAME` yang tidak dikenal), atau setiap adapter gagal dimuat atau melapor (`harnesses list`) |
| 2 | Setidaknya satu adapter tercantum, tetapi setidaknya satu gagal melapor (`harnesses list`) |
| 64 | Galat penggunaan: opsi atau perintah yang tidak dikenal, atau nilai opsi yang hilang atau tidak valid. Di bawah `--json`, galat berupa amplop JSON dengan kode `cli.usage`. |
