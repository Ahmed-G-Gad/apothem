Menghapus konfigurasi adapter asisten-pengkodean.

## Ringkasan

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

Menghapus target asisten-pengkodean yang dikelola adapter. Meminta konfirmasi kecuali `--yes` disediakan. Jika asisten-pengkodean yang dipilih tidak terpasang, perintah berhasil (keluar 0) dengan pemberitahuan "nothing to remove".

Alias bentuk-kontinu `apothem uninstalling` di-resolve ke handler yang sama.

## Opsi

| Opsi | Deskripsi |
|---|---|
| `--harness NAME` | Adapter asisten-pengkodean yang akan dihapus, atau `all` untuk set selingkup-registri (wajib). |
| `--yes` | Melewati prompt konfirmasi. |
| `--project PATH` | Root proyek untuk asisten-pengkodean berlingkup-proyek. |
| `--quiet`, `-q` | Menekan keluaran informasional; hanya kesalahan yang dipancarkan. |
| `--verbose`, `-v` | Memancarkan keluaran diagnostik tambahan. |
| `--format plain\|json` | Format keluaran (default: `plain`). |
| `--json` | Singkatan untuk `--format json`. |
| `--no-color` | Menonaktifkan kode warna ANSI dalam keluaran. |
| `-h`, `--help` | Menampilkan bantuan dan keluar. |

## Keluaran JSON

Ketika adapter terpasang dan berhasil dihapus:

```json
{"action": "uninstalled", "harness": "claude-code", "output_path": "..."}
```

Ketika adapter tidak terpasang:

```json
{"status": "not_installed", "harness": "claude-code"}
```

## Contoh

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem Uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## Kode keluar

| Kode | Arti |
|---|---|
| 0 | Adapter dihapus, atau tidak terpasang |
| 1 | Asisten-pengkodean tidak ditemukan, atau pengguna membatalkan prompt konfirmasi |
