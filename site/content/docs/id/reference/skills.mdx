Skill berada sebagai folder di bawah `src/apothem/skills/`, masing-masing dengan
titik masuk `SKILL.md`. Skill menangkap teknik yang dapat dipakai ulang dan dapat
dideteksi — skill memiliki sinyal deteksi, prosedur, dan hook penegakan.

Katalog skill lengkap dihasilkan di bawah, di [Inventaris Skill yang
Dihasilkan](#inventaris-skill-yang-dihasilkan).

## Kontrak frontmatter

`SKILL.md` membawa frontmatter delapan kunci yang kanonis. Kontrak yang dapat
dibaca mesin adalah [`skill.schema.json`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/schemas/skill.schema.json)
(`additionalProperties: false`); blok ini mencerminkannya:

```yaml
---
name: <skill name>
version: <semver>
updated: <YYYY-MM-DD>
description: <one-line role>
archetype: <class-template, e.g. workflow-template>
userInvocable: <true | false>
disable-model-invocation: <true | false>
allowed-tools: <comma-separated read-only tools and scoped rules, e.g. "Read, Glob, Grep" or "Read, Bash(git log *)">
---
```

## Emisi per harness

Skill sumber menggunakan kunci di atas. Sebagian harness membaca kunci yang
berbeda, sehingga pemasangan menerjemahkannya hanya untuk harness tersebut:

| Harness | Apa yang diubah pemasangan |
| --- | --- |
| Claude Code (pemasangan dan plugin) | Mengganti nama `userInvocable` menjadi `user-invocable`, kunci yang dibaca Claude Code. Claude Code mengabaikan kunci camelCase, sehingga tanpa penggantian nama itu skill yang ditandai `userInvocable: false` akan tetap muncul di menu `/`. |
| Folder skill tingkat pengguna bersama: `~/.agents/skills/` (ditulis oleh Codex, Cursor, GitHub Copilot, Windsurf, dan Zed) serta `~/.codebuddy/skills/`, `~/.kiro/skills/`, dan `~/.trae/skills/` | Satu bentuk untuk setiap pemasangan yang menulis salah satu folder ini, sehingga pemasangan tidak pernah menulis ulang berkas satu sama lain. Pemasangan ini mengganti nama `userInvocable` menjadi `user-invocable`, memindahkan `version`, `updated`, `archetype`, dan `portability` ke bawah peta `metadata:` di bagian akhir yang berisi string bertanda kutip, dan menulis `agents/openai.yaml` dengan `policy.allow_implicit_invocation: false` di samping setiap skill yang sumbernya menetapkan `disable-model-invocation: true`, karena Codex mengabaikan kunci tersebut dan membaca `~/.agents/skills/` terlepas dari apakah adapter Codex yang menulisnya atau bukan. Perintah yang dibungkus sebagai skill mempertahankan isinya secara utuh dan dibuka dengan satu catatan tetap yang menyebutkan folder aturan dan templat, `~/.config/apothem/rules/` dan `~/.config/apothem/templates/`. Kunci tingkat atas yang tersisa adalah `name`, `description`, `user-invocable`, `disable-model-invocation`, `allowed-tools`, `argument-hint`, dan `metadata`. |
| Qwen Code | Menulis ulang string `allowed-tools` yang dipisahkan koma sebagai daftar `allowedTools`, satu entri YAML per baris, karena `Qwen Code` hanya membaca kunci camelCase dan mensyaratkan sebuah daftar. Setiap entri mempertahankan ejaan sumbernya, termasuk pola seperti `Bash(git status *)`. Setiap kunci lain dan isi skill dipasang tanpa perubahan. |
| Harness lain | Tidak ada perubahan. |

`skill.schema.json` menerima salah satu dari kedua ejaan flag user-invocability
dan mewajibkan tepat satu di antaranya.

## Disiplin penulisan

- **Satu folder per skill.** Setiap skill adalah folder tersendiri dengan titik
  masuk di `SKILL.md`.
- **Sinyal deteksi.** Isi skill dibuka dengan sinyal deteksi yang memicu teknik
  tersebut.
- **Prosedur + penegakan.** Skill membawa baik prosedur yang diterapkan maupun
  sinyal penegakan yang menutup loop.
- **Panjang deskripsi.** `description` paling banyak 1.024 karakter, batas
  [Agent Skills](https://agentskills.io/specification). Tool yang lebih ketat
  menolak atau memotong deskripsi yang lebih panjang, dan skema menegakkan batas
  tersebut.
