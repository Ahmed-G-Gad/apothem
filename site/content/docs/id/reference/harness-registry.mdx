Registri harness adalah inventaris adaptor sumber-kebenaran yang digunakan oleh CLI,
dokumentasi, uji fixture, dan validasi pin konvensi. Sumber saat runtime adalah
`src/apothem/lib/harness_registry.py`; setiap baris di bawah dapat dilacak ke registri itu,
ke `capabilities.yml` setiap adaptor, dan ke `STANDARD-CONVENTION-PIN.md` setiap adaptor.

## Hook validasi

Registri tetap tersinkronisasi melalui pemeriksaan berikut:

| Pemeriksaan | Tujuan |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | Memastikan setiap adaptor memiliki pin konvensi terkini dan registri masih menyebutkan tujuh belas adaptor. |
| `python -m apothem.conformity.gate --all .` | Menjalankan pemeriksaan konformitas dokumentasi dan implementasi. |
| `python -m pytest` | Menjalankan uji fixture registri dan uji kontrak adaptor. |
