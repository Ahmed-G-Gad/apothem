> **Referensi kanonik untuk bentuk nama berkas, pengidentifikasi, dan nama branch di seluruh ekosistem.** Ringkasan di [`CLAUDE.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CLAUDE.md) Konvensi adalah deklarasi inline; halaman ini adalah referensi mandiri yang dirujuk kontributor hilir.

---

## 1. Nama sistem berkas

Berkas dan folder menggunakan **kebab-case** secara default. Pengidentifikasi tidak membawa spasi, garis bawah, maupun camel-case.

Pengecualian huruf besar kanonik disediakan untuk berkas singleton permukaan publikasi yang dikenali setiap kontributor pada perjumpaan pertama: `CLAUDE.md`, `README.md`, `LICENSE`, `CHANGELOG.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, dan singleton suite rencana (`MASTER-PLAN.md`, `PROGRESS.md`, `PHASE.md`, `SKILL.md`, `VERSION`). Setiap berkas lainnya menggunakan kebab-case.

## 2. Kunci frontmatter

Kunci frontmatter command menggunakan `kebab-case` (misalnya, `argument-hint`, `disable-model-invocation`, `allowed-tools`). Kunci skill menggunakan `kebab-case` kecuali `userInvocable`, ejaan camelCase yang dipakai korpus sumber; instalasi Claude Code mengganti namanya menjadi `user-invocable`. Kunci aturan dan pekerja terdelegasi menggunakan camelCase (misalnya, `pathFilter`, `alwaysApply`, `maxTurns`, `disallowedTools`). Tabel kunci wajib pada [skema frontmatter](/docs/reference/frontmatter-schema) mencantumkan kunci untuk setiap kelas.

## 3. Nama branch

Branch mengikuti `<type>/<short-description>` dengan tipe yang diambil dari himpunan tertutup `{feat, fix, chore, docs, refactor, test, perf, ci, build, style, revert, release}`. Deskripsinya kebab-case dan kurang dari lima puluh karakter.

## 4. Prefiks numerik

Prefiks numerik (`NN-`) pada path sistem berkas menyampaikan pengurutan dan hanya berlaku di tempat pengurutan bersifat intrinsik — folder fase, folder subfase, skrip migrasi, dan kelas artefak lain mana pun yang urutannya merupakan bagian dari kontrak. Singleton tingkat-root yang tidak memiliki urutan saudara tidak membawa prefiks numerik; menambahkannya salah menandakan hubungan pengurutan yang tidak ada. Disiplin lengkap berada di [`src/apothem/rules/canonical-layout.md`](https://github.com/ahmed-g-gad/apothem/blob/main/rules/canonical-layout.md) §2.1.

## 5. Validator

naming-grep di `src/apothem/conformity/naming_grep.py` adalah permukaan penegakan mekanis. CI memanggilnya melalui `make validate`.
