CLI `apothem` adalah antarmuka operator utama untuk mengelola profil bersama dan
adaptor harness.

## Flag global

| Flag | Deskripsi |
|------|-------------|
| `--version` | Mencetak versi Apothem dan keluar |
| `--help` | Mencetak bantuan untuk perintah |

## Subperintah

### `apothem install`

Memasang adaptor harness dari profil bersama.

```bash
apothem install --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| Opsi | Deskripsi |
|--------|-------------|
| `--harness <name>` | Nama adaptor harness (lihat nilai kanonis di bawah). Wajib. |
| `--profile PATH` | Path ke YAML profil bersama. Default-nya `~/.config/apothem/profile.yaml`. |
| `--project PATH` | Root proyek untuk harness berlingkup proyek. |
| `--dry-run` | Pratinjau pemasangan tanpa menulis berkas. |

Nilai `--harness` kanonis:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

Gunakan `--harness all --project <path>` untuk memilih kumpulan seluruh
registri. Daftar `exclude_harnesses` pada profil dihormati selama pemilihan batch
pemasangan/pembaruan.

### `apothem update`

Menurunkan ulang konfigurasi native sebuah adaptor harness dari profil bersama
saat ini.

```bash
apothem update --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| Opsi | Deskripsi |
|--------|-------------|
| `--harness <name>` | Nama adaptor harness. Wajib. |
| `--profile PATH` | Path ke YAML profil bersama. |
| `--project PATH` | Root proyek untuk harness berlingkup proyek. |
| `--dry-run` | Pratinjau pembaruan tanpa menulis berkas. |

`update` mematerialisasi ulang keluaran harness. Perintah ini tidak memperbarui
paket CLI Apothem; untuk peningkatan paket, gunakan pengelola paket yang dipakai
memasang Apothem.

### `apothem uninstall`

Menghapus konfigurasi native sebuah adaptor harness.

```bash
apothem uninstall --harness <name|all> [--project PATH] [--yes]
```

| Opsi | Deskripsi |
|--------|-------------|
| `--harness <name>` | Nama adaptor harness. Wajib. |
| `--project PATH` | Root proyek untuk harness berlingkup proyek. |
| `--yes` | Melewati prompt konfirmasi. |

### `apothem verify`

Memverifikasi bahwa sebuah adaptor harness terpasang dan path keluarannya ada.

```bash
apothem verify --harness <name|all> [--project PATH]
```

| Opsi | Deskripsi |
|--------|-------------|
| `--harness <name>` | Nama adaptor harness atau `all`. Wajib. |
| `--project PATH` | Root proyek untuk harness berlingkup proyek. |

Kode keluar adalah `0` saat adaptor terpasang, dan `1` saat tidak.

### `apothem profile`

Mengelola profil bersama Apothem.

```bash
apothem profile show [--profile PATH]
apothem profile init [--profile PATH] [--force]
apothem profile set <key> <value> [--profile PATH]
apothem profile edit [--profile PATH]
```

| Subperintah | Deskripsi |
|------------|-------------|
| `profile init` | Membuat kerangka profil minimal yang valid menurut skema. |
| `profile show` | Mencetak profil yang telah diselesaikan (YAML) ke stdout. |
| `profile set <key> <value>` | Menetapkan sebuah field profil. Nilainya diurai sebagai YAML (string, angka, boolean, daftar, dan pemetaan semuanya diterima). |
| `profile edit` | Membuka profil di `$EDITOR` (jatuh ke editor default platform). |

Opsi `--profile PATH` mengarahkan tiap subperintah ke berkas profil alternatif.
Default-nya `~/.config/apothem/profile.yaml`.

### `apothem harnesses`

Mendaftar dan memeriksa adaptor harness yang terdaftar.

```bash
apothem harnesses list
apothem harnesses show <name>
```

| Subperintah | Deskripsi |
|------------|-------------|
| `harnesses list` | Mencetak tabel setiap adaptor terdaftar beserta flag status pemasangan dan path keluarannya. |
| `harnesses show <name>` | Mencetak nama, status pemasangan, dan path keluaran sebuah adaptor. |

### `apothem doctor`

Menjalankan diagnostik sistem untuk pemasangan Apothem.

```bash
apothem doctor
```

Mencetak versi Apothem, interpreter Python, platform, path profil yang
diselesaikan, dan tabel status pemasangan per harness. Kode keluar adalah `0`
saat setiap adaptor terdaftar melaporkan terpasang; selain itu `1`.
