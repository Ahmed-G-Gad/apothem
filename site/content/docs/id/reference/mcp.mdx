Server Model Context Protocol (MCP) **dimiliki operator**. Apothem membawa
inventaris MCP di profil bersama (`mcp_servers`). Adapter yang tool-nya
menyimpan server MCP di berkas konfigurasi yang sudah ditulis Apothem
memproyeksikan inventaris itu ke dalam berkas tersebut; setiap adapter lain
tidak menulis entri server apa pun, dan pendaftaran server tetap menjadi urusan
Anda melalui tool tersebut.

## Tempat server MCP didaftarkan

Setiap tool mendaftarkan server MCP melalui mekanisme native-nya sendiri, dan
Apothem menghormati permukaan itu alih-alih menimpanya. Di Claude Code, server
didaftarkan dengan `claude mcp add` ke `~/.claude.json` (lingkup user atau local)
dan `.mcp.json` tingkat proyek; adapter Claude Code tidak menulis kedua berkas
itu, dan pengaturan Claude Code terkelola milik Apothem tidak pernah membawa blok
`mcpServers`.

## Menambahkan server

Daftarkan server melalui mekanisme native tool Anda; bentuk entri kanonisnya
adalah satu kunci di bawah `mcpServers`:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

Runtime tool memuat server yang terdaftar saat sesi dimulai; mulai ulang tool
untuk memuat server baru.

## Konvensi penamaan

Tool MCP tampil ke asisten sebagai `mcp__<server>__<tool>` sesuai konvensi
penamaan tool MCP standar milik tool tersebut.
