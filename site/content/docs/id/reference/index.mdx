Referensi per kelas artefak. Setiap halaman menjelaskan tujuan kelas, tata letak di disk, kontrak frontmatter, dan registri yang mendaftar setiap instansi.

Jalur relatif-repositori ditampilkan di bawah; setiap adapter memmaterialisasikannya ke direktori konfigurasi natifnya (mis. `~/.claude/` untuk adapter Claude Code — lihat [`site/content/docs/harnesses/<harness>.mdx`](/docs/harnesses) untuk tujuan tiap harness).

Registri kanonis lengkap tersebar di seluruh kohort artefak (`rules/`, `commands/`, `skills/`, `agents/`, `hooks/`). Halaman ini mencerminkan registri itu dalam bentuk yang dapat dinavigasi.
