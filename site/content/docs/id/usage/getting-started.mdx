Apothem menyediakan empat kemampuan inti: profil tata kelola bersama, korpus
aturan, pipeline perencanaan terstruktur, dan gerbang konformitas waktu nyata.

<Callout title="Baru di sini?">
  Untuk panduan terbimbing dari nol hingga eksekusi pertama, mulailah dengan
  [tutorial Memulai](/docs/tutorials/getting-started). Halaman ini adalah
  referensi cepat untuk keempat alur kerja inti setelah Anda selesai
  menyiapkan.
</Callout>

## Profil bersama

Profil Apothem Anda berada di `~/.config/apothem/profile.yaml` kecuali Anda
meneruskan `--profile PATH`. Profil ini adalah satu-satunya sumber kebenaran
tempat setiap adapter harness menurunkan konfigurasi native:

```yaml
identity:
  name: "Example User"
preferences:
  style: "concise"
rules:
  - "Validate external input before writing files."
```

Buat profil jika belum ada, lalu periksa. Pemasang satu langkah dan
`apothem install` sudah menulis profil awal pada eksekusi pertama, dan
`profile init` berhenti dengan kesalahan serta membiarkan berkas yang sudah ada
tidak berubah kecuali Anda meneruskan `--force`.

```bash
apothem profile init
apothem profile show --json
```

## Aturan pertama

Tambahkan aturan bersama ke YAML profil, lalu materialisasikan ulang harness
yang dipilih. Saat aturan itu menyertakan data contoh, gunakan placeholder
palsu agar tidak ada identitas atau kredensial nyata yang masuk ke profil
bersama atau ke run CI.

```bash
apothem profile set rules '["Always include a brief summary at the end of every response."]'
apothem update --harness claude-code
apothem verify --harness claude-code
```

## Rencana pertama

Pipeline `/plan` berjalan di dalam harness Anda sebagai slash command, bukan
melalui biner `apothem`. Setelah sebuah harness terpasang, mulai sebuah rencana
dari obrolan perkakas tersebut:

```text
/plan-spec
```

`/plan-spec` menyempurnakan prosa Anda menjadi spesifikasi, dan `/plan-generate`
mematerialisasikan suite rencana di bawah `<project-root>/.apothem/plans/{suite}/`.
Lihat [referensi perintah pipeline](/docs/pipeline) untuk alur lengkapnya.

## Gerbang konformitas

Dari checkout Apothem, jalankan:

```bash
PYTHONPATH=src python -m apothem.conformity.gate --all .
```

Setelah pemasangan skrip, jalankan:

```bash
PYTHONPATH="$HOME/.apothem/src" python3 -m apothem.conformity.gate --all .
```

Menjalankan semua pemeriksaan konformitas mekanis dan melaporkan lulus/gagal per
bar.
