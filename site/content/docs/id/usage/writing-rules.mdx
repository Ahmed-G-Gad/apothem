Aturan adalah berkas Markdown di `src/apothem/rules/` dengan ekstensi `.md`.

## Frontmatter aturan

```yaml
---
name: "..."
description: "..."
pathFilter: ""            # empty string for always-on; a glob for path-filtered
alwaysApply: true         # true for always-on; false for path-filtered
---
```

## Cakupan aturan

Cakupan aturan ditetapkan oleh dua field frontmatter, `alwaysApply` dan `pathFilter`:

| `alwaysApply` | `pathFilter` | Kapan diterapkan |
|---------------|--------------|--------------|
| `true` | `""` (kosong) | Selalu aktif: setiap sesi, setiap berkas |
| `false` | glob seperti `"**/*.py"` | Berbasis path: hanya ketika berkas aktif cocok dengan glob |

## Contoh aturan

```markdown
---
name: "python-conventions"
description: "Python style conventions for this project"
pathFilter: "**/*.py"
alwaysApply: false
---

# Python conventions

- Use type annotations on all public functions.
- Maximum line length: 88 characters.
- Prefer explicit over implicit.
```

## Menerapkan aturan ke harness

Setelah menulis aturan, perbarui setiap adapter harness yang terpasang. Jalankan `apothem harnesses list` untuk melihat kumpulan yang terpasang, lalu panggil update satu kali untuk setiap harness:

```bash
apothem update --harness claude-code
apothem update --harness cursor
```

## Validasi aturan

```bash
python -m apothem.conformity.gate --check frontmatter
```
