Hook adalah perintah shell yang terpicu pada peristiwa harness. Hook menegakkan
kesesuaian, menyuntikkan konteks, dan menjalankan gerbang kualitas tanpa campur
tangan operator.

## Peristiwa hook

| Peristiwa | Kapan terpicu |
|-------|--------------|
| `PreToolUse` | Sebelum setiap panggilan alat |
| `PostToolUse` | Setelah setiap panggilan alat |
| `SessionStart` | Saat bootstrap sesi |
| `PreCompact` | Sebelum pemadatan konteks |
| `PostCompact` | Setelah pemadatan konteks |
| `Stop` | Pada akhir sesi |

## Berkas pesan hook

Setiap hook memiliki berkas pesan terkait di
`src/apothem/hooks/messages/<event>-<name>.md` yang menyediakan konteks ke
asisten pada saat hook terpicu.

## Mendaftarkan hook

Tambahkan perintah hook ke `settings.json`:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "python src/apothem/hooks/my-check.py"
          }
        ]
      }
    ]
  }
}
```

## Pengirim hook

Semua hook dirutekan melalui `src/apothem/hooks/dispatch.py`, yang mengubah
setiap kesalahan hook menjadi amplop fail-open sehingga hook tidak pernah
memblokir harness.
