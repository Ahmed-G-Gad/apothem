Alur kerja sehari-hari. Panduan ini mencakup empat kemampuan inti Apothem —
profil tata kelola bersama, aturan perilaku, alur `/plan` dan `/research`, serta
gerbang kesesuaian — ditambah penulisan pekerja terdelegasi dan hook.
