**Vendor:** ByteDance
**Nama instalasi:** `trae`
**Status:** GA
**Konfigurasi native:** `<project>/.trae/rules/apothem-rules.md`

## Instalasi

```bash
apothem install --harness trae --project /path/to/project
```

Adapter menulis satu berkas aturan Trae berlingkup proyek dari aturan dan
permukaan tata kelola Apothem bersama.

**Berkas yang ditulis:** `<project>/.trae/rules/apothem-rules.md`

## Pemetaan profil ke konfigurasi native

Adapter membaca profil bersama Apothem dan merender berkas aturan proyek pada
setiap kali `apothem install` atau `apothem update` dijalankan. Profil bersama
adalah sumber kebenaran; suntingan lokal-proyek pada berkas yang dihasilkan
dicadangkan sebelum sinkronisasi berikutnya mengganti konten yang dikelola
Apothem.

Berkas dibuka dengan frontmatter YAML yang menetapkan `alwaysApply: true` dan
sebuah `description`, yang merupakan mode Always Apply Trae menurut
[dokumentasi aturan Trae](https://docs.trae.ai/ide/rules). Blok yang dikelola
Apothem mengikutinya; teks yang Anda tambahkan setelah blok tersebut
dipertahankan pada setiap sinkronisasi.

## Catatan kompatibilitas

Permukaan aturan Trae saat ini berlingkup proyek di bawah `.trae/rules/`;
aturan global berada di bawah `~/.trae/user_rules`. Adapter menulis berkas
`apothem-rules.md` khusus dan tidak pernah menimpa berkas aturan lain di
direktori tersebut maupun aturan global Anda. Permukaan server alat
`.trae/mcp.json` dan permukaan skill `.trae/skills/` dimiliki operator; Apothem
tidak menulisnya.

## Verifikasi

```bash
apothem verify --harness trae --project /path/to/project
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Setiap target terkelola ada; berkas terkelola tidak kosong, dan konfigurasi
   JSON atau YAML dapat diurai. Tambahkan `--profile PATH` untuk juga
   memastikan bahwa berkas yang terpasang cocok dengan profil tersebut.
3. Rutin verifikasi khusus adapter melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness trae --project /path/to/project
```

Menurunkan ulang berkas aturan proyek dari keadaan profil bersama saat ini.

## Pencopotan

```bash
apothem uninstall --harness trae --project /path/to/project
```

Menghapus blok Apothem, beserta frontmatter yang ditulis Apothem di atasnya, dari
`<project>/.trae/rules/apothem-rules.md` dan mempertahankan teks lain di
dalamnya. Berkas itu dihapus hanya ketika tidak ada lagi yang tersisa di
dalamnya. Sebelum perubahan, salinan berkas bercap waktu disimpan di bawah
`~/.apothem/backups/`; tidak ada berkas cadangan yang tertinggal di proyek. YAML
profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness trae --project /path/to/project` |
| Verifikasi gagal | Jalankan `apothem update --harness trae --project /path/to/project`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness trae --project /path/to/project` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
