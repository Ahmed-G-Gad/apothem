**Vendor:** Anthropic
**Nama instal:** `claude-code`
**Status:** GA
**Konfigurasi native:** `~/.claude/`

## Instalasi

```bash
apothem install --harness claude-code
```

Adaptor `claude-code` menginstal korpus Apothem bersama ke dalam pohon penemuan
native Claude Code. Agen Markdown, aturan, skill, gaya keluaran, pembantu baris
status, dan pengaturan diinstal di lokasi native-nya; prompt perintah juga
dibungkus sebagai skill agar alur kerja yang dapat digunakan kembali tetap terlihat
melalui permukaan skill Claude Code saat ini.

**Berkas yang ditulis:** `settings.json`, `agents/`, `rules/`, `skills/`,
`statuslines/`, `output-styles/`, dan subpohon dukungan `apothem/`
(`apothem/hooks/`, `apothem/conformity/`, `apothem/schemas/`,
`apothem/templates/`) di bawah `~/.claude/`. Berkas perintah dikonversi menjadi
direktori skill anak. Dispatcher hook dan gerbang konformitas berjalan dari salinan
materialisasinya — entri hook di `settings.json` memanggil
`~/.claude/.apothem/support/hooks/dispatch.py` dan
`~/.claude/.apothem/support/conformity/gate.py` melalui jalur absolut, sehingga tidak
diperlukan paket `apothem` yang dapat diimpor pada host.

Adaptor **tidak** mengelola `CLAUDE.md` — berkas itu adalah wilayah milik operator.
Permukaan tata kelola Apothem menjangkau Claude Code melalui pohon `rules/` yang
dipropagasikan dan hook SessionStart, bukan melalui `CLAUDE.md` yang
dimaterialisasi.

## Pemetaan profil ke konfigurasi native

Pada setiap `apothem install` atau `apothem update`, adaptor mempropagasikan korpus
`apothem` bersama ke `~/.claude/` sesuai manifes propagasi. Adaptor menggunakan
direktori native secara langsung jika memungkinkan dan mengonversi prompt perintah
menjadi folder skill. Anak yang cocok dan dikelola Apothem yang sudah ada
dicadangkan sebelum penggantian; entri tak terkait yang ditulis operator
dipertahankan. `settings.json` digabungkan agar kunci yang ditulis operator tetap
dapat dipulihkan.

## Catatan kompatibilitas

Tidak ada penerjemahan yang terjadi. Instalasi memvalidasi bahwa profil terbentuk dengan baik dan semua ikatan hook di settings.json dapat di-resolve.

Claude Code menerapkan semua ikatan hook di settings.json pada setiap awal sesi. Setiap adaptor diverifikasi terhadap harness native-nya sendiri — tidak ada harness "referensi" yang diistimewakan.

## Verifikasi

```bash
apothem verify --harness claude-code
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pemutakhiran

```bash
apothem update --harness claude-code
```

Menurunkan-ulang konfigurasi native dari profil bersama saat ini. Jalankan setelah
paket `apothem` yang terinstal diperbarui, agar permukaan konvensi yang
dipropagasikan (agen, aturan, skill, baris status, gaya keluaran) mencerminkan versi
baru. `CLAUDE.md` adalah milik operator dan tidak pernah disentuh oleh adaptor.

## Pencopotan

```bash
apothem uninstall --harness claude-code
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
Paket `apothem` yang terinstal dan repositori sumber tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness claude-code` |
| Verifikasi gagal | Jalankan `apothem update --harness claude-code`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Jalankan ulang `apothem update`; profil `apothem` bersama adalah sumber kebenaran, bukan `~/.claude/` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
