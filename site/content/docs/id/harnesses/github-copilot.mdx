**Vendor:** GitHub / Microsoft
**Nama instal:** `github-copilot`
**Status:** GA
**Konfigurasi native:** `<project>/.github/copilot-instructions.md`

## Instalasi

```bash
apothem install --harness github-copilot --project /path/to/project
```

Adaptor menurunkan berkas instruksi proyek dari aturan Apothem bersama dan permukaan
tata kelola.

**Berkas yang ditulis:** `<project>/.github/copilot-instructions.md`

## Pemetaan profil ke konfigurasi native

Adaptor membaca profil Apothem bersama dan merender berkas instruksi Copilot
seluruh repositori pada setiap jalannya `apothem install` atau `apothem update`.
Profil bersama adalah sumber kebenaran; suntingan lokal proyek pada berkas yang
dihasilkan dicadangkan sebelum sinkronisasi berikutnya menggantikan konten yang
dikelola Apothem.

## Catatan kompatibilitas

GitHub Copilot tidak mengekspos jalur instruksi global pengguna berbasis berkas yang
dapat dikelola adaptor ini. Apothem menargetkan berkas instruksi cakupan proyek yang
terdokumentasi dan membiarkan pengaturan pengguna tingkat IDE tetap dimiliki operator.

Apothem memperlakukan `copilot-instructions.md` sebagai satu suara di antara permukaan
instruksi asisten proyek: pemeriksaan koherensi multi-permukaan pada gerbang
konformitas memverifikasi bahwa klaim bersamanya tetap selaras secara semantik dengan
berkas instruksi proyek lainnya, sehingga Copilot tidak pernah menerima panduan yang
bertentangan dengan apa yang dibaca oleh bagian lain rantai alat.

## Verifikasi

```bash
apothem verify --harness github-copilot --project /path/to/project
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pemutakhiran

```bash
apothem update --harness github-copilot --project /path/to/project
```

Menurunkan-ulang berkas instruksi proyek dari keadaan profil bersama saat ini.

## Pencopotan

```bash
apothem uninstall --harness github-copilot --project /path/to/project
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness github-copilot --project /path/to/project` |
| Verifikasi gagal | Jalankan `apothem update --harness github-copilot --project /path/to/project`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness github-copilot --project /path/to/project` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
