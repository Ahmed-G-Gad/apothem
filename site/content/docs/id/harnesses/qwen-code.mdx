**Vendor:** Alibaba Cloud
**Nama instalasi:** `qwen-code`
**Status:** Beta
**Konfigurasi native:** `~/.qwen/`

## Instalasi

```bash
apothem install --harness qwen-code
```

Adaptor menulis pengaturan Qwen Code, memasang jangkar konteks `QWEN.md`,
mendaftarkan dispatcher hook Apothem, mengonversi perintah Apothem menjadi berkas
perintah Markdown Qwen, memasang keterampilan sebagai direktori SKILL.md, dan
menyesuaikan definisi asisten sebagai subagen Qwen.

**Berkas yang ditulis:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

## Pemetaan profil ke konfigurasi native

Adaptor merender kunci `settings.json` yang terdokumentasi untuk konteks dan hook,
menulis `QWEN.md`, serta menjalin perintah, keterampilan, dan definisi asisten
Apothem melalui direktori penemuan native Qwen Code. Aturan, templat, dan material
sumber hook tetap menjadi material dukungan di bawah `~/.qwen/.apothem/support/`.

## Catatan kompatibilitas

`~/.qwen/.apothem/support/` adalah material dukungan yang dirujuk oleh `QWEN.md` dan perintah
hook pada pengaturan; ini bukan namespace penemuan milik vendor.

## Verifikasi

```bash
apothem verify --harness qwen-code
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness qwen-code
```

Menyegarkan `settings.json`, `QWEN.md`, perintah native, keterampilan, subagen, dan
pohon dukungan Apothem.

## Pencopotan

```bash
apothem uninstall --harness qwen-code
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness qwen-code` |
| Verifikasi gagal | Jalankan `apothem update --harness qwen-code`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness qwen-code` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
