**Vendor:** Alibaba Cloud
**Nama instalasi:** `qwen-code`
**Status:** Beta
**Konfigurasi native:** `~/.qwen/`

## Instalasi

```bash
apothem install --harness qwen-code
```

Adapter menulis pengaturan Qwen Code, memasang jangkar konteks `QWEN.md`,
mendaftarkan dispatcher hook Apothem, mengonversi command Apothem menjadi berkas
command Markdown Qwen, memasang skill sebagai direktori SKILL.md, dan
mengadaptasi definisi helper sebagai subagen Qwen.

**Berkas yang ditulis:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/apothem/rules/00-apothem-profile.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

Berkas `~/.qwen/apothem/rules/00-apothem-profile.md` adalah dokumen profil.
Berkas ini membawa identitas dan preferensi Anda dari profil bersama.

## Pemetaan profil ke konfigurasi native

Adapter merender kunci `settings.json` yang terdokumentasi untuk konteks dan
hook, menulis `QWEN.md`, serta menjalin command, skill, dan definisi helper
Apothem melalui direktori penemuan native Qwen Code. Aturan, templat, dan materi
sumber hook tetap menjadi materi dukungan di bawah `~/.qwen/.apothem/support/`.

## Catatan kompatibilitas

`~/.qwen/.apothem/support/` adalah materi dukungan yang dirujuk oleh `QWEN.md`
dan command hook pada pengaturan; ini bukan namespace penemuan milik vendor.
Blok Apothem di `QWEN.md` diakhiri dengan bagian berkas dukungan Apothem yang
menyebutkan direktori absolut di bawah `~/.qwen/.apothem/support/` yang menjadi
acuan resolusi setiap sitasi bergaya repositori (`rules/<name>.md`,
`templates/...`, `hooks/...`).

## Verifikasi

```bash
apothem verify --harness qwen-code
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Setiap target terkelola ada; berkas terkelola tidak kosong, dan konfigurasi
   JSON atau YAML dapat diurai. Tambahkan `--profile PATH` untuk juga
   memastikan bahwa berkas yang terpasang cocok dengan profil tersebut.
3. Rutin verifikasi khusus adapter melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness qwen-code
```

Menyegarkan `settings.json`, `QWEN.md`, command native, skill, subagen, dan
pohon dukungan Apothem.

## Pencopotan

```bash
apothem uninstall --harness qwen-code
```

Menghapus entri yang ditambahkan adapter ke `~/.qwen/settings.json` (kunci Anda
sendiri, server MCP, dan handler hook tetap ada, dan berkas itu dihapus hanya
ketika Apothem yang membuatnya dan tidak ada lagi yang tersisa milik Anda).
Menghapus blok Apothem dari `~/.qwen/QWEN.md` dan dari dokumen profil
`~/.qwen/apothem/rules/00-apothem-profile.md` dan mempertahankan teks lain di
dalamnya; setiap berkas dihapus hanya ketika tidak ada lagi yang tersisa di
dalamnya. Juga menghapus berkas Apothem di `~/.qwen/commands/`,
`~/.qwen/skills/`, `~/.qwen/agents/`, dan `~/.qwen/.apothem/support/`; berkas
lain di folder-folder tersebut tetap ada. Setiap berkas dicadangkan di bawah
`~/.apothem/backups/` sebelum diubah atau dihapus. YAML profil bersama dan mesin
Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness qwen-code` |
| Verifikasi gagal | Jalankan `apothem update --harness qwen-code`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness qwen-code` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
