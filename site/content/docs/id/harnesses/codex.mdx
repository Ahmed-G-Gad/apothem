**Vendor:** OpenAI
**Nama instal:** `codex`
**Status:** Beta
**Konfigurasi native:** `~/.codex/AGENTS.md`, `~/.codex/hooks.json`,
`~/.codex/hooks/`, `~/.codex/agents/*.toml`, dan `~/.agents/skills/`

## Instalasi

```bash
apothem install --harness codex
```

Adaptor memasang instruksi dan hook native Codex, mengonversi agen Apothem menjadi agen
TOML Codex, dan membungkus prompt perintah yang dapat dipakai ulang sebagai skill Codex.

**Berkas yang ditulis:** `~/.codex/AGENTS.md`, `~/.codex/hooks.json`,
`~/.codex/hooks/`, `~/.codex/agents/*.toml`,
`~/.agents/skills/*/SKILL.md`, dan berkas dukungan di bawah
`~/.config/apothem/{rules,templates}/`.

## Pemetaan profil ke konfigurasi native

Adaptor membaca kohort bersama Apothem dan memasang masing-masing ke permukaan Codex
yang tepat: instruksi ke `AGENTS.md`, hook ke `hooks.json` dan `hooks/`, agen ke TOML,
skill ke `~/.agents/skills/`, dan aturan/template Markdown non-native ke
`~/.config/apothem/` sebagai materi dukungan.

## Catatan kompatibilitas

Codex menyediakan `~/.codex/rules/` untuk kebijakan eksekusi `.rules`. Apothem tidak
menempatkan aturan perilaku Markdown di sana; ia menyimpannya di `~/.config/apothem/` dan
merujuknya dari `AGENTS.md` dan skill yang terpasang.

## Verifikasi

```bash
apothem verify --harness codex
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pemutakhiran

```bash
apothem update --harness codex
```

Menyegarkan bootstrap Codex, agen yang dikonversi, skill, dan kohort dukungan.

## Pencopotan

```bash
apothem uninstall --harness codex
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor. YAML profil bersama dan
mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness codex` |
| Verifikasi gagal | Jalankan `apothem update --harness codex`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness codex` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
