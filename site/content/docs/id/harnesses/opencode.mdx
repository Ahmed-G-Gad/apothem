**Vendor:** OpenCode
**Nama instalasi:** `opencode`
**Status:** Beta
**Konfigurasi native:** `~/.config/opencode/`

## Instalasi

```bash
apothem install --harness opencode
```

Adaptor menulis konfigurasi JSON OpenCode, memasang keterampilan Apothem ke
permukaan keterampilan OpenCode, mengonversi prompt perintah menjadi berkas
perintah Markdown OpenCode, dan menormalkan definisi asisten Apothem sebagai
sub-asisten OpenCode.

**Berkas yang ditulis:**

```text
~/.config/opencode/opencode.json
~/.config/opencode/commands/
~/.config/opencode/skills/
~/.config/opencode/agents/
~/.config/opencode/.apothem/support/{rules,templates,hooks}/
```

## Pemetaan profil ke konfigurasi native

Adaptor merender `opencode.json` dengan daftar berkas `instructions` yang menunjuk
ke aturan Apothem yang terpasang, lalu menyebarkan setiap kumpulan bersama Apothem
ke permukaan native OpenCode atau ke subpohon dukungan milik Apothem. Anak yang
cocok dan sudah dikelola Apothem dicadangkan sebelum penggantian.

## Catatan kompatibilitas

Aturan dirujuk melalui daftar native `instructions`. Templat dan prompt hook adalah
material rujukan di bawah `~/.config/opencode/.apothem/support/`; perintah, keterampilan,
dan definisi asisten menggunakan lokasi penemuan native.

## Verifikasi

```bash
apothem verify --harness opencode
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama tersedia.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness opencode
```

Menyegarkan `opencode.json`, perintah native, keterampilan, definisi asisten, dan
pohon dukungan Apothem.

## Pencopotan

```bash
apothem uninstall --harness opencode
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness opencode` |
| Verifikasi gagal | Jalankan `apothem update --harness opencode`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness opencode` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
