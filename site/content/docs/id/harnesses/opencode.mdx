**Vendor:** OpenCode
**Nama instalasi:** `opencode`
**Status:** Beta
**Konfigurasi native:** `~/.config/opencode/`

## Instalasi

```bash
apothem install --harness opencode
```

Adapter menulis konfigurasi JSON OpenCode, memasang skill Apothem ke permukaan
skill OpenCode, mengonversi prompt command menjadi berkas command Markdown
OpenCode, dan menormalkan definisi helper Apothem sebagai subhelper OpenCode.

**Berkas yang ditulis:**

```text
~/.config/opencode/opencode.json
~/.config/opencode/apothem/rules/00-apothem-profile.md
~/.config/opencode/commands/
~/.config/opencode/skills/
~/.config/opencode/agents/
~/.config/opencode/.apothem/support/{rules,templates,hooks}/
```

## Pemetaan profil ke konfigurasi native

Adapter merender `opencode.json` dengan daftar berkas `instructions` yang
menyebut dokumen profil Anda dan aturan always-on Apothem, lalu menyebarkan
setiap kohor Apothem bersama ke permukaan native OpenCode atau ke support
subtree milik Apothem. Anak yang dikelola Apothem dan cocok yang sudah ada
dicadangkan sebelum penggantian.

## Catatan kompatibilitas

OpenCode menggabungkan setiap berkas yang disebut daftar `instructions` ke dalam
setiap sesi ([aturan OpenCode](https://opencode.ai/docs/rules/)). Karena itu,
daftar tersebut menyebut dokumen profil Anda terlebih dahulu, lalu hanya aturan
yang `alwaysApply`-nya bernilai `true`, masing-masing dengan satu jalur
`~/.config/opencode/.apothem/support/rules/<name>.md` eksplisit; OpenCode
mengekspansi `~/` di awal terhadap direktori home Anda. Aturan yang difilter
berdasarkan jalur, templat, dan prompt hook tetap terpasang sebagai materi
rujukan di bawah `~/.config/opencode/.apothem/support/`, tempat aturan, skill,
atau command yang mengutip salah satunya membacanya sesuai kebutuhan. Command,
skill, dan definisi helper menggunakan lokasi penemuan native.

Dokumen profil `~/.config/opencode/apothem/rules/00-apothem-profile.md`
membawa identitas dan preferensi Anda dari profil bersama, dan diakhiri dengan
bagian berkas dukungan Apothem yang menyebutkan direktori absolut di bawah
`~/.config/opencode/.apothem/support/` yang menjadi acuan resolusi setiap
sitasi bergaya repositori (`rules/<name>.md`, `templates/...`, `hooks/...`).
Dokumen ini adalah entri `instructions` pertama, sehingga OpenCode memuatnya di
setiap sesi.

`opencode.json` yang ditulis oleh rilis sebelumnya mencantumkan satu glob
`~/.config/opencode/.apothem/support/rules/*.md`, yang memuat setiap aturan.
`apothem install` dan `apothem update` menggantinya dengan daftar always-on, dan
`apothem uninstall` menghapus kedua bentuk tersebut. Entri `instructions` milik
Anda sendiri dipertahankan dalam setiap kasus.

## Verifikasi

```bash
apothem verify --harness opencode
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Setiap target terkelola ada; berkas terkelola tidak kosong, dan konfigurasi
   JSON atau YAML dapat diurai. Tambahkan `--profile PATH` untuk juga
   memastikan bahwa berkas yang terpasang cocok dengan profil tersebut.
3. Rutin verifikasi khusus adapter melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness opencode
```

Menyegarkan `opencode.json`, command native, skill, definisi helper, dan pohon
dukungan Apothem.

## Pencopotan

```bash
apothem uninstall --harness opencode
```

Menghapus entri yang ditambahkan adapter ke `~/.config/opencode/opencode.json`
(kunci Anda sendiri, server MCP, dan entri `instructions` tetap ada, dan berkas
itu dihapus hanya ketika Apothem yang membuatnya dan tidak ada lagi yang
tersisa milik Anda). Menghapus blok Apothem dari dokumen profil
`~/.config/opencode/apothem/rules/00-apothem-profile.md` dan mempertahankan teks
lain di dalamnya; berkas itu dihapus hanya ketika tidak ada lagi yang tersisa di
dalamnya. Juga menghapus berkas Apothem di `~/.config/opencode/commands/`,
`~/.config/opencode/skills/`, `~/.config/opencode/agents/`, dan
`~/.config/opencode/.apothem/support/`; berkas lain di folder-folder tersebut
tetap ada. Setiap berkas dicadangkan di bawah `~/.apothem/backups/` sebelum
diubah atau dihapus. YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness opencode` |
| Verifikasi gagal | Jalankan `apothem update --harness opencode`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness opencode` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
