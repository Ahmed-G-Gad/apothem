**Vendor:** AWS
**Nama instalasi:** `kiro`
**Status:** GA
**Konfigurasi native:** `<project>/.kiro/steering/apothem-rules.md`

## Instalasi

```bash
apothem install --harness kiro --project /path/to/project
```

Adaptor menulis satu berkas pengarahan (steering) Kiro berlingkup proyek dari
aturan bersama Apothem dan permukaan tata kelola.

**Berkas yang ditulis:** `<project>/.kiro/steering/apothem-rules.md`

## Pemetaan profil ke konfigurasi native

Adaptor membaca profil bersama Apothem dan merender berkas pengarahan proyek pada
setiap jalannya `apothem install` atau `apothem update`. Profil bersama adalah
sumber kebenaran; suntingan lokal proyek pada berkas yang dihasilkan dicadangkan
sebelum sinkronisasi berikutnya mengganti konten yang dikelola Apothem.

## Catatan kompatibilitas

Permukaan pengarahan Kiro berlingkup proyek di bawah `.kiro/steering/`. Adaptor
menulis berkas pengarahan khusus `apothem-rules.md` dengan front matter
`inclusion: always` dan tidak pernah menimpa berkas fondasi yang ditulis operator
Kiro (`product.md`, `tech.md`, `structure.md`). Spesifikasi Kiro (`.kiro/specs/`)
dan hook asisten dimiliki operator; Apothem tidak menulisnya.

## Verifikasi

```bash
apothem verify --harness kiro --project /path/to/project
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama tersedia.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness kiro --project /path/to/project
```

Menurunkan ulang berkas pengarahan proyek dari status profil bersama saat ini.

## Pencopotan

```bash
apothem uninstall --harness kiro --project /path/to/project
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness kiro --project /path/to/project` |
| Verifikasi gagal | Jalankan `apothem update --harness kiro --project /path/to/project`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness kiro --project /path/to/project` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
