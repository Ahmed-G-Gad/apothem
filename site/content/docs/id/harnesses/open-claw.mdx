**Vendor:** Open-Claw
**Nama instalasi:** `open-claw`
**Status:** Pratinjau
**Konfigurasi native:** `~/.openclaw/openclaw.json`

## Instalasi

```bash
apothem install --harness open-claw
```

Adapter menulis berkas konfigurasi global-pengguna OpenClaw, memproyeksikan
profil bersama ke dalam dokumen profil, dan memasang kohor pendukung Apothem di
bawah akar harness. Konfigurasi native OpenClaw adalah JSON; materializer
merender objek JSON kosong, dan berkas yang sudah ada tetap mempertahankan
kunci-kuncinya.

**Berkas yang ditulis:** `~/.openclaw/openclaw.json`, dokumen profil
`~/.openclaw/apothem/rules/00-apothem-profile.md`, dan berkas pendukung di bawah
`~/.openclaw/.apothem/support/`

Dokumen profil diakhiri dengan bagian berkas pendukung Apothem yang menyebutkan
direktori absolut di bawah `~/.openclaw/.apothem/support/` tempat setiap kutipan
bergaya repositori (`rules/<name>.md`, `templates/...`, `hooks/...`)
di-resolve.

## Pemetaan profil ke konfigurasi native

Adapter membaca profil bersama Apothem tetapi tidak menulis kunci konfigurasi
apa pun: `openclaw.json` yang baru atau kosong ditulis sebagai objek kosong, dan
berkas yang sudah ada tetap mempertahankan kunci-kuncinya. Identitas,
preferensi, dan aturan profil masuk ke dokumen profil. Command, skill, aturan,
templat, dan prompt hook bersama dipasang sebagai materi pendukung di bawah
`~/.openclaw/.apothem/support/`.

## Catatan kompatibilitas

Adapter pratinjau. OpenClaw tidak memuat pohon pendukung maupun dokumen profil
dengan sendirinya: tidak satu pun lokasi skill-nya, berkas instruksi
workspace-nya, atau konfigurasinya menunjuk ke sana, sehingga setelah instalasi
OpenClaw berjalan tanpa aturan, skill, atau server MCP Apothem. OpenClaw membaca
skill dari folder `skills/` dan `.agents/skills/` di workspace-nya,
`~/.agents/skills`, direktori state-nya, dan folder apa pun yang tercantum di
`skills.load.extraDirs`; untuk menggunakan skill Apothem, tambahkan sendiri
`~/.openclaw/.apothem/support/skills` ke daftar tersebut; `apothem update`
mempertahankan kunci yang Anda tambahkan ke `openclaw.json`. Server MCP berada
di blok `mcp.servers` dalam konfigurasi OpenClaw, yang Anda kelola dengan
`openclaw mcp add` dan subperintah terkait; adapter tidak menulis entri apa pun
di sana. (Perilaku OpenClaw menurut dokumentasinya tentang
[skill](https://docs.openclaw.ai/tools/skills) dan
[CLI MCP](https://docs.openclaw.ai/cli/mcp), dibaca 2026-10-02.)

## Verifikasi

```bash
apothem verify --harness open-claw
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Setiap target terkelola ada; berkas terkelola tidak kosong, dan konfigurasi
   JSON atau YAML dapat diurai. Tambahkan `--profile PATH` untuk juga
   memastikan bahwa berkas yang terpasang cocok dengan profil tersebut.
3. Rutin verifikasi khusus adapter melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness open-claw
```

Menurunkan ulang dokumen profil dari status profil bersama saat ini dan
menyegarkan berkas pendukung; `openclaw.json` tetap mempertahankan kunci yang
sudah dimilikinya.
Jalankan setelah menyunting `~/.config/apothem/profile.yaml` atau memutakhirkan
paket Apothem yang terpasang.

## Pencopotan

```bash
apothem uninstall --harness open-claw
```

Menghapus berkas konfigurasi native yang ditulis oleh adapter.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness open-claw` |
| Verifikasi gagal | Jalankan `apothem update --harness open-claw`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness open-claw` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
