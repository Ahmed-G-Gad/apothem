**Vendor:** Open-Claw
**Nama instalasi:** `open-claw`
**Status:** Pratinjau
**Konfigurasi native:** `~/.openclaw/openclaw.json`

## Instalasi

```bash
apothem install --harness open-claw
```

Adaptor menerjemahkan profil bersama ke berkas konfigurasi global-pengguna
OpenClaw dan memasang kohor dukungan Apothem di bawah akar harness. Konfigurasi
native OpenClaw adalah JSON; materializer merender JSON agar sesuai.

**Berkas yang ditulis:** `~/.openclaw/openclaw.json`, dokumen profil
`~/.openclaw/apothem/rules/00-apothem-profile.md`, dan berkas dukungan di bawah
`~/.openclaw/.apothem/support/`

Dokumen profil diakhiri dengan bagian berkas dukungan Apothem yang menyebutkan
direktori absolut di bawah `~/.openclaw/.apothem/support/` yang menjadi acuan
resolusi setiap sitasi bergaya repositori (`rules/<name>.md`, `templates/...`,
`hooks/...`).

## Pemetaan profil ke konfigurasi native

Adaptor membaca profil bersama Apothem tetapi tidak menulis kunci konfigurasi
apa pun: `openclaw.json` ditulis sebagai objek kosong. Identitas, preferensi,
dan aturan profil masuk ke dokumen profil. Command, skill, aturan, templat, dan
prompt hook bersama dipasang sebagai materi dukungan di bawah
`~/.openclaw/.apothem/support/`.

## Catatan kompatibilitas

Adaptor pratinjau. OpenClaw tidak memuat pohon dukungan maupun dokumen profil
dengan sendirinya: tidak satu pun lokasi skill-nya, berkas instruksi
workspace-nya, atau konfigurasinya menunjuk ke sana, sehingga setelah instalasi
OpenClaw berjalan tanpa aturan, skill, atau server MCP Apothem. OpenClaw membaca
skill dari folder `skills/` dan `.agents/skills/` di workspace-nya,
`~/.agents/skills`, direktori state-nya, dan folder apa pun yang tercantum di
`skills.load.extraDirs`; untuk menggunakan skill Apothem, tambahkan
`~/.openclaw/.apothem/support/skills` ke daftar tersebut sendiri;
`apothem update` mempertahankan kunci yang Anda tambahkan ke `openclaw.json`.
Server MCP berada di blok `mcp.servers` dalam konfigurasi OpenClaw, yang Anda
kelola dengan `openclaw mcp add` dan subperintah terkait; adaptor tidak menulis
entri apa pun di sana. (Perilaku OpenClaw menurut dokumentasi
[skill](https://docs.openclaw.ai/tools/skills) dan
[CLI MCP](https://docs.openclaw.ai/cli/mcp)-nya, dibaca 2026-10-02.)

## Verifikasi

```bash
apothem verify --harness open-claw
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness open-claw
```

Menurunkan ulang konfigurasi native dari keadaan profil bersama saat ini.
Jalankan setelah menyunting `~/.config/apothem/profile.yaml` atau memutakhirkan
paket Apothem yang terpasang.

## Pencopotan

```bash
apothem uninstall --harness open-claw
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness open-claw` |
| Verifikasi gagal | Jalankan `apothem update --harness open-claw`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness open-claw` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
