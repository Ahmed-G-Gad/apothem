**Vendor:** Open-Claw
**Nama instal:** `open-claw`
**Status:** Pratinjau
**Konfigurasi native:** `~/.openclaw/openclaw.json`

## Instalasi

```bash
apothem install --harness open-claw
```

Adaptor menerjemahkan profil bersama ke berkas konfigurasi global-pengguna OpenClaw dan
memasang kohort dukungan Apothem di bawah akar harness. Konfigurasi native OpenClaw
adalah JSON; materializer merender JSON agar sesuai.

**Berkas yang ditulis:** `~/.openclaw/openclaw.json` dan berkas dukungan di bawah
`~/.openclaw/.apothem/support/`

## Pemetaan profil ke konfigurasi native

Adaptor membaca profil bersama Apothem. Bidang skills native OpenClaw adalah daftar nama
yang diizinkan (bukan pemuat direktori) dan MCP adalah permukaan CLI, sehingga Apothem
tidak menulis kunci konfigurasi apa pun. Perintah, skill, aturan, template, dan prompt
hook bersama dipasang sebagai materi dukungan di bawah `~/.openclaw/.apothem/support/`.

## Catatan kompatibilitas

Adaptor pratinjau. Konfigurasi native JSON adalah permukaan aktif Open-Claw; Apothem
menggunakan hook direktori-skill tambahan yang terdokumentasi untuk skill dan menyimpan
kohort lainnya sebagai materi rujukan untuk panduan yang terpasang.

## Verifikasi

```bash
apothem verify --harness open-claw
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pemutakhiran

```bash
apothem update --harness open-claw
```

Menurunkan-ulang konfigurasi native dari keadaan profil bersama saat ini. Jalankan
setelah menyunting `~/.config/apothem/profile.yaml` atau memutakhirkan paket Apothem
yang terpasang.

## Pencopotan

```bash
apothem uninstall --harness open-claw
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor. YAML profil bersama dan
mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness open-claw` |
| Verifikasi gagal | Jalankan `apothem update --harness open-claw`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness open-claw` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
