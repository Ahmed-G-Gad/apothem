**Vendor:** Antigravity
**Nama instalasi:** `antigravity`
**Status:** Pratinjau
**Konfigurasi native:** `~/.gemini/GEMINI.md` plus
`~/.gemini/antigravity-cli/plugins/apothem/`

## Instalasi

```bash
apothem install --harness antigravity
```

Adaptor merender profil bersama ke `~/.gemini/GEMINI.md` dan memasang kumpulan
dukungan Apothem sebagai plugin CLI Antigravity.

**Berkas yang ditulis:** `~/.gemini/GEMINI.md`,
`~/.gemini/antigravity-cli/plugins/apothem/plugin.json`,
`~/.gemini/antigravity-cli/plugins/apothem/skills/`,
`~/.gemini/antigravity-cli/plugins/apothem/rules/`,
definisi asisten lokal yang telah dikonversi di dalam plugin,
`~/.gemini/antigravity-cli/plugins/apothem/apothem/templates/`, dan
`~/.gemini/antigravity-cli/plugins/apothem/apothem/hooks/`.

**Jangkar pengguna bersama.** `~/.gemini/GEMINI.md` juga merupakan jangkar
lingkup pengguna untuk perkakas keluarga Gemini. Adaptor Antigravity menyimpan
material Apothem tambahannya di dalam plugin `apothem` di bawah
`~/.gemini/antigravity-cli/plugins/`, sehingga tidak mengklaim direktori proyek
Gemini CLI yang generik.

## Pemetaan profil ke konfigurasi native

Adaptor membaca profil bersama Apothem dan merender jangkar instruksi plus
kumpulan dukungan pada setiap jalannya `apothem install` atau `apothem update`.

## Catatan kompatibilitas

Adaptor pratinjau. Jangkar `GEMINI.md` adalah konten instruksi aktif; plugin
Antigravity menjaga keterampilan perintah yang dikonversi, keterampilan yang dapat
digunakan kembali, definisi asisten lokal, aturan, templat, dan material dukungan
hook dalam namespace milik Apothem yang jelas.
Berkas hook tidak terdaftar sebagai peristiwa hook Antigravity aktif sampai adaptor
memiliki lapisan terjemahan skema untuk `hooks.json` Antigravity.

## Verifikasi

```bash
apothem verify --harness antigravity
```

Perintah verify memastikan bahwa:

1. Berkas konteks native ada di jalur yang diharapkan.
2. Metadata plugin CLI Antigravity Apothem ada dan mendeklarasikan nama plugin
   `apothem`.

## Pembaruan

```bash
apothem update --harness antigravity
```

Menurunkan ulang konfigurasi native dari status profil bersama saat ini. Jalankan
setelah menyunting `~/.config/apothem/profile.yaml` atau memutakhirkan paket
Apothem yang terpasang.

## Pencopotan

```bash
apothem uninstall --harness antigravity
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness antigravity` |
| Verifikasi gagal | Jalankan `apothem update --harness antigravity`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness antigravity` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
