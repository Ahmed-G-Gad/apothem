**Vendor:** Moonshot
**Nama instalasi:** `kimi-code`
**Status:** GA
**Konfigurasi native:** `<project>/AGENTS.md` ditambah `<project>/.kimi-code/.apothem/support/`

## Instalasi

```bash
apothem install --harness kimi-code --project /path/to/project
```

Adaptor menulis permukaan tata kelola Apothem bersama ke dalam `AGENTS.md` di
akar proyek sebagai blok terkelola yang dibatasi sentinel (prosa operator di luar
sentinel dipertahankan) dan menyimpan kohor Markdown non-native di bawah pohon
dukungan milik Apothem di `<project>/.kimi-code/.apothem/support/`.
`AGENTS.md` proyek dibaca oleh banyak alat pengodean selain Kimi Code, sehingga
blok tersebut ditulis sebagai panduan seluruh proyek yang tidak menyebut satu
alat tunggal pun sebagai pembacanya.

Kimi Code membaca berkas instruksi `AGENTS.md` di akar proyek mengikuti konvensi
AGENTS.md universal, dan konfigurasi proyek berada di bawah
`<project>/.kimi-code/`. Permukaan `<project>/.kimi-code/mcp.json` dimiliki
operator; Apothem menyebutnya tetapi tidak menulis entri apa pun.

**Berkas yang ditulis:** `<project>/AGENTS.md` (blok terkelola) dan kohor
command, skill, hook, agen, aturan, dan templat di bawah
`<project>/.kimi-code/.apothem/support/`.

## Pemetaan profil ke konfigurasi native

Adaptor membaca profil bersama Apothem dan merender permukaan instruksi
`AGENTS.md` di akar proyek pada setiap kali `apothem install` atau
`apothem update` dijalankan. Aturan perilaku dan korpus tata kelola mendarat di
blok terkelola `AGENTS.md`; kohor command, skill, hook, agen, aturan, dan templat
ditempatkan di bawah `.kimi-code/.apothem/support/` dan dirujuk dari permukaan
instruksi. Ini adalah tata letak yang dipilih adaptor, bukan celah pada Kimi Code:
Kimi Code memuat skill dari `.kimi-code/skills/` dan `.agents/skills/`, agen
kustom dari `.kimi-code/agents/` dan `.agents/agents/`, serta hook dari array
`[[hooks]]` di `~/.kimi-code/config.toml`, tetapi tidak memuatnya dari pohon
dukungan, sehingga salinan Apothem di sana adalah materi rujukan yang ditunjuk
oleh blok `AGENTS.md`. Blok tersebut diakhiri dengan bagian berkas dukungan
Apothem yang menyebutkan, relatif terhadap akar proyek, direktori di bawah
`.kimi-code/.apothem/support/` yang menjadi acuan resolusi setiap sitasi bergaya
repositori (`rules/<name>.md`, `templates/...`, `hooks/...`), sehingga
`AGENTS.md` yang di-commit tidak membawa jalur khusus mesin apa pun. (Perilaku
Kimi Code menurut halaman kustomisasinya untuk
[skill](https://moonshotai.github.io/kimi-code/en/customization/skills),
[subagen](https://moonshotai.github.io/kimi-code/en/customization/agents), dan
[hook](https://moonshotai.github.io/kimi-code/en/customization/hooks), dibaca
2026-10-02.)

## Catatan kompatibilitas

Kimi Code membaca instruksi proyek dari `AGENTS.md` atau
`.kimi-code/AGENTS.md` dan mengenali `.kimi-code/mcp.json` sebagai permukaan
MCP milik operator; Apothem menyebut permukaan tersebut tetapi tidak menulis
entri apa pun ke dalamnya. Permukaan instruksi yang dirender menggerakkan proyek
secara langsung. Kimi Code tidak mengekspos permukaan berkas statusline atau
output-style, sehingga kohor tersebut tidak dimaterialisasikan.

Kimi Code berjalan pada keluarga model Kimi dari Moonshot; lihat
[referensi konfigurasi vendor](https://moonshotai.github.io/kimi-code/en/configuration/config-files)
untuk model dan permukaan konfigurasi terkini.

## Verifikasi

```bash
apothem verify --harness kimi-code --project /path/to/project
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua bidang wajib dari profil bersama hadir.
3. Rutin verifikasi khusus adaptor melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness kimi-code --project /path/to/project
```

Menurunkan ulang blok terkelola `AGENTS.md` di akar proyek dan kohor dukungan
dari keadaan profil bersama saat ini.

## Pencopotan

```bash
apothem uninstall --harness kimi-code --project /path/to/project
```

Menghapus berkas konfigurasi native yang ditulis oleh adaptor.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness kimi-code --project /path/to/project` |
| Verifikasi gagal | Jalankan `apothem update --harness kimi-code --project /path/to/project`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness kimi-code --project /path/to/project` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
