**Vendor:** Hermes
**Nama instalasi:** `hermes`
**Status:** Pratinjau
**Konfigurasi native:** `~/.hermes/config.yaml`

## Instalasi

```bash
apothem install --harness hermes
```

Adapter menerjemahkan profil bersama ke berkas konfigurasi global-pengguna
Hermes Agent dan memasang kohor pendukung Apothem di bawah akar harness.

**Berkas yang ditulis:** `~/.hermes/config.yaml`, dokumen profil
`~/.hermes/apothem/rules/00-apothem-profile.md`, dan berkas pendukung di bawah
`~/.hermes/.apothem/support/`

Dokumen profil diakhiri dengan bagian berkas pendukung Apothem yang menyebutkan
direktori absolut di bawah `~/.hermes/.apothem/support/` tempat setiap kutipan
bergaya repositori (`rules/<name>.md`, `templates/...`, `hooks/...`)
di-resolve.

## Pemetaan profil ke konfigurasi native

Adapter membaca profil bersama Apothem dan merender konfigurasi YAML native,
termasuk inventaris MCP milik profil. Identitas, preferensi, dan aturan milik
profil dimasukkan ke dalam dokumen profil. Command, skill, definisi helper,
aturan, templat, dan prompt hook bersama ditempatkan sebagai materi pendukung
di bawah `~/.hermes/.apothem/support/`.

## Catatan kompatibilitas

Adapter pratinjau. Hermes tidak memuat pohon pendukung maupun dokumen profil
dengan sendirinya: tidak ada apa pun di `config.yaml` dan tidak ada satu pun
berkas konteks yang dibaca Hermes yang menunjuk ke sana, sehingga setelah
instalasi Hermes berjalan tanpa aturan, skill, atau hook Apothem. Hermes
membaca skill dari `~/.hermes/skills/` dan dari setiap folder yang tercantum di
bawah `skills.external_dirs` di `config.yaml`; untuk menggunakan skill Apothem,
tambahkan sendiri `~/.hermes/.apothem/support/skills` ke daftar tersebut;
`apothem update` mempertahankan kunci yang Anda tambahkan ke `config.yaml`.
Adapter menulis inventaris MCP milik profil di bawah kunci tingkat atas
`mcp_servers`, tempat Hermes membaca server MCP. Rilis Apothem sebelumnya
menulisnya di bawah `auxiliary.mcp`, yang dibaca Hermes sebagai model auxiliary
untuk dispatch alat MCP; baik `apothem update` maupun `apothem uninstall`
menghapus blok tersebut selama blok itu masih cocok dengan apa yang akan
ditulis oleh rilis semacam itu dari profil bersama Anda (lihat
[Pencopotan](#pencopotan)). (Perilaku Hermes menurut halaman panduan
penggunanya tentang
[skill](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/skills.md)
dan [MCP](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/features/mcp.md),
dibaca 2026-10-02.)

## Verifikasi

```bash
apothem verify --harness hermes
```

Perintah verify memastikan bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Setiap target terkelola ada; berkas terkelola tidak kosong, dan konfigurasi
   JSON atau YAML dapat diurai. Tambahkan `--profile PATH` untuk juga
   memastikan bahwa berkas yang terpasang cocok dengan profil tersebut.
3. Rutin verifikasi khusus adapter melaporkan keberhasilan.

## Pembaruan

```bash
apothem update --harness hermes
```

Menurunkan ulang konfigurasi native dari status profil bersama saat ini.
Jalankan setelah menyunting `~/.config/apothem/profile.yaml` atau memutakhirkan
paket Apothem yang terpasang.

## Pencopotan

```bash
apothem uninstall --harness hermes
```

Menghapus apa yang ditambahkan adapter: entri `mcp_servers` yang dicatat oleh
instalasinya di `config.yaml` (kunci milik Anda sendiri tetap ada, dan berkas
tersebut dihapus hanya ketika Apothem yang membuatnya dan tidak ada lagi milik
Anda yang tersisa di dalamnya), dokumen profil, dan pohon pendukung. YAML
profil bersama dan mesin Apothem tidak terpengaruh.

Pada instalasi yang dibuat oleh rilis sebelumnya, yang menulis server milik
profil di bawah `auxiliary.mcp`, blok tersebut juga dihapus ketika blok itu
masih cocok dengan apa yang akan ditulis rilis tersebut dari profil bersama
Anda saat ini di `~/.config/apothem/profile.yaml`. Ini adalah aturan yang sama
dengan yang diterapkan `apothem update`, sehingga mencopot tanpa memperbarui
terlebih dahulu tidak meninggalkan blok usang selama server MCP milik profil
tidak berubah. Blok yang telah Anda sunting, blok yang tidak lagi cocok dengan
server MCP milik profil Anda saat ini, atau blok yang tidak memiliki profil
bersama yang dapat dibaca sebagai pembanding, tetap di tempatnya, dan pengaturan
`auxiliary` Anda yang lain selalu tetap ada.

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| Berkas konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness hermes` |
| Verifikasi gagal | Jalankan `apothem update --harness hermes`, lalu verifikasi lagi |
| Konten konfigurasi tidak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness hermes` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis berkas. |
