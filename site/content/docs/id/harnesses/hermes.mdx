**Vendor:** Hermes
**Nama instal:** `hermes`
**Status:** Pratinjau
**Konfigurasi native:** `~/.hermes/config.yaml`

## Instalasi

```bash
apothem install --harness hermes
```

Adapter menerjemahkan profil bersama ke file konfigurasi global pengguna Hermes
Agent dan memasang kohort dukungan Apothem di bawah akar harness.

**File yang ditulis:** `~/.hermes/config.yaml` dan file dukungan di bawah
`~/.hermes/.apothem/support/`

## Pemetaan profil ke konfigurasi native

Adapter membaca profil bersama Apothem dan merender konfigurasi YAML native.
Permukaan keterampilan milik Hermes sendiri adalah `skills.config` — paket
registry yang dapat dipasang yang Hermes ekspos secara otomatis sebagai perintah
garis miring dinamis — yang tidak ditulis Apothem. Sebaliknya, Apothem
mengirimkan konten perintah dan keterampilan bersama sebagai materi dukungan di
bawah `~/.hermes/.apothem/support/`, yang dirujuk dari jangkar instruksi native. Definisi
pembantu, aturan, templat, dan prompt hook juga tetap menjadi materi dukungan di
bawah `~/.hermes/.apothem/support/`.

## Catatan kompatibilitas

Adapter pratinjau. Konfigurasi YAML native adalah permukaan Hermes yang aktif;
Apothem menggunakan hook direktori keterampilan eksternal yang terdokumentasi
untuk keterampilan dan menjaga kohort lainnya sebagai materi referensi untuk
panduan yang terpasang.

## Verifikasi

```bash
apothem verify --harness hermes
```

Perintah verify mengonfirmasi bahwa:

1. Konfigurasi native ada di jalur yang diharapkan.
2. Semua field wajib dari profil bersama ada.
3. Rutin verifikasi spesifik-adapter melaporkan keberhasilan.

## Pemutakhiran

```bash
apothem update --harness hermes
```

Menurunkan ulang konfigurasi native dari state profil bersama saat ini.
Jalankan setelah mengedit `~/.config/apothem/profile.yaml` atau memutakhirkan
paket Apothem yang terpasang.

## Pencopotan

```bash
apothem uninstall --harness hermes
```

Menghapus file konfigurasi native yang ditulis oleh adapter.
YAML profil bersama dan mesin Apothem tidak terpengaruh.

## Gerbang konformitas

```bash
python -m apothem.conformity.gate --all .
```

## Pemecahan masalah

| Gejala | Perbaikan |
|---------|-----|
| File konfigurasi tidak ditemukan | Jalankan ulang `apothem install --harness hermes` |
| Verifikasi gagal | Jalankan `apothem update --harness hermes`, lalu verifikasi lagi |
| Konten konfigurasi tak terduga | Periksa `~/.config/apothem/profile.yaml` atau `--profile PATH`, lalu jalankan ulang `apothem update --harness hermes` |

## Tombol konfigurasi

| Flag | Default | Deskripsi |
|------|---------|-------------|
| `--dry-run` | `false` | Pratinjau instalasi tanpa menulis file. |
