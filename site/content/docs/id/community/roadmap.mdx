## Rilis saat ini

- Menstabilkan ketujuh belas adapter perkakas.
- Menyelesaikan infrastruktur audit peninjauan.
- Menstabilkan permukaan CLI Apothem.
- Membangun pipeline CI/CD GitHub Actions.

## Jangka pendek

- Mematangkan distribusi npm / npx: jaga entry point `@ahmed-g-gad/apothem`
  selaras dengan setiap rilis dan memperluas cakupan platformnya.
- Mengembangkan daftar plugin Claude Code saat permukaan marketplace stabil.
- Pembaruan-otomatis adapter perkakas via `apothem update --watch`.
- Perkakas versioning dan migrasi profil.
- Validasi skema profil-bersama di gerbang kesesuaian.
- Adapter perkakas tambahan berdasarkan permintaan komunitas.

## Jangka panjang

- Sinkronisasi profil ter-host-awan (opsional, dikendalikan-operator).
- Ekstensi VS Code untuk umpan-balik kesesuaian waktu-nyata.
- Pengelolaan profil yang dibagi-tim.

## Permintaan dan umpan balik

Kirim permintaan peta jalan via
[GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).
Peta jalan diinformasikan-komunitas; permintaan populer bergerak lebih cepat.
