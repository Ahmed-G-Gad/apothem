Tutorials are guided, end-to-end lessons. You follow each one from start to
finish, and by the end you have something real working on your machine. They
assume no prior knowledge of Apothem and explain every step as you go.

If you already know what you want and just need the exact command, the
[how-to guides](/docs/how-to) and the [reference](/docs/harnesses) are
the faster path.

## Start here

- [Getting started](/docs/tutorials/getting-started) — install Apothem, write a
  shared profile, materialize a harness's native configuration, and verify it.
  Roughly fifteen minutes from an empty machine to a working first run.
