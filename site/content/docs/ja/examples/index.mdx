エンドツーエンドの実践ウォークスルー。各サンプルは、1 つのタスクを白紙の状態から
完成した成果物まで導き、各ステップでのコマンド・ファイル・推論を示します。

リポジトリに同梱される実行可能なサンプルプロジェクトは、リポジトリルートの
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples)
ディレクトリにあります。下記のページは、それらを順を追って解説するナラティブガイドです。

## ページ

| ページ | 説明 |
|------|-------------|
| [harness アダプターの作成](/docs/examples/authoring-a-harness-adapter) | 新しい harness アダプターをゼロから構築するためのステップバイステップガイド。 |
| [最小フック](/docs/examples/minimal-hook) | 可能な限り最小の Apothem フック——ファイル書き込みごとに発火する PreToolUse チェック。 |
| [カスタムルール](/docs/examples/custom-rule) | 命名規約を強制するプロジェクト固有の常時オンルールの作成。 |
| [計画ウォークスルー](/docs/examples/plan-walkthrough) | 実際のタスクに対する `/plan` パイプラインのエンドツーエンドウォークスルー。 |
