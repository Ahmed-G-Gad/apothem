エンドツーエンドの実践ウォークスルーです。
各サンプルは、1 つのタスクを白紙の状態から完成した成果物まで進め、各ステップでのコマンド、ファイル、そして判断の理由を示します。

リポジトリに同梱される実行可能なサンプルプロジェクトは、リポジトリルートの
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples)
ディレクトリにあります。
それぞれが自己完結しており、独自の README を持ちます。
以下のページは、それらとは別の実践ウォークスルーであり、それらのプロジェクトを解説するものではありません。

## ページ

| ページ | 説明 |
|------|-------------|
| [ハーネスアダプターの作成](/docs/examples/authoring-a-harness-adapter) | 新しいハーネスアダプターをゼロから構築するためのステップバイステップガイド。 |
| [最小のフック](/docs/examples/minimal-hook) | 可能な限り最小の Apothem フック — ファイルの書き込みのたびに発火する PreToolUse チェック。 |
| [カスタムルール](/docs/examples/custom-rule) | 命名規約を強制する、プロジェクト固有の常時有効なルールの作成。 |
| [プランのウォークスルー](/docs/examples/plan-walkthrough) | 実際のタスクに対する `/plan` パイプラインのエンドツーエンドのウォークスルー。 |
