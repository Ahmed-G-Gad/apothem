**ベンダー：** Zed Industries
**インストール名：** `zed`
**ステータス：** GA
**ネイティブ設定：** `<project>/.rules`

## インストール

```bash
apothem install --harness zed --project /path/to/project
```

アダプターは、共有の Apothem ルールとガバナンス面から、プロジェクトスコープの Zed
命令ファイルを 1 つ書き込みます。Zed が読み込むプロジェクト命令ファイルは 1 つだけで、
次のリストで最初に一致したものです。

```text
.rules
.cursorrules
.windsurfrules
.clinerules
.github/copilot-instructions.md
AGENT.md
AGENTS.md
CLAUDE.md
GEMINI.md
```

ツールごとのルールディレクトリはないため、Apothem 面全体が、このリストの先頭にある
フラットな `.rules` ファイルに収まります。

**書き込まれるファイル：** `<project>/.rules`

## プロファイルからネイティブ設定へのマッピング

アダプターは Apothem の共有プロファイルを読み取り、`apothem install` または `apothem update` を
実行するたびに、プロジェクトの `.rules` ファイルをレンダリングします。共有プロファイルが
信頼できる情報源です。既存の `.rules`（または生成されたファイルへのプロジェクトローカルな
編集）は、次回の同期が Apothem 管理のコンテンツを置き換える前にバックアップされます。

## 互換性に関する注意

Zed は `AGENTS.md` を主要な命令ファイルとし、プロジェクトの `.rules` をサポート対象の
互換ファイルとして維持しています（[Zed の命令](https://zed.dev/docs/ai/instructions)）。
Zed は最初に一致したものだけを読み込むため、新しい `.rules` は、プロジェクトがすでに依存して
いる `AGENTS.md`、`CLAUDE.md`、またはリストのより下位にある他のファイルを隠してしまいます。
インストールがそれらのファイルを編集することは決してありません。`.rules` に Apothem ブロック
しかなく、より優先度の低いファイルにあなたのテキストがある場合、インストールと更新は、
隠されたファイルを名指しする警告を出力します。必要な命令を Zed で維持するには、それらを
`.rules` の Apothem ブロックの外側にコピーしてください。

グローバルな `~/.config/zed/AGENTS.md` 命令ファイルと MCP コンテキストサーバーブロック
（`.zed/settings.json` の `context_servers`）はオペレーターの所有であり、Apothem はそれらを
書き込みません。

## 検証

```bash
apothem verify --harness zed --project /path/to/project
```

verify コマンドは次のことを確認します。

1. ネイティブ設定が想定されたパスに存在すること。
2. 管理対象の各ターゲットが存在すること。管理対象のファイルは空ではなく、JSON または YAML の設定は解析できること。`--profile PATH` を追加すると、インストールされたファイルがそのプロファイルと一致することも確認します。
3. アダプター固有の検証ルーチンが成功を報告すること。

## 更新

```bash
apothem update --harness zed --project /path/to/project
```

現在の共有プロファイルの状態から、プロジェクトの `.rules` ファイルを再導出します。

## アンインストール

```bash
apothem uninstall --harness zed --project /path/to/project
```

Apothem の管理ブロックを、ネイティブ設定ファイル `.rules` から削除し、あなた自身の文章は残します。ファイルは、ほかに何も残っていない場合にのみ削除されます。変更の前に、ファイルのタイムスタンプ付きのコピーが `~/.apothem/backups/` の下に保存されます。プロジェクトにバックアップファイルは残りません。共有プロファイルの YAML と Apothem エンジンには影響しません。

## コンフォーミティゲート

```bash
python -m apothem.conformity.gate --all .
```

## トラブルシューティング

| 症状 | 対処 |
|---------|-----|
| 設定ファイルが見つからない | `apothem install --harness zed --project /path/to/project` を再実行する |
| 検証が失敗した | `apothem update --harness zed --project /path/to/project` を実行してから、再度検証する |
| 想定外の設定内容 | `~/.config/apothem/profile.yaml` または `--profile PATH` を確認してから、`apothem update --harness zed --project /path/to/project` を再実行する |

## 設定ノブ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--dry-run` | `false` | ファイルを書き込まずにインストールをプレビューする。 |
