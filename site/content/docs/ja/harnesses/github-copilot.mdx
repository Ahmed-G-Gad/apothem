**ベンダー：** GitHub / Microsoft
**インストール名：** `github-copilot`
**ステータス：** GA
**ネイティブ設定：** `<project>/.github/copilot-instructions.md`

## インストール

```bash
apothem install --harness github-copilot --project /path/to/project
```

アダプターは、あなたの共有プロファイルと、共有の Apothem ルールおよびガバナンス面から、プロジェクトの命令ファイルを導出します。

**書き込まれるファイル：** `<project>/.github/copilot-instructions.md`

## プロファイルからネイティブ設定へのマッピング

アダプターは Apothem の共有プロファイルを読み取り、`apothem install` または `apothem update` を実行するたびに、リポジトリ全体に適用される Copilot の命令ファイルをレンダリングします。
信頼できる情報源は共有プロファイルです。生成されたファイルへのプロジェクトローカルな編集は、次回の同期が Apothem の管理するコンテンツを置き換える前にバックアップされます。

Apothem ブロック内では、あなたのプロファイルからレンダリングされるセクション（オペレーター、プリファレンス、カスタムルール、オプトインした振る舞い、MCP サーバー名）が最初に置かれ、共有のガバナンステキストがその後に続きます。
GitHub は、短い命令ファイルほどコードレビューで全体が処理される可能性が高いと述べているため（[コードレビューのカスタマイズ](https://docs.github.com/en/copilot/tutorials/customize-code-review)）、あなたに固有の部分がファイルの先頭に置かれます。

## 互換性に関する注意

GitHub Copilot は、このアダプターが管理できる、ファイルベースのユーザーグローバルな命令パスを公開していません。
Apothem は文書化されたプロジェクトスコープの命令ファイルを対象とし、IDE レベルのユーザー設定はオペレーターの所有のままにします。

Apothem リポジトリ内では、`.github/copilot-instructions.md` は、そのリポジトリのアシスタント命令面の中の 1 つの声です。
そのリポジトリのチェックアウトでは、コンフォーミティゲートの複数面整合性チェックが、`AGENTS.md`、`CLAUDE.md`、`.github/copilot-instructions.md` に共通する主張を比較します。
報告されるのは、3 つのファイルのうち 1 つが欠いている共通の主張と、`AGENTS.md` が述べる主張に矛盾しているファイルです。
このチェックは、Apothem があなたのプロジェクトに書き込む命令ファイルを読み取りません。
ゲートはデフォルトでは助言的です。所見を報告し、`0` で終了します。

## 検証

```bash
apothem verify --harness github-copilot --project /path/to/project
```

verify コマンドは次のことを確認します。

1. ネイティブ設定が想定されたパスに存在すること。
2. 管理対象の各ターゲットが存在すること。管理対象のファイルは空ではなく、JSON または YAML の設定は解析できること。`--profile PATH` を追加すると、インストールされたファイルがそのプロファイルと一致することも確認します。
3. アダプター固有の検証ルーチンが成功を報告すること。

## 更新

```bash
apothem update --harness github-copilot --project /path/to/project
```

現在の共有プロファイルの状態からプロジェクトの命令ファイルを再導出します。

## アンインストール

```bash
apothem uninstall --harness github-copilot --project /path/to/project
```

`<project>/.github/copilot-instructions.md` から Apothem ブロックを削除し、その外側にあるテキストは保持します。
ファイルが削除されるのは、その中に他に何も残っていない場合のみです。
変更の前に、ファイルのタイムスタンプ付きコピーが `~/.apothem/backups/` 配下に保存されます。
共有プロファイルの YAML と Apothem エンジンには影響しません。

## コンフォーミティゲート

```bash
python -m apothem.conformity.gate --all .
```

## トラブルシューティング

| 症状 | 対処 |
|---------|-----|
| 設定ファイルが見つからない | `apothem install --harness github-copilot --project /path/to/project` を再実行する |
| 検証が失敗した | `apothem update --harness github-copilot --project /path/to/project` を実行してから、再度検証する |
| 想定外の設定内容 | `~/.config/apothem/profile.yaml` または `--profile PATH` を確認してから、`apothem update --harness github-copilot --project /path/to/project` を再実行する |

## 設定ノブ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--dry-run` | `false` | ファイルを書き込まずにインストールをプレビューする。 |
