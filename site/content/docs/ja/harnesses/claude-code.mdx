**ベンダー：** Anthropic
**インストール名：** `claude-code`
**ステータス：** GA
**ネイティブ設定：** `~/.claude/`

## インストール

```bash
apothem install --harness claude-code
```

`claude-code` アダプターは、共有された Apothem コーパスを Claude
Code のネイティブな検出ツリーにインストールします。Markdown エージェント、ルール、
スキル、出力スタイル、ステータスラインヘルパー、設定は、それぞれのネイティブな場所に
インストールされます。コマンドプロンプトはさらにスキルとしてラップされ、再利用可能な
ワークフローが現在の Claude Code のスキル面を通じて引き続き見えるようになります。

**書き込まれるファイル：** `~/.claude/` 配下の `settings.json`、`agents/`、`rules/`、
`skills/`、`statuslines/`、`output-styles/`、および `apothem/` サポートサブツリー
（`apothem/hooks/`、`apothem/conformity/`、`apothem/schemas/`、
`apothem/templates/`）。コマンドファイルは子スキルディレクトリに変換されます。フック
ディスパッチャーと適合ゲートは、それらのマテリアライズされたコピーから実行されます。
`settings.json` のフックエントリは `~/.claude/.apothem/support/hooks/dispatch.py` と
`~/.claude/.apothem/support/conformity/gate.py` を絶対パスで呼び出すため、ホスト上にインポート
可能な `apothem` パッケージは不要です。

このアダプターは `CLAUDE.md` を**管理しません**。そのファイルはオペレーターの所有領域
です。Apothem のガバナンス面は、マテリアライズされた `CLAUDE.md` ではなく、伝播された
`rules/` ツリーと SessionStart フックを通じて Claude Code に到達します。

## プロファイルからネイティブ設定へのマッピング

`apothem install` または `apothem update` のたびに、アダプターは伝播マニフェストに
従って共有 `apothem` コーパスを `~/.claude/` に伝播します。アダプターは可能な場合は
ネイティブディレクトリを直接使用し、コマンドプロンプトをスキルフォルダーに変換します。
既存の、Apothem 管理下の一致する子は、置き換える前にバックアップされます。無関係な、
オペレーターが作成したエントリは保持されます。`settings.json` はマージされ、オペレーター
が作成したキーが引き続き復元可能になります。

## 互換性に関する注意

変換は一切発生しません。インストールでは、プロファイルが整形式であり、settings.json 内のすべてのフックバインディングが解決可能であることを検証します。

Claude Code は、すべてのセッション開始時に settings.json 内のすべてのフックバインディングを適用します。各アダプターは、自身のネイティブなハーネスに対して検証されます。特権的な「参照」ハーネスは存在しません。

## 検証

```bash
apothem verify --harness claude-code
```

verify コマンドは、次のことを確認します。

1. ネイティブ設定が期待されるパスに存在すること。
2. 共有プロファイルからのすべての必須フィールドが存在すること。
3. アダプター固有の検証ルーチンが成功を報告すること。

## 更新

```bash
apothem update --harness claude-code
```

現在の共有プロファイルからネイティブ設定を再導出します。インストール済みの
`apothem` パッケージを更新した後に実行して、伝播された規約面（エージェント、ルール、
スキル、ステータスライン、出力スタイル）が新しいバージョンを反映するようにします。
`CLAUDE.md` はオペレーターの所有物であり、アダプターによって決して触れられません。

## アンインストール

```bash
apothem uninstall --harness claude-code
```

アダプターによって書き込まれたネイティブ設定ファイルを削除します。
インストール済みの `apothem` パッケージとソースリポジトリは影響を受けません。

## 適合ゲート

```bash
python -m apothem.conformity.gate --all .
```

## トラブルシューティング

| 症状 | 対処 |
|---------|-----|
| 設定ファイルが見つからない | `apothem install --harness claude-code` を再実行する |
| 検証に失敗した | `apothem update --harness claude-code` を実行してから、再度検証する |
| 予期しない設定内容 | `apothem update` を再実行する。真実の源は共有 `apothem` プロファイルであり、`~/.claude/` ではない |

## 設定ノブ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--dry-run` | `false` | ファイルを書き込まずにインストールをプレビューする。 |
