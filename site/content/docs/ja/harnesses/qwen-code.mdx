**ベンダー：** Alibaba Cloud
**インストール名：** `qwen-code`
**ステータス：** ベータ版
**ネイティブ設定：** `~/.qwen/`

## インストール

```bash
apothem install --harness qwen-code
```

アダプターは Qwen Code の設定を書き込み、`QWEN.md` コンテキストアンカーをインストールし、Apothem のフックディスパッチャーを登録し、Apothem のコマンドを Qwen の Markdown コマンドファイルに変換し、スキルを SKILL.md ディレクトリとしてインストールし、ヘルパー定義を Qwen のサブエージェントとして適合させます。

**書き込まれるファイル：**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/apothem/rules/00-apothem-profile.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

ファイル `~/.qwen/apothem/rules/00-apothem-profile.md` はプロファイルドキュメントです。
共有プロファイルに由来するあなたのアイデンティティとプリファレンスを保持します。

## プロファイルからネイティブ設定へのマッピング

アダプターは、コンテキストとフック向けに文書化された `settings.json` のキーをレンダリングし、`QWEN.md` を書き込み、Apothem のコマンド、スキル、ヘルパー定義を Qwen Code のネイティブな検出ディレクトリに組み込みます。
ルール、テンプレート、フックのソース素材は、`~/.qwen/.apothem/support/` 配下のサポート素材として残ります。

## 互換性に関する注意

`~/.qwen/.apothem/support/` は、`QWEN.md` と設定のフックコマンドから参照されるサポート素材であり、ベンダー所有の検出名前空間ではありません。
`QWEN.md` 内の Apothem ブロックは Apothem サポートファイルのセクションで終わります。
このセクションは、リポジトリ形式の各参照（`rules/<name>.md`、`templates/...`、`hooks/...`）が解決される先の、`~/.qwen/.apothem/support/` 配下の絶対ディレクトリを示します。

## 検証

```bash
apothem verify --harness qwen-code
```

verify コマンドは次のことを確認します。

1. ネイティブ設定が想定されたパスに存在すること。
2. 管理対象の各ターゲットが存在すること。管理対象のファイルは空ではなく、JSON または YAML の設定は解析できること。`--profile PATH` を追加すると、インストールされたファイルがそのプロファイルと一致することも確認します。
3. アダプター固有の検証ルーチンが成功を報告すること。

## 更新

```bash
apothem update --harness qwen-code
```

`settings.json`、`QWEN.md`、ネイティブコマンド、スキル、サブエージェント、Apothem サポートツリーを更新します。

## アンインストール

```bash
apothem uninstall --harness qwen-code
```

アダプターが `~/.qwen/settings.json` に追加したエントリを削除します（あなた自身のキー、MCP サーバー、フックハンドラーは残り、このファイルは、Apothem が作成したものであり、かつあなたのものが何も残っていない場合にのみ削除されます）。
`~/.qwen/QWEN.md` と、プロファイルドキュメント `~/.qwen/apothem/rules/00-apothem-profile.md` から Apothem のブロックを削除し、それぞれの中の他のテキストは残します。各ファイルは、その中に他に何も残っていない場合にのみ削除されます。
また、`~/.qwen/commands/`、`~/.qwen/skills/`、`~/.qwen/agents/`、`~/.qwen/.apothem/support/` 内の Apothem のファイルも削除します。これらのフォルダー内のその他のファイルは残ります。
各ファイルは、変更または削除される前に `~/.apothem/backups/` 配下にバックアップされます。
共有プロファイルの YAML と Apothem エンジンには影響しません。

## コンフォーミティゲート

```bash
python -m apothem.conformity.gate --all .
```

## トラブルシューティング

| 症状 | 対処 |
|---------|-----|
| 設定ファイルが見つからない | `apothem install --harness qwen-code` を再実行する |
| 検証が失敗した | `apothem update --harness qwen-code` を実行してから、再度検証する |
| 想定外の設定内容 | `~/.config/apothem/profile.yaml` または `--profile PATH` を確認してから、`apothem update --harness qwen-code` を再実行する |

## 設定ノブ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--dry-run` | `false` | ファイルを書き込まずにインストールをプレビューする。 |
