**ベンダー：** Anysphere
**インストール名：** `cursor`
**ステータス：** GA
**ネイティブ設定：** プロジェクトルートの `.cursor/rules/`

## インストール

```bash
apothem install --harness cursor --project /path/to/project
```

アダプターは、共有の Apothem のルールとガバナンス面から、プロジェクトスコープの `.mdc`
ルールファイルを 1 つレンダリングします。

**書き込まれるファイル：** `<project>/.cursor/rules/apothem-rules.mdc`

このファイルがインストールのすべてです。ルール、スキル、コマンド、テンプレート、フックの
ファイルはその隣に一切配置されないため、このファイルは、プロジェクト内に存在しない Apothem の
ファイルを指し示す代わりに、その旨を記載しています。

## プロファイルからネイティブ設定へのマッピング

アダプターは Apothem の共有プロファイルを読み取り、`apothem install` または `apothem update` を
実行するたびにプロジェクトのルールファイルをレンダリングします。信頼できる情報源は共有
プロファイルです。生成されたファイルへのプロジェクトローカルな編集は、次回の同期が Apothem の
管理するコンテンツを置き換える前にバックアップされます。

ファイルは YAML フロントマター（`description`、`globs`、`alwaysApply: true`）で始まります。
Cursor はルールの種類を、ファイル先頭のフロントマターからしか読み取らないためです。Apothem が
管理するブロックがその後に続きます。ブロックの後にあなたが追加したテキストは、同期のたびに
保持されます。

## 互換性に関する注意

Cursor 0.45+ は、`.cursor/rules/` を通じてプロジェクトレベルの命令をサポートします。
アダプターはデフォルトで、プロジェクトスコープの `.cursor/rules/` ディレクトリに書き込みます。
Cursor には、このアダプターが管理できる、ファイルベースのユーザーグローバルなルールパスが
文書化されていません。

## 検証

```bash
apothem verify --harness cursor --project /path/to/project
```

verify コマンドは次のことを確認します。

1. ネイティブ設定が想定されたパスに存在すること。
2. 共有プロファイルのすべての必須フィールドが存在すること。
3. アダプター固有の検証ルーチンが成功を報告すること。

## 更新

```bash
apothem update --harness cursor --project /path/to/project
```

現在の共有プロファイルの状態からプロジェクトのルールファイルを再導出します。

## アンインストール

```bash
apothem uninstall --harness cursor --project /path/to/project
```

アダプターが書き込んだネイティブ設定ファイルを削除します。
共有プロファイルの YAML と Apothem エンジンには影響しません。

## コンフォーミティゲート

```bash
python -m apothem.conformity.gate --all .
```

## トラブルシューティング

| 症状 | 対処 |
|---------|-----|
| 設定ファイルが見つからない | `apothem install --harness cursor --project /path/to/project` を再実行する |
| 検証が失敗した | `apothem update --harness cursor --project /path/to/project` を実行してから、再度検証する |
| 想定外の設定内容 | `~/.config/apothem/profile.yaml` または `--profile PATH` を確認してから、`apothem update --harness cursor --project /path/to/project` を再実行する |

## 設定ノブ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--dry-run` | `false` | ファイルを書き込まずにインストールをプレビューする。 |
