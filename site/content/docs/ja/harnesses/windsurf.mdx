**ベンダー：** Devin Desktop（旧 Codeium Windsurf）
**インストール名：** `windsurf`
**ステータス：** GA
**ネイティブ設定：** `<project>/.devin/rules/apothem-rules.md`

Windsurf は現在 Devin Desktop となっており、`.devin/rules/` が推奨されるワークスペース
ルールの場所です（`.windsurf/rules/` より優先されます）。

## インストール

```bash
apothem install --harness windsurf --project /path/to/project
```

アダプターは、共有の Apothem ルールとガバナンス面から、プロジェクトスコープの Windsurf
ルールファイルを 1 つ書き込みます。

**書き込まれるファイル：** `<project>/.devin/rules/apothem-rules.md`

## プロファイルからネイティブ設定へのマッピング

アダプターは Apothem の共有プロファイルを読み取り、`apothem install` または `apothem update` を
実行するたびに、プロジェクトのルールファイルをレンダリングします。共有プロファイルが
信頼できる情報源です。生成されたファイルへのプロジェクトローカルな編集は、次回の同期が
Apothem 管理のコンテンツを置き換える前にバックアップされます。

このファイルは `trigger: always_on` フロントマターで始まり、これがルールの
アクティベーションモードを設定します。Apothem 管理のブロックはその後に続きます。
ブロックの後にあなたが追加したテキストは、同期のたびに保持されます。

## 互換性に関する注意

Windsurf の現在のルール面は `.devin/rules/` 配下のプロジェクトスコープです（推奨される
場所であり、後方互換のフォールバックである `.windsurf/rules/` より優先されます）。
ワークフローとマシンローカルなメモリはオペレーターの所有であり、Apothem はそれらを
書き込みません。単一ファイル形式の `.windsurfrules` は意図的に書き込まれません。

## 検証

```bash
apothem verify --harness windsurf --project /path/to/project
```

verify コマンドは次のことを確認します。

1. ネイティブ設定が想定されたパスに存在すること。
2. 管理対象の各ターゲットが存在すること。管理対象のファイルは空ではなく、JSON または YAML の設定は解析できること。`--profile PATH` を追加すると、インストールされたファイルがそのプロファイルと一致することも確認します。
3. アダプター固有の検証ルーチンが成功を報告すること。

## 更新

```bash
apothem update --harness windsurf --project /path/to/project
```

現在の共有プロファイルの状態から、プロジェクトのルールファイルを再導出します。

## アンインストール

```bash
apothem uninstall --harness windsurf --project /path/to/project
```

アダプターが書き込んだネイティブ設定ファイルを削除します。
共有プロファイルの YAML と Apothem エンジンには影響しません。

## コンフォーミティゲート

```bash
python -m apothem.conformity.gate --all .
```

## トラブルシューティング

| 症状 | 対処 |
|---------|-----|
| 設定ファイルが見つからない | `apothem install --harness windsurf --project /path/to/project` を再実行する |
| 検証が失敗した | `apothem update --harness windsurf --project /path/to/project` を実行してから、再度検証する |
| 想定外の設定内容 | `~/.config/apothem/profile.yaml` または `--profile PATH` を確認してから、`apothem update --harness windsurf --project /path/to/project` を再実行する |

## 設定ノブ

| フラグ | デフォルト | 説明 |
|------|---------|-------------|
| `--dry-run` | `false` | ファイルを書き込まずにインストールをプレビューする。 |
