Apothem は二形態のブランド規律を用います。

| 形態 | 用途 | 例 |
|---|---|---|
| **Apothem** | 表示形態——すべての本文、見出し、UI、ドキュメント | Apothem vX.Y.Z、Install Apothem |
| **apothem** | 識別子形態——CLI コマンド、パッケージ名、ファイルパス | npx @ahmed-g-gad/apothem、apothem install |

決して使わないこと：ApoThem（キャメルケース）、Apo-them（ハイフン付き）、APOTHEM（全大文字）、または本文中での小文字の `apothem`。`Apothem` が唯一の表示形態です。

## タグライン

> one profile, every harness

タグラインは、ワードマークのロックアップとソーシャルカードが掲げているとおりに、
小文字で表記します。

## ロゴ

Apothem マークは、上辺が平らな正六角形で、共通の中心から各辺の中点へと扇状に伸びる
六本のアポテム、それら六つの中点を通る内接円、そして中心のソースノードで構成されます。
上辺へのアポテムはエメラルド、残りの五本はスレートです。ジオメトリは
[`assets/DESIGN-SYSTEM.md`](https://github.com/ahmed-g-gad/apothem/blob/main/assets/DESIGN-SYSTEM.md) で規定されています。
ライトとダークのバリアントは
`assets/logo.svg` と `assets/logo-dark.svg` で利用できます。横並びのロックアップは
`assets/logo-wordmark.svg` と `assets/logo-wordmark-dark.svg` にあります。

ブラウザのファビコンは、完全なマークではなく、意図的にコンパクトな
`assets/favicon.svg` モノグラムを用います。16px では、モノグラムの方がブラウザの
タブやピン留め面でより鮮明です。

許可される用途とクリアスペース要件については[ロゴの使用](/docs/brand/logo-usage)を
参照してください。

## アセットパレットの根拠

Apothem マークの周縁ノードは装飾的なジオメトリです——ハーネスの数をエンコードせずに
ハブアンドスポークのアーキテクチャを想起させるため、アダプターが追加されても
マークは安定したままです。ハーネスパレットの色の割り当ては[ハーネスカラー](/docs/brand/harness-colors)に
あります。アクセシビリティの姿勢と面ごとの伝播規則は、そのページに記載されています。
