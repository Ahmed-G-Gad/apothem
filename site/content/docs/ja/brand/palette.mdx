## コアパレット

正規のパレット——スレートのニュートラルランプ、エメラルドのアクセントランプ、および
セマンティックな色相——は、
[`assets/design-tokens.css`](https://github.com/ahmed-g-gad/apothem/blob/main/assets/design-tokens.css)
（およびそのミラーである `assets/design-tokens.json`）のデザイントークンが所有します。
[`site/app/global.css`](https://github.com/ahmed-g-gad/apothem/blob/main/site/app/global.css)
のサイトテーマは、これらのトークン値を Fumadocs テーマが消費する CSS 変数にミラー
します。以下の各値は、正規のランプステップにトレースされます。

| 役割 | トークン（CSS） | ライトモード | ダークモード | 用途 |
|---|---|---|---|---|
| プライマリ | `--apothem-text` | slate-900 `#0f172a` | slate-50 `#f8fafc` | 見出し、ナビゲーションのテキスト、主要な読み取り面。 |
| アクセント | `--apothem-accent-text` | emerald-700 `#047857` | emerald-400 `#34d399` | アクティブなリンク、フォーカスリング、選択中のナビゲーション。 |
| 本文テキスト | `--apothem-text-muted` | slate-600 `#475066` | slate-300 `#c2ccda` | 既定の本文テキスト。 |
| 本文の地色 | `--apothem-surface` | slate-50 `#f8fafc` | slate-900 `#0f172a` | 既定の背景。 |
| ナビゲーションの地色 | `--apothem-surface-sunken` | slate-100 `#eef2f7` | slate-950 `#080c15` | ヘッダーとナビゲーションの帯。 |

## 工具パレット

工具のカラーは[工具カラー](/docs/brand/harness-colors)にあります。Apothem マークの
六角形——その中心ノードと終端ノード——へのジオメトリックマッピングは、ブランド
セクションに折り込まれています。
[`site/app/global.css`](https://github.com/ahmed-g-gad/apothem/blob/main/site/app/global.css)
の CSS 事実の源が、各トークンをその CSS 変数に配線します。

## ドキュメントでの使用

パレットはグローバルスタイルシート `site/app/global.css` を通じて配線され、ルート
レイアウトによってインポートされます。ライトモードとダークモードのバリアントは、
テーマの `.dark` クラスの状態に応じて切り替わります。

## 更新

パレットは、コアカラー（slate / emerald）が変化したとき、または工具が上流でブランド
カラーの変更を承認したときにのみ更新されます。工具ごとの変更は、
`site/app/global.css`、[工具カラー](/docs/brand/harness-colors)、および
`assets/src/` 配下の影響を受けるすべての SVG マスターにわたって原子的に伝播します。
