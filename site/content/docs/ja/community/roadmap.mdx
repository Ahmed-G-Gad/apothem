このロードマップは、Apothem が目指す方向を説明します。
これは意図の表明であり、確約ではありません。プロジェクトとそのユーザーの変化に応じて、優先順位は変わります。
すでに出荷されたものについては、[変更履歴](https://github.com/ahmed-g-gad/apothem/blob/main/CHANGELOG.md)を参照してください。
リポジトリの [ROADMAP.md](https://github.com/ahmed-g-gad/apothem/blob/main/ROADMAP.md) が唯一のロードマップであり、プロジェクトのウェブサイトにある[ロードマップページ](https://apothem.ahmedgad.com/docs/community/roadmap)はそこから生成されます。

ステータスの凡例: **計画中** · **進行中** · **出荷済み**。

## 現在のリリース

現在のラインは、ホストに依存しないハーネス構成マネージャーを出荷しています。
共有プロファイル（`~/.config/apothem/profile.yaml`）が、登録済みのアダプター向けのハーネスネイティブな設定へマテリアライズされ、`apothem` コマンドライン（`quickstart` · `install` · `update` · `uninstall` ·
`rollback` · `verify` · `status` · `diff` · `harnesses` · `profile` ·
`doctor` · `migrate-workspace` · `completion`）によって駆動されます。

## 短期

| 項目 | ステータス | 備考 |
| ---- | ------ | ----- |
| ドキュメントガイド | 進行中 | 実際のハーネスセットアップに向けた、よりタスク指向のガイド、図、例 |
| npm / npx 配布 | 計画中 | `@ahmed-g-gad/apothem` の npx エントリーポイントを各リリースと整合させ続け、そのプラットフォームカバレッジを広げる |
| Claude Code プラグインの掲載 | 計画中 | マーケットプレイスの面が安定するにつれて、プラグインの掲載を拡大する |
| ハーネスアダプターの追加 | 計画中 | 設定規約が安定し、ユーザーから要望があり次第、追加のハーネスに対応する |
| プロファイルスキーマの拡張 | 計画中 | より充実したハーネスごとのオーバーライド面と、より厳格な検証診断 |
| コンフォーミティゲートでのプロファイル検証 | 計画中 | ゲートチェックとして、共有プロファイルをそのスキーマに照らして検証する |
| プロファイルのバージョニングとマイグレーション | 計画中 | プロファイル形式にバージョンを付け、古いプロファイルを新しい形式へ移行する |
| `apothem update --watch` | 計画中 | プロファイルが変更されたときに、ハーネス設定を再マテリアライズする |

## 長期ビジョン

Apothem は、誰もが自分の使うすべてのツールにわたってハーネス設定を管理するための、標準の方法になることを目指しています。
規約を一度書き、それをあらゆる場所へマテリアライズし、好みとハーネスの両方が変化しても同期を保ちます。

## ロードマップに影響を与える方法

- [イシュートラッカー](https://github.com/ahmed-g-gad/apothem/issues)でイシューを作成するか、既存のイシューに賛成票を投じてください。
  そこでの機能リクエストが、ロードマップ項目を提案する方法です。
  人気のあるリクエストほど速く進みます。
- 変更を提案して取り込む方法については、[CONTRIBUTING.md](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md) を参照してください。
