## 現在のリリース

- 17 のハーネスアダプターを安定化する。
- 監査レビューのインフラを完成させる。
- Apothem CLI の面を安定化する。
- GitHub Actions の CI/CD パイプラインを確立する。

## 近い将来

- npm / npx 配布を成熟させる: `@ahmed-g-gad/apothem` エントリーポイントを
  各リリースと整合させ続け、そのプラットフォームカバレッジを広げる。
- マーケットプレイスの面が安定するにつれて、Claude Code プラグインの
  掲載を拡大する。
- `apothem update --watch` によるハーネスアダプターの自動更新。
- プロファイルのバージョニングおよびマイグレーションツール。
- 適合性ゲートにおける共有プロファイルスキーマの検証。
- コミュニティからのリクエストに基づく追加のハーネスアダプター。

## より長期

- クラウドホスト型のプロファイル同期(任意、オペレーターが制御)。
- リアルタイムの適合性フィードバックのための VS Code 拡張機能。
- チームで共有するプロファイル管理。
