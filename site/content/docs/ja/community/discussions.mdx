## GitHub Discussions

主要なコミュニティの場は [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions) です。

カテゴリ:

| カテゴリ | 用途 |
|----------|---------|
| Q&A | 使い方、設定、挙動に関する質問 |
| Ideas | 機能リクエストと設計に関する議論 |
| Show and tell | あなたの Apothem の使い方の共有 |
| General | その他なんでも |

## Issues

バグや具体的な機能リクエストには、
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues) を使用してください。

issue を開く前に、重複を避けるため、既存の issue とディスカッションを
検索してください。

## 貢献

コード、ドキュメント、ハーネスアダプターで貢献する方法については、
[貢献](/docs/developer-guide) を参照してください。まずはリポジトリの
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
と、そこで参照されているプルリクエストテンプレートから始めてください。
