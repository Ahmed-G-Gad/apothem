Model Context Protocol（MCP）サーバーは**オペレーター所有**です。Apothem は MCP インベントリを
共有プロファイル（`mcp_servers`）に保持します。ツールが MCP サーバーを、Apothem がすでに
書き込んでいる設定ファイルに保持している場合、そのアダプターはインベントリをそのファイルに
投影します。それ以外のアダプターはサーバーエントリを記述せず、サーバーはツールを通じて
あなたが登録するものであり続けます。

## MCP サーバーが登録される場所

各ツールは独自のネイティブ機構を通じて MCP サーバーを登録し、Apothem はその面を上書きする
のではなく尊重します。Claude Code では、サーバーは `claude mcp add` によって
`~/.claude.json`（ユーザースコープまたはローカルスコープ）と、プロジェクトレベルの
`.mcp.json` に登録されます。Claude Code アダプターはどちらのファイルも書き込まず、
Apothem が管理する Claude Code の設定が `mcpServers` ブロックを持つことは決してありません。

## サーバーの追加

サーバーは、使用しているツールのネイティブ機構を通じて登録してください。正規のエントリの形は、
`mcpServers` の下の 1 つのキーです:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

ツールのランタイムは、セッション開始時に登録済みのサーバーを読み込みます。新しいサーバーを
取り込むには、ツールを再起動してください。

## 命名規約

MCP ツールは、ツールの標準的な MCP ツール命名規約に従い、`mcp__<server>__<tool>` として
アシスタントに現れます。
