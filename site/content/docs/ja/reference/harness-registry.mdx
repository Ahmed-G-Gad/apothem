ハーネスレジストリは、CLI、ドキュメント、フィクスチャテスト、規約ピン検証で使用される
信頼できる唯一の情報源（source-of-truth）としてのアダプターインベントリです。ランタイムの
ソースは `src/apothem/lib/harness_registry.py` であり、以下の各行はそのレジストリ、各
アダプターの `capabilities.yml`、および各アダプターの `STANDARD-CONVENTION-PIN.md` まで
追跡できます。

## 検証フック

レジストリは次のチェックを通じて同期が保たれます。

| チェック | 目的 |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | 各アダプターが最新の規約ピンを持ち、レジストリが依然として 17 個のアダプターを列挙していることを確認します。 |
| `python -m apothem.conformity.gate --all .` | ドキュメントと実装の準拠性チェックを実行します。 |
| `python -m pytest` | レジストリのフィクスチャテストとアダプターの契約テストを実行します。 |
