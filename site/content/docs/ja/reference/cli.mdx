`apothem` CLI は、共有プロファイルとハーネスアダプターを管理するための主要な
オペレーターインターフェースです。

## グローバルフラグ

| フラグ | 説明 |
|------|-------------|
| `--version` | Apothem のバージョンを表示して終了します |
| `--help` | コマンドのヘルプを表示します |

## サブコマンド

### `apothem install`

共有プロファイルからハーネスアダプターをインストールします。

```bash
apothem install --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| オプション | 説明 |
|--------|-------------|
| `--harness <name>` | ハーネスアダプター名（下記の正規の値を参照）。必須。 |
| `--profile PATH` | 共有プロファイル YAML へのパス。デフォルトは `~/.config/apothem/profile.yaml`。 |
| `--project PATH` | プロジェクトスコープのハーネス向けのプロジェクトルート。 |
| `--dry-run` | ファイルを書き込まずにインストールをプレビューします。 |

正規の `--harness` の値:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
hermes
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

レジストリ全体の集合を選択するには `--harness all --project <path>` を使用します。
プロファイルの `exclude_harnesses` リストは、インストール/更新のバッチ選択時に
尊重されます。

### `apothem update`

現在の共有プロファイルから、ハーネスアダプターのネイティブ設定を再導出します。

```bash
apothem update --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| オプション | 説明 |
|--------|-------------|
| `--harness <name>` | ハーネスアダプター名。必須。 |
| `--profile PATH` | 共有プロファイル YAML へのパス。 |
| `--project PATH` | プロジェクトスコープのハーネス向けのプロジェクトルート。 |
| `--dry-run` | ファイルを書き込まずに更新をプレビューします。 |

`update` はハーネスの出力を再マテリアライズします。Apothem CLI パッケージ自体は
更新しません。パッケージのアップグレードには、Apothem をインストールした
パッケージマネージャーを使用してください。

### `apothem uninstall`

ハーネスアダプターのネイティブ設定を削除します。

```bash
apothem uninstall --harness <name|all> [--project PATH] [--yes]
```

| オプション | 説明 |
|--------|-------------|
| `--harness <name>` | ハーネスアダプター名。必須。 |
| `--project PATH` | プロジェクトスコープのハーネス向けのプロジェクトルート。 |
| `--yes` | 確認プロンプトをスキップします。 |

### `apothem verify`

ハーネスアダプターがインストールされており、その出力パスが存在することを検証します。

```bash
apothem verify --harness <name|all> [--project PATH]
```

| オプション | 説明 |
|--------|-------------|
| `--harness <name>` | ハーネスアダプター名、または `all`。必須。 |
| `--project PATH` | プロジェクトスコープのハーネス向けのプロジェクトルート。 |

アダプターがインストールされている場合の終了コードは `0`、そうでない場合は `1` です。

### `apothem profile`

共有 Apothem プロファイルを管理します。

```bash
apothem profile show [--profile PATH]
apothem profile init [--profile PATH] [--force]
apothem profile set <key> <value> [--profile PATH]
apothem profile edit [--profile PATH]
```

| サブコマンド | 説明 |
|------------|-------------|
| `profile init` | スキーマに準拠した最小限のプロファイルのひな型を作成します。 |
| `profile show` | 解決済みのプロファイル（YAML）を stdout に表示します。 |
| `profile set <key> <value>` | プロファイルのフィールドを設定します。値は YAML としてパースされます（文字列、数値、ブール値、リスト、マッピングがすべて受け付けられます）。 |
| `profile edit` | `$EDITOR` でプロファイルを開きます（プラットフォーム既定のエディターにフォールバックします）。 |

`--profile PATH` オプションは、各サブコマンドを別のプロファイルファイルに向けます。
デフォルトは `~/.config/apothem/profile.yaml`。

### `apothem harnesses`

登録済みのハーネスアダプターを一覧表示し、検査します。

```bash
apothem harnesses list
apothem harnesses show <name>
```

| サブコマンド | 説明 |
|------------|-------------|
| `harnesses list` | 登録済みの各アダプターを、そのインストール状態フラグと出力パスとともに表として表示します。 |
| `harnesses show <name>` | 1 つのアダプターの名前、インストール状態、出力パスを表示します。 |

### `apothem doctor`

Apothem インストールのシステム診断を実行します。

```bash
apothem doctor
```

Apothem のバージョン、Python インタープリター、プラットフォーム、解決された
プロファイルパス、およびハーネスごとのインストール状態の表を出力します。登録済みの
すべてのアダプターがインストール済みを報告した場合の終了コードは `0`、そうでない
場合は `1` です。
