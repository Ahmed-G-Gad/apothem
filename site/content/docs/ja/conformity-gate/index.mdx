ゲートが実行するのは、機械で判定できるバリデーターだけです。推論型のバーが求める推論による判断と、機械型 + 推論型の各バーの推論型の半分は、レビューで評価されます。

## 重大度の段階

ゲートには、クリティカル・重要・助言という重大度の段階も、2 件の検出事項というしきい値もありません。`--strict`（または `APOTHEM_CONFORMITY_STRICT=1`）を付けない場合、ゲートは検出事項を報告し、`0` で終了します。`--strict` を付けると、単一ファイルまたはフックのチェックは、いずれかのマッチャーが不合格のとき `2` で終了し、コーパス実行（`--all` または `--all-perwrite`）は、ブロッキングのバリデーターまたはマッチャーが不合格のとき `2` で終了します。助言的な検出事項は報告されるだけです。インストールされた Write/Edit フックは `--strict` を渡さないため、検出事項を報告し、書き込みは続行されます。ただし、そのフックの環境で `APOTHEM_CONFORMITY_STRICT=1` が設定されている場合は除きます。

## バリデーター

機械的に判定される部分は [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity) にあり、[`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py) によってオーケストレーションされます。
各バリデーターは、次の 3 つの方法のいずれかで実行されます。

- **per-write**: 保留中のすべての書き込みに対して（`--hook`）、または `--all-perwrite` を指定した場合は追跡対象のすべてのファイルに対して実行されます。
- **standalone**: `--all` でリポジトリ全体に対して、または `--check <name>` で 1 つずつ実行されます。
- **change-set**: ステージされた差分に対して、ゲートを経由せず、`python -m apothem.conformity.semver_stability_grep --staged` として直接実行されます。

## ゲートの実行

インストール済みのハーネスでは、ゲートは自動的に実行されます。Claude Code の
`settings.json` がゲートを `PreToolUse` フックとして配線し、すべての Write/Edit の前に、
`~/.claude/.apothem/support/conformity/gate.py` にあるマテリアライズされたコピーを呼び出します。
ゲートがチェックするのは、フックのスコープ内の書き込みだけであり、スコープ外の書き込みは無言で合格します。
そのスコープは、[コンフォーミティゲートの実行](/docs/usage/conformity-gate)に一覧があります。
ソースチェックアウトからは、モジュール形式で同じコードを実行します。
以下の `python` コマンドには、それぞれ先頭に `PYTHONPATH=src` を付けてください。
ゲートはデフォルトでは助言的です。検出事項を報告し、`0` で終了します。
ブロッキングの検出事項があった場合に `2` で終了させるには、`--strict` を追加します。不明なバリデーター名を指定すると `3` で終了します。

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help` は使用方法の概要を表示します。
完全な手順については、[コンフォーミティゲートの実行](/docs/usage/conformity-gate)を参照してください。
