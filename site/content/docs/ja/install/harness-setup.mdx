## ハーネスアダプターをインストールする

```bash
apothem install --harness <name>
```

利用可能な名前については[サポート対象ハーネス一覧](/docs/harnesses)を参照してください。
プロジェクトスコープのアダプターにはプロジェクトパスが必要です。

```bash
apothem install --harness cursor --project /path/to/project
apothem install --harness gemini-cli --project /path/to/project
apothem install --harness github-copilot --project /path/to/project
apothem install --harness windsurf --project /path/to/project
```

## 複数のハーネスをインストールする

サポートされているすべてのアダプターを対象にしたい場合は、レジストリ全体のセレクターを
使用します。登録済みのセットにはプロジェクトスコープのアダプターが含まれるため、
プロジェクトルートを渡してください。

```bash
apothem install --harness claude-code
apothem install --harness cursor --project /path/to/project
apothem install --harness all --project /path/to/project
```

## ハーネスのセットアップを検証する

```bash
apothem verify --harness <name>
apothem verify --harness all --project /path/to/project
```

登録済みのすべてのアダプターを一度に確認するには、`apothem doctor` を実行します。このコマンドはハーネスごとのインストール状況の表を出力し、検査が失敗した場合にのみ非ゼロで終了します。たとえば、インストール済みのハーネスが検証に通らない場合、フックコマンドが起動できない場合、存在するプロファイルが検証に通らない場合が該当します。インストールされていないハーネスは一覧に表示されますが、`doctor` を失敗させることはありません。

## インストール済みのハーネスを表示する

```bash
apothem harnesses list
```

アダプターごとの詳細（名前、インストール状態、出力パス）については
`apothem harnesses show <name>` を渡してください。
