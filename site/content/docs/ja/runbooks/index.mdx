メンテナー向けの運用手順です。各ランブックは順序立てられた、文脈に依存しない
手順です。既知の開始状態を、検証済みの終了状態へと導き、有能なコントリビューターが
事前の文脈なしに従えるように書かれています。

## ページ

| ページ | 説明 |
|------|-------------|
| [Pages 有効化](/docs/runbooks/pages-enablement) | `apothem.ahmedgad.com` を、新規の GitHub Pages 設定から `200 OK` を返す HTTPS のランディングページまで導きます。 |
| [リリースサイクル](/docs/runbooks/release-cycle) | `vX.Y.Z` リリースを、クリーンな作業ツリーから、検証済みの GitHub Release と npm の設定面まで導きます。 |
| [パブリッシャーアカウントの設定](/docs/runbooks/publisher-account-setup) | `@ahmed-g-gad/apothem` 向けに npmjs.com の信頼済みパブリッシャーと、GitHub 側のリリース前提条件を設定します。 |
| [リリースの復旧](/docs/runbooks/release-recovery) | リリース切り替えシーケンスが途中で失敗したとき、`ahmed-g-gad/apothem` を動作する状態へ復元します。 |
| [新しい環境アダプターの作成](/docs/runbooks/new-harness-adapter-authoring) | ファーストパーティへの組み込みに向けて、新しい環境アダプターを作成して公開します。 |
