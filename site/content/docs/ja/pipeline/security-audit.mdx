**役割：** セキュリティ監査者
**パイプライン位置：** フォートレス

OWASP ASVS 4.0 以降および OWASP Top 10 に照らした、包括的なセキュリティ態勢監査です。

このコマンドが参照する下限は、ASVS 4.0 の最終パッチリリースです。このコマンドは、より新しい ASVS リリースを自分では照会しません。指摘事項は、ASVS の章を番号と短い見出しで引用します。例として、V5（Validation, Sanitization, Encoding）、V12（File and Resources）、V14（Configuration）があります。

## 正規の呼び出し

```bash
/security-audit
```

引数付き：

```bash
/security-audit [path/to/repo/] [--focus CATEGORY] [--dry-run]
```

## 入力

固定された git コミットにあるホストリポジトリ

## 出力

セキュリティの所見（`_inputs/security-audit-findings.md`）

## 下流

監査レビューシーケンスの security-audit ステージ

## ワークフローのフェーズ

このコマンドは 6 つの監査フェーズを実行します。入力の取り込み、シークレットと権限、入力検証とインジェクション、デシリアライズとパストラバーサル、依存関係の CVE と CodeQL、そして検証ゲートを伴う所見の出力です。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 前提条件が未完了 | 依存フェーズが終わっていない | まず上流のフェーズを完了させる |
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 対象が拒否される | パスが git の作業ツリーではない | リポジトリルートをパスとして渡す |

## 例

```bash
# Dry-run to preview what would happen
/security-audit --dry-run

# Execute against a host repository
/security-audit path/to/repo/
```
