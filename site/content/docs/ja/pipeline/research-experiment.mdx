**役割：** 主任研究者（実行）
**パイプライン上の位置：** 中段

設計された研究または実験を実行し、完全な来歴を備えた生データを取得します。再現性を保証します。独立した第三者が再実行できるよう、環境、シード、プロトコルログ、バージョン固定を記録します。

## 標準的な呼び出し

```bash
/research-experiment
```

引数付き：

```bash
/research-experiment [path/to/research-suite/]
```

## 入力

`_inputs/study-design.md`（設計）と `_inputs/preregistration.md`（凍結された分析計画）。

## 出力

`_outputs/experiment-log.md`（タイムスタンプ付きのプロトコルトレース）、ホストにとって自然な場所に置かれた生データ、そして `_outputs/reproducibility-manifest.md`（環境、シード、プロトコル、バージョン固定）。

## 下流

/research-analysis（下流の消費者）

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います。

1. **コンテキストの読み込み** —— 研究設計と事前登録を読み込みます。
2. **シーケンスゲートの検証** —— `_inputs/study-design.md` が存在することを確認します。存在しない場合は `Blocked: run /research-design first` で停止します。
3. **実行と記録** —— プロトコルを実行し、来歴付きで生データを取得し、タイムスタンプ付きのプロトコルトレースを記録します。
4. **再現性の取得** —— 環境、シード、プロトコル、バージョン固定を記録します。
5. **引き継ぎマニフェストの更新** —— データの場所と再現性マニフェストを記録します。
6. **ログの発行** —— `_outputs/experiment-log.md` + 生データ + `_outputs/reproducibility-manifest.md`。

## 厳密性の下限

実行はまず、予算と範囲を較正するためのパイロットパスを走らせ、次に、宣言された計算利用計画（コア割り当て、メモリ上限、独立した反復の安全な並列化）のもとで完全な比較を実行します。各確率的手法は、記録されたシードとログ化されたハードウェアのもとで、事前登録された反復レジームを実行します。オプトイン・デフォルトオフの自律実験ループも利用できます。すなわち、凍結されたハーネスに対して、単一の可変対象への変更を提案し、それを固定予算で実行し、現行のものを上回った場合にのみ保持し、すべての試行を記録します。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-design first | 研究設計がない | `/research-design` を実行して `_inputs/study-design.md` を生成する |
| 実行が再現不可能 | シード／環境の記録が欠落 | 続行する前に完全な再現性マニフェストを記録する |
| プロトコルの逸脱が未記録 | 実行途中の変更が記録されていない | 実験ログに逸脱を記録し、分析時に開示する |

## 例

```bash
# 設計された研究を実行し、再現可能な生データを取得する
/research-experiment path/to/research-suite/
```
