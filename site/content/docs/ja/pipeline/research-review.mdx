**役割:** 主任研究者（査読）
**パイプライン上の位置:** チェーン中段

発表先の基準に照らして、論文に査読水準の対抗的批評を加えます——新規性、厳密性、再現性、明瞭性、倫理、統計レビュー、報告ガイドライン適合性。**7軸**のレビュアー記分カードと、重大度で振り分けた必須修正リストを発行し、各所見に具体的な根拠（コンクリート・ドライバー）の理由を付けます。デフォルトで反証の姿勢。

## 正規の呼び出し

```bash
/research-review
```

引数付き：

```bash
/research-review [--suite-name NAME]
```

## 入力

論文段階が記録した、ホストに自然な場所にある論文成果物。

## 出力

`_outputs/review-report.md` —— **7軸**のレビュアー記分カード（新規性 · 厳密性 · 再現性 · 明瞭性 · 倫理 · 統計レビュー · 報告ガイドライン適合性）、重大度で振り分けた（HIGH / MEDIUM / LOW）必須修正リスト（各所見に具体的な根拠の理由を付与）、再現性パッケージと再実行の判定、引用整合性監査、および全体の `accept · minor-revision · major-revision · reject` 判定。

## 下流

/research-publish（下流の消費者）。`major-revision` または `reject` の判定は、`/research-publish` を実行する前に必須の修正に対応しなければならないことを意味します。

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います：

1. **コンテキストの読み込み** — 論文の成果物を読み込みます。
2. **シーケンスゲートの検証** — 論文、`_outputs/analysis.md`、`_inputs/synthesis.md` が存在し、空でないことを確認します。そうでない場合は、`Blocked: run /research-paper first` で停止します。
3. **対抗的にレビュー** — 7 つの軸（新規性 · 厳密性 · 再現性 · 明瞭性 · 倫理 · 統計レビュー · 報告ガイドラインへの適合）を採点します。再現性の再実行と引用の整合性の監査を実行します。デフォルトで反証し、証拠とともに具体的な欠陥を特定します。
4. **修正の振り分け** — 必須の修正を、具体的な根拠とともに HIGH / MEDIUM / LOW にランク付けします。
5. **ハンドオフマニフェストの更新** — レビューレポートと、スコアカードの判定を記録します。
6. **レビューの出力** — `_outputs/review-report.md`。

## 厳密性の下限

レビューは、経験的な主張を進出ゲートの基準に照らして採点します——適切な複製、効果量と臨界差ランクを伴うノンパラメトリックな有意性、および比較される手法間での予算の同等性——そして、その判定を明示的な進出ゲートとして扱います。論文が進出するのは、発表先の基準を説得力をもって有意に上回り、その通過が記録されたときだけです。二重盲検の発表先では、レビュアーはいかなる身元の漏洩も匿名化の欠陥として指摘します。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-paper first | 論文がない | `/research-paper` を実行して原稿を作成する |
| 甘い採点 | レビュアーが最良のケースを想定した | デフォルトで反証；提示された証拠に基づいて採点する |
| 理由のない所見 | 修正が主張されただけで論証されていない | 各所見に具体的な根拠の理由を付ける |

## 例

```bash
# 論文を査読し、レビュアーのスコアカードを出力する
/research-review --suite-name <name>
```
