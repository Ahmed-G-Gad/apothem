**役割：** アーキテクチャレビュアー
**パイプライン位置：** フォートレス

`_inputs/design.md` の設計制作物に対するアーキテクチャ完全性レビュー。

## 正規の呼び出し

```bash
/architecture-review
```

引数付き：

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## 入力

ホストリポジトリ + `_inputs/design.md`

## 出力

アーキテクチャの所見（`_inputs/architecture-review-findings.md`）

## 下流

監査レビューシーケンスのアーキテクチャレビュー段階

## ワークフローのフェーズ

このコマンドは 5 つの監査フェーズを実行します。入力の取り込み、設計からコードへのトレーサビリティの走査、レイヤー境界の整合性の監査、パッケージ横断の結合の走査、そして検証ゲートを伴う所見の出力です。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | 設計アーティファクト `_inputs/design.md` が存在しない | `/plan-design` を実行して作成する |

## 例

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
