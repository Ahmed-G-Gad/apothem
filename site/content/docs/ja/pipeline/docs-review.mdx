**役割：** ドキュメントレビュアー
**パイプライン位置：** フォートレス

散文規約と十次元品質基準に照らしたドキュメントレビューパス。

## 正規の呼び出し

```bash
/docs-review
```

引数付き：

```bash
/docs-review [path/to/repo/ or path/to/docs-source/] [--focus FILE_OR_DIR] [--dry-run]
```

## 入力

ホストリポジトリのドキュメント面

## 出力

ドキュメントの所見（`_inputs/docs-review-findings.md`）

## 下流

監査レビューシーケンスのドキュメントレビューステージ

## ワークフローのフェーズ

このコマンドは 5 つのフェーズを実行します。入力の取り込み、ページごとの走査、所見ごとのトリアージ、所見の出力、そして検証ゲートです。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | 指定したパスで文書ファイルに到達できない | Markdown ページを含むリポジトリルートまたはドキュメントのソースディレクトリを渡す |

## 例

```bash
# Dry-run to preview what would happen
/docs-review --dry-run

# Execute against a repository root
/docs-review path/to/repo/
```
