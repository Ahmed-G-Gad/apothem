**役割:** 主任研究者（公開）
**パイプライン上の位置:** チェーン中段

論文を投稿先のテンプレートに整形し、投稿パッケージを組み立てます — 補足資料、データ／コードの可用性に関する記述、カバーレター、倫理および利益相反の宣言 — に加えて、DOI 付きのプレプリント／アーカイブ計画と投稿チェックリスト。オペレーターがパッケージを投稿します。終端の後続は `/research-disseminate` であり、公開された成果をその読者へと届けます。

## 正規の呼び出し

```bash
/research-publish
```

引数付き:

```bash
/research-publish [--suite-name NAME]
```

## 入力

論文の成果物と `_outputs/review-report.md`（査読による改訂と、その未判断リスト）。

## 出力

ホストにとって自然な場所にある、投稿先向けに整形された投稿パッケージ（整形された原稿＋補足資料＋データ／コードの可用性に関する記述＋カバーレター＋倫理／利益相反の宣言）＋ `_outputs/publication-record.md`（日付付きの投稿先規則の登録簿を含む。各規則について、その公式の出典ページ、読んだ日付、投稿段階を記載）＋投稿チェックリスト。

## 下流

/research-disseminate（下流の消費者）— オペレーターが投稿を行い、その後 `/research-disseminate` が公開された成果をその読者へと届けます。投稿先が改訂を返した場合は、パッケージを再構築する前に、改訂された論文に対して `/research-review` を再実行する。

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います:

1. **コンテキストを読み込む** — 論文とレビューレポートを読む。投稿先、サイクル、トラック、論文種別を固定し、各投稿先規則をその公式の出典ページ、読んだ日付、投稿段階とともに記録する。
2. **シーケンスゲートを検証する** — `_outputs/review-report.md` が存在し、その HIGH 重大度の改訂が解決されていることを確認する（またはオペレーターが残存リスクを明示的に受け入れている場合）。そうでない場合は、`Blocked: run /research-review first` で停止する。
3. **整形してパッケージ化する** — 各投稿先規則をその出典ページ、読んだ日付、投稿段階とともに引き継ぎ、手を加えていない投稿先のテンプレートの上に構築し、ページ数と語数を投稿先の方法で数え、コンパイルされた PDF を検査する。そのうえで補足資料、データ／コードの可用性、カバーレター、倫理／利益相反の宣言を組み立てる。
4. **プレプリント／アーカイブを計画する** — プレプリントと DOI の計画を記録する。投稿チェックリストを構築する。
5. **ハンドオフマニフェストを更新する** — 投稿パッケージと公開記録を記録する。
6. **パッケージを発行する** — 投稿先向けに整形された投稿パッケージ＋ `_outputs/publication-record.md`。

## 厳密性の下限

整形は段階的な開示を尊重します。二重盲検の発表先では、著者・所属機関・システムの身元は別途提出されるメタデータへと剥がされ、指定されたカメラレディ段階でのみ復元されます。アーカイブ寄託は、発表先に応じてスケールする再現性証拠パッケージ（データ、コード、固定された環境、シード、ハードウェアログ、インスタンスごとの結果、および図）を携えます。二重盲検の発表先では、原稿だけでなく、補足アーカイブと、リンクされたすべてのリポジトリやデータセットについても身元を検査します。

投稿先規則には出典があり、段階に対応付けられます。数に入るのは対象自身の公式ページのみです。近隣の投稿先、以前のサイクル、兄弟トラックが代わりになることは決してなく、改訂やカメラレディのための再構築では、初回投稿時の制限ではなくその段階の制限を適用します。背後に公式ページのない規則はオペレーターに質問し、投稿先に照らして未検証とマークします。投稿先のテンプレートファイルは配布されたままに保たれるため、ローカルで書かれた出発点のファイルはその旨が報告されます。ページ数と語数は、除外されるセクションを記録したうえで投稿先の方法で数え、各図と表は投稿先が受け取るサイズと形式でチェックします。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-review first | レビューレポートがない、または未解決の HIGH 重大度の改訂がある | `/research-review` を実行して `_outputs/review-report.md` を生成する、未解決の HIGH 改訂を解決して `/research-review` を再実行する、または残存リスクを明示的に受け入れる |
| 未対応の HIGH 改訂 | レビューの指摘を飛ばした | 改訂に対応して `/research-review` を再実行する |
| データ／コードの可用性の欠落 | 再現性のための面が存在しない | 投稿前に、データ／コードの可用性に関する記述を追加する |
| 出典のない投稿先規則 | 規則が別のサイクル、トラック、近隣の投稿先、または記憶に由来する | 対象を固定する。規則について公式ページ、読んだ日付、段階を記録するか、オペレーターに質問して未検証とマークする |
| テンプレートが改変されている | ローカルな編集が投稿先のページのジオメトリや組版設定を変更している | 投稿先のファイルを復元し、テンプレートが文書化しているオプションを通じてのみレイアウトを変更する |

## 例

```bash
# 投稿先の投稿パッケージを組み立てる
/research-publish --suite-name <name>
```
