**役割:** 主任研究者（公開）
**パイプライン上の位置:** チェーン中段

論文を投稿先のテンプレートに整形し、投稿パッケージを組み立てます — 補足資料、データ／コードの可用性に関する記述、カバーレター、倫理および利益相反の宣言 — に加えて、DOI 付きのプレプリント／アーカイブ計画と投稿チェックリスト。オペレーターがパッケージを投稿します。終端の後続は `/research-disseminate` であり、公開された成果をその読者へと届けます。

## 正規の呼び出し

```bash
/research-publish
```

引数付き:

```bash
/research-publish [path/to/research-suite/]
```

## 入力

論文の成果物と `_outputs/review-report.md`（査読による改訂）。

## 出力

ホストにとって自然な場所にある、投稿先向けに整形された投稿パッケージ（整形された原稿＋補足資料＋データ／コードの可用性に関する記述＋カバーレター＋倫理／利益相反の宣言）＋ `_outputs/publication-record.md` ＋投稿チェックリスト。

## 下流

/research-disseminate（下流の消費者）— オペレーターが投稿を行い、その後 `/research-disseminate` が公開された成果をその読者へと届けます。投稿先が改訂を返した場合は、パッケージを再構築する前に、改訂された論文に対して `/research-review` を再実行する。

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います:

1. **コンテキストを読み込む** — 論文とレビューレポートを読む。
2. **シーケンスゲートを検証する** — `_outputs/review-report.md` が存在することを確認する。存在しない場合は `Blocked: run /research-review first` で停止する。
3. **整形してパッケージ化する** — 投稿先のテンプレートを適用する。補足資料、データ／コードの可用性、カバーレター、倫理／利益相反の宣言を組み立てる。
4. **プレプリント／アーカイブを計画する** — プレプリントと DOI の計画を記録する。投稿チェックリストを構築する。
5. **ハンドオフマニフェストを更新する** — 投稿パッケージと公開記録を記録する。
6. **パッケージを発行する** — 投稿先向けに整形された投稿パッケージ＋ `_outputs/publication-record.md`。

## 厳密性の下限

整形は段階的な開示を尊重します。二重盲検の発表先では、著者・所属機関・システムの身元は別途提出されるメタデータへと剥がされ、指定されたカメラレディ段階でのみ復元されます。アーカイブ寄託は、発表先に応じてスケールする再現性証拠パッケージ（データ、コード、固定された環境、シード、ハードウェアログ、インスタンスごとの結果、および図）を携えます。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-review first | レビューレポートがない | `/research-review` を実行して `_outputs/review-report.md` を生成する |
| 未対応の HIGH 改訂 | レビューの指摘を飛ばした | 改訂に対応して `/research-review` を再実行する |
| データ／コードの可用性が欠落 | 再現性のための面が存在しない | 投稿前にデータ／コードの可用性に関する記述を追加する |

## 例

```bash
# 投稿先の投稿パッケージを組み立てる
/research-publish path/to/research-suite/
```
