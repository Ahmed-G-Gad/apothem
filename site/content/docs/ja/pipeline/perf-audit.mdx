**役割：** パフォーマンス監査者
**パイプライン位置：** フォートレス

USE メソッドを用いて、クラス別のパフォーマンス予算（フックランタイム、verify-ecosystem、コンフォーミティゲート、テスト、委任されたワーカー、シェル、lint）に対して監査します。

## 正規の呼び出し

```bash
/perf-audit
```

引数付き：

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## 入力

`hooks/`、`src/apothem/benchmarks/`、`tests/`、およびフックのブートストラップスタブ `hooks/lib/bootstrap.{sh,ps1}` を含むホストリポジトリ

## 出力

パフォーマンスの所見（`_inputs/perf-audit-findings.md`）

## 下流

監査レビューシーケンスのパフォーマンス監査段階

## ワークフローのフェーズ

このコマンドは 5 つの監査フェーズを実行します。入力の取り込み、クラス別の予算の発見、ベンチマークの実行、USE メソッドによるホットパスの特定、そして検証ゲートを伴う所見の出力です。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | リポジトリに `src/apothem/benchmarks/` が存在しない | ベンチマークのドライバーを追加してから再実行する。存在するまで、コマンドは実行を拒否する |

## 例

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
