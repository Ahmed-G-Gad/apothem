- **役割：** パフォーマンス監査者
- **パイプライン位置：** フォートレス

USE メソッドを用いて、クラス別のパフォーマンス予算（フックランタイム、verify-ecosystem、コンフォーミティゲート、テスト、委任されたワーカー、シェル、lint、インストール解決）に対して監査します。

## 正規の呼び出し

```bash
/perf-audit
```

引数付き：

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## 入力

`src/apothem/hooks/`、`src/apothem/benchmarks/`、`tests/`、およびフックのブートストラップスタブ `src/apothem/hooks/lib/bootstrap.{sh,ps1}` を含む Apothem リポジトリのチェックアウト

## 出力

パフォーマンスの所見（`_inputs/perf-audit-findings.md`）

## 下流

監査レビューシーケンスのパフォーマンス監査段階

## ワークフローのフェーズ

このコマンドは 5 つの監査フェーズを実行します。入力の取り込み、クラス別の予算の発見、ベンチマークの実行、USE メソッドによるホットパスの特定、そして検証ゲートを伴う所見の出力です。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| Apothem のチェックアウトではない | リポジトリに `src/apothem/benchmarks/` が存在しない | 修正は不要。コマンドはこの観点を対象外として報告し、`/audit` はそれをスキップする |

## 例

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
