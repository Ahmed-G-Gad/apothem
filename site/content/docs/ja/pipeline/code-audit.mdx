**役割：** 監査者
**パイプライン位置：** 要塞

リポジトリコーパス規模のクロスファイル・フォレンジックコード監査。

## 正規の呼び出し

```bash
/code-audit
```

引数付き：

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## 入力

承認済みのソースレイアウト、テストカバレッジのベースライン、そして（SHARED+ では）合格した CI ゲートを備えたホストリポジトリ

## 出力

コーパスレベルの所見（`_inputs/code-audit-findings.md`）

## 下流

監査レビューシーケンスのフォレンジックコード監査ステージ

## ワークフローのフェーズ

このコマンドは 6 つのフォレンジックフェーズを実行します。入力の取り込み、ファイル横断の依存関係の走査、型ヒントとカバレッジの監査、デッドコードと重複の検出、アーキテクチャの整合性の監査、そして検証ゲートを伴う所見の出力です。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | SHARED+ で CI ゲートの実行またはテストカバレッジのベースラインがない | ホストの CI パイプラインを先に実行してから、再実行する |

## 例

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
