**役割：** アクセシビリティ監査者
**パイプライン位置：** フォートレス

レンダリングされる各ページに対する WCAG 2.2 AA アクセシビリティ監査。

## 正規の呼び出し

```bash
/a11y-audit
```

引数付き：

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## 入力

デプロイ済み、またはローカルで配信されるプロジェクトのウェブサイト

## 出力

アクセシビリティの所見（`_inputs/a11y-audit-findings.md`）

## 下流

監査レビューシーケンスのアクセシビリティ監査段階

## ワークフローのフェーズ

このコマンドは 5 つの監査フェーズを実行します。入力の取り込み、ページごとの監査、所見ごとのトリアージ、所見の出力、そして検証ゲートです。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | サイトのパスまたは URL が解決されない | ビルド済みのサイトディレクトリ、または到達可能な URL を渡す |

## 例

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
