**役割：** 主任研究者（普及とインパクト）
**パイプライン上の位置：** 最終

採択後の普及とインパクトを推進します。公開アクションはオペレーターが実行します。本段階は準備の整った普及計画で止まり、決して自動公開しません。

## 標準的な呼び出し

```bash
/research-disseminate
```

引数付き：

```bash
/research-disseminate [--suite-name NAME] [--override] [--archive REPO] [--preprint SERVER]
```

## 入力

スイートの `_outputs/publication-record.md`（`/research-publish` が生成した発表先パッケージ + 投稿記録）。

## 出力

`_outputs/dissemination-plan.md`（プレプリント告知、公開成果物計画、FAIR アーカイブ寄託記録、altmetrics とインパクト追跡計画、反論 / 改訂ループ、そして登録報告のステージ 2 経路）。

## 下流

最終 —— 普及計画はパイプラインの最終成果物です。査読者への反論 / 改訂ループは、改訂が必要な場合に `/research-paper` へ再び入ることがあります。

## ワークフローの段階

このコマンドは標準的な `/research` パイプラインのワークフローに従います：

1. **コンテキストの読み込み** —— `_outputs/publication-record.md`、ルール、および既存のスイート状態を読み込みます。
2. **プレプリントと公開成果物の計画** —— プレプリント告知と、講演 / ポスター / ブログの計画を起草します。
3. **FAIR アーカイブ寄託の記録** —— データ + コードを永続識別子付きの FAIR リポジトリに寄託する計画を立てます。
4. **インパクト追跡の設定** —— 提案のインパクト経路に対して altmetrics とインパクト追跡を計画します。
5. **反論ループの準備** —— 査読者への反論と、該当する場合は登録報告のステージ 2 経路を起草します。
6. **検証と発出** —— 計画が実行可能であることを確認し、`_outputs/dissemination-plan.md` と引き継ぎマニフェストを発出します。公開アクションはオペレーターが実行します。

## 厳密性の下限

公開成果物は自然なドメイン言語を携えます。普及が匿名解除に先行する場合、著者・所属機関・システムの身元は指定された段階まで保留されます。FAIR 寄託は、独立した第三者が研究を再現できるようにする、発表先の野心に応じてスケールする、永続的で引用可能な再現性証拠パッケージです。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| FAIR 寄託記録がない | アーカイブ手順が省略された | FAIR リポジトリ（`--archive`）を選び、永続識別子付きの寄託計画を記録する |
| 計画が自動公開を試みる | 段階の境界を越えた | 準備の整った計画で止まる。あらゆる公開アクションはオペレーターが実行する |
| 発表記録がない | `/research-publish` がまだ実行されていない | まず `/research-publish` を実行して発表先パッケージを生成する |

## 例

```bash
# 採択後に普及を計画する
/research-disseminate --suite-name retrieval-latency

# プレプリントサーバーと FAIR アーカイブを固定する
/research-disseminate --preprint arXiv --archive Zenodo
```
