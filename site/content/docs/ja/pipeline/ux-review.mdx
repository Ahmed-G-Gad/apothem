**役割：** UX レビュアー
**パイプライン位置：** 要塞

CLI のエルゴノミクス、ドキュメント、オンボーディングを対象とした開発者体験レビュー。

## 正規の呼び出し

```bash
/ux-review
```

引数付き：

```bash
/ux-review [path/to/repo/] [--focus SURFACE] [--dry-run]
```

## 入力

README、インストールスクリプト、CLI のエントリーポイントを備えた、デプロイ済みのホストリポジトリ

## 出力

UX の所見（`_inputs/ux-review-findings.md`）

## 下流

監査レビューシーケンスの UX レビューステージ

## ワークフローのフェーズ

このコマンドは 5 つのフェーズを実行します。入力の取り込み、CLI の使いやすさの走査、インストールフローとエラー回復の監査、ドキュメントの発見しやすさの走査、そして検証ゲートを伴う所見の出力です。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 前提条件が未完了 | 依存フェーズが終わっていない | まず上流のフェーズを完了させる |
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 対象が未デプロイ | 対象にオペレーター向けの面がない | デプロイ済みのリポジトリルートを渡す |

## 例

```bash
# Dry-run to preview what would happen
/ux-review --dry-run

# Execute against a host repository
/ux-review path/to/repo/
```
