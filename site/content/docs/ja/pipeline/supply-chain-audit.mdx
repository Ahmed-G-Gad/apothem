**役割：** サプライチェーン監査者
**パイプライン位置：** フォートレス

SLSA + Sigstore + SBOM 標準に照らしたサプライチェーン監査。

## 正規の呼び出し

```bash
/supply-chain-audit
```

引数付き：

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## 入力

ホストリポジトリのリリースパイプライン

## 出力

サプライチェーンの所見（`_inputs/supply-chain-audit-findings.md`）

## 下流

監査レビューシーケンスの supply-chain-audit ステージ

## ワークフローのフェーズ

このコマンドは 5 つの監査フェーズを実行します。入力の取り込み、軸ごとの走査、所見ごとのトリアージ、所見の出力、そして検証ゲートです。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 前提条件が未完了 | 依存フェーズが終わっていない | まず上流のフェーズを完了させる |
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 対象が拒否される | 対象にリリース面がない | .github/workflows/、リリーススクリプト、またはビルドマニフェストのいずれかを含むリポジトリルートを渡す |

## 例

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
