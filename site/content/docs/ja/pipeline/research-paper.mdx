**役割:** 主任研究者（執筆）
**パイプライン上の位置:** 中間

統合・設計・分析から、トップレベルの論文ドラフトを組み立てます — 要旨、序論、関連研究、手法、結果、考察、限界、結論、参考文献。すべての引用は実在の出典に解決することが検証されます。架空の引用はありません。

## 標準的な呼び出し

```bash
/research-paper
```

引数付き:

```bash
/research-paper [path/to/research-suite/]
```

## 入力

`_inputs/synthesis.md`（SOTA マップ + ギャップ）、`_inputs/study-design.md`（手法）、および `_outputs/analysis.md`（結果）。

## 出力

ホストにとって自然な場所（`paper/`）に置かれる論文成果物 — 要旨、序論、関連研究、手法、結果、考察、限界、結論、参考文献。

## 下流

/research-review（下流の利用者）

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います。

1. **コンテキストの読み込み** — 統合、研究設計、分析を読み込みます。
2. **シーケンスゲートの検証** — `_outputs/analysis.md` が存在することを確認します。存在しない場合は `Blocked: run /research-analysis first` で停止します。
3. **ドラフトの組み立て** — 要旨から結論までを構成します。序論と関連研究は統合に、手法は設計に、結果は分析に基づきます。
4. **引用の検証** — すべての参考文献が実在の出典に解決します。
5. **引き継ぎマニフェストの更新** — 論文成果物のパスを記録します。
6. **論文の出力** — ホストにとって自然な `paper/` の場所に置かれる原稿。

## 厳密性の下限

二重盲検の発表先では、原稿は匿名性ポリシーが許すもののみを携えます。すなわち、著者・所属機関・資金提供・研究対象のシステムは、それらを名指しせずに自然なドメイン言語で記述され、指定された匿名解除段階のために別途提出されるメタデータへと保留されます。再現性と統計報告の深さは、対象とする発表先の野心に応じてスケールします。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| Blocked: run /research-analysis first | 分析がない | `/research-analysis` を実行して `_outputs/analysis.md` を生成します |
| 架空の引用 | 参考文献が解決しない | その引用を削除または修正します。決して出典を捏造しないでください |
| 結果の誇張 | 考察が分析を超えている | 主張を、分析された効果量 + 信頼区間に限定します |

## 例

```bash
# 統合 + 設計 + 分析から論文ドラフトを組み立てる
/research-paper path/to/research-suite/
```
