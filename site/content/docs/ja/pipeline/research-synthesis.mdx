**役割:** 主任研究者（統合）
**パイプライン上の位置:** チェーン中段

収集したソースを最新水準マップ＋文献マトリクスに調和させ、この作業が対象とする明示的な研究ギャップを述べます。すべての要となる論点は、2 つ以上の独立したソースに照らして、反証をデフォルトとして敵対的に検証されます。

## 正規の呼び出し

```bash
/research-synthesis
```

引数付き:

```bash
/research-synthesis [--suite-name NAME]
```

## 入力

`_inputs/source-ledger.md`（ランク付け済み・スクリーニング済みのソースインデックス）に加えて、`sources/` の下のソースごとの抽出。

## 出力

`_inputs/synthesis.md` — 最新水準マップ、文献マトリクス、係争中の所見台帳、および、その根拠となる検索の網羅範囲を伴う明示的な一文のギャップ陳述。報告数と研究数の両方を報告します。

## 下流

/research-proposal（下流のコンシューマー）

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います:

1. **コンテキストを読み込む** — ソース台帳とソースごとの抽出を読む。
2. **シーケンスゲートを検証する** — ソース台帳が存在することを確認する。存在しない場合は `Blocked: run /research-sources first` で停止する。
3. **統合する** — 台帳から各ソースの研究 ID、証拠クラス、完全性ステータスを引き継いで、最新水準マップ＋文献マトリクスを構築する。一致と矛盾を調和させる。明示的なギャップを述べ、その根拠となる検索の網羅範囲を明示する。
4. **敵対的に検証する** — すべての要となる論点を、2 つ以上の独立した研究に照らして、反証をデフォルトとして検証する。
5. **ハンドオフマニフェストを更新する** — 統合パスと係争中の論点台帳を記録する。
6. **統合を発行する** — `_inputs/synthesis.md`。

## 厳密性の下限

ギャップ陳述が確定される前に、統合はその用語・所見・推奨を、関連する兄弟コーパスに照らして調整します（コーパス横断の一貫性）。矛盾は係争中の所見台帳に記録され、決して黙って調和されることはありません。ギャップは、明確で簡潔な貢献に解決されなければなりません——裏付けのある論点によってすでに閉じられているものではなく、また重複する非明確な要素へと分解できるものでもありません。

## 証拠の数え方

- **報告ではなく研究。** 台帳で研究 ID を共有する報告、収集したサンプルを共有する研究、互いに引用し合うソースは、1 つのソースとして数えます。1 つの著者グループによる 2 本の論文は、まずデータの共有がないかをチェックします。確実性の評価も、同じ方法で独立した研究を数えます。
- **完全性。** 撤回または取り下げられたソースは裏付けに数えず、完全性ステータスが `concern` のソースが論点の唯一の裏付けになることは決してありません。
- **反対の証拠と網羅範囲。** 検索で見つかった先行する統合研究は、一次研究の所在を特定するためのものであり、それらと並んで数えることはしません。反対の証拠のクラスで何も残らなかった場合、その所見は `none found in the searches recorded` として記録され、決してコンセンサスとしては記録されません。また、ギャップの一文はその範囲を同じ用語で明示します。すなわち、インデックス、検索語と日付範囲、最終実行日、そして `incomplete` のフラグが付いたパスです。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-sources first | ソース台帳がない | `/research-sources` を実行して `_inputs/source-ledger.md` を生成する |
| 論点が 2 つ未満の独立した研究で生き残る | 裏付けが不十分、またはソースが研究やサンプルを共有している | 係争中または検証不能としてマークする。断言しない |
| ギャップが分野における不在として述べられている | ギャップの一文の背後に検索の網羅範囲がない | 記録された検索を範囲として明示する。それを超えて不在を断言しない |
| 明示的なギャップ陳述がない | 統合に対象が欠けている | 研究が対象とする一文のギャップを再導出する |

## 例

```bash
# 収集したソースを SOTA（最新水準）マップ＋ギャップに統合する
/research-synthesis --suite-name <name>
```
