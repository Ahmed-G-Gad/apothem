**役割：** 依存関係監査者
**パイプライン位置：** フォートレス

ライセンス、CVE、新鮮さに対する依存関係ごとの監査パス（直接 + 推移的）。

## 正規の呼び出し

```bash
/dependency-audit
```

引数付き：

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## 入力

ホストリポジトリの依存関係マニフェスト

## 出力

依存関係の所見（`_inputs/dependency-audit-findings.md`）

## 下流

監査レビューシーケンスの dependency-audit ステージ

## ワークフローのフェーズ

このコマンドは 5 つのフェーズを実行します。入力の取り込み、依存関係ごとの走査、所見ごとのトリアージ、所見の出力、そして検証ゲートです。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | リポジトリルートで依存関係のマニフェストが解決されない | 依存関係のマニフェストを含むリポジトリルートを渡す |

## 例

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
