**役割：** レビュアー
**パイプライン位置：** フォートレス

src/、scripts/、tools/ にわたる、オペレーター主導のファイルごとのコード品質レビューパス。

## 正規の呼び出し

```bash
/code-review
```

引数付き：

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## 入力

ライフサイクルのいずれかの状態にあるホストリポジトリ

## 出力

ファイルごとの所見（`_inputs/code-review-findings.md`）

## 下流

監査レビューシーケンスの逐行レビューステージ

## ワークフローのフェーズ

このコマンドは 5 つのフェーズを実行します。入力の取り込み、ファイルごとの走査、所見ごとのトリアージ、所見の出力、そして検証ゲートです。

## 失敗モード

| 症状 | 原因 | 復旧 |
|---------|-------|----------|
| 品質ゲート FAIL | 出力が基準を満たさない | 出力を修正して再実行する |
| 入力ファイルが欠落 | リポジトリに `src/`、`scripts/`、`tools/` のいずれも存在しない | そのうち少なくとも 1 つを含むリポジトリルートを渡す |

## 例

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
