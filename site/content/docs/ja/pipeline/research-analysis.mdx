**役割:** 主任研究者（分析）
**パイプライン上の位置:** チェーン中段

事前登録された計画に従って生データを分析します — 計画された統計検定を実行し、信頼区間付きの効果量を報告し（p 値だけではなく）、該当する場合は多重比較補正を適用し、頑健性／感度チェックを実行し、事前登録からのあらゆる逸脱を開示します。

## 正規の呼び出し

```bash
/research-analysis
```

引数付き:

```bash
/research-analysis [path/to/research-suite/]
```

## 入力

実験ステージが記録した、ホストにとって自然な場所にある生データ、加えて `_inputs/preregistration.md`（凍結された分析計画）。

## 出力

`_outputs/analysis.md`（効果量と信頼区間を伴う事前登録済みの検定、多重比較補正、頑健性チェック、開示された逸脱）＋ホストにとって自然な場所にある図／表。

## 下流

/research-paper（下流のコンシューマー）

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います:

1. **コンテキストを読み込む** — 生データと事前登録を読む。
2. **シーケンスゲートを検証する** — 実験の出力が存在することを確認する。存在しない場合は `Blocked: run /research-experiment first` で停止する。
3. **分析する** — 事前登録された検定を実行する。効果量＋信頼区間を報告する。多重比較を補正する。頑健性／感度チェックを実行する。
4. **逸脱を開示する** — 事前登録された計画からのあらゆる逸脱を記録する。
5. **ハンドオフマニフェストを更新する** — 分析パスと図／表を記録する。
6. **分析を発行する** — `_outputs/analysis.md` ＋図／表。

## 厳密性の下限

確率的な結果は、反復にわたる最良値・平均・中央値・標準偏差・最悪値として報告され、収束曲線と分布プロットを伴います。比較にはノンパラメトリック検定を用います——ペアワイズには対応のある符号順位検定、手法間には事後補正を伴うオムニバス順位検定——確率的優越の効果量と臨界差図とともに報告されます。結果が論文へ進むのは、進出ゲートを通過したときだけです。すなわち、比較対象を説得力をもって有意に上回り、その通過が監査可能なランブックに記録されたときです。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-experiment first | 生データがない | `/research-experiment` を実行してデータ＋ログを生成する |
| 効果量なしで p 値が報告される | 統計報告が不完全 | 効果量＋信頼区間を報告する |
| 開示されていない分析の逸脱 | 計画から無断で逸脱した | 事前登録に対する逸脱を開示する |

## 例

```bash
# 事前登録された計画に従って生データを分析する
/research-analysis path/to/research-suite/
```
