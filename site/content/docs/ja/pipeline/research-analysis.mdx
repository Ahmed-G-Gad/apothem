**役割:** 主任研究者（分析）
**パイプライン上の位置:** チェーン中段

事前登録された計画に従って生データを分析します — 独立した分析単位に対して計画された統計検定を実行し、信頼区間（ベイズ的計画では信用区間。p 値だけではなく）付きの効果量を報告し、該当する場合は多重比較補正を適用し、欠測データをどのように扱ったかを明記し、頑健性／感度チェックを実行し、事前登録からのあらゆる逸脱を開示します。

## 正規の呼び出し

```bash
/research-analysis
```

引数付き:

```bash
/research-analysis [--suite-name NAME] [--override] [--correction METHOD] [--alpha LEVEL]
```

## 入力

実験ステージが記録した、ホストにとって自然な場所にある生データ、加えて `_inputs/preregistration.md`（凍結された分析計画）。

## 出力

`_outputs/analysis.md`（各主要結果について、効果量、信頼区間、分析単位、およびドメインごとのバイアス判定を伴う事前登録済みの検定、多重比較補正、欠測データの扱い、頑健性チェック、開示された逸脱）＋ホストにとって自然な場所にある図／表。

## 下流

/research-paper（下流のコンシューマー）

## ワークフローのフェーズ

このコマンドは標準的な `/research` パイプラインのワークフローに従います:

1. **コンテキストを読み込む** — 生データと事前登録を読む。
2. **シーケンスゲートを検証する** — 実験の出力が存在することを確認する。存在しない場合は `Blocked: run /research-experiment first` で停止する。
3. **分析する** — 独立した分析単位に対して事前登録された検定を実行する。診断に検定を選ばせることなく前提を診断する。効果量＋信頼区間を報告する。多重比較を補正する。欠測データの扱いを明記する。頑健性／感度チェックを実行する。
4. **逸脱を開示する** — 事前登録された計画からのあらゆる逸脱を記録する。事前登録が指定するフォールバックへの移行は計画された適応として記録され、それ以外の置き換えはすべて逸脱となる。
5. **ハンドオフマニフェストを更新する** — 分析パスと図／表を記録する。
6. **分析を発行する** — `_outputs/analysis.md` ＋図／表。

## 統計的規律

- **検定は設計に従う。** 事前登録された主要検定は、事前登録自体のフォールバックのトリガーが発動しない限り維持されます。スクリーニング検定で棄却されなかったことは、前提が成り立つことを示しません。
- **n は独立した単位を数える。** 反復測定、サブサンプル、クラスター、シードは単位へと集約されるか従属性としてモデル化され、決して独立した反復としては数えられません。
- **帰無結果は 3 つの方法で読む。** 効果量の区間、関心のある最小効果に対する同等性の結果、そして感度の記述（達成された分析対象の n で検出可能な最小効果）を併せて報告します。観測された効果から計算された検出力は決して報告しません。
- **ベイズ的計画はそれ自身の基準で。** 事前登録されたベイズ的計画は、信用区間を伴う事後分布の要約を報告し、いかなる事後分布を報告する前にも事前分布の感度、計算の診断、事後予測のチェックを実行し、帰無結果には事前に固定した実質的同等性の領域を用います。
- **結果レベルのバイアスと図。** 各主要結果は、設計の妥当性への脅威の台帳を起点とし、決して 1 つのスコアに合算されない、ドメインごとの低 / いくらかの懸念 / 高の判定を持ちます。また、すべての図は符号化、不確実性の開示、アクセシビリティの下限を満たします。

## 厳密性の下限

確率的手法は、インスタンスまたは条件ごとに少なくとも 30 回の独立した反復で実行します。反復間のばらつきが検定対象の差に比べて大きい場合は、要約統計量が安定するまで反復回数を増やします。結果は、反復全体にわたる最良値、平均値、中央値、標準偏差、最悪値として報告し、収束曲線と分布プロットを併せて示します。比較にはノンパラメトリック検定を用います——ペアごとには対応のある符号順位検定、手法全体には事後補正を伴うオムニバス順位検定——これらは、確率的優越の効果量と臨界差図とともに報告されます。結果が論文に進めるのは、進出ゲートを通過したときだけです。すなわち、比較対象を説得力をもって有意に上回り、その通過が監査可能なランブックに記録されたときです。

## 失敗モード

| 症状 | 原因 | 回復 |
|---------|-------|----------|
| Blocked: run /research-experiment first | 生データがない | `/research-experiment` を実行してデータ＋ログを生成する |
| 効果量なしで p 値が報告される | 統計報告が不完全 | 効果量＋信頼区間を報告する |
| 従属した観測が反復として数えられている | 反復測定、サブサンプル、クラスター、またはシードが独立として扱われた | 独立した単位へ集約するか、従属性をモデル化する。n は単位を数える |
| 帰無結果に観測検出力が報告されている | 観測された効果から検出力が計算された | それを削除し、区間、同等性の結果、感度の記述を報告する |
| 開示されていない分析の逸脱 | 計画から無断で逸脱した | 事前登録に対する逸脱を開示する |

## 例

```bash
# 事前登録された計画に従って生データを分析する
/research-analysis --suite-name my-study
```
