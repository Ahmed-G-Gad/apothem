日常的なワークフロー。これらのガイドは Apothem の 4 つのコア機能——共有ガバナンス
プロファイル、動作ルール、`/plan` および `/research` パイプライン、そして適合性
ゲート——に加えて、委譲ワーカーとフックの作成を扱います。
