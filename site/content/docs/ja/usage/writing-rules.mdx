ルールは、`src/apothem/rules/` に置かれる、拡張子 `.md` の Markdown ファイルです。

## ルールのフロントマター

```yaml
---
name: "..."
description: "..."
pathFilter: ""            # empty string for always-on; a glob for path-filtered
alwaysApply: true         # true for always-on; false for path-filtered
---
```

## ルールのスコープ

ルールのスコープは、二つのフロントマターフィールド `alwaysApply` と `pathFilter` によって設定されます:

| `alwaysApply` | `pathFilter` | 適用されるタイミング |
|---------------|--------------|--------------|
| `true` | `""`（空） | 常時適用: すべてのセッション、すべてのファイル |
| `false` | `"**/*.py"` のような glob | パスによる絞り込み: アクティブなファイルが glob に一致する場合のみ |

## ルールの例

```markdown
---
name: "python-conventions"
description: "Python style conventions for this project"
pathFilter: "**/*.py"
alwaysApply: false
---

# Python conventions

- Use type annotations on all public functions.
- Maximum line length: 88 characters.
- Prefer explicit over implicit.
```

## ルールをハーネスに適用する

ルールを書いた後は、インストール済みの各ハーネスアダプターを更新します。`apothem harnesses list` を実行して、インストール済みの一覧を確認し、ハーネスごとに一度ずつ update を呼び出してください:

```bash
apothem update --harness claude-code
apothem update --harness cursor
```

## ルールの検証

```bash
python -m apothem.conformity.gate --check frontmatter
```
