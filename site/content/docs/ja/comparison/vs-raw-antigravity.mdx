Antigravity は Class I のマニフェスト伝播ハーネスです。Apothem はグローバルな `~/.gemini/GEMINI.md` のコンテキストアンカーを書き込み、`~/.gemini/antigravity-cli/plugins/apothem/` の下に Apothem プラグインをインストールします。このページでは、そのレイアウトを手作業で管理する場合と、Apothem で管理する場合を比較します。

## ステータス

**プレビュー。** Antigravity アダプターは、現在文書化されている `GEMINI.md` のコンテキストアンカーと、Antigravity CLI のプラグインの面を対象とします。ネイティブな面を持たないコホートは、引き続き Apothem のサポート素材のままです。

## 作業量の比較

| タスク | 手作業の設定 | Apothem で管理 |
| ---- | --------------- | --------------- |
| ルールを作成する | 各プラグインのルールファイルを手作業で書く | 共有コーパスに一度書く |
| 再利用可能なプロンプトを保持する | コマンドのプロンプトとスキルをプラグインのファイルに手作業でコピーする | プラグインのスキルへ変換またはコピーされる |
| フックのサポート素材を保持する | フックの参照を、有効な接続なしに手作業でコピーする | Apothem プラグインのサポートサブツリーの下にコピーされる |
| ルールを他のハーネスと揃えて保つ | ツールごとに手作業 | `apothem update` で自動的に行われる |
| 設定をインストール／削除する | ファイルを手作業でコピーおよび削除する | `apothem install` / `apothem uninstall` |
| 設定が正しいことを検証する | 手作業での確認 | `apothem verify --harness antigravity` |

## Apothem が管理する対象

Apothem は、Antigravity のグローバルなコンテキストファイル、プラグインのメタデータ、変換されたコマンドスキル、再利用可能なスキル、変換されたエージェント、ルール、テンプレート、フックのサポート素材を管理します。フックファイルはサポート素材として保持されます。アダプターが Antigravity の `hooks.json` 向けのスキーマ変換レイヤーを所有するまで、Apothem は有効な Antigravity のフックイベントを登録しません。

## 移行の手順

1. まだの場合は、共有プロファイルを作成するために `apothem profile init` を実行します。
2. 既存の手書きの Antigravity ルールを、共有コーパスに移します。
3. `apothem install --harness antigravity` を実行して、コーパスを伝播させます。
4. `apothem verify --harness antigravity` を実行して、設定が配置されたことを確認します。
5. 以降の変更はすべて `apothem update --harness antigravity` を使います。
