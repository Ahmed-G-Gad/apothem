Kimi Code はプロジェクトルートの `AGENTS.md` を命令ファイルとして読み取り、
プロジェクト設定を `<project>/.kimi-code/` の下に保持します。これには、
オペレーター所有の `.kimi-code/mcp.json` MCP 面も含まれます。
その命令ファイルと、それを支えるコホートは、プロジェクトごとに、いつまでも
手作業で書き続けることができます。
Apothem の kimi-code アダプターは、ガバナンス面を共有プロファイルから `AGENTS.md` に
管理ブロックとしてレンダリングし、すべてのハーネスとすべてのプロジェクトにわたって
一貫した状態を保ちます。このページでは、その構成を手作業で維持する場合と、
Apothem で管理する場合とを対比します。

## 労力の比較

| タスク | 手作業の構成 | Apothem 管理 |
| ---- | --------------- | --------------- |
| `AGENTS.md` 命令面を書く | プロジェクトごとに手で書いて再同期する | 共有プロファイルからレンダリングされる 1 つの管理ブロック |
| ルール、コマンド、スキル、エージェントを同期し続ける | プロジェクトごとに手作業でコピー | インストールのたびに、スキルとコマンド（スキルとして）を `<project>/.kimi-code/skills/` の下へ、ヘルパーをサブエージェントとして `<project>/.kimi-code/agents/` の下へ、ルール、フック、テンプレートを `<project>/.kimi-code/.apothem/support/` の下へ配置 |
| 更新時にオペレーターの文章を保持する | 手作業でマージ | センチネルで区切られたブロック。その外側にあるオペレーターの文章は保持される |
| ルールを他のハーネスと揃えて保つ | 手作業、ツールごと | `apothem update` で自動 |
| 構成が正しいか検証する | 手作業での確認 | `apothem verify --harness kimi-code --project <path>` |

## Apothem が管理するもの

kimi-code アダプターは、共有ルールとガバナンス面をプロジェクトルートの `AGENTS.md` の
管理ブロックへレンダリングし、スキルと、スキルとしてラップしたコマンドを、Kimi Code が
読み込むプロジェクトのスキルディレクトリである `.kimi-code/skills/` にインストールします。
ヘルパーは `.kimi-code/agents/` 内の Kimi Code サブエージェントとなり、そのツール名は
Kimi Code が照合する名前に変換されます。フック、ルール、テンプレートの各コホートは
`.kimi-code/.apothem/support/` の下に置かれます。Kimi Code はフックをユーザースコープの
`~/.kimi-code/config.toml` から読み込みますが、アダプターはこのファイルを書き込みません。
アダプターは `.kimi-code/mcp.json` を作成しません。MCP 面はオペレーター所有のままです。
Kimi Code はプロジェクトの命令を `AGENTS.md` または `.kimi-code/AGENTS.md` から
読み取ります。アダプターが書き込むのはプロジェクトルートの `AGENTS.md` だけであり、
両方のファイルが存在する場合にどちらが優先されるかは、Kimi Code のドキュメントに
記載されていません。共有ルールが変更されるたびに、次回の `apothem update` で
ファイルが再レンダリングされます。

## 移行手順

1. まだ共有プロファイルを作成していなければ、`apothem profile init` を実行して作成します。
2. 既存の `AGENTS.md` のルールを、共有コーパスへ移します。
3. `apothem install --harness kimi-code --project <path>` を実行して、`AGENTS.md` 命令面、`.kimi-code/skills/` のスキル、`.kimi-code/agents/` のサブエージェント、`.kimi-code/.apothem/support/` のサポートツリーをレンダリングします。
4. `apothem verify --harness kimi-code --project <path>` を実行して、構成が配置されたことを確認します。
5. 以降の変更には毎回 `apothem update --harness kimi-code --project <path>` を使います。
