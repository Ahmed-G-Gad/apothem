Open-Claw は `~/.openclaw/openclaw.json` を読み込みます。Apothem は共有のコマンド
群とスキル群を `~/.openclaw/.apothem/support/skills/` の下に設置し、
`~/.openclaw/openclaw.json` の 2 か所を編集します。そのディレクトリを
`skills.load.extraDirs` に追加し、OpenClaw がスキルを読み込むようにします。また、
`hooks.internal.entries.bootstrap-extra-files` フックエントリーのパスリストにパス
`apothem/AGENTS.md` を追加し（エントリーがない場合は `enabled: true` で作成します）、
OpenClaw が各ワークスペースに書き込む Apothem のルールファイルを読み込むようにします。
Open-Claw の `agents.defaults.skills` はあなたが所有する名前の許可リストで、MCP は
CLI 面であるため、Apothem はどちらも書き込みません。

## ステータス

**プレビュー。** Open-Claw アダプターは、現在ドキュメント化されている設定ファイル、
追加のスキルディレクトリ面、同梱の `bootstrap-extra-files` フックを対象とします。
ルールはワークスペースのファイル `apothem/AGENTS.md` を通じて読み込まれ、テンプレート、
agents、hook 材料は Apothem のサポート材料のままです。

## 工数の比較

| タスク | 素の手動設定 | Apothem 管理 |
| ---- | --------------- | --------------- |
| 再利用可能なスキルを書く | 設定とスキルディレクトリを手で編集 | 共有コーパスに一度書く |
| 群を他のハーネスと揃えておく | ツールごとに手動 | `apothem update` で自動 |
| 設定をインストール／削除する | 手動 | `apothem install` / `apothem uninstall` |
| 設定が正しいか検証する | 手動の確認 | `apothem verify --harness open-claw` |

## Apothem が管理するもの

Open-Claw アダプターは `openclaw.json` を書き込み、Apothem のスラッシュコマンドを
スキルとして包み、Apothem のスキルを参照先のサポートディレクトリへコピーし、ルール、
テンプレート、agents、hook 材料を Apothem サポートサブツリーの下に保持します。
Apothem はまた、各ワークスペースに `apothem/AGENTS.md` を書き込み、同梱の
`bootstrap-extra-files` フックに登録するため、OpenClaw はワークスペース自身の
`AGENTS.md` を変更せずに Apothem のルールを読み込みます。
OpenClaw は `skills.load.extraDirs` を、ワークスペース、`~/.agents/skills`、
`~/.openclaw/skills` のソースの後に読み込むため、それらのいずれかにある
同じ名前のスキルが、Apothem のコピーの代わりに使われます。

## 移行手順

1. まだ作成していない場合は `apothem profile init` を実行して共有プロファイルを作成
   します。
2. 再利用可能な Open-Claw のスキルやコマンドプロンプトを共有コーパスへ移します。
3. `apothem install --harness open-claw` を実行して、ネイティブ設定とサポートスキル
   ディレクトリをレンダリングします。
4. `apothem verify --harness open-claw` を実行して、設定が配置されたことを確認します。
