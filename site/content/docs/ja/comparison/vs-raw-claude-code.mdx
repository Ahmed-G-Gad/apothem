Claude Code（提供元 Anthropic）はネイティブ構成を `~/.claude/` の下に保持します。
Apothem の claude-code アダプターは全表面アダプターであり、共有コーパスをその
ツリーへ直接伝播します。本ページは、構成を手作業で維持するのと Apothem で管理する
のとを対比します。

## 労力の比較

| タスク | 手作業の構成 | Apothem 管理 |
| ---- | --------------- | --------------- |
| ルール、エージェント、コマンド、スキルを書く | `~/.claude/` の各表面を手で編集 | 共有コーパスに一度書く |
| 出力スタイルとステータスラインを維持する | 表面ごとに手で編集 | 共有コーパスから伝播 |
| フックを構成する | `settings.json` のフックエントリを手で編集 | 伝播（PreToolUse/PostToolUse/Stop/SessionStart） |
| 構成を他のハーネスと揃えて保つ | 手作業、ツールごと | `apothem update` で自動 |
| 構成が正しいか検証する | 手作業の検査 | `apothem verify --harness claude-code` |

## Apothem が管理するもの

アダプターはルール、エージェント、コマンド、スキル、出力スタイル、ステータス
ライン、`settings.json` を `~/.claude/` へ伝播します。ネイティブの PreToolUse、
PostToolUse、Stop、SessionStart の各フックは共有コーパスから構成されます。

Apothem は、ユーザースコープの `~/.claude/CLAUDE.md` に、センチネルで区切られた管理ブロックを 1 つ書き込みます。`apothem update` は、そのブロックだけを書き直し、その外側にあるあなたの文章は保持します。プロジェクトの `CLAUDE.md` ファイルには触れません。Apothem は、その周囲の伝播される表面を統治します。

## 移行手順

1. まだ作成していなければ、`apothem profile init` を実行して共有プロファイルを作成します。
2. 既存の `~/.claude/` のルール、エージェント、コマンド、スキルを、共有コーパスへ移します。
3. `CLAUDE.md` はそのまま残します。Apothem はその管理ブロックの外側にあるあなたの文章を保持し、そのブロックだけを書き直します。
4. `apothem install --harness claude-code` を実行して、コーパスを伝播させます。
5. `apothem verify --harness claude-code` を実行して、構成が配置されたことを確認します。
6. 以降の変更には毎回 `apothem update --harness claude-code` を使います。
