ハーネスごとのレガシーなワークスペースを、共有の `.apothem` レイアウトへ移行します。

## 構文

```
apothem migrate-workspace [--project PATH] [--dry-run]
                          [--quiet|-q] [--verbose|-v]
                          [--format plain|json] [--json] [--no-color]
```

`migrate-workspace` は、ハーネスごとのレガシーなデータホーム（`.apothem/<harness>/...`）とレガシーな `.plans/` ツリーを、単一の共有作業ディレクトリ `.apothem/{plans,memory,learning,contexts}` へ統合します。
基点は、`--project` が指定された場合はその解決済みのルート、指定されない場合は現在の作業ディレクトリ（プロジェクトローカルのデフォルト）です。

ハーネスごとのメモリ、コンテキスト、学習のストアは、id 単位で共有ストアへ和集合マージされます。学習シグナルは連結したうえで重複が除去されます。競合するレコード（同じ id で本体が異なるもの）はスキップされ、上書きされることは決してありません。
レガシーな `.plans/` ツリーは `.apothem/plans/` の下へ移動します。
取り込まれる各ソースは、事前にバックアップされます。
この移行はべき等です。すでに移行済みのツリーに対して再実行しても、何も起こりません。

## オプション

| オプション | 説明 |
|---|---|
| `--project PATH` | ユーザースコープの設定ディレクトリではなくプロジェクトツリーへマテリアライズする、プロジェクトスコープのアダプター向けのプロジェクトルート。 |
| `--dry-run` | レガシーなレイアウトを検出し、書き込みを行わずに、移行される内容を報告します。 |
| `--quiet`, `-q` | 情報出力を抑制し、エラーのみを出力します。 |
| `--verbose`, `-v` | 追加の診断出力を出力します。 |
| `--format plain\|json` | 出力形式（デフォルト: `plain`）。 |
| `--json` | `--format json` の短縮形です。 |
| `--no-color` | 出力中の ANSI カラーコードを無効にします。 |
| `-h`, `--help` | ヘルプを表示して終了します。 |

## JSON 出力

`--json` のエンベロープは、移行の結果を含みます。
移行が完了した場合、`status` は `success` となり、ペイロードはマージされたレコード数、`.plans/` ツリーが再配置されたかどうか、バックアップのルート、そしてスキップされた競合があればそれを報告します。
`--dry-run` で呼び出した場合は、代わりに `legacy_layout_detected` を報告します。

```json
{
  "schema_version": 1,
  "command": "migrate-workspace",
  "status": "success",
  "base": "/home/example/project",
  "migrated": true,
  "backup_root": "/home/example/project/.apothem/backups/migrate-20260101T120000Z",
  "memory_merged": 12,
  "contexts_merged": 4,
  "learning_merged": 7,
  "conflicts": [],
  "plans_moved": true,
  "notes": []
}
```

レガシーなレイアウトが存在しない場合、`migrated` は `false` となり、何も書き込まれません。
`--dry-run` のエンベロープは結果のカウントを省略し、検出結果のみを報告します。

```json
{
  "schema_version": 1,
  "command": "migrate-workspace",
  "base": "/home/example/project",
  "dry_run": true,
  "legacy_layout_detected": false
}
```

## 例

```bash
apothem migrate-workspace
apothem migrate-workspace --project .
apothem migrate-workspace --dry-run --json
```

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 移行が完了した、またはレガシーなレイアウトが見つからなかった（移行するものがない） |
| 1 | 予期されるエラー — 検証またはプロジェクトルートのエラー、あるいは移行の失敗 |
| 64 | 使用法エラー: 不明なオプションまたはコマンド、あるいは欠落した、または無効なオプション値。`--json` の下では、エラーはコード `cli.usage` を持つ JSON エンベロープになります。 |
