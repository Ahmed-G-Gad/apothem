現在の共有プロファイルからハーネスアダプターの設定を再インストールします。

## 構文

```
apothem update --harness NAME|all [--profile PATH] [--dry-run]
                [--project PATH]
                [--quiet|-q] [--verbose|-v]
                [--format plain|json] [--json] [--no-color]
```

`update` は、現在の共有プロファイルからハーネスの出力を再マテリアライズします。
`install` と同じプロファイル検証、`--harness all` の選択、プロジェクトスコープのチェック、ドライランの動作、JSON エンベロープを使用します。

進行形のエイリアス `apothem updating` は、同じハンドラーに解決されます。

## オプション

| オプション | 説明 |
|---|---|
| `--harness NAME` | 更新するハーネスアダプター、またはレジストリ全体のセットを表す `all`（必須）。 |
| `--profile PATH` | 共有プロファイル YAML へのパス。デフォルトは `~/.config/apothem/profile.yaml` です。 |
| `--dry-run` | ファイルを書き込まずに更新をプレビューします。 |
| `--project PATH` | プロジェクトスコープのハーネス向けのプロジェクトルート。選択したハーネスのセットにプロジェクトスコープのアダプターが含まれる場合は必須です。 |
| `--quiet`, `-q` | 情報出力を抑制します。エラーのみが出力されます。 |
| `--verbose`, `-v` | 追加の診断出力を出力します。 |
| `--format plain\|json` | 出力形式（デフォルト: `plain`）。 |
| `--json` | `--format json` の短縮形。 |
| `--no-color` | 出力中の ANSI カラーコードを無効にします。 |
| `-h`, `--help` | ヘルプを表示して終了します。 |

## JSON 出力

```json
{
  "schema_version": 1,
  "status": "success",
  "command": "update",
  "action": "updated",
  "harness": "claude-code",
  "profile_path": "C:\\Users\\Example\\.config\\apothem\\profile.yaml",
  "project": null,
  "files_written": [],
  "results": [],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

`--dry-run` は `status: "dry_run"` と `files_written: []` を返します。

## 例

```bash
apothem update --harness claude-code
apothem update --harness claude-code --dry-run
apothem update --harness all --project . --dry-run --json
apothem Updating --harness claude-code   # continuous-form alias
apothem updating --harness claude-code   # lowercase variant
```

## 終了コード

| コード | 意味 |
|---|---|
| 0 | アダプターが正常に更新された、またはドライランが問題なく計画された |
| 1 | 想定された検証、プロファイル、ハーネス、プロジェクト、またはアダプターのエラー |
| 2 | 少なくとも 1 回の書き込みの後の、部分的なバッチのマテリアライズ |
| 64 | 使用法エラー: 不明なオプションまたはコマンド、あるいは欠落した、または無効なオプション値。`--json` のもとでは、エラーはコード `cli.usage` を持つ JSON エンベロープになります。 |
