登録済みのハーネスアダプターを一覧表示し、検査します。

`harnesses` は、`list` と `show` の 2 つのサブコマンドを持つコマンドグループです。

## 構文

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## サブコマンド

### `harnesses list`

登録済みのすべてのハーネスアダプターを一覧表示します。

| オプション | 説明 |
|---|---|
| `--quiet`, `-q` | 情報出力を抑制し、エラーのみを出力します。 |
| `--verbose`, `-v` | 追加の診断出力を出力します。 |
| `--format plain\|json` | 出力形式（デフォルト: `plain`）。 |
| `--json` | `--format json` の短縮形です。 |
| `--no-color` | 出力中の ANSI カラーコードを無効にします。 |
| `-h`, `--help` | ヘルプを表示して終了します。 |

### `harnesses show NAME`

特定のハーネスアダプターの詳細を表示します。
`NAME` は kebab-case のハーネス識別子です。利用可能な識別子を確認するには、`apothem harnesses list` を実行します。

| オプション | 説明 |
|---|---|
| `NAME` | 検査するハーネスアダプター（必須の位置引数）。 |
| `--quiet`, `-q` | 情報出力を抑制し、エラーのみを出力します。 |
| `--verbose`, `-v` | 追加の診断出力を出力します。 |
| `--format plain\|json` | 出力形式（デフォルト: `plain`）。 |
| `--json` | `--format json` の短縮形です。 |
| `--no-color` | 出力中の ANSI カラーコードを無効にします。 |
| `-h`, `--help` | ヘルプを表示して終了します。 |

## 例

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

登録済みのハーネス ID は次のとおりです。

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 成功 |
| 1 | ハーネスが見つからない（不明な `NAME` を指定した `harnesses show`）、またはすべてのアダプターが読み込みまたは報告に失敗した（`harnesses list`） |
| 2 | 少なくとも 1 つのアダプターが一覧表示されたが、少なくとも 1 つが報告に失敗した（`harnesses list`） |
| 64 | 使用法エラー: 不明なオプションまたはコマンド、あるいは欠落した、または無効なオプション値。`--json` の下では、エラーはコード `cli.usage` を持つ JSON エンベロープになります。 |
