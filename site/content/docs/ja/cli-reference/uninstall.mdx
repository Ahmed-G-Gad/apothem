ハーネスアダプターの設定を削除します。

## 構文

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

アダプターが管理するハーネスのターゲットを削除し、続いて、インストールが作成したディレクトリを、それが空になった時点で削除します（あなたのものが何か入っているディレクトリは残ります）。
`--yes` が指定されない限り、確認を求めます。
プロンプトを表示できない場合 —— `--format json`（プロンプトのテキストが単一の JSON ドキュメントを壊してしまうため）または非対話シェル（TTY なし）—— には、`--yes` が指定されない限り、コマンドは構造化された `uninstall.confirmation_required` エラー（終了コード 1）で最初の段階で拒否します。
選択したハーネスがインストールされていない場合、コマンドは「nothing to remove」の通知とともに成功します（終了コード 0）。

`--harness all` による削除は、意図的に網羅的です。プロファイルの `exclude_harnesses` がインストール時にスキップするものも含め、登録されているすべてのハーネスを対象とします —— クリーンアップは、以前のより広範なインストールが残した可能性のある状態にまで及びます。
一度もインストールされていないハーネスは「nothing to remove」と報告します。

進行形のエイリアス `apothem uninstalling` は、同じハンドラーに解決されます。

## オプション

| オプション | 説明 |
|---|---|
| `--harness NAME` | 削除するハーネスアダプター、またはレジストリ全体のセットを表す `all`（必須）。 |
| `--yes` | 確認プロンプトをスキップします。 |
| `--project PATH` | プロジェクトスコープのハーネス向けのプロジェクトルート。 |
| `--quiet`, `-q` | 情報出力を抑制します。エラーのみが出力されます。 |
| `--verbose`, `-v` | 追加の診断出力を出力します。 |
| `--format plain\|json` | 出力形式（デフォルト: `plain`）。 |
| `--json` | `--format json` の短縮形。 |
| `--no-color` | 出力中の ANSI カラーコードを無効にします。 |
| `-h`, `--help` | ヘルプを表示して終了します。 |

## JSON 出力

アダプターがインストールされていて、正常に削除された場合:

```json
{"schema_version": 1, "action": "uninstalled", "harness": "claude-code", "output_path": "..."}
```

アダプターがインストールされていなかった場合、コマンドは `0` で終了します。JSON 出力では、エンベロープに `"status": "success"` と `"action": "uninstalled"` が含まれ、結果の行には `"outcome": "skipped"` と、メッセージ `"not installed; no files
removed"` が含まれます。`status` フィールドが `"not_installed"` になることはありません。

## 例

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem Uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## 終了コード

| コード | 意味 |
|---|---|
| 0 | アダプターがアンインストールされた、またはインストールされていなかった |
| 1 | ハーネスが見つからない、確認が拒否されたか利用できない（`--yes` なしでの非対話モードまたは JSON モード）、またはすべての削除が失敗した |
| 2 | 部分的な削除 — 失敗の前に少なくとも 1 つのハーネスが削除された |
| 64 | 使用法エラー: 不明なオプションまたはコマンド、あるいは欠落した、または無効なオプション値。`--json` のもとでは、エラーはコード `cli.usage` を持つ JSON エンベロープになります。 |
