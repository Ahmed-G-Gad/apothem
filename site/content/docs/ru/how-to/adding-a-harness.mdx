Цель: включить ещё одну среду, чтобы Apothem материализовал нативную конфигурацию
этой среды из вашего общего профиля.

## Предварительные требования

- Общий профиль по адресу `~/.config/apothem/profile.yaml` (создайте его с помощью
  `apothem profile init`, если он ещё не существует).
- CLI `apothem` в вашем `PATH`. Если вы установили самодостаточное дерево исходного
  кода, добавляйте к каждой команде префикс `PYTHONPATH="$HOME/.apothem/src"` и
  запускайте `python -m apothem` вместо `apothem` — или используйте
  `npx @ahmed-g-gad/apothem`.

## Шаги

1. Выведите список зарегистрированных сред и посмотрите, какие уже установлены:

   ```bash
   apothem harnesses list
   ```

   `apothem harnesses list` печатает каждый поддерживаемый идентификатор; тот же
   набор есть в [списке сред](/docs/harnesses) и в сгенерированном из исходного кода
   [реестре сред](/docs/reference/harness-registry). Выберите идентификатор для
   вашего инструмента, а не закрепляйте список здесь жёстко — он растёт по мере
   добавления адаптеров.

2. Изучите целевую среду, чтобы подтвердить её область и путь вывода:

   ```bash
   apothem harnesses show cursor
   ```

   Строка `Scope: project` означает, что адаптер материализуется в дерево проекта и
   требует `--project PATH`; `Scope: user` материализуется в каталог конфигурации
   пользовательского уровня и не нуждается во флаге проекта.

3. Предпросмотрите установку без записи файлов:

   ```bash
   apothem install --harness cursor --dry-run
   ```

4. Установите среду. Для среды пользовательского уровня:

   ```bash
   apothem install --harness claude-code
   ```

   Для среды уровня проекта передайте корень проекта:

   ```bash
   apothem install --harness cursor --project /path/to/project
   ```

   Установите все поддерживаемые среды сразу с помощью `--harness all` (среды уровня
   проекта по-прежнему нуждаются в `--project`; идентификаторы, перечисленные в
   `exclude_harnesses` в профиле, пропускаются).

## Проверка

```bash
apothem verify --harness cursor
```

Строка `✓ <harness-id> is verified` подтверждает, что управляемые цели существуют и
разбираются. `apothem doctor` даёт общесистемный обзор по каждой среде.

## Связанное

- [Редактируйте профиль](/docs/how-to/editing-the-profile), чтобы изменить то, что
  материализует адаптер, затем повторно запустите `apothem update`.
- [Установка](/docs/install) охватывает установку при первом запуске.
