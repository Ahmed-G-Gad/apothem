Цель: управлять `install.sh` / `install.ps1` без редактирования скрипта, задавая
переменные окружения перед его запуском.

## Предварительные требования

- POSIX-оболочка (`bash`) или PowerShell 5.1+.
- Переменные читаются один раз в начале установщика, поэтому задавайте их в той же
  команде (или сначала экспортируйте их), затем запускайте установщик.

## Переменные установщика

| Переменная | Что контролирует | По умолчанию |
| --- | --- | --- |
| `APOTHEM_HOME` | Назначение установки для клонированного дерева исходного кода | `$HOME/.apothem` |
| `APOTHEM_REPO` | Удалённый Git-репозиторий для клонирования | `https://github.com/ahmed-g-gad/apothem` |
| `APOTHEM_REF` | Git-ссылка для извлечения; если не задана, разрешается последний подписанный тег `vMAJOR.MINOR.PATCH`, значение тега закрепляет его, `main` выбирает движущуюся ветку | не задано (последний подписанный тег) |
| `APOTHEM_ALLOW_UNVERIFIED` | Понижает провал проверки подписи тега с фатального прерывания до предупреждения, когда установлено в `1` | `0` (проверять, отказ при ошибке) |
| `APOTHEM_SOURCE` | Явное локальное дерево исходного кода для использования вместо клонирования | не задано (клонировать) |
| `APOTHEM_HARNESS` | Среда для установки | `claude-code` |
| `APOTHEM_PROFILE` | Путь к YAML общего профиля | `$HOME/.config/apothem/profile.yaml` |
| `APOTHEM_SKIP_VERIFY` | Пропустить шаг проверки после установки, когда установлено в `1` | `0` (проверка выполняется) |
| `APOTHEM_AUTO_INSTALL_DEPS` | Автоматически устанавливает недостающие зависимости `click` / `rich` без запроса, если задано `1` | `0` (запрашивает или отклоняет в неинтерактивном конвейере) |
| `APOTHEM_BIN_DIR` | Каталог для размещённого shim-а команды `apothem` | `$HOME/.local/bin` (POSIX); `%LOCALAPPDATA%\Microsoft\WindowsApps` (Windows) |

`APOTHEM_SOURCE` имеет приоритет над клонированием: когда установлено в извлечённую
копию, содержащую `src/apothem`, установщик использует её напрямую, никогда не
обращается к `APOTHEM_REPO` / `APOTHEM_REF` и пропускает разрешение тега и проверку
подписи (нечего скачивать для проверки).

## Модель доверия

Если `APOTHEM_REF` не задана, установщик разрешает последний подписанный тег выпуска
и проверяет его подпись с помощью `git verify-tag` перед материализацией какой-либо
конфигурации; неподписанный или подделанный тег прерывает установку. Закрепите
известный выпуск с помощью `APOTHEM_REF=<tag>` (также проверяется; тег со
[страницы выпусков](https://github.com/ahmed-g-gad/apothem/releases)), выберите
движущуюся ветку с помощью `APOTHEM_REF=main` (без проверки) или установите
`APOTHEM_ALLOW_UNVERIFIED=1`, чтобы продолжить после провала проверки с
предупреждением (использование без сети, локально или до подписанного выпуска).

```bash title="Закреплённая, проверенная установка"
APOTHEM_REF=vMAJOR.MINOR.PATCH bash install.sh
```

```bash title="Продолжить без проверки (промежуточно / без сети)"
APOTHEM_ALLOW_UNVERIFIED=1 bash install.sh
```

## Шаги (POSIX bash)

1. Установите среду, отличную от значения по умолчанию:

   ```bash
   APOTHEM_HARNESS=cursor bash install.sh
   ```

2. Закрепите ссылку источника и назначение установки:

   ```bash
   APOTHEM_REF=main APOTHEM_HOME=/opt/apothem bash install.sh
   ```

3. Используйте локальную извлечённую копию и пользовательский профиль, пропуская
   проверку:

   ```bash
   APOTHEM_SOURCE=/work/apothem \
   APOTHEM_PROFILE=/work/profile.yaml \
   APOTHEM_SKIP_VERIFY=1 \
   bash install.sh
   ```

## Шаги (PowerShell)

Задайте каждую переменную в `$env:` перед запуском установщика:

```powershell
$env:APOTHEM_HARNESS = 'cursor'
pwsh -NoProfile -File install.ps1
```

```powershell
$env:APOTHEM_REF = 'main'
$env:APOTHEM_HOME = 'C:\opt\apothem'
pwsh -NoProfile -File install.ps1
```

```powershell
$env:APOTHEM_SOURCE = 'C:\work\apothem'
$env:APOTHEM_PROFILE = 'C:\work\profile.yaml'
$env:APOTHEM_SKIP_VERIFY = '1'
pwsh -NoProfile -File install.ps1
```

## Проверка

Установщик печатает `✓ Harness <name> installed`, затем (если не задано
`APOTHEM_SKIP_VERIFY=1`) `✓ verify passed`. Подтвердите независимо:

```bash
apothem verify --harness cursor
```

Если профиль ещё не существовал, установщик создаёт его из примера и завершает работу
досрочно — отредактируйте `$APOTHEM_PROFILE`, затем перезапустите.
