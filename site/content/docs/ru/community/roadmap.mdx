## Текущий выпуск

- Стабилизировать семнадцать адаптеров сред.
- Завершить инфраструктуру аудиторской проверки.
- Стабилизировать поверхность CLI Apothem.
- Установить конвейер CI/CD на GitHub Actions.

## Ближайшая перспектива

- Развить распространение через npm / npx: держать точку входа
  `@ahmed-g-gad/apothem` в соответствии с каждым выпуском и расширить её покрытие
  платформ.
- Расширять листинг плагина Claude Code по мере стабилизации поверхности маркетплейса.
- Автообновление адаптеров сред через `apothem update --watch`.
- Версионирование профиля и инструменты миграции.
- Проверка схемы общего профиля в шлюзе соответствия.
- Дополнительные адаптеры сред на основе запросов сообщества.

## Дальняя перспектива

- Облачная синхронизация профиля (опционально, под контролем оператора).
- Расширение VS Code для обратной связи о соответствии в реальном времени.
- Управление профилем, разделяемым командой.

## Запросы и обратная связь

Отправляйте запросы по дорожной карте через
[GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).
Дорожная карта формируется сообществом; популярные запросы продвигаются быстрее.
