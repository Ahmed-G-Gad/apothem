## Сначала удалите конфигурации окружений

Перед удалением Apothem удалите конфигурацию каждого адаптера окружения, чтобы оставить
ваши инструменты написания кода в чистом состоянии. Запустите `apothem harnesses list`, чтобы увидеть,
какие адаптеры установлены в данный момент, затем удаляйте их по одному или используйте
селектор по всему реестру:

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness cursor --project /path/to/project
apothem uninstall --harness all --project /path/to/project --yes
```

Передайте `--yes`, чтобы пропустить запрос подтверждения по каждому окружению.

## Удаление движка

Удаление соответствует тому каналу установки, который вы использовали:

- **Плагин Claude Code** — удалите плагин изнутри Claude Code:
  `/plugin uninstall apothem@apothem` (запись в маркетплейсе можно удалить
  с помощью `/plugin marketplace remove ahmed-g-gad/apothem`).
- **npx** — удалять нечего; `npx` запускается из своего кэша. Очистите его с помощью
  `npm cache clean --force`, если хотите избавиться от кэшированной копии.
- **Одноразовый инсталлятор** — запустите соответствующий скрипт удаления из
  извлечённого дерева: `scripts/installer/uninstall.sh` (POSIX) или
  `scripts/installer/uninstall.ps1` (PowerShell). Оба запрашивают подтверждение перед
  удалением и отказываются от небезопасных целей.
- **Резервные копии и состояние** — резервные копии установки находятся в `~/.apothem/backups/`;
  удалите `~/.apothem/`, как только они вам больше не понадобятся.

## Что НЕ удаляется

- Общий профиль YAML по адресу `~/.config/apothem/profile.yaml` или
  `--profile PATH` никогда не удаляется командой `apothem uninstall`.
- Несвязанные файлы, созданные оператором в каталогах окружений, сохраняются.
- Наборы планов в `<project>/.apothem/plans/` (и в устаревшем `<project>/.plans/`) не затрагиваются.

Чтобы полностью очистить корень окружения, удалите нативный путь окружения, описанный на
[справочных страницах окружений](/docs/harnesses), предварительно убедившись, что вы создали резервные копии
любых пользовательских правил, вспомогательных модулей или файлов профиля, которые хотите сохранить.
