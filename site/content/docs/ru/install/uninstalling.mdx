## Сначала удалите конфигурации окружений

Команда `apothem` без `npx`, которую использует эта страница, — это шим-файл, записываемый одношаговым установщиком (канал 3 [руководства по установке](/docs/install)); она работает, когда каталог этого шим-файла есть в `PATH`. В других каналах установки вместо `apothem` используйте `npx @ahmed-g-gad/apothem`, как описано в руководстве по установке.

Перед удалением Apothem удалите конфигурацию каждого адаптера окружения, чтобы
оставить ваши окружения в чистом состоянии. Запустите `apothem harnesses list`,
чтобы увидеть, какие адаптеры установлены в данный момент, затем удаляйте их по
одному или используйте селектор для всего реестра:

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness cursor --project /path/to/project
apothem uninstall --harness all --project /path/to/project --yes
```

Передайте `--yes`, чтобы пропустить запрос подтверждения для каждого окружения.

## Удаление движка

Способ удаления соответствует каналу установки, который вы использовали. Номера
каналов — это номера из
[таблицы каналов установки](/docs/install#выберите-канал):

- **Плагин Claude Code (канал 1)** — удалите плагин изнутри Claude Code: `/plugin uninstall apothem@apothem` (запись маркетплейса можно удалить командой `/plugin marketplace remove ahmed-g-gad/apothem`).
- **npx (канал 2)** — удалять нечего; `npx` запускается из своего кэша. Очистите его командой `npm cache clean --force`, если хотите убрать кэшированную копию.
- **Одношаговый установщик (канал 3)** — запустите соответствующий скрипт удаления из чекаута: `scripts/installer/uninstall.sh` (POSIX) или `scripts/installer/uninstall.ps1` (PowerShell). Каждый скрипт удаляет окружение, названное в `--harness` (`-Harness` в PowerShell), иначе `APOTHEM_HARNESS`, иначе Claude Code. Он также удаляет shim-команду `apothem`. Источник берётся из `APOTHEM_SOURCE`, если она задана, либо из `APOTHEM_HOME` (по умолчанию `$HOME/.apothem`). Источник остаётся, если не передан `--remove-source` (`-RemoveSource` в PowerShell). Этот флаг удаляет только управляемую копию в `APOTHEM_HOME` и только если в ней есть каталог `.git`. При расположении по умолчанию этот флаг также удаляет резервные копии установки и журнал в `~/.apothem/`. Оба скрипта запрашивают подтверждение перед удалением конфигураций окружений и источника. `--yes` (`-Yes` в PowerShell) пропускает запросы. Оба отказываются работать с небезопасными целями.
- **Расширение для семейства VS Code (канал 4)** — сначала выполните команду **Apothem: Uninstall** из палитры команд, чтобы удалить конфигурации окружений, затем удалите расширение в представлении «Расширения» или командой `code --uninstall-extension ahmed-g-gad.apothem`. По умолчанию расширение запускает движок через `npx`, поэтому пункт **npx** выше охватывает кэш.
- **Загрузчики командной строки (каналы 5–7)** — удалите расширение или плагин средствами его хост-инструмента после того, как конфигурации окружений удалены. Хосты:

  ```text
  channel 5   Gemini CLI extension
  channel 6   Qwen Code extension
  channel 7   Codex plugin
  ```

  Загрузчик лишь добавляет контекст ассистента (контекстный файл, команду или
  навык), который вызывает движок через `npx`, поэтому больше ничего не
  остаётся. Хосты расширений каналов 5 и 6 принимают команду удаления; для
  хоста плагинов канала 7 удалите `apothem` в его браузере плагинов.

  ```bash
  gemini extensions uninstall apothem   # channel 5
  qwen extensions uninstall apothem     # channel 6
  ```
- **Прямой движок (канал 8)** — удалять нечего; удалите клон после того, как
  конфигурации окружений удалены.
- **Резервные копии и состояние** — резервные копии установки находятся в
  `~/.apothem/backups/`, а журнал установок — в `~/.apothem/state/`. Объём
  обоих ограничен: после каждой установки, удаления и отката Apothem хранит
  10 самых новых записей об установке для каждого корня установки и 10 самых
  новых наборов резервных копий для каждого окружения и никогда не удаляет
  резервную копию, которая всё ещё нужна сохранённой записи, поэтому последние
  10 установок по-прежнему можно откатить. Чтобы хранить меньше, выполните
  [`apothem backups prune --keep N`](/docs/cli-reference/backups) (добавьте
  `--dry-run`, чтобы сначала увидеть, что будет удалено); команда никогда не
  удаляет резервную копию, из которой восстанавливает откат последней
  установки окружения. Когда движок удалён и вам больше не нужна никакая
  история, удалите `~/.apothem/`.

## Что НЕ удаляется

- Общий профиль YAML по адресу `~/.config/apothem/profile.yaml` или
  `--profile PATH` никогда не удаляется командой `apothem uninstall`.
- Несвязанные файлы, созданные оператором, в каталогах окружений сохраняются.
- Записи, которые вы добавили в общий файл настроек, сохраняются: ваши
  собственные правила разрешений, MCP-серверы и обработчики хуков остаются.
  Удаление убирает только те ключи и элементы списков, которые журнал
  установок фиксирует как принадлежащие Apothem (см.
  [Настройки](/docs/reference/settings#слияние-с-вашим-собственным-файлом-настроек)).
- Общие хранилища данных в `.apothem/` в корне установки (`memory/`,
  `contexts/`, `learning/`) сохраняются, пока их по-прежнему использует другое
  установленное окружение с тем же корнем. Удаление последнего окружения в этом
  корне сначала копирует каждое хранилище в `~/.apothem/backups/`, а затем
  удаляет его вместе со всем, что в нём находится.
- Наборы планов в `<project>/.apothem/plans/` (и в устаревшем `<project>/.plans/`) не затрагиваются.

## Каталоги

Удаление также убирает каталоги, созданные установкой (например,
`~/.claude/`, которого не было до первой установки), как только они
становятся пустыми. Каталог, в котором ещё остаётся ваш файл или данные,
используемые другим установленным окружением, сохраняется. Каталоги,
существовавшие до установки, никогда не удаляются.

Чтобы полностью очистить корень окружения, удалите нативный путь окружения,
описанный на [справочных страницах окружений](/docs/harnesses), предварительно
убедившись, что вы создали резервные копии всех пользовательских правил,
вспомогательных файлов или файлов профиля, которые хотите сохранить.
