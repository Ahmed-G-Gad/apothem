Краткий справочник по терминам, которые встретятся вам по всей документации Apothem.

## Общий профиль

Файл YAML, прошедший проверку по схеме, по адресу `~/.config/apothem/profile.yaml`
(переопределяется через `--profile PATH`). Это единственный источник истины для вашей
идентичности, предпочтений и конфигурации; каждый адаптер окружения читает его при
установке и выводит из него нативную конфигурацию этого окружения.

## Адаптер окружения

Адаптер для конкретной платформы, который преобразует общий профиль в нативный формат конфигурации для
конкретного окружения. Поддерживаемые среды выполнения перечислены в:

```text
Claude Code, Cursor, Gemini CLI, etc.
```

Установка Apothem всегда означает: установить общий профиль, а затем материализовать один или несколько
адаптеров.

## Поведенческое правило

Файл Markdown в каталоге src/apothem/rules/, который загружается при каждом взаимодействии (всегда активный) или
только при редактировании файлов по определённому пути (с фильтрацией по пути). Правила формализуют то, как должно
вести себя окружение.

## Хук

Скрипт на Python, зарегистрированный в settings.json, который срабатывает на событиях жизненного цикла окружения
(PreToolUse, PostToolUse, SessionStart, PreCompact, Stop, PostCompact). Хуки обеспечивают соблюдение требований
соответствия в реальном времени до того, как вывод попадёт на диск. Модель событий хуков сегодня является поверхностью Claude Code;
адаптеры для окружений без механизма хуков просто опускают его.

## Шлюз соответствия

Механическая часть пятнадцатипунктного шлюза предэмиссии (M1-M15) — отдельные валидаторы,
которые должны пройти проверку до того, как будет выпущен любой артефакт. Шлюз предэмиссии — это нижний порог качества;
шлюз соответствия запускает свои машинно-проверяемые пункты, а хуки обеспечивают соблюдение отдельных пунктов в реальном времени.

## Набор планов

Структурированный каталог по адресу &lt;project-root&gt;/.apothem/plans/&lt;suite-name&gt;/, содержащий спецификацию, мастер-план, по-фазовые
файлы PHASE.md и выходные артефакты. Конвейером /plan управляются наборы планов.

## Навык

Переиспользуемая, вызываемая слэш-командой техника, упакованная в виде файла SKILL.md в каталоге
src/apothem/skills/&lt;name&gt;/. Навыки расширяют поверхность слэш-команд за пределы встроенного
конвейера /plan.

## Делегированный исполнитель

Постоянный ассистент с заданным назначением, определённый по каноническому пути:

```text
src/apothem/agents/<name>.md
```

Делегированные исполнители выполняют исследование, аудит, проверку качества и управление памятью.
