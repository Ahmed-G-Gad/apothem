Qwen Code читает настройки, хуки, `QWEN.md`, нативные команды Markdown,
каталоги SKILL.md и субагентов Markdown. Apothem рендерит документированные
ключи настроек из общего профиля и преобразует общие когорты в нативную форму
файловой системы Qwen там, где Qwen Code её поддерживает.

## Сравнение усилий

| Задача | Ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Писать правила | Вручную сопровождать QWEN.md и вспомогательные файлы | Отрендерены или указаны из общего профиля |
| Настраивать хуки | Вручную править записи хуков в `settings.json` | Устанавливаются через нативную карту хуков Qwen Code |
| Писать команды, навыки, агентов | Сопровождать каждый каталог Qwen вручную | Преобразуются из общих когорт Apothem |
| Держать когорты согласованными с другими средами | Вручную, по каждому инструменту | Автоматически при `apothem update` |
| Установить / удалить поверхность | Вручную | `apothem install` / `apothem uninstall` |
| Проверить, что конфигурация верна | Ручная проверка | `apothem verify --harness qwen-code` |

## Чем управляет Apothem

Адаптер qwen-code пишет `settings.json`, устанавливает `QWEN.md`, преобразует
слеш-команды Apothem в файлы команд Markdown для Qwen, копирует навыки в
нативную поверхность навыков, адаптирует вспомогательные определения как
субагентов Qwen и регистрирует диспетчеры хуков Apothem. Правила, шаблоны и
исходный материал хуков остаются в вспомогательном поддереве Apothem и
указываются из нативного контекста.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если вы ещё этого не сделали.
2. Перенесите существующие правила, команды, навыки и агентов Qwen Code в общий корпус.
3. Выполните `apothem install --harness qwen-code`, чтобы отрендерить нативную поверхность.
4. Выполните `apothem verify --harness qwen-code`, чтобы убедиться, что конфигурация развернута.
5. Используйте `apothem update --harness qwen-code` для каждого последующего изменения.
