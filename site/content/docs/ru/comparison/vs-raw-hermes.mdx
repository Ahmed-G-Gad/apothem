Hermes читает `~/.hermes/config.yaml`. Apothem записывает нативную конфигурацию
YAML (проецируя перечень MCP из профиля в `mcp_servers`) и устанавливает общие
группы команд и навыков под `~/.hermes/.apothem/support/skills/`. Собственный
`skills.config` в Hermes — это список пакетов из реестра, поэтому Apothem его не
создаёт.

## Статус

**Предварительная версия.** Адаптер Hermes нацелен на текущий задокументированный
файл конфигурации и поверхность обнаружения навыков. Группы, не являющиеся
навыками, остаются вспомогательным материалом Apothem.

## Сравнение усилий

| Задача | Сырая ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Создавать переиспользуемые навыки | Вручную редактировать конфигурацию и каталоги навыков | Написать один раз в общем корпусе |
| Поддерживать согласованность групп с другими окружениями | Вручную, для каждого инструмента | Автоматически при `apothem update` |
| Установить / удалить конфигурацию | Вручную | `apothem install` / `apothem uninstall` |
| Проверить корректность конфигурации | Ручной осмотр | `apothem verify --harness hermes` |

## Чем управляет Apothem

Адаптер Hermes записывает `config.yaml`, оборачивает слеш-команды Apothem в
навыки, копирует навыки Apothem во вспомогательный каталог и хранит правила,
шаблоны, исполнителей и материал хуков в поддереве поддержки Apothem. Hermes
загружает эти навыки только после того, как вы добавите
`~/.hermes/.apothem/support/skills` в `skills.external_dirs` в `config.yaml`.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если вы ещё
   этого не сделали.
2. Перенесите переиспользуемые навыки или промпты команд Hermes в общий корпус.
3. Выполните `apothem install --harness hermes`, чтобы отрендерить нативную
   конфигурацию и вспомогательный каталог навыков.
4. Добавьте `~/.hermes/.apothem/support/skills` в `skills.external_dirs` в
   `config.yaml`, чтобы Hermes загружал установленные навыки. `apothem update`
   сохраняет ключи, которые вы добавляете в `config.yaml`.
5. Выполните `apothem verify --harness hermes`, чтобы подтвердить, что
   конфигурация на месте.
