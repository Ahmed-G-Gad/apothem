Windsurf читает правила из каталога `.devin/rules/`. Адаптер windsurf в
Apothem рендерит правила на основе каталога из общего профиля. На этой странице
ручное сопровождение этой конфигурации сравнивается с управлением ею через
apothem.

## Сравнение усилий

| Задача | Сырая ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Написать правила | Писать вручную каждый файл в `.windsurf/rules/` | Отрендерены из общего корпуса |
| Сохранять единый формат правил | Выбирать вручную между `.windsurf/rules/` и одним файлом `.windsurfrules` | Адаптер пишет только `.devin/rules/` |
| Согласовывать правила с другими средами | Вручную, для каждого инструмента | Автоматически при `apothem update` |
| Проверять, что конфигурация верна | Ручная проверка | `apothem verify --harness windsurf` |

## Чем управляет apothem

Адаптер windsurf рендерит общие правила в каталог `.devin/rules/`; он не пишет
один файл `.windsurfrules`. У Windsurf нет хука PreToolUse, поэтому намерение
ограждения живёт в тексте правил, а не в точке перехвата вызова инструмента.
Каждое изменение общих правил повторно рендерит каталог при следующем
`apothem update`.

## Путь миграции

1. Запустите `apothem profile init`, чтобы создать общий профиль, если вы ещё
   этого не сделали.
2. Перенесите правила из существующего `.windsurf/rules/` (и любого одиночного
   файла `.windsurfrules`) в общий корпус.
3. Запустите `apothem install --harness windsurf`, чтобы отрендерить каталог
   `.devin/rules/`.
4. Запустите `apothem verify --harness windsurf`, чтобы подтвердить, что
   конфигурация установлена.
5. Используйте `apothem update --harness windsurf` для каждого последующего
   изменения.
