Cursor читает правила в формате MDC под `.cursor/rules/`. Формат MDC требует
полей frontmatter — `description`, `globs` и `alwaysApply`. Адаптер cursor от
Apothem рендерит один файл правил `.mdc` из общего профиля. Эта страница
противопоставляет ручное сопровождение такой конфигурации управлению ею с
помощью Apothem.

## Сравнение усилий

| Задача | Ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Писать правила | Вручную писать каждый файл `.mdc` в `.cursor/rules/` | Отрендерено из общего корпуса |
| Писать frontmatter MDC | Вручную задавать `description` / `globs` / `alwaysApply` для каждого файла | Генерируется адаптером |
| Сохранять единый формат правил | Вручную выбирать между правилами MDC и одним файлом `.cursorrules` | Адаптер пишет один файл MDC, `.cursor/rules/apothem-rules.mdc`, и не пишет `.cursorrules` |
| Поддерживать правила согласованными с другими окружениями | Вручную, для каждого инструмента | Автоматически при `apothem update` |
| Делиться переиспользуемыми навыками и командами | Вручную копировать каждую папку навыка в `~/.agents/skills/` и поддерживать копии актуальными | Записываются адаптером в `~/.agents/skills/`, одна копия для всех проектов, и обновляются при `apothem update` |
| Проверить, что конфигурация верна | Ручная инспекция | `apothem verify --harness cursor --project <path>` |

## Чем управляет Apothem

Адаптер cursor рендерит общие правила в один файл `.mdc`,
`<project>/.cursor/rules/apothem-rules.mdc`, генерируя требуемый frontmatter MDC
(`description`, `globs`, `alwaysApply`). Адаптер пишет только основанный на
каталогах формат MDC, который читает Cursor; он не пишет единый файл
`.cursorrules`. Он также записывает навыки и команды, обёрнутые как навыки, в
`~/.agents/skills/`, а правила и шаблоны, на которые ссылаются эти навыки, — в
`~/.config/apothem/`, оба в вашем домашнем каталоге.
Cursor документирует хуки в файлах `hooks.json` и через свой формат плагинов.
Адаптер не собирает плагин; он добавляет одну запись `sessionStart` в
`.cursor/hooks.json` проекта, которая запускает начальную загрузку сессии, и
оставляет ваши собственные записи как есть. Он не регистрирует защиту вызовов
инструментов, поэтому замысел ограждающих перил живёт в прозе правил.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если вы этого ещё не сделали.
2. Перенесите правила из существующих `.cursor/rules/` (и любого `.cursorrules`) в общий корпус.
3. Выполните `apothem install --harness cursor --project <path>`, чтобы отрендерить `apothem-rules.mdc` с корректным frontmatter MDC.
4. Выполните `apothem verify --harness cursor --project <path>`, чтобы подтвердить, что конфигурация установлена.
5. Для каждого последующего изменения используйте `apothem update --harness cursor --project <path>`.
