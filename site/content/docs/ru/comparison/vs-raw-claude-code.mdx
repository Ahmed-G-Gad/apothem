Claude Code (производитель Anthropic) хранит свою нативную конфигурацию под
`~/.claude/`. Адаптер claude-code в Apothem — это адаптер полной поверхности: он
распространяет общий корпус прямо в это дерево. Эта страница противопоставляет
ручное сопровождение конфигурации управлению ею с помощью Apothem.

## Сравнение усилий

| Задача | Ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Написать правила, агенты, команды, скиллы | Править каждую поверхность в `~/.claude/` вручную | Написать один раз в общем корпусе |
| Сопровождать output-styles и statuslines | Править вручную по каждой поверхности | Распространяются из общего корпуса |
| Настроить хуки | Править записи хуков в `settings.json` вручную | Распространяются (PreToolUse/PostToolUse/Stop/SessionStart) |
| Поддерживать конфигурацию согласованной с другими средами | Вручную, по каждому инструменту | Автоматически при `apothem update` |
| Проверить корректность конфигурации | Ручная проверка | `apothem verify --harness claude-code` |

## Чем управляет Apothem

Адаптер распространяет правила, агенты, команды, скиллы, output-styles,
statuslines и `settings.json` в `~/.claude/`. Нативные хуки PreToolUse,
PostToolUse, Stop и SessionStart настраиваются из общего корпуса.

Apothem **не** управляет `CLAUDE.md` — этот файл является территорией оператора.
Ваши проектные и личные инструкции в `CLAUDE.md` остаются вашими; Apothem
управляет распространёнными поверхностями вокруг него.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если у вас его
   ещё нет.
2. Перенесите ваши существующие правила, агенты, команды и скиллы из
   `~/.claude/` в общий корпус.
3. Оставьте `CLAUDE.md` на месте — Apothem его не тронет.
4. Выполните `apothem install --harness claude-code`, чтобы распространить
   корпус.
5. Выполните `apothem verify --harness claude-code`, чтобы подтвердить, что
   конфигурация установлена.
6. Используйте `apothem update --harness claude-code` для каждого последующего
   изменения.
