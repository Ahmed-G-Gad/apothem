Antigravity — это среда распространения манифеста Класса I: Apothem записывает
глобальный якорь контекста `~/.gemini/GEMINI.md` и устанавливает плагин Apothem
под `~/.gemini/antigravity-cli/plugins/apothem/`. Эта страница противопоставляет
ручное сопровождение этой раскладки управлению ею с помощью Apothem.

## Сравнение усилий

| Задача | Ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Написать правила | Вручную писать каждый файл правил плагина | Написать один раз в общем корпусе |
| Сохранить переиспользуемые промпты | Вручную копировать промпты команд и скиллы в файлы плагина | Преобразуются или копируются как скиллы плагина |
| Сохранить вспомогательные материалы хуков | Вручную копировать ссылки на хуки без активной привязки | Копируются под вспомогательное дерево плагина Apothem |
| Поддерживать правила согласованными с другими средами | Вручную, по каждому инструменту | Автоматически при `apothem update` |
| Установить / удалить конфигурацию | Вручную копировать и удалять файлы | `apothem install` / `apothem uninstall` |
| Проверить корректность конфигурации | Ручная проверка | `apothem verify --harness antigravity` |

## Чем управляет Apothem

Apothem управляет файлом глобального контекста Antigravity, метаданными плагина,
преобразованными скиллами команд, переиспользуемыми скиллами, преобразованными
агентами, правилами, шаблонами и вспомогательными материалами хуков. Файлы хуков
сохраняются как вспомогательный материал; Apothem не регистрирует активные
события хуков Antigravity, пока адаптер не получит слой перевода схемы для
`hooks.json` Antigravity.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если у вас его
   ещё нет.
2. Перенесите ваши написанные вручную правила Antigravity в общий корпус.
3. Выполните `apothem install --harness antigravity`, чтобы распространить
   корпус.
4. Выполните `apothem verify --harness antigravity`, чтобы подтвердить, что
   конфигурация установлена.
5. Используйте `apothem update --harness antigravity` для каждого последующего
   изменения.
