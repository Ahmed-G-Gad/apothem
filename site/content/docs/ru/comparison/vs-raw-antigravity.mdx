Antigravity — это окружение класса I с распространением манифеста: Apothem записывает глобальный якорь контекста `~/.gemini/GEMINI.md` и устанавливает плагин Apothem в `~/.gemini/antigravity-cli/plugins/apothem/`. На этой странице сравнивается ручное сопровождение такой структуры с управлением ею через Apothem.

## Статус

**Предварительная версия.** Адаптер Antigravity ориентирован на текущий задокументированный якорь контекста `GEMINI.md` и поверхность плагина Antigravity CLI. Группы, для которых нет нативной поверхности, остаются вспомогательными материалами Apothem.

## Сравнение усилий

| Задача | Ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Написать правила | Вручную написать каждый файл правил плагина | Написать один раз в общем корпусе |
| Сохранить переиспользуемые промпты | Вручную скопировать промпты команд и навыки в файлы плагина | Преобразуются или копируются в навыки плагина |
| Сохранить вспомогательные материалы хуков | Вручную скопировать ссылки на хуки без активного подключения | Копируются в поддерево поддержки плагина Apothem |
| Поддерживать правила согласованными с другими окружениями | Вручную, для каждого инструмента | Автоматически при `apothem update` |
| Установить и удалить конфигурацию | Копировать и удалять файлы вручную | `apothem install` / `apothem uninstall` |
| Проверить корректность конфигурации | Ручная проверка | `apothem verify --harness antigravity` |

## Чем управляет Apothem

Apothem управляет глобальным файлом контекста Antigravity, метаданными плагина, преобразованными командами-навыками, переиспользуемыми навыками, преобразованными агентами, правилами, шаблонами и вспомогательными материалами хуков. Файлы хуков сохраняются как вспомогательные материалы; Apothem не регистрирует активные события хуков Antigravity, пока адаптер не получит слой трансляции схемы для `hooks.json` Antigravity.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если вы ещё этого не сделали.
2. Перенесите ваши написанные вручную правила Antigravity в общий корпус.
3. Выполните `apothem install --harness antigravity`, чтобы распространить корпус.
4. Выполните `apothem verify --harness antigravity`, чтобы подтвердить, что конфигурация установлена.
5. Используйте `apothem update --harness antigravity` для каждого последующего изменения.
