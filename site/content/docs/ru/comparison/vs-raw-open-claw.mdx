Open-Claw читает `~/.openclaw/openclaw.json`. Apothem устанавливает общие группы
команд и skills под `~/.openclaw/.apothem/support/skills/` и пишет там один ключ,
`skills.load.extraDirs`, который указывает этот каталог, чтобы OpenClaw загружал
эти skills. Его `agents.defaults.skills` — это список разрешённых имён, которым
владеете вы, а MCP — это поверхность CLI, поэтому Apothem не пишет ни то, ни
другое.

## Статус

**Предпросмотр.** Адаптер Open-Claw нацелен на текущий задокументированный файл
конфигурации и дополнительную поверхность каталога skills. Группы, не связанные
со skills, остаются вспомогательным материалом Apothem.

## Сравнение усилий

| Задача | Сырая ручная конфигурация | Под управлением Apothem |
| ---- | --------------- | --------------- |
| Писать переиспользуемые skills | Редактировать вручную конфиг и каталоги skills | Написать один раз в общем корпусе |
| Держать группы согласованными с другими окружениями | Вручную, для каждого инструмента | Автоматически при `apothem update` |
| Установить / удалить конфиг | Вручную | `apothem install` / `apothem uninstall` |
| Проверить корректность конфига | Ручная инспекция | `apothem verify --harness open-claw` |

## Чем управляет Apothem

Адаптер Open-Claw пишет `openclaw.json`, оборачивает слеш-команды Apothem в
skills, копирует skills Apothem в указанный вспомогательный каталог и хранит
правила, шаблоны, agents и материал хуков под вспомогательным поддеревом Apothem.
OpenClaw читает `skills.load.extraDirs` с наименьшим приоритетом среди своих
источников skills, поэтому skill с тем же именем в вашем рабочем пространстве,
`~/.agents/skills` или `~/.openclaw/skills` используется вместо копии Apothem.

## Путь миграции

1. Выполните `apothem profile init`, чтобы создать общий профиль, если вы ещё
   этого не сделали.
2. Перенесите переиспользуемые skills или промпты команд Open-Claw в общий корпус.
3. Выполните `apothem install --harness open-claw`, чтобы отрендерить нативную
   конфигурацию и вспомогательный каталог skills.
4. Выполните `apothem verify --harness open-claw`, чтобы подтвердить, что
   конфигурация установлена.
