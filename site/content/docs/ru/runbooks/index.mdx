Операционные процедуры для сопровождающих. Каждое руководство по эксплуатации —
это последовательная, не зависящая от контекста процедура: она переводит
известное начальное состояние в проверенное конечное состояние и написана так,
чтобы компетентный участник мог следовать ей без предварительного контекста.

## Страницы

| Страница | Описание |
|------|-------------|
| [Включение Pages](/docs/runbooks/pages-enablement) | Доведите `apothem.ahmedgad.com` от свежей конфигурации GitHub Pages до целевой HTTPS-страницы с `200 OK`. |
| [Цикл релиза](/docs/runbooks/release-cycle) | Доведите релиз `vX.Y.Z` от чистого рабочего дерева до проверенных поверхностей GitHub Release и npm. |
| [Настройка учётной записи издателя](/docs/runbooks/publisher-account-setup) | Настройте доверенного издателя npmjs.com для `@ahmed-g-gad/apothem` и предварительные требования к релизу на стороне GitHub. |
| [Восстановление релиза](/docs/runbooks/release-recovery) | Восстановите `ahmed-g-gad/apothem` до рабочего состояния, когда последовательность переключения релиза даёт сбой на полпути. |
| [Создание нового адаптера окружения](/docs/runbooks/new-harness-adapter-authoring) | Создайте и опубликуйте новый адаптер окружения для включения в основной состав проекта. |
| [Контрольный список развёртывания](/docs/runbooks/deployment-checklist) | Пройдите контрольный список предварительной проверки перед развёртыванием экосистемы Apothem или предоставлением доступа к ней. |
| [Церемония слияния для единственного сопровождающего](/docs/runbooks/solo-maintainer-merge) | Когда сопровождающий может напрямую слить собственный pull request, и церемония самослияния для защиты, которая требует одобрения и применяет это требование к администраторам. |
| [Контрольный список межмашинной синхронизации](/docs/runbooks/cross-machine-sync-checklist) | Убедитесь, что адаптер Claude Code корректно устанавливается, проходит валидацию и удаляется на свежем хосте, с полными проверками переносимости. |
