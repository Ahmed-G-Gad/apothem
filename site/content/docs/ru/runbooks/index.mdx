Операционные процедуры для сопровождающих. Каждое руководство по эксплуатации —
это последовательная, не зависящая от контекста процедура: она ведёт известное
начальное состояние к проверенному конечному, написанная так, чтобы
компетентный участник мог следовать ей без предварительного контекста.

## Страницы

| Страница | Описание |
|------|-------------|
| [Включение Pages](/docs/runbooks/pages-enablement) | Доведите `apothem.ahmedgad.com` от свежей конфигурации GitHub Pages до целевой HTTPS-страницы с `200 OK`. |
| [Цикл выпуска](/docs/runbooks/release-cycle) | Доведите выпуск `vX.Y.Z` от чистого рабочего дерева до проверенных поверхностей GitHub Release и npm. |
| [Настройка учётной записи публикатора](/docs/runbooks/publisher-account-setup) | Настройте доверенного публикатора npmjs.com для `@ahmed-g-gad/apothem` и предварительные условия выпуска на стороне GitHub. |
| [Восстановление выпуска](/docs/runbooks/release-recovery) | Восстановите `ahmed-g-gad/apothem` до рабочего состояния, когда последовательность переключения выпуска даёт сбой на полпути. |
| [Создание нового адаптера среды](/docs/runbooks/new-harness-adapter-authoring) | Создайте и опубликуйте новый адаптер среды для включения в качестве первой стороны. |
