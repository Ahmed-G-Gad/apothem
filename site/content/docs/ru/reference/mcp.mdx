Серверы Model Context Protocol (MCP) **принадлежат оператору**. Apothem хранит
инвентарь MCP в общем профиле (`mcp_servers`). Адаптер, инструмент которого
хранит свои серверы MCP в файле конфигурации, уже записываемом Apothem,
проецирует этот инвентарь в этот файл; все остальные адаптеры не создают
записей серверов, и регистрировать серверы через инструмент по-прежнему вам.

## Где регистрируются серверы MCP

Каждый инструмент регистрирует серверы MCP через собственный нативный механизм,
и Apothem соблюдает эту поверхность, а не перезаписывает её. В Claude Code
серверы регистрируются командой `claude mcp add` в `~/.claude.json`
(пользовательская или локальная область) и в `.mcp.json` на уровне проекта;
адаптер Claude Code не записывает ни один из этих файлов, а управляемые Apothem
настройки Claude Code никогда не содержат блок `mcpServers`.

## Добавление сервера

Зарегистрируйте сервер через нативный механизм вашего инструмента; каноническая
форма записи — один ключ под `mcpServers`:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

Среда выполнения инструмента загружает зарегистрированные серверы при запуске
сессии; перезапустите инструмент, чтобы он подхватил новые серверы.

## Соглашение об именовании

Инструменты MCP становятся доступны ассистенту как `mcp__<server>__<tool>`
согласно стандартному соглашению об именовании MCP-инструментов этого
инструмента.
