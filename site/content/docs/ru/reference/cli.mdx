CLI `apothem` — это основной интерфейс оператора для управления общим профилем и
адаптерами окружений.

## Глобальные флаги

| Флаг | Описание |
|------|-------------|
| `--version` | Выводит версию Apothem и завершает работу |
| `--help` | Выводит справку по команде |

## Подкоманды

### `apothem install`

Устанавливает адаптер окружения из общего профиля.

```bash
apothem install --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| Параметр | Описание |
|--------|-------------|
| `--harness <name>` | Имя адаптера окружения (см. канонические значения ниже). Обязательный. |
| `--profile PATH` | Путь к YAML общего профиля. По умолчанию `~/.config/apothem/profile.yaml`. |
| `--project PATH` | Корень проекта для окружений с областью видимости проекта. |
| `--dry-run` | Предпросмотр установки без записи файлов. |

Канонические значения `--harness`:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
hermes
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

Используйте `--harness all --project <path>`, чтобы выбрать весь набор реестра.
Список `exclude_harnesses` из профиля учитывается при пакетном выборе во время
установки/обновления.

### `apothem update`

Заново выводит нативную конфигурацию адаптера окружения из текущего общего
профиля.

```bash
apothem update --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| Параметр | Описание |
|--------|-------------|
| `--harness <name>` | Имя адаптера окружения. Обязательный. |
| `--profile PATH` | Путь к YAML общего профиля. |
| `--project PATH` | Корень проекта для окружений с областью видимости проекта. |
| `--dry-run` | Предпросмотр обновления без записи файлов. |

`update` заново материализует вывод окружения. Он не обновляет пакет CLI Apothem;
для обновления пакета используйте менеджер пакетов, которым устанавливался
Apothem.

### `apothem uninstall`

Удаляет нативную конфигурацию адаптера окружения.

```bash
apothem uninstall --harness <name|all> [--project PATH] [--yes]
```

| Параметр | Описание |
|--------|-------------|
| `--harness <name>` | Имя адаптера окружения. Обязательный. |
| `--project PATH` | Корень проекта для окружений с областью видимости проекта. |
| `--yes` | Пропускает запрос подтверждения. |

### `apothem verify`

Проверяет, что адаптер окружения установлен и его путь вывода существует.

```bash
apothem verify --harness <name|all> [--project PATH]
```

| Параметр | Описание |
|--------|-------------|
| `--harness <name>` | Имя адаптера окружения или `all`. Обязательный. |
| `--project PATH` | Корень проекта для окружений с областью видимости проекта. |

Код выхода равен `0`, когда адаптер установлен, и `1`, когда нет.

### `apothem profile`

Управляет общим профилем Apothem.

```bash
apothem profile show [--profile PATH]
apothem profile init [--profile PATH] [--force]
apothem profile set <key> <value> [--profile PATH]
apothem profile edit [--profile PATH]
```

| Подкоманда | Описание |
|------------|-------------|
| `profile init` | Создаёт минимальный каркас профиля, валидный по схеме. |
| `profile show` | Выводит разрешённый профиль (YAML) в stdout. |
| `profile set <key> <value>` | Задаёт поле профиля. Значение разбирается как YAML (строки, числа, булевы значения, списки и отображения — всё принимается). |
| `profile edit` | Открывает профиль в `$EDITOR` (с откатом к редактору по умолчанию для платформы). |

Параметр `--profile PATH` направляет каждую подкоманду на альтернативный файл
профиля. По умолчанию `~/.config/apothem/profile.yaml`.

### `apothem harnesses`

Перечисляет и проверяет зарегистрированные адаптеры окружений.

```bash
apothem harnesses list
apothem harnesses show <name>
```

| Подкоманда | Описание |
|------------|-------------|
| `harnesses list` | Выводит таблицу каждого зарегистрированного адаптера с его флагом статуса установки и путём вывода. |
| `harnesses show <name>` | Выводит имя, состояние установки и путь вывода одного адаптера. |

### `apothem doctor`

Запускает системную диагностику установки Apothem.

```bash
apothem doctor
```

Выводит версию Apothem, интерпретатор Python, платформу, разрешённый путь
профиля и таблицу статуса установки по каждому окружению. Код выхода равен `0`,
когда каждый зарегистрированный адаптер сообщает об установке; иначе `1`.
