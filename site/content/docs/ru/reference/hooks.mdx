Хуки срабатывают на событиях инструментов и загружают контексты сообщений, которые
ассистент трактует как дополнительные системные подсказки. Подключение находится в
блоке хуков `settings.json` Claude Code, файле хуков `hooks.json` Codex
и карте хуков `settings.json` Qwen Code.

| Событие | Тайм-аут | Назначение |
|-------|--------:|---------|
| SessionStart | 30 секунд | Чтение памяти, проверка состояния плана, отчёт о готовности |
| PreCompact | 30 секунд | Проверить, что состояние внешне сохранено перед компактификацией |
| PostCompact | 30 секунд | Восстановить рабочее состояние после компактификации |
| Stop | 60 секунд | Внешнее сохранение состояния в конце сессии |
| PreToolUse (Bash) | 10 секунд | Валидация Bash — изоляция артефактов git |
| PreToolUse (Write/Edit/NotebookEdit/apply_patch) | 10 секунд | Изоляция ссылок на планы, проверки frontmatter |

## Диспетчер

Установленные записи хуков вызывают диспетчер по абсолютному пути скрипта.
Шаблоны настроек содержат токен `${HARNESS_ROOT}` —
`python "${HARNESS_ROOT}/apothem/hooks/dispatch.py" <event> [<message-name>]`
— который установщик во время установки преобразует в реальный путь корня harness
(Claude Code и Qwen Code материализуют диспетчер в
`<harness-root>/apothem/hooks/`; Codex — в `<harness-root>/hooks/`).
Диспетчер — это автономный скрипт стандартной библиотеки: он инициализирует собственный `sys.path`,
поэтому на хосте не требуется импортируемый пакет `apothem`. Из исходного
checkout форма модуля `python -m apothem.hooks.dispatch <event>` (с
`PYTHONPATH=src`) выполняет тот же код для разработки. Диспетчер загружает
`hooks/lib/resolve_root.py` для разрешения корня экосистемы и делегирует
`hooks/emit_hook_context.py` и `hooks/session_start_bootstrap.py`.

## Контексты сообщений

Контексты Markdown по событиям находятся в `src/apothem/hooks/messages/`:

- `postcompact.md`, `precompact.md`, `stop.md`
- `pretooluse-bash.md`, `pretooluse-write.md`, `pretooluse-edit.md`,
  `pretooluse-notebookedit.md`

Каждый файл контекста загружается диспетчером, когда его событие срабатывает
и его аргумент контекста зарегистрирован в файле настроек.
