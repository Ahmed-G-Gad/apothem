`CLAUDE.md` — это всегда загружаемая конфигурация проекта. Окружение-хост загружает её при каждом взаимодействии, поэтому её содержимое является *базовым контекстом*, который расширяет каждый другой артефакт. Она остаётся согласованной с `AGENTS.md` (канонической поверхностью инструкций для агентов) и `.github/copilot-instructions.md`, которые отражают те же дисциплины.

## Что в нём содержится

Проектный `CLAUDE.md` написан в виде разделов прозы: канон AI-поверхностей, рабочий цикл plan → harden → ship, назначение проекта и структура исходного кода, дисциплины планов, релизов и заголовков файлов, обработка неоднозначности, а также соглашения о написании кода и адаптерах окружений. Он описывает *что представляет собой проект* и *как в нём работать*; он не повторяет мандаты управления, которые находятся в группе правил и передаются среде выполнения в виде файлов правил.

| Поверхность управления | Где находится |
|---|---|
| Сквозные мандаты (CM-N) | `src/apothem/rules/operational-mandates.md` и файлы правил по каждому мандату |
| Пятнадцать производственных мандатов (M-N) | файлы правил по каждому мандату (`definitiveness.md`, `pre-emission-gate.md`, `production-ready-prs.md`, …) |
| Когнитивная идентичность и архитектурная позиция | `src/apothem/rules/cognitive-identity.md` |
| Управление с масштабированием по серьёзности | раздел *Seriousness Scaling* каждого правила |
| Конвейер `/plan` | команды `/plan-*` и `src/apothem/skills/plan-suite/` |
| Каталоги артефактов | структура исходного кода — `rules/`, `commands/`, `skills/`, `agents/`, `hooks/` |

## Соглашения об идентификаторах мандатов

У трёх префиксов разные значения:

- **CM-N** — конфигурационный мандат, определённый в группе правил
  (`src/apothem/rules/operational-mandates.md` и файлы правил по каждому мандату).
- **TM-N** — шаблонный мандат, определённый в
  `src/apothem/skills/plan-suite/master-template.md` §4.
- **CP-N** — основной принцип, определённый в том же шаблоне §6.

Шаблон набора планов — это канонический реестр TM/CP; этапы конвейера `/plan` разрешают перекрёстные ссылки через этот файл.
