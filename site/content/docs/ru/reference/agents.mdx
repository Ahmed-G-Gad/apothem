Постоянные помощники хранятся как плоские файлы в каноническом каталоге
помощников с суффиксом `<name>.md`. Канонический путь:

```text
src/apothem/agents/
```

Каждый помощник — это узкоспециализированная роль, например исследование,
аудит, качество, рефакторинг или создание каркасов, со своими ограничениями
инструментов и собственным системным промптом.

Таблица и список путей ниже показывают четырёх из помощников. Сгенерированный
инвентарь в конце этой страницы перечисляет определения всех помощников.

| Помощник | Файл | Паттерн | Политика модели |
|-------|------|---------|--------------|
| Codebase Explorer | см. путь к манифесту ниже | Исследование | выбирается хостом |

## Контракт фронтматтера

```yaml
---
name: <agent name>
version: <semver>
updated: <YYYY-MM-DD>
description: <one-line role>
tools: <comma-separated tool list>
disallowedTools: <comma-separated deny list>
maxTurns: <integer>
---
```

`tools` необязателен. Помощник, который его опускает, наследует все инструменты
сессии, включая подключённые инструменты MCP, а его ограничение несёт
`disallowedTools`. Все четырнадцать поставляемых помощников перечисляют `tools`.

## Подключённые серверы MCP

Помощник, который перечисляет `tools`, может вызывать только перечисленное.
Claude Code допускает инструмент MCP в этот список, только когда запись называет
сервер, как в `mcp__<server>__*`; голый `mcp__*` документирован как запись
`disallowedTools` и больше нигде. Имена серверов принадлежат тому, кто их
подключает, поэтому поставляемый помощник не может их назвать.

`citation-auditor` и `research-scout` ищут научные источники. Каждый
поставляется с `tools: Read, Glob, Grep, WebSearch, WebFetch` и запрещает
инструменты, которые записывают файлы, выполняют команды, запускают других
помощников или публикуют: `Write`, `Edit`, `MultiEdit`, `NotebookEdit`, `Bash`,
`PowerShell`, `Monitor`, `Agent`, `Artifact` и инструменты списка задач. Без
настройки профиля ни один из них не достигает инструмента MCP, и оба ищут
источники через веб-поиск и веб-загрузку.

Чтобы дать одному из них подключённый научный индекс, назовите сервер в ключе
профиля `agent_mcp_servers`, который сопоставляет имя агента с именами серверов.
Тогда установка Claude Code через движок (`apothem install`) добавляет по одной
записи `mcp__<server>__*` на каждый названный сервер в строку `tools` этого
агента и не меняет никакого другого агента. Установка Gemini CLI делает то же
самое с одной записью `mcp_<server>_*` на сервер в списке разрешений `tools`
агента, для имени сервера из букв, цифр и `-`. В обоих случаях сервер, который
называет собственный `disallowedTools` агента, остаётся запрещённым. Запись допускает каждый инструмент этого сервера, включая
любой записывающий, поэтому называйте только сервер, которому доверяете поиск:
инструкции помощников ограничивают их вызовами поиска, просмотра, чтения,
проверки и разрешения, но окружение обеспечивает только те имена, которые
перечисляет строка `tools`. Имя для агента, которого не существует или у
которого нет явной строки `tools`, сообщается и пропускается.

Окружения, отличные от Claude Code и Gemini CLI, игнорируют ключ. Дерево плагина Claude Code собирается без
профиля и сохраняет простой список, поэтому пользователь плагина вместо этого
определяет агента уровня пользователя в `~/.claude/agents/`. Синтаксис профиля,
правила имён серверов и этот обходной путь описаны на странице
[Предоставление помощнику доступа к серверам MCP](/docs/reference/mcp#предоставление-помощнику-доступа-к-серверам-mcp).

## Преобразование по окружениям

Помощник, чей набор `tools` после вычета `disallowedTools` не включает ни одного
инструмента редактирования файлов (`Write`, `Edit`, `MultiEdit` или
`NotebookEdit`), работает только для чтения. Помощник без набора `tools`
работает только для чтения, когда `disallowedTools` запрещает как минимум
`Write` и `Edit`. Каждое окружение, которое преобразует помощников, обеспечивает
это ограничение нативно, указывает его в инструкциях помощника или убирает
пометку «только для чтения»:

| Окружение | Ограничение инструментов | Ограничение ходов | Модель и уровень усилий |
| --- | --- | --- | --- |
| Claude Code | `tools` / `disallowedTools` как написано, плюс любые записи `mcp__<server>__*`, которые ключ профиля `agent_mcp_servers` добавляет в перечисленную строку `tools`; без `tools` наследуются все инструменты, включая MCP | `maxTurns` | наследуется (не задаётся) |
| Codex | ничего не выводится; ограничение указано в инструкциях помощника, а запись регулирует песочница родительской сессии | недоступно | наследуется (не задаётся) |
| Gemini CLI | список разрешений `tools` из имён инструментов Gemini, плюс любые записи `mcp_<server>_*`, которые ключ профиля `agent_mcp_servers` добавляет в перечисленный явный список; без `tools` — список разрешений, вытекающий из запретов, плюс `mcp_*` | `max_turns` | наследуется (не задаётся) |
| Qwen Code | `tools` / `disallowedTools` в именах инструментов Qwen; без `tools` список не выводится, поэтому инструменты MCP наследуются, а запреты применяются | не сопоставляется | `model: inherit` |
| OpenCode | `permission` (`allow` / `deny` для каждого инструмента); инструменты MCP не ограничиваются | не сопоставляется | наследуется (не задаётся) |
| Antigravity | ничего не выводится; из описания удаляется «read-only» | недоступно | наследуется (не задаётся) |
| CodeBuddy | `tools` / `disallowedTools` как строки через запятую, ограниченные именами инструментов, которые документирует CodeBuddy; без записи MCP | `maxTurns` | наследуется (не задаётся) |
| Trae | `tools` / `disallowedTools` как строки через запятую, ограниченные именами инструментов, которые документирует Trae; без записи MCP | недоступно | наследуется (не задаётся) |
| GitHub Copilot | список разрешений `tools` из псевдонимов Copilot (`read`, `search`, `edit`, `execute`, `web`, `agent`, `todo`) с учтёнными в нём запретами, потому что у Copilot нет ключа запрета; псевдоним, покрывающий запрещённый инструмент, не включается; без записи MCP | недоступно | наследуется (не задаётся) |
| Cursor | без списка инструментов (у Cursor его нет); `readonly: true` для пяти помощников только для чтения без `Bash`, а остальные помощники только для чтения теряют пометку «read-only» | недоступно | наследуется (не задаётся) |
| Kimi Code | `tools` / `disallowedTools` как списки имён инструментов Kimi Code (`WebFetch` становится `FetchURL`, `TodoWrite` становится `TodoList`; имена, для которых у Kimi Code нет инструмента, не включаются); без записи MCP | недоступно | наследуется (не задаётся) |
| Kiro | список разрешений `tools` из категорий инструментов Kiro (`read`, `write`, `shell`, `web`, `subagent`) с учтёнными в нём запретами, потому что этот список — единственное записываемое ограничение; категория, покрывающая запрещённый инструмент, не включается; без записи MCP | недоступно | наследуется (не задаётся) |
| Windsurf | список разрешений `allowed-tools` из имён инструментов Devin (`read`, `edit`, `grep`, `glob`, `exec`, `write`) с учтёнными в нём запретами, потому что у Devin нет ключа запрета; три помощника, которым нужны веб-инструменты, не устанавливаются; без записи MCP | недоступно | модель субагента Devin по умолчанию (не задаётся) |

Hermes и Open-Claw получают файлы помощников как вспомогательный материал, а не
как нативных помощников.

## Оркестрация

Развёртывание помощников, протокол параллельного запуска, обеспечение
соблюдения контракта возврата и дисциплина изоляции описаны в правиле
оркестрации. Дерево диспетчеризации для каждого исполнителя описано в правиле
паттернов оркестрации, §Decision Tree. Канонические пути:

```text
src/apothem/rules/agent-orchestration.md
src/apothem/rules/agent-orchestration-patterns.md
```
