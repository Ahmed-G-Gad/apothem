Реестр окружений — это инвентарь адаптеров, выступающий источником истины, который
используют CLI, документация, фикстурные тесты и проверка якорей соглашений. Источник
во время выполнения — `src/apothem/lib/harness_registry.py`; каждая строка ниже прослеживается
до этого реестра, до файла `capabilities.yml` каждого адаптера и до файла
`STANDARD-CONVENTION-PIN.md` каждого адаптера.

## Хуки валидации

Реестр поддерживается в синхронизированном состоянии этими проверками:

| Проверка | Назначение |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | Подтверждает, что у каждого адаптера есть актуальный якорь соглашения и что реестр по-прежнему перечисляет семнадцать адаптеров. |
| `python -m apothem.conformity.gate --all .` | Запускает проверки соответствия документации и реализации. |
| `python -m pytest` | Прогоняет фикстурные тесты реестра и контрактные тесты адаптеров. |
