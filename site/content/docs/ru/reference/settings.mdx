`settings.json` несёт конфигурацию harness Claude Code: подключение хуков,
разрешения инструментов, переменные окружения и настройки строки состояния.

Полный канонический справочник живёт в
[settings-reference.md](/docs/reference/settings-reference). Эта страница резюмирует контракт
и указывает на более глубокий справочник.

## Разделы

| Раздел | Назначение |
|---------|---------|
| `permissions` | Белые и чёрные списки инструментов для каждого matcher |
| `hooks` | Таблица команд хуков, ключуемая по событию (каноническое подключение) |
| `env` | Переменные окружения для каждой сессии |
| `statusLine` | Шаблон строки состояния, который рендерит хост |

## Инвариант единого шаблона

Адаптер Claude Code поставляет один шаблон `settings.json`. Команды хуков
используют форму exec (`command` плюс `args`) вместо строк команд, специфичных для
shell, поэтому межплатформенное поведение проверяется внутри одного файла. Новые
записи разрешений и события хуков попадают в этот файл атомарно.
