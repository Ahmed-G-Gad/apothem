`settings.json` содержит конфигурацию окружения Claude Code: подключение хуков,
разрешения инструментов, переменные окружения и настройки строки состояния.

Полный канонический справочник находится в
[settings-reference.md](/docs/reference/settings-reference). Эта страница кратко излагает контракт
и указывает на более подробный справочник.

## Разделы

| Раздел | Назначение |
|---------|---------|
| `permissions` | Белые и чёрные списки инструментов для каждого matcher |
| `hooks` | Таблица команд хуков с ключами по событиям (каноническое подключение) |
| `env` | Переменные окружения для отдельной сессии |
| `statusLine` | Шаблон строки состояния, который отображает хост |

## Инвариант единого шаблона

Адаптер Claude Code поставляет один шаблон `settings.json`. Команды хуков
используют exec-форму (`command` плюс `args`) вместо командных строк,
специфичных для оболочки, поэтому поведение на разных ОС проверяется в одном
файле. Новые записи разрешений и события хуков попадают в этот файл атомарно.

## Слияние с вашим собственным файлом настроек

`settings.json` — это также ваш файл. Установка сливает шаблон с ним, а не
заменяет его, и записывает в журнал установок
(`~/.apothem/state/<harness>/ledger.jsonl`), какие именно ключи и элементы
списков она добавила:

- `permissions.allow` и `permissions.deny` сливаются как объединение множеств:
  ваши правила остаются первыми, а правила Apothem добавляются в конец.
  Написанное вами запрещающее правило всегда сохраняется, а Claude Code
  применяет запрещающие правила раньше разрешающих.
- Ваши собственные обработчики хуков остаются на месте. Обработчик считается
  принадлежащим Apothem, только если он запускает скрипт, который Apothem
  установил в корневом каталоге окружения, поэтому обработчик, вызывающий
  какой-либо другой `hooks/dispatch.py`, — ваш.
- Повторная установка заменяет только то, что Apothem добавил в прошлый раз,
  поэтому запись, которую шаблон убрал, удаляется, а запись, которую добавили
  вы, сохраняется.
- Удаление убирает только те записи, которые журнал фиксирует как
  принадлежащие Apothem. Правило, которое случайно совпадает с одним из правил
  Apothem (например, `Read` в вашем собственном списке `allow` до первой
  установки), остаётся. Файл удаляется, только если его создал Apothem и в нём
  не осталось ничего вашего.

Те же правила применяются к другим файлам настроек, с которыми Apothem
выполняет слияние, например к картам MCP-серверов в `settings.json` Qwen Code
и `opencode.json` OpenCode.
