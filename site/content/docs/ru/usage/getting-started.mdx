Apothem предоставляет четыре основные возможности: общий профиль управления,
корпус правил, структурированный конвейер планирования и шлюз соответствия в
реальном времени.

<Callout title="Впервые здесь?">
  Для пошагового руководства от нуля до первого запуска начните с
  [руководства по началу работы](/docs/tutorials/getting-started). Эта страница —
  краткий справочник по четырём основным рабочим процессам после настройки.
</Callout>

## Общий профиль

Ваш профиль Apothem находится в `~/.config/apothem/profile.yaml`, если вы не
передаёте `--profile PATH`. Это единый источник истины, из которого каждый
адаптер окружения выводит нативную конфигурацию:

```yaml
identity:
  name: "Example User"
preferences:
  style: "concise"
rules:
  - "Validate external input before writing files."
```

Создайте профиль, если его ещё нет, затем просмотрите его. Одношаговые
установщики и `apothem install` при первом запуске уже записывают стартовый
профиль, а `profile init` останавливается с ошибкой и оставляет существующий
файл без изменений, если только вы не передадите `--force`.

```bash
apothem profile init
apothem profile show --json
```

## Первое правило

Добавьте общие правила в YAML профиля, затем повторно материализуйте выбранное
окружение. Когда эти правила содержат данные-примеры, используйте фиктивные
заполнители, чтобы ни реальная идентичность, ни учётные данные не попали в
общий профиль или в запуск CI.

```bash
apothem profile set rules '["Always include a brief summary at the end of every response."]'
apothem update --harness claude-code
apothem verify --harness claude-code
```

## Первый план

Конвейер `/plan` выполняется внутри вашего окружения как слеш-команды, а не
через бинарный файл `apothem`. После установки окружения запустите план из чата
инструмента:

```text
/plan-spec
```

`/plan-spec` уточняет вашу прозу до спецификации, а `/plan-generate`
материализует набор планов в `<project-root>/.apothem/plans/{suite}/`. Полный
поток смотрите в [справочнике команд конвейера](/docs/pipeline).

## Шлюз соответствия

Из чекаута Apothem выполните:

```bash
PYTHONPATH=src python -m apothem.conformity.gate --all .
```

После установки через скрипт выполните:

```bash
PYTHONPATH="$HOME/.apothem/src" python3 -m apothem.conformity.gate --all .
```

Выполняет все механические проверки соответствия и сообщает о прохождении/сбое по
каждому пункту.
