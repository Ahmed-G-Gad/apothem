Apothem предоставляет четыре основные возможности: общий профиль управления,
корпус правил, структурированный конвейер планирования и шлюз соответствия в
реальном времени.

<Callout title="Впервые здесь?">
  Для пошагового руководства от нуля до первого запуска начните с
  [вводного руководства](/docs/tutorials/getting-started). Эта страница — краткий
  справочник по четырём основным рабочим процессам после настройки.
</Callout>

## Общий профиль

Ваш профиль Apothem находится в `~/.config/apothem/profile.yaml`, если вы не
передаёте `--profile PATH`. Это единый источник истины, из которого каждый
адаптер среды выводит нативную конфигурацию:

```yaml
identity:
  name: "Example User"
preferences:
  style: "concise"
rules:
  - "Validate external input before writing files."
```

Создайте и просмотрите профиль:

```bash
apothem profile init
apothem profile show --json
```

## Первое правило

Добавьте общие правила в YAML профиля, затем повторно материализуйте выбранную
среду. Когда эти правила содержат данные-примеры, используйте фиктивные
заполнители, чтобы ни реальная личность, ни учётные данные не попали в общий
профиль или в запуск CI.

```bash
apothem profile set rules '["Always include a brief summary at the end of every response."]'
apothem update --harness claude-code
apothem verify --harness claude-code
```

## Первый план

Конвейер `/plan` выполняется внутри вашего harness как
слеш-команды, а не через бинарный файл `apothem`. После установки среды запустите
план из чата инструмента:

```text
/plan-spec
```

`/plan-spec` уточняет вашу прозу в спецификацию, а `/plan-generate`
материализует набор планов в `<project-root>/.apothem/plans/{suite}/`. Полный поток
смотрите в [справочнике команд конвейера](/docs/pipeline).

## Шлюз соответствия

Запустите из корня репозитория:

```bash
python -m apothem.conformity.gate --all .
```

Выполняет все механические проверки соответствия и сообщает о прохождении/сбое по
каждой планке.
