Хуки — это команды shell, срабатывающие на события harness. Они обеспечивают
соответствие, внедряют контекст и запускают шлюзы качества без вмешательства
оператора.

## События хуков

| Событие | Когда срабатывает |
|-------|--------------|
| `PreToolUse` | Перед каждым вызовом инструмента |
| `PostToolUse` | После каждого вызова инструмента |
| `SessionStart` | При запуске сессии |
| `PreCompact` | Перед уплотнением контекста |
| `PostCompact` | После уплотнения контекста |
| `Stop` | В конце сессии |

## Файлы сообщений хука

У каждого хука есть соответствующий файл сообщения в
`src/apothem/hooks/messages/<event>-<name>.md`, который предоставляет контекст
ассистенту в момент срабатывания хука.

## Регистрация хука

Добавьте команду хука в `settings.json`:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "python src/apothem/hooks/my-check.py"
          }
        ]
      }
    ]
  }
}
```

## Диспетчер хуков

Все хуки маршрутизируются через `src/apothem/hooks/dispatch.py`, который
преобразует любую ошибку хука в конверт fail-open, чтобы хуки никогда не
блокировали harness.
