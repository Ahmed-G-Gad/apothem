Правила — это файлы Markdown с расширением `.md` в `src/apothem/rules/`.

## Frontmatter правила

```yaml
---
name: "..."
description: "..."
pathFilter: ""            # empty string for always-on; a glob for path-filtered
alwaysApply: true         # true for always-on; false for path-filtered
---
```

## Области действия правил

Область действия правила задаётся двумя полями frontmatter, `alwaysApply` и `pathFilter`:

| `alwaysApply` | `pathFilter` | Когда применяется |
|---------------|--------------|--------------|
| `true` | `""` (пусто) | Всегда: каждая сессия, каждый файл |
| `false` | glob-шаблон вида `"**/*.py"` | Фильтр по пути: только когда активный файл соответствует шаблону |

## Пример правила

```markdown
---
name: "python-conventions"
description: "Python style conventions for this project"
pathFilter: "**/*.py"
alwaysApply: false
---

# Python conventions

- Use type annotations on all public functions.
- Maximum line length: 88 characters.
- Prefer explicit over implicit.
```

## Применение правил к окружениям

После написания правила обновите каждый установленный адаптер окружения. Выполните `apothem harnesses list`, чтобы увидеть установленный набор, затем вызовите update по одному разу для каждого окружения:

```bash
apothem update --harness claude-code
apothem update --harness cursor
```

## Валидация правил

```bash
python -m apothem.conformity.gate --check frontmatter
```
