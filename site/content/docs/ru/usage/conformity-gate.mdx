Шлюз соответствия в `src/apothem/conformity/gate.py` выполняет пятнадцать
механических проверок для каждого артефакта, который создаёт оператор.

## Запуск шлюза

```bash
python -m apothem.conformity.gate
```

## Полосы шлюза

| Полоса | Проверка | Вид |
|-----|-------|------|
| M1 | Соответствие области действия | Аналитическая |
| M2 | Внутренняя изоляция плана (CM-7) | Механическая |
| M3 | Соблюдение стандартов | Аналитическая |
| M4 | Корректность frontmatter | Механическая |
| M5 | Отсутствие запрещённых формулировок | Механическая |
| M6 | Редакционное раскрытие | Аналитическая |
| M7 | Отсутствие ссылок на план в артефактах | Механическая |
| M8 | Наличие заголовка авторства | Механическая |
| M9 | Честная оценка | Аналитическая |
| M10 | Дисциплина именования | Механическая |
| M11 | Аппарат спринта | Аналитическая |
| M12 | Каноническая компоновка | Механическая |
| M13 | Мастерство кода | Аналитическая |
| M14 | Системное участие | Аналитическая |
| M15 | Человеческое авторство | Механическая |

## Целевые проверки

```bash
# Запустить одну проверку
python -m apothem.conformity.gate --check multi-surface-coherence

# Запустить для конкретного файла
python -m apothem.conformity.gate src/apothem/rules/my-rule.md
```

## Интеграция с CI

Шлюз запускается в CI через `.github/workflows/conformity.yml` при каждом push.
