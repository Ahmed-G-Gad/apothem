Делегированные работники Apothem — это постоянные, переиспользуемые определения
работников, хранящиеся в дереве `src/apothem/` (канонический каталог показан
ниже — имя сохранено для совместимости с загрузчиком runtime):

```text
src/apothem/agents/
```

Каждый делегированный работник кодирует специализированную роль, сигналы
обнаружения и набор разрешённых инструментов.

## Структура файла делегированного работника

```markdown
---
name: "my-agent"
description: "..."
tools: "Read, Grep, Glob"
---

# My assistant

## Role
...

## Detection signals
Matched when: ...

## Workflow
...
```

## Встроенные делегированные работники

| Делегированный работник | Назначение |
|-------|---------|
| `codebase-explorer` | Глубокое исследование кодовой базы |
| `convention-auditor` | Проверка именования и форматирования |
| `memory-auditor` | Проверка точности памяти |
| `quality-gate` | Lint, тесты, проверка типов, сканирование безопасности |

## Вызов делегированных работников

Делегированные работники диспетчеризуются оркестратором через инструмент
делегирования, предоставляемый runtime хоста. Оркестратор выбирает подходящего
работника на основе описания задачи и сигналов обнаружения.
