**Поставщик:** Alibaba Cloud
**Имя установки:** `qwen-code`
**Статус:** Бета
**Нативная конфигурация:** `~/.qwen/`

## Установка

```bash
apothem install --harness qwen-code
```

Адаптер записывает настройки Qwen Code, устанавливает якорь контекста `QWEN.md`,
регистрирует диспетчеры хуков Apothem, преобразует команды Apothem в файлы команд
Qwen в формате Markdown, устанавливает навыки как каталоги SKILL.md и адаптирует
определения помощников как субагенты Qwen.

**Записываемые файлы:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

## Сопоставление профиля с нативной конфигурацией

Адаптер рендерит документированные ключи `settings.json` для контекста и хуков,
записывает `QWEN.md` и встраивает команды, навыки и определения помощников
Apothem в нативные каталоги обнаружения Qwen Code. Правила, шаблоны и исходный
материал хуков остаются вспомогательным материалом в `~/.qwen/.apothem/support/`.

## Заметки о совместимости

`~/.qwen/.apothem/support/` — это вспомогательный материал, на который ссылаются
`QWEN.md` и команды хуков в настройках; это не пространство имён обнаружения,
принадлежащее поставщику.
Блок Apothem в `QWEN.md` завершается разделом о вспомогательных файлах Apothem,
который называет абсолютный каталог в `~/.qwen/.apothem/support/`, относительно
которого разрешается каждая ссылка в стиле репозитория (`rules/<name>.md`,
`templates/...`, `hooks/...`).

## Проверка

```bash
apothem verify --harness qwen-code
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness qwen-code
```

Обновляет `settings.json`, `QWEN.md`, нативные команды, навыки, субагенты и
дерево поддержки Apothem.

## Удаление

```bash
apothem uninstall --harness qwen-code
```

Удаляет файлы нативной конфигурации, записанные адаптером.
YAML общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Исправление |
|---------|-----|
| Файл конфигурации не найден | Повторно запустите `apothem install --harness qwen-code` |
| Проверка не пройдена | Запустите `apothem update --harness qwen-code`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем повторно запустите `apothem update --harness qwen-code` |

## Параметры конфигурации

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предпросмотр установки без записи файлов. |
