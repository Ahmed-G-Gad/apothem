**Поставщик:** GitHub / Microsoft
**Имя установки:** `github-copilot`
**Статус:** GA
**Нативная конфигурация:** `<project>/.github/copilot-instructions.md`

## Установка

```bash
apothem install --harness github-copilot --project /path/to/project
```

Адаптер выводит файл инструкций проекта из общих правил Apothem и поверхности
управления.

**Записанные файлы:** `<project>/.github/copilot-instructions.md`

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem и рендерит файл инструкций Copilot для всего
репозитория при каждом запуске `apothem install` или `apothem update`. Общий профиль
является источником истины; локальные правки проекта в сгенерированном файле
резервируются перед тем, как следующая синхронизация заменит управляемое Apothem
содержимое.

## Замечания о совместимости

GitHub Copilot не предоставляет файлового пути пользовательских глобальных инструкций,
которым этот адаптер мог бы управлять. Apothem нацеливается на документированный файл
инструкций уровня проекта и оставляет пользовательские настройки уровня IDE во владении
оператора.

Apothem рассматривает `copilot-instructions.md` как один из голосов среди поверхностей
инструкций для ассистентов проекта: проверка многоповерхностной согласованности шлюза
соответствия подтверждает, что его общие утверждения остаются семантически
согласованными с остальными файлами инструкций проекта, поэтому Copilot никогда не
получает указаний, противоречащих тому, что читает остальная часть набора инструментов.

## Проверка

```bash
apothem verify --harness github-copilot --project /path/to/project
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness github-copilot --project /path/to/project
```

Заново выводит файл инструкций проекта из текущего состояния общего профиля.

## Удаление

```bash
apothem uninstall --harness github-copilot --project /path/to/project
```

Удаляет файлы нативной конфигурации, записанные адаптером.
YAML общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Решение |
|---------|-----|
| Файл конфигурации не найден | Заново выполните `apothem install --harness github-copilot --project /path/to/project` |
| Проверка не прошла | Выполните `apothem update --harness github-copilot --project /path/to/project`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем заново выполните `apothem update --harness github-copilot --project /path/to/project` |

## Настроечные параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предварительный просмотр установки без записи файлов. |
