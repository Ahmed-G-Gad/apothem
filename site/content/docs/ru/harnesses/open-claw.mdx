**Поставщик:** Open-Claw
**Имя установки:** `open-claw`
**Статус:** Предварительная версия
**Нативная конфигурация:** `~/.openclaw/openclaw.json`

## Установка

```bash
apothem install --harness open-claw
```

Адаптер переводит общий профиль в пользовательский глобальный файл конфигурации
OpenClaw и устанавливает группы поддержки Apothem под корнем окружения. Нативная
конфигурация OpenClaw — это JSON; materializer отрисовывает JSON для соответствия.

**Записанные файлы:** `~/.openclaw/openclaw.json` и файлы поддержки в
`~/.openclaw/.apothem/support/`

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem. Нативное поле skills в OpenClaw — это список
разрешённых имён (а не загрузчик каталога), а MCP — поверхность CLI, поэтому Apothem не
записывает никаких ключей конфигурации. Общие команды, навыки, правила, шаблоны и
промпты хуков устанавливаются как материал поддержки в `~/.openclaw/.apothem/support/`.

## Замечания о совместимости

Адаптер предварительной версии. Нативная конфигурация JSON является активной
поверхностью Open-Claw; Apothem использует документированный хук дополнительного
каталога навыков для навыков и сохраняет остальные группы как справочный материал для
установленных указаний.

## Проверка

```bash
apothem verify --harness open-claw
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness open-claw
```

Заново выводит нативную конфигурацию из текущего состояния общего профиля. Выполните
после редактирования `~/.config/apothem/profile.yaml` или обновления установленного
пакета Apothem.

## Удаление

```bash
apothem uninstall --harness open-claw
```

Удаляет файлы нативной конфигурации, записанные адаптером. YAML общего профиля и движок
Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Решение |
|---------|-----|
| Файл конфигурации не найден | Заново выполните `apothem install --harness open-claw` |
| Проверка не прошла | Выполните `apothem update --harness open-claw`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем заново выполните `apothem update --harness open-claw` |

## Настроечные параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предварительный просмотр установки без записи файлов. |
