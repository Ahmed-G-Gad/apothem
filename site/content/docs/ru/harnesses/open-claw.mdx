**Поставщик:** Open-Claw
**Имя установки:** `open-claw`
**Статус:** Предварительная версия
**Нативная конфигурация:** `~/.openclaw/openclaw.json`

## Установка

```bash
apothem install --harness open-claw
```

Адаптер записывает глобальный пользовательский файл конфигурации OpenClaw,
проецирует общий профиль в документ профиля и устанавливает группы поддержки
Apothem в корень окружения. Нативная конфигурация OpenClaw — это JSON;
материализатор рендерит пустой объект JSON, а существующий файл сохраняет свои
ключи.

**Записываемые файлы:** `~/.openclaw/openclaw.json`, документ профиля
`~/.openclaw/apothem/rules/00-apothem-profile.md` и файлы поддержки в
`~/.openclaw/.apothem/support/`

Документ профиля завершается разделом о вспомогательных файлах Apothem, который
называет абсолютный каталог в `~/.openclaw/.apothem/support/`, относительно
которого разрешается каждая ссылка в стиле репозитория (`rules/<name>.md`,
`templates/...`, `hooks/...`).

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem, но не создаёт ключей конфигурации:
новый или пустой `openclaw.json` записывается как пустой объект, а существующий
файл сохраняет свои ключи. Идентичность, предпочтения и правила из профиля
попадают в документ профиля. Общие команды, навыки, правила, шаблоны и промпты
хуков устанавливаются как вспомогательный материал в
`~/.openclaw/.apothem/support/`.

## Заметки о совместимости

Адаптер в предварительной версии. OpenClaw сам не загружает ни дерево
поддержки, ни документ профиля: ни одно из его расположений навыков, ни его
файлы инструкций рабочей области, ни его конфигурация не указывают туда, поэтому
после установки OpenClaw работает без правил, навыков и серверов MCP Apothem.
OpenClaw читает навыки из папок `skills/` и `.agents/skills/` своей рабочей
области, из `~/.agents/skills`, из своего каталога состояния и из любой папки,
указанной в `skills.load.extraDirs`; чтобы использовать навыки Apothem, добавьте
`~/.openclaw/.apothem/support/skills` в этот список самостоятельно; `apothem update`
сохраняет ключи, которые вы добавляете в `openclaw.json`. Серверы MCP находятся
в блоке `mcp.servers` конфигурации OpenClaw, которым вы управляете с помощью
`openclaw mcp add` и связанных подкоманд; адаптер не добавляет туда ни одной
записи. (Поведение OpenClaw описано по его документации о
[навыках](https://docs.openclaw.ai/tools/skills) и
[CLI для MCP](https://docs.openclaw.ai/cli/mcp), прочитанной 2026-10-02.)

## Проверка

```bash
apothem verify --harness open-claw
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Каждая управляемая цель существует; управляемые файлы не пусты, а
   конфигурации JSON или YAML разбираются. Добавьте `--profile PATH`, чтобы
   дополнительно подтвердить, что установленные файлы соответствуют этому
   профилю.
3. Процедура проверки, специфичная для адаптера, сообщает об успехе.

## Обновление

```bash
apothem update --harness open-claw
```

Повторно выводит документ профиля из текущего состояния общего профиля и
обновляет вспомогательные файлы; `openclaw.json` сохраняет ключи, которые в нём
уже есть. Запускайте после редактирования `~/.config/apothem/profile.yaml` или
обновления установленного пакета Apothem.

## Удаление

```bash
apothem uninstall --harness open-claw
```

Удаляет то, что добавил адаптер: документ профиля и дерево поддержки. Ваши
собственные ключи в `openclaw.json` остаются на месте, а сам файл удаляется
только тогда, когда его создал Apothem и от вас в нём ничего не осталось. YAML
общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Исправление |
|---------|-----|
| Файл конфигурации не найден | Повторно запустите `apothem install --harness open-claw` |
| Проверка не пройдена | Запустите `apothem update --harness open-claw`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем повторно запустите `apothem update --harness open-claw` |

## Параметры конфигурации

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предпросмотр установки без записи файлов. |
