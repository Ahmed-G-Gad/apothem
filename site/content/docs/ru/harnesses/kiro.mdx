**Поставщик:** AWS
**Имя установки:** `kiro`
**Статус:** GA
**Нативная конфигурация:** `<project>/.kiro/steering/apothem-rules.md`

## Установка

```bash
apothem install --harness kiro --project /path/to/project
```

Адаптер записывает один файл управления (steering) Kiro с областью проекта на
основе общих правил Apothem и поверхности управления.

**Записанные файлы:** `<project>/.kiro/steering/apothem-rules.md`

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem и рендерит файл управления проекта при каждом
запуске `apothem install` или `apothem update`. Общий профиль является источником
истины; локальные правки проекта в сгенерированном файле резервируются перед тем,
как следующая синхронизация заменит управляемое Apothem содержимое.

## Заметки о совместимости

Поверхность управления Kiro имеет область проекта в `.kiro/steering/`. Адаптер
записывает выделенный файл управления `apothem-rules.md` с фронт-маттером
`inclusion: always` и никогда не затирает базовые файлы Kiro, написанные оператором
(`product.md`, `tech.md`, `structure.md`). Спецификации Kiro (`.kiro/specs/`) и
хуки помощников принадлежат оператору; Apothem их не записывает.

## Проверка

```bash
apothem verify --harness kiro --project /path/to/project
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness kiro --project /path/to/project
```

Повторно выводит файл управления проекта из текущего состояния общего профиля.

## Удаление

```bash
apothem uninstall --harness kiro --project /path/to/project
```

Удаляет файлы нативной конфигурации, записанные адаптером.
YAML общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Исправление |
|---------|-----|
| Файл конфигурации не найден | Повторно запустите `apothem install --harness kiro --project /path/to/project` |
| Проверка не пройдена | Запустите `apothem update --harness kiro --project /path/to/project`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем повторно запустите `apothem update --harness kiro --project /path/to/project` |

## Регуляторы конфигурации

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предпросмотр установки без записи файлов. |
