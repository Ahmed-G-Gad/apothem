**Поставщик:** Zed Industries
**Имя установки:** `zed`
**Статус:** GA
**Нативная конфигурация:** `<project>/.rules`

## Установка

```bash
apothem install --harness zed --project /path/to/project
```

Адаптер записывает один файл инструкций Zed с областью проекта из общей поверхности
правил и управления Apothem. Zed читает единственный плоский файл `.rules` в корне
проекта (рядом с семейством `AGENTS.md` / `CLAUDE.md`) как инструкции; каталога
правил для каждого инструмента нет, поэтому вся поверхность Apothem помещается в
этот один файл.

**Записанные файлы:** `<project>/.rules`

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem и отрисовывает файл `.rules` проекта при каждом
запуске `apothem install` или `apothem update`. Общий профиль является источником
истины; любой существующий `.rules` (или локальные для проекта правки
сгенерированного файла) резервируется до того, как следующая синхронизация заменит
управляемое Apothem содержимое.

## Замечания о совместимости

Текущая поверхность инструкций Zed — это плоский файл `.rules` в корне проекта.
Глобальный файл инструкций `~/.config/zed/AGENTS.md` и блок контекстных серверов MCP
(`context_servers` в `.zed/settings.json`) принадлежат оператору; Apothem их не
записывает.

## Проверка

```bash
apothem verify --harness zed --project /path/to/project
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness zed --project /path/to/project
```

Заново выводит файл `.rules` проекта из текущего состояния общего профиля.

## Удаление

```bash
apothem uninstall --harness zed --project /path/to/project
```

Удаляет файл нативной конфигурации, записанный адаптером, предварительно переименовав
его в резервную копию с меткой времени. YAML общего профиля и движок Apothem не
затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Решение |
|---------|-----|
| Файл конфигурации не найден | Заново выполните `apothem install --harness zed --project /path/to/project` |
| Проверка не прошла | Выполните `apothem update --harness zed --project /path/to/project`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем заново выполните `apothem update --harness zed --project /path/to/project` |

## Настроечные параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предварительный просмотр установки без записи файлов. |
