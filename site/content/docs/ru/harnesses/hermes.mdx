**Поставщик:** Hermes
**Имя установки:** `hermes`
**Статус:** Предварительная версия
**Нативная конфигурация:** `~/.hermes/config.yaml`

## Установка

```bash
apothem install --harness hermes
```

Адаптер переводит общий профиль в пользовательский глобальный файл конфигурации
Hermes Agent и устанавливает когорты поддержки Apothem под корнем окружения.

**Записанные файлы:** `~/.hermes/config.yaml` и файлы поддержки под
`~/.hermes/.apothem/support/`

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem и рендерит нативную конфигурацию YAML.
Собственная поверхность навыков Hermes — это `skills.config` — устанавливаемые
пакеты реестра, которые Hermes автоматически предоставляет как динамические
слеш-команды, — которую Apothem не пишет. Вместо этого Apothem доставляет общее
содержимое команд и навыков как вспомогательный материал под
`~/.hermes/.apothem/support/`, на который ссылается нативный якорь инструкций.
Вспомогательные определения, правила, шаблоны и подсказки хуков также остаются
вспомогательным материалом под `~/.hermes/.apothem/support/`.

## Замечания о совместимости

Адаптер в предварительной версии. Нативная конфигурация YAML — это активная
поверхность Hermes; Apothem использует документированный внешний хук каталога
навыков для навыков и сохраняет остальные когорты как справочный материал для
установленного руководства.

## Проверка

```bash
apothem verify --harness hermes
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness hermes
```

Заново выводит нативную конфигурацию из текущего состояния общего профиля.
Запускайте после редактирования `~/.config/apothem/profile.yaml` или обновления
установленного пакета Apothem.

## Удаление

```bash
apothem uninstall --harness hermes
```

Удаляет нативные файлы конфигурации, записанные адаптером.
YAML общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Исправление |
|---------|-----|
| Файл конфигурации не найден | Повторно запустите `apothem install --harness hermes` |
| Проверка не пройдена | Запустите `apothem update --harness hermes`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем повторно запустите `apothem update --harness hermes` |

## Настроечные параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предварительный просмотр установки без записи файлов. |
