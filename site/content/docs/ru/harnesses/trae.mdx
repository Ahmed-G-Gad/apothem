**Поставщик:** ByteDance
**Имя установки:** `trae`
**Статус:** GA
**Нативная конфигурация:** `<project>/.trae/rules/apothem-rules.md`

## Установка

```bash
apothem install --harness trae --project /path/to/project
```

Адаптер записывает один файл правил Trae с областью проекта из общей поверхности правил
и управления Apothem.

**Записанные файлы:** `<project>/.trae/rules/apothem-rules.md`

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem и отрисовывает файл правил проекта при каждом
запуске `apothem install` или `apothem update`. Общий профиль является источником
истины; локальные для проекта правки сгенерированного файла резервируются до того, как
следующая синхронизация заменит управляемое Apothem содержимое.

## Замечания о совместимости

Текущая поверхность правил Trae имеет область проекта в `.trae/rules/`. Адаптер
записывает выделенный файл `apothem-rules.md`, который сосуществует с принадлежащими
оператору якорями `project_rules.md` и `user_rules.md` и никогда их не перезаписывает.
Поверхность серверов инструментов `.trae/mcp.json` и поверхность навыков
`.trae/skills/` принадлежат оператору; Apothem их не записывает.

## Проверка

```bash
apothem verify --harness trae --project /path/to/project
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness trae --project /path/to/project
```

Заново выводит файл правил проекта из текущего состояния общего профиля.

## Удаление

```bash
apothem uninstall --harness trae --project /path/to/project
```

Удаляет файлы нативной конфигурации, записанные адаптером.
YAML общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Решение |
|---------|-----|
| Файл конфигурации не найден | Заново выполните `apothem install --harness trae --project /path/to/project` |
| Проверка не прошла | Выполните `apothem update --harness trae --project /path/to/project`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем заново выполните `apothem update --harness trae --project /path/to/project` |

## Настроечные параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предварительный просмотр установки без записи файлов. |
