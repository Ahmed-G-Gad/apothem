**Поставщик:** OpenAI
**Имя установки:** `codex`
**Статус:** Beta
**Нативная конфигурация:** `~/.codex/AGENTS.md`, `~/.codex/hooks.json`,
`~/.codex/hooks/`, `~/.codex/agents/*.toml` и `~/.agents/skills/`

## Установка

```bash
apothem install --harness codex
```

Адаптер устанавливает нативные инструкции и хуки Codex, преобразует агентов Apothem в
TOML-агентов Codex и оборачивает повторно используемые промпты команд как навыки Codex.

**Записанные файлы:** `~/.codex/AGENTS.md`, `~/.codex/hooks.json`,
`~/.codex/hooks/`, `~/.codex/agents/*.toml`,
`~/.agents/skills/*/SKILL.md`, и файлы поддержки в
`~/.config/apothem/{rules,templates}/`.

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общие группы Apothem и устанавливает каждую в правильную поверхность
Codex: инструкции в `AGENTS.md`, хуки в `hooks.json` и `hooks/`, агентов в TOML, навыки
в `~/.agents/skills/`, а ненативные правила/шаблоны Markdown в `~/.config/apothem/` как
материал поддержки.

## Замечания о совместимости

Codex резервирует `~/.codex/rules/` для политик выполнения `.rules`. Apothem не
размещает там поведенческие правила Markdown; он хранит их в `~/.config/apothem/` и
ссылается на них из `AGENTS.md` и установленных навыков.

## Проверка

```bash
apothem verify --harness codex
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness codex
```

Обновляет начальную загрузку Codex, преобразованных агентов, навыки и группы поддержки.

## Удаление

```bash
apothem uninstall --harness codex
```

Удаляет файлы нативной конфигурации, записанные адаптером. YAML общего профиля и движок
Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Решение |
|---------|-----|
| Файл конфигурации не найден | Заново выполните `apothem install --harness codex` |
| Проверка не прошла | Выполните `apothem update --harness codex`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем заново выполните `apothem update --harness codex` |

## Настроечные параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предварительный просмотр установки без записи файлов. |
