**Поставщик:** Anysphere
**Имя установки:** `cursor`
**Статус:** GA
**Нативная конфигурация:** `.cursor/rules/` в корне проекта

## Установка

```bash
apothem install --harness cursor --project /path/to/project
```

Адаптер рендерит единый файл правил `.mdc` в области проекта на основе общей
поверхности правил и управления Apothem.

**Записываемые файлы:** `<project>/.cursor/rules/apothem-rules.mdc`

Этот файл и есть вся установка: рядом с ним не размещается ни один файл
правил, навыков, команд, шаблонов или хуков, поэтому сам файл сообщает об этом,
а не указывает на файлы Apothem, которых нет в проекте.

## Сопоставление профиля с нативной конфигурацией

Адаптер читает общий профиль Apothem и рендерит файл правил проекта при каждом
запуске `apothem install` или `apothem update`. Общий профиль является
источником истины; для локальных правок сгенерированного файла в проекте
создаётся резервная копия, прежде чем следующая синхронизация заменит
содержимое, управляемое Apothem.

Файл начинается со своего YAML-фронтматтера (`description`, `globs`,
`alwaysApply: true`), потому что Cursor считывает тип правила только из
фронтматтера в начале файла. За ним следует блок, управляемый Apothem; текст,
который вы добавляете после блока, сохраняется при каждой синхронизации.

## Заметки о совместимости

Cursor 0.45+ поддерживает инструкции на уровне проекта через `.cursor/rules/`.
Адаптер по умолчанию записывает в каталог `.cursor/rules/` в области проекта;
в Cursor нет документированного файлового пути для глобальных
пользовательских правил, которым мог бы управлять этот адаптер.

## Проверка

```bash
apothem verify --harness cursor --project /path/to/project
```

Команда verify подтверждает, что:

1. Нативная конфигурация существует по ожидаемому пути.
2. Все обязательные поля из общего профиля присутствуют.
3. Специфичная для адаптера процедура проверки сообщает об успехе.

## Обновление

```bash
apothem update --harness cursor --project /path/to/project
```

Повторно выводит файл правил проекта из текущего состояния общего профиля.

## Удаление

```bash
apothem uninstall --harness cursor --project /path/to/project
```

Удаляет файлы нативной конфигурации, записанные адаптером.
YAML общего профиля и движок Apothem не затрагиваются.

## Шлюз соответствия

```bash
python -m apothem.conformity.gate --all .
```

## Устранение неполадок

| Симптом | Исправление |
|---------|-----|
| Файл конфигурации не найден | Повторно запустите `apothem install --harness cursor --project /path/to/project` |
| Проверка не пройдена | Запустите `apothem update --harness cursor --project /path/to/project`, затем проверьте снова |
| Неожиданное содержимое конфигурации | Проверьте `~/.config/apothem/profile.yaml` или `--profile PATH`, затем повторно запустите `apothem update --harness cursor --project /path/to/project` |

## Параметры конфигурации

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--dry-run` | `false` | Предпросмотр установки без записи файлов. |
