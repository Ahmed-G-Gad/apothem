Apothem использует двухформенную дисциплину бренда:

| Форма | Применение | Примеры |
|---|---|---|
| **Apothem** | Отображаемая форма — весь текст, заголовки, интерфейс, документация | Apothem vX.Y.Z, Install Apothem |
| **apothem** | Форма идентификатора — команды CLI, имена пакетов, пути к файлам | npx @ahmed-g-gad/apothem, apothem install |

Никогда не используйте: ApoThem (верблюжий регистр), Apo-them (через дефис), APOTHEM (всё заглавными) или строчное `apothem` в тексте. `Apothem` — единственная отображаемая форма.

## Слоган

> one profile, every harness

Слоган пишется строчными буквами — именно так, как его несут локапы словесного знака
и социальные карточки.

## Логотип

Знак Apothem — это правильный шестиугольник с плоской вершиной, в котором шесть апофем
расходятся из общего центра к середине каждой стороны, вписанная окружность проходит через эти
шесть середин, а в центре находится узел-источник. Апофема к верхней стороне —
изумрудная (emerald), остальные пять — серые (slate); геометрия описана в
[`assets/DESIGN-SYSTEM.md`](https://github.com/ahmed-g-gad/apothem/blob/main/assets/DESIGN-SYSTEM.md).
Светлый и тёмный варианты доступны в `assets/logo.svg` и
`assets/logo-dark.svg`. Горизонтальные локапы находятся в `assets/logo-wordmark.svg`
и `assets/logo-wordmark-dark.svg`.

Фавикон браузера намеренно использует компактную монограмму `assets/favicon.svg`
вместо полного знака; при 16px монограмма чётче во вкладках браузера и на
закреплённых поверхностях.

См. [Использование логотипа](/docs/brand/logo-usage) для разрешённых применений и
требований к свободному пространству.

## Обоснование палитры ресурсов

Периферийные узлы знака Apothem — это декоративная геометрия: они вызывают
ассоциацию с архитектурой «звезда» (концентратор и спицы), не кодируя количество
окружений, поэтому знак остаётся стабильным по мере добавления адаптеров. Назначения
цветов для палитры окружений находятся в [Цвета окружений](/docs/brand/harness-colors);
позиция по доступности и правила распространения по поверхностям задокументированы
на этой странице.
