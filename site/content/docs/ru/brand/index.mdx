Apothem использует двухформенную дисциплину бренда:

| Форма | Применение | Примеры |
|---|---|---|
| **Apothem** | Отображаемая форма — весь текст, заголовки, интерфейс, документация | Apothem vX.Y.Z, Install Apothem |
| **apothem** | Форма идентификатора — команды CLI, имена пакетов, пути к файлам | npx @ahmed-g-gad/apothem, apothem install |

Никогда не используйте: Apothem (одна заглавная), apothem (через дефис) или APOTHEM (всё заглавными).

## Слоган

> Один общий профиль. Семнадцать harness. Без переизобретения.

## Логотип

Знак Apothem использует мотив плетения apothem. Светлый и тёмный варианты
доступны в `assets/logo.svg` и `assets/logo-dark.svg`. Горизонтальные локапы
находятся в `assets/logo-wordmark.svg` и `assets/logo-wordmark-dark.svg`.

Фавикон браузера намеренно использует компактную монограмму `assets/favicon.svg`
вместо полного знака плетения; при 16px монограмма чётче во вкладках браузера и на
закреплённых поверхностях.

См. [Использование логотипа](/docs/brand/logo-usage) для разрешённых применений и
требований к свободному пространству.

## Обоснование палитры ресурсов

Периферийные узлы знака Apothem — это декоративная геометрия: они вызывают
ассоциацию с архитектурой «звезда» (концентратор и спицы), не кодируя количество
сред, поэтому знак остаётся стабильным по мере добавления адаптеров. Назначения
цветов для палитры сред находятся в [Цвета сред](/docs/brand/harness-colors);
позиция по доступности и правила распространения по поверхностям задокументированы
на этой странице.
