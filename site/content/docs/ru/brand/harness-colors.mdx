## Палитра окружений

Пятнадцать из семнадцати окружений окрашены в соответствии с их основной
фирменной идентичностью, чтобы читатель мог различать инструменты на диаграмме.
Сам знак Apothem использует только цвета slate и emerald со страницы
[палитры](/docs/brand/palette); цвета окружений в нём нет. Оставшиеся два —
`glm` и `kimi-code` — пока не имеют определённого фирменного цвета; их строки
добавляются, как только фирменный цвет задан в вышестоящем источнике, согласно
шагу распространения в разделе [Обновления](#обновления).

## Товарные знаки

Названия окружений, названия продуктов и фирменные цвета на этой странице и по
всему сайту принадлежат их владельцам и являются товарными знаками
соответствующих владельцев. Apothem называет инструмент только для того, чтобы
указать, какой из них он настраивает, и использует цвет инструмента только для
того, чтобы отличить его на диаграмме. Apothem — независимый проект; он не
аффилирован ни с одной из этих компаний или проектов, не спонсируется и не
одобряется ими и не поставляет ни одного из их логотипов.

## Обоснование именования

- **`apothem-hub`** — геометрический центр, о котором напоминает название (апофема правильного многоугольника направлена внутрь, к его ядру).
- **`shared-profile`** — вышестоящий источник, отличающийся от цвета любого отдельного окружения, чтобы на каждой диаграмме он читался как стрелка «входа».
- **Токены по окружениям** повторяют slug окружения, используемый по всей кодовой базе (`harnesses/<slug>/`, ключ точки входа, аргумент CLI `--harness <slug>`). Одно слово на понятие; одна и та же строка везде.

## Доступность

Каждый токен светлого режима обеспечивает контраст WCAG 2.2 AA с белым текстом (≥4.5 : 1) там, где контраст это позволяет без искажения фирменного цвета. Там, где нативный фирменный цвет окружения сам по себе не достигает порога AA с белым текстом (в частности, семейство янтарных / оранжевых и семейство небесно-голубых / бирюзовых токенов, перечисленных выше), диаграммы, которым нужен контраст текста на цвете уровня WCAG AA, используют в качестве заливки **вариант для тёмного режима** (осветлённый оттенок), чтобы белый текст читался чётко. Столбец тёмного режима откалиброван для этой цели: каждый токен тёмного режима проходит AA с белым текстом.

## Обновления

Палитра обновляется только тогда, когда окружение утверждает изменение бренда в вышестоящем источнике. Изменения бренда отдельного окружения распространяются атомарно на `site/app/global.css`, эту страницу и каждый затронутый мастер-файл SVG под `assets/src/`.
