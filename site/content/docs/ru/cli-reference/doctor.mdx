Запускает системную диагностику для установки Apothem.

## Синопсис

```
apothem doctor [--quiet|-q] [--verbose|-v]
               [--format plain|json] [--json] [--no-color]
```

Проверяет установку Apothem и сообщает статус каждого зарегистрированного
адаптера harness. Если общий профиль присутствует, он проверяется на соответствие
поставляемой схеме — а не только на факт существования, — так что некорректный
профиль выявляется как диагностическая ошибка, а не как зелёное «найдено». Вывод
JSON содержит поле `profile_valid` (`true` / `false` или `null`, когда профиль
отсутствует) и поле `profile_error` при сбое проверки. Завершается с кодом 0,
когда все проверки пройдены, и с кодом 1, когда один или несколько harness не
установлены или когда присутствующий профиль не проходит проверку схемы.

## Параметры

| Параметр | Описание |
|---|---|
| `--quiet`, `-q` | Подавляет информационный вывод; выводятся только ошибки. |
| `--verbose`, `-v` | Выводит дополнительную диагностику. |
| `--format plain\|json` | Формат вывода (по умолчанию: `plain`). |
| `--json` | Сокращение для `--format json`. |
| `--no-color` | Отключает ANSI-коды цвета в выводе. |
| `-h`, `--help` | Показывает справку и завершает работу. |

## Примеры

```bash
apothem doctor
apothem doctor --json
```

## Коды завершения

| Код | Значение |
|---|---|
| 0 | Все проверки пройдены |
| 1 | harness не установлен или присутствующий профиль не прошёл проверку схемы |
