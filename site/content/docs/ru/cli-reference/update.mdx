Переустанавливает конфигурацию адаптера окружения из текущего общего профиля.

## Синтаксис

```
apothem update --harness NAME|all [--profile PATH] [--dry-run]
                [--project PATH]
                [--quiet|-q] [--verbose|-v]
                [--format plain|json] [--json] [--no-color]
```

`update` заново материализует вывод окружения из текущего общего профиля. Она
использует ту же проверку профиля, тот же выбор `--harness all`, ту же проверку
области проекта, то же поведение пробного запуска и тот же конверт JSON, что и
`install`.

Псевдоним в продолженной форме `apothem updating` разрешается в тот же
обработчик.

## Параметры

| Параметр | Описание |
|---|---|
| `--harness NAME` | Адаптер окружения для обновления или `all` для набора уровня всего реестра (обязателен). |
| `--profile PATH` | Путь к YAML общего профиля. По умолчанию `~/.config/apothem/profile.yaml`. |
| `--dry-run` | Предпросмотр обновления без записи файлов. |
| `--project PATH` | Корень проекта для окружений с областью проекта. Обязателен, когда выбранный набор окружений включает адаптеры с областью проекта. |
| `--quiet`, `-q` | Подавить информационный вывод; выводятся только ошибки. |
| `--verbose`, `-v` | Выводить дополнительную диагностическую информацию. |
| `--format plain\|json` | Формат вывода (по умолчанию: `plain`). |
| `--json` | Сокращение для `--format json`. |
| `--no-color` | Отключить цветовые коды ANSI в выводе. |
| `-h`, `--help` | Показать справку и завершить работу. |

## Вывод JSON

```json
{
  "schema_version": 1,
  "status": "success",
  "command": "update",
  "action": "updated",
  "harness": "claude-code",
  "profile_path": "C:\\Users\\Example\\.config\\apothem\\profile.yaml",
  "project": null,
  "files_written": [],
  "results": [],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

`--dry-run` возвращает `status: "dry_run"` и `files_written: []`.

## Примеры

```bash
apothem update --harness claude-code
apothem update --harness claude-code --dry-run
apothem update --harness all --project . --dry-run --json
apothem Updating --harness claude-code   # continuous-form alias
apothem updating --harness claude-code   # lowercase variant
```

## Коды выхода

| Код | Значение |
|---|---|
| 0 | Адаптер успешно обновлён, или пробный запуск спланирован без ошибок |
| 1 | Ожидаемая ошибка проверки, профиля, окружения, проекта или адаптера |
| 2 | Частичная пакетная материализация после как минимум одной записи |
| 64 | Ошибка использования: неизвестный параметр или команда либо отсутствующее или недопустимое значение параметра. При `--json` ошибка представляет собой конверт JSON с кодом `cli.usage`. |
