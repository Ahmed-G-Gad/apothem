Интерфейс командной строки `apothem` управляет конфигурациями адаптеров ассистента по написанию кода из общего профиля. Каждая страница ниже документирует одну подкоманду: её сводку, параметры, поведение и коды выхода.

Каждая из команд `install`, `update` и `uninstall` также принимает псевдоним в продолженной форме (`installing`, `updating`, `uninstalling`), идентичный по флагам и поведению базовой команде. Обновление и удаление через каналы установки — плагин Claude Code, `npx` и одношаговые скрипты установщика — задокументированы в руководствах по установке [Обновление](/docs/install/updating) и [Удаление](/docs/install/uninstalling), а не самими псевдонимами.

## Команды

| Команда | Описание |
|---------|-------------|
| [quickstart](/docs/cli-reference/quickstart) | Управляемый первый запуск: обеспечивает наличие профиля, показывает предпросмотр записей, затем устанавливает. |
| [install](/docs/cli-reference/install) | Устанавливает конфигурацию адаптера ассистента по написанию кода из общего профиля (псевдоним: `installing`). |
| [update](/docs/cli-reference/update) | Переустанавливает конфигурацию адаптера ассистента по написанию кода из текущего общего профиля (псевдоним: `updating`). |
| [uninstall](/docs/cli-reference/uninstall) | Удаляет конфигурацию адаптера ассистента по написанию кода (псевдоним: `uninstalling`). |
| [rollback](/docs/cli-reference/rollback) | Восстанавливает ассистента по написанию кода в состояние, предшествовавшее его записанной установке. |
| [verify](/docs/cli-reference/verify) | Проверяет установку адаптера ассистента по написанию кода. |
| [status](/docs/cli-reference/status) | Сообщает о состоянии установки, проверки и дрейфа для каждого зарегистрированного ассистента по написанию кода. |
| [diff](/docs/cli-reference/diff) | Показывает предпросмотр ожидающих изменений конфигурации для одного ассистента по написанию кода. |
| [harnesses](/docs/cli-reference/harnesses) | Перечисляет и инспектирует зарегистрированные адаптеры ассистента по написанию кода. |
| [profile](/docs/cli-reference/profile) | Управляет общим профилем Apothem. |
| [doctor](/docs/cli-reference/doctor) | Запускает системную диагностику установки Apothem. |
| [completion](/docs/cli-reference/completion) | Выводит загружаемый через source скрипт автодополнения оболочки (bash, zsh, fish, powershell). |

Для slash-команд и обзора CLI более высокого уровня см. справочные страницы
[Обзор CLI](/docs/reference/cli) и [Slash-команды](/docs/reference/commands).
