Интерфейс командной строки `apothem` управляет конфигурациями адаптеров
окружений на основе общего профиля. Каждая страница ниже документирует одну
подкоманду: её краткий синтаксис, параметры, поведение и коды выхода.

Каждая из команд `install`, `update` и `uninstall` также принимает псевдоним в
продолженной форме (`installing`, `updating`, `uninstalling`), идентичный
базовой команде по флагам и поведению. Обновление и удаление через каналы
установки — плагин Claude Code, `npx` и одношаговые скрипты-установщики —
задокументированы в руководствах по установке
[Обновление](/docs/install/updating) и [Удаление](/docs/install/uninstalling),
а не самими псевдонимами.

## Контракт вывода JSON

Каждая команда принимает `--json` (сокращение для `--format json`) и в этом
случае записывает в stdout ровно один документ JSON. Каждый документ начинается
с ключа верхнего уровня `schema_version` — целого числа, которое сегодня
равно `1`:

```json
{"schema_version": 1, "status": "success", "command": "verify", "...": "..."}
```

- **Стабильность.** В пределах одного `schema_version` изменения аддитивны:
  может появиться новый ключ, но ни один ключ не переименовывается и не
  удаляется, и ни одно значение не меняет тип. Любое другое изменение
  увеличивает `schema_version`.
- **Версионированные артефакты.** `profile show --json` выводит сам профиль,
  поэтому его `schema_version` — это версия схемы профиля (сегодня тоже `1`).
- **Одно исключение.** `harnesses list --json` выводит массив JSON (по одному
  объекту на окружение), как и всегда, поэтому у него нет ключа верхнего
  уровня, который нёс бы версию. Обёртывание его в объект сломало бы
  существующие парсеры; пока это не сделает повышение версии, считайте его
  форму соответствующей `schema_version` `1`.
- **Ошибки.** Ожидаемые сбои используют ту же форму документа с
  `"status": "error"` и объектом `error`, несущим `code`, `field`,
  `reason` и `fix`.

## Коды выхода

Каждая команда использует один и тот же небольшой набор кодов выхода; каждая
страница перечисляет те, которые она может вернуть.

| Код | Значение |
|---|---|
| 0 | Успех |
| 1 | Ожидаемый сбой: ошибка проверки, профиля, окружения, проекта или адаптера |
| 2 | Частичный результат: пакетная операция записала или удалила что-то до сбоя (только команды, на странице которых он указан) |
| 64 | Ошибка использования: неизвестный параметр или команда, отсутствующий обязательный параметр или недопустимое значение параметра |

Ошибка использования никогда не затрагивает файловую систему. При `--json`
(или `--format json`) она печатает один документ ошибки с `"code": "cli.usage"`
вместо обычного текста справки по использованию, чтобы автоматизация могла
отличить опечатку во флаге от частичной записи.

Для slash-команд и обзора CLI более высокого уровня см. справочные страницы
[Обзор CLI](/docs/reference/cli) и [Slash-команды](/docs/reference/commands).
