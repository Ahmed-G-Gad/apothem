Перечисляет и показывает зарегистрированные адаптеры окружений.

`harnesses` — группа команд с двумя подкомандами: `list` и `show`.

## Сводка

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## Подкоманды

### `harnesses list`

Перечисляет все зарегистрированные адаптеры окружений.

| Параметр | Описание |
|---|---|
| `--quiet`, `-q` | Подавляет информационный вывод; выводятся только ошибки. |
| `--verbose`, `-v` | Выводит дополнительную диагностику. |
| `--format plain\|json` | Формат вывода (по умолчанию: `plain`). |
| `--json` | Сокращение для `--format json`. |
| `--no-color` | Отключает коды цвета ANSI в выводе. |
| `-h`, `--help` | Показывает справку и завершает работу. |

### `harnesses show NAME`

Показывает сведения о конкретном адаптере окружения. `NAME` — идентификатор
окружения в kebab-case; выполните `apothem harnesses list`, чтобы увидеть
доступные идентификаторы.

| Параметр | Описание |
|---|---|
| `NAME` | Адаптер окружения, сведения о котором нужно показать (обязательный позиционный аргумент). |
| `--quiet`, `-q` | Подавляет информационный вывод; выводятся только ошибки. |
| `--verbose`, `-v` | Выводит дополнительную диагностику. |
| `--format plain\|json` | Формат вывода (по умолчанию: `plain`). |
| `--json` | Сокращение для `--format json`. |
| `--no-color` | Отключает коды цвета ANSI в выводе. |
| `-h`, `--help` | Показывает справку и завершает работу. |

## Примеры

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

Зарегистрированные идентификаторы окружений:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

## Коды выхода

| Код | Значение |
|---|---|
| 0 | Успех |
| 1 | Окружение не найдено (`harnesses show` с неизвестным `NAME`) или ни один адаптер не удалось загрузить или получить от него сведения (`harnesses list`) |
| 2 | Хотя бы один адаптер перечислен, но хотя бы один не смог сообщить сведения (`harnesses list`) |
| 64 | Ошибка использования: неизвестный параметр или команда либо отсутствующее или недопустимое значение параметра. При `--json` ошибка выводится как конверт JSON с кодом `cli.usage`. |
