Мигрирует устаревшее рабочее пространство уровня отдельного ассистента по написанию кода в общий макет `.apothem`.

## Сводка

```
apothem migrate-workspace [--project PATH] [--dry-run]
                          [--quiet|-q] [--verbose|-v]
                          [--format plain|json] [--json] [--no-color]
```

`migrate-workspace` сворачивает устаревший каталог данных уровня отдельного
ассистента по написанию кода (`.apothem/<harness>/...`) и устаревшее дерево
`.plans/` в единый общий рабочий каталог
`.apothem/{plans,memory,learning,contexts}`. Базой служит разрешённый корень
`--project`, если он указан, иначе текущий рабочий каталог (значение по умолчанию,
локальное для проекта).

Память, контексты и хранилища обучения уровня отдельного ассистента по написанию
кода объединяются по id в общее хранилище; сигналы обучения конкатенируются и
дедуплицируются; конфликтующая запись (тот же id, другое тело) пропускается, а не
перезаписывается. Устаревшее дерево `.plans/` перемещается под `.apothem/plans/`.
Каждый потребляемый источник сначала резервируется. Миграция идемпотентна —
повторный запуск на уже мигрированном дереве является операцией без эффекта.

## Параметры

| Параметр | Описание |
|---|---|
| `--project PATH` | Корень проекта для адаптеров с областью проекта, которые материализуются в дерево проекта, а не в каталог конфигурации с областью пользователя. |
| `--dry-run` | Обнаруживает устаревший макет и сообщает, что было бы мигрировано, без записи. |
| `--quiet`, `-q` | Подавляет информационный вывод; выдаются только ошибки. |
| `--verbose`, `-v` | Выводит дополнительный диагностический вывод. |
| `--format plain\|json` | Формат вывода (по умолчанию: `plain`). |
| `--json` | Сокращение для `--format json`. |
| `--no-color` | Отключает коды цвета ANSI в выводе. |
| `-h`, `--help` | Показывает справку и завершает работу. |

## Вывод JSON

Конверт `--json` несёт результат миграции. При завершённой миграции `status`
равен `success`, и полезная нагрузка сообщает счётчики объединённых записей,
было ли перемещено дерево `.plans/`, корень резервной копии и любые пропущенные
конфликты. Вызов `--dry-run` вместо этого сообщает `legacy_layout_detected`.

```json
{
  "command": "migrate-workspace",
  "status": "success",
  "base": "/home/example/project",
  "migrated": true,
  "backup_root": "/home/example/project/.apothem/.backups/01J9Z…",
  "memory_merged": 12,
  "contexts_merged": 4,
  "learning_merged": 7,
  "conflicts": [],
  "plans_moved": true,
  "notes": []
}
```

Когда устаревший макет отсутствует, `migrated` равен `false`, и ничего не
записывается. Конверт `--dry-run` опускает счётчики результата и сообщает только
об обнаружении:

```json
{
  "command": "migrate-workspace",
  "base": "/home/example/project",
  "dry_run": true,
  "legacy_layout_detected": false
}
```

## Примеры

```bash
apothem migrate-workspace
apothem migrate-workspace --project .
apothem migrate-workspace --dry-run --json
```

## Коды выхода

| Код | Значение |
|---|---|
| 0 | Миграция завершена или устаревший макет не найден (мигрировать нечего) |
| 1 | Ожидаемая ошибка — ошибка проверки или корня проекта, либо сбой миграции |
