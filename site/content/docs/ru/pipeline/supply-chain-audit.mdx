**Роль:** Аудитор цепочки поставок
**Позиция в пайплайне:** последовательность аудиторских проверок

Аудит цепочки поставок относительно стандартов SLSA + Sigstore + SBOM.

## Каноническое обращение

```bash
/supply-chain-audit
```

С аргументами:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## Входы

Релиз-пайплайн хост-репозитория

## Выходы

Находки цепочки поставок в `_inputs/supply-chain-audit-findings.md`

## Ниже по потоку

Стадия supply-chain-audit Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз аудита: приём входных данных, проход по осям, сортировку каждой находки, выпуск находок и шлюз валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Предпосылка не выполнена | Зависимая фаза не завершена | Сначала завершите вышестоящую фазу |
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Цель отклонена | В цели нет поверхности релиза | Передайте корень репозитория с .github/workflows/, скриптом релиза или манифестом сборки |

## Примеры

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
