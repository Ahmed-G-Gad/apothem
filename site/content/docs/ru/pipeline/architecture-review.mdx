**Роль:** Рецензент архитектуры
**Позиция в пайплайне:** последовательность аудиторских проверок

Проверка архитектурной целостности относительно артефакта проектирования в `_inputs/design.md`.

## Каноническое обращение

```bash
/architecture-review
```

С аргументами:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Входы

Хост-репозиторий + `_inputs/design.md`

## Выходы

Находки архитектурного обзора в `_inputs/architecture-review-findings.md`

## Ниже по потоку

Стадия рецензирования архитектуры в Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз аудита: приём входных данных, проход трассируемости от проекта к коду, аудит целостности границ слоёв, сканирование связанности между пакетами и выпуск находок с шлюзом валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | Артефакт проектирования `_inputs/design.md` отсутствует | Выполните `/plan-design`, чтобы создать его |

## Примеры

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
