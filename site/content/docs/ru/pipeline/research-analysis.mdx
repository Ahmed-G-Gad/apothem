**Роль:** Главный исследователь (анализ)
**Позиция в конвейере:** середина цепочки

Анализирует исходные данные согласно предзарегистрированному плану — выполняет запланированные статистические тесты, сообщает размеры эффекта с доверительными интервалами (не только p-значения), применяет поправку на множественные сравнения там, где это уместно, выполняет проверки устойчивости / чувствительности и раскрывает каждое отклонение от предрегистрации.

## Каноническое обращение

```bash
/research-analysis
```

С аргументами:

```bash
/research-analysis [path/to/research-suite/]
```

## Входные данные

Исходные данные в естественном для хоста месте, записанном этапом эксперимента, плюс `_inputs/preregistration.md` (замороженный план анализа).

## Выходные данные

`_outputs/analysis.md` (предзарегистрированные тесты с размерами эффекта и ДИ, поправка на множественные сравнения, проверки устойчивости и раскрытые отклонения) + рисунки / таблицы в естественном для хоста месте.

## Ниже по потоку

/research-paper (потребитель ниже по потоку)

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать исходные данные и предрегистрацию.
2. **Проверить Шлюз последовательности** — Подтвердить, что выходные данные эксперимента существуют; иначе остановиться с `Blocked: run /research-experiment first`.
3. **Проанализировать** — Выполнить предзарегистрированные тесты; сообщить размеры эффекта + ДИ; внести поправку на множественные сравнения; выполнить проверки устойчивости / чувствительности.
4. **Раскрыть отклонения** — Зафиксировать каждое отступление от предзарегистрированного плана.
5. **Обновить манифест передачи** — Зафиксировать путь анализа и рисунки / таблицы.
6. **Выпустить анализ** — `_outputs/analysis.md` + рисунки / таблицы.

## Нижняя граница строгости

Стохастические результаты сообщаются как лучшее, среднее, медиана, стандартное отклонение и худшее по повторениям, с кривыми сходимости и графиками распределения. Сравнения используют непараметрические тесты — парный тест знаковых рангов попарно, омнибусный ранговый тест с апостериорной поправкой между методами — сообщаемые с размером эффекта стохастического превосходства и диаграммой критической разности. Результат проходит в статью лишь тогда, когда преодолевает шлюз продвижения: он убедительно и значимо превосходит свои компараторы, а прохождение залогировано в проверяемом журнале выполнения.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /research-experiment first | Нет исходных данных | Запустите `/research-experiment`, чтобы получить данные + журнал |
| p-значение сообщено без размера эффекта | Неполная статистическая отчётность | Сообщите размеры эффекта + доверительные интервалы |
| Нераскрытое отклонение анализа | План отклонился молча | Раскройте отклонение относительно предрегистрации |

## Примеры

```bash
# Проанализировать исходные данные согласно предзарегистрированному плану
/research-analysis path/to/research-suite/
```
