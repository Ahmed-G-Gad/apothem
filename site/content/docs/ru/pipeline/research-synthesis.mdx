**Роль:** Главный исследователь (синтез)
**Позиция в конвейере:** середина цепочки

Согласует собранные источники в карту современного уровня + матрицу литературы и формулирует явный исследовательский пробел, который закрывает работа. Каждое несущее утверждение состязательно проверяется по двум или более независимым источникам, опровергая по умолчанию.

## Каноническое обращение

```bash
/research-synthesis
```

С аргументами:

```bash
/research-synthesis [path/to/research-suite/]
```

## Входные данные

`_inputs/source-ledger.md` (ранжированный, отсеянный индекс источников) плюс извлечения по источникам в каталоге `sources/`.

## Выходные данные

`_inputs/synthesis.md` — карта современного уровня, матрица литературы, реестр спорных выводов и явная формулировка пробела в одном предложении.

## Ниже по потоку

/research-proposal (потребитель ниже по потоку)

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать реестр источников и извлечения по источникам.
2. **Проверить Шлюз последовательности** — Подтвердить, что реестр источников существует; иначе остановиться с `Blocked: run /research-sources first`.
3. **Синтезировать** — Построить карту современного уровня + матрицу литературы; согласовать совпадения и противоречия; сформулировать явный пробел.
4. **Состязательно проверить** — Каждое несущее утверждение опровергается по умолчанию по двум или более независимым источникам.
5. **Обновить манифест передачи** — Зафиксировать путь синтеза и реестр спорных утверждений.
6. **Выпустить синтез** — `_inputs/synthesis.md`.

## Нижняя граница строгости

Прежде чем формулировка пробела будет финализирована, синтез согласует свою терминологию, выводы и рекомендации с родственными смежными корпусами (межкорпусная согласованность); конфликт фиксируется в реестре спорных выводов и никогда не согласуется молча. Пробел должен сводиться к отчётливому, экономному вкладу — не к тому, что уже закрыт подтверждённым утверждением, и не разложимому на перекрывающиеся неотчётливые элементы.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /research-sources first | Нет реестра источников | Запустите `/research-sources`, чтобы получить `_inputs/source-ledger.md` |
| Утверждение остаётся без ≥2 источников | Недостаточное подтверждение | Пометьте как спорное или непроверяемое; не утверждайте |
| Нет явной формулировки пробела | Синтезу не хватает цели | Заново выведите пробел в одном предложении, который закрывает исследование |

## Примеры

```bash
# Синтезировать собранные источники в карту современного уровня + пробел
/research-synthesis path/to/research-suite/
```
