**Роль:** Аудитор
**Позиция в конвейере:** последовательность аудиторских проверок

Межфайловый криминалистический аудит кода на уровне корпуса репозитория.

## Каноническое обращение

```bash
/code-audit
```

С аргументами:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## Входы

Хост-репозиторий с утверждённой структурой исходного кода, базовым уровнем покрытия тестами и (на уровне SHARED и выше) проходящим шлюзом CI

## Выходы

Находки уровня корпуса в `_inputs/code-audit-findings.md`

## Ниже по течению

Этап криминалистического аудита кода последовательности аудита и обзора

## Фазы рабочего процесса

Команда выполняет шесть фаз криминалистического аудита: приём входных данных, проход зависимостей между файлами, аудит подсказок типов и покрытия, выявление мёртвого и дублирующегося кода, аудит архитектурной целостности и выпуск находок с шлюзом валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | Нет запуска шлюза CI и базового уровня покрытия тестами на уровне SHARED и выше | Сначала запустите CI-конвейер хоста, затем перезапустите |

## Примеры

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
