**Роль:** Аудитор
**Позиция в конвейере:** крепость

Межфайловый криминалистический аудит кода на уровне корпуса репозитория.

## Каноническое обращение

```bash
/code-audit
```

С аргументами:

```bash
/code-audit [path/to/plan-suite/] [phase-id] [--dry-run]
```

## Входы

Хост-репозиторий в любом состоянии жизненного цикла

## Выходы

Находки на уровне корпуса + REPORT.md

## Ниже по течению

Этап криминалистического аудита кода последовательности аудита и обзора

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/plan`:

1. **Загрузить контекст** — Прочитать набор планов, правила и Контракт возобновления.
2. **Проверить предварительные условия** — Подтвердить, что зависимые фазы завершены.
3. **Выполнить задачи** — Выполнить миссию команды.
4. **Проверить выходы** — Подтвердить, что все объявленные выходы существуют и проходят шлюзы качества.
5. **Обновить PROGRESS.md** — Записать проверенные выходы в Реестр выходов фаз.
6. **Выпустить REPORT.md** — Записано доказательство выпуска шлюза предвыпуска.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Предварительное условие не выполнено | Зависимая фаза не завершена | Сначала завершите вышестоящую фазу |
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | Файл набора планов отсутствует | Запустите `/plan-generate`, чтобы его создать |

## Примеры

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a named plan suite
/code-audit path/to/plan-suite/
```
