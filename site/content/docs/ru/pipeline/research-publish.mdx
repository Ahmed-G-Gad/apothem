**Роль:** Главный исследователь (публикация)
**Позиция в конвейере:** середина цепочки

Форматирует статью по шаблону площадки и собирает пакет для подачи — дополнительные материалы, заявление о доступности данных / кода, сопроводительное письмо, заявления об этике и конфликте интересов — плюс план препринта / архивирования с DOI и контрольный список подачи. Оператор подаёт пакет; конечный преемник — `/research-disseminate`, который доносит опубликованную работу до её аудитории.

## Каноническое обращение

```bash
/research-publish
```

С аргументами:

```bash
/research-publish [path/to/research-suite/]
```

## Входные данные

Поставляемая статья и `_outputs/review-report.md` (правки рецензирования).

## Выходные данные

Отформатированный по площадке пакет для подачи в естественном для хоста месте (отформатированная рукопись + дополнительные материалы + заявление о доступности данных / кода + сопроводительное письмо + заявления об этике / конфликте интересов) + `_outputs/publication-record.md` + контрольный список подачи.

## Ниже по потоку

/research-disseminate (потребитель ниже по потоку) — подачу выполняет оператор, затем `/research-disseminate` доносит опубликованную работу до её аудитории. Когда площадка возвращает правки, снова запустите `/research-review` против исправленной статьи перед пересборкой пакета.

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать статью и отчёт о рецензировании.
2. **Проверить Шлюз последовательности** — Подтвердить, что `_outputs/review-report.md` существует; иначе остановиться с `Blocked: run /research-review first`.
3. **Отформатировать и упаковать** — Применить шаблон площадки; собрать дополнительные материалы, доступность данных/кода, сопроводительное письмо, заявления об этике / конфликте интересов.
4. **Спланировать препринт / архивирование** — Зафиксировать план препринта и DOI; составить контрольный список подачи.
5. **Обновить манифест передачи** — Зафиксировать пакет для подачи и запись о публикации.
6. **Выпустить пакет** — Отформатированный по площадке пакет для подачи + `_outputs/publication-record.md`.

## Нижняя граница строгости

Форматирование чтит поэтапное раскрытие: для площадки с двойным слепым рецензированием идентичность автора, учреждения и системы вынесена в отдельно подаваемые метаданные и восстанавливается лишь на назначенном этапе готовой к печати версии. Архивный депозит несёт масштабированный под площадку пакет доказательств воспроизводимости (данные, код, закреплённое окружение, семена, журнал оборудования, результаты по экземплярам и рисунки).

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /research-review first | Нет отчёта о рецензировании | Запустите `/research-review`, чтобы получить `_outputs/review-report.md` |
| Неустранённая правка HIGH | Замечание рецензирования пропущено | Устраните правку и снова запустите `/research-review` |
| Отсутствует доступность данных/кода | Поверхность воспроизводимости отсутствует | Добавьте заявление о доступности данных / кода перед подачей |

## Примеры

```bash
# Собрать пакет для подачи на площадку
/research-publish path/to/research-suite/
```
