**Роль:** Аудитор
**Позиция в пайплайне:** средняя

Криминалистический аудит существующего набора плана — верность прозы, согласованность, качество.

## Каноническое обращение

```bash
/plan-review
```

С аргументами:

```bash
/plan-review [path/to/plan-suite/] [--focus AREA] [--dry-run]
```

## Входы

Сгенерированный набор плана + `_inputs/handoff-manifest.yml` из `/plan-generate`.

## Выходы

Оценочные карты рецензирования в `PLAN-NOTES.md` (`## Review Scorecards`), Сводка рецензирования в `PROGRESS.md`, карты влияния правок по находкам в `PLAN-NOTES.md` (объёмные долговременные отчёты — в `_outputs/`) и дополненный `_inputs/handoff-manifest.yml`, несущий вердикт рецензирования.

## Ниже по потоку

`/plan-design` (условно — только для наборов с архитектурой), затем `/plan-execute`; для наборов без архитектуры `/plan-execute` потребляет оценочные карты рецензирования напрямую, чтобы шлюзовать исполнение на уровне SHARED+.

## Фазы рабочего процесса

Команда выполняет криминалистический, слепой, построчный аудит, затем уточняет через интерактивные вопросы и ответы:

1. **Загрузить контекст** — Прочитать каждый файл набора плана (`phases/**/PHASE.md`, инфраструктурные файлы, отчёты) и вышестоящий Манифест передачи; отказать с `Blocked: run /plan-generate first`, когда набор отсутствует.
2. **Аудит** — Обмести измерения (верность прозы, внутренняя согласованность, полнота, качество, риск, стандарты, домен, архитектура, творческое качество) под Мандатом слепого рецензирования.
3. **Сортировать находки** — Распорядиться каждой находкой (принять · доработать · отклонить · отложить) через канал структурированного запроса с подсчётом серьёзности по находкам.
4. **Запустить шлюз пред-эмиссии** — Прогнать пятнадцатистрочный шлюз против отчёта о рецензии и обновлённых оценочных карт; отказ блокирует продвижение.
5. **Выдать рецензию** — Записать Оценочные карты рецензирования в `PLAN-NOTES.md`, Сводку рецензирования в `PROGRESS.md` и дополненный Манифест передачи.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /plan-generate first | Нет сгенерированного набора | Выполните `/plan-generate`, чтобы создать набор, который аудирует эта команда |
| Остаются открытые находки | Аудит выявил неустранённые дефекты | Распорядитесь каждой находкой (принять · доработать · отклонить · отложить) до итогового вердикта |
| Оценочная карта FAIL | Измерение опускается ниже порога CONDITIONAL | Устраните проблемное измерение и перерецензируйте |

## Примеры

```bash
# Сухой прогон для предпросмотра области аудита
/plan-review --dry-run

# Аудит именованного набора плана с фокусом на одной области
/plan-review path/to/plan-suite/ --focus architecture
```
