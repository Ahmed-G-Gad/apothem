**Роль:** Кузница
**Позиция в пайплайне:** голова

Доводит свободную прозу или сырые заметки до спецификации `_spec/spec.md` уровня spec, готовой для `/plan-generate`.

## Каноническое обращение

```bash
/plan-spec
```

С аргументами:

```bash
/plan-spec [path/to/prose-source] [--suite-name NAME] [--refine-existing] [--standalone] [--quick SLUG [--tag TAG]]
```

## Входы

Свободная проза, сырые заметки или ad-hoc-требования (предоставленные оператором инлайн или в виде пути).

## Выходы

`_spec/spec.md` (продвинутая спецификация) + `_inputs/handoff-manifest.yml`. `--quick` вместо этого записывает единственный облегчённый файл плана, локальный для проекта, по пути `<project-root>/.apothem/plans/<YYYY-MM-DD>--<kebab-slug>.md`.

## Ниже по потоку

/plan-generate (потребитель ниже по потоку)

## Фазы рабочего процесса

Кузница выполняет шесть фаз преобразования (спецификация продвигается из `_inputs/forge.md` в `_spec/spec.md` на G4):

1. **Обнаружение и извлечение** — Прочитать прозу / заметки и извлечь каждое требование, решение и ограничение.
2. **Тщательное рассмотрение** — Обдумать каждую поверхность; вывести каждое противоречие через канал структурированного запроса.
3. **Отображение потенции** — Сопоставить каждое требование с его рычагом ниже по потоку.
4. **Проверка сохранения** — Прогнать пятнадцатистрочный шлюз пред-эмиссии (G4) против кандидата спецификации перед продвижением.
5. **Применение экспертизы** — Применить доменную экспертизу; зафиксировать находки пробелов экспертизы.
6. **Зачистка разрешения вопросов** — Разрешить каждый открытый запрос по шлюзам G0–G5, затем выдать `_spec/spec.md` плюс Манифест передачи.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Отсутствует входная проза | Не предоставлена проза / заметки | Предоставьте свободную прозу инлайн или в виде пути |
| Неразрешённое противоречие | Проза несёт конфликтующие требования | Остановитесь на G3 (Перед поправкой); разрешите через структурированный запрос, никогда молча |
| Спецификация не проходит шлюз | Строка пред-эмиссии падает на G4 | Исправьте проблемную строку перед продвижением из `_inputs/forge.md` |

## Примеры

```bash
# Выковать сырые заметки в спецификацию уровня spec
/plan-spec ~/notes/feature.md --suite-name my-feature

# Облегчённый файл плана, локальный для проекта (минует элиситацию Кузницы)
/plan-spec --quick my-feature
```
