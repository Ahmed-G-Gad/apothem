**Роль:** Главный исследователь (теоретическое обоснование)
**Позиция в конвейере:** середина цепочки

Строит фундаментальный концептуальный и теоретический каркас для сформулированного исследовательского вопроса — априорное обоснование, к которому восходят этапы систематического поиска и синтеза. Каждый конструкт укоренён в первичной теории, а каждое теоретизированное отношение сформулировано в опровержимой форме.

## Каноническая команда

```bash
/research-theory
```

С аргументами:

```bash
/research-theory [--suite-name NAME] [--override] [--framework NAME]
```

## Входные данные

`_spec/research-spec.md` набора (сформулированный, фальсифицируемый набор вопросов, созданный `/research-spec`).

## Выходные данные

`_inputs/theory.md` (концептуальный / теоретический каркас, теория изменений / логическая модель, конструкты с их операциональными определениями и диаграмма концептуальной модели).

## Ниже по потоку

/research-sources (потребитель ниже по потоку — систематический поиск возводит свои критерии включения к этим конструктам).

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать `_spec/research-spec.md`, правила и любое существующее состояние набора.
2. **Очертить концептуальную модель** — Определить конструкты и их операциональные определения; укоренить каждый в первичной теории.
3. **Начертить теорию изменений** — Построить логическую модель, связывающую конструкты с ожидаемыми результатами; сформулировать каждое отношение в опровержимой форме.
4. **Изобразить модель в виде диаграммы** — Выпустить диаграмму концептуальной модели, на которую ссылаются последующие этапы.
5. **Проверить выходные данные** — Подтвердить, что каждый конструкт укоренён в теории и каждое отношение опровержимо; разрешить неоднозначность через канал структурированного запроса.
6. **Выпустить каркас** — `_inputs/theory.md` плюс обновлённый манифест передачи.

## Режимы сбоев

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| У конструкта нет операционального определения | Понятие сформулировано абстрактно | Определите конструкт в измеримых терминах; сошлитесь на первичную теорию |
| Теоретизированное отношение неопровержимо | Отношение сформулировано как трюизм | Переформулируйте отношение как фальсифицируемое утверждение |
| Отсутствует входная спецификация | `/research-spec` ещё не выполнен | Сначала выполните `/research-spec`, чтобы сформулировать вопрос |

## Примеры

```bash
# Построить теоретический каркас для сформулированного вопроса
/research-theory --suite-name retrieval-latency

# Привязаться к именованному теоретическому каркасу
/research-theory --framework "information foraging theory"
```
