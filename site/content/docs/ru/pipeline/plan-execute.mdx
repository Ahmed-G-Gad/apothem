**Роль:** Исполнитель
**Позиция в пайплайне:** терминальная

Выполняет конкретную фазу из Master Plan Suite с проверкой соответствия.

## Каноническое обращение

```bash
/plan-execute
```

С аргументами:

```bash
/plan-execute [path/to/plan-suite/] [phase-id] [--dry-run]
```

## Входы

Сгенерированный + отрецензированный набор плана; отрецензированный `_inputs/handoff-manifest.yml`

## Выходы

Файлы REPORT.md по фазам, артефакты базы кода, COMPLETION.md

## Ниже по потоку

`/fortress` упрочняет выполненную работу до состояния, закрытого релизным шлюзом, одним вызовом (обнаружение, проверка, устранение, повторный аудит, шлюз). По умолчанию он приостанавливается для подтверждения на границе каждого раунда; `--autonomous` выполняет раунды без приостановок. `/code-review` — каноническая точка входа в последовательность аудиторских проверок из одиннадцати команд, которая проходит цепочку по одному этапу за раз. `/plan-execute` — терминальный этап конвейера *плана*; когда финальная фаза завершена, собранный код передаётся в последовательность аудиторских проверок для рецензирования.

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу пайплайна `/plan`:

1. **Загрузить контекст** — Читает набор планов, правила и Контракт возобновления.
2. **Проверить предпосылки** — Подтверждает, что зависимые фазы завершены.
3. **Выполнить задачи** — Исполняет миссию команды.
4. **Проверить выходы** — Подтверждает, что все объявленные выходы существуют и проходят шлюзы качества.
5. **Выпустить REPORT.md** — Записывается результат шлюза предэмиссии.
6. **Обновить PROGRESS.md** — Записывает проверенные выходы в Реестр выходов фазы.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Предпосылка не выполнена | Зависимая фаза не завершена | Сначала завершите фазу выше по потоку |
| Ворота качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | Файл набора плана отсутствует | Выполните `/plan-generate`, чтобы создать его |

## Примеры

```bash
# Dry-run to preview what would happen
/plan-execute --dry-run

# Execute against a named plan suite
/plan-execute path/to/plan-suite/
```
