**Роль:** Аудитор зависимостей
**Позиция в пайплайне:** крепость

Проход аудита по каждой зависимости (прямые + транзитивные) на лицензию, CVE и свежесть.

## Каноническое обращение

```bash
/dependency-audit
```

С аргументами:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## Входы

Манифесты зависимостей хост-репозитория

## Выходы

Находки по зависимостям в `_inputs/dependency-audit-findings.md`

## Ниже по потоку

Стадия dependency-audit Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз: приём входных данных, проход по зависимостям, сортировку каждой находки, выпуск находок и шлюз валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | В корне репозитория не находится ни один манифест зависимостей | Передайте корень репозитория, содержащий манифест зависимостей |

## Примеры

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
