**Роль:** Генератор
**Позиция в пайплайне:** средняя

Генерирует полный Master Plan Suite из написанного `_spec/spec.md`.

## Каноническое обращение

```bash
/plan-generate
```

С аргументами:

```bash
/plan-generate [path/to/prose.md] [--mode NEW|OVERHAUL] [--seriousness LEVEL] [--context CONTEXT] [--mission MISSION] [--domain DOMAIN] [--dry-run]
```

## Входы

Написанные `_spec/spec.md` + `_inputs/handoff-manifest.yml` из `/plan-spec` (одна лишь проза отклоняется: выполните `/plan-spec`, чтобы написать `_spec/spec.md`; `--override` обходит шлюз и записывает замечание в PLAN-NOTES.md).

## Выходы

`PREAMBLE.md`, `MASTER-PLAN.md`, `PROGRESS.md`, `PLAN-NOTES.md` и пофазовые файлы `phases/**/PHASE.md`, плюс дополненный `_inputs/handoff-manifest.yml`.

## Ниже по потоку

/plan-review (далее по потоку); `/plan-execute` — только после появления карточек оценки ревью (или с `--override`)

## Фазы рабочего процесса

Команда генерирует полный Master Plan Suite из написанной спецификации:

1. **Загрузить требования** — Прочитать `_spec/spec.md` и вышестоящий Манифест передачи; отказать с `Blocked: run /plan-spec first`, когда спецификация отсутствует.
2. **Обнаружить** — Выполнить масштабируемое по серьёзности обнаружение с Пятью когнитивными фильтрами; разрешить каждый пробел в авторитетных данных через канал структурированного запроса.
3. **Декомпозировать** — Разбить работу на ацикличный граф фаз с явным порядком зависимостей.
4. **Выдать набор планов** — Написать `PREAMBLE.md`, `MASTER-PLAN.md`, `PROGRESS.md`, `PLAN-NOTES.md` и каждый `phases/NN-topic/PHASE.md`.
5. **Запустить шлюз пред-эмиссии** — Прогнать пятнадцатистрочную зачистку против каждого выданного артефакта; отказ блокирует одобрение пользователем до устранения.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /plan-spec first | Нет написанного `_spec/spec.md` | Выполните `/plan-spec`, чтобы написать спецификацию и выдать Манифест |
| Генерация против файла `_inputs/` | Спецификация всё ещё в процессе элиситации | Сначала продвиньте `_inputs/forge.md` в `_spec/spec.md` через `/plan-spec` |
| Строка пред-эмиссии падает | Выданный артефакт не проходит шлюз | Исправьте проблемную строку перед одобрением пользователем |

## Примеры

```bash
# Сухой прогон для предпросмотра сгенерированного графа фаз
/plan-generate --dry-run

# Сгенерировать набор из написанной прозы
/plan-generate path/to/prose.md --mode NEW
```
