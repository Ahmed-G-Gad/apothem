**Роль:** Аудитор доступности
**Позиция в пайплайне:** крепость

Аудит доступности относительно WCAG 2.2 AA для каждой отрендеренной страницы.

## Каноническое обращение

```bash
/a11y-audit
```

С аргументами:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## Входы

Развёрнутый или обслуживаемый локально сайт проекта

## Выходы

Находки по доступности (A11y) в `_inputs/a11y-audit-findings.md`

## Ниже по потоку

Стадия аудита доступности в Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз аудита: приём входных данных, аудит по страницам, сортировку каждой находки, выпуск находок и шлюз валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | Путь к сайту или URL не разрешается | Передайте собранный каталог сайта или доступный URL |

## Примеры

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
