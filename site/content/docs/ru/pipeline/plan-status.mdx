**Роль:** Репортёр
**Позиция в пайплайне:** только чтение

Репортёр прогресса набора плана только для чтения — выдаёт статус, не изменяя ни одного файла.

## Каноническое обращение

```bash
/plan-status
```

С аргументами:

```bash
/plan-status [path/to/plan-suite/] [--verbose]
```

## Входы

Любой набор плана в любом состоянии жизненного цикла — читает `PROGRESS.md`, `PLAN-NOTES.md`, `MASTER-PLAN.md` и отчёты в `phases/`.

## Выходы

Стратегический отчёт о статусе в выходной поток оператора. Эта команда работает только для чтения — она не создаёт и не изменяет ни одного файла.

## Ниже по потоку

Используется автономно для инспекции прогресса — ортогонально каноническому порядку, вызывается только для чтения в любой момент.

## Фазы рабочего процесса

Команда работает только для чтения — она читает файлы отслеживания набора и составляет отчёт; она ничего не пишет:

1. **Загрузить контекст** — Прочитать `PROGRESS.md`, `PLAN-NOTES.md`, `MASTER-PLAN.md` и просканировать `phases/` на наличие существующих отчётов.
2. **Оценить статус** — Обозреть измерения задач / фаз / артефактов и прочитать Контракт возобновления.
3. **Выдать отчёт о статусе** — Представить статус завершения, трекер фаз и стратегический анализ напрямую оператору.
4. **Точечная проверка** — С `--verbose` оценить состояние набора и привести доказательства точечной проверки (markdown-ссылки, диапазоны строк, SHA коммитов) против существующих файлов, ничего не изменяя.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Отсутствует обязательный файл отслеживания | Набор плана неполный | Обозначить пробел как находку; выполнить `/plan-generate`, чтобы создать набор |
| Некорректный файл отслеживания | Раздел усечён или непарсируем | Назвать отсутствие / противоречие в отчёте; ремонт направляется в команды с записью |
| Поле отсутствует или противоречиво между файлами | Дрейф отслеживания | Сообщить о противоречии явно; не синтезировать отсутствующее значение |

## Примеры

```bash
# Отчёт о самом недавнем наборе плана
/plan-status

# Подробная оценка состояния для именованного набора плана
/plan-status path/to/plan-suite/ --verbose
```
