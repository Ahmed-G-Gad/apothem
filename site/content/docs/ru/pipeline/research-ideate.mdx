**Роль:** Главный исследователь (формулирование задачи)
**Позиция в конвейере:** головная

Формулирует пространство задачи с нуля — сканирование возможностей и пробелов, сканирование опровергнутых ранее гипотез и генерация кандидатных исследовательских вопросов с ранжированием — входная стадия конвейера `/research`. Каждый кандидат обрамляется относительно априорного теоретического якоря, опирается на предшествующие работы и формулируется в фальсифицируемой форме, готовый для `/research-spec`.

## Канонический вызов

```bash
/research-ideate
```

С аргументами:

```bash
/research-ideate [path/to/domain-notes] [--suite-name NAME] [--override] [--domain NAME]
```

## Входы

Доменное зерно — доменные заметки в свободной форме (предоставленные оператором встроенно или в виде пути), либо просто имя `--domain` при старте с нуля.

## Выходы

`_inputs/ideation.md` (обрамлённое пространство задачи, сканирование возможностей и пробелов, сканирование опровергнутых ранее гипотез и ранжированный список кандидатных вопросов) плюс Манифест передачи в папке исследовательского набора.

## Ниже по потоку

/research-spec (нижестоящий потребитель — обрамляет выбранного кандидата в фальсифицируемую спецификацию).

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать доменное зерно, правила и любое существующее состояние набора.
2. **Просканировать пространство возможностей и пробелов** — Составить карту того, что изучено, что оспаривается и что остаётся нерешённым в домене.
3. **Просканировать опровергнутые ранее гипотезы** — Выявить гипотезы, уже опровергнутые предшествующими работами, чтобы список не проходил повторно по уже решённой почве.
4. **Сгенерировать и ранжировать кандидатов** — Произвести кандидатные исследовательские вопросы, каждый из которых сформулирован в фальсифицируемой форме, ранжированные по решаемости и значимости.
5. **Проверить выходы** — Подтвердить, что каждый кандидат опирается на первичные предшествующие работы и опровергаем; разрешить каждую неоднозначность через канал структурированных запросов.
6. **Выпустить список идей** — `_inputs/ideation.md` плюс манифест передачи.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Нет фальсифицируемого кандидата | Доменное зерно слишком широкое или чисто описательное | Сузить домен через структурированный запрос; переобрамить кандидатов как опровергаемые вопросы |
| Кандидат пересказывает опровергнутую ранее гипотезу | Сканирование предшествующих работ пропущено | Запустить сканирование опровергнутых ранее гипотез; отбросить или переобрамить перекрывающегося кандидата |
| Отсутствует доменное зерно | Не предоставлены заметки или `--domain` | Предоставить доменные заметки встроенно / в виде пути либо передать `--domain NAME` |

## Примеры

```bash
# Просканировать домен и сгенерировать ранжированные кандидатные вопросы
/research-ideate ~/notes/retrieval-systems.md --suite-name retrieval-latency

# Начать с простого имени домена
/research-ideate --domain "vector-index recall under drift"
```
