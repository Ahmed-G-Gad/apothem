**Роль:** Главный исследователь (выполнение)
**Позиция в конвейере:** середина цепочки

Выполняет спроектированное исследование или эксперимент и фиксирует сырые данные с полным происхождением. Гарантирует воспроизводимость: записывает окружение, семя, журнал протокола и закреплённые версии, чтобы независимая сторона могла повторить запуск.

## Каноническая команда

```bash
/research-experiment
```

С аргументами:

```bash
/research-experiment [path/to/research-suite/]
```

## Входные данные

`_inputs/study-design.md` (проект) и `_inputs/preregistration.md` (зафиксированный план анализа).

## Выходные данные

`_outputs/experiment-log.md` (трасса протокола с временными метками), сырые данные в естественном для хоста месте и `_outputs/reproducibility-manifest.md` (окружение, семя, протокол, закреплённые версии).

## Ниже по потоку

/research-analysis (потребитель ниже по потоку)

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать проект исследования и предварительную регистрацию.
2. **Проверить шлюз последовательности** — Подтвердить, что `_inputs/study-design.md` существует; иначе остановиться с `Blocked: run /research-design first`.
3. **Выполнить и записать** — Выполнить протокол; зафиксировать сырые данные с происхождением; записать трассу протокола с временными метками.
4. **Зафиксировать воспроизводимость** — Записать окружение, семя, протокол и закреплённые версии.
5. **Обновить манифест передачи** — Записать расположение данных и манифест воспроизводимости.
6. **Выпустить журнал** — `_outputs/experiment-log.md` + сырые данные + `_outputs/reproducibility-manifest.md`.

## Нижняя граница строгости

Выполнение запускает пилотный проход для калибровки бюджетов и диапазонов, затем полное сравнение по заявленному плану использования вычислений (распределение ядер, потолки памяти, безопасное распараллеливание независимых повторений). Каждый стохастический метод выполняет свой предрегистрированный режим повторений с записанными семенами и залогированным оборудованием. Доступен подключаемый, по умолчанию выключенный автономный цикл эксперимента: против замороженной оснастки он предлагает изменение единственной изменяемой цели, запускает его при фиксированном бюджете, сохраняет его лишь тогда, когда оно превосходит действующего лидера, и журналирует каждую попытку.

## Режимы сбоев

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /research-design first | Нет проекта исследования | Выполните `/research-design`, чтобы создать `_inputs/study-design.md` |
| Запуск не воспроизводим | Отсутствует запись семени / окружения | Запишите полный манифест воспроизводимости перед продолжением |
| Отклонение от протокола не задокументировано | Изменение в ходе запуска не записано | Запишите отклонение в журнале эксперимента; раскройте его при анализе |

## Примеры

```bash
# Выполнить спроектированное исследование и зафиксировать воспроизводимые сырые данные
/research-experiment path/to/research-suite/
```
