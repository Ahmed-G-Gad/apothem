**Роль:** Главный исследователь (написание)
**Положение в конвейере:** в середине цепочки

Собирает черновик статьи высшего уровня на основе синтеза, проекта и анализа — аннотация, введение, обзор связанных работ, метод, результаты, обсуждение, ограничения, заключение, список литературы. Каждая ссылка проверяется на разрешимость к реальному источнику; никаких фантомных ссылок.

## Каноническая команда

```bash
/research-paper
```

С аргументами:

```bash
/research-paper [path/to/research-suite/]
```

## Входные данные

`_inputs/synthesis.md` (карта SOTA + пробел), `_inputs/study-design.md` (метод) и `_outputs/analysis.md` (результаты).

## Выходные данные

Артефакт статьи в естественном для хоста месте (`paper/`) — аннотация, введение, обзор связанных работ, метод, результаты, обсуждение, ограничения, заключение, список литературы.

## Ниже по потоку

/research-review (потребитель ниже по потоку)

## Фазы рабочего процесса

Команда следует стандартному рабочему процессу конвейера `/research`:

1. **Загрузить контекст** — Прочитать синтез, проект исследования и анализ.
2. **Проверить шлюз последовательности** — Подтвердить, что `_outputs/analysis.md` существует; иначе остановиться с `Blocked: run /research-analysis first`.
3. **Собрать черновик** — Составить от аннотации до заключения; введение и обзор связанных работ опираются на синтез, метод — на проект, результаты — на анализ.
4. **Проверить ссылки** — Каждая ссылка разрешается к реальному источнику.
5. **Обновить манифест передачи** — Записать путь к артефакту статьи.
6. **Выпустить статью** — рукопись в естественном для хоста месте `paper/`.

## Нижняя граница строгости

При площадке с двойным слепым рецензированием рукопись несёт лишь то, что допускает политика анонимности: автор, учреждение, финансирование и изучаемая система описываются на естественном доменном языке без их именования, отложенные до отдельно подаваемых метаданных для назначенного этапа деанонимизации. Глубина отчётности о воспроизводимости и статистике масштабируется под амбицию целевой площадки.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Blocked: run /research-analysis first | Нет анализа | Запустите `/research-analysis`, чтобы получить `_outputs/analysis.md` |
| Фантомная ссылка | Ссылка не разрешается | Удалите или исправьте ссылку; никогда не выдумывайте источник |
| Завышенные результаты | Обсуждение выходит за рамки анализа | Ограничьте утверждения проанализированными размерами эффекта + ДИ |

## Примеры

```bash
# Собрать черновик статьи из синтеза + проекта + анализа
/research-paper path/to/research-suite/
```
