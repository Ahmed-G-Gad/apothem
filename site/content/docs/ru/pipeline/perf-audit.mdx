**Роль:** Аудитор производительности
**Позиция в пайплайне:** последовательность аудиторских проверок

Проводит аудит по бюджетам производительности для каждого класса (среда выполнения хуков, verify-ecosystem, шлюз соответствия, тесты, делегированные исполнители, shell, lint) методом USE.

## Каноническое обращение

```bash
/perf-audit
```

С аргументами:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## Входы

Репозиторий хоста, содержащий `hooks/`, `src/apothem/benchmarks/`, `tests/` и заглушки начальной загрузки хуков `hooks/lib/bootstrap.{sh,ps1}`

## Выходы

Находки по производительности в `_inputs/perf-audit-findings.md`

## Ниже по потоку

Стадия аудита производительности в Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз аудита: приём входных данных, обнаружение бюджетов по классам, выполнение бенчмарков, выявление горячих путей методом USE и выпуск находок с шлюзом валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | В репозитории нет `src/apothem/benchmarks/` | Добавьте драйверы бенчмарков и перезапустите; команда не запустится, пока их нет |

## Примеры

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
