**Роль:** Рецензент документации
**Позиция в пайплайне:** крепость

Проход обзора документации относительно соглашений по прозе и стандартов качества из десяти измерений.

## Каноническое обращение

```bash
/docs-review
```

С аргументами:

```bash
/docs-review [path/to/repo/ or path/to/docs-source/] [--focus FILE_OR_DIR] [--dry-run]
```

## Входы

Поверхность документации хост-репозитория

## Выходы

Находки по документации в `_inputs/docs-review-findings.md`

## Ниже по потоку

Стадия обзора документации Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз: приём входных данных, проход по страницам, сортировку каждой находки, выпуск находок и шлюз валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | По этому пути не доступно ни одного файла документации | Передайте корень репозитория или каталог с исходниками документации, содержащий страницы Markdown |

## Примеры

```bash
# Dry-run to preview what would happen
/docs-review --dry-run

# Execute against a repository root
/docs-review path/to/repo/
```
