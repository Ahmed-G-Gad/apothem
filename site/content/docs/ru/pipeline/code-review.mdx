**Роль:** Рецензент
**Позиция в пайплайне:** крепость

Управляемый оператором проход обзора качества кода по каждому файлу через src/, scripts/ и tools/.

## Каноническое обращение

```bash
/code-review
```

С аргументами:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Входы

Хост-репозиторий в любом состоянии жизненного цикла

## Выходы

Находки по каждому файлу в `_inputs/code-review-findings.md`

## Ниже по потоку

Стадия построчного обзора Последовательности рецензирования аудита

## Фазы рабочего процесса

Команда выполняет пять фаз: приём входных данных, проход по файлам, сортировку каждой находки, выпуск находок и шлюз валидации.

## Режимы отказа

| Симптом | Причина | Восстановление |
|---------|-------|----------|
| Шлюз качества FAIL | Выход не соответствует стандартам | Исправьте выход и перезапустите |
| Отсутствует входной файл | В репозитории нет ни `src/`, ни `scripts/`, ни `tools/` | Передайте корень репозитория, в котором есть хотя бы один из них |

## Примеры

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
