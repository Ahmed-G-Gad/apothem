Этот раздел документирует внутреннее управление качеством проекта: реестры
мандатов, определяющие, что должен удовлетворять каждый выпускаемый артефакт,
проверку, контролирующую артефакты перед их отправкой, категории запросов,
разделяющие то, что инструмент может решить, от того, о чём он должен спросить, и
политики, управляющие релизами, значками и позиционированием проекта.

Эти страницы являются нормативными для сопровождающих и для автоматических
проверок в репозитории. Руководства по повседневному использованию находятся в
разделе [Руководства](/docs/usage), а схемы и соглашения, которые они цитируют, —
в разделе [Справочник](/docs/reference).

## Страницы

| Страница | Описание |
|------|-------------|
| [Сквозные мандаты](/docs/governance/cross-cutting-mandates) | Внутренний для экосистемы реестр мандатов (CM-1–CM-28), управляющий всеми взаимодействиями и операциями конвейера. |
| [Реестр внешнего соответствия](/docs/governance/outward-conformity-registry) | Реестр из пятнадцати мандатов (M1–M15), которому должен удовлетворять каждый артефакт, созданный в проекте-хосте. |
| [Реестр проверки перед выпуском](/docs/governance/pre-emission-gate-registry) | Обязательная пятнадцатистолбцовая проверка соответствия, выполняемая перед любым выпуском значимого масштаба. |
| [Реестр авторитетного запроса](/docs/governance/authoritative-inquiry-registry) | Обязательные категории запросов и исключения для автоматических решений: что спрашивается, а что решается. |
| [Политика значков](/docs/governance/badge-policy) | Источники динамических и статических значков для README и то, как каждый значок остаётся правдивым. |
