> **Канонический реестр шлюза предэмиссии из пятнадцати пунктов.** Этот документ содержит полную таблицу шлюза из пятнадцати пунктов и YAML-блок схемы результата шлюза; содержательные таблица и схема живут здесь, операционализированные `src/apothem/rules/pre-emission-gate.md`.

Перед любой эмиссией артефакта значимого масштаба (по порогу тривиального и нетривиального в `site/content/docs/governance/outward-conformity-registry.mdx` §1) запустите шлюз предэмиссии из пятнадцати пунктов. Механизируйте проверку через хуки PreToolUse там, где это возможно (механические grep в `src/apothem/conformity/*-grep.py`, оркеструемые `src/apothem/conformity/gate.py`); там, где механизация невозможна, проводите рассуждение. **Сбой любого отдельного пункта блокирует эмиссию; пересматривайте, пока каждый пункт не пройдёт; эмитируйте с записанным результатом шлюза.**

| # | Пункт | Тип проверки | Сбой → действие |
| - | --- | ---------- | ---------------- |
| 1 | M1 агностицизм хоста | обоснованный | пересмотреть для соответствия соглашениям хоста |

## 1. Схема результата шлюза

Каждый запуск шлюза записывает результат в рабочую трассу артефакта (скрытый комментарий, блок метаданных, отдельный файл журнала эмиссии — что позволяют конвенции хоста):

```yaml
conformity-attestation:
  artifact: <path-or-identifier>
  ecosystem-version: <git-commit-sha-or-equivalent ratifying the rule set in force>
  bars:
    M1-host-agnosticism:        pass | n/a (with reason)
    M2-editorial-disclosure:    pass | n/a
    M3-ten-dimensions:          pass | n/a
    M4-self-application:        pass
    M5-authority:               pass
    M6-expertise:               pass | n/a
    M7-option-annotation:       pass | n/a (no option set)
    M8-definitiveness:          pass
    M9-visual-leverage:         pass | n/a (subject not structural)
    M10-bidirectional-binding:  pass
    M11-agile-sprints:          pass | n/a (trivial work)
    M12-phase-layout:           pass | n/a
    M13-code-craft:             pass | n/a (not code)
    M14-systemicity:            pass
    M15-production-ready:       pass | n/a (no host-public-surface change)
  surfaced-gaps: []
  unresolved-inquiries: []
  amendments-disclosed: []
  date: <ISO-8601>
```

Пометки `n/a` явные и обоснованные — никогда не молчаливые пропуски. Поле `ecosystem-version` привязывает результат шлюза к воспроизводимому состоянию экосистемы пользовательского масштаба (активный на момент запуска шлюза git-коммит дерева исходников Apothem — например, чекаут `~/.claude/` для адаптера Claude Code), чтобы будущие аудиты могли повторить шлюз для тех же тел правил.
