> **Канонический реестр ворот предэмиссии из пятнадцати пунктов.** Этот документ несёт полную таблицу из пятнадцати пунктов ворот и YAML-блок схемы доказательства релиза; содержательная таблица и схема живут здесь, операционализированные `src/apothem/rules/pre-emission-gate.md`.

Перед любой эмиссией артефакта значимого масштаба (по порогу тривиального против нетривиального в `site/content/docs/governance/outward-conformity-registry.mdx` §1) запусти ворота предэмиссии из пятнадцати пунктов. Механизируй через хуки PreToolUse там, где это возможно (механические greps в `src/apothem/conformity/*-grep.py`, оркестрируемые `src/apothem/conformity/gate.py`); рассуждай там, где механизация невозможна. **Сбой любого одного пункта блокирует эмиссию; пересматривай, пока каждый пункт не пройдёт; эмитируй с записанным доказательством релиза ворот.**

| 1 | M1 агностицизм хоста | рассуждаемая | пересмотреть для соответствия конвенциям хоста |

## 1. Схема доказательства релиза

Каждый запуск ворот записывает результат в рабочую трассу артефакта (скрытый комментарий, блок метаданных, отдельный файл журнала эмиссии — что позволяют конвенции хоста):

```yaml
conformity-attestation:
  artifact: <path-or-identifier>
  ecosystem-version: <git-commit-sha-or-equivalent ratifying the rule set in force>
  bars:
    M1-host-agnosticism:        pass | n/a (with reason)
    M2-editorial-disclosure:    pass | n/a
    M3-ten-dimensions:          pass | n/a
    M4-self-application:        pass
    M5-authority:               pass
    M6-expertise:               pass | n/a
    M7-option-annotation:       pass | n/a (no option set)
    M8-definitiveness:          pass
    M9-visual-leverage:         pass | n/a (subject not structural)
    M10-bidirectional-binding:  pass
    M11-agile-sprints:          pass | n/a (trivial work)
    M12-phase-layout:           pass | n/a
    M13-code-craft:             pass | n/a (not code)
    M14-systemicity:            pass
    M15-production-ready:       pass | n/a (no host-public-surface change)
  surfaced-gaps: []
  unresolved-inquiries: []
  amendments-disclosed: []
  date: <ISO-8601>
```

Пометки `n/a` явны и обоснованы — никогда не молчаливые пропуски. Поле `ecosystem-version` привязывает доказательство релиза к воспроизводимому состоянию экосистемы пользовательского масштаба (git-коммит дерева исходников Apothem, активный при запуске ворот — например, чекаут `~/.claude/` для адаптера Claude Code), чтобы будущие аудиты могли воспроизвести ворота против тех же тел правил.
