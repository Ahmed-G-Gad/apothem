Сквозные проработанные руководства. Каждый пример ведёт одну задачу от пустого
старта до готового артефакта, показывая команды, файлы и рассуждения на каждом
шаге.

Запускаемые примеры проектов, поставляемые с репозиторием, находятся в каталоге
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) в корне
репозитория; страницы ниже — это повествовательные руководства, которые их
разбирают.

## Страницы

| Страница | Описание |
|------|-------------|
| [Создание адаптера harness](/docs/examples/authoring-a-harness-adapter) | Пошаговое руководство по созданию нового адаптера harness с нуля. |
| [Минимальный хук](/docs/examples/minimal-hook) | Минимально возможный хук Apothem — проверка PreToolUse, срабатывающая при каждой записи файла. |
| [Пользовательское правило](/docs/examples/custom-rule) | Создание специфичного для проекта постоянного правила, обеспечивающего соблюдение конвенции именования. |
| [Разбор плана](/docs/examples/plan-walkthrough) | Сквозной разбор конвейера `/plan` для реальной задачи. |
