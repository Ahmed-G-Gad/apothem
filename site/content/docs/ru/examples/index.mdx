Проработанные сквозные пошаговые разборы. Каждый разбор проводит одну задачу от
пустого старта до готового артефакта, показывая команды, файлы и рассуждения на
каждом шаге.

Запускаемые проекты-примеры, поставляемые с репозиторием, находятся в каталоге
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) в корне
репозитория. Каждый проект самодостаточен и имеет собственный README. Страницы
ниже — это пошаговые разборы, написанные отдельно от этих проектов; они не
пересказывают их.

## Страницы

| Страница | Описание |
|------|-------------|
| [Создание адаптера окружения](/docs/examples/authoring-a-harness-adapter) | Пошаговое руководство по созданию нового адаптера окружения с нуля. |
| [Минимальный хук](/docs/examples/minimal-hook) | Наименьший возможный хук Apothem — проверка PreToolUse, которая срабатывает при каждой записи файла. |
| [Пользовательское правило](/docs/examples/custom-rule) | Создание специфичного для проекта постоянно действующего правила, которое обеспечивает соблюдение соглашения об именовании. |
| [Прохождение плана](/docs/examples/plan-walkthrough) | Сквозной пошаговый разбор конвейера `/plan` для реальной задачи. |
