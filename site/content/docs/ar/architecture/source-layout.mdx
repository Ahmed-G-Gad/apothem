اعتمد <bdi>Apothem</bdi> [تخطيط <bdi>src-layout</bdi> من <bdi>PyPA</bdi>](https://packaging.python.org/en/latest/discussions/src-layout-vs-flat-layout/)، فوضع كل شيفرة <bdi>Python</bdi> القابلة للاستيراد تحت <bdi>`src/apothem/`</bdi>.

## لماذا تخطيط <bdi>src-layout</bdi>

- **عزل الاستيراد.** لا يُحَلّ <bdi>`import apothem`</bdi> إلا عندما يكون <bdi>`src/`</bdi> على المسار
  (يعمل المحرّك بالصيغة <bdi>`PYTHONPATH=src python -m apothem`</bdi>)، ممّا يمنع الاستيراد
  العَرَضي لشجرة العمل من دليل غير ذي صلة.
- **زمن تشغيل مكتفٍ ذاتيًا.** يعمل <bdi>Apothem</bdi> مباشرةً من نسخة مسحوبة واعتمادياته
  مُضمَّنة تحت <bdi>`src/apothem/_vendor/`</bdi> — ولا تلزم أي خطوة تثبيت.
  ويُبقي تخطيط <bdi>src-layout</bdi> ذلك السطح القابل للاستيراد منفصلًا بوضوح عن أدوات
  المستودع واختباراته وسكربتاته.
- **توزيع نظيف.** يُنتِج التخطيط نفسه <bdi>sdist</bdi> و<bdi>wheel</bdi> سليمَي البنية
  (وتثبيتًا قابلًا للتحرير اختياريًا عبر <bdi>`pip install -e .`</bdi>) يطابق محتواهما بالضبط
  ما يُشحَن، دون تسرّب أي وحدات شاردة من المستوى الأعلى إليهما.

## بنية الشجرة

```
src/apothem/
    agents/         persistent agent definitions (*.md)
    audit/          inventory and provenance tools
    benchmarks/     performance benchmarks
    cli/            Click CLI (top-level commands listed below the tree)
    commands/       slash command definitions (*.md)
    conformity/     mechanical gate checkers (*_grep.py)
    harnesses/      one sub-package per harness adapter (17 adapters)
    hooks/          hook dispatcher + message files
    lib/            shared Python library
    output-styles/  output-style definitions (*.md)
    rules/          behavioral rules (*.md)
    schemas/        YAML/JSON schemas
    skills/         reusable skill templates (folder/SKILL.md)
    statuslines/    status-line config (*.json)
    templates/      reusable template artifacts
```

## المُنتَجات القابلة للاستيراد مقابل مُنتَجات التهيئة

كثير من العناصر تحت <bdi>`src/apothem/`</bdi> مُنتَجات تهيئة بصيغة <bdi>Markdown</bdi>، لا
وحدات <bdi>Python</bdi>. سطح <bdi>Python</bdi> القابل للاستيراد هو:

- <bdi>`src/apothem/cli/`</bdi> (واجهة سطر الأوامر المبنية على <bdi>Click</bdi> والمكشوفة بوصفها نقطة الدخول <bdi>`apothem`</bdi>)
- <bdi>`src/apothem/harnesses/`</bdi> (الحزم الفرعية لمحوّلات أُطُر العمل السبعة عشر)
- <bdi>`src/apothem/lib/`</bdi> (المكتبة المشتركة: الملف التعريفي، والسجلّ، والمُجسِّد، والانتشار)
- <bdi>`src/apothem/hooks/`</bdi> (<bdi>dispatch.py</bdi>، و<bdi>lib/</bdi>)
- <bdi>`src/apothem/conformity/`</bdi> (سكربتات <bdi>grep</bdi> الميكانيكية)
- <bdi>`src/apothem/audit/`</bdi> (سكربتات الجرد)
- <bdi>`src/apothem/benchmarks/`</bdi> (مُشغِّلات قياس الأداء)
