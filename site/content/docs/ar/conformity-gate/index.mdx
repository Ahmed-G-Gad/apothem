## سُلّم الخطورة

لا تملك البوابة سلّم الخطورة (حرجة، ومهمّة، واستشارية) ولا عتبة النتيجتين. ومن دون <bdi>`--strict`</bdi> (أو <bdi>`APOTHEM_CONFORMITY_STRICT=1`</bdi>) تُبلغ البوابة عن النتائج وتخرج برمز <bdi>`0`</bdi>. ومع <bdi>`--strict`</bdi> يخرج فحص الملف الواحد أو الخطّاف برمز <bdi>`2`</bdi> عند فشل أي مُطابِق، ويخرج تشغيل المجموعة (<bdi>`--all-perwrite`</bdi>) برمز <bdi>`2`</bdi> عند فشل مُطابِق مانع؛ ولا تُبلَّغ المُطابِقات الاستشارية إلا تقريرًا. ولا يمرّر خطّاف <bdi>Write/Edit</bdi> المثبَّت <bdi>`--strict`</bdi>، فيُبلغ عن النتائج وتمضي الكتابة ما لم يُضبط <bdi>`APOTHEM_CONFORMITY_STRICT=1`</bdi> في بيئته.

- **<bdi>per-write</bdi>**: على كل كتابة معلّقة (<bdi>`--hook`</bdi>)، أو على كل ملف متتبَّع مع <bdi>`--all-perwrite`</bdi>.

- **<bdi>change-set</bdi>**: على فرق مُجهَّز للإيداع، خارج مسوحات البوابة.

## تشغيل البوابة

على إطار عمل مُثبَّت، تعمل البوابة تلقائيًا: يربطها <bdi>`settings.json`</bdi> الخاص بـ
<bdi>Claude Code</bdi> بوصفها خطّاف <bdi>`PreToolUse`</bdi> يستدعي النسخة المُجسَّدة في
<bdi>`~/.claude/.apothem/support/conformity/gate.py`</bdi> قبل كل عملية
<bdi>Write/Edit</bdi>. ومن نسخة مسحوبة من المصدر، تُشغِّل صيغة الوحدة الشيفرةَ نفسها.
والبوابة استشارية افتراضيًا: تُبلِغ عن النتائج وتخرج بالرمز <bdi>`0`</bdi>. أضِف
<bdi>`--strict`</bdi> لتخرج بالرمز <bdi>`2`</bdi> عند نتيجة حاجبة. واسم أداة تحقّق غير
معروف يخرج بالرمز <bdi>`3`</bdi>.

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

يطبع <bdi>`python -m apothem.conformity.gate --help`</bdi> ملخّص الاستخدام.
راجِع [تشغيل بوابة المطابقة](/docs/usage/conformity-gate) للإجراء الكامل.
