تصف خارطة الطريق هذه الوجهة التي يمضي إليها <bdi>Apothem</bdi>. وهي بيان نيّة لا
التزام؛ إذ تتبدّل الأولويات مع تطوّر المشروع ومستخدميه. ولمعرفة ما شُحن بالفعل، راجع
[سجلّ التغييرات](https://github.com/ahmed-g-gad/apothem/blob/main/CHANGELOG.md).
ملف
[<bdi>ROADMAP.md</bdi>](https://github.com/ahmed-g-gad/apothem/blob/main/ROADMAP.md) في
المستودع هو خارطة الطريق الوحيدة؛
و[صفحة خارطة الطريق](https://apothem.ahmedgad.com/docs/community/roadmap) على موقع
المشروع مولَّدة منه.

مفتاح الحالات: **مُخطَّط** · **قيد التنفيذ** · **مشحون**.

## الإصدار الحالي

يشحن الخط الحالي مدير إعدادات أُطُر العمل المستقل عن المضيف: ملف تعريفي مشترك
(<bdi>`~/.config/apothem/profile.yaml`</bdi>) يُجسَّد في إعدادات أصلية لأُطُر العمل
للمحوّلات المسجَّلة، ويقوده سطر الأوامر <bdi>`apothem`</bdi> (<bdi>`quickstart`</bdi> ·
<bdi>`install`</bdi> · <bdi>`update`</bdi> · <bdi>`uninstall`</bdi> ·
<bdi>`rollback`</bdi> · <bdi>`verify`</bdi> · <bdi>`status`</bdi> · <bdi>`diff`</bdi> ·
<bdi>`harnesses`</bdi> · <bdi>`profile`</bdi> · <bdi>`doctor`</bdi> ·
<bdi>`migrate-workspace`</bdi> · <bdi>`completion`</bdi>).

| البند | الحالة | ملاحظات |
| ---- | ------ | ----- |
| سبعة عشر محوّل إطار عمل | مشحون | لكلٍّ منها التثبيت وإلغاء التثبيت والتحديث والتحقّق؛ وتسردها صفحات [أُطُر العمل المدعومة](https://apothem.ahmedgad.com/docs/harnesses) |
| انتشار القوالب المُوجَّه بالبيان | مشحون | مصدر حقيقة واحد للانتشار في <bdi>`src/apothem/lib/propagation-manifest.yaml`</bdi> |
| موقع الوثائق | مشحون | موقع عام مع فهارس مرجعية مولَّدة، وأصول العلامة، وفهرس للموقع قابل للقراءة آليًا، وأدلة تشغيل الإصدار |
| إصدارات موقَّعة | مشحون | يحمل كل إصدار <bdi>GitHub</bdi> مُنتَجات موقَّعة، و<bdi>SBOM</bdi>، وإثبات منشأ البناء |
| خطّا الأنابيب <bdi>`/plan`</bdi> و<bdi>`/research`</bdi> | مشحون | خط أنابيب التخطيط ذو المراحل (المواصفة، والتوليد، والمراجعة، والتنفيذ)، إضافةً إلى خط أنابيب البحث ذي المراحل الثلاث عشرة |
| أوامر التدقيق وحلقة <bdi>`/fortress`</bdi> | مشحون | تدقيقات عند الطلب للأمان، والشيفرة، وإمكانية الوصول، والأداء، والاعتماديات، وسلسلة التوريد، ونموذج التهديد، والمعمارية، ومراجعة الشيفرة، ومراجعة الوثائق، وتجربة المستخدم، تغلّفها حلقة التقوية <bdi>`/fortress`</bdi> |
| البنية التحتية للتدقيق ومراجعة الانحراف | مشحون | ماسحات الجرد والانحراف التي تعمل خلف أوامر التدقيق |
| بوابة المطابقة | مشحون | أدوات تحقّق لترويسات التأليف، والتسمية، وحِرفية الشيفرة، والتحوّط اللغوي، وتبادلية الربط على كل سطح مُجسَّد، مع لقطات ذهبية لفارق السلوك تُثبّت مخرجات كل محوّل |
| ذاكرة دائمة وتعلّم مستمر اختياري | مشحون | طبقة ذاكرة دائمة وحلقة تعلّم اختيارية تحملان الاصطلاحات المؤكَّدة عبر الجلسات |
| خط أنابيب <bdi>CI/CD</bdi> وسلسلة توريد الإصدارات الموقَّعة | مشحون | كل تغيير مشروط بـ <bdi>lint</bdi>، والاختبارات، وفحوص الأنواع، وبناء الوثائق، وفحوص سلسلة التوريد قبل الإصدار |

## المدى القريب

| البند | الحالة | ملاحظات |
| ---- | ------ | ----- |
| أدلة الوثائق | قيد التنفيذ | مزيد من الأدلة المركّزة على المهام، والمخططات، والأمثلة لإعدادات أُطُر عمل حقيقية |
| التوزيع عبر <bdi>npm / npx</bdi> | مُخطَّط | إبقاء نقطة الدخول <bdi>`@ahmed-g-gad/apothem`</bdi> عبر <bdi>npx</bdi> متوائمة مع كل إصدار وتوسيع تغطيتها للمنصّات |
| إدراج إضافة <bdi>Claude Code</bdi> | مُخطَّط | توسيع إدراج الإضافة مع استقرار سطح سوق الإضافات |
| مزيد من محوّلات أُطُر العمل | مُخطَّط | أُطُر عمل إضافية مع استقرار اصطلاحات إعدادها وطلب المستخدمين لها |
| تحسينات مخطط الملف التعريفي | مُخطَّط | أسطح تجاوز أغنى لكل إطار عمل وتشخيصات تحقّق أكثر صرامة |
| التحقّق من الملف التعريفي في بوابة المطابقة | مُخطَّط | التحقّق من الملف التعريفي المشترك مقابل مخططه بوصفه فحصًا من فحوص البوابة |
| ترقيم نسخ الملف التعريفي وترحيله | مُخطَّط | ترقيم نسخ صيغة الملف التعريفي وترحيل الملفات التعريفية الأقدم إلى الصيغة الأحدث |
| <bdi>`apothem update --watch`</bdi> | مُخطَّط | إعادة تجسيد إعدادات أُطُر العمل حين يتغيّر الملف التعريفي |

## الرؤية بعيدة المدى

يهدف <bdi>Apothem</bdi> إلى أن يكون الطريقة الافتراضية التي يدير بها أيّ شخص إعدادات
أُطُر العمل عبر كل أداة يستخدمها: اكتب الاصطلاحات مرة واحدة، وجسّدها في كل مكان،
وأبقِها متزامنة مع تطوّر التفضيلات وأُطُر العمل كليهما.

## كيف تؤثّر في خارطة الطريق

- افتح مشكلة أو صوّت لمشكلة قائمة في
  [متتبّع المشكلات](https://github.com/ahmed-g-gad/apothem/issues)؛ فطلب الميزة هناك
  هو سبيل اقتراح بند في خارطة الطريق. والطلبات الشائعة تتقدّم أسرع.
- راجع [<bdi>CONTRIBUTING.md</bdi>](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
  لمعرفة كيفية اقتراح التغييرات وإدخالها.
