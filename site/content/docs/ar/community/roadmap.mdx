## الإصدار الحالي

- ترسيخ استقرار محوّلات البيئات السبعة عشر.
- إكمال بنية مراجعة التدقيق التحتية.
- ترسيخ استقرار سطح واجهة سطر أوامر Apothem.
- إرساء خط أنابيب CI/CD عبر GitHub Actions.

## المدى القريب

- إنضاج توزيع npm / npx: إبقاء نقطة دخول `@ahmed-g-gad/apothem`
  متوافقة مع كل إصدار وتوسيع تغطيتها للمنصّات.
- تنمية إدراج إضافة Claude Code مع استقرار سطح المتجر.
- التحديث التلقائي لمحوّل البيئة عبر `apothem update --watch`.
- أدوات إصدار الملف التعريفي وترحيله.
- التحقق من مخطط الملف التعريفي المشترك في بوابة المطابقة.
- محوّلات بيئات إضافية بناءً على طلبات المجتمع.

## المدى الأبعد

- مزامنة الملف التعريفي المستضافة سحابيًا (اختيارية، يتحكّم بها المشغّل).
- إضافة VS Code لتغذية راجعة فورية عن المطابقة.
- إدارة الملف التعريفي المشترك للفريق.
