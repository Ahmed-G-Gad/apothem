يشحن Apothem نصّي مثبّت يغطّيان بينهما مصفوفة سطح المكتب والخادم لمطوّري
العصر الحديث. لا يوجد بناء خاص بمنصّة محدّدة: المحرّك [زمن تشغيل قائم
بذاته](/docs/architecture/self-contained-runtime) يعمل من شجرة مصدره مع
تبعيات مُضمَّنة، لذا فإن دعم المنصّة هو بالضبط مجموعة المضيفات التي يستطيع
فيها أحد المثبّتين وضع تلك الشجرة وتشغيلها. ويوسّع مسارا التثبيت الآخران
المصفوفة أكثر: تعمل الإضافات والملحقات الأصلية للأدوات أينما تعمل أداتها
المضيفة، وتعمل صيغة npx (`npx @ahmed-g-gad/apothem`) على أيّ نظام تشغيل به
Node.js 18+.

## مصفوفة نظام التشغيل والصدفة

| عائلة نظام التشغيل | الأصداف المدعومة | نص المثبّت |
| --------- | ---------------- | ---------------- |
| macOS | POSIX `bash` (bash النظام أو bash أحدث ثبّته المستخدم) | `install.sh` |
| Linux | POSIX `bash` | `install.sh` |
| نظام Windows الفرعي لـ Linux (WSL2) | POSIX `bash` | `install.sh` |
| BSD (FreeBSD، OpenBSD، NetBSD) | POSIX `bash` | `install.sh` |
| Termux (Android) | POSIX `bash` | `install.sh` |
| حاوية Linux في ChromeOS (Crostini) | POSIX `bash` | `install.sh` |
| Windows | Windows PowerShell 5.1+ | `install.ps1` |
| أيّ منصّة بها PowerShell 7+ | PowerShell 7+ (متعدّد المنصّات) | `install.ps1` |

النصّان متكافئان وظيفيًا. يتطلّب `install.sh` صدفة `bash` متوافقة مع POSIX.
ويتطلّب `install.ps1` صدفة Windows PowerShell 5.1 أو أحدث، أو
PowerShell 7+ على أيّ منصّة يدعمها PowerShell 7 نفسه — بما في ذلك
macOS وLinux، حيث يكون بديلًا عن `install.sh`.

## المتطلّب المسبق الوحيد: Python نظامي

لا يثبّت Apothem أيّ حزم Python. تعمل استيرادات المحرّك مقابل
مفسّر تملكه بالفعل، مع وضع المصدر المرفق في مقدّمة
`PYTHONPATH`. يفحص كل مثبّت المتطلّب المسبق قبل القيام بأيّ
شيء آخر:

- **CPython 3.10 أو أحدث.** يفحص المثبّت `python3` و`python` و
  الأسماء المُؤطّرة بالإصدار (`python3.14` نزولًا إلى `python3.10`)، قابلًا
  أول واحد يُبلّغ عن إصدار ≥ 3.10. وعلى Windows يرفض رقائق مشغّل
  متجر Microsoft، ويطبّق محدّد `find-python` المرفق الأرضية ذاتها.
- **مكتبات زمن التشغيل قابلة للاستيراد.** يستورد المحرّك `click` و`rich` من مفسّر النظام؛ أما بقية اعتمادياته الخارجية فهي مضمّنة (vendored) داخل شجرة المصدر. يتحقّق المثبِّت من أن كلتيهما قابلتان للاستيراد، ويذكر أي واحدة ناقصة، ويعرض تثبيت المتطلّبات الناقصة نيابةً عنك — بعد تأكيدك، أو تلقائيًّا باستخدام `--yes` / `APOTHEM_AUTO_INSTALL_DEPS=1`.
- **`git`** مطلوب فقط للتثبيت الشبكي (يستنسخ النص شجرة المصدر). لا يتطلّب
  التثبيت المحلي من سحب `git`.

إن كان المفسّر أو المكتبات أو `git` غائبًا، يخرج المثبّت
برسالة تشخيصية تسمّي بالضبط ما يجب توفيره، بدلًا من التخمين أو
تعديل بيئتك.

## كيف تُدعَم منصّة

تُدعَم منصّة عندما يتحقّق الشرطان:

1. يعمل أحد المثبّتين عليها — أي أن المضيف لديه صدفة POSIX
   `bash` (`install.sh`) أو PowerShell مدعوم (`install.ps1`).
2. يعمل عليها مفسّر CPython 3.10+ مع `click` و`rich` قابلين للاستيراد.

لا يوجد مكوّن مُترجَم، ولا امتداد أصلي، ولا ثنائي خاص بكل منصّة. تعمل شجرة
المصدر ذاتها أينما يعمل المفسّر، لذا فإن المصفوفة أعلاه هي البيان الكامل
الدقيق للدعم — لا يُدّعى أكثر من ذلك.

## الخطوة الموصى بها التالية

**شغّل المثبّت لمنصّتك** — `curl -fsSL https://apothem.ahmedgad.com/install.sh | bash` على صدفة POSIX، أو `irm https://apothem.ahmedgad.com/install.ps1 | iex` على PowerShell — بعد تأكيد وجود مفسّر CPython 3.10+ على PATH لديك.
