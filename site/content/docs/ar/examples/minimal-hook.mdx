يُظهِر هذا المثال أصغر خطّاف <bdi>Apothem</bdi> ممكن: خطّاف <bdi>PreToolUse</bdi>
يُطلَق قبل كل استدعاء لأداة <bdi>`Write`</bdi> ويُسجِّل المسار الهدف.

## نص الخطّاف

```python
# src/apothem/hooks/log_writes.py
import json, sys

data = json.load(sys.stdin)
path = data.get("tool_input", {}).get("file_path", "unknown")
print(f"[apothem] Writing to: {path}", file=sys.stderr)
sys.exit(0)  # always exit 0; block with the deny envelope below
```

## التسجيل في settings.json

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "python src/apothem/hooks/log_writes.py"
          }
        ]
      }
    ]
  }
}
```

## اختبار الخطّاف

أجرِ أي كتابة ملف في <bdi>Claude Code</bdi> وراقب خرج <bdi>stderr</bdi> في لوحة
تتبّع الخطّاف.

## حجب الكتابات

لحجب عملية الكتابة، اطبع غلاف الرفض إلى <bdi>stdout</bdi> وأبقِ رمز الخروج <bdi>`0`</bdi>، كما تفعل خطّافات <bdi>Apothem</bdi> نفسها:

```python
print(json.dumps({"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "deny", "permissionDecisionReason": "blocked by log_writes"}}))
sys.exit(0)
```
