<bdi>Antigravity</bdi> إطار عمل من الصنف I لنشر البيان (<bdi>manifest-propagation</bdi>): يكتب <bdi>Apothem</bdi> مرساة السياق العامّة <bdi>`~/.gemini/GEMINI.md`</bdi> ويثبّت إضافة <bdi>Apothem</bdi> تحت <bdi>`~/.gemini/antigravity-cli/plugins/apothem/`</bdi>. وتقارن هذه الصفحة بين صيانة ذلك التخطيط يدويًا وإدارته بواسطة <bdi>Apothem</bdi>.

## الحالة

**مرحلة معاينة.** يستهدف محوّل <bdi>Antigravity</bdi> مرساة السياق <bdi>`GEMINI.md`</bdi> الموثّقة حاليًا وسطح إضافات واجهة سطر أوامر <bdi>Antigravity</bdi>. أما الحزم التي لا تملك سطحًا أصليًا فتبقى مادة دعم تابعة لـ<bdi>Apothem</bdi>.

## مقارنة الجهد

| المهمة | التهيئة اليدوية الخام | تديرها <bdi>Apothem</bdi> |
| ---- | --------------- | --------------- |
| كتابة القواعد | كتابة كل ملف قاعدة للإضافة يدويًا | كتابتها مرّةً واحدة في المتن المشترك |
| الحفاظ على المطالبات القابلة لإعادة الاستخدام | نسخ مطالبات الأوامر والمهارات إلى ملفات الإضافة يدويًا | محوَّلة أو منسوخة بوصفها مهارات للإضافة |
| الحفاظ على مادة دعم الخطّافات | نسخ مراجع الخطّافات يدويًا دون توصيل فعّال | منسوخة ضمن شجرة دعم إضافة <bdi>Apothem</bdi> |
| إبقاء القواعد متوائمة مع أُطُر العمل الأخرى | يدويّ، لكل أداة | تلقائيًا عند <bdi>`apothem update`</bdi> |
| تثبيت التهيئة وإزالتها | نسخ الملفات وحذفها يدويًا | <bdi>`apothem install`</bdi> / <bdi>`apothem uninstall`</bdi> |
| التحقق من صحة التهيئة | فحص يدوي | <bdi>`apothem verify --harness antigravity`</bdi> |

## ما الذي يديره Apothem

يدير <bdi>Apothem</bdi> ملف السياق العام لـ<bdi>Antigravity</bdi>، وبيانات الإضافة الوصفية، ومهارات الأوامر المحوَّلة، والمهارات القابلة لإعادة الاستخدام، والعوامل المحوَّلة، والقواعد، والقوالب، ومادة دعم الخطّافات. تُحفَظ ملفات الخطّافات بوصفها مادة دعم؛ ولا يسجّل <bdi>Apothem</bdi> أحداث خطّافات <bdi>Antigravity</bdi> الفعّالة حتى يمتلك المحوّل طبقة ترجمة مخطّطية لملف <bdi>`hooks.json`</bdi> الخاص بـ<bdi>Antigravity</bdi>.

## مسار الترحيل

1. شغّل <bdi>`apothem profile init`</bdi> لإنشاء الملف التعريفي المشترك إن لم تكن قد فعلت ذلك بعد.
2. انقل قواعد <bdi>Antigravity</bdi> المكتوبة يدويًا إلى المتن المشترك.
3. شغّل <bdi>`apothem install --harness antigravity`</bdi> لنشر المتن.
4. شغّل <bdi>`apothem verify --harness antigravity`</bdi> للتأكّد من وصول التهيئة إلى وجهتها.
5. استخدم <bdi>`apothem update --harness antigravity`</bdi> مع كل تغيير لاحق.
