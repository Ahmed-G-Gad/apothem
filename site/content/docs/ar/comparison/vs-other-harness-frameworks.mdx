تؤطّر هذه الصفحة <bdi>Apothem</bdi> أمام فئات الأدوات التي يستخدمها المشغّلون
بالفعل لإدارة تهيئة الـ harness. وهي تُسمّي فئات قدرات، لا
منتجات بعينها — فالمقارنة بنيوية وتنطبق بغضّ النظر عن أيّ أداة في كل فئة تلجأ
إليها.

## الفئات

ينقسم المشغّلون الذين يديرون تهيئة مساعدي الذكاء الاصطناعي عبر أدوات متعددة إلى
أحد أربعة مناهج:

1. **التهيئة اليدوية لكل أداة.** تحرّر ملف التهيئة الأصلي لكل بيئة يدويًّا — ملف
   واحد لكل أداة، بلا مصدر مشترك.
2. **أدوات تهيئة البيئة الواحدة.** أداة مكرّسة لمنصّة مساعد واحدة تدير تهيئة تلك
   المنصّة جيدًا لكنها لا تطال الأدوات الأخرى التي تستخدمها.
3. **مديرو dotfile عامّو الغرض.** أداة تُخضِع ملفات التهيئة للتحكّم في الإصدارات
   وتزامنها عبر الأجهزة لكنها تعامل كل ملف كنصّ مُعتِم.
4. **مديرو التهيئة متعدّدة البيئات.** أداة تحتفظ بملف تعريف مشترك واحد وتُحوِّله
   إلى الصيغة الأصلية لكل بيئة. ينتمي <bdi>Apothem</bdi> إلى هذه الفئة.

## مقارنة القدرات

| القدرة | يدويًّا لكل أداة | أداة بيئة واحدة | مدير dotfile | Apothem |
| ---------- | --------------- | ------------------- | --------------- | ------- |
| يغطّي بيئات كثيرة | نعم (بالجهد) | لا (بيئة واحدة) | نعم (على مستوى الملفات) | نعم (سبعة عشر محوِّلًا) |
| مصدر حقيقة مشترك واحد | لا | لا | لا | نعم |
| يُحوِّل الصيغ الأصلية لكل بيئة | يدويًّا | نعم (بيئة واحدة) | لا | نعم |
| منع الانجراف بين البيئات | يدويًّا | لا ينطبق | تزامن ملفات فقط | نعم |
| ترجمة الصيغة (<bdi>`.mdc`</bdi>، <bdi>`.toml`</bdi>، <bdi>`.md`</bdi> مُضمَّن) | يدويًّا | لبيئتها | لا | نعم |
| أمر التحقّق | لا يوجد | يتفاوت | لا يوجد | نعم |
| إضافة بيئة جديدة | مزيد من العمل اليدوي | غير ممكن | تتبّع مزيد من الملفات | تثبيت محوِّل واحد |

## أين يناسب كل منهج

**التهيئة اليدوية لكل أداة** تناسب أداة واحدة بتهيئة نادرًا ما تغيّرها. تنمو
الكلفة مع كل أداة تضيفها ومع كل قاعدة تُبقيها متوائمة فيما بينها.

**أدوات البيئة الواحدة** تناسب المشغّلين الملتزمين بمنصّة واحدة. وهي لا تحلّ مشكلة
تعدّد الأدوات — فلحظة إضافتك مساعدًا ثانيًا، تعود إلى إبقاء تهيئتين متوائمتين.

**مديرو dotfile** يناسبون مزامنة ملفات اعتباطية عبر الأجهزة. ينقلون البايتات بين
الأجهزة لكنهم لا يفهمون صيغ البيئات، ولذا لا يمكنهم تحويل ملف تعريف واحد إلى
سبعة عشر شكلًا أصليًّا ولا التحقّق من أيٍّ منها.

**Apothem** يناسب المشغّلين الذين يُشغّلون عدة مساعدي ذكاء اصطناعي ويريدون مصدر
حقيقة واحدًا. تكتب ملف التعريف مرّةً واحدة؛ ويتولّى <bdi>Apothem</bdi> تحويل التهيئة
الأصلية لكل بيئة وتثبيتها وتحديثها والتحقّق منها.
