تؤطّر هذه الصفحة <bdi>Apothem</bdi> أمام فئات الأدوات التي يستخدمها المشغّلون
بالفعل لإدارة تهيئة إطار العمل. وهي تُسمّي فئات قدرات، لا
منتجات بعينها — فالمقارنة بنيوية وتنطبق بغضّ النظر عن أيّ أداة في كل فئة تلجأ
إليها.

## الفئات

ينقسم المشغّلون الذين يديرون تهيئة مساعدي الذكاء الاصطناعي عبر أدوات متعددة إلى
أحد أربعة مناهج:

1. **التهيئة اليدوية لكل أداة.** تحرّر ملف التهيئة الأصلي لكل إطار عمل يدويًّا — ملف
   واحد لكل أداة، بلا مصدر مشترك.
2. **أدوات تهيئة إطار العمل الواحد.** أداة مكرّسة لمنصّة مساعد واحدة تدير تهيئة تلك
   المنصّة جيدًا لكنها لا تطال الأدوات الأخرى التي تستخدمها.
3. **مديرو dotfile عامّو الغرض.** أداة تُخضِع ملفات التهيئة للتحكّم في الإصدارات
   وتزامنها عبر الأجهزة لكنها تعامل كل ملف كنصّ مُعتِم.
4. **مديرو التهيئة متعدّدة أُطُر العمل.** أداة تحتفظ بملف تعريفي مشترك واحد وتُحوِّله
   إلى الصيغة الأصلية لكل إطار عمل. ينتمي <bdi>Apothem</bdi> إلى هذه الفئة.

| القدرة | يدويًّا لكل أداة | أداة لإطار عمل واحد | مدير dotfile | Apothem |
| ---------- | --------------- | ------------------- | --------------- | ------- |
| يغطّي أُطُر عمل كثيرة | نعم (بالجهد) | لا (إطار عمل واحد) | نعم (على مستوى الملفات) | نعم (سبعة عشر محوِّلًا) |
| مصدر حقيقة مشترك واحد | لا | لا | لا | نعم |
| يُحوِّل الصيغ الأصلية لكل إطار عمل | يدويًّا | نعم (إطار عمل واحد) | لا | نعم |
| منع الانجراف بين أُطُر العمل | يدويًّا | لا ينطبق | تزامن ملفات فقط | نعم |
| ترجمة الصيغة (<bdi>`.mdc`</bdi>، <bdi>`.toml`</bdi>، <bdi>`.md`</bdi> مُضمَّن) | يدويًّا | لإطار عملها | لا | نعم |
| أمر التحقّق | لا يوجد | يتفاوت | لا يوجد | نعم |

## أين يناسب كل منهج

**التهيئة اليدوية لكل أداة** تناسب أداة واحدة بتهيئة نادرًا ما تغيّرها. تنمو
الكلفة مع كل أداة تضيفها ومع كل قاعدة تُبقيها متوائمة فيما بينها.

**أدوات إطار العمل الواحد** تناسب المشغّلين الملتزمين بمنصّة واحدة. وهي لا تحلّ مشكلة
تعدّد الأدوات — فلحظة إضافتك مساعدًا ثانيًا، تعود إلى إبقاء تهيئتين متوائمتين.

**مديرو dotfile** يناسبون مزامنة ملفات اعتباطية عبر الأجهزة. ينقلون البايتات بين
الأجهزة لكنهم لا يفهمون صيغ أُطُر العمل، ولذا لا يمكنهم تحويل ملف تعريف واحد إلى
سبعة عشر شكلًا أصليًّا ولا التحقّق من أيٍّ منها.

**Apothem** يناسب المشغّلين الذين يُشغّلون عدة مساعدي ذكاء اصطناعي ويريدون مصدر
حقيقة واحدًا. تكتب ملف التعريف مرّةً واحدة؛ ويتولّى <bdi>Apothem</bdi> تحويل التهيئة
الأصلية لكل إطار عمل وتثبيتها وتحديثها والتحقّق منها.
