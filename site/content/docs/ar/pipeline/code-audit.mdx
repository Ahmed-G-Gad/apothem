**الدور:** المُدقِّق
**الموضع في خط الأنابيب:** الحصن

تدقيق شِفرة جنائي عابر للملفّات على نطاق مَجموعة المستودع.

## الاستدعاء القانوني

```bash
/code-audit
```

مع وسائط:

```bash
/code-audit [path/to/plan-suite/] [phase-id] [--dry-run]
```

## المُدخَلات

مستودعٌ مُضيف في أيّ حالة من حالات دورة الحياة

## المُخرَجات

نتائج على مستوى المَجموعة + <bdi>REPORT.md</bdi>

## المصبّ

طور تدقيق الشِّفرة الجنائي من تسلسل تدقيق المراجعة

## أطوار سير العمل

يتّبع الأمر سير عمل خط أنابيب <bdi>`/plan`</bdi> القياسي:

1. **تحميل السياق** — قراءة حزمة الخطّة والقواعد وعقد الاستئناف.
2. **التحقّق من المتطلّبات المسبقة** — تأكيد اكتمال الأطوار التابعة.
3. **تنفيذ المهامّ** — أداء مهمّة الأمر.
4. **التحقّق من المُخرَجات** — تأكيد وجود كلّ المُخرَجات المُعلَنة واجتيازها بوابات الجودة.
5. **تحديث <bdi>PROGRESS.md</bdi>** — تسجيل المُخرَجات المُتحقَّق منها في سِجلّ مُخرَجات الطور.
6. **إصدار <bdi>REPORT.md</bdi>** — تسجيل إثبات إصدار بوابة ما قبل الإطلاق.

## أنماط الإخفاق

| العَرَض | السبب | التعافي |
|---------|-------|----------|
| متطلّب مسبق غير مكتمل | لم يُنجَز الطور التابع | أنجِز الطور المنبعي أولًا |
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملفّ مُدخَل مفقود | ملفّ حزمة الخطّة غائب | شغِّل <bdi>`/plan-generate`</bdi> لإنشائه |

## أمثلة

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a named plan suite
/code-audit path/to/plan-suite/
```
