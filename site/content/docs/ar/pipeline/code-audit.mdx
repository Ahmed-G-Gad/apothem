**الدور:** المُدقِّق
**الموضع في خط الأنابيب:** الحصن

تدقيق شِفرة جنائي عابر للملفّات على نطاق مَجموعة المستودع.

## الاستدعاء القانوني

```bash
/code-audit
```

مع وسائط:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## المُدخَلات

مستودع مُضيف بتخطيط مصدر معتمَد، وخطّ أساس لتغطية الاختبارات، وبوابة <bdi>CI</bdi> ناجحة عند <bdi>SHARED+</bdi>

## المُخرَجات

نتائج على مستوى المجموعة في <bdi>`_inputs/code-audit-findings.md`</bdi>

## المصبّ

مرحلة تدقيق الشِّفرة الجنائي من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر ست مراحل جنائية: استيعاب المدخلات، وجولة تتبّع التبعيات بين الملفات، وتدقيق تلميحات الأنواع والتغطية، واكتشاف الشيفرة الميتة والمكرّرة، وتدقيق السلامة المعمارية، وإصدار النتائج مع بوابة التحقّق.

## أنماط الإخفاق

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملف إدخال مفقود | لم تُشغَّل بوابة <bdi>CI</bdi> ولا يوجد خطّ أساس لتغطية الاختبارات عند <bdi>SHARED+</bdi> | شغِّل خطّ <bdi>CI</bdi> الخاص بالمُضيف أولًا، ثم أعِد التشغيل |

## أمثلة

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
