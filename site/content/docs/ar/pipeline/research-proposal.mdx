**الدور:** الباحث الرئيسي (الخطة المرجعية)
**الموضع في خط المعالجة:** منتصف السلسلة

يحوّل الفجوة المُركَّبة والإطار النظري إلى خطة مرجعية قابلة للتمويل وللمراجعة. تُطرَح الجدوى الأخلاقية في البداية، وتُثبَّت خطة التسجيل المسبق واختيار دليل الإبلاغ قبل تفعيل أيّ تصميم دراسة.

## الاستدعاء المعياري

```bash
/research-proposal
```

مع الوسائط:

```bash
/research-proposal [--suite-name NAME] [--override] [--guideline NAME] [--prereg-registry NAME]
```

## المدخلات

ملفّ المجموعة <bdi>`_inputs/synthesis.md`</bdi> (خريطة <bdi>SOTA</bdi> ＋ تحليل الفجوة) و<bdi>`_inputs/theory.md`</bdi> (الإطار المفاهيمي).

## المخرجات

<bdi>`_inputs/proposal.md`</bdi> (التسلسل الهرمي لأهداف <bdi>SMART</bdi>، وتقييم الجدوى، وسجلّ الموارد / الجدول الزمني / المخاطر، ومسار الأثر، وخطة التسجيل المسبق، والاختيار المسبق لدليل الإبلاغ <bdi>EQUATOR</bdi>).

## المراحل اللاحقة

<bdi>/research-design</bdi> (المستهلِك اللاحق — يُفعِّل المقترح ليصبح تصميم دراسة مُجمَّدًا ومُسجَّلًا مسبقًا).

## مراحل سير العمل

يتّبع الأمر سير عمل خط معالجة <bdi>`/research`</bdi> القياسي:

1. **تحميل السياق** — قراءة <bdi>`_inputs/synthesis.md`</bdi> و<bdi>`_inputs/theory.md`</bdi> والقواعد وأيّ حالة قائمة للمجموعة.
2. **بناء التسلسل الهرمي لأهداف <bdi>SMART</bdi>** — تحويل الفجوة إلى أهداف محدّدة وقابلة للقياس وقابلة للتحقيق وذات صلة ومحدّدة زمنيًا.
3. **تقييم الجدوى والمخاطر** — بناء سجلّ الموارد / الجدول الزمني / المخاطر؛ وطرح الجدوى الأخلاقية في البداية.
4. **تخطيط التسجيل المسبق والإبلاغ** — اختيار السجلّ، وصياغة خطة التسجيل المسبق، والاختيار المسبق لدليل الإبلاغ <bdi>EQUATOR</bdi>.
5. **رسم مسار الأثر** — تتبُّع كيف تُنتج الأهداف، إن تحقّقت، أثرًا لاحقًا.
6. **التحقّق والإصدار** — تأكيد أنّ الأهداف قابلة للاختبار وأنّ الخطة قابلة للتكرار؛ وإصدار <bdi>`_inputs/proposal.md`</bdi> إضافةً إلى بيان التسليم.

## الحدّ الأدنى للصرامة

لا يحدّد طموحُ جهة النشر المستهدَفة اختيارَ دليل الإبلاغ فحسب، بل كذلك عمقَ الحدّ الأدنى للصرامة الذي يجب أن تجتازه مرحلتا التصميم والتجربة اللاحقتان — الحدّ الأدنى لإعادة التكرار، وتكافؤ الميزانية، والضبط على تقسيمات منفصلة، والدلالة الإحصائية مع حجم الأثر — إضافةً إلى حزمة أدلّة قابلية إعادة الإنتاج التي سيحملها المُسلَّم.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| الهدف غير قابل للقياس | صِيغ الهدف بوصفه نشاطًا لا نتيجة | أعِد صياغته هدفًا <bdi>SMART</bdi> بمقياس نجاح صريح |
| لا توجد خطة تسجيل مسبق | تخطّي خطوة التسجيل المسبق | اختر سجلًّا وصُغ الخطة قبل الانتقال إلى <bdi>`/research-design`</bdi> |
| مدخل التركيب مفقود | <bdi>`/research-synthesis`</bdi> لم يُشغَّل بعد | شغّل <bdi>`/research-synthesis`</bdi> أولًا لإنتاج تحليل الفجوة |

## أمثلة

```bash
# تحويل الفجوة إلى خطة مرجعية قابلة للتمويل
/research-proposal --suite-name retrieval-latency

# تثبيت دليل الإبلاغ وسجلّ التسجيل المسبق
/research-proposal --guideline PRISMA --prereg-registry OSF
```
