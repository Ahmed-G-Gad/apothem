**الدور:** الباحث الرئيسي (النشر)
**الموضع في خط المعالجة:** منتصف السلسلة

يُنسّق الورقة وفق قالب جهة النشر ويُجمّع حزمة التقديم — المواد التكميلية، وبيان توافر البيانات / الشيفرة، وخطاب التقديم، وإقرارات الأخلاقيات وتضارب المصالح — إضافةً إلى خطة طبعة مسبقة / أرشفة مع <bdi>DOI</bdi> وقائمة تحقّق للتقديم. يتولّى المشغّل تقديم الحزمة؛ والخَلَف النهائي هو <bdi>`/research-disseminate`</bdi> الذي يحمل العمل المنشور إلى جمهوره.

## الاستدعاء المعياري

```bash
/research-publish
```

مع الوسائط:

```bash
/research-publish [path/to/research-suite/]
```

## المدخلات

ناتج الورقة و<bdi>`_outputs/review-report.md`</bdi> (مراجعات تقييم الأقران).

## المخرجات

حزمة التقديم المُنسَّقة وفق جهة النشر في موضع طبيعي للمضيف (المخطوطة المُنسَّقة ＋ المواد التكميلية ＋ بيان توافر البيانات / الشيفرة ＋ خطاب التقديم ＋ إقرارات الأخلاقيات / تضارب المصالح) ＋ <bdi>`_outputs/publication-record.md`</bdi> ＋ قائمة تحقّق للتقديم.

## المراحل اللاحقة

<bdi>/research-disseminate</bdi> (المستهلِك اللاحق) — يتولّى المشغّل عملية التقديم، ثم يحمل <bdi>`/research-disseminate`</bdi> العمل المنشور إلى جمهوره. وعندما تُعيد جهة النشر مراجعات، أعد تشغيل <bdi>`/research-review`</bdi> مقابل الورقة المُنقَّحة قبل إعادة بناء الحزمة.

## مراحل سير العمل

يتّبع الأمر سير عمل خط معالجة <bdi>`/research`</bdi> القياسي:

1. **تحميل السياق** — قراءة الورقة وتقرير التقييم.
2. **التحقّق من بوابة التسلسل** — التأكّد من وجود <bdi>`_outputs/review-report.md`</bdi>؛ وإلا التوقّف مع <bdi>`Blocked: run /research-review first`</bdi>.
3. **التنسيق والتجميع** — تطبيق قالب جهة النشر؛ وتجميع المواد التكميلية، وتوافر البيانات / الشيفرة، وخطاب التقديم، وإقرارات الأخلاقيات / تضارب المصالح.
4. **تخطيط الطبعة المسبقة / الأرشفة** — تسجيل خطة الطبعة المسبقة و<bdi>DOI</bdi>؛ وبناء قائمة تحقّق التقديم.
5. **تحديث بيان التسليم** — تسجيل حزمة التقديم وسجلّ النشر.
6. **إصدار الحزمة** — حزمة التقديم المُنسَّقة وفق جهة النشر ＋ <bdi>`_outputs/publication-record.md`</bdi>.

## الحدّ الأدنى للصرامة

يحترم التنسيقُ الكشفَ المرحلي: بالنسبة إلى جهة نشر مزدوجة التعمية، يُجرَّد المؤلّف والمؤسّسة وهوية النظام إلى بيانات وصفية تُقدَّم منفصلةً، ولا تُستعاد إلا في مرحلة النسخة الجاهزة للطباعة المُخصَّصة. ويحمل الإيداع الأرشيفي حزمةَ أدلّة قابلية إعادة الإنتاج المُقاسة على طموح جهة النشر (البيانات، والشيفرة، والبيئة المُثبَّتة، والبذور، وسجلّ العتاد، والنتائج لكلّ نسخة، والأشكال).

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| <bdi>Blocked: run /research-review first</bdi> | لا يوجد تقرير تقييم | شغّل <bdi>`/research-review`</bdi> لإنتاج <bdi>`_outputs/review-report.md`</bdi> |
| مراجعة <bdi>HIGH</bdi> غير مُعالَجة | تخطّي ملاحظة تقييم | عالِج المراجعة وأعد تشغيل <bdi>`/research-review`</bdi> |
| غياب توافر البيانات / الشيفرة | سطح قابلية التكرار مفقود | أضِف بيان توافر البيانات / الشيفرة قبل التقديم |

## أمثلة

```bash
# تجميع حزمة تقديم جهة النشر
/research-publish path/to/research-suite/
```
