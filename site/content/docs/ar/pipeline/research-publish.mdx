**الدور:** الباحث الرئيسي (النشر)
**الموضع في خط المعالجة:** منتصف السلسلة

يُنسّق الورقة وفق قالب جهة النشر ويُجمّع حزمة التقديم — المواد التكميلية، وبيان توافر البيانات / الشيفرة، وخطاب التقديم، وإقرارات الأخلاقيات وتضارب المصالح — إضافةً إلى خطة طبعة مسبقة / أرشفة مع <bdi>DOI</bdi> وقائمة تحقّق للتقديم. يتولّى المشغّل تقديم الحزمة؛ والخَلَف النهائي هو <bdi>`/research-disseminate`</bdi> الذي يحمل العمل المنشور إلى جمهوره.

## الاستدعاء المعياري

```bash
/research-publish
```

مع الوسائط:

```bash
/research-publish [--suite-name NAME]
```

## المدخلات

ناتج الورقة و<bdi>`_outputs/review-report.md`</bdi> (مراجعات تقييم الأقران وقائمة ما لم يُحكَم عليه فيه).

## المخرجات

حزمة التقديم المُنسَّقة وفق جهة النشر في موضع طبيعي للمضيف (المخطوطة المُنسَّقة ＋ المواد التكميلية ＋ بيان توافر البيانات / الشيفرة ＋ خطاب التقديم ＋ إقرارات الأخلاقيات / تضارب المصالح) ＋ <bdi>`_outputs/publication-record.md`</bdi> (بما في ذلك سجلّ قواعد جهة النشر المؤرَّخ: كلّ قاعدة مع صفحة مصدرها الرسمية، وتاريخ قراءتها، ومرحلة التقديم) ＋ قائمة تحقّق للتقديم.

## المراحل اللاحقة

<bdi>/research-disseminate</bdi> (المستهلِك اللاحق) — يتولّى المشغّل عملية التقديم، ثم يحمل <bdi>`/research-disseminate`</bdi> العمل المنشور إلى جمهوره. وعندما تُعيد جهة النشر مراجعات، أعد تشغيل <bdi>`/research-review`</bdi> مقابل الورقة المُنقَّحة قبل إعادة بناء الحزمة.

## مراحل سير العمل

يتّبع الأمر سير عمل خط معالجة <bdi>`/research`</bdi> القياسي:

1. **تحميل السياق** — قراءة الورقة وتقرير التقييم؛ وتثبيت جهة النشر والدورة والمسار ونوع المقالة، وتسجيل كلّ قاعدة من قواعد جهة النشر مع صفحة مصدرها الرسمية وتاريخ قراءتها ومرحلة التقديم.
2. **التحقّق من بوابة التسلسل** — التأكّد من وجود <bdi>`_outputs/review-report.md`</bdi>، وأن جميع مراجعات الشدّة <bdi>HIGH</bdi> فيه مُعالَجة (أو أن يكون المُشغِّل قد قبِل المخاطرة المتبقّية صراحةً)؛ وإلا فتوقّف برسالة <bdi>`Blocked: run /research-review first`</bdi>.
3. **التنسيق والتجميع** — حمل كلّ قاعدة من قواعد جهة النشر مع صفحة مصدرها وتاريخ قراءتها ومرحلة التقديم، والبناء على قالب جهة النشر دون تعديله، وعدّ الصفحات والكلمات بطريقة جهة النشر، وفحص ملفّ <bdi>PDF</bdi> المُجمَّع؛ ثم تجميع المواد التكميلية، وتوافر البيانات والشيفرة، وخطاب التقديم، وإقرارات الأخلاقيات / تضارب المصالح.
4. **تخطيط الطبعة المسبقة / الأرشفة** — تسجيل خطة الطبعة المسبقة و<bdi>DOI</bdi>؛ وبناء قائمة تحقّق التقديم.
5. **تحديث بيان التسليم** — تسجيل حزمة التقديم وسجلّ النشر.
6. **إصدار الحزمة** — حزمة التقديم المُنسَّقة وفق جهة النشر ＋ <bdi>`_outputs/publication-record.md`</bdi>.

## الحدّ الأدنى للصرامة

يحترم التنسيقُ الكشفَ المرحلي: بالنسبة إلى جهة نشر مزدوجة التعمية، يُجرَّد المؤلّف والمؤسّسة وهوية النظام إلى بيانات وصفية تُقدَّم منفصلةً، ولا تُستعاد إلا في مرحلة النسخة الجاهزة للطباعة المُخصَّصة. ويحمل الإيداع الأرشيفي حزمةَ أدلّة قابلية إعادة الإنتاج المُقاسة على طموح جهة النشر (البيانات، والشيفرة، والبيئة المُثبَّتة، والبذور، وسجلّ العتاد، والنتائج لكلّ نسخة، والأشكال). وبالنسبة إلى جهة نشر مزدوجة التعمية، يُفحَص الأرشيف التكميلي وكلّ مستودع أو مجموعة بيانات مرتبطة بحثًا عن الهوية، لا المخطوطة وحدها.

قواعد جهة النشر موثَّقة المصدر ومُرحَّلة. لا تُحتسَب إلا الصفحات الرسمية للجهة المستهدَفة نفسها: فجهة نشر مجاورة، أو دورة سابقة، أو مسار شقيق لا يحلّ محلّها أبدًا، وإعادة البناء لمراجعة أو للنسخة الجاهزة للطباعة تفرض حدود تلك المرحلة، لا حدود التقديم الأوّلي. والقاعدة التي لا تقف وراءها صفحة رسمية يُسأَل عنها المُشغِّل وتُوسَم بأنها غير مُتحقَّق منها مقابل جهة النشر. وتبقى ملفّات قالب جهة النشر كما صدرت، لذا يُبلَّغ عن ملفّ البداية المكتوب محلّيًّا بوصفه كذلك. وتُعَدّ الصفحات والكلمات بطريقة جهة النشر، مع تسجيل الأقسام المستثناة، ويُفحَص كلّ شكل وجدول بالحجم والتنسيق اللذين تتسلّمهما جهة النشر.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| <bdi>Blocked: run /research-review first</bdi> | لا يوجد تقرير تقييم، أو مراجعات <bdi>HIGH</bdi> مفتوحة | شغّل <bdi>`/research-review`</bdi> لإنتاج <bdi>`_outputs/review-report.md`</bdi>، أو عالِج مراجعات <bdi>HIGH</bdi> المفتوحة وأعِد تشغيل <bdi>`/research-review`</bdi>، أو اقبل المخاطرة المتبقّية صراحةً |
| مراجعة <bdi>HIGH</bdi> غير مُعالَجة | تخطّي ملاحظة تقييم | عالِج المراجعة وأعِد تشغيل <bdi>`/research-review`</bdi> |
| غياب توافر البيانات / الشيفرة | سطح قابلية التكرار مفقود | أضِف بيان توافر البيانات / الشيفرة قبل التقديم |
| قاعدة جهة نشر بلا مصدر | تأتي القاعدة من دورة أو مسار آخر أو من جهة نشر مجاورة، أو من الذاكرة | ثبِّت الجهة المستهدَفة؛ وسجّل الصفحة الرسمية وتاريخ القراءة والمرحلة للقاعدة، أو اسأل المُشغِّل وسِمها بأنها غير مُتحقَّق منها |
| قالب مُعدَّل | تعديل محلّي يُغيّر هندسة صفحة جهة النشر أو إعدادات الخطوط | استعِد ملفّات جهة النشر وغيّر التخطيط فقط عبر الخيارات التي يوثّقها القالب |
