**الدور:** مُراجِع التوثيق
**موضع خط الأنابيب:** القلعة

مرور مراجعة للتوثيق مقابل أعراف النثر ومعايير الجودة ذات الأبعاد العشرة.

## الاستدعاء المعياري

```bash
/docs-review
```

مع وسائط:

```bash
/docs-review [path/to/repo/ or path/to/docs-source/] [--focus FILE_OR_DIR] [--dry-run]
```

## المدخلات

سطح توثيق مستودع المُضيف

## المخرجات

نتائج التوثيق في <bdi>`_inputs/docs-review-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة مراجعة التوثيق من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل: استيعاب المدخلات، وجولة على كل صفحة، وفرز كل نتيجة، وإصدار النتائج، وبوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملف إدخال مفقود | لا توجد ملفات توثيق يمكن الوصول إليها عند المسار | مرِّر جذر مستودع أو دليل مصدر توثيق يحتوي صفحات <bdi>Markdown</bdi> |

## أمثلة

```bash
# Dry-run to preview what would happen
/docs-review --dry-run

# Execute against a repository root
/docs-review path/to/repo/
```
