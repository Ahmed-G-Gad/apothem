**الدور:** مراجِع المعمارية
**موضع خط الأنابيب:** القلعة

مراجعة سلامة المعمارية مقابل مُنتَج التصميم في <bdi>`_inputs/design.md`</bdi>.

## الاستدعاء المعياري

```bash
/architecture-review
```

مع وسائط:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## المدخلات

مستودع المُضيف + <bdi>`_inputs/design.md`</bdi>

## المخرجات

نتائج المعمارية في <bdi>`_inputs/architecture-review-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة مراجعة المعمارية من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل للتدقيق: استيعاب المدخلات، وجولة التتبّع من التصميم إلى الشيفرة، وتدقيق سلامة حدود الطبقات، ومسح الاقتران بين الحزم، وإصدار النتائج مع بوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملف إدخال مفقود | قِطعة التصميم <bdi>`_inputs/design.md`</bdi> غائبة | شغِّل <bdi>`/plan-design`</bdi> لإنشائها |

## أمثلة

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
