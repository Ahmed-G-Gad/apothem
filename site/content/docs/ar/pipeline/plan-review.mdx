**الدور:** المُدقِّق
**الموضع في خط المعالجة:** وسطي

تدقيق جنائي لحزمة خطة قائمة — أمانة النثر، والاتّساق، والجودة.

## الاستدعاء المعياري

```bash
/plan-review
```

مع الوسائط:

```bash
/plan-review [path/to/plan-suite/] [--focus AREA] [--dry-run]
```

## المدخلات

حزمة خطة مُولَّدة + <bdi>`_inputs/handoff-manifest.yml`</bdi> من <bdi>`/plan-generate`</bdi>.

## المخرجات

بطاقات تقييم المراجعة في <bdi>`PLAN-NOTES.md`</bdi> (<bdi>`## Review Scorecards`</bdi>)، وملخّص المراجعة في <bdi>`PROGRESS.md`</bdi>، وخرائط أثر التنقيح لكل اكتشاف في <bdi>`PLAN-NOTES.md`</bdi> (التقارير الكبيرة الدائمة في <bdi>`_outputs/`</bdi>)، و<bdi>`_inputs/handoff-manifest.yml`</bdi> المُعزَّز الحامل لحُكم المراجعة.

## المراحل اللاحقة

<bdi>`/plan-design`</bdi> (مشروط — للحزم الحاملة لمعمارية فقط) ثم <bdi>`/plan-execute`</bdi>؛ أمّا الحزم غير الحاملة لمعمارية فيستهلك <bdi>`/plan-execute`</bdi> بطاقات تقييم المراجعة مباشرةً لضبط التنفيذ عند مستوى SHARED فأعلى.

## مراحل سير العمل

يُجري الأمر تدقيقًا جنائيًّا أعمى سطرًا بسطر، ثم يصقل عبر أسئلة وأجوبة تفاعلية:

1. **تحميل السياق** — قراءة كل ملفات حزمة الخطة (<bdi>`phases/**/PHASE.md`</bdi>، وملفات البنية التحتية، والتقارير) وبيان التسليم الأعلى منها؛ والرفض بـ<bdi>`Blocked: run /plan-generate first`</bdi> عند غياب الحزمة.
2. **التدقيق** — مسح الأبعاد (أمانة النثر، والاتّساق الداخلي، والاكتمال، والجودة، والمخاطر، والمعايير، والمجال، والمعمارية، والجودة الإبداعية) تحت تكليف المراجعة العمياء.
3. **فرز الاكتشافات** — البتّ في كل اكتشاف (قبول · تنقيح · رفض · تأجيل) عبر قناة الاستفسار المُهيكَل مع عدّ الخطورة لكل اكتشاف.
4. **تشغيل بوّابة ما قبل الإصدار** — تشغيل البوّابة ذات الخمسة عشر شريطًا مقابل تقرير المراجعة وبطاقات التقييم المُحدَّثة؛ والفشل يمنع الترقية.
5. **إصدار المراجعة** — كتابة بطاقات تقييم المراجعة إلى <bdi>`PLAN-NOTES.md`</bdi>، وملخّص المراجعة إلى <bdi>`PROGRESS.md`</bdi>، وبيان التسليم المُعزَّز.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| <bdi>Blocked: run /plan-generate first</bdi> | لا توجد حزمة مُولَّدة | شغّل <bdi>`/plan-generate`</bdi> لإنتاج الحزمة التي يدقّقها هذا الأمر |
| اكتشافات مفتوحة باقية | كشف التدقيق عيوبًا غير محسومة | احسم كل اكتشاف (قبول · تنقيح · رفض · تأجيل) قبل الحُكم النهائي |
| بطاقة تقييم FAIL | بُعد يهبط دون عتبة CONDITIONAL | عالِج البُعد المُخفِق وأعد المراجعة |

## أمثلة

```bash
# تشغيل تجريبي لمعاينة نطاق التدقيق
/plan-review --dry-run

# تدقيق حزمة خطة مُسمّاة، مُركَّز على منطقة واحدة
/plan-review path/to/plan-suite/ --focus architecture
```
