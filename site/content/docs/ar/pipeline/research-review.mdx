**الدور:** الباحث الرئيسي (مراجعة الأقران)
**الموضع في خط المعالجة:** منتصف السلسلة

يُخضِع الورقة لنقد تخاصمي بمستوى مراجعة الأقران مقابل معايير جهة النشر — الأصالة، الصرامة، قابلية إعادة الإنتاج، الوضوح، الأخلاقيات، المراجعة الإحصائية، والتوافق مع إرشادات الإبلاغ. يصدر بطاقة تقييم المراجِع ذات **المحاور السبعة** إضافةً إلى قائمة بالمراجعات الإلزامية مُرتّبة بحسب الخطورة، مع تسويغ قائم على مُحرّك ملموس لكل اكتشاف. الدحض افتراضيًا.

## الاستدعاء المعياري

```bash
/research-review
```

مع وسائط:

```bash
/research-review [--suite-name NAME]
```

## المدخلات

مُسلَّم الورقة في الموضع الطبيعي للمضيف الذي سجّلته مرحلة الورقة.

## المخرجات

<bdi>`_outputs/review-report.md`</bdi> — بطاقة تقييم المراجِع ذات **المحاور السبعة** (الأصالة · الصرامة · قابلية إعادة الإنتاج · الوضوح · الأخلاقيات · المراجعة الإحصائية · التوافق مع إرشادات الإبلاغ)، وقائمة المراجعات الإلزامية المُرتّبة بحسب الخطورة (<bdi>HIGH</bdi> / <bdi>MEDIUM</bdi> / <bdi>LOW</bdi>) مع تسويغ قائم على مُحرّك ملموس لكل اكتشاف، وحزمة قابلية إعادة الإنتاج وحُكم إعادة التشغيل، وتدقيق سلامة الاستشهادات، والحُكم العامّ <bdi>`accept · minor-revision · major-revision · reject`</bdi>.

## المراحل اللاحقة

<bdi>/research-publish</bdi> (المستهلِك اللاحق). يعني حكمُ <bdi>`major-revision`</bdi> أو <bdi>`reject`</bdi> أنّ المراجعات المطلوبة يجب معالجتها قبل تشغيل <bdi>`/research-publish`</bdi>.

## مراحل سير العمل

يتّبع الأمر سير العمل المعياري لخط معالجة <bdi>`/research`</bdi>:

1. **تحميل السياق** — اقرأ مُخرَج الورقة.
2. **التحقّق من بوّابة التسلسل** — تأكيد وجود الورقة و<bdi>`_outputs/analysis.md`</bdi> و<bdi>`_inputs/synthesis.md`</bdi> وأنها غير فارغة؛ وإلّا يتوقّف التنفيذ برسالة <bdi>`Blocked: run /research-paper first`</bdi>.
3. **المراجعة التخاصمية** — قيّم المحاور السبعة (الأصالة · الصرامة · قابلية إعادة الإنتاج · الوضوح · الأخلاقيات · المراجعة الإحصائية · التوافق مع إرشادات الإبلاغ)؛ وشغّل إعادة تشغيل قابلية إعادة الإنتاج وتدقيق سلامة الاستشهادات؛ والدحض افتراضيًّا؛ وحدِّد العيوب الملموسة بالأدلّة.
4. **فرز المراجعات** — رتِّب المراجعات المطلوبة <bdi>HIGH</bdi> / <bdi>MEDIUM</bdi> / <bdi>LOW</bdi> مع تسويغ قائم على دافع ملموس.
5. **تحديث بيان التسليم** — سجِّل تقرير المراجعة وحُكم بطاقة التقييم.
6. **إصدار المراجعة** — <bdi>`_outputs/review-report.md`</bdi>.

## الحدّ الأدنى للصرامة

تُقيِّم المراجعةُ الادّعاءات التجريبية مقابل عتبة بوّابة التقدّم — إعادة تكرار كافية، ودلالة لا معلميّة مع حجم أثر ورتب فروق حرجة، وتكافؤ ميزانية عبر الطرائق المُقارَنة — وتعامل الحُكم بوصفه بوّابةَ تقدّم صريحة: لا تتقدّم ورقةٌ إلا حين تتفوّق على عتبة جهة النشر تفوّقًا مُقنِعًا وذا دلالة، مع تسجيل الاجتياز. وفي ظلّ جهة نشر مزدوجة التعمية، يَسِم المراجِعُ أيضًا أيّ تسرّب للهوية بوصفه عيبًا في إخفاء الهوية.

## أنماط الفشل

| العَرَض | السبب | التعافي |
|---------|-------|----------|
| Blocked: run /research-paper first | لا توجد ورقة | شغّل <bdi>`/research-paper`</bdi> لإنتاج المخطوطة |
| تقييم متساهل | افترض المراجِع أفضل الحالات | الدحض افتراضيًا؛ قيّم وفق الأدلّة المتوفّرة |
| اكتشاف بلا تسويغ | المراجعة مُدّعاة لا مُبرّرة | أرفِق تسويغًا قائمًا على مُحرّك ملموس بكل اكتشاف |

## أمثلة

```bash
# راجِع الورقة بمراجعة الأقران وأصدِر بطاقة تقييم المراجِع
/research-review --suite-name <name>
```
