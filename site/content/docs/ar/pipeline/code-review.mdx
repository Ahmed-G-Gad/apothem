**الدور:** المُراجِع
**موضع خط الأنابيب:** القلعة

مرور مراجعة لجودة الشِّفرة يقوده المُشغِّل، ملفًا ملفًا، عبر <bdi>src/</bdi> و<bdi>scripts/</bdi> و<bdi>tools/</bdi>.

## الاستدعاء المعياري

```bash
/code-review
```

مع وسائط:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## المدخلات

مستودع المُضيف في أيّ حالة من حالات دورة الحياة

## المخرجات

نتائج لكلّ ملف في <bdi>`_inputs/code-review-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة المراجعة سطرًا سطرًا من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل: استيعاب المدخلات، وجولة على كل ملف، وفرز كل نتيجة، وإصدار النتائج، وبوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملف إدخال مفقود | المستودع لا يحتوي أيًّا من <bdi>`src/`</bdi> أو <bdi>`scripts/`</bdi> أو <bdi>`tools/`</bdi> | مرِّر جذر مستودع يحتوي واحدًا على الأقل منها |

## أمثلة

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
