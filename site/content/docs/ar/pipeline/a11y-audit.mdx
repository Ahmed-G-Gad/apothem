**الدور:** مدقّق إتاحة الوصول
**موضع خط الأنابيب:** القلعة

تدقيق إتاحة الوصول مقابل <bdi>WCAG 2.2 AA</bdi> لكلّ صفحة مُصيَّرة.

## الاستدعاء المعياري

```bash
/a11y-audit
```

مع وسائط:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## المدخلات

موقع المشروع الإلكتروني المنشور أو المُقدَّم محليًّا

## المخرجات

نتائج إتاحة الوصول في <bdi>`_inputs/a11y-audit-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة تدقيق إتاحة الوصول من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل للتدقيق: استيعاب المدخلات، وتدقيق كل صفحة، وفرز كل نتيجة، وإصدار النتائج، وبوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملف إدخال مفقود | مسار الموقع أو <bdi>URL</bdi> لا يُحلّ إلى موقع | مرِّر دليلًا لموقع مبنيّ أو <bdi>URL</bdi> يمكن الوصول إليه |

## أمثلة

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
