**الدور:** مُراجِع تجربة الاستخدام
**الموضع في خط الأنابيب:** الحصن

مراجعةُ تجربة المُطوِّر لأرغونوميا واجهة سطر الأوامر والوثائق والانضمام الأوّل.

## الاستدعاء القانوني

```bash
/ux-review
```

مع وسائط:

```bash
/ux-review [path/to/repo/] [--focus SURFACE] [--dry-run]
```

## المُدخَلات

مستودع مُضيف مُنشَر يحتوي على <bdi>README</bdi> وسكربتات التثبيت ونقطة دخول <bdi>CLI</bdi>

## المُخرَجات

نتائج تجربة الاستخدام في <bdi>`_inputs/ux-review-findings.md`</bdi>

## المصبّ

طور مراجعة تجربة الاستخدام من تسلسل تدقيق المراجعة

## أطوار سير العمل

يُنفِّذ الأمر خمسة أطوار: استيعاب المدخلات، وجولة على <bdi>CLI</bdi> من حيث سهولة الاستخدام، وتدقيق تدفّق التثبيت واستعادة الأخطاء، ومسح قابلية اكتشاف التوثيق، وإصدار النتائج مع بوابة التحقّق.

## أنماط الإخفاق

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| متطلب مسبق غير مكتمل | لم ينتهِ الطور المعتمَد عليه | أكمِل الطور في اتجاه المنبع أولًا |
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| الهدف غير مُنشَر | الهدف يفتقر إلى السطح الموجَّه للمُشغِّل | مرِّر جذر المستودع المُنشَر |

## أمثلة

```bash
# Dry-run to preview what would happen
/ux-review --dry-run

# Execute against a host repository
/ux-review path/to/repo/
```
