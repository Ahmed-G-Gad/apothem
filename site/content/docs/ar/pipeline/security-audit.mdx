**الدور:** مُدقِّق الأمان
**موضع خط الأنابيب:** القلعة

تدقيق شامل لوضع الأمان مقابل <bdi>OWASP ASVS</bdi> 4.0 أو أحدث، و<bdi>OWASP Top 10</bdi>.

الحدّ الأدنى للأمر هو آخر إصدار تصحيحي من <bdi>ASVS</bdi> 4.0. ولا يبحث بنفسه عن إصدارات <bdi>ASVS</bdi> الأحدث. وتُشير الملاحظات إلى فصول <bdi>ASVS</bdi> برقمها وعنوانها المختصر، مثل <bdi>V5</bdi> (التحقّق والتعقيم والترميز)، و<bdi>V12</bdi> (الملفات والموارد)، و<bdi>V14</bdi> (الإعدادات).

## الاستدعاء المعياري

```bash
/security-audit
```

مع وسائط:

```bash
/security-audit [path/to/repo/] [--focus CATEGORY] [--dry-run]
```

## المدخلات

مستودع المُضيف عند الـ<bdi>commit</bdi> المُثبَّت في <bdi>git</bdi>

## المخرجات

نتائج الأمان في <bdi>`_inputs/security-audit-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة <bdi>security-audit</bdi> من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر ست مراحل للتدقيق: استيعاب المدخلات، والأسرار والصلاحيات، والتحقّق من المدخلات والحقن، وإلغاء التسلسل واجتياز المسارات، وثغرات <bdi>CVE</bdi> في التبعيات و<bdi>CodeQL</bdi>، وإصدار النتائج مع بوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| متطلب مسبق غير مكتمل | لم تنتهِ المرحلة المعتمَد عليها | أكمل المرحلة في اتجاه المنبع أولًا |
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| رفض الهدف | المسار ليس شجرة عمل <bdi>git</bdi> | مرِّر جذر المستودع بوصفه المسار |

## أمثلة

```bash
# Dry-run to preview what would happen
/security-audit --dry-run

# Execute against a host repository
/security-audit path/to/repo/
```
