**الدور:** الباحث الرئيسي (التأليف)
**الموقع في خطّ المعالجة:** في منتصف السلسلة

يجمّع مسودة ورقة بحثية من الطراز الأول انطلاقًا من التركيب والتصميم والتحليل — الملخّص، والمقدّمة، والأعمال ذات الصلة، والمنهج، والنتائج، والمناقشة، والقيود، والخاتمة، والمراجع. يُتحقَّق من كل استشهاد ليحلّ إلى مصدر حقيقي؛ لا استشهادات وهمية.

## الاستدعاء القياسي

```bash
/research-paper
```

مع وسائط:

```bash
/research-paper [path/to/research-suite/]
```

## المدخلات

<bdi>`_inputs/synthesis.md`</bdi> (خريطة <bdi>SOTA</bdi> + الفجوة)، و<bdi>`_inputs/study-design.md`</bdi> (المنهج)، و<bdi>`_outputs/analysis.md`</bdi> (النتائج).

## المخرجات

ناتج الورقة في موقع طبيعي للمضيف (<bdi>`paper/`</bdi>) — الملخّص، والمقدّمة، والأعمال ذات الصلة، والمنهج، والنتائج، والمناقشة، والقيود، والخاتمة، والمراجع.

## التدفّق السفلي

<bdi>/research-review</bdi> (مستهلك التدفّق السفلي)

## مراحل سير العمل

يتّبع الأمر سير العمل القياسي لخطّ معالجة <bdi>`/research`</bdi>:

1. **تحميل السياق** — قراءة التركيب وتصميم الدراسة والتحليل.
2. **التحقّق من بوابة التسلسل** — تأكيد وجود <bdi>`_outputs/analysis.md`</bdi>؛ وإلّا فالتوقّف بـ <bdi>`Blocked: run /research-analysis first`</bdi>.
3. **تجميع المسودة** — تأليف المحتوى من الملخّص حتى الخاتمة؛ تستند المقدّمة والأعمال ذات الصلة إلى التركيب، ويستند المنهج إلى التصميم، وتستند النتائج إلى التحليل.
4. **التحقّق من الاستشهادات** — يحلّ كل مرجع إلى مصدر حقيقي.
5. **تحديث بيان التسليم** — تسجيل مسار ناتج الورقة.
6. **إصدار الورقة** — المخطوطة في موقع <bdi>`paper/`</bdi> الطبيعي للمضيف.

## الحدّ الأدنى للصرامة

في ظلّ جهة نشر مزدوجة التعمية، لا تحمل المخطوطةُ إلا ما تسمح به سياسةُ إخفاء الهوية: يُوصَف المؤلّف والمؤسّسة والتمويل والنظام قيد الدراسة بلغة مجال طبيعية دون تسميتها، مع حجزها لبيانات وصفية تُقدَّم منفصلةً لمرحلة كشف هوية مُخصَّصة. ويتناسب عمقُ قابلية إعادة الإنتاج والإبلاغ الإحصائي مع طموح جهة النشر المستهدَفة.

## أنماط الإخفاق

| العَرَض | السبب | التعافي |
|---------|-------|----------|
| <bdi>Blocked: run /research-analysis first</bdi> | لا تحليل | شغّل <bdi>`/research-analysis`</bdi> لإنتاج <bdi>`_outputs/analysis.md`</bdi> |
| استشهاد وهمي | المرجع لا يحلّ | احذف الاستشهاد أو صحّحه؛ لا تختلق مصدرًا أبدًا |
| نتائج مبالَغ فيها | المناقشة تتجاوز التحليل | قيّد الادّعاءات بأحجام الأثر المحلّلة + فترات الثقة |

## أمثلة

```bash
# تجميع مسودة الورقة انطلاقًا من التركيب + التصميم + التحليل
/research-paper path/to/research-suite/
```
