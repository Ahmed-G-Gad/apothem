**الدور:** الباحث الرئيسي (الصياغة)
**الموضع في خط المعالجة:** منتصف السلسلة

يصوغ سؤال بحث حُرّ الصياغة أو ملاحظات خامًا في <bdi>`_spec/research-spec.md`</bdi> بمستوى المواصفة — مجموعة فرضيات قابلة للاختبار والدحض بنطاق صريح، ومعايير تضمين / استبعاد، ومقاييس نجاح — جاهزة لـ <bdi>`/research-theory`</bdi>.

## الاستدعاء المعياري

```bash
/research-spec
```

مع الوسائط:

```bash
/research-spec [path/to/question-or-notes] [--suite-name NAME] [--quick SLUG]
```

## المدخلات

سؤال بحث حُرّ الصياغة أو ملاحظات خام (يقدّمها المُشغِّل ضمن السطر أو كمسار).

## المخرجات

<bdi>`_spec/research-spec.md`</bdi> (السؤال، والفرضيات القابلة للدحض، والنطاق، ومعايير التضمين / الاستبعاد، ومقاييس النجاح، والمسرد) ＋ <bdi>`_inputs/handoff-manifest.yml`</bdi>. أمّا <bdi>`--quick`</bdi> فيكتب بدلًا من ذلك موجزًا بحثيًّا خفيفًا محليًّا للمشروع.

## المراحل اللاحقة

<bdi>/research-theory</bdi> (المستهلِك اللاحق)

## مراحل سير العمل

يتّبع الأمر سير عمل خط معالجة <bdi>`/research`</bdi> القياسي:

1. **تحميل السياق** — قراءة السؤال / الملاحظات، والقواعد، وأي حالة قائمة للحزمة.
2. **صياغة السؤال** — التفكيك إلى فرضيات قابلة للدحض بنطاق صريح ومعايير تضمين / استبعاد؛ وإظهار كل التباس عبر قناة الاستفسار المُهيكَل.
3. **تحديد مقاييس النجاح** — بيان المعايير القابلة للقياس التي سيُحكَم بها على البحث.
4. **التحقّق من المخرجات** — التأكّد من أن المواصفة قاطعة (كل فجوة في بيانات السلطة قد حُلّت عبر قناة الاستفسار المُهيكَل، ولم يُترَك أيٌّ منها كعنصر نائب تأكيد غير معبّأ) وأنها تجتاز الحدّ الأدنى لتفويض الصرامة.
5. **تحديث بيان التسليم** — تسجيل مسار المواصفة وأعداد الاستفسارات المفتوحة / المحلولة.
6. **إصدار المواصفة** — <bdi>`_spec/research-spec.md`</bdi> إضافةً إلى بيان التسليم.

## الحدّ الأدنى للصرامة

يُقيَّد كلُّ إسهام مُدَّعى بأن يكون متمايزًا وجوهريًّا وقابلًا للاستئصال باستقلالية، حتى يمكن عزل أثره الحدّي لاحقًا. ويتناسب عمقُ الحدّ الأدنى للصرامة المطلوب مع طموح جهة النشر المستهدَفة؛ وحيثما لم يُحدَّد ذلك الطموح جرى تأكيده عبر الاستفسار المُهيكَل، ولا يُختلَق أبدًا.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| التباس فرضية غير محلول | السؤال غير محدّد بدقة كافية | الإظهار عبر الاستفسار المُهيكَل؛ لا تختلق نطاقًا |
| لا يوجد مقياس نجاح قابل للقياس | الهدف مذكور كنشاط لا كنتيجة | إعادة الصياغة كنتيجة قابلة للاختبار والدحض |
| مدخل السؤال مفقود | لم يُقدَّم نصّ / ملاحظات | قدِّم سؤال البحث ضمن السطر أو كمسار |

## أمثلة

```bash
/research-spec --quick retrieval-latency
```
