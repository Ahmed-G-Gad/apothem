**الدور:** الحارس
**الموضع في خط الأنابيب:** ملفِّف / متعامد (قبل التنفيذ)

حارسٌ ذو حلقة مغلقة لخط أنابيب <bdi>`/plan`</bdi>. حيث يُبلِّغ <bdi>`/plan-review`</bdi> عن حزمة مُولَّدة ويُنقِّحها، يلفّ <bdi>`/plan-audit`</bdi> الدورة المنبعية (<bdi>`/plan-spec → /plan-generate → /plan-review`</bdi>) ويقود الحزمة إلى كُلٍّ مُراجَعٍ بلا نتائج — مُشغِّلًا الأطوار المنبعية المفقودة فقط، ومُدقِّقًا في النتيجة، ومُصلِحًا في مكانها النتائج القابلة للحل آليًا، ومُظهِرًا مفارق الحُكم عبر قناة الاستفسار المُهيكَل، ومُكرِّرًا حتى تصير الحزمة نظيفة أو يُطلَق تراجعٌ محدود. وهو لا يُنفِّذ أبدًا عمل تنفيذ الأطوار؛ بل يترك الحزمة جاهزةً لـ <bdi>`/plan-execute`</bdi>.

## الاستدعاء القانوني

```bash
/plan-audit
```

مع وسائط:

```bash
/plan-audit [suite-path] [--from spec|generate|review] [--remediate] [--cap N] [--maintenance] [--dry-run]
```

## المُدخَلات

<bdi>`_spec/spec.md`</bdi> الخاص بالحزمة الهدف، و<bdi>`_inputs/handoff-manifest.yml`</bdi>، وملفّات البنية التحتية، و<bdi>`phases/**/PHASE.md`</bdi>، وأيّ تقارير أطوار قائمة.

## المُخرَجات

تقريرٌ دائمٌ ومحدودٌ عند <bdi>`<suite>/_outputs/audit-report-<YYYY-MM-DD>.md`</bdi>؛ وبيان تسليم مُحدَّث يحمل حُكم انعدام النتائج، وعدد النتائج المفتوحة، وسجلّ المعالجة، وأيّ توجيه صيانة؛ وحالة طرفية غير صفرية عندما تبقى نتائج متبقّية.

## الموضع في خط الأنابيب

<bdi>`/plan-audit`</bdi> **متعامد** على خط الأنابيب الخطّي، وليس طورًا داخله. التسلسل الخطّي القانوني هو <bdi>`/plan-spec → /plan-generate → /plan-review → /plan-design`</bdi> (شَرطي، للحزم الحاملة للمعمارية فقط) <bdi>`→ /plan-execute`</bdi>. يشمل <bdi>`/plan-audit`</bdi> الأطوار <bdi>`/plan-spec → /plan-generate → /plan-review`</bdi> بوصفها مُلفِّفًا ذا حلقة مغلقة واحدًا يمكن استدعاؤه عند أيّ نقطة: يفحص الحالة ويُشغِّل الأطوار المفقودة فقط. وهو متميّز عن سلسلة تدقيق الحصن (تُدخَل عند <bdi>`/code-review`</bdi>، وطرفية عند <bdi>`/threat-model-audit`</bdi>)، التي تُدقِّق في قاعدة شِفرة مُنفَّذة بدلًا من حزمة خطّة.

## أطوار سير العمل

1. **حلّ الهدف** — يحلّ الحزمة من الوسيط، أو يختار الحزمة الأحدث تعديلًا تحت <bdi>`.apothem/plans/`</bdi> (<bdi>`.plans/`</bdi> بديل احتياطي متوافق مع الإصدارات السابقة) ويُعلِن عن الحلّ.
2. **تقييم الطور** — يكشف أيّ آثار موجودة (<bdi>spec</bdi> جاهز / مُولَّد / مُراجَع / مُنفَّذ) ويُسمّي أصغر فجوة نحو كُلٍّ مُراجَعٍ قابلٍ للتنفيذ.
3. **الوصول إلى كُلٍّ قابلٍ للمراجعة** — يُشغِّل الأطوار المنبعية المفقودة فقط، مُفوِّضًا كلّ فجوة إلى الأمر القانوني لها؛ ولا يُعيد أبدًا تشغيل طورٍ مُستوفًى لمجرّد تحديث النثر.
4. **التدقيق الجنائي** — يُطبِّق أبعاد تدقيق <bdi>`/plan-review`</bdi>، وكتالوج تقنيات التخطيط، وبوابة ما قبل الإصدار ذات الخمسة عشر قضيبًا.
5. **المعالجة النشطة** — يُصلِح النتائج الآلية في مكانها؛ ويُظهِر مفارق الحُكم عبر قناة الاستفسار المُهيكَل؛ ويُوجِّه العمل الخارج عن النطاق شرعًا إلى حزمة شقيقة <bdi>`*-maintenance`</bdi>.
6. **حلقة بسقفٍ وتراجع** — يُكرِّر التدقيق-والمعالجة حتى لا تبقى نتائج مفتوحة، محدودًا بسقف تكرار (الافتراضي 3) مع تراجعٍ مُعرَّف عند استنفاد السقف.

## أنماط الإخفاق

| العَرَض | السبب | التعافي |
|---------|-------|----------|
| استُنفِد السقف مع نتائج متبقّية | نتائج غير قابلة للحل ضمن سقف التكرار | راجِع تقرير التدقيق؛ ووجِّه البنود المؤهَّلة إلى حزمة <bdi>`*-maintenance`</bdi>؛ ولا ترفع <bdi>`--cap`</bdi> إلّا بمبرّر |
| مفترق حُكم غير محلول | نتيجةٌ تتطلّب قرار سياسة/نطاق/صلاحية | أجِب على مُحَثّ الاستفسار المُهيكَل؛ فالحلقة لا تختار في صمت أبدًا |
| غياب <bdi>spec</bdi> ذي مرجعية | لا يوجد <bdi>`_spec/spec.md`</bdi> | يُوجِّه المُلفِّف إلى <bdi>`/plan-spec`</bdi> لتأليفه |
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | تُصلِح المعالجة السبب الجذري وتُعيد تدقيق المواضع المُلامَسة |

## أمثلة

```bash
# Dry-run: report detected suite, stage, planned audit dimensions, would-write targets
/plan-audit --dry-run

# Audit and actively remediate a named suite, capping the loop at 2 iterations
/plan-audit path/to/plan-suite/ --remediate --cap 2
```
