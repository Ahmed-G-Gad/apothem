**الدور:** مُدقِّق التبعيات
**موضع خط الأنابيب:** القلعة

مرور تدقيق لكلّ تبعية (المباشرة + المتعدّية) للتحقّق من الترخيص و<bdi>CVE</bdi> والحداثة.

## الاستدعاء المعياري

```bash
/dependency-audit
```

مع وسائط:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## المدخلات

بيانات تبعيات مستودع المُضيف

## المخرجات

نتائج التبعيات في <bdi>`_inputs/dependency-audit-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة <bdi>dependency-audit</bdi> من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل: استيعاب المدخلات، وجولة على كل تبعية، وفرز كل نتيجة، وإصدار النتائج، وبوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ملف إدخال مفقود | لا يُحلّ أي ملف بيان تبعيات في جذر المستودع | مرِّر جذر مستودع يحتوي ملف بيان تبعيات |

## أمثلة

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
