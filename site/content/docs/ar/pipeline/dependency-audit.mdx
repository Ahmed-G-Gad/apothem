**الدور:** مُدقِّق التبعيات
**موضع خط الأنابيب:** القلعة

مرور تدقيق لكلّ تبعية (المباشرة + المتعدّية) للتحقّق من الترخيص و<bdi>CVE</bdi> والحداثة.

## الاستدعاء المعياري

```bash
/dependency-audit
```

مع وسائط:

```bash
/dependency-audit [path/to/plan-suite/] [phase-id] [--dry-run]
```

## المدخلات

بيانات تبعيات مستودع المُضيف

## المخرجات

نتائج التبعيات + <bdi>REPORT.md</bdi>

## في اتجاه المصبّ

مرحلة <bdi>dependency-audit</bdi> من تسلسل مراجعة التدقيق

## مراحل سير العمل

يتّبع الأمر سير العمل المعياري لخط أنابيب <bdi>`/plan`</bdi>:

1. **تحميل السياق** — يقرأ حزمة الخطة والقواعد وعقد الاستئناف.
2. **التحقّق من المتطلبات المسبقة** — يؤكّد اكتمال مراحل التبعية.
3. **تنفيذ المهام** — يؤدّي مهمّة الأمر.
4. **التحقّق من المخرجات** — يؤكّد وجود جميع المخرجات المُعلَنة واجتيازها بوّابات الجودة.
5. **تحديث <bdi>PROGRESS.md</bdi>** — يسجّل المخرجات المُتحقَّق منها في سجلّ مخرجات المرحلة.
6. **إصدار <bdi>REPORT.md</bdi>** — يُسجَّل إثبات الإفراج لبوّابة ما قبل الإصدار.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| متطلب مسبق غير مكتمل | لم تنتهِ المرحلة المعتمَد عليها | أكمل المرحلة في اتجاه المنبع أولًا |
| بوّابة الجودة FAIL | المُخرَج لا يفي بالمعايير | أصلح المُخرَج وأعد التشغيل |
| ملف إدخال مفقود | ملف حزمة الخطة غائب | شغّل <bdi>`/plan-generate`</bdi> لإنشائه |

## أمثلة

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a named plan suite
/dependency-audit path/to/plan-suite/
```
