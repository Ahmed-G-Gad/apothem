- **الدور:** مدقّق الأداء
- **موضع خط الأنابيب:** القلعة

يدقّق مقابل ميزانيات الأداء لكلّ صنف (زمن تشغيل الخطّافات، و<bdi>verify-ecosystem</bdi>، وبوابة المطابقة، والاختبارات، والعمّال المُفوَّضون، و<bdi>shell</bdi>، و<bdi>lint</bdi>، وتحليل التثبيت)، باستخدام أسلوب <bdi>USE</bdi>.

## الاستدعاء المعياري

```bash
/perf-audit
```

مع وسائط:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## المدخلات

نسخة من مستودع <bdi>Apothem</bdi> تحتوي على <bdi>`src/apothem/hooks/`</bdi> و<bdi>`src/apothem/benchmarks/`</bdi> و<bdi>`tests/`</bdi>، وعلى هياكل التمهيد الأولية للخطّافات <bdi>`src/apothem/hooks/lib/bootstrap.{sh,ps1}`</bdi>

## المخرجات

نتائج الأداء في <bdi>`_inputs/perf-audit-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة تدقيق الأداء من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل للتدقيق: استيعاب المدخلات، واكتشاف ميزانيات كل صنف، وتنفيذ المقاييس المرجعية، وتحديد المسارات الساخنة بأسلوب <bdi>USE</bdi>، وإصدار النتائج مع بوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| ليست نسخة من مستودع <bdi>Apothem</bdi> | المستودع يفتقد <bdi>`src/apothem/benchmarks/`</bdi> | لا شيء يحتاج إلى إصلاح: يُبلغ الأمر أن هذا البُعد غير منطبق، ويتخطّاه <bdi>`/audit`</bdi> |

## أمثلة

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
