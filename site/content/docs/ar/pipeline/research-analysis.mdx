**الدور:** الباحث الرئيسي (التحليل)
**الموضع في خط المعالجة:** منتصف السلسلة

يحلّل البيانات الخام وفق الخطة المُسجَّلة مسبقًا — يُجري الاختبارات الإحصائية المُخطَّطة، ويُبلّغ عن أحجام الأثر مع فترات الثقة (لا قيم <bdi>p</bdi> وحدها)، ويطبّق تصحيح المقارنات المتعدّدة حيث ينطبق، ويُجري فحوص المتانة / الحساسية، ويُفصِح عن كل انحراف عن التسجيل المسبق.

## الاستدعاء المعياري

```bash
/research-analysis
```

مع الوسائط:

```bash
/research-analysis [path/to/research-suite/]
```

## المدخلات

البيانات الخام في الموضع الطبيعي للمضيف الذي سجّلته مرحلة التجربة، إضافةً إلى <bdi>`_inputs/preregistration.md`</bdi> (خطة التحليل المُجمَّدة).

## المخرجات

<bdi>`_outputs/analysis.md`</bdi> (الاختبارات المُسجَّلة مسبقًا مع أحجام الأثر وفترات الثقة، وتصحيح المقارنات المتعدّدة، وفحوص المتانة، والانحرافات المُفصَح عنها) ＋ الأشكال / الجداول في موضع طبيعي للمضيف.

## المراحل اللاحقة

<bdi>/research-paper</bdi> (المستهلِك اللاحق)

## مراحل سير العمل

يتّبع الأمر سير عمل خط معالجة <bdi>`/research`</bdi> القياسي:

1. **تحميل السياق** — قراءة البيانات الخام والتسجيل المسبق.
2. **التحقّق من بوابة التسلسل** — التأكّد من وجود مخرجات التجربة؛ وإلا التوقّف مع <bdi>`Blocked: run /research-experiment first`</bdi>.
3. **التحليل** — تشغيل الاختبارات المُسجَّلة مسبقًا؛ والإبلاغ عن أحجام الأثر ＋ فترات الثقة؛ وتصحيح المقارنات المتعدّدة؛ وإجراء فحوص المتانة / الحساسية.
4. **الإفصاح عن الانحرافات** — تسجيل كل خروج عن الخطة المُسجَّلة مسبقًا.
5. **تحديث بيان التسليم** — تسجيل مسار التحليل والأشكال / الجداول.
6. **إصدار التحليل** — <bdi>`_outputs/analysis.md`</bdi> ＋ الأشكال / الجداول.

## الحدّ الأدنى للصرامة

تُبلَّغ النتائج العشوائية بوصفها الأفضل والمتوسّط والوسيط والانحراف المعياري والأسوأ عبر التكرارات، مع منحنيات التقارب ومخطّطات التوزيع. وتستخدم المقارناتُ اختباراتٍ لا معلميّةً — اختبار الرتب المُوقَّعة المُزدوَج للمقارنة الثنائية، واختبار رتب شامل مع تصحيح بَعدِيّ عبر الطرائق — مُبلَّغةً مع حجم أثر التفوّق العشوائي ومخطّط الفروق الحرجة. ولا تتقدّم نتيجةٌ إلى الورقة إلا حين تجتاز بوّابة التقدّم: أن تتفوّق على مُقارِناتها تفوّقًا مُقنِعًا وذا دلالة، وأن يُسجَّل هذا الاجتياز في سجلّ تشغيل قابل للتدقيق.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| <bdi>Blocked: run /research-experiment first</bdi> | لا توجد بيانات خام | شغّل <bdi>`/research-experiment`</bdi> لإنتاج البيانات ＋ السجلّ |
| الإبلاغ عن قيمة <bdi>p</bdi> دون حجم الأثر | تقرير إحصائي غير مكتمل | بلِّغ عن أحجام الأثر ＋ فترات الثقة |
| انحراف تحليلي غير مُفصَح عنه | انحرفت الخطة بصمت | أفصِح عن الانحراف مقابل التسجيل المسبق |
