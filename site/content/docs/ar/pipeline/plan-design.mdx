**الدور:** المعماري
**الموضع في خط الأنابيب:** شَرطي، بعد المراجعة وقبل التنفيذ

يُنتِج أثر التصميم المعماري عند <bdi>`_inputs/design.md`</bdi> عندما تحوي حزمة
الخطّة عملًا حاملًا للمعمارية. وهو شَرطي عن قصد: فحزمة النثر أو التوثيق أو
البيانات الوصفية أو التجهيزات الضيّقة تنتقل من <bdi>`/plan-review`</bdi> مباشرةً
إلى <bdi>`/plan-execute`</bdi>؛ أمّا الحزمة التي تُغيِّر المكوّنات أو الواجهات أو
المخطّطات أو تدفّق البيانات أو المُحوِّلات أو طوبولوجيا الإصدار أو حدود الأمان أو
سلوك التشغيل فتمرّ عبر <bdi>`/plan-design`</bdi> أولًا.

## الاستدعاء القانوني

```bash
/plan-design path/to/plan-suite/
```

مع وسائط:

```bash
/plan-design [path/to/plan-suite/] [--refine-existing] [--dry-run]
```

## المُدخَلات

حزمة خطّة مُراجَعة + <bdi>`_spec/spec.md`</bdi> + <bdi>`_inputs/handoff-manifest.yml`</bdi>
+ بطاقات نتائج مراجعة <bdi>PASS</bdi> من <bdi>`/plan-review`</bdi>.

## المُخرَجات

<bdi>`_inputs/design.md`</bdi> إضافةً إلى <bdi>`_inputs/handoff-manifest.yml`</bdi>
مُعزَّز يحمل مسار أثر التصميم، ونتيجة بوابة التصميم، ونتيجة التغطية على سبعة
محاور، وملخّص مصفوفة الربط ثنائية الاتجاه.

## بوابة القابلية للتطبيق

شغِّل <bdi>`/plan-design`</bdi> عندما يُعلِن أو يضمر طورٌ تالٍ واحد على الأقل ما
يلي:

- تغييرات في تخطيط المصدر أو حدّ الحزمة أو حدّ المُحوِّل أو حدّ الوحدة.
- واجهات عامة أو بروتوكولات أو مخطّطات أو عقود تهيئة أو سلوك <bdi>CLI</bdi>.
- تدفّق بيانات عبر المكوّنات أو ترتيب دورة الحياة أو انتقالات الحالة أو حواف
  الاعتماد.
- معمارية الأمان أو الأداء أو التزامن أو القابلية للرصد أو النشر أو الإصدار أو
  سلسلة التوريد.
- تمريرة <bdi>`/architecture-review`</bdi> لاحقة يجب أن تتبّع التنفيذ رجوعًا إلى
  أثر تصميم.

تخطَّ <bdi>`/plan-design`</bdi> عندما تقتصر الحزمة على تحريرات نصّية أو تحديثات
لجرد مُولَّد أو تحديثات تجهيزات ضيّقة أو إصلاحات توثيق لمرّة واحدة أو عملٍ آخر
يمكن التحقّق من تنفيذه دون سطح تتبّع معماري. ومسار التخطّي صريح: يُسجِّل
<bdi>`/plan-review`</bdi> التصنيف غير المعماري، ثم يتابع <bdi>`/plan-execute`</bdi>
من حزمة الخطّة المُراجَعة.

## المصبّ

يستهلك <bdi>`/plan-execute`</bdi> أثر التصميم للأطوار الحاملة للمعمارية. ويستهلك
<bdi>`/architecture-review`</bdi> الأثر نفسه أثناء سلسلة مراجعة التدقيق. وإن كان
<bdi>`_inputs/design.md`</bdi> غائبًا عن عملٍ حاملٍ للمعمارية، توقّفت مراجعة
المعمارية وأعادت توجيه الحزمة عبر <bdi>`/plan-design`</bdi>.

## أطوار سير العمل

يتّبع الأمر ستة أطوار تحويلية خاصة بالمعمارية:

1. **ابتلاع المُدخَلات** — يقرأ الحزمة المُراجَعة وبطاقات النتائج ومُخرَجات
   الأطوار وبيان التسليم؛ ويحجب عند دليل مراجعة مفقود أو فاشل في <bdi>SHARED+</bdi>.
2. **التفكيك المعماري** — يجوب المعمارية والتزامن والأداء والأمان والاختبار
   و<bdi>Tooling</bdi> والقابلية للرصد؛ ويُحدِّد المكوّنات والحواف والأسئلة
   المعمارية المفتوحة.
3. **تصميم واجهة المكوّنات** — يُعرِّف الواجهات العامة وعقود البروتوكولات
   والمخطّطات والثوابت وأنماط الإخفاق وحدود عكس الاعتماد.
4. **التصديق على الروابط بين المكوّنات** — يُغلِق كلّ حافة منبع ومصبّ وشقيقة
   ومعيار ومرساة؛ ويُصدِر مصفوفة ربط ثنائية الاتجاه عندما يعبر بيان المكوّنات
   عتبة المصفوفة.
5. **إصدار أثر التصميم** — يكتب <bdi>`_inputs/design.md`</bdi> مع أقسام المكوّنات
   والمخطّطات وسجلّات القرارات ونتيجة التحقّق والروابط.
6. **بوابة التحقّق من التصميم** — يُشغِّل بوابة ما قبل الإصدار ذات الخمسة عشر
   قضيبًا؛ ولا يُحدِّث <bdi>`_inputs/handoff-manifest.yml`</bdi> إلّا بعد اجتياز
   التصميم.

## شكل أثر التصميم

يحتوي <bdi>`_inputs/design.md`</bdi> المُصدَر على:

- ملخّص تنفيذي يحوي عدد المكوّنات والتغطية على سبعة محاور.
- قسم واحد لكلّ مكوّن رئيسي، مُرتَّب من أسطح المجال الداخلية إلى المُحوِّلات
  وأسطح المُشغِّل الخارجية.
- مخطّطات <bdi>Mermaid</bdi> للمعمارية أو التسلسل أو الحالة أو الاعتماد حيث يكون
  الهيكل غامضًا لولا ذلك.
- سجلّات قرارات معمارية مُستقِرّة مع البدائل والمفاضلات وملاحظات القابلية
  للعكس.
- نتيجة بوابة التحقّق ومصفوفة الربط ثنائية الاتجاه عند الاقتضاء.
- روابط الأثر نفسه الخماسية الاتجاه نحو أسطح التخطيط في المنبع والمصبّ.

## أنماط الإخفاق

| العَرَض | السبب | التعافي |
|---------|-------|----------|
| متطلّب مُسبَق ناقص | طور مُعتمَد عليه غير مكتمل | أكمِل الطور المنبعي أولًا |
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| الحزمة المُراجَعة مفقودة | حزمة الخطّة أو بطاقات المراجعة غائبة | شغِّل <bdi>`/plan-generate`</bdi> ثم <bdi>`/plan-review`</bdi> |
| حزمة غير معمارية | لا طور يحتاج سطح تتبّع معماري | سجِّل التخطّي وتابِع إلى <bdi>`/plan-execute`</bdi> |
| مراجعة المعمارية تحجب | <bdi>`_inputs/design.md`</bdi> غائب عن تنفيذ حامل للمعمارية | شغِّل <bdi>`/plan-design`</bdi> ثم أعِد تشغيل <bdi>`/architecture-review`</bdi> |

## أمثلة

```bash
# Dry-run to preview applicability, component count, and open questions
/plan-design --dry-run

# Emit design for a named architecture-bearing suite
/plan-design path/to/plan-suite/
```
