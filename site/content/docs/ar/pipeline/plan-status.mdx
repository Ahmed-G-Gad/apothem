**الدور:** مُبلِّغ
**الموضع في خط المعالجة:** للقراءة فقط

مُبلِّغ تقدُّم حزمة الخطة للقراءة فقط — يصدر الحالة دون تعديل أيّ ملف.

## الاستدعاء المعياري

```bash
/plan-status
```

مع الوسائط:

```bash
/plan-status [path/to/plan-suite/] [--verbose]
```

## المدخلات

أيّ حزمة خطة في أيّ حالة من دورة حياتها — يقرأ <bdi>`PROGRESS.md`</bdi> و<bdi>`PLAN-NOTES.md`</bdi> و<bdi>`MASTER-PLAN.md`</bdi> وتقارير <bdi>`phases/`</bdi>.

## المخرجات

تقرير حالة استراتيجي يُكتَب إلى مجرى مخرجات المشغّل. هذا الأمر للقراءة فقط — لا يُنشئ أيّ ملف ولا يُعدّله.

## المراحل اللاحقة

تُستخدَم بمفردها لفحص التقدُّم — متعامدة مع التسلسل المعياري، وقابلة للاستدعاء للقراءة فقط في أيّ نقطة.

## مراحل سير العمل

الأمر للقراءة فقط — يقرأ ملفات التتبّع الخاصة بالحزمة ويُبلِّغ؛ ولا يكتب شيئًا:

1. **تحميل السياق** — قراءة <bdi>`PROGRESS.md`</bdi> و<bdi>`PLAN-NOTES.md`</bdi> و<bdi>`MASTER-PLAN.md`</bdi>، ومسح <bdi>`phases/`</bdi> بحثًا عن التقارير الموجودة.
2. **تقييم الحالة** — مسح أبعاد المهمّة / المرحلة / الناتج وقراءة عقد الاستئناف.
3. **إصدار تقرير الحالة** — عرض حالة الاكتمال، ومتعقّب المراحل، والتحليل الاستراتيجي مباشرةً إلى المشغّل.
4. **الفحص الموضعي** — مع <bdi>`--verbose`</bdi>، تقدير صحّة الحزمة وذكر أدلّة الفحص الموضعي (روابط ماركداون، نطاقات الأسطر، تجزئات الإيداع) مقابل الملفات الموجودة دون تعديل أيّ منها.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| ملف تتبّع مطلوب مفقود | حزمة الخطة غير مكتملة | اعرض الفجوة بوصفها ملاحظة؛ شغّل <bdi>`/plan-generate`</bdi> لإنشاء الحزمة |
| ملف تتبّع مُشوَّه | قسم مبتور أو غير قابل للتحليل | اذكر الغياب / التناقض في التقرير؛ ويُوجَّه الإصلاح إلى الأوامر الكاتبة |
| حقل غائب أو متناقض عبر الملفات | انحراف في التتبّع | أبلِغ عن التناقض صراحةً؛ ولا تُركّب القيمة المفقودة |

## أمثلة

```bash
# الإبلاغ عن أحدث حزمة خطة
/plan-status

# تقدير صحّة مُسهَب مقابل حزمة خطة مُسمّاة
/plan-status path/to/plan-suite/ --verbose
```
