**الدور:** الباحث الرئيسي (التنفيذ)
**الموضع في خط الأنابيب:** منتصف السلسلة

يُنفّذ الدراسة أو التجربة المُصمَّمة ويلتقط البيانات الخام بمصدرية كاملة. يضمن قابلية الإعادة: يسجّل البيئة والبذرة وسجلّ البروتوكول وتثبيت الإصدارات حتى يتمكّن طرف مستقل من إعادة التشغيل.

## الاستدعاء المعياري

```bash
/research-experiment
```

مع وسائط:

```bash
/research-experiment [path/to/research-suite/]
```

## المدخلات

<bdi>`_inputs/study-design.md`</bdi> (التصميم) و<bdi>`_inputs/preregistration.md`</bdi> (خطة التحليل المُجمَّدة).

## المخرجات

<bdi>`_outputs/experiment-log.md`</bdi> (أثر البروتوكول المختوم زمنيًا)، والبيانات الخام في موقع طبيعي للمضيف، و<bdi>`_outputs/reproducibility-manifest.md`</bdi> (البيئة، البذرة، البروتوكول، تثبيت الإصدارات).

## في المصبّ

‏<bdi>/research-analysis</bdi> (المستهلك في المصبّ)

## مراحل سير العمل

يتبع الأمر سير عمل خط أنابيب <bdi>/research</bdi> المعياري:

1. **تحميل السياق** — قراءة تصميم الدراسة والتسجيل المسبق.
2. **التحقّق من بوّابة التسلسل** — تأكيد وجود <bdi>`_inputs/study-design.md`</bdi>؛ وإلا فالتوقّف برسالة <bdi>`Blocked: run /research-design first`</bdi>.
3. **التشغيل والتسجيل** — تنفيذ البروتوكول؛ التقاط البيانات الخام بمصدريتها؛ تسجيل أثر البروتوكول المختوم زمنيًا.
4. **التقاط قابلية الإعادة** — تسجيل البيئة والبذرة والبروتوكول وتثبيت الإصدارات.
5. **تحديث بيان التسليم** — تسجيل موقع البيانات وبيان قابلية الإعادة.
6. **إصدار السجلّ** — <bdi>`_outputs/experiment-log.md`</bdi> + البيانات الخام + <bdi>`_outputs/reproducibility-manifest.md`</bdi>.

## الحدّ الأدنى للصرامة

يُجري التنفيذُ تمريرة تجريبية استطلاعية لمعايرة الميزانيات والنطاقات، ثم المقارنة الكاملة تحت خطّة مُعلَنة لاستغلال الحوسبة (توزيع الأنوية، وسقوف الذاكرة، والتوازي الآمن للتكرارات المستقلّة). وتُشغّل كلُّ طريقة عشوائية نظامَ تكرارها المُسجَّل مسبقًا مع بذور مُسجَّلة وعتاد مُوثَّق. وتتوفّر حلقةُ تجربة مستقلّة اختيارية معطَّلة افتراضيًّا: مقابل مِطواعٍ (harness) مُجمَّد، تقترح تغييرًا على هدف واحد قابل للتحوير، وتشغّله بالميزانية المُثبَّتة، ولا تحتفظ به إلا إن تفوّق على القائم، وتُدوِّن كلّ تجربة في يوميّاتها.

## أنماط الفشل

| العَرَض | السبب | الاسترداد |
|---------|-------|----------|
| Blocked: run /research-design first | لا يوجد تصميم للدراسة | شغّل <bdi>`/research-design`</bdi> لإنتاج <bdi>`_inputs/study-design.md`</bdi> |
| التشغيل غير قابل للإعادة | سجلّ البذرة / البيئة مفقود | سجّل بيان قابلية الإعادة الكامل قبل المتابعة |
| انحراف البروتوكول غير موثّق | تغيير في أثناء التشغيل لم يُسجَّل | سجّل الانحراف في سجلّ التجربة؛ وأفصِح عنه عند التحليل |

## أمثلة

```bash
# شغّل الدراسة المُصمَّمة والتقط بيانات خام قابلة للإعادة
/research-experiment path/to/research-suite/
```
