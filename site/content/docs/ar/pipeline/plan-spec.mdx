**الدور:** المِصْهَر
**الموضع في خط المعالجة:** الرأس

يصقل النثر الحرّ أو الملاحظات الخام إلى مواصفة <bdi>`_spec/spec.md`</bdi> بدرجة <bdi>spec</bdi> جاهزة لـ <bdi>`/plan-generate`</bdi>.

## الاستدعاء المعياري

```bash
/plan-spec
```

مع الوسائط:

```bash
/plan-spec [path/to/prose-source] [--suite-name NAME] [--refine-existing] [--standalone] [--quick SLUG [--tag TAG]]
```

## المدخلات

نثر حرّ، أو ملاحظات خام، أو متطلبات مُخصَّصة (يقدّمها المشغّل مضمَّنة أو بوصفها مسارًا).

## المخرجات

<bdi>`_spec/spec.md`</bdi> (المواصفة المُرقّاة) + <bdi>`_inputs/handoff-manifest.yml`</bdi>. ويكتب <bdi>`--quick`</bdi> بدلًا من ذلك ملفّ خطة خفيفًا واحدًا محليًّا للمشروع في <bdi>`<project-root>/.apothem/plans/<YYYY-MM-DD>--<kebab-slug>.md`</bdi>.

## المراحل اللاحقة

<bdi>/plan-generate</bdi> (المستهلِك اللاحق)

## مراحل سير العمل

يُجري المِصْهَر ست مراحل تحويل (تُرقّى المواصفة من <bdi>`_inputs/forge.md`</bdi> إلى <bdi>`_spec/spec.md`</bdi> عند G4):

1. **الاكتشاف والاستخراج** — قراءة النثر / الملاحظات واستخراج كل متطلَّب وقرار وقيد.
2. **التدبُّر الدقيق** — التفكير عبر كل سطح؛ وعرض كل تناقض عبر قناة الاستفسار المُهيكَل.
3. **رسم خريطة الفاعلية** — ربط كل متطلَّب بأثره اللاحق.
4. **التحقّق من الحفظ** — تشغيل بوّابة ما قبل الإصدار ذات الخمسة عشر شريطًا (G4) مقابل المواصفة المُرشَّحة قبل الترقية.
5. **تطبيق الخبرة** — تطبيق خبرة المجال؛ وتسجيل اكتشافات فجوات الخبرة.
6. **مسح حسم الأسئلة** — حسم كل استفسار مفتوح عبر البوّابات G0–G5، ثم إصدار <bdi>`_spec/spec.md`</bdi> إضافةً إلى بيان التسليم.

## أنماط الفشل

| العَرَض | السبب | المعالجة |
|---------|-------|----------|
| مدخل نثر مفقود | لم يُقدَّم نثر / ملاحظات | قدّم النثر الحرّ مضمَّنًا أو بوصفه مسارًا |
| تناقض غير محسوم | يحمل النثر متطلبات متعارضة | توقّف عند G3 (ما قبل التعديل)؛ واحسمه عبر الاستفسار المُهيكَل، لا صمتًا |
| المواصفة تُخفِق في البوّابة | يُخفِق شريط ما قبل الإصدار عند G4 | أصلح الشريط المُخفِق قبل الترقية من <bdi>`_inputs/forge.md`</bdi> |

## أمثلة

```bash
# صهر الملاحظات الخام إلى مواصفة بدرجة spec
/plan-spec ~/notes/feature.md --suite-name my-feature

# ملفّ خطة خفيف محليّ للمشروع (يتجاوز استنباط المِصْهَر)
/plan-spec --quick my-feature
```
