**الدور:** مُدقِّق سلسلة التوريد
**موضع خط الأنابيب:** القلعة

تدقيق سلسلة التوريد مقابل معايير <bdi>SLSA + Sigstore + SBOM</bdi>.

## الاستدعاء المعياري

```bash
/supply-chain-audit
```

مع وسائط:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## المدخلات

خط أنابيب إصدار مستودع المُضيف

## المخرجات

نتائج سلسلة التوريد في <bdi>`_inputs/supply-chain-audit-findings.md`</bdi>

## في اتجاه المصبّ

مرحلة <bdi>supply-chain-audit</bdi> من تسلسل مراجعة التدقيق

## مراحل سير العمل

يُنفِّذ الأمر خمس مراحل للتدقيق: استيعاب المدخلات، وجولة على كل محور، وفرز كل نتيجة، وإصدار النتائج، وبوابة التحقّق.

## أنماط الفشل

| العَرَض | السبب | الاستعادة |
|---------|-------|----------|
| متطلب مسبق غير مكتمل | لم تنتهِ المرحلة المعتمَد عليها | أكمل المرحلة في اتجاه المنبع أولًا |
| بوابة الجودة <bdi>FAIL</bdi> | المُخرَج لا يفي بالمعايير | أصلِح المُخرَج وأعِد التشغيل |
| رفض الهدف | الهدف يفتقر إلى سطح إصدار | مرِّر جذر مستودع يحتوي <bdi>.github/workflows/</bdi> أو سكربت إصدار أو بيان بناء |

## أمثلة

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
