**الدور:** الباحث الرئيسي (التأسيس النظري)
**الموضع في خط الأنابيب:** منتصف السلسلة

يبني الإطار المفاهيمي والنظري التأسيسي لسؤال بحثي مُؤطَّر — وهو الأساس القَبْلي الذي تعود إليه مرحلتا البحث المنهجي والتركيب. كل بُنية متجذّرة في النظرية الأولية، وكل علاقة مُنظَّرة مصاغة بصورة قابلة للدحض.

## الاستدعاء المعياري

```bash
/research-theory
```

مع وسائط:

```bash
/research-theory [--suite-name NAME] [--override] [--framework NAME]
```

## المدخلات

ملفّ <bdi>`_spec/research-spec.md`</bdi> الخاص بالمجموعة (مجموعة الأسئلة المُؤطَّرة والقابلة للتزييف التي ينتجها <bdi>`/research-spec`</bdi>).

## المخرجات

<bdi>`_inputs/theory.md`</bdi> (الإطار المفاهيمي / النظري، ونظرية التغيير / النموذج المنطقي، والبُنى مع تعريفاتها الإجرائية، ومخطّط نموذج مفاهيمي).

## في المصبّ

‏<bdi>/research-sources</bdi> (المستهلك في المصبّ — يعيد البحث المنهجي معايير الإدراج الخاصة به إلى هذه البُنى).

## مراحل سير العمل

يتبع الأمر سير عمل خط أنابيب <bdi>/research</bdi> المعياري:

1. **تحميل السياق** — قراءة <bdi>`_spec/research-spec.md`</bdi> والقواعد وأيّ حالة قائمة للمجموعة.
2. **تأطير النموذج المفاهيمي** — تعريف البُنى وتعريفاتها الإجرائية؛ وتجذير كلّ منها في النظرية الأولية.
3. **رسم نظرية التغيير** — بناء النموذج المنطقي الذي يربط البُنى بالنتائج المتوقَّعة؛ وصياغة كل علاقة بصورة قابلة للدحض.
4. **رسم مخطّط النموذج** — إصدار مخطّط نموذج مفاهيمي تشير إليه المراحل في المصبّ.
5. **التحقّق من المخرجات** — تأكيد أنّ كل بُنية متجذّرة في النظرية وأنّ كل علاقة قابلة للدحض؛ وحلّ الغموض عبر قناة الاستعلام المُهيكَل.
6. **إصدار الإطار** — <bdi>`_inputs/theory.md`</bdi> إضافةً إلى بيان التسليم المُحدَّث.

## أنماط الفشل

| العَرَض | السبب | الاسترداد |
|---------|-------|----------|
| البُنية تفتقر إلى تعريف إجرائي | المفهوم مصاغ بصورة مجرّدة | عرِّف البُنية بمصطلحات قابلة للقياس؛ واستشهد بالنظرية الأولية |
| العلاقة المُنظَّرة غير قابلة للدحض | العلاقة مصاغة كبديهية | أعِد صياغة العلاقة كادّعاء قابل للتزييف |
| المدخل المرجعي مفقود | <bdi>`/research-spec`</bdi> لم يُشغَّل بعد | شغّل <bdi>`/research-spec`</bdi> أولًا لتأطير السؤال |

## أمثلة

```bash
# ابنِ الإطار النظري لسؤال مُؤطَّر
/research-theory --suite-name retrieval-latency

# ثبّت إلى إطار نظري مُسمّى
/research-theory --framework "information foraging theory"
```
