**المورّد:** <bdi>Alibaba Cloud</bdi>
**اسم التثبيت:** <bdi>`qwen-code`</bdi>
**الحالة:** إصدار تجريبي
**الإعداد الأصلي:** <bdi>`~/.qwen/`</bdi>

## التثبيت

```bash
apothem install --harness qwen-code
```

يكتب المحوّل إعدادات <bdi>Qwen Code</bdi>، ويثبّت مرساة سياق <bdi>`QWEN.md`</bdi>،
ويُسجِّل موزِّعات خطّافات <bdi>Apothem</bdi>، ويحوّل أوامر <bdi>Apothem</bdi> إلى ملفات
أوامر <bdi>Qwen</bdi> بصيغة <bdi>Markdown</bdi>، ويثبّت المهارات بوصفها أدلّة
<bdi>SKILL.md</bdi>، ويُكيِّف تعريفات المساعِدات بوصفها عوامل فرعية لـ <bdi>Qwen</bdi>.

**الملفات المكتوبة:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

## تعيين الملف التعريفي إلى الإعداد الأصلي

يُجسِّد المحوّل مفاتيح <bdi>`settings.json`</bdi> المُوثَّقة للسياق والخطّافات، ويكتب
<bdi>`QWEN.md`</bdi>، وينسج أوامر <bdi>Apothem</bdi> ومهاراته وتعريفات مساعِداته عبر
أدلّة الاكتشاف الأصلية في <bdi>Qwen Code</bdi>. وتبقى القواعد والقوالب والمادة المصدرية
للخطّافات مادةَ دعم تحت <bdi>`~/.qwen/.apothem/support/`</bdi>.

## ملاحظات التوافق

<bdi>`~/.qwen/.apothem/support/`</bdi> مادة دعم يُشير إليها <bdi>`QWEN.md`</bdi> وأوامر
الخطّافات في الإعدادات؛ وليس مساحة أسماء اكتشاف يملكها المورّد.
تنتهي كتلة <bdi>Apothem</bdi> في <bdi>`QWEN.md`</bdi> بقسم ملفات دعم <bdi>Apothem</bdi>
الذي يُسمّي الدليل المطلق تحت <bdi>`~/.qwen/.apothem/support/`</bdi> الذي تُحَلّ نسبةً
إليه كل إحالة بأسلوب المستودع (<bdi>`rules/<name>.md`</bdi>، و<bdi>`templates/...`</bdi>،
و<bdi>`hooks/...`</bdi>).

## التحقّق

```bash
apothem verify --harness qwen-code
```

يؤكّد أمر التحقّق ما يلي:

1. الإعداد الأصلي موجود في المسار المتوقَّع.
2. جميع الحقول الإلزامية من الملف التعريفي المشترك موجودة.
3. روتين التحقّق الخاص بالمحوّل يُبلِغ عن النجاح.

## التحديث

```bash
apothem update --harness qwen-code
```

يُحدِّث <bdi>`settings.json`</bdi>، و<bdi>`QWEN.md`</bdi>، والأوامر الأصلية، والمهارات،
والعوامل الفرعية، وشجرة دعم <bdi>Apothem</bdi>.

## إلغاء التثبيت

```bash
apothem uninstall --harness qwen-code
```

يُزيل ملفات الإعداد الأصلي التي كتبها المحوّل.
لا يتأثّر ملف <bdi>YAML</bdi> الخاص بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness qwen-code`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness qwen-code`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | افحص <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness qwen-code`</bdi> |

## مفاتيح الضبط

| الراية | القيمة الافتراضية | الوصف |
|------|---------|-------------|
| <bdi>`--dry-run`</bdi> | <bdi>`false`</bdi> | معاينة التثبيت دون كتابة ملفات. |
