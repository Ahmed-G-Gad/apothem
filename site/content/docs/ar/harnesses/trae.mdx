**المورّد:** <bdi>ByteDance</bdi>
**اسم التثبيت:** <bdi>`trae`</bdi>
**الحالة:** إصدار عام
**الإعداد الأصلي:** <bdi>`<project>/.trae/rules/apothem-rules.md`</bdi>

## التثبيت

```bash
apothem install --harness trae --project /path/to/project
```

يكتب المحوّل ملف قواعد واحدًا لـ <bdi>Trae</bdi> على نطاق المشروع انطلاقًا من القواعد
المشتركة لـ <bdi>Apothem</bdi> وسطح الحوكمة.

**الملفات المكتوبة:** <bdi>`<project>/.trae/rules/apothem-rules.md`</bdi>

## تعيين الملف التعريفي إلى الإعداد الأصلي

يقرأ المحوّل الملف التعريفي المشترك لـ <bdi>Apothem</bdi> ويُجسِّد ملف قواعد المشروع
في كل تشغيل لـ <bdi>`apothem install`</bdi> أو <bdi>`apothem update`</bdi>. الملف
التعريفي المشترك هو مصدر الحقيقة؛ وتُنسَخ التعديلات المحلّية للمشروع على الملف
المُولَّد احتياطيًا قبل أن تستبدل المزامنة التالية المحتوى الذي يديره
<bdi>Apothem</bdi>.

يبدأ الملف ببيانات أمامية بصيغة <bdi>YAML</bdi> تضبط <bdi>`alwaysApply: true`</bdi>
وحقلًا <bdi>`description`</bdi>، وهو وضع <bdi>Always Apply</bdi> في <bdi>Trae</bdi>
وفق [وثائق قواعد <bdi>Trae</bdi>](https://docs.trae.ai/ide/rules). وتليها الكتلة التي
يديرها <bdi>Apothem</bdi>؛ ويُحتفَظ بالنص الذي تضيفه بعد الكتلة في كل مزامنة.

## ملاحظات التوافق

سطح القواعد الحالي في <bdi>Trae</bdi> على نطاق المشروع تحت <bdi>`.trae/rules/`</bdi>؛
وتقع القواعد العامة تحت <bdi>`~/.trae/user_rules`</bdi>. يكتب المحوّل ملفًا مخصّصًا
<bdi>`apothem-rules.md`</bdi> ولا يطمس أبدًا ملفات القواعد الأخرى في ذلك الدليل ولا
قواعدك العامة. سطح خوادم الأدوات <bdi>`.trae/mcp.json`</bdi> وسطح المهارات
<bdi>`.trae/skills/`</bdi> يملكهما المُشغِّل؛ ولا يكتبهما <bdi>Apothem</bdi>.

## التحقّق

```bash
apothem verify --harness trae --project /path/to/project
```

يؤكّد أمر التحقّق ما يلي:

1. الإعداد الأصلي موجود في المسار المتوقَّع.
2. جميع الحقول الإلزامية من الملف التعريفي المشترك موجودة.
3. روتين التحقّق الخاص بالمحوّل يُبلِغ عن النجاح.

## التحديث

```bash
apothem update --harness trae --project /path/to/project
```

يُعيد اشتقاق ملف قواعد المشروع من الحالة الراهنة للملف التعريفي المشترك.

## إلغاء التثبيت

```bash
apothem uninstall --harness trae --project /path/to/project
```

يُزيل ملفات الإعداد الأصلي التي كتبها المحوّل.
لا يتأثّر ملف <bdi>YAML</bdi> الخاص بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness trae --project /path/to/project`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness trae --project /path/to/project`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | افحص <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness trae --project /path/to/project`</bdi> |

## مفاتيح الضبط

| الراية | القيمة الافتراضية | الوصف |
|------|---------|-------------|
| <bdi>`--dry-run`</bdi> | <bdi>`false`</bdi> | معاينة التثبيت دون كتابة ملفات. |
