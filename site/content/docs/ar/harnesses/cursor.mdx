**المورّد:** <bdi>Anysphere</bdi>
**اسم التثبيت:** <bdi>`cursor`</bdi>
**الحالة:** إتاحة عامة
**الإعداد الأصلي:** <bdi>`.cursor/rules/`</bdi> في جذر المشروع

## التثبيت

```bash
apothem install --harness cursor --project /path/to/project
```

يُجسِّد المحوّل ملف قواعد <bdi>`.mdc`</bdi> واحدًا بنطاق المشروع من سطح القواعد
والحوكمة المشترك في <bdi>Apothem</bdi>.

**الملفات المكتوبة:** <bdi>`<project>/.cursor/rules/apothem-rules.mdc`</bdi>

هذا الملف هو التثبيت بأكمله: لا يُوضَع بجواره أي ملف قاعدة أو مهارة أو أمر أو قالب أو
خطّاف، لذا ينصّ الملف على ذلك بدلًا من الإشارة إلى ملفات <bdi>Apothem</bdi> غير
موجودة في المشروع.

## تعيين الملف التعريفي إلى الإعداد الأصلي

يقرأ المحوّل الملف التعريفي المشترك لـ <bdi>Apothem</bdi> ويُجسِّد ملف قواعد المشروع
في كل تشغيل لـ <bdi>`apothem install`</bdi> أو <bdi>`apothem update`</bdi>. الملف
التعريفي المشترك هو مصدر الحقيقة؛ وتُنسَخ التعديلات المحلية للمشروع على الملف
المُولَّد احتياطيًا قبل أن تستبدل المزامنة التالية المحتوى الذي يديره
<bdi>Apothem</bdi>.

يبدأ الملف ببياناته الأمامية بصيغة <bdi>YAML</bdi> (<bdi>`description`</bdi>،
و<bdi>`globs`</bdi>، و<bdi>`alwaysApply: true`</bdi>)، لأن <bdi>Cursor</bdi> لا يقرأ
نوع القاعدة إلا من البيانات الأمامية في بداية الملف. وتليها الكتلة التي يديرها
<bdi>Apothem</bdi>؛ ويُحتفَظ بالنص الذي تضيفه بعد الكتلة في كل مزامنة.

## ملاحظات التوافق

يدعم <bdi>Cursor 0.45+</bdi> التعليمات على مستوى المشروع عبر
<bdi>`.cursor/rules/`</bdi>. يكتب المحوّل افتراضيًا إلى دليل
<bdi>`.cursor/rules/`</bdi> بنطاق المشروع؛ ولا يملك <bdi>Cursor</bdi> مسارًا موثّقًا
قائمًا على الملفات للقواعد العامّة على مستوى المستخدم كي يديره هذا المحوّل.

## التحقّق

```bash
apothem verify --harness cursor --project /path/to/project
```

يؤكّد أمر التحقّق ما يلي:

1. الإعداد الأصلي موجود في المسار المتوقَّع.
2. كل هدف مُدار موجود؛ والملفات المُدارة غير فارغة، وتُحلَّل إعدادات <bdi>JSON</bdi> أو <bdi>YAML</bdi>. أضِف <bdi>`--profile PATH`</bdi> لتتحقّق كذلك من أن الملفات المثبّتة تطابق ذلك الملف التعريفي.
3. روتين التحقّق الخاص بالمحوّل يُبلِغ عن النجاح.

## التحديث

```bash
apothem update --harness cursor --project /path/to/project
```

يُعيد اشتقاق ملف قواعد المشروع من الحالة الراهنة للملف التعريفي المشترك.

## إلغاء التثبيت

```bash
apothem uninstall --harness cursor --project /path/to/project
```

يُزيل ملفات الإعداد الأصلي التي كتبها المحوّل.
لا يتأثّر ملف <bdi>YAML</bdi> الخاص بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness cursor --project /path/to/project`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness cursor --project /path/to/project`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | افحص <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness cursor --project /path/to/project`</bdi> |
