**المورّد:** <bdi>Codeium</bdi>
**اسم التثبيت:** <bdi>`windsurf`</bdi>
**الحالة:** إصدار عام
**الإعداد الأصلي:** <bdi>`<project>/.devin/rules/apothem-rules.md`</bdi>

## التثبيت

```bash
apothem install --harness windsurf --project /path/to/project
```

يكتب المحوّل ملف قواعد <bdi>Windsurf</bdi> واحدًا بنطاق المشروع من قواعد <bdi>Apothem</bdi>
المشتركة وسطح الحوكمة.

**الملفات المكتوبة:** <bdi>`<project>/.devin/rules/apothem-rules.md`</bdi>

## تعيين الملف التعريفي إلى الإعداد الأصلي

يقرأ المحوّل الملف التعريفي المشترك لـ<bdi>Apothem</bdi> ويجسّد ملف قواعد المشروع في
كل عملية <bdi>`apothem install`</bdi> أو <bdi>`apothem update`</bdi>. الملف التعريفي
المشترك هو مصدر الحقيقة؛ وتُحفظ التعديلات المحلّية للمشروع على الملف المُولَّد كنسخة
احتياطية قبل أن تستبدل المزامنة التالية المحتوى الذي يديره <bdi>Apothem</bdi>.

## ملاحظات التوافق

سطح قواعد <bdi>Windsurf</bdi> الحالي بنطاق المشروع تحت <bdi>`.devin/rules/`</bdi>.
سير العمل والذاكرة المحلّية للجهاز يملكها المُشغِّل؛ ولا يكتبها <bdi>Apothem</bdi>.
ولا تُكتَب صيغة الملف الواحد <bdi>`.windsurfrules`</bdi> عن قصد.

## التحقّق

```bash
apothem verify --harness windsurf --project /path/to/project
```

يؤكّد أمر التحقّق ما يلي:

1. وجود الإعداد الأصلي في المسار المتوقَّع.
2. وجود جميع الحقول الإلزامية من الملف التعريفي المشترك.
3. إبلاغ روتين التحقّق الخاص بالمحوّل عن النجاح.

## التحديث

```bash
apothem update --harness windsurf --project /path/to/project
```

يعيد اشتقاق ملف قواعد المشروع من الحالة الراهنة للملف التعريفي المشترك.

## إلغاء التثبيت

```bash
apothem uninstall --harness windsurf --project /path/to/project
```

يزيل ملفات الإعداد الأصلي التي كتبها المحوّل.
لا يتأثّر ملفّ <bdi>YAML</bdi> الخاص بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوّابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness windsurf --project /path/to/project`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness windsurf --project /path/to/project`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | تحقّق من <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness windsurf --project /path/to/project`</bdi> |
