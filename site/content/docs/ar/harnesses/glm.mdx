**المورّد:** <bdi>Z.ai</bdi>
**اسم التثبيت:** <bdi>`glm`</bdi>
**الحالة:** إتاحة عامة
**الإعداد الأصلي:** <bdi>`<project>/.apothem/providers/glm.toml`</bdi>

<bdi>GLM (Z.ai)</bdi> **واجهة خلفية للنماذج**، لا إطار عمل. لا تشحن <bdi>Z.ai</bdi> سطر
أوامر رسميًا من إنتاجها لـ <bdi>GLM</bdi>؛ بل تُوجَّه إلى <bdi>GLM</bdi> أداةٌ تتحدّث
البروتوكول المتوافق مع <bdi>Anthropic</bdi> أو المتوافق مع <bdi>OpenAI</bdi>، بضبط عنوان
<bdi>URL</bdi> أساسي للواجهة الخلفية ومفتاح. يكتب محوّل <bdi>`glm`</bdi> ملف إعداد
مزوّد يُسجِّل سطحَي التوافق كليهما، بحيث يمكن ربط أي أداة متوافقة بعائلة نماذج
<bdi>GLM</bdi>.

## التثبيت

```bash
apothem install --harness glm --project /path/to/project
```

يكتب المحوّل ملف مزوّد واحدًا بنطاق المشروع يُسجِّل نقاط نهاية الواجهة الخلفية لـ
<bdi>GLM</bdi> وعناصر نائبة يضبطها المُشغِّل.

**الملفات المكتوبة:** <bdi>`<project>/.apothem/providers/glm.toml`</bdi>

## تعيين الملف التعريفي إلى الإعداد الأصلي

يُسجِّل ملف المزوّد واجهتين خلفيتين. تستخدم الواجهة الخلفية المتوافقة مع
<bdi>Anthropic</bdi> عنوان <bdi>URL</bdi> الأساسي
<bdi>`https://api.z.ai/api/anthropic`</bdi>؛ وتتوجّه الأداة التي تتحدّث بروتوكول
<bdi>Anthropic</bdi> إلى <bdi>GLM</bdi> بضبط <bdi>`ANTHROPIC_BASE_URL`</bdi>،
و<bdi>`ANTHROPIC_AUTH_TOKEN`</bdi>، و<bdi>`API_TIMEOUT_MS`</bdi> اختياريًا. ويسرد جدول
<bdi>env</bdi> نفسه <bdi>`ANTHROPIC_DEFAULT_OPUS_MODEL`</bdi>،
و<bdi>`ANTHROPIC_DEFAULT_SONNET_MODEL`</bdi>، و<bdi>`ANTHROPIC_DEFAULT_HAIKU_MODEL`</bdi>،
التي تربط أدوار <bdi>opus</bdi> و<bdi>sonnet</bdi> و<bdi>haiku</bdi> في الأداة بنماذج
<bdi>GLM</bdi>. تستخدم الواجهة الخلفية المتوافقة مع <bdi>OpenAI</bdi> عنوان
<bdi>URL</bdi> الأساسي <bdi>`https://api.z.ai/api/coding/paas/v4`</bdi>. رمز المصادقة
عنصر نائب تستبدله بمفتاح <bdi>Z.ai</bdi> الخاص بك — لا يكتب <bdi>Apothem</bdi> سرًّا
حقيقيًا أبدًا. مُعرِّفات النماذج متقلّبة بتغيّر النسخ، لذا لا يُثبِّت
<bdi>Apothem</bdi> أيًّا منها؛ ويحمل الملف عناصر نائبة <bdi>`<GLM_MODEL_ID>`</bdi>
تملؤها من [وثائق <bdi>Z.ai</bdi>](https://docs.z.ai/devpack/tool/claude) الحالية. لا
شيء من الملف التعريفي المشترك يدخل هذا الملف؛ فهو قالب ثابت.

## ملاحظات التوافق

لأن <bdi>GLM</bdi> واجهة خلفية لا إطار عمل، فهو لا يكشف أي سطح للقواعد أو الأوامر أو
المهارات أو الخطّافات — لا يكتب المحوّل سوى ملف مزوّد الواجهة الخلفية ولا شيء غيره.
يبقى مفتاح <bdi>Z.ai</bdi> الخاص بك واختياراتك لمُعرِّفات النماذج ملكًا للمُشغِّل.
اصطلاحات سطح المورّد التي يعتمد عليها المحوّل مُثبَّتة في
<bdi>`src/apothem/harnesses/glm/STANDARD-CONVENTION-PIN.md`</bdi>، ملتقَطة بوصفها لقطة
مقابل وثائق <bdi>Z.ai</bdi> الحيّة.

يُشغِّل <bdi>GLM</bdi> عائلة نماذج <bdi>GLM</bdi> من <bdi>Z.ai</bdi>؛ راجع
[مرجع إعداد المورّد](https://docs.z.ai/devpack/tool/claude) للاطلاع على سطح الإعداد
الحالي الخاص بالواجهة الخلفية والنموذج والتوافق مع <bdi>Anthropic</bdi>.

## التحقّق

```bash
apothem verify --harness glm --project /path/to/project
```

يؤكّد أمر التحقّق ما يلي:

1. الإعداد الأصلي موجود في المسار المتوقَّع.
2. ملف المزوّد موجود وغير فارغ.
3. روتين التحقّق الخاص بالمحوّل يُبلِغ عن النجاح.

## التحديث

```bash
apothem update --harness glm --project /path/to/project
```

يصبح ملف المزوّد ملكًا لك بمجرّد وجوده. لا يكتب <bdi>`install`</bdi> القالب إلا حين
يكون <bdi>`.apothem/providers/glm.toml`</bdi> غائبًا، ولا يكتب <bdi>`install`</bdi> ولا
<bdi>`update`</bdi> فوقه أبدًا بعد ذلك، لذا يبقى مرجع مفتاحك واختياراتك للنماذج بعد
كل إعادة تشغيل. لاعتماد قالب أحدث، انقل ملفك جانبًا، وشغّل <bdi>`update`</bdi>، وانسخ
قيمك إلى الملف الجديد.

## إلغاء التثبيت

```bash
apothem uninstall --harness glm --project /path/to/project
```

لا يُزيل ملف المزوّد إلا حين يكون <bdi>Apothem</bdi> قد أنشأه وما يزال القالب غير
المُعدَّل، وينسخه احتياطيًا أولًا تحت جذر النسخ الاحتياطية في <bdi>Apothem</bdi>.
ويُترَك في مكانه أي ملف أنشأته أنت أو عدّلته. لا يتأثّر ملف <bdi>YAML</bdi> الخاص
بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness glm --project /path/to/project`</bdi> |
| فشل التحقّق | ملف المزوّد مفقود أو فارغ. إذا كان مفقودًا، فشغّل <bdi>`apothem update --harness glm --project /path/to/project`</bdi>. وإذا كان فارغًا، فانقل <bdi>`.apothem/providers/glm.toml`</bdi> جانبًا أولًا، ثم شغّل <bdi>`update`</bdi> وتحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | عدّل <bdi>`.apothem/providers/glm.toml`</bdi> مباشرةً؛ فـ<bdi>Apothem</bdi> لا يُعيد كتابة ملف موجود أبدًا، ولا يضيف الملف التعريفي المشترك إليه شيئًا. وللحصول على قالب جديد، انقل الملف جانبًا وشغّل <bdi>`apothem update --harness glm --project /path/to/project`</bdi> |
