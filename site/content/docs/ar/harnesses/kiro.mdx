**المورّد:** <bdi>AWS</bdi>
**اسم التثبيت:** <bdi>`kiro`</bdi>
**الحالة:** إصدار عام
**الإعداد الأصلي:** <bdi>`<project>/.kiro/steering/apothem-rules.md`</bdi>

## التثبيت

```bash
apothem install --harness kiro --project /path/to/project
```

يكتب المحوّل ملفّ توجيه (steering) واحدًا لـ<bdi>Kiro</bdi> على نطاق المشروع، انطلاقًا
من قواعد <bdi>Apothem</bdi> المشتركة وسطح الحوكمة.

**الملفات المكتوبة:** <bdi>`<project>/.kiro/steering/apothem-rules.md`</bdi>

## تعيين الملف التعريفي إلى الإعداد الأصلي

يقرأ المحوّل الملف التعريفي المشترك لـ<bdi>Apothem</bdi> ويجسّد ملفّ توجيه المشروع
في كلّ عملية <bdi>`apothem install`</bdi> أو <bdi>`apothem update`</bdi>. الملف
التعريفي المشترك هو مصدر الحقيقة؛ وتُنسَخ احتياطيًا التعديلات المحلّية للمشروع على
الملفّ المُولَّد قبل أن تستبدل المزامنة التالية المحتوى الذي يديره <bdi>Apothem</bdi>.

## ملاحظات التوافق

سطح التوجيه في <bdi>Kiro</bdi> على نطاق المشروع تحت <bdi>`.kiro/steering/`</bdi>.
يكتب المحوّل ملفّ توجيه مُخصّصًا <bdi>`apothem-rules.md`</bdi> يحمل البيانات الأمامية
<bdi>`inclusion: always`</bdi>، ولا يطمس أبدًا ملفات الأساس التي كتبها مشغّل
<bdi>Kiro</bdi> (<bdi>`product.md`</bdi> و<bdi>`tech.md`</bdi> و<bdi>`structure.md`</bdi>).
تخصّ مواصفات <bdi>Kiro</bdi> (<bdi>`.kiro/specs/`</bdi>) وخطافات المساعِدات المشغّلَ؛
ولا يكتبها <bdi>Apothem</bdi>.

## التحقّق

```bash
apothem verify --harness kiro --project /path/to/project
```

يؤكّد أمر التحقّق ما يلي:

1. وجود الإعداد الأصلي في المسار المتوقَّع.
2. وجود جميع الحقول الإلزامية من الملف التعريفي المشترك.
3. إبلاغ روتين التحقّق الخاص بالمحوّل بالنجاح.

## التحديث

```bash
apothem update --harness kiro --project /path/to/project
```

يعيد اشتقاق ملفّ توجيه المشروع من الحالة الراهنة للملف التعريفي المشترك.

## إلغاء التثبيت

```bash
apothem uninstall --harness kiro --project /path/to/project
```

يزيل ملفات الإعداد الأصلي التي كتبها المحوّل.
لا يتأثّر ملفّ <bdi>YAML</bdi> الخاص بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوّابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness kiro --project /path/to/project`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness kiro --project /path/to/project`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | تحقّق من <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness kiro --project /path/to/project`</bdi> |

## مفاتيح الضبط

| العَلَم | الافتراضي | الوصف |
|------|---------|-------------|
| <bdi>`--dry-run`</bdi> | <bdi>`false`</bdi> | معاينة التثبيت دون كتابة ملفات. |
