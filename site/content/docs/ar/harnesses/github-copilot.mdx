**المورّد:** <bdi>GitHub / Microsoft</bdi>
**اسم التثبيت:** <bdi>`github-copilot`</bdi>
**الحالة:** <bdi>GA</bdi>
**الإعداد الأصلي:** <bdi>`<project>/.github/copilot-instructions.md`</bdi>

## التثبيت

```bash
apothem install --harness github-copilot --project /path/to/project
```

يشتقّ المحوّل ملفّ تعليمات المشروع من قواعد <bdi>Apothem</bdi> المشتركة وسطح
الحوكمة.

**الملفات المكتوبة:** <bdi>`<project>/.github/copilot-instructions.md`</bdi>

## تعيين الملف التعريفي إلى الإعداد الأصلي

يقرأ المحوّل الملف التعريفي المشترك لـ<bdi>Apothem</bdi> ويعرض ملفّ تعليمات
<bdi>Copilot</bdi> على مستوى المستودع في كل عملية <bdi>`apothem install`</bdi> أو
<bdi>`apothem update`</bdi>. الملف التعريفي المشترك هو مصدر الحقيقة؛ وتُحفَظ نسخة
احتياطية من التعديلات المحلية للمشروع على الملفّ المُولَّد قبل أن تستبدل المزامنة
التالية المحتوى المُدار بواسطة <bdi>Apothem</bdi>.

## ملاحظات التوافق

لا يكشف <bdi>GitHub Copilot</bdi> عن مسار تعليمات عامّ للمستخدم قائم على الملفات
يمكن لهذا المحوّل إدارته. يستهدف <bdi>Apothem</bdi> ملفّ تعليمات نطاق المشروع
الموثَّق، ويترك إعدادات المستخدم على مستوى بيئة التطوير المتكاملة في ملكية المشغّل.

يتعامل <bdi>Apothem</bdi> مع <bdi>`copilot-instructions.md`</bdi> بوصفه صوتًا واحدًا
بين أسطح تعليمات المساعد في المشروع: يتحقّق فحص التماسك متعدّد الأسطح في بوّابة
المطابقة من أنّ ادّعاءاته المشتركة تبقى متوائمة دلاليًا مع ملفات تعليمات المشروع
الأخرى، لذا لا يتلقّى <bdi>Copilot</bdi> أبدًا إرشادًا يتعارض مع ما تقرؤه بقيّة سلسلة
الأدوات.

## التحقّق

```bash
apothem verify --harness github-copilot --project /path/to/project
```

يؤكّد أمر التحقّق ما يلي:

1. وجود الإعداد الأصلي في المسار المتوقَّع.
2. وجود جميع الحقول الإلزامية من الملف التعريفي المشترك.
3. إبلاغ روتين التحقّق الخاص بالمحوّل عن النجاح.

## التحديث

```bash
apothem update --harness github-copilot --project /path/to/project
```

يعيد اشتقاق ملفّ تعليمات المشروع من حالة الملف التعريفي المشترك الحالية.

## إلغاء التثبيت

```bash
apothem uninstall --harness github-copilot --project /path/to/project
```

يزيل ملفات الإعداد الأصلية التي كتبها المحوّل.
لا يتأثّر <bdi>YAML</bdi> الملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوّابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness github-copilot --project /path/to/project`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness github-copilot --project /path/to/project`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | تحقّق من <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness github-copilot --project /path/to/project`</bdi> |

## مفاتيح الضبط

| العَلَم | الافتراضي | الوصف |
|------|---------|-------------|
| <bdi>`--dry-run`</bdi> | <bdi>`false`</bdi> | معاينة التثبيت دون كتابة ملفات. |
