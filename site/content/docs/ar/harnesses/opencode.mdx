**المورّد:** <bdi>OpenCode</bdi>
**اسم التثبيت:** <bdi>`opencode`</bdi>
**الحالة:** إصدار تجريبي
**الإعداد الأصلي:** <bdi>`~/.config/opencode/`</bdi>

## التثبيت

```bash
apothem install --harness opencode
```

يكتب المحوّل إعداد <bdi>JSON</bdi> الخاص بـ<bdi>OpenCode</bdi>، ويثبّت مهارات
<bdi>Apothem</bdi> في سطح مهارات <bdi>OpenCode</bdi>، ويحوّل مُحفّزات الأوامر إلى
ملفات أوامر <bdi>Markdown</bdi> خاصّة بـ<bdi>OpenCode</bdi>، ويطبّع تعريفات مساعِدات
<bdi>Apothem</bdi> بوصفها مساعِدات فرعية لـ<bdi>OpenCode</bdi>.

**الملفات المكتوبة:**

```text
~/.config/opencode/opencode.json
~/.config/opencode/commands/
~/.config/opencode/skills/
~/.config/opencode/agents/
~/.config/opencode/.apothem/support/{rules,templates,hooks}/
```

## تعيين الملف التعريفي إلى الإعداد الأصلي

يجسّد المحوّل <bdi>`opencode.json`</bdi> بقائمة ملفات <bdi>`instructions`</bdi> تشير
إلى قواعد <bdi>Apothem</bdi> المثبّتة، ثم ينشر كلّ مجموعة <bdi>Apothem</bdi> مشتركة
إمّا إلى سطح أصلي خاصّ بـ<bdi>OpenCode</bdi> أو إلى شجرة دعم فرعية يملكها
<bdi>Apothem</bdi>. وتُنسَخ احتياطيًا العناصر الفرعية المُطابِقة الموجودة التي يديرها
<bdi>Apothem</bdi> قبل استبدالها.

## ملاحظات التوافق

يُشار إلى القواعد عبر قائمة <bdi>`instructions`</bdi> الأصلية. أمّا القوالب ومُحفّزات
الخطافات فهي مادّة مرجعية تحت <bdi>`~/.config/opencode/.apothem/support/`</bdi>؛ وتستخدم
الأوامر والمهارات وتعريفات المساعِدات مواقع الاكتشاف الأصلية.

## التحقّق

```bash
apothem verify --harness opencode
```

يؤكّد أمر التحقّق ما يلي:

1. وجود الإعداد الأصلي في المسار المتوقَّع.
2. وجود جميع الحقول الإلزامية من الملف التعريفي المشترك.
3. إبلاغ روتين التحقّق الخاص بالمحوّل بالنجاح.

## التحديث

```bash
apothem update --harness opencode
```

يحدّث <bdi>`opencode.json`</bdi>، والأوامر الأصلية، والمهارات، وتعريفات المساعِدات،
وشجرة دعم <bdi>Apothem</bdi>.

## إلغاء التثبيت

```bash
apothem uninstall --harness opencode
```

يزيل ملفات الإعداد الأصلي التي كتبها المحوّل.
لا يتأثّر ملفّ <bdi>YAML</bdi> الخاص بالملف التعريفي المشترك ولا محرّك <bdi>Apothem</bdi>.

## بوّابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```

## استكشاف الأخطاء وإصلاحها

| العَرَض | الإصلاح |
|---------|-----|
| ملف الإعداد غير موجود | أعد تشغيل <bdi>`apothem install --harness opencode`</bdi> |
| فشل التحقّق | شغّل <bdi>`apothem update --harness opencode`</bdi>، ثم تحقّق مجدّدًا |
| محتوى إعداد غير متوقَّع | تحقّق من <bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>، ثم أعد تشغيل <bdi>`apothem update --harness opencode`</bdi> |

| العَلَم | الافتراضي | الوصف |
|------|---------|-------------|
