**المورّد:** <bdi>Anthropic</bdi>
**اسم التثبيت:** <bdi>`claude-code`</bdi>
**الحالة:** <bdi>GA</bdi>
**الإعداد الأصلي:** <bdi>`~/.claude/`</bdi>

## التثبيت

```bash
apothem install --harness claude-code
```

يقوم محوّل <bdi>`claude-code`</bdi> بتثبيت مجموعة <bdi>Apothem</bdi> المشتركة في
شجرة الاكتشاف الأصلية لـ<bdi>Claude Code</bdi>. تُثبَّت وكلاء <bdi>Markdown</bdi>،
والقواعد، والمهارات، وأنماط المخرجات، ومساعدات شريط الحالة، والإعدادات في مواقعها
الأصلية؛ كما تُغلَّف مطالبات الأوامر بصورة إضافية بوصفها مهارات لتبقى سير العمل
القابلة لإعادة الاستخدام مرئية عبر سطح المهارات الحالي لـ<bdi>Claude Code</bdi>.

**الملفات المكتوبة:** <bdi>`settings.json`</bdi>، و<bdi>`agents/`</bdi>،
و<bdi>`rules/`</bdi>، و<bdi>`skills/`</bdi>، و<bdi>`statuslines/`</bdi>،
و<bdi>`output-styles/`</bdi>، وشجرة الدعم الفرعية <bdi>`apothem/`</bdi>
(<bdi>`apothem/hooks/`</bdi>، و<bdi>`apothem/conformity/`</bdi>،
و<bdi>`apothem/schemas/`</bdi>، و<bdi>`apothem/templates/`</bdi>) تحت
<bdi>`~/.claude/`</bdi>. تُحوَّل ملفات الأوامر إلى أدلّة مهارات فرعية. يعمل موزّع
الخطافات وبوّابة المطابقة من نسخهما المُجسَّدة — تستدعي مدخلات الخطافات في
<bdi>`settings.json`</bdi> الملفّ <bdi>`~/.claude/.apothem/support/hooks/dispatch.py`</bdi>
والملفّ <bdi>`~/.claude/.apothem/support/conformity/gate.py`</bdi> بالمسار المطلق، لذلك لا
حاجة إلى حزمة <bdi>`apothem`</bdi> قابلة للاستيراد على المضيف.

لا يدير المحوّل **ملفّ** <bdi>`CLAUDE.md`</bdi> — فهذا الملفّ منطقة يملكها المشغّل.
يبلغ سطح حوكمة <bdi>Apothem</bdi> إلى <bdi>Claude Code</bdi> عبر شجرة
<bdi>`rules/`</bdi> المُنتشَرة وخطّاف <bdi>SessionStart</bdi>، لا عبر
<bdi>`CLAUDE.md`</bdi> مُجسَّد.

## تعيين الملف التعريفي إلى الإعداد الأصلي

في كل عملية <bdi>`apothem install`</bdi> أو <bdi>`apothem update`</bdi>، ينشر
المحوّل مجموعة <bdi>`apothem`</bdi> المشتركة إلى <bdi>`~/.claude/`</bdi> وفق بيان
الانتشار. يستخدم المحوّل الأدلّة الأصلية مباشرةً حيثما أمكن ويحوّل مطالبات الأوامر
إلى مجلدات مهارات. تُحفَظ نسخة احتياطية من العناصر الفرعية المُدارة بواسطة
<bdi>Apothem</bdi> المطابقة الموجودة قبل استبدالها؛ وتُصان المدخلات غير ذات الصلة
التي أنشأها المشغّل. يُدمَج <bdi>`settings.json`</bdi> بحيث تبقى المفاتيح التي
أنشأها المشغّل قابلة للاستعادة.

## ملاحظات التوافق

لا تحدث أي ترجمة. يتحقّق التثبيت من أنّ الملف التعريفي جيّد التكوين وأنّ جميع ارتباطات الخطافات في <bdi>settings.json</bdi> قابلة للحلّ.

يطبّق <bdi>Claude Code</bdi> جميع ارتباطات الخطافات في <bdi>settings.json</bdi> عند كل بدء جلسة. يُتحقَّق من كل محوّل مقابل إطار عمله الأصلي الخاص — ولا يوجد إطار عمل «مرجعي» متميّز.

## التحقّق

```bash
apothem verify --harness claude-code
```

يؤكّد أمر التحقّق ما يلي:

1. وجود الإعداد الأصلي في المسار المتوقَّع.
2. وجود جميع الحقول الإلزامية من الملف التعريفي المشترك.
3. إبلاغ روتين التحقّق الخاص بالمحوّل عن النجاح.

## التحديث

```bash
apothem update --harness claude-code
```

يعيد اشتقاق الإعداد الأصلي من الملف التعريفي المشترك الحالي. شغّله بعد تحديث حزمة
<bdi>`apothem`</bdi> المثبّتة، حتى يعكس سطح الاتفاقيات المُنتشَر (الوكلاء، والقواعد،
والمهارات، وأشرطة الحالة، وأنماط المخرجات) الإصدار الجديد. ملفّ <bdi>`CLAUDE.md`</bdi>
يملكه المشغّل ولا يلمسه المحوّل أبدًا.

## إلغاء التثبيت

```bash
apothem uninstall --harness claude-code
```

يزيل ملفات الإعداد الأصلية التي كتبها المحوّل.
لا تتأثّر حزمة <bdi>`apothem`</bdi> المثبّتة ولا مستودع المصدر.

## بوّابة المطابقة

```bash
python -m apothem.conformity.gate --all .
```
