الهدف: فعّل إطار عمل إضافيًا لكي يُجسِّد <bdi>Apothem</bdi> تهيئته الأصلية من ملفك التعريفي
المشترك.

## المتطلّبات المسبقة

- ملف تعريفي مشترك في <bdi>`~/.config/apothem/profile.yaml`</bdi> (أنشئ واحدًا عبر
  <bdi>`apothem profile init`</bdi> إن لم يكن موجودًا بعد).
- واجهة <bdi>`apothem`</bdi> على <bdi>`PATH`</bdi> لديك. إذا ثبّتّ شجرة المصدر القائمة بذاتها،
  فصدّر كل أمر بـ <bdi>`PYTHONPATH="$HOME/.apothem/src"`</bdi>
  وشغّل <bdi>`python -m apothem`</bdi> بدلًا من <bdi>`apothem`</bdi> — أو استخدم
  <bdi>`npx @ahmed-g-gad/apothem`</bdi>.

## الخطوات

1. اسرد أُطُر العمل المُسجَّلة وانظر أيّها مثبَّت بالفعل:

   ```bash
   apothem harnesses list
   ```

   يطبع <bdi>`apothem harnesses list`</bdi> كل مُعرّف مدعوم؛ والمجموعة ذاتها موجودة في
   [قائمة أُطُر العمل](/docs/harnesses) و[سجلّ أُطُر العمل](/docs/reference/harness-registry)
   المُولّد من المصدر. اختر مُعرّف أداتك بدلًا من تثبيت القائمة هنا — فهي
   تنمو مع إضافة المحوّلات.

2. افحص إطار العمل المستهدف لتأكيد نطاقه ومسار مُخرَجه:

   ```bash
   apothem harnesses show cursor
   ```

   سطر <bdi>`Scope: project`</bdi> يعني أن المحوّل يُجسِّد في شجرة مشروع
   ويتطلّب <bdi>`--project PATH`</bdi>؛ بينما <bdi>`Scope: user`</bdi> يُجسِّد في دليل تهيئة
   بنطاق المستخدم ولا يحتاج إلى راية مشروع.

3. عاين التثبيت دون كتابة ملفات:

   ```bash
   apothem install --harness cursor --project /path/to/project --dry-run
   ```

4. ثبّت إطار العمل. لإطار عمل بنطاق المستخدم:

   ```bash
   apothem install --harness claude-code
   ```

   لإطار عمل بنطاق المشروع، مرّر جذر المشروع:

   ```bash
   apothem install --harness cursor --project /path/to/project
   ```

   ثبّت كل إطار عمل مدعوم دفعة واحدة عبر <bdi>`--harness all`</bdi> (لا تزال أُطُر العمل بنطاق المشروع تحتاج إلى <bdi>`--project`</bdi>؛ وتُتخطّى المُعرّفات المدرجة في
   <bdi>`exclude_harnesses`</bdi> في الملف التعريفي).

## التحقق

```bash
apothem verify --harness cursor --project /path/to/project
```

سطر <bdi>`✓ <harness-id> is verified`</bdi> يؤكّد أن الأهداف المُدارة موجودة وقابلة للتحليل.
يقدّم <bdi>`apothem doctor`</bdi> رؤية النظام بأكمله عبر كل إطار عمل.

## ذات صلة

- [حرّر الملف التعريفي](/docs/how-to/editing-the-profile) لتغيير ما
  يُجسّده المحوّل، ثم أعد تشغيل <bdi>`apothem update`</bdi>.
- يغطّي [التثبيت](/docs/install) تثبيت أول تشغيل.
