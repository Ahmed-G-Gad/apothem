الهدف: غيّر قيمة في الملف التعريفي المشترك وادفعها إلى كل إطار عمل ثبّتّه.

## المتطلّبات المسبقة

- واجهة <bdi>`apothem`</bdi> على <bdi>`PATH`</bdi> لديك (أو الصورة القائمة بذاتها: صدّر بـ
  <bdi>`PYTHONPATH="$HOME/.apothem/src"`</bdi> وشغّل <bdi>`python -m apothem`</bdi>، أو استخدم
  <bdi>`npx @ahmed-g-gad/apothem`</bdi>).
- ملف تعريفي في <bdi>`~/.config/apothem/profile.yaml`</bdi>. أنشئ واحدًا عبر
  <bdi>`apothem profile init`</bdi> إن كان مفقودًا.

## شكل الملف التعريفي

الملف التعريفي مستند <bdi>YAML</bdi> واحد. مفاتيحه عالية المستوى:

- <bdi>`identity`</bdi> (مطلوب) — <bdi>`name`</bdi>، بالإضافة إلى اختيارية <bdi>`role`</bdi>، <bdi>`email`</bdi>، <bdi>`website`</bdi>،
  <bdi>`github`</bdi>.
- <bdi>`preferences`</bdi> — <bdi>`language`</bdi>، <bdi>`style`</bdi> (<bdi>`concise`</bdi> / <bdi>`verbose`</bdi> / <bdi>`balanced`</bdi>),
  <bdi>`formatter`</bdi>، <bdi>`test_framework`</bdi>.
- <bdi>`rules`</bdi> — قائمة بسلاسل قواعد إضافية تُشارَك مع أُطُر العمل القادرة.
- <bdi>`seriousness`</bdi> — واحد من <bdi>`EXPLORING`</bdi>، <bdi>`PERSONAL_USE`</bdi>، <bdi>`SHARED`</bdi>,
  <bdi>`PUBLIC_LAUNCH`</bdi>.
- <bdi>`enforcement`</bdi> — مفاتيح تشغيل اختيارية (<bdi>`sprints`</bdi>، <bdi>`agent_teams`</bdi>، <bdi>`multitasking`</bdi>,
  <bdi>`continuous_execution`</bdi>، <bdi>`learning_loop`</bdi>)، وكل راية معطّلة افتراضيًا.
- <bdi>`harnesses`</bdi> — تجاوزات لكل إطار عمل مفهرسة بمُعرّف إطار العمل.
- <bdi>`exclude_harnesses`</bdi> — مُعرّفات أُطُر عمل تتخطّاها الأوامر الدفعية
  (<bdi>`--harness all`</bdi>).
- <bdi>`mcp_servers`</bdi> — تعريفات خوادم <bdi>MCP</bdi> مفهرسة باسم الخادم.
- <bdi>`agent_mcp_servers`</bdi> — لكل اسم مساعِد، خوادم <bdi>MCP</bdi> التي يجوز لذلك المساعِد استدعاؤها
  (انظر [منح مساعِد الوصول إلى خوادم <bdi>MCP</bdi>](/docs/reference/mcp#give-a-helper-access-to-mcp-servers)).
  فارغ افتراضيًا، لذا لا يصل أيّ مساعِد إلى أداة <bdi>MCP</bdi>.
- <bdi>`workspace`</bdi> — المكان الذي يحفظ فيه <bdi>Apothem</bdi> دليل العمل المشترك الخاص به
  (<bdi>`directory_name`</bdi>، <bdi>`scope`</bdi>).
- <bdi>`schema_version`</bdi> — إصدار اختياري لمخطط الملف التعريفي؛ والملف التعريفي الذي يخلو منه
  يُقرأ على أنه الإصدار 1.

كل حقل مُدرَج في [حقول الملف التعريفي](/docs/reference/profile-fields).

## الخطوات

1. افحص الملف التعريفي الحالي:

   ```bash
   apothem profile show
   ```

2. حرّره. افتحه في محرّر نظامك:

   ```bash
   apothem profile edit
   ```

   أو عيّن مفتاحًا منقّطًا واحدًا من سطر الأوامر. تُخزَّن القيمة
   حرفيًا (باستثناء <bdi>`true`</bdi>/<bdi>`false`</bdi> والإدخال الصريح <bdi>`[..]`</bdi>/<bdi>`{..}`</bdi>، فهذه تُحلَّل) ويُتحقّق من
   الملف التعريفي مقابل المخطط قبل الكتابة — يُرفض التعيين غير الصالح ويبقى
   الملف التعريفي على القرص دون تغيير:

   ```bash
   apothem profile set seriousness SHARED
   apothem profile set identity.name "Ada Lovelace"
   ```

3. أعد تجسيد أُطُر العمل لكي يصل التغيير إلى تهيئتها الأصلية.
   لإطار عمل بنطاق المستخدم:

   ```bash
   apothem update --harness claude-code
   ```

   لإطار عمل بنطاق المشروع، مرّر جذر المشروع؛ استخدم <bdi>`all`</bdi> لتحديث كل إطار عمل مثبَّت:

   ```bash
   apothem update --harness cursor --project /path/to/project
   apothem update --harness all --project /path/to/project
   ```

## التحقق

```bash
apothem profile show
apothem verify --harness all
```

يعكس <bdi>`profile show`</bdi> تحريرك.

يتحقّق <bdi>`apothem verify --harness all`</bdi> من كل إطار عمل مُسجَّل، عدا ما يُدرجه <bdi>`exclude_harnesses`</bdi> من الملف التعريفي، فيخرج برمز غير صفري ما لم تكن كل الأُطُر الأخرى مثبّتة. وأُطُر العمل ذات نطاق المشروع تحتاج أيضًا إلى <bdi>`--project PATH`</bdi>؛ ومن دونه تتوقّف الدُفعة بخطأ <bdi>`project.required`</bdi>. وللتحقّق من إطار العمل الذي حدّثته وحده، شغّل الأمر نفسه مع اسم ذلك الإطار:

```bash
apothem verify --harness <name>
```

وللحصول على نظرة شاملة للنظام تتسامح مع أُطُر العمل غير المثبّتة، شغّل <bdi>`apothem doctor`</bdi>.
