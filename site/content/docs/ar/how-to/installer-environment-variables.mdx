الهدف: قيادة <bdi>`install.sh`</bdi> / <bdi>`install.ps1`</bdi> دون تحرير السكربت،
بضبط متغيّرات البيئة قبل تشغيله.

## المتطلّبات المسبقة

- صدفة <bdi>POSIX</bdi> (<bdi>`bash`</bdi>) أو <bdi>PowerShell 5.1+</bdi>. تُشغِّل
  أمثلة <bdi>PowerShell</bdi> أدناه الأمر <bdi>`pwsh`</bdi>
  (<bdi>PowerShell 7+</bdi>). وفي <bdi>Windows PowerShell 5.1</bdi> شغِّل بدلًا من
  ذلك الأمر
  <bdi>`powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1`</bdi>.
- تُقرأ المتغيّرات مرة واحدة في بداية المُثبِّت، لذا اضبطها في الأمر نفسه (أو
  صدِّرها أولًا)، ثم شغِّل المُثبِّت.

## متغيّرات المُثبِّت

| المتغيّر | يتحكّم في | القيمة الافتراضية |
| --- | --- | --- |
| <bdi>`APOTHEM_HOME`</bdi> | وجهة التثبيت لشجرة المصدر المُستنسَخة | <bdi>`$HOME/.apothem`</bdi> |
| <bdi>`APOTHEM_REPO`</bdi> | مستودع <bdi>Git</bdi> البعيد المراد استنساخه | <bdi>`https://github.com/ahmed-g-gad/apothem`</bdi> |
| <bdi>`APOTHEM_REF`</bdi> | مرجع <bdi>Git</bdi> المراد سحبه؛ وغير المضبوط يَحُلّ أحدث وسم <bdi>`vMAJOR.MINOR.PATCH`</bdi> موقَّع، وقيمة الوسم تثبّته، و<bdi>`main`</bdi> يختار الفرع المتحرّك. ويُجهِض التثبيتَ أي مرجع ليس وسمًا، مثل <bdi>`main`</bdi>، ما لم يُضبَط <bdi>`APOTHEM_ALLOW_UNVERIFIED=1`</bdi> | غير مضبوط (أحدث وسم موقَّع) |
| <bdi>`APOTHEM_ALLOW_UNVERIFIED`</bdi> | يُخفِّض فشل التحقّق من توقيع الوسم من خطأ فادح يُجهِض التثبيت إلى تحذير عند ضبطه على <bdi>`1`</bdi> | <bdi>`0`</bdi> (يتحقّق، ويرفض عند الفشل) |
| <bdi>`APOTHEM_VERIFY`</bdi> | <bdi>`signature`</bdi> يتحقّق من توقيع <bdi>GPG</bdi> لوسم الإصدار؛ و<bdi>`checksum`</bdi> يُثبِّت أرشيف المنصّة الخاص بالإصدار بعد فحص بصمة <bdi>SHA-256</bdi> الخاصة به مقابل ملف <bdi>`SHA256SUMS`</bdi> الخاص بالإصدار (سلامة، لا إثبات لهوية من نشره) | <bdi>`signature`</bdi> |
| <bdi>`APOTHEM_RELEASE_BASE`</bdi> | قاعدة التنزيل لوضع التحقّق بالمجموع الاختباري | <bdi>`<APOTHEM_REPO>/releases/download`</bdi> |
| <bdi>`APOTHEM_SOURCE`</bdi> | شجرة مصدر محلية صريحة تُستخدَم بدلًا من الاستنساخ | غير مضبوط (استنساخ) |
| <bdi>`APOTHEM_HARNESS`</bdi> | إطار العمل المراد تثبيته | <bdi>`claude-code`</bdi> |
| <bdi>`APOTHEM_PROFILE`</bdi> | مسار ملف <bdi>YAML</bdi> للملف التعريفي المشترك | <bdi>`$HOME/.config/apothem/profile.yaml`</bdi> |
| <bdi>`APOTHEM_SKIP_VERIFY`</bdi> | يتخطّى خطوة التحقّق اللاحقة للتثبيت عند ضبطه على <bdi>`1`</bdi> | <bdi>`0`</bdi> (يعمل التحقّق) |
| <bdi>`APOTHEM_AUTO_INSTALL_DEPS`</bdi> | يُثبِّت المتطلّبات المسبقة المفقودة <bdi>`click`</bdi> / <bdi>`rich`</bdi> تلقائيًا، دون مطالبة، عند ضبطه على <bdi>`1`</bdi> | <bdi>`0`</bdi> (يطالب، أو يرفض في أنبوب غير تفاعلي) |
| <bdi>`APOTHEM_BIN_DIR`</bdi> | دليل غلاف الأمر <bdi>`apothem`</bdi> الذي يضعه المُثبِّت | <bdi>`$HOME/.local/bin`</bdi> (<bdi>POSIX</bdi>)؛ <bdi>`%LOCALAPPDATA%\Microsoft\WindowsApps`</bdi> (<bdi>Windows</bdi>) |
| <bdi>`NO_COLOR`</bdi> | يُطفئ الخرج الملوَّن عند ضبطه على أي قيمة ([<bdi>no-color.org</bdi>](https://no-color.org/))؛ ويكون التلوين مُطفأً أيضًا كلما لم يكن الخرج طرفية (أنبوب، أو ملف، أو سجلّ <bdi>CI</bdi>) | غير مضبوط (التلوين على طرفية تفاعلية فقط) |

يتقدّم <bdi>`APOTHEM_SOURCE`</bdi> على الاستنساخ: عند ضبطه على نسخة مسحوبة تحتوي
على <bdi>`src/apothem`</bdi>، يستخدمها المُثبِّت مباشرةً، ولا يمسّ
<bdi>`APOTHEM_REPO`</bdi> / <bdi>`APOTHEM_REF`</bdi> أبدًا، ويتخطّى حلّ الوسم
والتحقّق من التوقيع (لا يُجلَب شيء للتحقّق منه).

عندما يشير <bdi>`APOTHEM_HOME`</bdi> إلى دليل موجود ليس نسخة <bdi>git</bdi>
مُستنسَخة، يرفض المُثبِّت حذفه: انقله جانبًا، أو وجِّه <bdi>`APOTHEM_HOME`</bdi>
إلى مكان آخر، أو مرِّر <bdi>`--yes`</bdi> (<bdi>`-Yes`</bdi> على
<bdi>Windows</bdi>) للتصريح بالاستبدال. أما الدليل الفارغ المتقادم فيُستبدَل دون
الراية.

## نموذج الثقة

حين لا يكون <bdi>`APOTHEM_REF`</bdi> مضبوطًا، يَحُلّ المُثبِّت أحدث وسم إصدار
موقَّع ويتحقّق من توقيعه بالأمر <bdi>`git verify-tag`</bdi> قبل تجسيد أي إعداد؛
والوسم غير الموقَّع أو المُتلاعَب به يُوقِف التثبيت. أما الوسم الموقَّع الذي يغيب
المفتاح العام لمشرفه عن حلقة المفاتيح المحلية فيُوقِف التثبيت بدلًا من ذلك مع
إرشادات لاستيراد المفتاح — استورِد المفتاح وافحص بصمته مقابل القيمة المنشورة في
[<bdi>SECURITY.md</bdi>](https://github.com/ahmed-g-gad/apothem/blob/main/SECURITY.md).
قيِّد التثبيت بإصدار معروف عبر <bdi>`APOTHEM_REF=<tag>`</bdi> (يُتحقَّق منه أيضًا؛
وسم من [صفحة الإصدارات](https://github.com/ahmed-g-gad/apothem/releases))، أو اختر
الفرع المتحرّك عبر <bdi>`APOTHEM_REF=main`</bdi> (دون تحقّق)، أو اضبط
<bdi>`APOTHEM_ALLOW_UNVERIFIED=1`</bdi> للمضيّ بعد فشل التحقّق مع تحذير (للاستخدام
المعزول عن الشبكة، أو المحلي، أو مع الإصدارات السابقة لاعتماد التوقيع).

```bash title="Pinned, verified install"
APOTHEM_REF=vMAJOR.MINOR.PATCH bash install.sh
```

```bash title="Check the archive digest when the signing key is not imported"
APOTHEM_VERIFY=checksum bash install.sh
```

```bash title="Proceed without verification (interim / air-gapped)"
APOTHEM_ALLOW_UNVERIFIED=1 bash install.sh
```

## الخطوات (<bdi>POSIX bash</bdi>)

1. ثبِّت إطار عمل غير افتراضي:

   ```bash
   APOTHEM_HARNESS=cursor bash install.sh
   ```

2. قيِّد وجهة التثبيت، واختر الفرع المتحرّك <bdi>`main`</bdi>. فالفرع ليس وسمًا
   موقَّعًا، لذلك يحتاج المُثبِّت أيضًا إلى <bdi>`APOTHEM_ALLOW_UNVERIFIED=1`</bdi>:

   ```bash
   APOTHEM_REF=main APOTHEM_ALLOW_UNVERIFIED=1 APOTHEM_HOME=/opt/apothem bash install.sh
   ```

3. استخدم نسخة مسحوبة محلية وملفًا تعريفيًا مخصّصًا، مع تخطّي التحقّق:

   ```bash
   APOTHEM_SOURCE=/work/apothem \
   APOTHEM_PROFILE=/work/profile.yaml \
   APOTHEM_SKIP_VERIFY=1 \
   bash install.sh
   ```

## الخطوات (<bdi>PowerShell</bdi>)

اضبط كل متغيّر على <bdi>`$env:`</bdi> قبل تشغيل المُثبِّت:

```powershell
$env:APOTHEM_HARNESS = 'cursor'
pwsh -NoProfile -File install.ps1
```

```powershell
$env:APOTHEM_ALLOW_UNVERIFIED = '1'
$env:APOTHEM_REF = 'main'
$env:APOTHEM_HOME = 'C:\opt\apothem'
pwsh -NoProfile -File install.ps1
```

```powershell
$env:APOTHEM_SOURCE = 'C:\work\apothem'
$env:APOTHEM_PROFILE = 'C:\work\profile.yaml'
$env:APOTHEM_SKIP_VERIFY = '1'
pwsh -NoProfile -File install.ps1
```

## التحقّق

يطبع المُثبِّت <bdi>`✓ Harness <name> installed`</bdi>، ثم (ما لم يكن
<bdi>`APOTHEM_SKIP_VERIFY=1`</bdi>) <bdi>`✓ verify passed`</bdi>. أكِّد ذلك بشكل
مستقل:

```bash
apothem verify --harness cursor
```

عندما لا يكون الملف التعريفي موجودًا بعد، يُنشئ المُثبِّت ملفًا من المثال ويتابع
إلى التثبيت والتحقّق في التشغيل نفسه. حقول الهوية في المثال عناصر نائبة، لذا
يطبع التثبيت ملاحظة؛ حرِّر <bdi>`$APOTHEM_PROFILE`</bdi>، ثم شغِّل
<bdi>`apothem update --harness <name>`</bdi> لتطبيق هويتك. وتشغيل
<bdi>`--dry-run`</bdi> دون ملف تعريفي يُعايِن باستخدام المثال في مكانه ولا يكتب
شيئًا.
