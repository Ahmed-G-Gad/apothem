سجلّ الهارنس هو جرد المحوّلات المصدر-للحقيقة المُستخدَم من قِبل الـ CLI
والوثائق واختبارات التركيبات والتحقّق من دبّوس العُرف. مصدر وقت-التشغيل
هو <bdi>`src/apothem/lib/harness_registry.py`</bdi>؛ وكل صف أدناه قابل للتتبّع إلى ذلك
السجلّ، وملف <bdi>`capabilities.yml`</bdi> لكل-محوّل، و
<bdi>`STANDARD-CONVENTION-PIN.md`</bdi> لكل محوّل.

## خطّافات التحقّق

يبقى السجلّ متزامنًا عبر هذه الفحوص:

| الفحص | الغرض |
| --- | --- |
| <bdi>`python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD`</bdi> | يؤكّد أنّ لكل محوّل دبّوس عُرف حاليًّا وأنّ السجلّ لا يزال يُعدِّد سبعة عشر محوّلًا. |
| <bdi>`python -m apothem.conformity.gate --all .`</bdi> | يُشغِّل فحوص مطابقة الوثائق والتنفيذ. |
| <bdi>`python -m pytest`</bdi> | يُمرِّن اختبارات تركيبات السجلّ واختبارات عقد المحوّل. |
