سجلّ أُطُر العمل هو جرد المحوّلات الذي يُعدّ مصدر الحقيقة، وتستخدمه واجهة سطر الأوامر،
والوثائق، واختبارات التجهيزات، والتحقّق من تثبيتات الاصطلاح. ومصدر وقت التشغيل هو
<bdi>`src/apothem/lib/harness_registry.py`</bdi>؛ وكل صف أدناه قابل للتتبّع إلى ذلك
السجلّ، وإلى <bdi>`capabilities.yml`</bdi> الخاص بكل محوّل، وإلى
<bdi>`STANDARD-CONVENTION-PIN.md`</bdi> الخاص بكل محوّل.

## دعم حِزم الحمولة

قيم الحالة هي <bdi>`native`</bdi>، و<bdi>`converted`</bdi>، و<bdi>`support-tree`</bdi>،
و<bdi>`profile-projected`</bdi>، و<bdi>`unsupported`</bdi>، و<bdi>`not-applicable`</bdi>،
و<bdi>`discovery-pending`</bdi>.

تُعاد كتابة الحزمة <bdi>`converted`</bdi> بصيغة إطار العمل نفسه، وبعض حقول المصدر لا
مكان لها فيها. ولكل حزمة أوامر أو عوامل أو قواعد مُحوَّلة، يحمل ملف
<bdi>`capabilities.yml`</bdi> الخاص بالمحوّل خريطة <bdi>`conversion_losses`</bdi> تبيّن
ما يحدث لكل حقل من حقول البيانات الأمامية في المصدر:

| القيمة | المعنى |
| --- | --- |
| <bdi>`native:<field>`</bdi> | يقرؤه إطار العمل تحت ذلك الحقل. |
| <bdi>`sidecar:<path>`</bdi> | يُكتَب في ملف منفصل بجوار الملف المُحوَّل، مثل <bdi>`agents/openai.yaml`</bdi> الخاص بـ <bdi>Codex</bdi>. |
| <bdi>`filename`</bdi> | يحمله اسم الملف أو المجلّد. |
| <bdi>`inlined`</bdi> | ينتقل إلى نص المُوجِّه أو المتن. |
| <bdi>`ignored`</bdi> | يبقى في الملف، لكن إطار العمل لا يقرؤه. |
| <bdi>`dropped`</bdi> | يُستبعَد. |

## الجذور المشتركة

بعض أهداف التثبيت تُحمِّلها أُطُر عمل غير الإطار الذي يكتبها. ويُسجِّل السجلّ كل مسار
من هذا النوع في <bdi>`SHARED_ROOTS`</bdi> مع مالك واحد (المحوّل الوحيد الذي يكتبه)
والقرّاء الذين تُحمِّله وثائق مورّديهم افتراضيًا، مع صفحات المورّدين دليلًا. وتثبيت
المالك يضع محتوى <bdi>Apothem</bdi> أمام كل قارئ، وإلغاء تثبيت المالك يزيله من كل
قارئ.

| المسار | المالك | القرّاء |
| --- | --- | --- |
| <bdi>`~/.agents/skills/`</bdi> | <bdi>Codex</bdi> | <bdi>Cursor</bdi>، <bdi>Gemini CLI</bdi>، <bdi>GitHub Copilot</bdi>، <bdi>Kimi Code</bdi>، <bdi>Open-Claw</bdi>، <bdi>OpenCode</bdi>، <bdi>Windsurf</bdi>، <bdi>Zed</bdi> |
| <bdi>`~/.claude/skills/`</bdi> | <bdi>Claude Code</bdi> | <bdi>Cursor</bdi>، <bdi>OpenCode</bdi> |
| <bdi>`~/.claude/CLAUDE.md`</bdi> | <bdi>Claude Code</bdi> | <bdi>OpenCode</bdi> |
| <bdi>`<project>/AGENTS.md`</bdi> | <bdi>Kimi Code</bdi> | <bdi>Antigravity</bdi>، <bdi>CodeBuddy</bdi>، <bdi>Codex</bdi>، <bdi>Cursor</bdi>، <bdi>GitHub Copilot</bdi>، <bdi>Hermes</bdi>، <bdi>Kiro</bdi>، <bdi>OpenCode</bdi>، <bdi>Windsurf</bdi>، <bdi>Zed</bdi> |
| <bdi>`<project>/GEMINI.md`</bdi> | <bdi>Gemini CLI</bdi> | <bdi>Antigravity</bdi>، <bdi>GitHub Copilot</bdi>، <bdi>Zed</bdi> |
| <bdi>`~/.gemini/GEMINI.md`</bdi> | <bdi>Antigravity</bdi> | <bdi>Gemini CLI</bdi> |
| <bdi>`<project>/.github/copilot-instructions.md`</bdi> | <bdi>GitHub Copilot</bdi> | <bdi>Zed</bdi> |

لا تُسمّي كتلة <bdi>Apothem</bdi> التي يكتبها المالك في ملف تعليمات مشترك أيَّ أداة
بعينها قارئًا لها. ويُخفِق <bdi>`tests/unit/test_shared_roots.py`</bdi> عندما يكتب
محوّلان هدفًا من أهداف السجلّ، أو عندما يُسمّى الهدف تسمية ملف تعليمات عابر للأدوات
(<bdi>`AGENTS.md`</bdi>، و<bdi>`CLAUDE.md`</bdi>، و<bdi>`GEMINI.md`</bdi>،
و<bdi>`copilot-instructions.md`</bdi>)، دون مالك مُعلَن.

## خطّافات التحقّق

يبقى السجلّ متزامنًا عبر هذه الفحوص:

| الفحص | الغرض |
