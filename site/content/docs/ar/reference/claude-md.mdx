<bdi>`CLAUDE.md`</bdi> هو تهيئة النظام البيئي المُحمَّلة دائمًا. يُحمِّله زمن
تشغيل <bdi>harness</bdi> المضيف عند كل تفاعل، لذا فإن محتواه هو *السياق الأساسي* الذي
يُوسِّعه كل عنصر آخر.

## الأقسام

| القسم | الغرض |
|---------|---------|
| §1 حزمة الخطّة | يُسمِّي قالب حزمة الخطّة الرئيسي والأوامر الثمانية <bdi>`/plan-<stage>`</bdi> |
| §2 الهوية المعرفية وهندسة البرمجيات | يُعلِن دور مهندس البرمجيات الأقدم والموقف الإبداعي |
| §3 أدلّة العناصر | جذور القرص لكل فئة (القواعد، الأوامر، المهارات، العاملون المساعِدون المُفوَّضون، إلخ) |
| §4 الحوكمة المُتدرِّجة بالجدّية | عدسة تدرّج رباعية المستويات (EXPLORING / PERSONAL_USE / SHARED / PUBLIC_LAUNCH) |
| §5 التوجيهات التشغيلية | أُطر حلّ المشكلات، والاكتشاف الاستراتيجي، والتواصل |
| §6 التفويضات الشاملة | سجلّ <bdi>CM-N</bdi> (من <bdi>CM-1</bdi> حتى <bdi>CM-28</bdi>) |
| §7 السجلّات | سجلّات فرعية للأوامر، والقواعد، والعاملين المساعِدين المُفوَّضين، والخطّافات، والمهارات، والتطوّر، والفئات الفارغة |

## أعراف مُعرِّفات التفويض

تحمل ثلاث بادئات معاني مختلفة:

- **<bdi>CM-N</bdi>** — تفويض تهيئة، مُعرَّف في <bdi>`CLAUDE.md`</bdi> §6 ضمنيًا أو
  في <bdi>`src/apothem/rules/*.md`</bdi> وفق §7.2.
- **<bdi>TM-N</bdi>** — تفويض قالب، مُعرَّف في
  <bdi>`src/apothem/skills/plan-suite/master-template.md`</bdi> §4.
- **<bdi>CP-N</bdi>** — مبدأ أساسي، مُعرَّف في القالب نفسه §6.

قالب حزمة الخطّة هو سجلّ <bdi>TM/CP</bdi> الكنسي؛ تحلّ مراحل خطّ أنابيب
<bdi>`/plan`</bdi> الإحالات المتقاطعة عبر ذلك الملف.
