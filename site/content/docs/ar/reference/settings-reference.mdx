> **النطاق.** يصف هذا المستند ملف توصيل الخطّافات
> (<bdi>`settings.json`</bdi>) الخاصّ بـ **مُحوِّل <bdi>Claude Code</bdi>**.
> تستخدم بقيّة الـ harness أسطح إعداداتها الأصليّة الخاصّة بها — انظر
> [`site/content/docs/harnesses/<harness>.mdx`](/docs/harnesses) لمعرفة
> نقطة دخول الإعداد المكافئة لكل مُحوِّل.

## نظرة عامة

يضبط <bdi>`settings.json`</bdi> تنفيذ خطّافات <bdi>Claude Code</bdi> لمنظومة Apothem.
وهو يُصرِّح أيّ الخطّافات تُطلَق على أيّ الأحداث، ومُهَلها، وسطح
الأذونات على المستوى الأعلى. يشحن Apothem قالبًا كنسيًّا واحدًا لأنّ <bdi>Claude Code</bdi>
يُحمِّل <bdi>`~/.claude/settings.json`</bdi> عبر كل المنصّات المدعومة.

## زمن تشغيل بـ Python فقط

يستخدم كل خطّاف مُعَدّ شكل أمر <bdi>exec</bdi> الخاص بـ <bdi>Claude Code</bdi>. ويحمل القالب المشحون الرمزين <bdi>`${PYTHON_BIN}`</bdi> و<bdi>`${HARNESS_ROOT}`</bdi>؛ و<bdi>`apothem install`</bdi> يستبدل <bdi>`${PYTHON_BIN}`</bdi> بالمفسِّر المُحلَّل المطلق:

```json
{
  "type": "command",
  "command": "${PYTHON_BIN}",
  "args": ["${HARNESS_ROOT}/.apothem/support/hooks/dispatch.py", "PreToolUse", "pretooluse-write"]
}
```

يُصيِّر <bdi>`apothem install`</bdi> الرمز إلى المسار المطلق لجذر الـ harness
(صيغة الشرطة المائلة الأماميّة، صالحة على <bdi>Windows</bdi> و<bdi>macOS</bdi> و<bdi>Linux</bdi>)، بحيث
يستدعي <bdi>`settings.json`</bdi> المثبَّت المُوزِّع المُجَسَّد عند
<bdi>`~/.claude/.apothem/support/hooks/dispatch.py`</bdi> مباشرةً. المُوزِّع
وبوّابة المطابقة (<bdi>`~/.claude/.apothem/support/conformity/gate.py`</bdi>، مع فيكسترات
الـ schema بجانبها عند <bdi>`~/.claude/.apothem/support/schemas/`</bdi>) كلاهما نصّان برمجيّان
مستقلّان من المكتبة القياسيّة — لا يلزم على المضيف حزمة <bdi>`apothem`</bdi> قابلة للاستيراد،
وقالب واحد يخدم كل منصّة.

## مخطّط إعداد الخطّافات

### الأذونات

```json
"permissions": {
  "allow": ["Read", "Glob", "Grep"]
}
```

تتطلّب الأدوات غير الموجودة في <bdi>`allow`</bdi> موافقة صريحة لكل استدعاء أو إذنًا على مستوى مساحة العمل.
الأدوات للقراءة فقط مُوافَق عليها مسبقًا؛ عمليّات الكتابة (<bdi>`Write`</bdi> و<bdi>`Edit`</bdi> و<bdi>`NotebookEdit`</bdi>
و<bdi>`Bash`</bdi>) تمرّ عبر مُحقِّق <bdi>`PreToolUse`</bdi>.

### أحداث الخطّافات

> **قيم المُهَل تُماثِل الكتلة الكنسيّة في <bdi>`CLAUDE.md`</bdi> §7.4** — الجدول أدناه
> يُعيد إنتاجها لراحة القارئ؛ والعمود الكنسيّ هو الحاكم.

| الحدث | المُطلِق | المُهلة | الغرض | التفويض |
| ----- | ------- | ------- | ------- | ------- |
| **<bdi>SessionStart</bdi>** | جلسة <bdi>Claude Code</bdi> جديدة | 30 ثانية | تهيئة السياق، وقراءة الذاكرة، وفحص حالة الخطّة | CM-14 |
| **<bdi>PreToolUse</bdi>** | قبل <bdi>Write/Edit/NotebookEdit/Bash</bdi> | 10 ثوانٍ | التحقّق من امتثال <bdi>CM-7</bdi> + البيانات الأمامية | CM-7، CM-22 |
| **<bdi>PostToolUse</bdi>** | بعد كل استدعاء أداة (المطابِق <bdi>`*`</bdi>) | 10 ثوانٍ | تنبيه استشاري للضغط الاستباقي | إدارة السياق (الضغط الاستباقي) |
| **<bdi>Stop</bdi>** | الخروج من الجلسة | 60 ثانية | التخريج عند نهاية الجلسة | CM-14/CM-22/CM-24/CM-26 |

يُسجِّل هذا القالب أربعة أحداث. ولا يُسجِّل <bdi>`PreCompact`</bdi> ولا <bdi>`PostCompact`</bdi>؛ أما قالبا <bdi>Codex</bdi> و<bdi>Qwen Code</bdi> فيسجّلانهما، ويسردهما [مرجع الخطّافات](/docs/reference/hooks) لكل إطار عمل على حدة.

يقبل <bdi>`dispatch.py`</bdi> إضافةً <bdi>`UserPromptSubmit`</bdi> و<bdi>`Notification`</bdi> في قائمته
البيضاء للأحداث. لم يُوصَّل أيٌّ منهما في القوالب المشحونة؛ أضِف كتلة matcher بنفس
نمط المُحدِّد + التوزيع لتفعيله.

### الحقول على المستوى الأعلى

| الحقل | الغرض | مطلوب |
| ----- | ------- | -------- |
| `permissions` | كائن بمصفوفة <bdi>`allow`</bdi> تسرد أسماء الأدوات المُوافَق عليها مسبقًا (أدوات القراءة فقط افتراضيًّا) | نعم |
| `hooks` | خريطة من اسم الحدث ← مصفوفة كتل <bdi>`{matcher, hooks[]}`</bdi>؛ انظر **أحداث الخطّافات** أدناه | نعم |
| `model` | مُحدِّد نموذج قابل للحلّ من قِبَل المضيف. يُقبَل لقبٌ أو معرِّف كامل عندما يختار المُشغِّل ضبط أحدهما. | اختياري |
| `defaultShell` | الصَّدَفة الافتراضيّة لاستدعاءات أداة <bdi>`Bash`</bdi>. لا يضبط Apothem هذا في القالب المشترك. | اختياري |
| `autoUpdatesChannel` | قناة تحديث <bdi>Claude Code</bdi>. لا يضبط Apothem هذا في القالب المشترك. | اختياري |
| `effortLevel` | جهد الاستدلال الافتراضيّ (<bdi>`low`</bdi>، <bdi>`medium`</bdi>، <bdi>`high`</bdi>، <bdi>`max`</bdi>) | اختياري |

## التحقّق

ثلاثة مُحقِّقات تُغطّي سطح الخطّافات، بصرامة متصاعدة:

```bash
# بنيويّ + نظافة Python (سريع، دون اتصال)
python scripts/dev/validate_hooks.py

# المنظومة الكاملة (البنية + الفرونت-ماتر + فحوص الخطّافات المُفوَّضة)
python scripts/dev/validate_ecosystem.py

# مسح خصاميّ (يعصف بكل أمر خطّاف مُعَدّ بمدخلات مُتدهورة)
python scripts/dev/chaos_pass.py
```

يجب أن تخرج الثلاثة جميعًا بالرمز 0 قبل إيداع تغييرات الخطّافات أو الإعدادات.

اختبار دخان عابر لحدث مفرد:

```bash
python src/apothem/hooks/dispatch.py --event-name SessionStart
```

الخرج المتوقَّع: مظروف <bdi>JSON</bdi> من سطر واحد يحتوي على <bdi>`hookSpecificOutput`</bdi>.

## مشكلات شائعة

### انتهاء مُهلة <bdi>SessionStart</bdi>

الأكثر شيوعًا أنّ مُحدِّد <bdi>`find-python`</bdi> يكتشف شِيم <bdi>Microsoft Store</bdi> ويفشل
في حلّ مُفسِّر حقيقيّ. تحقّق:

```bash
python src/apothem/hooks/dispatch.py --event-name SessionStart
```

إن طبع الأمر مظروف <bdi>JSON</bdi> صالحًا لكن لوحة <bdi>Claude Code</bdi> أظهرت انتهاء مُهلة،
فارفع <bdi>`timeout`</bdi> الحدث في <bdi>`settings.json`</bdi>. وإن فشل الأمر على مستوى الصَّدَفة،
فثبِّت <bdi>CPython 3.10+</bdi> حقيقيًّا واضمن أنّه على الـ <bdi>PATH</bdi> أو قابل للاكتشاف بواسطة المُحدِّد.

### كل <bdi>Write/Edit</bdi> مَحظور

يُعلِّم <bdi>`PreToolUse`</bdi> المصطلحات الداخليّة للخطّة في محتوى يُكتَب خارج جذر تثبيت الـ harness (<bdi>`~/.claude/`</bdi> لمُحوِّل <bdi>Claude Code</bdi>).
راجِع المحتوى بحثًا عن انتهاكات <bdi>CM-7</bdi> (انظر
<bdi>`src/apothem/rules/persistent-conventions-vigilance.md`</bdi>). لغة النطاق فقط
لأدوات قاعدة الشِّفرة.

### عدم تحميل <bdi>settings.json</bdi>

يقرأ <bdi>Claude Code</bdi> الملف <bdi>`~/.claude/settings.json`</bdi>. تحقّق من تثبيت Apothem في
جذر الـ harness المتوقَّع وأعِد تشغيل الجلسة بعد تغيير الملف.

### الخطّافات لا تفعل شيئًا بصمت

عقد الخطّاف هو «اخرج دائمًا بالرمز 0، وأصدِر دائمًا <bdi>JSON</bdi> صالحًا». إن تعذّر تحديد موضع
المُفسِّر، يُعيد المُحدِّد فراغًا ويصير الأمر بلا عمل (<bdi>no-op</bdi>). شغِّل <bdi>`chaos_pass.py`</bdi>
للتأكّد من أنّ كل خطّاف مُعَدّ يُعيد مظروفًا صالحًا — فهو يلتقط مسارات الحلّ المُتدهورة
التي ستُخفيها جلسة حيّة.

## الأسبقيّة الطبقيّة

يحلّ <bdi>Claude Code</bdi> كائن الإعدادات الفعّال بتركيب ثلاث طبقات بترتيب
تصاعديّ للأسبقيّة:

| الطبقة | الموقع | مُودَع؟ | المسوّغ |
|------|----------|------------|-----------|
| 1. **النظام** | افتراضيات إطار العمل المُترجَمة داخل <bdi>Claude Code</bdi> نفسه | لا ينطبق (يتحكّم فيه المُورِّد) | الأرضية؛ يرث كل مُشغِّل الخطَّ الأساسي نفسه. |
| 2. **المشروع** | <bdi>`<harness-root>/settings.json`</bdi> | ✅ مُودَع | أعراف المشروع المشتركة: الخطّافات، والأذونات، وخوادم <bdi>MCP</bdi>، وتوصيل شريط الحالة. ويقع قالب مصدر <bdi>Apothem</bdi> داخل دليل القوالب الخاص بمحوّل <bdi>Claude Code</bdi>. |
| 3. **محلّيّ للمستخدِم** | <bdi>`<harness-root>/settings.local.json`</bdi> (gitignored) — مُقَولَب بوصفه <bdi>`settings.local.example.json`</bdi> ضمن <bdi>`examples/harnesses/claude-code/`</bdi> | ❌ Gitignored | تجاوزات خاصّة بالمُشغِّل: رموز <bdi>API</bdi>، ومسارات محلّيّة للجهاز، وميزات اختيارية. |

تتجاوز قيم الطبقة الأعلى قيم الطبقة الأدنى **على مستوى المفتاح-الورقة** — حين
تُصرِّح طبقتا المشروع والمحلّيّة للمستخدِم كلتاهما بإدخال <bdi>`permissions.allow`</bdi>، يُؤخَذ
الاتّحاد؛ وحين تُصرِّحان معًا بقيمة قياسيّة مثل <bdi>`theme`</bdi>، تفوز القيمة المحلّيّة للمستخدِم. أمّا
دلالة الدمج الدقيقة لكل مفتاح فيملكها harness الخاصّ بـ <bdi>Claude Code</bdi>.

### إنشاء تجاوُز محلّيّ للمستخدِم

1. انسخ <bdi>`examples/harnesses/claude-code/settings.local.example.json`</bdi> إلى <bdi>`<harness-root>/settings.local.json`</bdi>. يطابق اسم الملف <bdi>`settings.local.json`</bdi> نمط <bdi>`.gitignore`</bdi>، فلا يهبط الملف أبدًا في التحكّم بالإصدارات.
2. حرِّر النسخة المحلّية، وأبقِ فقط المفاتيح المراد تجاوزها؛ إذ يُركّب إطار العمل الطبقات، فترث المفاتيح الغائبة من طبقة المشروع.
3. تحقّق من أن الملف يُحلَّل بوصفه <bdi>JSON</bdi> صالحًا قبل الحفظ؛ فإطار العمل يرفض <bdi>JSON</bdi> المُشوَّه عند بدء الجلسة.
