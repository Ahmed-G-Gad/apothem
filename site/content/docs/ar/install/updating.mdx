## تحديث مُلحَق Claude Code

حدّث إدراج السوق (marketplace)، ثم حدّث المُلحَق من قائمة `/plugin`
داخل Claude Code:

```text title="Inside Claude Code"
/plugin marketplace update apothem
```

افتح `/plugin`، واختر **apothem**، ثم اختر إجراء التحديث عندما يُدرَج إصدار
أحدث من المُلحَق.

## يُشغّل npx الإصدار الحالي دائمًا

يحلّ `npx @ahmed-g-gad/apothem` إلى الحزمة المنشورة الحالية في كل
تشغيل، لذا لا يوجد شيء لتحديثه. عندما تقدّم ذاكرة npx المؤقتة القديمة نسخةً
أقدم، ثبّت وسم التوزيع (dist-tag) صراحةً:

```bash
npx @ahmed-g-gad/apothem@latest --version
```

## تحديث إعداد قائم على المُثبِّت

أعِد تشغيل المُثبِّت — فهو متّسق (idempotent) ويقفز سريعًا بالشجرة الموجودة —
أو شغّل نص التحديث المخصّص:

```bash title="macOS · Linux · WSL2 · BSD"
bash scripts/installer/update.sh
```

```powershell title="Windows · PowerShell"
pwsh -NoProfile -File scripts/installer/update.ps1
```

يعيد نص التحديث سحب شجرة المصدر في `APOTHEM_HOME` (الافتراضي
`~/.apothem`) إلى `APOTHEM_REF` — وإن لم يُضبَط يحلّ إلى أحدث وسم إصدار
موقّع بصيغة `vMAJOR.MINOR.PATCH`، وقيمة الوسم تثبّته، ويختار `main`
الفرع المتحرّك. يتحقّق من توقيع الوسم بـ `git verify-tag` قبل
إعادة التجسيد؛ ويُجهَض عند وسم غير موقّع أو مُتلاعَب به ما لم
يخفّض `APOTHEM_ALLOW_UNVERIFIED=1` الإجهاض إلى تحذير. ثم
يعيد تجسيد إطار العمل المُسمّى بـ `APOTHEM_HARNESS` عبر تشغيل
`apothem update` من الشجرة المُحدَّثة (ويأخذ إطار العمل قيمته الافتراضية وفق جدول
[متغيّرات بيئة المُثبِّت](/docs/how-to/installer-environment-variables)). ويتطلّب تثبيتًا سابقًا: فعندما
لا توجد شجرة في `APOTHEM_HOME` ولم يُضبَط `APOTHEM_SOURCE`، يخرج برسالة
توجّهك إلى المُثبِّت أولًا.

## إعادة تجسيد مُخرَج إطار العمل

بعد تحديث المحرّك أو تحرير `~/.config/apothem/profile.yaml`،
أعِد اشتقاق إعداد إطار العمل المُثبَّت. لا تحتاج المحوّلات ذات نطاق المستخدم إلى
`--project`؛ بينما تحتاجها المحوّلات ذات نطاق المشروع.

```bash
apothem update --harness claude-code
apothem update --harness cursor --project /path/to/project
apothem update --harness all --project /path/to/project
```

شغّل الأمر نفسه مع `--dry-run --json` عندما تحتاج إلى معاينة قابلة للقراءة آليًا
دون أي كتابة على نظام الملفات.

## حدود الأمر الحالية

يحدّث `apothem update` مُخرَج إطار العمل فقط. ولا تنفّذ واجهة سطر الأوامر
`update --self` أو `update --check` أو `update --apply`؛ حدّث المحرّك
نفسه عبر القناة التي ثبّتت منها — مسار `/plugin`، أو تشغيل
`npx` جديد، أو نصوص المُثبِّت/التحديث أعلاه.

## التحقّق من إصدار المحرّك

```bash
apothem --version
npx @ahmed-g-gad/apothem --version
```
