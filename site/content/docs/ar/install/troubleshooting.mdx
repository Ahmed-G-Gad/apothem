حلول لمشكلات تثبيت <bdi>Apothem</bdi> وزمن تشغيله الشائعة.

## مشكلات التثبيت

### لم يُعثَر على <bdi>Python 3.10+</bdi>

تفحص المُثبِّتات <bdi>`python3`</bdi> و<bdi>`python`</bdi> والأسماء المُرقَّمة
بالإصدار (من <bdi>`python3.14`</bdi> حتى <bdi>`python3.10`</bdi>) — مع رفض أغلفة
مُشغِّل <bdi>Microsoft Store</bdi> — وتتوقّف برسالة
<bdi>`No Python >= 3.10 found in PATH`</bdi> عندما لا يبلغ أي مرشّح الحدّ الأدنى
3.10. ويفحص غلاف <bdi>npx</bdi> المتغيّر <bdi>`APOTHEM_PYTHON`</bdi> إن كان
مضبوطًا، ثم <bdi>`python3`</bdi> و<bdi>`python`</bdi> و<bdi>`py -3`</bdi>، ويخرج
بالقيمة 1 مع رسالته الخاصة عندما لا يستوفي أي مرشّح الشرط. ثبّت
<bdi>CPython 3.10</bdi> أو أحدث من <bdi>python.org</bdi> أو من مستودع حِزَم نظام
التشغيل لديك، وتأكّد من أنّ <bdi>`python3 --version`</bdi> (أو
<bdi>`py -3 --version`</bdi> على <bdi>Windows</bdi>) يُبلِغ عن 3.10 على الأقل، ثم
أعِد التشغيل.

### اعتماديات زمن تشغيل مفقودة: <bdi>click</bdi>، <bdi>rich</bdi>

يُضمِّن المحرّك معظم اعتمادياته من الأطراف الثالثة داخل شجرة المصدر، لكن يجب أن
يكون <bdi>`click`</bdi> و<bdi>`rich`</bdi> قابلَيْن للاستيراد تحت المُفسِّر الذي
يختاره المُثبِّت. وعندما يكون أيٌّ منهما مفقودًا، يُسمّيه المُثبِّت ويعرض تثبيته
نيابةً عنك:

```text
! Missing Python prerequisites under <python>: click rich
  Install click rich under <python> now? [y/N]
```

اقبَل الطلب ليُشغّل المُثبِّت <bdi>`pip install`</bdi> تحت ذلك المُفسِّر. ولتخطّي
الطلب، مرِّر <bdi>`--yes`</bdi> (<bdi>`-Yes`</bdi> على <bdi>PowerShell</bdi>) أو
اضبط <bdi>`APOTHEM_AUTO_INSTALL_DEPS=1`</bdi> للتثبيت تلقائيًا. وإن رفضت — أو كان
<bdi>`pip`</bdi> غير متاح، أو فضّلت مدير حِزَم نظام التشغيل لديك — فثبّت الحِزَم
المُسمّاة بنفسك (مثل <bdi>`python3-click`</bdi> و<bdi>`python3-rich`</bdi> على
مضيفات عائلة <bdi>Debian</bdi>، أو <bdi>`pip install click rich`</bdi>) ثم أعِد
التشغيل.

### لم يُعثَر على <bdi>`apothem`</bdi> بعد تشغيل المُثبِّت

يضع المُثبِّت شجرة المصدر في <bdi>`~/.apothem`</bdi>، ويكتب غلافًا باسم
<bdi>`apothem`</bdi> في <bdi>`~/.local/bin`</bdi> افتراضيًا (<bdi>POSIX</bdi>)، أو
في <bdi>`%LOCALAPPDATA%\Microsoft\WindowsApps`</bdi> (<bdi>Windows</bdi>). ولا
يعدّل <bdi>`PATH`</bdi> لديك. وإذا لم يُعثَر على <bdi>`apothem`</bdi>، فذلك الدليل
ليس على <bdi>`PATH`</bdi>؛ أضِفه، أو استخدم صيغة <bdi>`PYTHONPATH`</bdi> الواردة
أدناه حتى تفعل ذلك. شغّل المحرّك عبر صيغة الاستدعاء التي يطبعها المُثبِّت عند
الاكتمال:

```bash
PYTHONPATH="$HOME/.apothem/src" python -m apothem <command>
```

أو استخدم صيغة <bdi>npx</bdi> (<bdi>`npx @ahmed-g-gad/apothem <command>`</bdi>)،
التي لا تحتاج إلى إدخال في <bdi>`PATH`</bdi>.

### فشل <bdi>`/plugin marketplace add`</bdi>

يجلب <bdi>`/plugin marketplace add ahmed-g-gad/apothem`</bdi> قائمة سوق الإضافات من
<bdi>GitHub</bdi>. وعندما يفشل، تأكّد من قدرة الجهاز على الوصول إلى
<bdi>`https://github.com/ahmed-g-gad/apothem`</bdi> (قواعد الشبكة أو الوكيل أو جدار
الحماية)، ثم أعِد المحاولة. وإذا أُضيف سوق الإضافات سابقًا أثناء عملية جلب جزئية،
فأزِله وأعِد إضافته قبل تشغيل <bdi>`/plugin install apothem@apothem`</bdi>.

### يقدّم <bdi>npx</bdi> نسخة قديمة

يخزّن <bdi>`npx`</bdi> الحِزَم المُنزَّلة مؤقتًا. وعندما يُبلِغ
<bdi>`npx @ahmed-g-gad/apothem --version`</bdi> عن نسخة أقدم من الإصدار الحالي،
امسح الذاكرة المؤقتة أو ثبّت وسم التوزيع (<bdi>dist-tag</bdi>):

```bash
npx clear-npx-cache
npx @ahmed-g-gad/apothem@latest --version
```

### حجب <bdi>irm / iex</bdi> على <bdi>Windows</bdi>

إذا حجبت سياسة تنفيذ <bdi>PowerShell</bdi> المُثبِّت:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
irm https://apothem.ahmedgad.com/install.ps1 | iex
```

## مشكلات زمن التشغيل

### لا يجد <bdi>apothem install</bdi> أي أُطُر عمل

شغّل <bdi>apothem doctor</bdi> لقراءة جدول <bdi>Harness Status</bdi>، الذي يحوي صفًّا واحدًا لكل إطار عمل. ويعني الصف المُعلَّم بـ <bdi>`not installed`</bdi> أن <bdi>Apothem</bdi> لم يجد تثبيتًا لذلك الإطار. والصف المُعلَّم بـ <bdi>`needs --project`</bdi> يخص إطار عمل ذا نطاق مشروع، ولا يفحصه <bdi>doctor</bdi> إلا حين تمرّر <bdi>`--project <path>`</bdi>. وإذا أبلغ <bdi>doctor</bdi> بـ <bdi>`No harness is installed yet`</bdi>، فتأكّد من تثبيت إطار العمل لديك، ثم شغّل <bdi>`apothem install --harness <name>`</bdi>.

### يُبلِغ <bdi>apothem verify</bdi> عن محوّل فاشل

أعِد تشغيل <bdi>apothem install</bdi> لإعادة تجسيد المحوّل. وإذا استمرّت المشكلة،
فراجع الصفحة الخاصة بالمحوّل ضمن [محوّلات أُطُر العمل](/docs/harnesses).

### الخطّافات لا تُطلَق في <bdi>Claude Code</bdi>

تأكّد من أنّ <bdi>Apothem</bdi> موصول عبر فحص <bdi>~/.claude/settings.json</bdi>
بحثًا عن إدخالات الخطّاف. وإذا كان الملف يفتقر إلى الخطّافات، فشغّل
<bdi>apothem install</bdi> مجدّدًا.
