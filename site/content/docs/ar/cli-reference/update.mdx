يعيد تثبيت إعداد محوّل إطار عمل من الملف التعريفي المشترك الحالي.

## الموجز

```
apothem update --harness NAME|all [--profile PATH] [--dry-run]
                [--project PATH]
                [--quiet|-q] [--verbose|-v]
                [--format plain|json] [--json] [--no-color]
```

يعيد <bdi>`update`</bdi> تجسيد مخرجات إطار العمل من الملف التعريفي المشترك الحالي.
ويستخدم التحقّق نفسه من الملف التعريفي، واختيار <bdi>`--harness all`</bdi> نفسه،
وفحص نطاق المشروع نفسه، وسلوك التشغيل التجريبي نفسه، وغلاف <bdi>JSON</bdi> نفسه التي
يستخدمها <bdi>`install`</bdi>.

يُحَلّ الاسم المستعار بصيغة الاستمرار <bdi>`apothem updating`</bdi> إلى المعالج
نفسه.

## الخيارات

| الخيار | الوصف |
|---|---|
| <bdi>`--harness NAME`</bdi> | محوّل إطار العمل المراد تحديثه، أو <bdi>`all`</bdi> للمجموعة الشاملة للسجلّ كله (مطلوب). |
| <bdi>`--profile PATH`</bdi> | مسار ملف <bdi>YAML</bdi> للملف التعريفي المشترك. القيمة الافتراضية <bdi>`~/.config/apothem/profile.yaml`</bdi>. |
| <bdi>`--dry-run`</bdi> | يعاين التحديث دون كتابة ملفات. |
| <bdi>`--project PATH`</bdi> | جذر المشروع لأُطُر العمل ذات نطاق المشروع. مطلوب عندما تتضمّن مجموعة أُطُر العمل المختارة محوّلات ذات نطاق المشروع. |
| <bdi>`--quiet`, `-q`</bdi> | يُخمِد المخرجات المعلوماتية؛ لا تُصدَر إلا الأخطاء. |
| <bdi>`--verbose`, `-v`</bdi> | يُصدِر مخرجات تشخيصية إضافية. |
| <bdi>`--format plain\|json`</bdi> | صيغة المخرجات (الافتراضي: <bdi>`plain`</bdi>). |
| <bdi>`--json`</bdi> | اختصار لـ <bdi>`--format json`</bdi>. |
| <bdi>`--no-color`</bdi> | يعطّل رموز ألوان <bdi>ANSI</bdi> في المخرجات. |
| <bdi>`-h`, `--help`</bdi> | يعرض المساعدة ويخرج. |

## مخرجات <bdi>JSON</bdi>

```json
{
  "schema_version": 1,
  "status": "success",
  "command": "update",
  "action": "updated",
  "harness": "claude-code",
  "profile_path": "C:\\Users\\Example\\.config\\apothem\\profile.yaml",
  "project": null,
  "files_written": [],
  "results": [],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

يُرجِع <bdi>`--dry-run`</bdi> القيمتين <bdi>`status: "dry_run"`</bdi>
و<bdi>`files_written: []`</bdi>.

## أمثلة

```bash
apothem update --harness claude-code
apothem update --harness claude-code --dry-run
apothem update --harness all --project . --dry-run --json
apothem Updating --harness claude-code   # continuous-form alias
apothem updating --harness claude-code   # lowercase variant
```

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | حُدِّث المحوّل بنجاح، أو خُطِّط التشغيل التجريبي دون أخطاء |
| 1 | خطأ متوقّع في التحقّق، أو الملف التعريفي، أو إطار العمل، أو المشروع، أو المحوّل |
| 2 | تجسيد جزئي للدفعة بعد عملية كتابة واحدة على الأقل |
| 64 | خطأ استخدام: خيار أو أمر غير معروف، أو قيمة خيار مفقودة أو غير صالحة. ومع <bdi>`--json`</bdi> يكون الخطأ غلاف <bdi>JSON</bdi> يحمل الرمز <bdi>`cli.usage`</bdi>. |
