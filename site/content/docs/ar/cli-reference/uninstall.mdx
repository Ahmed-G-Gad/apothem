يزيل تهيئة مُحَوِّل مساعد برمجي.

## الموجز

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

يزيل أهداف المساعد البرمجي التي يديرها المُحَوِّل. يطلب التأكيد ما لم يُقدَّم <bdi>`--yes`</bdi>. إذا لم يكن المساعد البرمجي المُحدَّد مُثبَّتًا، ينجح الأمر (رمز الخروج <bdi>0</bdi>) مع إشعار <bdi>«nothing to remove»</bdi>.

يُحَلّ الاسم البديل بالصيغة المستمرّة <bdi>`apothem uninstalling`</bdi> إلى المعالج نفسه.

## الخيارات

| الخيار | الوصف |
|---|---|
| `--harness NAME` | مُحَوِّل المساعد البرمجي المراد إزالته، أو `all` للمجموعة على نطاق السجلّ بأكمله (مطلوب). |
| `--yes` | يتخطّى مطالبة التأكيد. |
| `--project PATH` | جذر المشروع للمساعدات البرمجية بنطاق المشروع. |
| `--quiet`, `-q` | يُخمِد المخرجات المعلوماتية؛ تُصدَر الأخطاء فقط. |
| `--verbose`, `-v` | يُصدِر مخرجات تشخيصية إضافية. |
| `--format plain\|json` | تنسيق المخرجات (الافتراضي: `plain`). |
| `--json` | اختصار لـ `--format json`. |
| `--no-color` | يُعطِّل رموز ألوان <bdi>ANSI</bdi> في المخرجات. |
| `-h`, `--help` | يعرض المساعدة ويخرج. |

## مخرجات JSON

عندما يكون المُحَوِّل مُثبَّتًا ويُزال بنجاح:

```json
{"action": "uninstalled", "harness": "claude-code", "output_path": "..."}
```

عندما لم يكن المُحَوِّل مُثبَّتًا:

```json
{"status": "not_installed", "harness": "claude-code"}
```

## أمثلة

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem Uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | تمّت إزالة المُحَوِّل، أو لم يكن مُثبَّتًا |
| 1 | لم يُعثَر على المساعد البرمجي، أو أجهض المستخدم مطالبة التأكيد |

## انظر أيضًا

- <bdi>`apothem uninstalling`</bdi> — اسم بديل بالصيغة المستمرّة لهذا الأمر (مُوثَّق هنا؛ تقبل واجهة سطر الأوامر كلتا الصيغتين)
- [apothem install](/docs/cli-reference/install) — تثبيت تهيئة مساعد برمجي
- [apothem verify](/docs/cli-reference/verify) — تأكيد حالة التثبيت
