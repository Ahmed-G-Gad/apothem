يطبع سكربت إكمال للصدفة المطلوبة إلى <bdi>stdout</bdi>. تفعيل الإكمال **اختياري**:
هذا الأمر لا يفعل سوى طباعة السكربت — ولا يحرّر أبدًا ملفات بدء تشغيل صدفتك. وأنت من
يُلحق المخرجات بملف الإكمال الخاص بالصدفة بنفسك.

## الموجز

```
apothem completion bash|zsh|fish|powershell
```

يفعّل السكربت المُصدَر إكمال <bdi>`<TAB>`</bdi> للأوامر الفرعية لـ
<bdi>`apothem`</bdi>، وراياتها، و— للخيار <bdi>`--harness`</bdi> — لمعرّفات أُطُر
العمل المُسجَّلة إضافةً إلى <bdi>`all`</bdi>.

## الأصداف المدعومة

| الصدفة | كيف يُنتَج السكربت |
|---|---|
| <bdi>`bash`</bdi> | سكربت إكمال <bdi>bash</bdi> الأصلي في <bdi>Click</bdi>. |
| <bdi>`zsh`</bdi> | سكربت إكمال <bdi>zsh</bdi> الأصلي في <bdi>Click</bdi>. |
| <bdi>`fish`</bdi> | سكربت إكمال <bdi>fish</bdi> الأصلي في <bdi>Click</bdi>. |
| <bdi>`powershell`</bdi> | سكربت <bdi>`Register-ArgumentCompleter`</bdi> يولّده صنف إكمال <bdi>PowerShell</bdi> الذي يسجّله <bdi>Apothem</bdi> لدى <bdi>Click</bdi> (إذ لا يشحن <bdi>Click</bdi> صنفًا كهذا أصليًا)، ويقود بروتوكول الإكمال نفسه الذي تستخدمه الأصداف الأخرى. |

طلب أي صدفة أخرى يُنهي الأمر بالرمز <bdi>`64`</bdi> مع قائمة الأصداف المدعومة.

## تفعيل الإكمال لكل صدفة

يجب أولًا أن يكون الأمر <bdi>`apothem`</bdi> على <bdi>`PATH`</bdi> لديك. تكتب
المُثبِّتات ذات الخطوة الواحدة غلاف <bdi>`apothem`</bdi> في
<bdi>`$HOME/.local/bin`</bdi> (<bdi>POSIX</bdi>) أو
<bdi>`%LOCALAPPDATA%\Microsoft\WindowsApps`</bdi> (<bdi>Windows</bdi>) ولا تحرّر
<bdi>`PATH`</bdi> لديك أبدًا، لذا أضِف ذلك الدليل إن لم يكن مُدرَجًا فيه أصلًا. ثم
فعّل الإكمال بإلحاق السكربت بملف الإكمال الخاص بالصدفة وإعادة تشغيل الصدفة:

```bash
# bash — append to your bashrc
apothem completion bash >> ~/.bashrc

# zsh — append to your zshrc
apothem completion zsh >> ~/.zshrc

# fish — write to the fish completions directory
apothem completion fish > ~/.config/fish/completions/apothem.fish
```

```powershell
# PowerShell — append the completer registration to your profile
apothem completion powershell >> $PROFILE
```

لتجربة الإكمال في الجلسة الحالية فقط دون تحرير أي ملف، حمّل السكربت مباشرةً عبر
<bdi>source</bdi> (<bdi>bash/zsh</bdi>): <bdi>`source <(apothem completion bash)`</bdi>.

## لماذا هو اختياري

لا يحرّر <bdi>Apothem</bdi> أبدًا ملفات بدء تشغيل صدفة المُشغِّل بصمت. تطبع
المُثبِّتات تلميحًا من سطر واحد يشير إلى هذا الأمر؛ ويقرّر المُشغِّل ما إذا كان سيفعّل
الإكمال وأيّ ملف سيُلحق به. وهذا يُبقي أثر التثبيت قابلًا للتنبّؤ وقابلًا للعكس —
فإزالة الكتلة المُلحَقة تعطّل الإكمال.

## الخيارات

| الخيار | الوصف |
|---|---|
| <bdi>`SHELL`</bdi> | واحدة من <bdi>`bash`</bdi>، <bdi>`zsh`</bdi>، <bdi>`fish`</bdi>، <bdi>`powershell`</bdi> (وسيط موضعي مطلوب). |
| <bdi>`-h`, `--help`</bdi> | يعرض المساعدة ويخرج. |

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | أُصدِر سكربت الإكمال |
| 64 | طُلبت صدفة غير مدعومة، أو وقع خطأ استخدام آخر (مع <bdi>`--json`</bdi>، غلاف خطأ <bdi>`cli.usage`</bdi>) |
