إدارة الملف التعريفي المشترك لـ <bdi>Apothem</bdi>.

<bdi>`profile`</bdi> مجموعة أوامر ذات أربعة أوامر فرعية: <bdi>`init`</bdi>، و<bdi>`show`</bdi>، و<bdi>`set`</bdi>، و<bdi>`edit`</bdi>.
الملف التعريفي المشترك هو مصدر الحقيقة الوحيد الذي يُجسِّده كل محوّل إطار عمل في
إعداده الأصلي.

## الموجز

```
apothem profile init [--profile PATH] [--force]
                     [--quiet|-q] [--verbose|-v]
                     [--format plain|json] [--json] [--no-color]
apothem profile show [--profile PATH] [--quiet|-q] [--verbose|-v]
                     [--format plain|json] [--json] [--no-color]
apothem profile set KEY VALUE
                     [--profile PATH] [--quiet|-q] [--verbose|-v]
                     [--format plain|json] [--json] [--no-color]
apothem profile edit [--profile PATH] [--quiet|-q] [--verbose|-v]
                     [--format plain|json] [--json] [--no-color]
```

## الخيارات المشتركة

يقبل كل أمر فرعي الخيارات المشتركة أدناه.

| الخيار | الوصف |
|---|---|
| <bdi>`--profile PATH`</bdi> | مسار ملف <bdi>YAML</bdi> للملف التعريفي المشترك (القيمة الافتراضية هي الموقع القياسي للملف التعريفي). |
| <bdi>`--quiet`</bdi>، <bdi>`-q`</bdi> | يُخمِد المخرجات المعلوماتية؛ لا تُصدَر إلا الأخطاء. |
| <bdi>`--verbose`</bdi>، <bdi>`-v`</bdi> | يُصدِر مخرجات تشخيصية إضافية. |
| <bdi>`--format plain\|json`</bdi> | صيغة المخرجات (الافتراضي: <bdi>`plain`</bdi>). |
| <bdi>`--json`</bdi> | اختصار لـ <bdi>`--format json`</bdi>. |
| <bdi>`--no-color`</bdi> | يُعطِّل رموز ألوان <bdi>ANSI</bdi> في المخرجات. |
| <bdi>`-h`</bdi>، <bdi>`--help`</bdi> | يعرض المساعدة ويخرج. |

## الأوامر الفرعية

### <bdi>`profile init`</bdi>

يُنشئ هيكلًا أوّليًا أدنى لملف تعريفي صالح وفق المخطط في
<bdi>`~/.config/apothem/profile.yaml`</bdi> أو <bdi>`--profile PATH`</bdi>. تُحفَظ
الملفات الموجودة ما لم يُقدَّم <bdi>`--force`</bdi>.

السطر الأول من الهيكل الأوّلي سطر وضع <bdi>`yaml-language-server`</bdi> يُسمّي قيمة
<bdi>`$id`</bdi> لمخطط الملف التعريفي،
<bdi>`https://apothem.ahmedgad.com/schemas/profile.schema.json`</bdi>. يقدّم الموقع
المخطط المُحزَّم على ذلك العنوان، لذا فإن المحرّر الذي يدعم لغة <bdi>YAML</bdi>
يتحقّق من الملف التعريفي أثناء تحريرك له. وكل مخطط مُحزَّم تحت
<bdi>`src/apothem/schemas/`</bdi> يُقدَّم بالطريقة نفسها على
<bdi>`https://apothem.ahmedgad.com/schemas/<file>`</bdi>.

| الخيار | الوصف |
|---|---|
| <bdi>`--force`</bdi> | يكتب فوق هيكل أوّلي موجود للملف التعريفي. |

### <bdi>`profile show`</bdi>

يعرض الملف التعريفي المشترك بعد التحقّق منه وتوسيع قيمه الافتراضية. مع
<bdi>`--json`</bdi> يكون المستند هو الملف التعريفي نفسه، تتصدّره
<bdi>`schema_version`</bdi>: نسخة مخطط الملف التعريفي التي قرأه المحرّك على أساسها
(راجع [عقد مخرجات <bdi>JSON</bdi>](/docs/cli-reference#عقد-مخرجات-json)).

### <bdi>`profile set KEY VALUE`</bdi>

يُعيِّن مفتاحًا في الملف التعريفي المشترك. <bdi>`KEY`</bdi> مسار منقوط ينزل داخل
الملف التعريفي المتداخل (<bdi>`identity.name`</bdi>، و<bdi>`preferences.style`</bdi>،
و<bdi>`enforcement.sprints`</bdi>، و<bdi>`harnesses.<harness>.preferences.style`</bdi>)؛
والمفتاح المفرد الذي لا نقطة فيه يُعيِّن عقدة في المستوى الأعلى. تُخزَّن
<bdi>`VALUE`</bdi> سلسلةً حرفية — لا تُحوَّل الكلمات المجرّدة قسرًا (تبقى
<bdi>`no`</bdi> هي <bdi>`"no"`</bdi>، وتبقى <bdi>`2024-01-01`</bdi> و<bdi>`1.0`</bdi>
سلاسل نصّية) — باستثناء <bdi>`true`</bdi>/<bdi>`false`</bdi> (أعلام الفرض المنطقية)
والإدخال الصريح <bdi>`[...]`</bdi>/<bdi>`{...}`</bdi> بصيغة قائمة/خريطة. ويُتحقَّق من
الملف التعريفي المُجمَّع بالكامل مقابل المخطط قبل الكتابة؛ ويُرفَض التعيين غير
الصالح ويبقى الملف التعريفي على القرص دون تغيير.

| الوسيط | الوصف |
|---|---|
| <bdi>`KEY`</bdi> | المسار المنقوط داخل الملف التعريفي المراد تعيينه (مطلوب). |
| <bdi>`VALUE`</bdi> | القيمة الحرفية المراد إسنادها؛ يُتحقَّق منها قبل الكتابة (مطلوب). |

### <bdi>`profile edit`</bdi>

يفتح الملف التعريفي المشترك في محرّر النظام.

## أخطاء التحقّق

كل أمر يقرأ الملف التعريفي يتحقّق منه مقابل المخطط المُحزَّم ويُبلِغ عن **كل** مشكلة
يجدها في تمريرة واحدة، بحيث يمكن لتعديل واحد أن يُصلحها جميعًا:

- **المخرجات النصّية العادية** تُسمّي المشكلة الأولى كاملةً (<bdi>`Field`</bdi>،
  و<bdi>`Reason`</bdi>، و<bdi>`Fix`</bdi>، و<bdi>`Offending value (redacted)`</bdi>:
  المُدخَل الذي فشل، مع استبدال القيم ذات هيئة الأسرار بـ <bdi>`<redacted>`</bdi>؛
  وهو ليس أبدًا بديلًا مقترحًا)، ثم تسرد حتى عشر مشكلات أخرى تحت
  <bdi>`Other problems`</bdi>.
- **مخرجات <bdi>JSON</bdi>** تحتفظ بالمشكلة الأولى في حقول المستوى الأعلى من الكائن
  <bdi>`error`</bdi>، وتضيف مصفوفة <bdi>`errors`</bdi> تضمّ كل مشكلة (<bdi>`code`</bdi>،
  و<bdi>`field`</bdi>، و<bdi>`reason`</bdi>، و<bdi>`fix`</bdi>، و<bdi>`safe_value`</bdi>).
- **المفاتيح غير المعروفة** لا تُردِّد إلا المفتاح غير المتوقَّع وقيمته المُنقَّحة، لا
  الملف التعريفي كاملًا.
- **علامات الكتلة المُدارة.** لا يجوز لأي مفتاح أو قيمة نصّية أن يحتوي
  <bdi>`<!-- BEGIN APOTHEM MANAGED BLOCK -->`</bdi> أو
  <bdi>`<!-- END APOTHEM MANAGED BLOCK -->`</bdi>. يكتب <bdi>Apothem</bdi> هاتين
  العلامتين حول الكتلة التي يديرها في ملفات التعليمات، ويقع نصّ الملف التعريفي داخل
  تلك الكتلة، لذا فإن وجود علامة فيه سيشطر الكتلة. ويفشل كل حقل من هذا النوع بالرمز
  <bdi>`profile.managed_block_marker`</bdi>: يكون <bdi>`field`</bdi> مساره المنقوط (مثل
  <bdi>`rules.2`</bdi> أو <bdi>`mcp_servers.search.env.SEARCH_MODE`</bdi>) ويُسمّي
  <bdi>`reason`</bdi> العلامة. ولا تُردَّد القيمة نفسها أبدًا (قيمة
  <bdi>`safe_value`</bdi> هي <bdi>`null`</bdi>)، إذ قد تكون بيانات اعتماد.

يكتب <bdi>`profile init`</bdi> (وكل أمر آخر يُنشئ هيكلًا أوّليًا لملف تعريفي)
<bdi>`schema_version: 1`</bdi>. ويُقرَأ الملف التعريفي الذي لا يحمل
<bdi>`schema_version`</bdi> على أنه النسخة 1.

## أمثلة

```bash
apothem profile init
apothem profile init --profile ./profile.yaml --force --json
apothem profile show
apothem profile show --json
apothem profile set seriousness SHARED
apothem profile set rules '["Use fake placeholders in examples."]'
apothem profile edit
```

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | نجاح (أو، بالنسبة إلى <bdi>`edit`</bdi>، خرج المحرّر خروجًا طبيعيًا) |
| 1 | الملف التعريفي مفقود، أو غير صالح، أو موجود مسبقًا دون <bdi>`--force`</bdi>، أو تتعذّر كتابته |
| 64 | خطأ في الاستخدام: خيار أو أمر غير معروف، أو قيمة خيار مفقودة أو غير صالحة. مع <bdi>`--json`</bdi> يكون الخطأ غلاف <bdi>JSON</bdi> بالرمز <bdi>`cli.usage`</bdi>. |
