ترحيل مساحة عمل قديمة خاصة بكل إطار عمل إلى البنية المشتركة <bdi>`.apothem`</bdi>.

## الموجز

```
apothem migrate-workspace [--project PATH] [--dry-run]
                          [--quiet|-q] [--verbose|-v]
                          [--format plain|json] [--json] [--no-color]
```

يطوي <bdi>`migrate-workspace`</bdi> دليل بيانات قديمًا خاصًا بكل إطار عمل
(<bdi>`.apothem/<harness>/...`</bdi>) وشجرة <bdi>`.plans/`</bdi> قديمة في دليل العمل
المشترك الواحد <bdi>`.apothem/{plans,memory,learning,contexts}`</bdi>. والقاعدة هي
جذر <bdi>`--project`</bdi> المُحلَّل عند تقديمه، وإلا فدليل العمل الحالي (الافتراضي
المحلي للمشروع).

تُدمَج مخازن الذاكرة والسياقات والتعلّم الخاصة بكل إطار عمل دمجَ اتحاد في المخزن
المشترك حسب المُعرِّف؛ وتُضَمّ إشارات التعلّم بعضها إلى بعض مع إزالة التكرار؛
ويُتخطّى السجلّ المتعارض (المُعرِّف نفسه، والمتن مختلف)، ولا يُكتَب فوقه أبدًا.
وتُنقَل شجرة <bdi>`.plans/`</bdi> القديمة إلى ما تحت <bdi>`.apothem/plans/`</bdi>.
ويُنسَخ كل مصدر مُستهلَك احتياطيًا أولًا. والترحيل متساوي الأثر عند التكرار —
إعادة تشغيله على شجرة مُرحَّلة سلفًا لا تفعل شيئًا.

## الخيارات

| الخيار | الوصف |
|---|---|
| <bdi>`--project PATH`</bdi> | جذر المشروع للمحوّلات ذات نطاق المشروع التي تُجسِّد في شجرة مشروع بدلًا من دليل إعداد بنطاق المستخدم. |
| <bdi>`--dry-run`</bdi> | يكتشف البنية القديمة ويُبلِغ عمّا سيُرحَّل دون كتابة. |
| <bdi>`--quiet`</bdi>، <bdi>`-q`</bdi> | يُخمِد المخرجات المعلوماتية؛ لا تُصدَر إلا الأخطاء. |
| <bdi>`--verbose`</bdi>، <bdi>`-v`</bdi> | يُصدِر مخرجات تشخيصية إضافية. |
| <bdi>`--format plain\|json`</bdi> | صيغة المخرجات (الافتراضي: <bdi>`plain`</bdi>). |
| <bdi>`--json`</bdi> | اختصار لـ <bdi>`--format json`</bdi>. |
| <bdi>`--no-color`</bdi> | يُعطِّل رموز ألوان <bdi>ANSI</bdi> في المخرجات. |
| <bdi>`-h`</bdi>، <bdi>`--help`</bdi> | يعرض المساعدة ويخرج. |

## مخرجات <bdi>JSON</bdi>

يحمل غلاف <bdi>`--json`</bdi> نتيجة الترحيل. عند اكتمال الترحيل تكون قيمة
<bdi>`status`</bdi> هي <bdi>`success`</bdi>، وتُبلِغ الحمولة عن أعداد السجلّات
المُدمَجة، وعمّا إذا نُقِلت شجرة <bdi>`.plans/`</bdi>، وعن جذر النسخ الاحتياطية، وعن
أي تعارضات مُتخطّاة. أما استدعاء <bdi>`--dry-run`</bdi> فيُبلِغ بدلًا من ذلك عن
<bdi>`legacy_layout_detected`</bdi>.

```json
{
  "schema_version": 1,
  "command": "migrate-workspace",
  "status": "success",
  "base": "/home/example/project",
  "migrated": true,
  "backup_root": "/home/example/project/.apothem/.backups/01J9Z…",
  "memory_merged": 12,
  "contexts_merged": 4,
  "learning_merged": 7,
  "conflicts": [],
  "plans_moved": true,
  "notes": []
}
```

عندما لا توجد بنية قديمة، تكون قيمة <bdi>`migrated`</bdi> هي <bdi>`false`</bdi> ولا
يُكتَب أي شيء. ويُغفِل غلاف <bdi>`--dry-run`</bdi> أعداد النتيجة ولا يُبلِغ إلا عن
الاكتشاف:

```json
{
  "schema_version": 1,
  "command": "migrate-workspace",
  "base": "/home/example/project",
  "dry_run": true,
  "legacy_layout_detected": false
}
```

## أمثلة

```bash
apothem migrate-workspace
apothem migrate-workspace --project .
apothem migrate-workspace --dry-run --json
```

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | اكتمل الترحيل، أو لم يُعثَر على بنية قديمة (لا شيء لترحيله) |
| 1 | خطأ متوقَّع — خطأ تحقّق أو خطأ في جذر المشروع، أو إخفاق في الترحيل |
| 64 | خطأ في الاستخدام: خيار أو أمر غير معروف، أو قيمة خيار مفقودة أو غير صالحة. مع <bdi>`--json`</bdi> يكون الخطأ غلاف <bdi>JSON</bdi> بالرمز <bdi>`cli.usage`</bdi>. |
