سرد محوّلات أُطُر العمل المُسجَّلة وفحصها.

<bdi>`harnesses`</bdi> مجموعة أوامر ذات أمرين فرعيين: <bdi>`list`</bdi> و<bdi>`show`</bdi>.

## الموجز

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## الأوامر الفرعية

### <bdi>`harnesses list`</bdi>

يسرد كل محوّلات أُطُر العمل المُسجَّلة.

| الخيار | الوصف |
|---|---|
| <bdi>`--quiet`</bdi>، <bdi>`-q`</bdi> | يُخمِد المخرجات المعلوماتية؛ لا تُصدَر إلا الأخطاء. |
| <bdi>`--verbose`</bdi>، <bdi>`-v`</bdi> | يُصدِر مخرجات تشخيصية إضافية. |
| <bdi>`--format plain\|json`</bdi> | صيغة المخرجات (الافتراضي: <bdi>`plain`</bdi>). |
| <bdi>`--json`</bdi> | اختصار لـ <bdi>`--format json`</bdi>. |
| <bdi>`--no-color`</bdi> | يُعطِّل رموز ألوان <bdi>ANSI</bdi> في المخرجات. |
| <bdi>`-h`</bdi>، <bdi>`--help`</bdi> | يعرض المساعدة ويخرج. |

### <bdi>`harnesses show NAME`</bdi>

يعرض تفاصيل محوّل إطار عمل محدّد. <bdi>`NAME`</bdi> هو مُعرِّف إطار العمل بصيغة
<bdi>kebab-case</bdi>؛ شغِّل <bdi>`apothem harnesses list`</bdi> لرؤية المُعرِّفات
المتاحة.

| الخيار | الوصف |
|---|---|
| <bdi>`NAME`</bdi> | محوّل إطار العمل المراد فحصه (وسيط موضعي مطلوب). |
| <bdi>`--quiet`</bdi>، <bdi>`-q`</bdi> | يُخمِد المخرجات المعلوماتية؛ لا تُصدَر إلا الأخطاء. |
| <bdi>`--verbose`</bdi>، <bdi>`-v`</bdi> | يُصدِر مخرجات تشخيصية إضافية. |
| <bdi>`--format plain\|json`</bdi> | صيغة المخرجات (الافتراضي: <bdi>`plain`</bdi>). |
| <bdi>`--json`</bdi> | اختصار لـ <bdi>`--format json`</bdi>. |
| <bdi>`--no-color`</bdi> | يُعطِّل رموز ألوان <bdi>ANSI</bdi> في المخرجات. |
| <bdi>`-h`</bdi>، <bdi>`--help`</bdi> | يعرض المساعدة ويخرج. |

## أمثلة

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

مُعرِّفات أُطُر العمل المُسجَّلة هي:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

## رموز الخروج

| الرمز | المعنى |
|---|---|
| 0 | نجاح |
| 1 | لم يُعثَر على إطار العمل (<bdi>`harnesses show`</bdi> مع <bdi>`NAME`</bdi> غير معروف)، أو أخفق كل محوّل في التحميل أو الإبلاغ (<bdi>`harnesses list`</bdi>) |
| 2 | أُدرِج محوّل واحد على الأقل، لكن محوّلًا واحدًا على الأقل أخفق في الإبلاغ (<bdi>`harnesses list`</bdi>) |
| 64 | خطأ في الاستخدام: خيار أو أمر غير معروف، أو قيمة خيار مفقودة أو غير صالحة. مع <bdi>`--json`</bdi> يكون الخطأ غلاف <bdi>JSON</bdi> بالرمز <bdi>`cli.usage`</bdi>. |
