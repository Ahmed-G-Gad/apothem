سير العمل اليومية. تغطّي هذه الأدلّة قدرات <bdi>Apothem</bdi> الأساسية الأربع —
ملف تعريف الحوكمة المشترك، وقواعد السلوك، وخطّا أنابيب <bdi>`/plan`</bdi>
و<bdi>`/research`</bdi>، وبوابة المطابقة — إضافةً إلى كتابة العمّال المُفوَّضين
والخطّافات.
