العمّال المُفوَّضون في <bdi>Apothem</bdi> هم تعريفات عُمّال دائمة وقابلة لإعادة الاستخدام
مُخزَّنة تحت شجرة <bdi>`src/apothem/`</bdi> (الدليل الكنسي مُبيَّن أدناه — الاسم
مُحتفَظ به للتوافق مع مُحمِّل وقت التشغيل):

```text
src/apothem/agents/
```

كل عامل مُفوَّض يُرمِّز دورًا متخصّصًا وإشارات اكتشاف ومجموعة أدوات مسموحًا بها.

## بنية ملف العامل المُفوَّض

```markdown
---
name: "my-agent"
description: "..."
tools: "Read, Grep, Glob"
---

# My assistant

## Role
...

## Detection signals
Matched when: ...

## Workflow
...
```

## العمّال المُفوَّضون المُدمَجون

| العامل المُفوَّض | الغرض |
|-------|---------|
| <bdi>`codebase-explorer`</bdi> | استكشاف عميق لقاعدة الشيفرة |
| <bdi>`convention-auditor`</bdi> | التحقّق من التسمية والتنسيق |
| <bdi>`memory-auditor`</bdi> | التحقّق من دقّة الذاكرة |
| <bdi>`quality-gate`</bdi> | فحص lint والاختبار وفحص الأنواع والمسح الأمني |

## استدعاء العمّال المُفوَّضين

يُوزِّع المُنسِّقُ العمّالَ المُفوَّضين عبر أداة التفويض التي يعرضها وقت تشغيل
المضيف. ويختار المُنسِّقُ العاملَ المُفوَّضَ المُطابِق بناءً على وصف المهمّة وإشارات الاكتشاف.
