تُجري بوابة المطابقة الموجودة في <bdi>`src/apothem/conformity/gate.py`</bdi>
خمسة عشر فحصًا آليًّا على كلّ مُنتَج يكتبه المُشغِّل.

## تشغيل البوابة

```bash
python -m apothem.conformity.gate
```

## أعمدة البوابة

| العمود | الفحص | النوع |
|-----|-------|------|
| M1 | اتّساق النطاق | استدلالي |
| M2 | عزل داخلي للخطة (CM-7) | آلي |
| M3 | الامتثال للمعايير | استدلالي |
| M4 | صلاحية الـ<bdi>frontmatter</bdi> | آلي |
| M5 | لا عبارات محظورة | آلي |
| M6 | الإفصاح التحريري | استدلالي |
| M7 | لا إشارات للخطة في المُنتَجات | آلي |
| M8 | وجود ترويسة التأليف | آلي |
| M9 | تقييم صادق | استدلالي |
| M10 | انضباط التسمية | آلي |
| M11 | جهاز السبرنت | استدلالي |
| M12 | التخطيط القانوني | آلي |
| M13 | حِرفة الشيفرة | استدلالي |
| M14 | المشاركة المنظومية | استدلالي |
| M15 | التأليف البشري | آلي |

## فحوصات موجَّهة

```bash
# تشغيل فحص واحد
python -m apothem.conformity.gate --check multi-surface-coherence

# التشغيل على ملف محدَّد
python -m apothem.conformity.gate src/apothem/rules/my-rule.md
```

## التكامل مع <bdi>CI</bdi>

تعمل البوابة في الـ<bdi>CI</bdi> عبر <bdi>`.github/workflows/conformity.yml`</bdi>
عند كلّ دفعة <bdi>push</bdi>.
