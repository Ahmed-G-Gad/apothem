تُشغِّل بوابة المطابقة في <bdi>`src/apothem/conformity/gate.py`</bdi> الجزء الميكانيكي
من بوابة ما قبل الإصدار ذات الخمسة عشر شريطًا (<bdi>M1-M15</bdi>) على كل مُنتَج
يؤلّفه المُشغِّل.

تفترض الأوامر في هذه الصفحة وجود نسخة مسحوبة من <bdi>Apothem</bdi>، لذا ابدأ كلًّا منها بـ <bdi>`PYTHONPATH=src`</bdi>. وبعد التثبيت عبر النص البرمجي، استخدم <bdi>`PYTHONPATH="$HOME/.apothem/src"`</bdi> بدلًا من <bdi>`src`</bdi>.

## تشغيل البوابة

البوابة **استشارية افتراضيًا**: تُبلِغ عن النتائج وتخرج بالرمز <bdi>`0`</bdi>، لذا لا
يحجبك التشغيل المحلّي أبدًا. أضِف <bdi>`--strict`</bdi> (أو اضبط
<bdi>`APOTHEM_CONFORMITY_STRICT=1`</bdi>) للخروج برمز غير صفري عند وجود نتيجة حاجبة —
وهو الوضع الذي يستخدمه <bdi>CI</bdi> و<bdi>pre-commit</bdi> لإفشال تغيير مخالف.

```bash
# Advisory: report every validator's findings across the repo, exit 0
PYTHONPATH=src python -m apothem.conformity.gate --all .

# Strict: exit non-zero (code 2) when a blocking finding is present
PYTHONPATH=src python -m apothem.conformity.gate --all --strict .
```

رموز الخروج: <bdi>`0`</bdi> نظيف (أو استشاري)، و<bdi>`2`</bdi> حجب بسبب نتائج في الوضع
الصارم، و<bdi>`3`</bdi> خطأ في الاستخدام: راية أو اسم أداة تحقّق غير معروف، أو ملف
غير موجود، أو دليل جذر غير موجود. يطبع <bdi>`--help`</bdi> الاستخدام الكامل ويخرج
بالرمز <bdi>`0`</bdi>. وتقبل كل أداة تحقّق مستقلّة الراية <bdi>`--help`</bdi> نفسها
وتخرج بالرمز <bdi>`3`</bdi> عند راية غير معروفة أو جذر مفقود.

يُحَلّ الجذر النسبي مثل <bdi>`.`</bdi> إلى مسار مطلق قبل تشغيل أي أداة تحقّق، لذا
يفحص <bdi>`--all .`</bdi> و<bdi>`--all "$PWD"`</bdi> الشجرة نفسها. تُبلِغ كل أداة
تحقّق عن <bdi>`inspected`</bdi> — أي عدد الأهداف التي فحصتها — وينسخ
<bdi>`--all`</bdi> ذلك العدد إلى كل مُدخَل في النتائج. وأداة التحقّق التي لم تفحص شيئًا
تُبلِغ عن <bdi>`passed: false`</bdi>، لذا لا يمكن أن يجتاز دليل عمل خاطئ بصمت.
أداتا التحقّق الخاصتان بحزم الخطط هما الاستثناء: تعيش حزم الخطط في الشجرة
<bdi>`.apothem/plans/`</bdi> التي يتجاهلها <bdi>git</bdi>، لذا تُبلِغان عن
<bdi>`empty_scope_expected: true`</bdi> على نسخة مسحوبة نظيفة وتجتازان مع ذلك. وتفعل
أدوات التحقّق الخاصة بسير العمل الشيء نفسه عندما لا يكون للمشروع دليل
<bdi>`.github/workflows/`</bdi> بعد، وكذلك تفعل أداة التحقّق من عنوان الكوميت عندما لا
يكون للدليل سجلّ كوميتات.

## فحوص موجَّهة

```bash
# List every registered validator
PYTHONPATH=src python -m apothem.conformity.gate --list

# Run a single named validator
PYTHONPATH=src python -m apothem.conformity.gate --check multi-surface-coherence

# Run every validator against one file
PYTHONPATH=src python -m apothem.conformity.gate src/apothem/rules/my-rule.md
```

وضع <bdi>`--hook`</bdi> (<bdi>`python -m apothem.conformity.gate --hook`</bdi>) هو نقطة
الدخول التي يستدعيها إطار العمل: يقرأ حمولة <bdi>JSON</bdi> لمُدخَلات الأداة من
<bdi>stdin</bdi> ويُشغِّل سلسلة المطابِقات الخاصة بكل عملية كتابة على عملية الكتابة
المعلّقة. هذا هو الشكل الذي يستدعيه خطّاف <bdi>`PreToolUse`</bdi> المنشور؛ ونادرًا ما
تستدعيه يدويًا.

وضع الخطّاف **مقصور على مجموعة من الأدلة**. لا يُشغِّل سلسلة المطابِقات إلا على عمليات
الكتابة التي يقع هدفها تحت أحدها؛ وعملية الكتابة الواقعة خارج كل النطاقات تنتهي فورًا
باجتياز صامت. القيم الافتراضية هي جذور أُطُر العمل على نطاق المستخدم القادرة على
الخطّافات التي يثبّت <bdi>Apothem</bdi> فيها — وتُسمّي صفحة كل إطار عمل تحت قسم
«أُطُر العمل» جذرَه الخاص. اضبط <bdi>`APOTHEM_CONFORMITY_SCOPE`</bdi> على دليل
لاستبدالها:

```bash
# Run the per-write matcher chain against one project tree instead
export APOTHEM_CONFORMITY_SCOPE=/path/to/project
```

الخطّاف الذي يبدو أنه لا يفعل شيئًا يكون عادةً حالة خروج عن النطاق لا إخفاقًا — افحص
هدف عملية الكتابة مقابل النطاقات أعلاه أولًا.

## التكامل مع <bdi>CI</bdi>

تُشغِّل مهمّة الجودة في <bdi>`.github/workflows/ci.yml`</bdi> البوابة في الوضع الصارم (<bdi>`python -m apothem.conformity.gate --all . --strict`</bdi>) عند الدفع إلى <bdi>`main`</bdi>، وعند طلبات الدمج إلى <bdi>`main`</bdi> التي تمسّ المسارات التي تراقبها تلك المهمّة. أما سير العمل المنفصل <bdi>`.github/workflows/conformity.yml`</bdi> فيُشغِّل مسح التركيبات الاختبارية (<bdi>`tests/conformity-scenarios/verify.py --strict`</bdi>).
