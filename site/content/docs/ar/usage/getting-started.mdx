يوفّر <bdi>Apothem</bdi> أربع قدرات أساسية: ملفًا تعريفيًا مشتركًا للحوكمة، ومدوّنة
قواعد، وخط أنابيب تخطيط مُهيكَل، وبوابة مطابقة في الوقت الفعلي.

<Callout title="هل أنت جديد هنا؟">
  للحصول على جولة إرشادية من الصفر حتى أول تشغيل، ابدأ من
  [درس البدء التعليمي](/docs/tutorials/getting-started). هذه الصفحة مرجع سريع لسير
  العمل الأساسية الأربعة بعد أن تنتهي من الإعداد.
</Callout>

## الملف التعريفي المشترك

يقع ملف <bdi>Apothem</bdi> التعريفي الخاص بك في
<bdi>`~/.config/apothem/profile.yaml`</bdi> ما لم تمرّر <bdi>`--profile PATH`</bdi>.
وهو مصدر الحقيقة الوحيد الذي يشتقّ منه كل محوّل خاص بإطار عمل إعداده الأصلي:

```yaml
identity:
  name: "Example User"
preferences:
  style: "concise"
rules:
  - "Validate external input before writing files."
```

أنشئ الملف التعريفي إن لم يكن موجودًا بعد، ثم افحصه. تكتب المُثبِّتات بخطوة واحدة
والأمر <bdi>`apothem install`</bdi> ملفًا تعريفيًا مبدئيًا في أول تشغيل، ويتوقّف
<bdi>`profile init`</bdi> بخطأ ويترك الملف الموجود دون تغيير ما لم تمرّر
<bdi>`--force`</bdi>.

```bash
apothem profile init
apothem profile show --json
```

## القاعدة الأولى

أضِف قواعد مشتركة إلى ملف <bdi>YAML</bdi> الخاص بالملف التعريفي، ثم أعِد تجسيد
إطار العمل المختار. وعندما تتضمّن تلك القواعد بيانات أمثلة، استخدم قيمًا نائبة
وهمية حتى لا تصل أي هوية أو بيانات اعتماد حقيقية إلى ملف تعريفي مشترك أو إلى تشغيل
<bdi>CI</bdi>.

```bash
apothem profile set rules '["Always include a brief summary at the end of every response."]'
apothem update --harness claude-code
apothem verify --harness claude-code
```

## الخطة الأولى

يعمل خط أنابيب <bdi>`/plan`</bdi> داخل إطار العمل الخاص بك بوصفه أوامر الشرطة
المائلة، لا عبر الملف التنفيذي <bdi>`apothem`</bdi>. بمجرد تثبيت إطار عمل، ابدأ
خطة من محادثة الأداة:

```text
/plan-spec
```

يصقل <bdi>`/plan-spec`</bdi> نصّك الحرّ إلى مواصفة، ويجسّد
<bdi>`/plan-generate`</bdi> حزمة خطّة ضمن
<bdi>`<project-root>/.apothem/plans/{suite}/`</bdi>. راجع
[مرجع أوامر خط الأنابيب](/docs/pipeline) للاطّلاع على التدفق الكامل.

## بوابة المطابقة

من نسخة مسحوبة من <bdi>Apothem</bdi>، شغّل:

```bash
PYTHONPATH=src python -m apothem.conformity.gate --all .
```

بعد التثبيت بالسكربت، شغّل:

```bash
PYTHONPATH="$HOME/.apothem/src" python3 -m apothem.conformity.gate --all .
```

يُشغِّل جميع فحوص المطابقة الميكانيكية ويُبلِغ عن النجاح/الفشل لكل شريط.
