Worked, end-to-end walkthroughs. Each example takes a single task from a blank
start to a finished artifact, showing the commands, the files, and the
reasoning at each step.

The runnable example projects that ship with the repository live in the
repo-root [`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples)
directory; the pages below are the narrated guides that walk through them.

## Pages

| Page | Description |
|------|-------------|
| [Authoring a harness adapter](/docs/examples/authoring-a-harness-adapter) | Step-by-step guide to building a new harness adapter from scratch. |
| [Minimal hook](/docs/examples/minimal-hook) | The smallest possible Apothem hook — a PreToolUse check that fires on every file write. |
| [Custom rule](/docs/examples/custom-rule) | Authoring a project-specific always-on rule that enforces a naming convention. |
| [Plan walkthrough](/docs/examples/plan-walkthrough) | An end-to-end walkthrough of the `/plan` pipeline for a real task. |
