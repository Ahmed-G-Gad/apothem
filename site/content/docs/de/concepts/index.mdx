Apothem basiert auf einer Handvoll Design-Ideen. Dieser Abschnitt erläutert sie —
warum Governance plattformagnostisch ist, wie der Harness-Kollaborator gerahmt wird,
was die Audit-Review-Sequenz garantiert und wie sich der Governance-Aufwand an das
Engagement anpasst.
