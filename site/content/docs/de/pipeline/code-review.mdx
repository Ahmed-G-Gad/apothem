**Rolle:** Prüfer
**Pipeline-Position:** Festung

Operatorgesteuerter Code-Qualitäts-Review-Durchlauf pro Datei über src/, scripts/ und tools/.

## Kanonischer Aufruf

```bash
/code-review
```

Mit Argumenten:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Eingaben

Host-Repository in einem beliebigen Lebenszyklus-Zustand

## Ausgaben

Befunde pro Datei unter `_inputs/code-review-findings.md`

## Nachgelagert

Die Zeile-für-Zeile-Review-Stufe der Audit-Review-Sequenz

## Workflow-Phasen

Der Befehl durchläuft fünf Phasen: Eingabeaufnahme, Durchlauf pro Datei, Triage je Befund, Ausgabe der Befunde und das Validierungs-Gate.

## Fehlermodi

| Symptom | Ursache | Behebung |
|---------|-------|----------|
| Qualitätstor FAIL | Die Ausgabe erfüllt die Standards nicht | Behebe die Ausgabe und führe erneut aus |
| Fehlende Eingabedatei | Das Repository enthält keines der Verzeichnisse `src/`, `scripts/` oder `tools/` | Übergib ein Repository-Wurzelverzeichnis, das mindestens eines davon enthält |

## Beispiele

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
