**Rolle:** Barrierefreiheits-Prüfer
**Pipeline-Position:** Festung

Barrierefreiheits-Audit gegen WCAG 2.2 AA für jede gerenderte Seite.

## Kanonischer Aufruf

```bash
/a11y-audit
```

Mit Argumenten:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## Eingaben

Bereitgestellte oder lokal ausgelieferte Projekt-Website

## Ausgaben

Barrierefreiheits-Befunde unter `_inputs/a11y-audit-findings.md`

## Nachgelagert

Die Barrierefreiheits-Prüfungsstufe der Audit-Review-Sequenz

## Workflow-Phasen

Der Befehl durchläuft fünf Audit-Phasen: Eingabeaufnahme, Audit je Seite, Triage je
Befund, Ausgabe der Befunde und das Validierungs-Gate.

## Fehlermodi

| Symptom | Ursache | Behebung |
|---------|-------|----------|
| Qualitätstor FAIL | Die Ausgabe erfüllt die Standards nicht | Behebe die Ausgabe und führe erneut aus |
| Fehlende Eingabedatei | Pfad zur Website oder URL wird nicht aufgelöst | Übergib ein gebautes Website-Verzeichnis oder eine erreichbare URL |

## Beispiele

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
