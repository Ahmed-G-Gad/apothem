**Rolle:** Architektur-Prüfer
**Pipeline-Position:** Festung

Architektur-Integritätsprüfung gegen das Design-Artefakt in `_inputs/design.md`.

## Kanonischer Aufruf

```bash
/architecture-review
```

Mit Argumenten:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Eingaben

Host-Repository + `_inputs/design.md`

## Ausgaben

Architektur-Befunde unter `_inputs/architecture-review-findings.md`

## Nachgelagert

Die Architektur-Prüfungsstufe der Audit-Prüfsequenz

## Workflow-Phasen

Der Befehl durchläuft fünf Audit-Phasen: Eingabeaufnahme, Rückverfolgung von Design
zu Code, Audit der Integrität der Schichtgrenzen, Sweep der Kopplung zwischen
Paketen sowie Ausgabe der Befunde mit dem Validierungs-Gate.

## Fehlermodi

| Symptom | Ursache | Behebung |
|---------|-------|----------|
| Qualitätstor FAIL | Die Ausgabe erfüllt die Standards nicht | Behebe die Ausgabe und führe erneut aus |
| Fehlende Eingabedatei | Designartefakt `_inputs/design.md` fehlt | Führe `/plan-design` aus, um es zu erstellen |

## Beispiele

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
