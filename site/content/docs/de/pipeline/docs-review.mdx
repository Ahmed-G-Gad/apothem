**Rolle:** Dokumentationsprüfer
**Pipeline-Position:** Festung

Dokumentations-Review-Durchlauf gegen die Prosakonventionen und die Qualitätsstandards der zehn Dimensionen.

## Kanonischer Aufruf

```bash
/docs-review
```

Mit Argumenten:

```bash
/docs-review [path/to/repo/ or path/to/docs-source/] [--focus FILE_OR_DIR] [--dry-run]
```

## Eingaben

Dokumentationsfläche des Host-Repositorys

## Ausgaben

Dokumentationsbefunde unter `_inputs/docs-review-findings.md`

## Nachgelagert

Die Dokumentations-Review-Stufe der Audit-Prüfsequenz

## Workflow-Phasen

Der Befehl durchläuft fünf Phasen: Eingabeaufnahme, Durchlauf pro Seite, Triage je Befund, Ausgabe der Befunde und das Validierungs-Gate.

## Fehlermodi

| Symptom | Ursache | Behebung |
|---------|-------|----------|
| Qualitätstor FAIL | Die Ausgabe erfüllt die Standards nicht | Behebe die Ausgabe und führe erneut aus |
| Fehlende Eingabedatei | Unter dem Pfad sind keine Dokumentationsdateien erreichbar | Übergib ein Repository-Wurzelverzeichnis oder ein Verzeichnis mit Dokumentationsquellen, das Markdown-Seiten enthält |

## Beispiele

```bash
# Dry-run to preview what would happen
/docs-review --dry-run

# Execute against a repository root
/docs-review path/to/repo/
```
