Referenz pro Artefaktklasse. Jede Seite beschreibt den Zweck der Klasse, ihr Plattenlayout, den Frontmatter-Vertrag und die Registry, die jede Instanz auflistet.

Unten werden repository-relative Pfade gezeigt; jeder Adapter materialisiert sie in sein natives Konfigurationsverzeichnis (z. B. `~/.claude/` für den Claude Code Adapter — siehe [`site/content/docs/harnesses/<harness>.mdx`](/docs/harnesses) für die jeweiligen Harness-Ziele).

Die vollständige kanonische Registry erstreckt sich über die Artefaktkohorten (`rules/`, `commands/`, `skills/`, `agents/`, `hooks/`). Diese Seite spiegelt diese Registry in navigierbarer Form wider.
