## Schweregradleiter

| Schweregrad | Wirkung auf das Gate |
|---|---|
| **Kritisch** | Gate FAIL — Ausgabe bedingungslos blockiert |
| **Wichtig** | Gate FAIL, wenn 2+ wichtige Stufen gleichzeitig nicht bestanden werden |
| **Beratend** | Gate WARN — im signierten Eintrag protokolliert; blockiert die Ausgabe nicht |

Die meisten Matcher des mechanischen Anteils sind standardmäßig **Wichtig**. M5 (Autorität — Geheimnisse, erfundene Endpunkte) und M12 (verwaiste Ausgaben) sind **Kritisch**.

## Validatoren

Der mechanische Anteil liegt unter [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity) und wird von [`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py) orchestriert.
Das Gate führt jeden Validator auf eine von drei Arten aus:

- **per-write**: bei jedem anstehenden Schreibvorgang (`--hook`) oder mit `--all-perwrite` für jede versionierte Datei.
- **standalone**: mit `--all` über das gesamte Repository oder mit `--check <name>` einzeln.
- **change-set**: gegen einen gestagten Diff, außerhalb der Durchläufe des Gates.

## Das Gate ausführen

Auf einem installierten Harness läuft das Gate automatisch: Die `settings.json`
von Claude Code bindet es als `PreToolUse`-Hook ein, der vor jedem Write/Edit die
materialisierte Kopie unter `~/.claude/.apothem/support/conformity/gate.py`
aufruft. Aus einem Quell-Checkout treibt die Modulform denselben Code an. Das
Gate ist standardmäßig beratend: Es meldet Befunde und endet mit `0`. Fügen Sie
`--strict` hinzu, damit es bei einem blockierenden Befund mit `2` endet. Ein
unbekannter Validator-Name endet mit `3`.

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help` gibt die Nutzungsübersicht aus.
Das vollständige Verfahren finden Sie unter [Das Konformitäts-Gate ausführen](/docs/usage/conformity-gate).
