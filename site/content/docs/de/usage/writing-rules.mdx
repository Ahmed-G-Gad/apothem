Regeln sind Markdown-Dateien in `src/apothem/rules/` mit der Endung `.md`.

## Regel-Frontmatter

```yaml
---
name: "..."
description: "..."
pathFilter: ""            # empty string for always-on; a glob for path-filtered
alwaysApply: true         # true for always-on; false for path-filtered
---
```

## Regel-Geltungsbereiche

| Geltungsbereich | Wann angewendet |
|-------|-------------|
| `always-on` | Jede Sitzung, jede Datei |
| `path-filtered` | Nur wenn die aktive Datei `path-filter` entspricht |
| `operator-selected` | Der Operator aktiviert sie ausdrücklich in settings.json |

## Beispielregel

```markdown
---
name: "python-conventions"
description: "Python style conventions for this project"
pathFilter: "**/*.py"
alwaysApply: false
---

# Python conventions

- Use type annotations on all public functions.
- Maximum line length: 88 characters.
- Prefer explicit over implicit.
```

## Regeln auf Harnesses anwenden

Nachdem du eine Regel geschrieben hast, aktualisiere jeden installierten
Harness-Adapter. Führe `apothem harnesses list` aus, um den installierten Satz
zu sehen, und rufe dann update einmal pro Harness auf:

```bash
apothem update --harness claude-code
apothem update --harness cursor
```

## Regelvalidierung

```bash
python -m apothem.conformity.gate --check frontmatter
```
