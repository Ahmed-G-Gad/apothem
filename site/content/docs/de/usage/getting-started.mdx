Apothem bietet vier Kernfähigkeiten: ein gemeinsames Governance-Profil, einen
Regelkorpus, eine strukturierte Planungs-Pipeline und ein Konformitäts-Gate in
Echtzeit.

<Callout title="Neu hier?">
  Für eine geführte Tour von null bis zum ersten Lauf beginnen Sie mit dem
  [Erste-Schritte-Tutorial](/docs/tutorials/getting-started). Diese Seite ist
  eine Schnellreferenz zu den vier Kern-Workflows, sobald Sie eingerichtet sind.
</Callout>

## Das gemeinsame Profil

Ihr Apothem-Profil liegt unter `~/.config/apothem/profile.yaml`, sofern Sie
nicht `--profile PATH` übergeben. Es ist die einzige Quelle der Wahrheit, aus der
jeder Harness-Adapter seine native Konfiguration ableitet:

```yaml
identity:
  name: "Example User"
preferences:
  style: "concise"
rules:
  - "Validate external input before writing files."
```

Erstellen Sie das Profil, falls es noch nicht existiert, und prüfen Sie es dann.
Die Ein-Schritt-Installer und `apothem install` schreiben bei einem ersten Lauf
bereits ein Starter-Profil, und `profile init` bricht mit einem Fehler ab und
lässt eine bestehende Datei unverändert, sofern Sie nicht `--force` übergeben.

```bash
apothem profile init
apothem profile show --json
```

## Erste Regel

Fügen Sie dem Profil-YAML gemeinsame Regeln hinzu und materialisieren Sie
anschließend den ausgewählten Harness neu. Enthalten diese Regeln Beispieldaten,
verwenden Sie fiktive Platzhalter, damit keine echte Identität und keine echten
Anmeldedaten in einem geteilten Profil oder einem CI-Lauf landen.

```bash
apothem profile set rules '["Always include a brief summary at the end of every response."]'
apothem update --harness claude-code
apothem verify --harness claude-code
```

## Erster Plan

Die `/plan`-Pipeline läuft innerhalb Ihres Harness als
Slash-Befehle, nicht über die `apothem`-Binärdatei. Sobald ein Harness
installiert ist, starten Sie einen Plan aus dem Chat des Werkzeugs:

```text
/plan-spec
```

`/plan-spec` verfeinert Ihren Fließtext zu einer Spezifikation, und
`/plan-generate` materialisiert eine Plan-Suite unter
`<project-root>/.apothem/plans/{suite}/`. Den vollständigen Ablauf finden Sie in
der [Pipeline-Befehlsreferenz](/docs/pipeline).

## Konformitäts-Gate

Führen Sie von einem Apothem-Checkout aus Folgendes aus:

```bash
PYTHONPATH=src python -m apothem.conformity.gate --all .
```

Nach einer Skript-Installation führen Sie Folgendes aus:

```bash
PYTHONPATH="$HOME/.apothem/src" python3 -m apothem.conformity.gate --all .
```

Führt alle mechanischen Konformitätsprüfungen aus und meldet bestanden/nicht
bestanden pro Stufe.
