**Anbieter:** Open-Claw
**Installationsname:** `open-claw`
**Status:** Vorschau
**Native Konfiguration:** `~/.openclaw/openclaw.json`

## Installation

```bash
apothem install --harness open-claw
```

Der Adapter übersetzt das gemeinsame Profil in die benutzerglobale
Konfigurationsdatei von OpenClaw und installiert Apothem-Unterstützungs-Kohorten
unter dem Stammverzeichnis des Harness. Die native Konfiguration von OpenClaw ist
JSON; der Materializer rendert passend dazu JSON.

**Geschriebene Dateien:** `~/.openclaw/openclaw.json`, das Profildokument
`~/.openclaw/apothem/rules/00-apothem-profile.md` und Unterstützungsdateien unter
`~/.openclaw/.apothem/support/`

Das Profildokument endet mit einem Abschnitt zu den Apothem-Unterstützungsdateien,
der das absolute Verzeichnis unter `~/.openclaw/.apothem/support/` nennt, gegen
das jedes Zitat im Repository-Stil (`rules/<name>.md`, `templates/...`,
`hooks/...`) aufgelöst wird.

## Zuordnung von Profil zu nativer Konfiguration

Der Adapter liest Apothems gemeinsames Profil, verfasst aber keine
Konfigurationsschlüssel: `openclaw.json` wird als leeres Objekt geschrieben.
Identität, Präferenzen und Regeln des Profils gehen in das Profildokument.
Gemeinsame Commands, Skills, Regeln, Templates und Hook-Prompts werden als
Unterstützungsmaterial unter `~/.openclaw/.apothem/support/` installiert.

## Kompatibilitätshinweise

Vorschau-Adapter. OpenClaw lädt den Unterstützungsbaum und das Profildokument
nicht von sich aus: Weder seine Skill-Speicherorte noch seine
Workspace-Anweisungsdateien noch seine Konfiguration verweisen dorthin, sodass
OpenClaw nach der Installation ohne Apothems Regeln, Skills oder MCP-Server
läuft. OpenClaw liest Skills aus den Ordnern `skills/` und `.agents/skills/`
seines Workspace, aus `~/.agents/skills`, aus seinem Zustandsverzeichnis und aus
jedem in `skills.load.extraDirs` aufgeführten Ordner; um die Apothem-Skills zu
verwenden, fügen Sie `~/.openclaw/.apothem/support/skills` selbst zu dieser
Liste hinzu; `apothem update` behält Schlüssel bei, die Sie zu `openclaw.json`
hinzufügen. MCP-Server liegen im Block `mcp.servers` der OpenClaw-Konfiguration,
den Sie mit `openclaw mcp add` und den zugehörigen Unterbefehlen verwalten; der
Adapter schreibt dort keine Einträge. (Verhalten von OpenClaw gemäß seiner
Dokumentation zu [Skills](https://docs.openclaw.ai/tools/skills) und zur
[MCP-CLI](https://docs.openclaw.ai/cli/mcp), gelesen am 2026-10-02.)

## Verifizierung

```bash
apothem verify --harness open-claw
```

Der verify-Befehl bestätigt, dass:

1. Die native Konfiguration liegt am erwarteten Pfad.
2. Jedes verwaltete Ziel existiert; verwaltete Dateien sind nicht leer, und JSON- oder YAML-Konfigurationen lassen sich parsen. Fügen Sie `--profile PATH` hinzu, um außerdem zu bestätigen, dass die installierten Dateien zu diesem Profil passen.
3. Die adapterspezifische Verifizierungsroutine meldet Erfolg.

## Aktualisierung

```bash
apothem update --harness open-claw
```

Leitet die native Konfiguration aus dem aktuellen Zustand des gemeinsamen Profils
neu ab. Führen Sie dies aus, nachdem Sie `~/.config/apothem/profile.yaml`
bearbeitet oder das installierte Apothem-Paket aktualisiert haben.

## Deinstallation

```bash
apothem uninstall --harness open-claw
```

Entfernt die vom Adapter geschriebenen nativen Konfigurationsdateien.
Das YAML des gemeinsamen Profils und die Apothem-Engine bleiben unberührt.

## Konformitäts-Gate

```bash
python -m apothem.conformity.gate --all .
```

## Fehlerbehebung

| Symptom | Behebung |
|---------|-----|
| Konfigurationsdatei nicht gefunden | Führen Sie `apothem install --harness open-claw` erneut aus |
| Verifizierung fehlgeschlagen | Führen Sie `apothem update --harness open-claw` aus und verifizieren Sie dann erneut |
| Unerwarteter Konfigurationsinhalt | Prüfen Sie `~/.config/apothem/profile.yaml` oder `--profile PATH` und führen Sie dann `apothem update --harness open-claw` erneut aus |

## Konfigurationsschalter

| Flag | Standard | Beschreibung |
|------|---------|-------------|
| `--dry-run` | `false` | Installation in der Vorschau anzeigen, ohne Dateien zu schreiben. |
