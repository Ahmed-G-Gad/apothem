**Anbieter:** Alibaba Cloud
**Installationsname:** `qwen-code`
**Status:** Beta
**Native Konfiguration:** `~/.qwen/`

## Installation

```bash
apothem install --harness qwen-code
```

Der Adapter schreibt die Einstellungen von Qwen Code, installiert einen
`QWEN.md`-Kontextanker, registriert Apothem-Hook-Dispatcher, konvertiert
Apothem-Commands in Markdown-Command-Dateien von Qwen, installiert Skills als
SKILL.md-Verzeichnisse und passt Helferdefinitionen als Qwen-Subagenten an.

**Geschriebene Dateien:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/apothem/rules/00-apothem-profile.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

Die Datei `~/.qwen/apothem/rules/00-apothem-profile.md` ist das Profildokument.
Es trägt Ihre Identität und Ihre Präferenzen aus dem gemeinsamen Profil.

## Zuordnung von Profil zu nativer Konfiguration

Der Adapter rendert dokumentierte `settings.json`-Schlüssel für Kontext und
Hooks, schreibt `QWEN.md` und verteilt Apothem-Commands, -Skills und
Helferdefinitionen über die nativen Discovery-Verzeichnisse von Qwen Code.
Regeln, Templates und Hook-Quellmaterial bleiben Unterstützungsmaterial unter
`~/.qwen/.apothem/support/`.

## Kompatibilitätshinweise

`~/.qwen/.apothem/support/` ist Unterstützungsmaterial, auf das `QWEN.md` und
die Hook-Befehle in den Einstellungen verweisen; es ist kein anbietereigener
Discovery-Namensraum.
Der Apothem-Block in `QWEN.md` endet mit einem Abschnitt zu den
Apothem-Unterstützungsdateien, der das absolute Verzeichnis unter
`~/.qwen/.apothem/support/` nennt, gegen das jeder Verweis im Repository-Stil
(`rules/<name>.md`, `templates/...`, `hooks/...`) aufgelöst wird.

## Verifizierung

```bash
apothem verify --harness qwen-code
```

Der Befehl verify bestätigt Folgendes:

1. Die native Konfiguration existiert am erwarteten Pfad.
2. Jedes verwaltete Ziel existiert; verwaltete Dateien sind nicht leer, und
   JSON- oder YAML-Konfigurationen lassen sich parsen. Fügen Sie `--profile PATH`
   hinzu, um außerdem zu bestätigen, dass die installierten Dateien zu diesem
   Profil passen.
3. Die adapterspezifische Verifizierungsroutine meldet Erfolg.

## Aktualisierung

```bash
apothem update --harness qwen-code
```

Aktualisiert `settings.json`, `QWEN.md`, native Commands, Skills, Subagenten und
den Apothem-Unterstützungs-Teilbaum.

## Deinstallation

```bash
apothem uninstall --harness qwen-code
```

Entfernt die Einträge, die der Adapter zu `~/.qwen/settings.json` hinzugefügt
hat (Ihre eigenen Schlüssel, MCP-Server und Hook-Handler bleiben erhalten, und
die Datei wird nur gelöscht, wenn Apothem sie angelegt hat und nichts von Ihnen
übrig ist). Entfernt den Apothem-Block aus `~/.qwen/QWEN.md` und aus dem
Profildokument `~/.qwen/apothem/rules/00-apothem-profile.md` und behält jeden
anderen Text darin; jede dieser Dateien wird nur gelöscht, wenn darin nichts
anderes mehr übrig ist. Entfernt außerdem die Apothem-Dateien in
`~/.qwen/commands/`, `~/.qwen/skills/`, `~/.qwen/agents/` und
`~/.qwen/.apothem/support/`; andere Dateien in diesen Ordnern bleiben bestehen.
Jede Datei wird unter `~/.apothem/backups/` gesichert, bevor sie geändert oder
entfernt wird. Die YAML-Datei des gemeinsamen Profils und die Apothem-Engine
bleiben unberührt.

## Konformitäts-Gate

```bash
python -m apothem.conformity.gate --all .
```

## Fehlerbehebung

| Symptom | Behebung |
|---------|-----|
| Konfigurationsdatei nicht gefunden | Führen Sie `apothem install --harness qwen-code` erneut aus |
| Verifizierung fehlgeschlagen | Führen Sie `apothem update --harness qwen-code` aus und verifizieren Sie dann erneut |
| Unerwarteter Konfigurationsinhalt | Prüfen Sie `~/.config/apothem/profile.yaml` oder `--profile PATH` und führen Sie dann `apothem update --harness qwen-code` erneut aus |

## Konfigurationsschalter

| Flag | Standard | Beschreibung |
|------|---------|-------------|
| `--dry-run` | `false` | Vorschau der Installation, ohne Dateien zu schreiben. |
