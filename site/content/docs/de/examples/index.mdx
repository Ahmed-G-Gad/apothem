Durchgearbeitete End-to-End-Anleitungen. Jedes Beispiel führt eine einzelne
Aufgabe von einem leeren Start zu einem fertigen Artefakt und zeigt die Befehle,
die Dateien und die Überlegungen bei jedem Schritt.

Die mit dem Repository ausgelieferten lauffähigen Beispielprojekte liegen im
Verzeichnis
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) im
Repository-Stammverzeichnis; die nachfolgenden Seiten sind die erzählten
Leitfäden, die durch sie hindurchführen.

## Seiten

| Seite | Beschreibung |
|------|-------------|
| [Einen Harness-Adapter erstellen](/docs/examples/authoring-a-harness-adapter) | Schritt-für-Schritt-Anleitung zum Aufbau eines neuen Harness-Adapters von Grund auf. |
| [Minimaler Hook](/docs/examples/minimal-hook) | Der kleinstmögliche Apothem-Hook — eine PreToolUse-Prüfung, die bei jedem Dateischreiben auslöst. |
| [Eigene Regel](/docs/examples/custom-rule) | Eine projektspezifische, dauerhaft aktive Regel erstellen, die eine Benennungskonvention durchsetzt. |
| [Plan-Durchlauf](/docs/examples/plan-walkthrough) | Ein End-to-End-Durchlauf der `/plan`-Pipeline für eine echte Aufgabe. |
