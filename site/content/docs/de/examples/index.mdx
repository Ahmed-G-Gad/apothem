Ausgearbeitete End-to-End-Durchgänge. Jedes Beispiel führt eine einzelne
Aufgabe von einem leeren Anfang bis zu einem fertigen Artefakt und zeigt bei
jedem Schritt die Befehle, die Dateien und die Überlegungen.

Die lauffähigen Beispielprojekte, die mit dem Repository ausgeliefert werden,
liegen im Verzeichnis
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) im
Stammverzeichnis des Repositorys. Jedes ist in sich abgeschlossen und hat
seine eigene README. Die Seiten unten sind eigenständige ausgearbeitete
Durchgänge; sie erzählen diese Projekte nicht nach.

## Seiten

| Seite | Beschreibung |
|------|-------------|
| [Einen Harness-Adapter erstellen](/docs/examples/authoring-a-harness-adapter) | Schritt-für-Schritt-Anleitung zum Aufbau eines neuen Harness-Adapters von Grund auf. |
| [Minimaler Hook](/docs/examples/minimal-hook) | Der kleinstmögliche Apothem-Hook — eine PreToolUse-Prüfung, die bei jedem Schreiben einer Datei auslöst. |
| [Eigene Regel](/docs/examples/custom-rule) | Eine projektspezifische, stets aktive Regel verfassen, die eine Benennungskonvention durchsetzt. |
| [Plan-Durchlauf](/docs/examples/plan-walkthrough) | Ein End-to-End-Durchgang durch die `/plan`-Pipeline für eine reale Aufgabe. |
