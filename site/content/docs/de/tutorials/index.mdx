Tutorials sind geführte, durchgängige Lektionen. Sie folgen jeder von Anfang bis
Ende, und am Schluss haben Sie etwas Echtes, das auf Ihrer Maschine läuft. Sie
setzen kein Vorwissen über Apothem voraus und erklären jeden Schritt im Verlauf.

Wenn Sie bereits wissen, was Sie wollen, und nur den genauen Befehl brauchen, sind
die [Anleitungen](/docs/how-to) und die [Referenz](/docs/harnesses) der
schnellere Weg.

## Hier beginnen

- [Erste Schritte](/docs/tutorials/getting-started) — installieren Sie Apothem,
  schreiben Sie ein geteiltes Profil, materialisieren Sie die native Konfiguration
  eines Harness und verifizieren Sie sie. Etwa fünfzehn Minuten von einer leeren
  Maschine bis zu einem funktionierenden ersten Lauf.
