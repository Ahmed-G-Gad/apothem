Antigravity ist ein Harness der Klasse I mit Manifest-Propagation: Apothem schreibt den globalen Kontextanker `~/.gemini/GEMINI.md` und installiert ein Apothem-Plugin unter `~/.gemini/antigravity-cli/plugins/apothem/`. Diese Seite stellt das Pflegen dieses Layouts von Hand der Verwaltung mit Apothem gegenüber.

## Status

**Vorschau.** Der Antigravity-Adapter zielt auf den aktuell dokumentierten Kontextanker `GEMINI.md` und die Plugin-Oberfläche der Antigravity-CLI. Kohorten ohne native Oberfläche bleiben Apothem-Unterstützungsmaterial.

## Aufwandsvergleich

| Aufgabe | Manuelle Konfiguration | Von Apothem verwaltet |
| ---- | --------------- | --------------- |
| Regeln schreiben | Jede Plugin-Regeldatei von Hand schreiben | Einmal im gemeinsamen Korpus schreiben |
| Wiederverwendbare Prompts bewahren | Befehlsprompts und Skills von Hand in Plugin-Dateien kopieren | In Plugin-Skills konvertiert oder kopiert |
| Hook-Unterstützungsmaterial bewahren | Hook-Referenzen ohne aktive Verdrahtung von Hand kopieren | Unter dem Apothem-Plugin-Unterstützungs-Teilbaum kopiert |
| Regeln über andere Harnesses hinweg abgestimmt halten | Manuell, pro Werkzeug | Automatisch bei `apothem update` |
| Konfiguration installieren / entfernen | Dateien von Hand kopieren und löschen | `apothem install` / `apothem uninstall` |
| Prüfen, ob die Konfiguration korrekt ist | Manuelle Inspektion | `apothem verify --harness antigravity` |

## Was Apothem verwaltet

Apothem verwaltet die globale Kontextdatei von Antigravity, die Plugin-Metadaten, die konvertierten Befehls-Skills, die wiederverwendbaren Skills, die konvertierten Agenten, Regeln, Vorlagen und das Hook-Unterstützungsmaterial. Hook-Dateien werden als Unterstützungsmaterial aufbewahrt; Apothem registriert keine aktiven Antigravity-Hook-Ereignisse, bis der Adapter eine Schema-Übersetzungsschicht für Antigravity-`hooks.json` besitzt.

## Migrationspfad

1. Führen Sie `apothem profile init` aus, um das gemeinsame Profil zu erstellen, falls noch nicht geschehen.
2. Verschieben Sie Ihre von Hand geschriebenen Antigravity-Regeln in den gemeinsamen Korpus.
3. Führen Sie `apothem install --harness antigravity` aus, um den Korpus zu propagieren.
4. Führen Sie `apothem verify --harness antigravity` aus, um zu bestätigen, dass die Konfiguration angekommen ist.
5. Verwenden Sie `apothem update --harness antigravity` für jede spätere Änderung.
