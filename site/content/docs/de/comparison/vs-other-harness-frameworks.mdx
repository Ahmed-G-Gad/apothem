Diese Seite ordnet Apothem den Werkzeugkategorien zu, die Betreiber bereits zur
Verwaltung der Konfiguration von Harnesses nutzen. Sie benennt
Fähigkeitskategorien, keine konkreten Produkte — der Vergleich ist strukturell
und gilt unabhängig davon, zu welchem Werkzeug jeder Kategorie Sie greifen.

## Die Kategorien

Betreiber, die die Konfiguration von KI-Assistenten über mehrere Werkzeuge
hinweg verwalten, fallen in einen von vier Ansätzen:

1. **Manuelle Konfiguration pro Werkzeug.** Sie bearbeiten die native
   Konfigurationsdatei jeder Umgebung von Hand — eine Datei pro Werkzeug, keine
   gemeinsame Quelle.
2. **Konfigurationswerkzeuge für eine einzelne Umgebung.** Ein Werkzeug, das
   einer Assistenzplattform gewidmet ist und deren Konfiguration gut verwaltet,
   aber die anderen Werkzeuge, die Sie nutzen, nicht erreicht.
3. **Allzweck-Dotfile-Manager.** Ein Werkzeug, das Konfigurationsdateien über
   Maschinen hinweg versioniert und synchronisiert, aber jede Datei als
   undurchsichtigen Text behandelt.
4. **Konfigurationsmanager für mehrere Umgebungen.** Ein Werkzeug, das ein
   einziges geteiltes Profil hält und daraus das native Format jeder Umgebung
   rendert. Apothem gehört in diese Kategorie.

## Fähigkeitsvergleich

| Fähigkeit | Manuell pro Werkzeug | Werkzeug für eine Umgebung | Dotfile-Manager | Apothem |
| ---------- | --------------- | ------------------- | --------------- | ------- |
| Deckt viele Umgebungen ab | Ja (mit Mühe) | Nein (eine Umgebung) | Ja (auf Dateiebene) | Ja (siebzehn Adapter) |
| Einzige geteilte Quelle der Wahrheit | Nein | Nein | Nein | Ja |
| Rendert native Formate pro Umgebung | Manuell | Ja (eine Umgebung) | Nein | Ja |
| Verhinderung von Drift zwischen Umgebungen | Manuell | N. z. | Nur Dateisynchronisation | Ja |
| Formatübersetzung (`.mdc`, `.toml`, eingebettetes `.md`) | Manuell | Für ihre Umgebung | Nein | Ja |
| Verifikationsbefehl | Keiner | Variiert | Keiner | Ja |
| Eine neue Umgebung hinzufügen | Mehr Handarbeit | Nicht möglich | Mehr Dateien verfolgen | Einen Adapter installieren |

## Wozu jeder Ansatz passt

**Die manuelle Konfiguration pro Werkzeug** passt zu einem einzelnen Werkzeug
mit Konfiguration, die Sie selten ändern. Die Kosten wachsen mit jedem Werkzeug,
das Sie hinzufügen, und jeder Regel, die Sie zwischen ihnen ausgerichtet halten.

**Werkzeuge für eine einzelne Umgebung** passen zu Betreibern, die sich auf eine
Plattform festgelegt haben. Sie lösen das Multi-Werkzeug-Problem nicht — sobald
Sie einen zweiten Assistenten hinzufügen, sind Sie wieder dabei, zwei
Konfigurationen ausgerichtet zu halten.

**Dotfile-Manager** passen zur maschinenübergreifenden Synchronisation
beliebiger Dateien. Sie bewegen Bytes zwischen Maschinen, verstehen aber keine
Umgebungsformate, sodass sie weder ein Profil in siebzehn native Formen rendern
noch irgendeine davon verifizieren können.

**Apothem** passt zu Betreibern, die mehrere KI-Assistenten ausführen und eine
einzige Quelle der Wahrheit wollen. Sie schreiben das Profil einmal; Apothem
rendert, installiert, aktualisiert und verifiziert die native Konfiguration
jeder Umgebung.
