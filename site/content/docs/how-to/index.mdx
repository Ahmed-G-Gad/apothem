Each recipe states one concrete goal and the ordered steps that reach it.
Steps are copy-paste runnable and map to a real supported workflow.

## Recipes

- [Add a harness](/docs/how-to/adding-a-harness) — enable a harness adapter so
  its native configuration is materialized from the shared profile.
- [Edit the profile](/docs/how-to/editing-the-profile) — change the shared
  profile and re-materialize every installed harness.
- [Installer environment variables](/docs/how-to/installer-environment-variables)
  — control the script installer (destination, source, harness, profile,
  verify) without editing the script.
