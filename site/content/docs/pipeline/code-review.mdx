**Role:** Reviewer
**Pipeline position:** fortress

Operator-driven per-file code-quality review pass across src/, scripts/, and tools/.

## Canonical invocation

```bash
/code-review
```

With arguments:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Inputs

Host repository at any lifecycle state

## Outputs

Per-file findings at `_inputs/code-review-findings.md`

## Downstream

The line-by-line review stage of the Audit Review Sequence

## Workflow phases

The command runs five phases: input ingest, per-file walk, per-finding triage, findings emission, and the validation gate.

## Failure modes

| Symptom | Cause | Recovery |
|---------|-------|----------|
| Quality gate FAIL | Output does not meet standards | Fix the output and re-run |
| Missing input file | Repository has none of `src/`, `scripts/`, or `tools/` | Pass a repository root that contains at least one of them |

## Examples

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
