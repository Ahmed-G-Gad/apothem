**Role:** A11y auditor
**Pipeline position:** fortress

Accessibility audit against WCAG 2.2 AA for every rendered page.

## Canonical invocation

```bash
/a11y-audit
```

With arguments:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## Inputs

Deployed or locally-served project website

## Outputs

A11y findings at `_inputs/a11y-audit-findings.md`

## Downstream

The accessibility-audit stage of the Audit Review Sequence

## Workflow phases

The command runs five audit phases: input ingest, per-page audit, per-finding triage, findings emission, and the validation gate.

## Failure modes

| Symptom | Cause | Recovery |
|---------|-------|----------|
| Quality gate FAIL | Output does not meet standards | Fix the output and re-run |
| Missing input file | Site path or URL does not resolve | Pass a built site directory or a reachable URL |

## Examples

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
