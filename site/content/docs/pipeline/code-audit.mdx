**Role:** Auditor
**Pipeline position:** fortress

Cross-file forensic code audit at repository-corpus scope.

## Canonical invocation

```bash
/code-audit
```

With arguments:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## Inputs

Host repository with an approved source layout, a test-coverage baseline, and (at SHARED+) a passing CI gate

## Outputs

Corpus-level findings at `_inputs/code-audit-findings.md`

## Downstream

The forensic-code-audit stage of the Audit Review Sequence

## Workflow phases

The command runs six forensic phases: input ingest, cross-file dependency walk, type-hint and coverage audit, dead-code and duplicate detection, architectural-integrity audit, and findings emission with the validation gate.

## Failure modes

| Symptom | Cause | Recovery |
|---------|-------|----------|
| Quality gate FAIL | Output does not meet standards | Fix the output and re-run |
| Missing input file | No CI gate run or test-coverage baseline at SHARED+ | Run the host's CI pipeline first, then re-run |

## Examples

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
