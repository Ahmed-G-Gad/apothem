**Role:** Perf auditor
**Pipeline position:** fortress

Audits against per-class performance budgets (hook runtime, verify-ecosystem, conformity gate, tests, delegated workers, shell, lint), using the USE method.

## Canonical invocation

```bash
/perf-audit
```

With arguments:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## Inputs

Host repository that contains `hooks/`, `src/apothem/benchmarks/`, `tests/`, and the hook bootstrap stubs `hooks/lib/bootstrap.{sh,ps1}`

## Outputs

Performance findings at `_inputs/perf-audit-findings.md`

## Downstream

The performance-audit stage of the Audit Review Sequence

## Workflow phases

The command runs five audit phases: input ingest, per-class budget discovery, benchmark execution, hot-path identification by the USE method, and findings emission with the validation gate.

## Failure modes

| Symptom | Cause | Recovery |
|---------|-------|----------|
| Quality gate FAIL | Output does not meet standards | Fix the output and re-run |
| Missing input file | Repository lacks `src/apothem/benchmarks/` | Add the benchmark drivers, then re-run; the command refuses until they exist |

## Examples

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
