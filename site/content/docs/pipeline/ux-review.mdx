**Role:** UX reviewer
**Pipeline position:** fortress

Developer-experience review of CLI ergonomics, docs, and onboarding.

## Canonical invocation

```bash
/ux-review
```

With arguments:

```bash
/ux-review [path/to/repo/] [--focus SURFACE] [--dry-run]
```

## Inputs

Deployed host repository with a README, install scripts, and a CLI entry point

## Outputs

UX findings in `_inputs/ux-review-findings.md`

## Downstream

The UX-review stage of the Audit Review Sequence

## Workflow phases

The command runs five phases: input ingest, CLI-ergonomics walk, installation-flow and error-recovery audit, documentation-discoverability sweep, and findings emission with the validation gate.

## Failure modes

| Symptom | Cause | Recovery |
|---------|-------|----------|
| Prerequisite incomplete | Dependent phase not finished | Complete upstream phase first |
| Quality gate FAIL | Output does not meet standards | Fix the output and re-run |
| Target not deployed | Target lacks the operator-facing surface | Pass the deployed repository root |

## Examples

```bash
# Dry-run to preview what would happen
/ux-review --dry-run

# Execute against a host repository
/ux-review path/to/repo/
```
