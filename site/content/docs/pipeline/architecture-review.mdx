**Role:** Arch reviewer
**Pipeline position:** fortress

Architectural-integrity review against the design artifact at `_inputs/design.md`.

## Canonical invocation

```bash
/architecture-review
```

With arguments:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Inputs

Host repository + `_inputs/design.md`

## Outputs

Architecture findings at `_inputs/architecture-review-findings.md`

## Downstream

The architecture-review stage of the Audit Review Sequence

## Workflow phases

The command runs five audit phases: input ingest, design-to-code traceability walk, layer-boundary integrity audit, cross-package coupling sweep, and findings emission with the validation gate.

## Failure modes

| Symptom | Cause | Recovery |
|---------|-------|----------|
| Quality gate FAIL | Output does not meet standards | Fix the output and re-run |
| Missing input file | Design artifact `_inputs/design.md` absent | Run `/plan-design` to create it |

## Examples

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
