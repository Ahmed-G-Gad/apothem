对你在整个 Apothem 文档中会遇到的术语的快速参考。

## 共享配置档案

位于 `~/.config/apothem/profile.yaml` 的经 schema 校验的 YAML 文件（可用 `--profile PATH` 覆盖）。它是你的身份、偏好与配置的唯一可信来源；每个工具适配器在安装时读取它，并从中派生该工具的原生配置。

## 工具适配器

一种按平台划分的适配器，将共享配置档案转换为特定工具的原生配置格式。受支持的运行时列举如下：

```text
Claude Code, Cursor, Gemini CLI, etc.
```

安装 Apothem 始终意味着：先安装共享配置档案，然后物化一个或多个适配器。

## 行为规则

src/apothem/rules/ 下的 Markdown 文件，会在每次交互时加载（始终启用），或仅在编辑特定路径下的文件时加载（按路径过滤）。规则将工具应有的行为明确成文。有四条规则始终启用：`agnostic-posture`、`authority-inquiry`、`session-closure` 和 `context-management`。规则索引 `apothem-rule-index` 与它们一同加载，列出其他每条规则以及何时阅读它。不按路径限定规则范围的工具不会加载其他任何规则，因此会话要靠该索引找到它们。

## 钩子

注册在工具的钩子配置（Claude Code 为 settings.json）中的 Python 脚本，会在 PreToolUse、PostToolUse、SessionStart 和 Stop 等生命周期事件上触发；部分适配器还会注册 PreCompact 和 PostCompact。钩子在输出落盘之前实时执行合规强制项。对于没有钩子机制的工具，其适配器会省略钩子。

## 合规闸门

十五道预发布闸门（M1-M15）中的机械部分——在制品被发布之前运行的、可由机器检查的校验器；默认为建议性，在 `--strict` 下则为阻断性。预发布闸门是质量底线；合规闸门运行其中可由机器检查的关卡，而钩子则实时强制执行单项关卡。

## 计划套件

位于 &lt;project-root&gt;/.apothem/plans/&lt;suite-name&gt;/ 的结构化目录，包含一份规格说明、一份主计划、每阶段的 PHASE.md 文件以及输出制品。/plan 流水线管理计划套件。

## 技能

一种可复用、可通过斜杠命令调用的技术，打包为 src/apothem/skills/&lt;name&gt;/ 下的 SKILL.md 文件。技能将斜杠命令界面扩展到内置的 /plan 流水线之外。

## 委派工作者

一种持久的、按目的划定范围的助手，定义于规范路径：

```text
src/apothem/agents/<name>.md
```

委派工作者负责处理调研、审计、质量检查和记忆管理。
