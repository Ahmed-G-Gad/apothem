移除一个工具适配器配置。

## 概要

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

移除由适配器管理的工具目标，然后在安装所创建的目录变为空之后移除这些目录（包含你自己任何内容的目录会保留）。

共享工作目录的记忆、上下文和学习存储，只有当这是该目录中最后一个已安装的工具时，才会被备份并移除。卸载会在安装所记录的位置移除它们，因此无论安装把它们写到哪里，卸载都能找到（参见 `workspace` 配置档案字段）。`plans/` 目录永远不会被移除。

除非提供 `--yes`，否则会提示确认。在无法提示时——`--format json`（提示文本会破坏单个 JSON 文档）或非交互式 shell（无 TTY）——该命令会预先拒绝执行，并返回结构化的 `uninstall.confirmation_required` 错误（退出码 1），除非提供了 `--yes`。如果所选工具未安装，该命令会成功（退出码 0）；在纯文本输出中，它会打印 `NAME is not installed; nothing to remove.`，其中 `NAME` 为工具 ID。

安装根目录下 `.apothem/` 中的共享数据存储（`memory/`、`contexts/`、`learning/`），只要同一根目录下仍有另一个已安装的工具在使用它们，就会保留。当你移除的工具是该根目录下的最后一个工具时，该命令会先将每个数据存储复制到 Apothem 备份根目录（`~/.apothem/backups/`），然后连同其中的全部内容一并移除。你保存在 `plans/` 中的任何内容绝不会被移除。

使用 `--harness all` 进行的移除刻意做到穷尽：它覆盖每个已注册的工具，包括配置档案的 `exclude_harnesses` 在安装时跳过的工具——清理会触及先前范围更广的安装可能遗留的状态。从未安装过的工具会收到同样的提示。

连续式别名 `apothem uninstalling`（也接受写作 `apothem Uninstalling`）解析到同一个处理程序。

## 选项

| 选项 | 描述 |
|---|---|
| `--harness NAME` | 要移除的工具适配器，或用 `all` 表示覆盖整个注册表的集合（必填）。 |
| `--yes` | 跳过确认提示。 |
| `--project PATH` | 项目作用域工具的项目根目录。 |
| `--quiet`, `-q` | 抑制信息性输出；只输出错误。 |
| `--verbose`, `-v` | 输出额外的诊断信息。 |
| `--format plain\|json` | 输出格式（默认：`plain`）。 |
| `--json` | `--format json` 的简写。 |
| `--no-color` | 在输出中禁用 ANSI 颜色码。 |
| `-h`, `--help` | 显示帮助并退出。 |

## JSON 输出

当适配器已安装并被成功移除时：

```json
{
  "schema_version": 1,
  "status": "success",
  "command": "uninstall",
  "action": "uninstalled",
  "harness": "claude-code",
  "profile_path": null,
  "project": null,
  "files_written": [],
  "results": [
    {
      "harness": "claude-code",
      "outcome": "updated",
      "operation": "uninstall",
      "path": "C:\\Users\\Example\\.claude\\settings.json",
      "message": "managed files removed"
    }
  ],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

当适配器未安装时，命令以 `0` 退出。在 JSON 输出中，信封包含 `"status": "success"` 和 `"action": "uninstalled"`；结果行包含 `"outcome": "skipped"`，其消息为 `"not installed; no files
removed"`。`status` 字段绝不会是 `"not_installed"`。

## 示例

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## 退出码

| 代码 | 含义 |
|---|---|
| 0 | 适配器已卸载，或本就未安装 |
| 1 | 未找到工具、确认被拒绝或无法进行确认（在未提供 `--yes` 的非交互式或 JSON 模式下），或每一项移除都失败了 |
| 2 | 部分移除——在失败之前至少有一个工具已被移除 |
| 64 | 用法错误：未知的选项或命令，或缺失或无效的选项值。在 `--json` 下，该错误是一个代码为 `cli.usage` 的 JSON 信封。 |
