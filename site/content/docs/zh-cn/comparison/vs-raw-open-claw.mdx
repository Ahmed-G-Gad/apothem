Open-Claw 读取 `~/.openclaw/openclaw.json`。Apothem 在
`~/.openclaw/.apothem/support/skills/` 下安装共享的命令集合和技能集合，并编辑
`~/.openclaw/openclaw.json` 中的两处。它把该目录添加到 `skills.load.extraDirs`，以便
OpenClaw 加载这些技能。它把路径 `apothem/AGENTS.md` 添加到钩子条目
`hooks.internal.entries.bootstrap-extra-files` 的路径列表中，没有该条目时会以
`enabled: true` 创建它，以便 OpenClaw 加载它写入每个工作区的 Apothem 规则文件。它的
`agents.defaults.skills` 是一个归你所有的名称白名单，且 MCP 是一个 CLI 面，因此
Apothem 两者都不编写。

## 状态

**预览。** Open-Claw 适配器面向当前已文档化的配置文件、额外的技能目录面以及内置的
`bootstrap-extra-files` 钩子。规则通过工作区文件 `apothem/AGENTS.md` 加载；模板、agents
与钩子材料仍属于 Apothem 支持材料。

## 工作量对比

| 任务 | 原生手工配置 | Apothem 管理 |
| ---- | --------------- | --------------- |
| 编写可复用技能 | 手工编辑配置和技能目录 | 在共享语料中编写一次 |
| 让各工具的集合保持一致 | 逐工具手动 | `apothem update` 时自动 |
| 安装 / 移除配置 | 手动 | `apothem install` / `apothem uninstall` |
| 验证配置是否正确 | 手动检查 | `apothem verify --harness open-claw` |

## Apothem 管理什么

Open-Claw 适配器写入 `openclaw.json`，把 Apothem 斜杠命令封装为技能，把 Apothem
技能复制进被引用的支持目录，并把规则、模板、agents 与钩子材料保留在 Apothem
支持子树下。
它还会把 `apothem/AGENTS.md` 写入每个工作区，并在内置的 `bootstrap-extra-files` 钩子中
注册它，因此 OpenClaw 无需改动工作区自己的 `AGENTS.md` 就能加载 Apothem 规则。
OpenClaw 在你的工作区、`~/.agents/skills` 与 `~/.openclaw/skills` 这些来源之后才读取
`skills.load.extraDirs`，因此其中任何一处的同名技能都会取代 Apothem 的副本被使用。

## 迁移路径

1. 如果尚未创建共享 profile，运行 `apothem profile init`。
2. 把可复用的 Open-Claw 技能或命令提示词移入共享语料。
3. 运行 `apothem install --harness open-claw` 以渲染原生配置和支持技能目录。
4. 运行 `apothem verify --harness open-claw` 以确认配置已落地。
