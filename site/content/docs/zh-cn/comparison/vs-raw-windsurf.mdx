Windsurf 从 `.devin/rules/` 目录读取规则。Apothem 的 windsurf 适配器从共享
配置档案渲染这些基于目录的规则。本页将手工维护该配置与用 apothem 管理它进行
对比。

## 工作量对比

| 任务 | 原生手工配置 | Apothem 管理 |
| ---- | --------------- | --------------- |
| 编写规则 | 在 `.windsurf/rules/` 下手写每个文件 | 从共享语料渲染 |
| 保持单一规则格式 | 在 `.windsurf/rules/` 与单文件 `.windsurfrules` 之间手动取舍 | 适配器只写入 `.devin/rules/` |
| 与其他环境保持规则对齐 | 手动、逐工具 | 在 `apothem update` 时自动完成 |
| 验证配置正确 | 手动检查 | `apothem verify --harness windsurf` |

## Apothem 管理什么

windsurf 适配器将共享规则渲染到 `.devin/rules/` 目录；它不写入单文件
`.windsurfrules`。Windsurf 没有 PreToolUse 钩子，因此护栏意图存在于规则散文
之中，而非工具调用拦截点。每次对共享规则的变更都会在下一次 `apothem update`
时重新渲染该目录。

## 迁移路径

1. 若你尚未创建共享配置档案，运行 `apothem profile init`。
2. 把你现有 `.windsurf/rules/`（以及任何单文件 `.windsurfrules`）中的规则
   移入共享语料。
3. 运行 `apothem install --harness windsurf` 以渲染 `.devin/rules/` 目录。
4. 运行 `apothem verify --harness windsurf` 确认配置已落地。
5. 之后每次变更都使用 `apothem update --harness windsurf`。
