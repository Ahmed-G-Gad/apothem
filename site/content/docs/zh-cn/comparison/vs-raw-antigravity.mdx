Antigravity 是 I 类清单传播工具：Apothem 会写入全局的 `~/.gemini/GEMINI.md` 上下文锚点，并在 `~/.gemini/antigravity-cli/plugins/apothem/` 下安装一个 Apothem 插件。本页将手工维护该布局与使用 Apothem 管理它进行对比。

## 状态

**预览版。** Antigravity 适配器面向当前已文档化的 `GEMINI.md` 上下文锚点以及 Antigravity CLI 插件表面。没有原生表面的集合仍作为 Apothem 支持材料保留。

## 工作量对比

| 任务 | 手工配置 | Apothem 托管 |
| ---- | --------------- | --------------- |
| 编写规则 | 手写每个插件规则文件 | 在共享语料库中写一次 |
| 保留可复用提示 | 手工将命令提示与技能复制进插件文件 | 转换或复制为插件技能 |
| 保留钩子支持材料 | 手工复制钩子引用，不做有效接线 | 复制到 Apothem 插件支持子树下 |
| 使规则与其他工具保持一致 | 手工，逐个工具 | 执行 `apothem update` 时自动完成 |
| 安装 / 移除配置 | 手工复制与删除文件 | `apothem install` / `apothem uninstall` |
| 验证配置是否正确 | 手工检查 | `apothem verify --harness antigravity` |

## Apothem 管理的内容

Apothem 管理 Antigravity 的全局上下文文件、插件元数据、转换后的命令技能、可复用技能、转换后的委托工作者、规则、模板以及钩子支持材料。钩子文件作为支持材料予以保留；在适配器拥有针对 Antigravity `hooks.json` 的模式翻译层之前，Apothem 不会注册有效的 Antigravity 钩子事件。

## 迁移路径

1. 如果尚未创建共享配置档案，请运行 `apothem profile init`。
2. 将你现有手写的 Antigravity 规则迁移到共享语料库中。
3. 运行 `apothem install --harness antigravity` 以传播语料库。
4. 运行 `apothem verify --harness antigravity` 以确认配置已落地。
5. 此后的每次变更都使用 `apothem update --harness antigravity`。
