**角色：** 安全审计员
**流水线位置：** 堡垒

针对 OWASP ASVS 4.0 或更高版本以及 OWASP Top 10 的全面安全态势审计。

本命令的下限是 ASVS 4.0 的最终补丁版本。它不会自行查找更新的 ASVS 发行版。发现项会按编号与简短标题引用 ASVS 章节，例如 V5（验证、净化、编码）、V12（文件与资源）和 V14（配置）。

## 规范调用

```bash
/security-audit
```

带参数：

```bash
/security-audit [path/to/repo/] [--focus CATEGORY] [--dry-run]
```

## 输入

位于固定 git 提交的宿主仓库

## 输出

安全发现项位于 `_inputs/security-audit-findings.md`

## 下游

审计审查序列的 security-audit 阶段

## 工作流阶段

该命令分为六个审计阶段：输入摄取、密钥与权限、输入校验与注入、反序列化与路径遍历、依赖 CVE 与 CodeQL，以及附带校验门的发现项输出。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 前置条件未完成 | 依赖阶段尚未结束 | 先完成上游阶段 |
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 目标被拒绝 | 路径不是 git 工作树 | 将仓库根目录作为路径传入 |

## 示例

```bash
# Dry-run to preview what would happen
/security-audit --dry-run

# Execute against a host repository
/security-audit path/to/repo/
```
