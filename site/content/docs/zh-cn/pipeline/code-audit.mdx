**角色：** 审计员
**流水线位置：** 堡垒

仓库语料库范围的跨文件取证代码审计。

## 规范调用

```bash
/code-audit
```

带参数：

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## 输入

具有经批准的源码布局、测试覆盖率基线，以及（在 SHARED+ 级别）通过的 CI 闸门的宿主仓库

## 输出

语料库级别的发现项位于 `_inputs/code-audit-findings.md`

## 下游

审计审查序列的取证代码审计阶段

## 工作流阶段

该命令分为六个取证式阶段：输入摄取、跨文件依赖遍历、类型提示与覆盖率审计、死代码与重复代码检测、架构完整性审计，以及附带校验门的发现项输出。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 缺失输入文件 | 在 SHARED+ 级别未运行 CI 闸门，或缺少测试覆盖率基线 | 先运行宿主的 CI 流水线，然后重新运行 |

## 示例

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
