**角色：** 供应链审计者
**流水线位置：** 堡垒

针对 SLSA + Sigstore + SBOM 标准的供应链审计。

## 规范调用

```bash
/supply-chain-audit
```

带参数：

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## 输入

宿主仓库发布流水线

## 输出

供应链发现项位于 `_inputs/supply-chain-audit-findings.md`

## 下游

审计审查序列的 supply-chain-audit 阶段

## 工作流阶段

该命令分为五个审计阶段：输入摄取、逐轴遍历、逐项分诊、发现项输出，以及校验门。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 前置条件未完成 | 依赖阶段尚未结束 | 先完成上游阶段 |
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 目标被拒绝 | 目标缺少发布表面 | 传入带有 .github/workflows/、发布脚本或构建清单之一的仓库根目录 |

## 示例

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
