**角色：** 首席研究者（同行评审）
**流水线位置：** 链路中段

依据发表场所的标准，对论文进行同行评审级别的对抗式批判——新颖性、严谨性、可复现性、清晰度、伦理、统计审查以及报告规范符合度。产出一份**七轴**评审记分卡以及一份按严重程度分级的必需修订清单，每项发现都附带具体驱动因素的理由。默认反驳立场。

## 规范调用

```bash
/research-review
```

带参数：

```bash
/research-review [path/to/research-suite/]
```

## 输入

论文阶段所记录的、位于宿主自然位置的论文交付物。

## 输出

`_outputs/review-report.md` —— **七轴**评审记分卡（新颖性 · 严谨性 · 可复现性 · 清晰度 · 伦理 · 统计审查 · 报告规范符合度）、按严重程度分级（HIGH / MEDIUM / LOW）的必需修订清单（每项发现都附带具体驱动因素的理由）、可复现性包与重跑裁决、引用完整性审计，以及总体的 `accept · minor-revision · major-revision · reject` 裁决。

## 下游

/research-publish（下游消费者）。`major-revision` 或 `reject` 裁决会驱动修订循环回到 `/research-paper`，先处理必需修订，再重新评审。

## 工作流阶段

该命令遵循标准的 `/research` 流水线工作流：

1. **加载上下文** —— 读取论文交付物。
2. **验证序列门** —— 确认论文存在；否则以 `Blocked: run /research-paper first` 中止。
3. **对抗式评审** —— 对七个轴评分（新颖性 · 严谨性 · 可复现性 · 清晰度 · 伦理 · 统计审查 · 报告规范符合度）；运行可复现性重跑与引用完整性审计；默认反驳；用证据定位具体缺陷。
4. **分级修订** —— 将必需修订按 HIGH / MEDIUM / LOW 排序，并附具体驱动因素的理由。
5. **更新交接清单** —— 记录评审报告和记分卡裁决。
6. **产出评审** —— `_outputs/review-report.md`。

## 严谨性强制底线

评审对照晋级门标尺为经验论断评分——充足的重复、带效应量和临界差异排名的非参数显著性、以及受比较方法间的预算对等——并将裁决视为一道明确的晋级门：一篇论文只有令人信服且显著地胜过发表场所标尺时才晋级，且该清越被记入日志。在双盲发表场所下，评审者还会将任何身份泄露标记为一处匿名化缺陷。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| Blocked: run /research-paper first | 没有论文 | 运行 `/research-paper` 以产出手稿 |
| 偏宽容的评分 | 评审者假设了最佳情形 | 默认反驳；依据现有证据评分 |
| 没有理由的发现 | 修订只是断言，未经论证 | 为每项发现附上具体驱动因素的理由 |

## 示例

```bash
# 对论文进行同行评审并产出评审记分卡
/research-review path/to/research-suite/
```
