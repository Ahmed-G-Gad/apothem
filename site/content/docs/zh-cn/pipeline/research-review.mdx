**角色：** 首席研究者（同行评审）
**流水线位置：** 链路中段

依据发表场所的标准，对论文进行同行评审级别的对抗式批判——新颖性、严谨性、可复现性、清晰度、伦理、统计审查以及报告规范符合度。产出一份**七轴**评审记分卡以及一份按严重程度分级的必需修订清单，每项发现都附带具体驱动因素的理由。默认反驳立场，且每一点都基于草稿自身的文字和证据，绝不基于发表场所、机构或作者的声望。

## 规范调用

```bash
/research-review
```

带参数：

```bash
/research-review [--suite-name NAME] [--venue STANDARD] [--paper PATH [--scale SPEC] [--roles LIST] [--out PATH]]
```

## 输入

论文阶段所记录的、位于宿主自然位置的论文交付物。使用 `--paper` 时，论文是你提供的 PDF 或文本文件（或粘贴的文本），而非研究套件的交付物，且无需套件。

## 输出

`_outputs/review-report.md` —— **七轴**评审记分卡（新颖性 · 严谨性 · 可复现性 · 清晰度 · 伦理 · 统计审查 · 报告规范符合度）、按严重程度分级（HIGH / MEDIUM / LOW）的必需修订清单（每项发现都附带具体驱动因素的理由）、可复现性包与重跑裁决、引用完整性审计，以及总体的 `accept · minor-revision · major-revision · reject` 裁决。

使用 `--paper` 时，报告会写入项目根目录下的 `.apothem/plans/<date>--review-<slug>.md`（或写入 `--out` 路径）：一份七轴记分卡（每个评审者角色一行）、公式、消融与基线检查行、按严重程度排序的必需修订、最多五个向作者提出的问题，以及映射到你所指定推荐量表上的决定。它被标注为模型辅助的阅读，而非同行评审。

## 下游

/research-publish（下游消费者）。`major-revision` 或 `reject` 裁决意味着，必须先处理所需修订，然后才能运行 `/research-publish`。

## 工作流阶段

该命令遵循标准的 `/research` 流水线工作流：

1. **加载上下文** —— 读取论文交付物。
2. **验证序列闸门** —— 确认论文、`_outputs/analysis.md` 与 `_inputs/synthesis.md` 均存在且非空；否则以 `Blocked: run /research-paper first` 中止。
3. **对抗式评审** —— 对七个轴评分（新颖性 · 严谨性 · 可复现性 · 清晰度 · 伦理 · 统计审查 · 报告规范符合度）；将每项论断归类为描述性、关联性或因果性，并检查反复出现的评估错误；检查图表编码是否诚实、在无色彩时是否可读；运行可复现性重跑与引用完整性审计；默认反驳；以证据定位具体缺陷。
4. **分级修订** —— 将所需修订按 HIGH / MEDIUM / LOW 排序，并附具体驱动因素的理由。评审无法判断的轴不给出裁决；它连同理由留在未判断清单上，总体裁决会将其作为限定条件标明。
5. **更新交接清单** —— 记录评审报告与记分卡裁决。
6. **发出评审** —— `_outputs/review-report.md`。

## 评审他人的论文

`--paper` 用于评审不属于研究套件的手稿，例如你受邀审稿的投稿，或同事的草稿。

- **发表场所档案。** `--venue` 接受一个通用档案的 id（例如 `empirical-conference` 或 `field-journal`）。指定的具体发表场所会使用最接近的通用档案，并在报告中说明这一点。Apothem 只提供通用档案，绝不声称代表任何发表场所自身的标准；你粘贴的指南在提供时具有约束力，报告标题会记录其来源、日期，以及它们所涵盖的年份或周期和投稿轨道。
- **手稿版本。** 报告会记录所阅读的版本（预印本、录用稿、记录版本或未知）、文件所带的任何版本标记、其来源以及阅读日期，从而将评审固定到某一修订版本。
- **评审者角色。** 默认角色为方法、领域和怀疑者。`--roles` 可更改该列表。角色之间存在分歧时，报告会列出分歧，而不是取平均。
- **保密性。** 系统会询问你一次，该论文是保密投稿、已发表论文还是你自己的草稿。答案未知时适用更严格的处理：检索使用标题、标识符或通用主题词，绝不使用手稿中的句子。
- **新颖性。** 没有套件就没有先前工作的图谱，因此评审使用论文中点名的相邻工作，外加一份有边界的检索记录。空的检索结果绝不被视为新颖性的证据，且除非该记录涵盖某个学术索引，否则新颖性置信度保持为低。
- **匿名性。** 在你为双盲发表场所进行自身的就绪检查时，评审会检查正文之外的各个层面（文档属性、随附及链接的文件、存储库历史、补充材料归档、渲染后的图表）；无法打开的层面会进入未判断清单，绝不进入无问题清单。对于分配给你的保密投稿，评审不会在这些层面中搜寻身份信息：未经搜寻而偶然遇到的身份信息会作为泄露报告给你，且不计入任何评分。

## 严谨性强制底线

任何轴的裁决、发现或置信度都不基于期刊级指标、引用次数、作者级指数，或发表场所、机构或作者的声誉；引用此类数字的评审只作描述性引用，并说明其衡量的内容、来源和日期。HIGH 严重程度的发现包括：带有未披露拼接、合成或处理步骤的实验图像，以及与报告结局不同且未说明理由的注册结局。统计审查会检查 n 统计的是独立单位，而非同一单位的重复测量、折或种子。

评审对照晋级门标尺为经验论断评分——充足的重复、带效应量和临界差异排名的非参数显著性、以及受比较方法间的预算对等——并将裁决视为一道明确的晋级门：一篇论文只有令人信服且显著地胜过发表场所标尺时才晋级，且该清越被记入日志。在双盲发表场所下，评审者还会将任何身份泄露标记为一处匿名化缺陷。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| Blocked: run /research-paper first | 没有论文 | 运行 `/research-paper` 以产出手稿 |
| Blocked: no paper supplied | `--paper` 文件缺失或无法读取 | 传入可读的 PDF 或文本文件，或粘贴文本 |
| 偏宽容的评分 | 评审者假设了最佳情形 | 默认反驳；依据现有证据评分 |
| 基于声望的论点 | 将发表场所、机构、作者、期刊级指标或引用次数用作证据 | 删除该论点；依据草稿自身的文字和证据重新陈述 |
| 没有理由的发现 | 修订只是断言，未经论证 | 为每项发现附上具体驱动因素的理由 |

## 示例

```bash
# 对论文进行同行评审并产出评审记分卡
/research-review --suite-name <name>

# 依据通用发表场所档案，以 1-10 量表评审所提供的 PDF
/research-review --paper ./submission.pdf --venue empirical-conference --scale 1-10
```
