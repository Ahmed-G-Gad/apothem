**角色：** 无障碍审计者
**流水线位置：** 堡垒

针对每个渲染页面进行 WCAG 2.2 AA 无障碍审计。

## 规范调用

```bash
/a11y-audit
```

带参数：

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## 输入

已部署或本地提供的项目网站

## 输出

无障碍发现项位于 `_inputs/a11y-audit-findings.md`

## 下游

审计审查序列中的无障碍审计阶段

## 工作流阶段

该命令分为五个审计阶段：输入摄取、逐页审计、逐项分诊、发现项输出，以及校验门。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 缺失输入文件 | 站点路径或 URL 无法解析 | 传入已构建的站点目录或可访问的 URL |

## 示例

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
