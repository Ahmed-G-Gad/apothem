**角色：** 依赖审计者
**流水线位置：** 堡垒

针对许可证、CVE 和新鲜度的逐依赖审计扫查（直接 + 传递）。

## 规范调用

```bash
/dependency-audit
```

带参数：

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## 输入

宿主仓库依赖清单

## 输出

依赖发现项位于 `_inputs/dependency-audit-findings.md`

## 下游

审计审查序列的 dependency-audit 阶段

## 工作流阶段

该命令分为五个阶段：输入摄取、逐依赖遍历、逐项分诊、发现项输出，以及校验门。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 缺失输入文件 | 仓库根目录下没有可解析的依赖清单 | 传入包含依赖清单的仓库根目录 |

## 示例

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
