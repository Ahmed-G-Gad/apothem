**角色：** 架构审查者
**流水线位置：** 堡垒

针对 `_inputs/design.md` 的设计制品进行架构完整性审查。

## 规范调用

```bash
/architecture-review
```

带参数：

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## 输入

宿主仓库 + `_inputs/design.md`

## 输出

架构发现项位于 `_inputs/architecture-review-findings.md`

## 下游

审计审查序列中的架构审查阶段

## 工作流阶段

该命令分为五个审计阶段：输入摄取、设计到代码的可追溯性遍历、分层边界完整性审计、跨包耦合扫描，以及附带校验门的发现项输出。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 缺失输入文件 | 设计工件 `_inputs/design.md` 不存在 | 运行 `/plan-design` 以创建它 |

## 示例

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
