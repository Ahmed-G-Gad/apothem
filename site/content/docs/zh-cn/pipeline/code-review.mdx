**角色：** 审查者
**流水线位置：** 堡垒

横跨 src/、scripts/ 和 tools/ 的、由操作者驱动的逐文件代码质量审查扫查。

## 规范调用

```bash
/code-review
```

带参数：

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## 输入

任意生命周期状态下的宿主仓库

## 输出

逐文件发现项位于 `_inputs/code-review-findings.md`

## 下游

审计审查序列的逐行审查阶段

## 工作流阶段

该命令分为五个阶段：输入摄取、逐文件遍历、逐项分诊、发现项输出，以及校验门。

## 失败模式

| 症状 | 原因 | 恢复 |
|---------|-------|----------|
| 质量门 FAIL | 输出未达到标准 | 修复输出并重新运行 |
| 缺失输入文件 | 仓库中不存在 `src/`、`scripts/` 或 `tools/` 中的任何一个 | 传入至少包含其中一个目录的仓库根目录 |

## 示例

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
