## 十五道关卡

| 关卡 | ID | 强制规定 | 检查类别 | 失败 → 行动 |
|---|---|---|---|---|
| 1 | M1 | 宿主项目无关性 | 推理判断 | 修订以匹配宿主约定 |
| 2 | M2 | 编辑纪律（披露账本） | 机械 | 添加披露标记 |
| 3 | M3 | 十项质量维度 | 推理判断 | 针对未通过的维度进行修订 |
| 4 | M4 | 自我适用（存在闸门签署记录） | 机械 | 记录签署记录块 |
| 5 | M5 | 权威原则（不编造身份 / 端点 / 机密） | 机械 | 转交询问 |
| 6 | M6 | 专业知识融入（揭示的缺口） | 推理判断 | 揭示缺口；引用改进之处 |
| 7 | M7 | 选项标注（Recommended 标记 + 驱动因素理由） | 机械 | 标注选项集 |
| 8 | M8 | 确定性（规定性文字中不含含糊措辞） | 机械 | 将含糊措辞提升为条件句 |
| 9 | M9 | 视觉杠杆（结构性主题配有图示） | 推理判断 | 编写 / 刷新图示 |
| 10 | M10 | 双向绑定（互逆的反向指针已闭合） | 机械 | 闭合半边 |
| 11 | M11 | 敏捷冲刺（目标 / 待办列表 / DoR / DoD / 评审 / 回顾） | 推理判断 | 重构为冲刺 |
| 12 | M12 | 阶段报告与规范布局 | 机械 | 编写汇总；迁移到规范布局 |
| 13 | M13 | 代码工艺（lint / 格式化 / 类型检查；魔法数字；裸 except） | 机械 | 应用各语言的代码工艺规则 |
| 14 | M14 | 系统性（声明上游 / 下游 / 同级 / 执行者） | 推理判断 | 声明；在登记册中编入索引 |
| 15 | M15 | 生产就绪（测试 + 文档 + CHANGELOG + 合规提交 + CI 绿色 + semver 稳定性） | 机械 | 补齐缺失的表面 |

## 严重级别阶梯

| 严重级别 | 对闸门的影响 |
|---|---|
| **关键** | 闸门 FAIL——无条件阻止发布 |
| **重要** | 当 2 道及以上“重要”关卡同时失败时，闸门 FAIL |
| **建议性** | 闸门 WARN——记录在签署记录中；不阻止发布 |

大多数机械部分的匹配器默认为**重要**。M5（权威——机密、编造的端点）和 M12（孤儿输出）为**关键**。

## 校验器

机械部分位于 [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity)，由 [`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py) 编排。闸门以下列三种方式之一运行每个校验器：

- **per-write**：在每次待处理的写入时运行（`--hook`），或用 `--all-perwrite` 对每个已跟踪的文件运行。
- **standalone**：用 `--all` 在整个仓库范围内运行，或用 `--check <name>` 逐个运行。
- **change-set**：针对已暂存的差异运行，位于闸门的扫查之外。

## 运行闸门

在已安装的工具上，闸门会自动运行：Claude Code 的 `settings.json` 将其接入为一个 `PreToolUse` 钩子，在每次 Write/Edit 之前调用位于 `~/.claude/.apothem/support/conformity/gate.py` 的物化副本。在源码检出中，模块形式驱动同一套代码。闸门默认是建议性的：它报告发现项并以 `0` 退出。添加 `--strict` 可在出现阻断性发现项时以 `2` 退出。未知的校验器名称以 `3` 退出。

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help` 会打印用法摘要。完整流程参见[运行合规闸门](/docs/usage/conformity-gate)。
