## 当前发布

- 稳定十七个工具适配器。
- 完成审计审查基础设施。
- 稳定 Apothem CLI 表面。
- 建立 GitHub Actions CI/CD 流水线。

## 近期

- 让 npm / npx 分发成熟：使 `@ahmed-g-gad/apothem` 入口点与每次发布保持
  一致，并拓宽其平台覆盖。
- 随着市场表面的稳定，发展 Claude Code 插件的上架。
- 通过 `apothem update --watch` 实现工具适配器自动更新。
- 配置文件版本化与迁移工具。
- 在符合性闸门中进行共享配置文件模式验证。
- 基于社区请求的更多工具适配器。

## 长期

- 云端托管的配置文件同步（可选，由操作者控制）。
- 用于实时符合性反馈的 VS Code 扩展。
- 团队共享的配置文件管理。

## 请求与反馈

通过 [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions)
提交路线图请求。路线图由社区意见塑造；呼声更高的请求推进更快。
