## GitHub Discussions

主要的社区场所是 [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions)。

类别：

| 类别 | 用于 |
|----------|---------|
| Q&A | 关于用法、配置与行为的问题 |
| Ideas | 特性请求与设计讨论 |
| Show and tell | 分享你如何使用 Apothem |
| General | 其他任何内容 |

## Issues

对于缺陷与具体的特性请求，请使用
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues)。

在开启 issue 之前，请搜索现有的 issue 与讨论，以避免重复。

## 贡献

关于如何贡献代码、文档与工具适配器，请参见 [贡献](/docs/developer-guide)。从仓库的
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
及其引用的拉取请求模板入手。
