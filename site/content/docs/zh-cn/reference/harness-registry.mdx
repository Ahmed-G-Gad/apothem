工具适配器注册表是 CLI、文档、固件测试与约定锚点校验所使用的权威适配器清单。
运行时源是 `src/apothem/lib/harness_registry.py`；下表中的每一行都可追溯到该注册表、
各适配器的 `capabilities.yml` 以及每个适配器的 `STANDARD-CONVENTION-PIN.md`。

## 校验钩子

注册表通过以下检查保持同步：

| 检查 | 用途 |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | 确认每个适配器都有当前的约定锚点，且注册表仍然枚举十七个适配器。 |
| `python -m apothem.conformity.gate --all .` | 运行文档与实现的合规性检查。 |
| `python -m pytest` | 执行注册表固件测试与适配器契约测试。 |
