Model Context Protocol（MCP）服务器**归操作者所有**。Apothem 在共享配置档案中携带 MCP 清单（`mcp_servers`）。如果某个适配器所对应的工具将其 MCP 服务器保存在 Apothem 本已写入的配置文件中，该适配器就会将该清单投射到该文件中；其他每个适配器都不编写任何服务器条目，这些服务器仍由你通过工具自行注册。

## MCP 服务器在何处注册

每个工具都通过其自身的原生机制注册 MCP 服务器，Apothem 遵从该表面而不是覆盖它。在 Claude Code 上，服务器通过 `claude mcp add` 注册到 `~/.claude.json`（用户或本地作用域）以及项目级的 `.mcp.json` 中；Claude Code 适配器不会写入这两个文件中的任何一个，并且 Apothem 受管的 Claude Code 设置绝不携带 `mcpServers` 区块。

## 添加服务器

通过你的工具的原生机制注册服务器；规范的条目形态是 `mcpServers` 下的一个键：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

工具的运行时会在会话开始时加载已注册的服务器；重启工具即可载入新的服务器。

## 命名约定

按照工具的标准 MCP 工具命名约定，MCP 工具以 `mcp__<server>__<tool>` 的形式呈现给助手。
