**厂商：** Zed Industries
**安装名称：** `zed`
**状态：** GA
**原生配置：** `<project>/.rules`

## 安装

```bash
apothem install --harness zed --project /path/to/project
```

适配器根据共享的 Apothem 规则和治理表面，写入一个项目级的 Zed 指令文件。Zed 读取一个项目指令文件，即此列表中第一个匹配的文件：

```text
.rules
.cursorrules
.windsurfrules
.clinerules
.github/copilot-instructions.md
AGENT.md
AGENTS.md
CLAUDE.md
GEMINI.md
```

不存在按工具划分的规则目录，因此整个 Apothem 表面都落在该列表顶部的扁平 `.rules` 文件中。

**写入的文件：** `<project>/.rules`

## 配置档案到原生配置的映射

适配器读取 Apothem 的共享配置档案，并在每次 `apothem install` 或 `apothem update` 运行时渲染项目 `.rules` 文件。共享配置档案是事实来源；在下一次同步替换 Apothem 管理的内容之前，任何已存在的 `.rules`（或对生成文件所做的项目本地编辑）都会被备份。

## 兼容性说明

Zed 将 `AGENTS.md` 称为其主要指令文件，并保留项目 `.rules` 作为受支持的兼容性文件（[Zed 指令](https://zed.dev/docs/ai/instructions)）。由于 Zed 只读取第一个匹配项，新的 `.rules` 会遮蔽项目已依赖的 `AGENTS.md`、`CLAUDE.md` 或列表中位置更靠后的任何其他文件。安装绝不会编辑这些文件。当 `.rules` 只包含 Apothem 块，而某个优先级更低的文件包含你的文本时，安装和更新会打印一条指明被遮蔽文件的警告；若要在 Zed 中保留你需要的指令，请将它们复制到 `.rules` 中 Apothem 块之外的位置。

全局 `~/.config/zed/AGENTS.md` 指令文件和 MCP 上下文服务器块（`.zed/settings.json` 中的 `context_servers`）归操作者所有；Apothem 不写入它们。

## 验证

```bash
apothem verify --harness zed --project /path/to/project
```

verify 命令确认：

1. 原生配置存在于预期路径。
2. 每个受管目标都存在；受管文件非空，并且 JSON 或 YAML 配置可以解析。添加 `--profile PATH` 还可以确认已安装的文件与该配置档案相符。
3. 适配器专属的验证例程报告成功。

## 更新

```bash
apothem update --harness zed --project /path/to/project
```

根据当前的共享配置档案状态，重新派生项目 `.rules` 文件。

## 卸载

```bash
apothem uninstall --harness zed --project /path/to/project
```

移除 Apothem 在原生配置文件 `.rules` 中的受管块，并保留你自己的文本。只有当文件中已无其他内容时才会删除该文件。在变更之前，会在 `~/.apothem/backups/` 下保存一份带时间戳的文件副本；项目中不会留下备份文件。共享配置档案 YAML 与 Apothem 引擎不受影响。

## 合规闸门

```bash
python -m apothem.conformity.gate --all .
```

## 故障排查

| 症状 | 修复方法 |
|---------|-----|
| 找不到配置文件 | 重新运行 `apothem install --harness zed --project /path/to/project` |
| 验证失败 | 运行 `apothem update --harness zed --project /path/to/project`，然后再次验证 |
| 意外的配置内容 | 检查 `~/.config/apothem/profile.yaml` 或 `--profile PATH`，然后重新运行 `apothem update --harness zed --project /path/to/project` |

## 配置开关

| 标志 | 默认值 | 说明 |
|------|---------|-------------|
| `--dry-run` | `false` | 预览安装而不写入文件。 |
