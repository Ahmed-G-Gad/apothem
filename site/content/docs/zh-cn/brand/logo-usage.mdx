## 变体

| 变体 | 文件 | 使用场景 |
|---|---|---|
| 标志，浅色表面 | `assets/logo.svg` | README 页眉、站点首屏、图示、浅色背景 |
| 标志，深色表面 | `assets/logo-dark.svg` | 站点首屏与深色背景 |
| 文字标志，浅色表面 | `assets/logo-wordmark.svg` | 品牌名称需与标志一同出现的宽幅组合 |
| 文字标志，深色表面 | `assets/logo-wordmark-dark.svg` | 深色表面上的宽幅组合 |
| 浏览器站点图标 | `assets/favicon.svg`、`assets/favicon.ico`、`assets/favicon-16x16.png`、`assets/favicon-32x32.png` | 浏览器标签页与 ICO 回退使用方 |
| Apple 触摸图标 | `assets/apple-touch-icon-180.png` | iOS 书签 |
| 社交卡片 | `assets/og-banner-1200x630.png`、`assets/twitter-card.png`、`assets/social-preview.svg` | Open Graph、Twitter/X 以及 GitHub 仓库预览表面 |

## 栅格尺寸

预生成的标志栅格图提供 16、32、64、128、192、256、512 与 1024px 尺寸。
浅色与深色变体均有提供，唯 192px 栅格图仅有浅色（PWA `purpose: "any"`
安装图标）。站点图标使用简化的字母组合标记，
而非完整的编织标志，因此在浏览器标签页尺寸下仍保持清晰可辨。

## 留白

在所有侧边保持至少为 logo 高度 1/4 的留白。
不要将 logo 置于会使其难以辨识的背景上。
仅在小型方形表面使用站点图标的字母组合标记；在标志有足够空间舒展的任何地方，
使用完整的标志或文字标志。

## 允许的用法

- 链接到 Apothem 网站或仓库
- 关于 Apothem 的集成文档与博客文章
- 引用 Apothem 的演示文稿

## 禁止的用法

- 修改 logo 的形状、比例或编织图案
- 未经许可使用 logo 来暗示官方背书
- 以创造出新的复合标志的方式将 logo 与其他标志组合
