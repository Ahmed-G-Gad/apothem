Cet exemple ajoute une règle permanente propre au projet qui impose une convention de nommage à tous les fichiers.

## Fichier de la règle

```markdown
---
name: "kebab-filenames"
description: "Enforce kebab-case filenames in the src/ tree"
pathFilter: ""
alwaysApply: true
---

# Kebab-case filenames

All new files created under `src/` MUST use kebab-case naming
(lowercase letters, digits, and hyphens only — no underscores,
no camelCase, no PascalCase).

**Correct:** `src/styles/button-group.css`, `src/components/nav-bar.css`
**Incorrect:** `src/styles/buttonGroup.css`, `src/components/NavBar.css`

When in doubt, err on the side of more hyphens.
```

Enregistrez ceci dans `rules/kebab-filenames.md` au sein de la racine d'installation de votre environnement (`~/.claude/` pour l'adaptateur Claude Code ; pour les autres environnements, remplacez-la par leur chemin natif).

## Vérifier que la règle est bien formée

Lancez le validateur de frontmatter sur le fichier de règle que vous venez d'écrire. Depuis un checkout d'Apothem, faites précéder la commande de `PYTHONPATH=src` ; après une installation par script, faites-la précéder de `PYTHONPATH="$HOME/.apothem/src"` :

```bash
python -m apothem.conformity.gate --check frontmatter-grep ~/.claude/rules/kebab-filenames.md
```

Une règle bien formée signale une réussite sans réserve :

```json
{
  "orchestrator": "conformity-gate",
  "passed": true,
  "grep_count": 1
}
```

## Propager vers les environnements

Exécutez la commande de mise à jour une fois par environnement installé :

```bash
apothem update --harness claude-code
apothem update --harness cursor
```
