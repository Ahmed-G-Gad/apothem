Des parcours commentés, de bout en bout. Chaque parcours mène une seule tâche
d'un point de départ vierge jusqu'à un artefact terminé, en montrant les
commandes, les fichiers et le raisonnement à chaque étape.

Les projets d'exemple exécutables livrés avec le dépôt se trouvent dans le
répertoire
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) à la
racine du dépôt. Chaque projet est autonome et possède son propre README. Les
pages ci-dessous sont des parcours rédigés séparément de ces projets ; elles ne
les racontent pas.

## Pages

| Page | Description |
|------|-------------|
| [Créer un adaptateur d'environnement](/docs/examples/authoring-a-harness-adapter) | Guide pas à pas pour construire un nouvel adaptateur d'environnement à partir de zéro. |
| [Hook minimal](/docs/examples/minimal-hook) | Le plus petit hook Apothem possible — une vérification PreToolUse qui se déclenche à chaque écriture de fichier. |
| [Règle personnalisée](/docs/examples/custom-rule) | Rédiger une règle permanente propre au projet qui impose une convention de nommage. |
| [Parcours d'un plan](/docs/examples/plan-walkthrough) | Un parcours de bout en bout du pipeline `/plan` pour une tâche réelle. |
