Hermes lit `~/.hermes/config.yaml`. Apothem écrit la configuration YAML native
(en projetant l'inventaire MCP du profil dans `mcp_servers`) et installe les
cohortes partagées de commandes et de skills sous
`~/.hermes/.apothem/support/skills/`. Le `skills.config` propre à Hermes est
une liste de paquets de registre ; Apothem ne le rédige donc pas.

## Statut

**Aperçu.** L'adaptateur Hermes cible le fichier de configuration documenté
actuel et la surface de découverte des skills. Les cohortes autres que les
skills restent du matériel de support Apothem.

## Comparaison de l'effort

| Tâche | Configuration brute à la main | Géré par Apothem |
| ---- | --------------- | --------------- |
| Rédiger des skills réutilisables | Modifier à la main la configuration et les répertoires de skills | Écrire une seule fois dans le corpus partagé |
| Garder les cohortes alignées avec les autres environnements | Manuel, outil par outil | Automatique lors de `apothem update` |
| Installer / supprimer la configuration | Manuel | `apothem install` / `apothem uninstall` |
| Vérifier que la configuration est correcte | Inspection manuelle | `apothem verify --harness hermes` |

## Ce qu'Apothem gère

L'adaptateur Hermes écrit `config.yaml`, enveloppe les commandes slash
d'Apothem sous forme de skills, copie les skills d'Apothem dans le répertoire de
support, et conserve les règles, les templates, les agents et le matériel de
hooks sous la sous-arborescence de support d'Apothem. Hermes ne charge ces
skills qu'après que vous avez ajouté `~/.hermes/.apothem/support/skills` à
`skills.external_dirs` dans `config.yaml`.

## Chemin de migration

1. Exécutez `apothem profile init` pour créer le profil partagé si ce n'est pas
   encore fait.
2. Déplacez les skills ou les prompts de commande Hermes réutilisables dans le
   corpus partagé.
3. Exécutez `apothem install --harness hermes` pour générer la configuration
   native et le répertoire de skills de support.
4. Exécutez `apothem verify --harness hermes` pour confirmer que la
   configuration est bien en place.
