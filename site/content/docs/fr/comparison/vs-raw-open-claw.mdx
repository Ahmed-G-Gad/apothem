Open-Claw lit `~/.openclaw/openclaw.json`. Apothem installe des cohortes
partagées de commandes et de skills sous `~/.openclaw/.apothem/support/skills/`
et y écrit une seule clé, `skills.load.extraDirs`, qui liste ce répertoire afin
qu'OpenClaw charge les skills. Son `agents.defaults.skills` est une liste de noms
autorisés qui vous appartient et MCP est une surface de CLI, donc Apothem n'écrit
ni l'un ni l'autre.

## Statut

**Aperçu.** L'adaptateur Open-Claw cible le fichier de configuration actuellement
documenté et la surface supplémentaire de répertoire de skills. Les cohortes hors
skills restent du matériel de support Apothem.

## Comparaison d'effort

| Tâche | Config à la main brute | Géré par Apothem |
| ---- | --------------- | --------------- |
| Écrire des skills réutilisables | Modifier à la main la config et les répertoires de skills | Écrire une fois dans le corpus partagé |
| Garder les cohortes alignées avec les autres environnements | Manuel, par outil | Automatique lors d'`apothem update` |
| Installer / supprimer la config | Manuel | `apothem install` / `apothem uninstall` |
| Vérifier que la config est correcte | Inspection manuelle | `apothem verify --harness open-claw` |

## Ce que gère Apothem

L'adaptateur Open-Claw écrit `openclaw.json`, enveloppe les commandes en barre
oblique d'Apothem en skills, copie les skills d'Apothem dans le répertoire de
support référencé, et conserve les règles, modèles, agents et matériel de hooks
sous la sous-arborescence de support d'Apothem.
OpenClaw lit `skills.load.extraDirs` avec la priorité la plus basse de ses
sources de skills, donc un skill du même nom dans votre espace de travail,
`~/.agents/skills` ou `~/.openclaw/skills` est utilisé à la place de la copie
d'Apothem.

## Chemin de migration

1. Exécutez `apothem profile init` pour créer le profil partagé si ce n'est pas
   déjà fait.
2. Déplacez les skills ou les prompts de commandes réutilisables d'Open-Claw dans
   le corpus partagé.
3. Exécutez `apothem install --harness open-claw` pour générer la configuration
   native et le répertoire de skills de support.
4. Exécutez `apothem verify --harness open-claw` pour confirmer que la
   configuration a bien été posée.
