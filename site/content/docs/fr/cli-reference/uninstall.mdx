Supprime la configuration d'un adaptateur d'environnement.

## Synopsis

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

Supprime les cibles de l'environnement gérées par l'adaptateur, puis les
répertoires que l'installation a créés, une fois qu'ils sont vides (un
répertoire contenant quoi que ce soit qui vous appartient est conservé).
Demande une confirmation, sauf si
`--yes` est fourni. Lorsqu'aucune invite n'est possible — `--format json` (le
texte de l'invite corromprait l'unique document JSON) ou un shell non
interactif (sans TTY) —, la commande refuse d'emblée avec une erreur structurée
`uninstall.confirmation_required` (code de sortie 1), sauf si `--yes` est
fourni. Si un environnement sélectionné n'est pas installé, la commande réussit
(code de sortie 0) avec un avis « nothing to remove ».

Une suppression `--harness all` est délibérément exhaustive : elle couvre
chaque environnement enregistré, y compris ceux que le champ
`exclude_harnesses` du profil ignore lors de l'installation — le nettoyage
atteint l'état qu'une installation antérieure de portée plus large a pu
laisser derrière elle. Les environnements qui n'ont jamais été installés
signalent « nothing to remove ».

L'alias en forme continue `apothem uninstalling` se résout vers le même
gestionnaire.

## Options

| Option | Description |
|---|---|
| `--harness NAME` | Adaptateur d'environnement à supprimer, ou `all` pour l'ensemble couvrant tout le registre (obligatoire). |
| `--yes` | Ignore l'invite de confirmation. |
| `--project PATH` | Racine du projet pour les environnements à portée de projet. |
| `--quiet`, `-q` | Supprime la sortie informative ; seules les erreurs sont émises. |
| `--verbose`, `-v` | Émet une sortie de diagnostic supplémentaire. |
| `--format plain\|json` | Format de sortie (par défaut : `plain`). |
| `--json` | Raccourci de `--format json`. |
| `--no-color` | Désactive les codes de couleur ANSI dans la sortie. |
| `-h`, `--help` | Affiche l'aide et quitte. |

## Sortie JSON

Lorsque l'adaptateur est installé et supprimé avec succès :

```json
{"schema_version": 1, "action": "uninstalled", "harness": "claude-code", "output_path": "..."}
```

Lorsque l'adaptateur n'était pas installé :

```json
{"schema_version": 1, "status": "not_installed", "harness": "claude-code"}
```

## Exemples

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem Uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## Codes de sortie

| Code | Signification |
|---|---|
| 0 | Adaptateur désinstallé, ou qui n'était pas installé |
| 1 | Environnement introuvable, confirmation refusée ou impossible (mode non interactif ou JSON sans `--yes`), ou échec de chaque suppression |
| 2 | Suppression partielle — au moins un environnement a été supprimé avant un échec |
| 64 | Erreur d'utilisation : une option ou une commande inconnue, ou une valeur d'option manquante ou invalide. Sous `--json`, l'erreur est une enveloppe JSON avec le code `cli.usage`. |
