Supprime la configuration d'un adaptateur de harness.

## Synopsis

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

Supprime les cibles du harness gérées par l'adaptateur. Demande une confirmation à moins que `--yes` ne soit fourni. Si un harness sélectionné n'est pas installé, la commande réussit (code de sortie 0) avec un avis « nothing to remove ».

L'alias en forme continue `apothem uninstalling` se résout vers le même gestionnaire.

## Options

| Option | Description |
|---|---|
| `--harness NAME` | Adaptateur de harness à supprimer, ou `all` pour l'ensemble de tout le registre (obligatoire). |
| `--yes` | Ignore l'invite de confirmation. |
| `--project PATH` | Racine du projet pour les harness à portée de projet. |
| `--quiet`, `-q` | Supprime la sortie informative ; seules les erreurs sont émises. |
| `--verbose`, `-v` | Émet une sortie de diagnostic supplémentaire. |
| `--format plain\|json` | Format de sortie (par défaut : `plain`). |
| `--json` | Raccourci pour `--format json`. |
| `--no-color` | Désactive les codes de couleur ANSI dans la sortie. |
| `-h`, `--help` | Affiche l'aide et quitte. |

## Sortie JSON

Lorsque l'adaptateur est installé et supprimé avec succès :

```json
{"action": "uninstalled", "harness": "claude-code", "output_path": "..."}
```

Lorsque l'adaptateur n'était pas installé :

```json
{"status": "not_installed", "harness": "claude-code"}
```

## Exemples

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem Uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## Codes de sortie

| Code | Signification |
|---|---|
| 0 | Adaptateur désinstallé, ou n'était pas installé |
| 1 | Harness introuvable, ou l'utilisateur a annulé l'invite de confirmation |
