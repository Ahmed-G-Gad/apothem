Liste et inspecte les adaptateurs d'environnement enregistrés.

`harnesses` est un groupe de commandes doté de deux sous-commandes : `list` et
`show`.

## Synopsis

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## Sous-commandes

### `harnesses list`

Liste tous les adaptateurs d'environnement enregistrés.

| Option | Description |
|---|---|
| `--quiet`, `-q` | Supprime la sortie informative ; seules les erreurs sont émises. |
| `--verbose`, `-v` | Émet une sortie de diagnostic supplémentaire. |
| `--format plain\|json` | Format de sortie (par défaut : `plain`). |
| `--json` | Raccourci de `--format json`. |
| `--no-color` | Désactive les codes de couleur ANSI dans la sortie. |
| `-h`, `--help` | Affiche l'aide et quitte. |

### `harnesses show NAME`

Affiche les détails d'un adaptateur d'environnement spécifique. `NAME` est
l'identifiant de l'environnement en kebab-case ; exécutez
`apothem harnesses list` pour voir les identifiants disponibles.

| Option | Description |
|---|---|
| `NAME` | Adaptateur d'environnement à inspecter (argument positionnel obligatoire). |
| `--quiet`, `-q` | Supprime la sortie informative ; seules les erreurs sont émises. |
| `--verbose`, `-v` | Émet une sortie de diagnostic supplémentaire. |
| `--format plain\|json` | Format de sortie (par défaut : `plain`). |
| `--json` | Raccourci de `--format json`. |
| `--no-color` | Désactive les codes de couleur ANSI dans la sortie. |
| `-h`, `--help` | Affiche l'aide et quitte. |

## Exemples

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

Les identifiants d'environnement enregistrés sont :

## Codes de sortie

| Code | Signification |
|---|---|
| 0 | Succès |
| 1 | Environnement introuvable (`harnesses show` avec un `NAME` inconnu), ou tous les adaptateurs ont échoué à se charger ou à produire leur rapport (`harnesses list`) |
| 2 | Au moins un adaptateur listé, mais au moins un adaptateur n'a pas pu produire son rapport (`harnesses list`) |
| 64 | Erreur d'utilisation : une option ou une commande inconnue, ou une valeur d'option manquante ou invalide. Sous `--json`, l'erreur est une enveloppe JSON avec le code `cli.usage`. |
