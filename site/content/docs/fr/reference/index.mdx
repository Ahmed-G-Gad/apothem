Référence par classe d'artefact. Chaque page décrit la finalité de la classe, sa disposition sur disque, le contrat de frontmatter et le registre qui liste chaque instance.

Les chemins relatifs au dépôt sont indiqués ci-dessous ; chaque adaptateur les matérialise dans son répertoire de configuration natif (p. ex. `~/.claude/` pour l'adaptateur Claude Code ; voir [`site/content/docs/harnesses/<harness>.mdx`](/docs/harnesses) pour les destinations propres à chaque environnement).
