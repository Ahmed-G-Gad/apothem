`settings.json` porte la configuration du harness Claude Code : câblage des hooks,
permissions d'outils, variables d'environnement et réglages de la ligne d'état.

La référence canonique complète vit dans
[settings-reference.md](/docs/reference/settings-reference). Cette page résume le contrat
et pointe vers la référence plus approfondie.

## Sections

| Section | Objet |
|---------|---------|
| `permissions` | Listes blanches et noires d'outils par matcher |
| `hooks` | Table de commandes de hook indexée par événement (le câblage canonique) |
| `env` | Variables d'environnement par session |
| `statusLine` | Modèle de ligne d'état que l'hôte rend |

## Invariant de modèle unique

L'adaptateur Claude Code livre un seul modèle `settings.json`. Les commandes de
hook utilisent la forme exec (`command` plus `args`) au lieu de chaînes de commande
spécifiques au shell, de sorte que le comportement multi-OS est revu au sein d'un
unique fichier. Les nouvelles entrées de permissions et les événements de hook
atterrissent dans ce fichier de façon atomique.
