## GitHub Discussions

Le principal lieu d'échange de la communauté est [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).

Catégories :

| Catégorie | À utiliser pour |
|----------|---------|
| Q&A | Questions sur l'usage, la configuration et le comportement |
| Ideas | Demandes de fonctionnalités et discussions de conception |
| Show and tell | Partagez comment vous utilisez Apothem |
| General | Tout le reste |

## Issues

Pour les bugs et les demandes de fonctionnalités concrètes, utilisez
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues).

Avant d'ouvrir une issue, cherchez parmi les issues et discussions existantes
pour éviter les doublons.

## Contribuer

Voir [Contribuer](/docs/developer-guide) pour savoir comment contribuer du code,
de la documentation et des adaptateurs d'environnement. Commencez par le
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
du dépôt et le modèle de pull request auquel il renvoie.
