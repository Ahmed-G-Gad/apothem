## Version actuelle

- Stabiliser les dix-sept adaptateurs d'environnement.
- Compléter l'infrastructure d'audit et de revue.
- Stabiliser la surface CLI d'Apothem.
- Établir le pipeline de CI/CD GitHub Actions.

## À court terme

- Faire mûrir la distribution npm / npx : maintenir le point d'entrée
  `@ahmed-g-gad/apothem` aligné sur chaque version et élargir sa couverture de
  plateformes.
- Développer la fiche du plugin Claude Code à mesure que la surface de la
  place de marché se stabilise.
- Mise à jour automatique des adaptateurs d'environnement via
  `apothem update --watch`.
- Outillage de versionnage et de migration des profils.
- Validation du schéma de profil partagé dans la porte de conformité.
- Adaptateurs d'environnement supplémentaires selon les demandes de la
  communauté.

## À plus long terme

- Synchronisation de profil hébergée dans le cloud (optionnelle, contrôlée par
  l'opérateur).
- Extension VS Code pour un retour de conformité en temps réel.
- Gestion de profil partagé en équipe.
