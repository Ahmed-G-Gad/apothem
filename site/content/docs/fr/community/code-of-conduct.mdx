Apothem s'engage à offrir un environnement accueillant et inclusif à tous les
contributeurs et utilisateurs.

## Nos standards

- Employer un langage accueillant et inclusif.
- Respecter les points de vue et les expériences différents.
- Accepter avec bienveillance les critiques constructives.
- Se concentrer sur ce qui est le mieux pour la communauté.
- Faire preuve d'empathie envers les autres membres de la communauté.

## Comportements inacceptables

- Le harcèlement sous toutes ses formes.
- Le langage ou les actes discriminatoires.
- Le trollage, les insultes ou les attaques personnelles.
- La publication d'informations privées d'autrui sans autorisation.

## Signalement

Signalez les violations à [me@ahmedgad.com](mailto:me@ahmedgad.com).

## Application

Les mainteneurs du projet examineront les signalements et prendront les mesures
appropriées, y compris des bannissements temporaires ou permanents pour les
violations graves.

Ce code de conduite est adapté du
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
