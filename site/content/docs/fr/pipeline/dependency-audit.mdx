**Rôle :** Auditeur de dépendances
**Position dans le pipeline :** forteresse

Passe d'audit par dépendance (directes + transitives) pour la licence, les CVE et la fraîcheur.

## Invocation canonique

```bash
/dependency-audit
```

Avec des arguments :

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## Entrées

Manifestes de dépendances du dépôt hôte

## Sorties

Constats sur les dépendances dans `_inputs/dependency-audit-findings.md`

## En aval

L'étape dependency-audit de la Séquence de Relecture d'Audit

## Phases du flux de travail

La commande exécute cinq phases : ingestion des entrées, parcours dépendance par dépendance, tri constat par constat, émission des constats, et le portail de validation.

## Modes d'échec

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Portail de qualité FAIL | La sortie ne respecte pas les normes | Corrigez la sortie et relancez |
| Fichier d'entrée manquant | Aucun manifeste de dépendances ne se résout à la racine du dépôt | Passez une racine de dépôt qui contient un manifeste de dépendances |

## Exemples

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
