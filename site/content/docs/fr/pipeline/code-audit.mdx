**Rôle :** Auditeur
**Position dans le pipeline :** forteresse

Audit de code forensique inter-fichiers à l'échelle du corpus du dépôt.

## Invocation canonique

```bash
/code-audit
```

Avec arguments :

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## Entrées

Dépôt hôte avec une disposition des sources approuvée, une base de référence de couverture des tests et, au niveau SHARED+, un portail CI au vert

## Sorties

Constats au niveau du corpus dans `_inputs/code-audit-findings.md`

## En aval

L'étape d'audit de code forensique de la Séquence de revue d'audit

## Phases du flux de travail

La commande exécute six phases d'analyse forensique : ingestion des entrées, parcours des dépendances inter-fichiers, audit des annotations de types et de la couverture, détection du code mort et des doublons, audit de l'intégrité architecturale, et émission des constats avec le portail de validation.

## Modes de défaillance

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Portail de qualité FAIL | La sortie ne respecte pas les normes | Corrigez la sortie et relancez |
| Fichier d'entrée manquant | Aucune exécution du portail CI ni base de référence de couverture des tests au niveau SHARED+ | Exécutez d'abord le pipeline CI de l'hôte, puis relancez |

## Exemples

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
