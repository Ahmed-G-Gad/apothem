**Rôle :** Relecteur d'architecture
**Position dans le pipeline :** forteresse

Revue d'intégrité architecturale par rapport à l'artefact de conception dans `_inputs/design.md`.

## Invocation canonique

```bash
/architecture-review
```

Avec des arguments :

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Entrées

Dépôt hôte + `_inputs/design.md`

## Sorties

Constats d'architecture dans `_inputs/architecture-review-findings.md`

## En aval

L'étape de revue d'architecture de la Séquence de Revue d'Audit

## Phases du flux de travail

La commande exécute cinq phases d'audit : ingestion des entrées, parcours de traçabilité de la conception au code, audit de l'intégrité des frontières de couches, balayage du couplage inter-paquets, et émission des constats avec le portail de validation.

## Modes d'échec

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Portail de qualité FAIL | La sortie ne respecte pas les normes | Corrigez la sortie et relancez |
| Fichier d'entrée manquant | L'artefact de conception `_inputs/design.md` est absent | Exécutez `/plan-design` pour le créer |

## Exemples

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
