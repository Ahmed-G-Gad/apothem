**Rôle :** Exécuteur
**Position dans le pipeline :** terminal

Exécute une phase précise d'une Suite de Plan Maître avec vérification de conformité.

## Invocation canonique

```bash
/plan-execute
```

Avec des arguments :

```bash
/plan-execute [path/to/plan-suite/] [phase-id] [--dry-run]
```

## Entrées

Suite de planification générée + relue ; `_inputs/handoff-manifest.yml` relu

## Sorties

Fichiers REPORT.md par phase, artefacts de la base de code, COMPLETION.md

## En aval

`/fortress` durcit le travail exécuté jusqu'à un état validé par les portails d'aptitude à la publication, en un seul appel (détection, vérification, remédiation, nouvel audit, portail). Par défaut, il marque une pause pour confirmation à la fin de chaque tour ; `--autonomous` exécute les tours sans pause. `/code-review` — le point d'entrée canonique de la séquence de revue d'audit à onze commandes, qui parcourt la chaîne une étape à la fois. `/plan-execute` est l'étape terminale du pipeline de *plan* ; lorsque la phase finale s'achève, le code construit passe à la forteresse d'audit pour relecture.

## Phases du flux de travail

La commande suit le flux de travail standard du pipeline `/plan` :

1. **Charger le contexte** — Lit la suite de planification, les règles et le Contrat de Reprise.
2. **Vérifier les prérequis** — Confirme que les phases de dépendance sont terminées.
3. **Exécuter les tâches** — Accomplit la mission de la commande.
4. **Vérifier les sorties** — Confirme que toutes les sorties déclarées existent et passent les portails de qualité.
5. **Émettre REPORT.md** — Le résultat du portail de pré-émission est consigné.
6. **Mettre à jour PROGRESS.md** — Consigne les sorties vérifiées dans le Registre des Sorties de Phase.

## Modes d'échec

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Prérequis incomplet | Phase dépendante non terminée | Terminez d'abord la phase en amont |
| Portail de qualité FAIL | La sortie ne respecte pas les normes | Corrigez la sortie et relancez |
| Fichier d'entrée manquant | Fichier de suite de planification absent | Exécutez `/plan-generate` pour le créer |

## Exemples

```bash
# Dry-run to preview what would happen
/plan-execute --dry-run

# Execute against a named plan suite
/plan-execute path/to/plan-suite/
```
