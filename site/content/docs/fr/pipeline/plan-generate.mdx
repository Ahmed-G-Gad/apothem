**Rôle :** Générateur
**Position dans le pipeline :** intermédiaire

Génère une Suite de Plan Maître complète à partir du `_spec/spec.md` rédigé.

## Invocation canonique

```bash
/plan-generate
```

Avec des arguments :

```bash
/plan-generate [path/to/prose.md] [--mode NEW|OVERHAUL] [--seriousness LEVEL] [--context CONTEXT] [--mission MISSION] [--domain DOMAIN] [--dry-run]
```

## Entrées

Le `_spec/spec.md` rédigé + `_inputs/handoff-manifest.yml` issu de `/plan-spec` (ou de la prose fournie par l'opérateur).

## Sorties

`PREAMBLE.md`, `MASTER-PLAN.md`, `PROGRESS.md`, `PLAN-NOTES.md`, et les fichiers `phases/**/PHASE.md` par phase, ainsi que le `_inputs/handoff-manifest.yml` augmenté.

## En aval

/plan-review ou /plan-execute (en aval)

## Phases du flux de travail

La commande génère une Suite de Plan Maître complète à partir de la spec rédigée :

1. **Ingérer les exigences** — Lire `_spec/spec.md` et le manifeste de transfert en amont ; refuser avec `Blocked: run /plan-spec first` lorsque la spec est absente.
2. **Découvrir** — Exécuter une découverte calibrée sur la gravité avec les Cinq Filtres Cognitifs ; résoudre chaque lacune de donnée faisant autorité via le canal d'interrogation structurée.
3. **Décomposer** — Découper le travail en un graphe de phases acyclique avec un ordre de dépendance explicite.
4. **Émettre la suite** — Rédiger `PREAMBLE.md`, `MASTER-PLAN.md`, `PROGRESS.md`, `PLAN-NOTES.md`, et chaque `phases/NN-topic/PHASE.md`.
5. **Exécuter la porte de pré-émission** — Exécuter le balayage à quinze barres sur chaque artefact émis ; un échec bloque l'approbation de l'opérateur jusqu'à résolution.

## Modes de défaillance

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Blocked: run /plan-spec first | Aucun `_spec/spec.md` rédigé | Exécutez `/plan-spec` pour rédiger la spec et émettre le manifeste |
| Génération sur un fichier `_inputs/` | La spec est encore en cours d'élicitation | Promouvez d'abord `_inputs/forge.md` vers `_spec/spec.md` via `/plan-spec` |
| Une barre de pré-émission échoue | Un artefact émis échoue à la porte | Corrigez la barre défaillante avant l'approbation de l'opérateur |

## Exemples

```bash
# Dry-run pour prévisualiser le graphe de phases généré
/plan-generate --dry-run

# Générer une suite à partir de prose rédigée
/plan-generate path/to/prose.md --mode NEW
```
