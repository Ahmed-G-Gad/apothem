**Rôle :** Auditeur de la chaîne d'approvisionnement
**Position dans le pipeline :** forteresse

Audit de la chaîne d'approvisionnement face aux normes SLSA + Sigstore + SBOM.

## Invocation canonique

```bash
/supply-chain-audit
```

Avec des arguments :

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## Entrées

Pipeline de publication du dépôt hôte

## Sorties

Constats de la chaîne d'approvisionnement dans `_inputs/supply-chain-audit-findings.md`

## En aval

L'étape supply-chain-audit de la Séquence de Relecture d'Audit

## Phases du flux de travail

La commande exécute cinq phases d'audit : ingestion des entrées, parcours axe par axe, tri constat par constat, émission des constats, et le portail de validation.

## Modes d'échec

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Prérequis incomplet | Phase dépendante non terminée | Achevez d'abord la phase amont |
| Porte qualité FAIL | La sortie ne respecte pas les normes | Corrigez la sortie et relancez |
| Cible refusée | La cible ne possède aucune surface de publication | Passez une racine de dépôt qui contient .github/workflows/, un script de publication ou un manifeste de build |

## Exemples

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
