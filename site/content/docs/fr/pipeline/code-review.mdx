**Rôle :** Relecteur
**Position dans le pipeline :** forteresse

Passe de relecture de qualité du code, fichier par fichier, pilotée par l'opérateur, à travers src/, scripts/ et tools/.

## Invocation canonique

```bash
/code-review
```

Avec des arguments :

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Entrées

Dépôt hôte dans n'importe quel état du cycle de vie

## Sorties

Constats fichier par fichier dans `_inputs/code-review-findings.md`

## En aval

L'étape de relecture ligne par ligne de la Séquence de Relecture d'Audit

## Phases du flux de travail

La commande exécute cinq phases : ingestion des entrées, parcours fichier par fichier, tri constat par constat, émission des constats, et le portail de validation.

## Modes d'échec

| Symptôme | Cause | Récupération |
|---------|-------|----------|
| Porte qualité FAIL | La sortie ne respecte pas les normes | Corrigez la sortie et relancez |
| Fichier d'entrée manquant | Le dépôt ne contient ni `src/`, ni `scripts/`, ni `tools/` | Passez une racine de dépôt qui contient au moins l'un d'eux |

## Exemples

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
