## Installer un adaptateur d'environnement

```bash
apothem install --harness <name>
```

Consultez la [liste des environnements pris en charge](/docs/harnesses) pour connaître les noms disponibles.
Les adaptateurs à portée de projet nécessitent le chemin du projet :

```bash
apothem install --harness cursor --project /path/to/project
apothem install --harness gemini-cli --project /path/to/project
apothem install --harness github-copilot --project /path/to/project
apothem install --harness windsurf --project /path/to/project
```

## Installer plusieurs environnements

Utilisez le sélecteur couvrant tout le registre lorsque vous voulez chaque adaptateur pris en charge. Comme
l'ensemble enregistré inclut des adaptateurs à portée de projet, indiquez la racine du projet.

```bash
apothem install --harness claude-code
apothem install --harness cursor --project /path/to/project
apothem install --harness all --project /path/to/project
```

## Vérifier la configuration de l'environnement

```bash
apothem verify --harness <name>
apothem verify --harness all --project /path/to/project
```

Pour vérifier d'un seul coup chaque adaptateur enregistré, exécutez `apothem doctor`. La commande affiche un tableau de l'état d'installation par environnement et ne se termine avec un code non nul que si un contrôle échoue, par exemple un environnement installé qui ne passe pas la vérification, une commande de hook qui ne peut pas démarrer, ou un profil présent qui ne passe pas la validation. Un environnement non installé est listé mais ne fait pas échouer `doctor`.

## Afficher les environnements installés

```bash
apothem harnesses list
```

Passez `apothem harnesses show <name>` pour obtenir le détail par adaptateur (nom, état
d'installation et chemin de sortie).
