सपाट फ़ाइलों के रूप में रहते हैं। विहित पथ है:

```text
src/apothem/agents/
```

प्रत्येक सहायक अपने स्वयं के टूल प्रतिबंधों और सिस्टम प्रॉम्प्ट के साथ एक
रिसर्च, ऑडिट, गुणवत्ता, या ऑर्केस्ट्रेशन भूमिका है।

| सहायक | फ़ाइल | पैटर्न | मॉडल नीति |

| Convention Auditor | नीचे मैनिफ़ेस्ट पथ देखें | ऑडिट | होस्ट-चयनित |

विहित मैनिफ़ेस्ट पथ:

```text

src/apothem/agents/quality-gate.md

```

## Frontmatter कॉन्ट्रैक्ट

```yaml
---
name: <agent name>
version: <semver>
updated: <YYYY-MM-DD>
description: <one-line role>
tools: <comma-separated tool list>
disallowedTools: <comma-separated deny list>
maxTurns: <integer>
---
```

## ऑर्केस्ट्रेशन

सहायक परिनियोजन, समानांतर-लॉन्च प्रोटोकॉल, रिटर्न-कॉन्ट्रैक्ट प्रवर्तन,
और आइसोलेशन अनुशासन ऑर्केस्ट्रेशन नियम में रहते हैं। प्रति-पेशेवर डिस्पैच
ट्री ऑर्केस्ट्रेशन पैटर्न नियम, §Decision Tree में रहता है। विहित पथ:

```text
src/apothem/rules/agent-orchestration.md
src/apothem/rules/agent-orchestration-patterns.md
```
