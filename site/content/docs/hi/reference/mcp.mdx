Model Context Protocol (MCP) सर्वर **ऑपरेटर-स्वामित्व वाले** हैं। Apothem साझा
प्रोफ़ाइल में MCP इन्वेंट्री वहन करता है और उसे प्रत्येक टूल के नेटिव MCP सतह में
प्रक्षेपित करता है, परंतु अपनी ओर से कोई सर्वर एंट्री नहीं लिखता — यह सतह प्रबंधित
करने के लिए आपकी ही रहती है।

## MCP सर्वर कहाँ पंजीकृत होते हैं

प्रत्येक टूल अपने नेटिव तंत्र के माध्यम से MCP सर्वर पंजीकृत करता है, और Apothem उस
सतह को अधिलेखित करने के बजाय उसका सम्मान करता है। Claude Code अडैप्टर (अनेक में से एक)
पर, सर्वर `claude mcp add` के साथ `~/.claude.json` (उपयोगकर्ता या लोकल स्कोप) तथा
प्रोजेक्ट-स्तरीय `.mcp.json` में पंजीकृत होते हैं; अन्य अडैप्टर अपनी-अपनी नेटिव सतहों
में प्रक्षेपित करते हैं। Apothem की प्रबंधित सेटिंग्स कभी `mcpServers` ब्लॉक वहन नहीं करतीं।

## एक सर्वर जोड़ना

अपने टूल के नेटिव तंत्र के माध्यम से एक सर्वर पंजीकृत करें; विहित एंट्री आकृति
`mcpServers` के अंतर्गत एक कुंजी है:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

टूल का रनटाइम सत्र आरंभ पर पंजीकृत सर्वर लोड करता है; नए सर्वर लेने के लिए टूल को
पुनः आरंभ करें।

## नामकरण कन्वेंशन

MCP टूल, टूल के मानक MCP-टूल नामकरण कन्वेंशन के अनुसार सहायक को
`mcp__<server>__<tool>` के रूप में सामने आते हैं।
