Model Context Protocol (MCP) सर्वर **ऑपरेटर-स्वामित्व वाले** हैं। Apothem MCP
इन्वेंट्री को साझा प्रोफ़ाइल (`mcp_servers`) में वहन करता है। जिस अडैप्टर का टूल
अपने MCP सर्वर किसी ऐसी कॉन्फ़िग फ़ाइल में रखता है जिसे Apothem पहले से लिखता है,
वह अडैप्टर उस इन्वेंट्री को उस फ़ाइल में प्रक्षेपित करता है; हर अन्य अडैप्टर कोई
सर्वर प्रविष्टि नहीं लिखता, और सर्वरों को टूल के माध्यम से पंजीकृत करना आपके ही
ज़िम्मे रहता है।

## MCP सर्वर कहाँ पंजीकृत होते हैं

प्रत्येक टूल अपने नेटिव तंत्र के माध्यम से MCP सर्वर पंजीकृत करता है, और Apothem
उस सतह को अधिलेखित करने के बजाय उसका सम्मान करता है। Claude Code पर, सर्वर
`claude mcp add` के साथ `~/.claude.json` (उपयोगकर्ता या लोकल दायरा) और एक
प्रोजेक्ट-स्तरीय `.mcp.json` में पंजीकृत होते हैं; Claude Code अडैप्टर इनमें से
कोई भी फ़ाइल नहीं लिखता, और Apothem की प्रबंधित Claude Code सेटिंग्स कभी कोई
`mcpServers` ब्लॉक नहीं रखतीं।

## सर्वर जोड़ना

अपने टूल के नेटिव तंत्र के माध्यम से सर्वर पंजीकृत करें; विहित प्रविष्टि आकार
`mcpServers` के अंतर्गत एक कुंजी है:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

टूल का रनटाइम सत्र आरंभ पर पंजीकृत सर्वर लोड करता है; नए सर्वर ग्रहण करने के लिए
टूल को पुनः आरंभ करें।

## नामकरण परिपाटी

MCP टूल, टूल की मानक MCP-टूल नामकरण परिपाटी के अनुसार, सहायक के सामने
`mcp__<server>__<tool>` के रूप में आते हैं।
