Model Context Protocol (MCP) सर्वर **ऑपरेटर-स्वामित्व वाले** हैं। Apothem MCP
इन्वेंट्री को साझा प्रोफ़ाइल (`mcp_servers`) में वहन करता है। जिस अडैप्टर का टूल
अपने MCP सर्वर किसी ऐसी कॉन्फ़िग फ़ाइल में रखता है जिसे Apothem पहले से लिखता है,
वह अडैप्टर उस इन्वेंट्री को उस फ़ाइल में प्रक्षेपित करता है; हर अन्य अडैप्टर कोई
सर्वर प्रविष्टि नहीं लिखता, और सर्वरों को टूल के माध्यम से पंजीकृत करना आपके ही
ज़िम्मे रहता है।

## MCP सर्वर कहाँ पंजीकृत होते हैं

प्रत्येक टूल अपने नेटिव तंत्र के माध्यम से MCP सर्वर पंजीकृत करता है, और Apothem
उस सतह को अधिलेखित करने के बजाय उसका सम्मान करता है। Claude Code पर, सर्वर
`claude mcp add` के साथ `~/.claude.json` (उपयोगकर्ता या लोकल दायरा) और एक
प्रोजेक्ट-स्तरीय `.mcp.json` में पंजीकृत होते हैं; Claude Code अडैप्टर इनमें से
कोई भी फ़ाइल नहीं लिखता, और Apothem की प्रबंधित Claude Code सेटिंग्स कभी कोई
`mcpServers` ब्लॉक नहीं रखतीं।

## किसी सहायक को MCP सर्वरों तक पहुँच दें

केवल-पठन अनुसंधान एजेंट (`research-scout`, `citation-auditor`)
`Read, Glob, Grep, WebSearch, WebFetch` की स्पष्ट `tools` सूची के साथ शिप होते
हैं। Claude Code किसी MCP टूल को किसी सबएजेंट की स्पष्ट सूची में केवल तब स्वीकार
करता है जब कोई प्रविष्टि सर्वर का नाम `mcp__<server>__*` के रूप में देती है।
प्रोफ़ाइल की `agent_mcp_servers` कुंजी प्रति एजेंट उन सर्वरों के नाम देती है:

```yaml
agent_mcp_servers:
  research-scout:
    - "your-scholarly-server"
  citation-auditor:
    - "your-scholarly-server"
```

Claude Code इंस्टॉल हर सूचीबद्ध एजेंट की `tools` पंक्ति में प्रति नामित सर्वर एक
`mcp__<server>__*` प्रविष्टि जोड़ता है, और किसी अन्य एजेंट या पंक्ति को नहीं
बदलता। कुंजी के बिना हर एजेंट सादी सूची रखता है, इसलिए कोई एजेंट किसी MCP टूल तक
नहीं पहुँचता। हर सर्वर नाम वैसे ही लिखें जैसे `/mcp` उसे दिखाता है। Claude Code
टूल नामों में `:` और `.` को `_` के रूप में लिखता है, इसलिए इंस्टॉल सर्वर
`plugin:bio-research:biorxiv` को `mcp__plugin_bio-research_biorxiv__*` के रूप में
रेंडर करता है। किसी नाम में अक्षर, अंक, `-`, `_`, `:` और `.` होते हैं, वह किसी
अक्षर या अंक से शुरू और समाप्त होता है, और उसमें `_`, `:` और `.` में से कोई दो
कभी लगातार नहीं आते (रेंडर की गई प्रविष्टि में `__` आ जाएगा); `*`, व्हाइटस्पेस और
हर अन्य वर्ण अस्वीकार किए जाते हैं।
कोई अनुदान उस सर्वर के हर टूल का नाम देता है, जिसमें लिखने वाला कोई भी टूल शामिल
है, इसलिए केवल उसी सर्वर का अनुदान दें जिस पर आप खोजों के लिए भरोसा करते हैं;
एजेंटों के निर्देश उन्हें खोजों तक सीमित करते हैं, लेकिन हार्नेस केवल उन्हीं नामों
को लागू करता है जिन्हें आप सूचीबद्ध करते हैं। ऐसे एजेंट के लिए अनुदान जो मौजूद
नहीं है, या जिसकी कोई स्पष्ट `tools` सूची नहीं है, रिपोर्ट किया जाता है और छोड़
दिया जाता है। `harnesses.claude-code` के अंतर्गत एक प्रति-हार्नेस ओवरराइड साझा
सूचियों में जुड़ जाता है।

अनुदान `Claude Code` और `Gemini CLI` पर इंजन इंस्टॉल (`apothem install`) पर लागू
होता है। `Gemini CLI` पर इंस्टॉल सूचीबद्ध एजेंट की `tools` अनुमति-सूची में प्रति
नामित सर्वर एक `mcp_<server>_*` प्रविष्टि जोड़ता है, उदाहरण के लिए
`mcp_your-scholarly-server_*`, और किसी अन्य एजेंट या पंक्ति को नहीं बदलता।
`Gemini CLI` हर MCP टूल को `mcp_{serverName}_{toolName}` नाम देता है और सर्वर को
`mcp_` के बाद पहले अंडरस्कोर तक के पाठ से पढ़ता है, इसलिए अंडरस्कोर वाले सर्वर
नाम को वहाँ संबोधित नहीं किया जा सकता। Apothem `Gemini CLI` अनुदान केवल अक्षरों,
अंकों और `-` से बने नाम के लिए लिखता है: अंडरस्कोर, कोलन या पीरियड वाला नाम
`Claude Code` के लिए मान्य है लेकिन `Gemini CLI` के लिए छोड़ दिया जाता है और
रिपोर्ट किया जाता है, कभी किसी अन्य नाम में फिर से नहीं लिखा जाता। जो एजेंट पहले
से हर MCP सर्वर तक पहुँचता है (कोई `tools` सूची नहीं, या ऐसी सूची जिसमें `mcp_*`
है) उसे अपरिवर्तित छोड़ दिया जाता है और रिपोर्ट किया जाता है। `Gemini CLI` में कोई
deny सूची नहीं है, इसलिए जिस सर्वर का नाम एजेंट का अपना `disallowedTools` देता है
उसे कोई प्रविष्टि नहीं मिलती और उसे रिपोर्ट किया जाता है: अस्वीकृति जीतती है, जैसे
`Claude Code` पर। Gemini अनुदान साझा `agent_mcp_servers` सूचियाँ और
`harnesses.gemini-cli` ओवरराइड पढ़ता है, `harnesses.claude-code` वाला नहीं। अन्य
हार्नेस कुंजी को अनदेखा करते हैं: `Qwen Code` `tools` के लिए कोई प्रति-सर्वर
प्रविष्टि प्रलेखित नहीं करता; `OpenCode` अनुमतियों के माध्यम से टूल नियंत्रित करता
है; `Codex` और `Antigravity` कोई टूल सूची उत्सर्जित नहीं करते।

Claude Code प्लगइन बिना प्रोफ़ाइल के जोड़ा जाता है, इसलिए उसके दो एजेंट सादी सूची
रखते हैं। प्लगइन फ़ाइलें संपादित किए बिना उन्हें कनेक्टर पहुँच देने के लिए,
`~/.claude/agents/` में अपनी पसंद के नाम के अंतर्गत अपना स्वयं का एक
उपयोगकर्ता-स्तरीय एजेंट परिभाषित करें, जो वही केवल-पठन `tools` सूची और साथ में
आपकी इच्छित `mcp__<server>__*` प्रविष्टियाँ रखता हो।

## सर्वर जोड़ना

अपने टूल के नेटिव तंत्र के माध्यम से सर्वर पंजीकृत करें; विहित प्रविष्टि आकार
`mcpServers` के अंतर्गत एक कुंजी है:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

टूल का रनटाइम सत्र आरंभ पर पंजीकृत सर्वर लोड करता है; नए सर्वर ग्रहण करने के लिए
टूल को पुनः आरंभ करें।

## नामकरण परिपाटी

MCP टूल, टूल की मानक MCP-टूल नामकरण परिपाटी के अनुसार, सहायक के सामने
`mcp__<server>__<tool>` के रूप में आते हैं।
