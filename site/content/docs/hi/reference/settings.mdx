`settings.json` Claude Code harness के कॉन्फ़िगरेशन को वहन करता है: हुक वायरिंग,
टूल अनुमतियाँ, एनवायरनमेंट वेरिएबल, और स्टेटस-लाइन सेटिंग्स।

पूर्ण विहित संदर्भ
[settings-reference.md](/docs/reference/settings-reference) पर रहता है। यह पृष्ठ कॉन्ट्रैक्ट का
सारांश देता है और गहन संदर्भ की ओर इशारा करता है।

## अनुभाग

| अनुभाग | प्रयोजन |
|---------|---------|
| `permissions` | प्रति matcher टूल व्हाइटलिस्ट और ब्लैकलिस्ट |
| `hooks` | इवेंट-कुंजीबद्ध हुक कमांड तालिका (विहित वायरिंग) |
| `env` | प्रति-सत्र एनवायरनमेंट वेरिएबल |
| `statusLine` | स्टेटस-लाइन टेम्पलेट जिसे होस्ट रेंडर करता है |

## एकल-टेम्पलेट अपरिवर्त्य

Claude Code अडैप्टर एक ही `settings.json` टेम्पलेट भेजता है। हुक कमांड
shell-विशिष्ट कमांड स्ट्रिंग के बजाय exec रूप (`command` और `args`) का उपयोग करते
हैं, इसलिए क्रॉस-OS व्यवहार एक ही फ़ाइल के भीतर समीक्षित होता है। नई अनुमति
प्रविष्टियाँ और हुक इवेंट उस फ़ाइल में परमाणविक रूप से उतरते हैं।
