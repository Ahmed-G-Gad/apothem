`apothem` CLI साझा प्रोफ़ाइल और टूल अडैप्टर के प्रबंधन के लिए प्राथमिक ऑपरेटर
इंटरफ़ेस है।

## ग्लोबल फ़्लैग

| फ़्लैग | विवरण |
|------|-------------|
| `--version` | Apothem संस्करण प्रिंट करें और बाहर निकलें |
| `--help` | कमांड के लिए सहायता प्रिंट करें |

## उपकमांड

### `apothem install`

साझा प्रोफ़ाइल से एक टूल अडैप्टर इंस्टॉल करें।

```bash
apothem install --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| विकल्प | विवरण |
|--------|-------------|
| `--harness <name>` | टूल अडैप्टर का नाम (नीचे विहित मान देखें)। आवश्यक। |
| `--profile PATH` | साझा प्रोफ़ाइल YAML का पथ। डिफ़ॉल्ट `~/.config/apothem/profile.yaml`। |
| `--project PATH` | प्रोजेक्ट-दायरे के टूल के लिए प्रोजेक्ट रूट। |
| `--dry-run` | फ़ाइलें लिखे बिना इंस्टॉल का पूर्वावलोकन करें। |

विहित `--harness` मान:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
hermes
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

रजिस्ट्री-व्यापी सेट चुनने के लिए `--harness all --project <path>` का उपयोग करें।
प्रोफ़ाइल की `exclude_harnesses` सूची इंस्टॉल/अपडेट बैच चयन के दौरान सम्मानित की
जाती है।

### `apothem update`

मौजूदा साझा प्रोफ़ाइल से किसी टूल अडैप्टर की नेटिव कॉन्फ़िग को पुनः-व्युत्पन्न करें।

```bash
apothem update --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| विकल्प | विवरण |
|--------|-------------|
| `--harness <name>` | टूल अडैप्टर का नाम। आवश्यक। |
| `--profile PATH` | साझा प्रोफ़ाइल YAML का पथ। |
| `--project PATH` | प्रोजेक्ट-दायरे के टूल के लिए प्रोजेक्ट रूट। |
| `--dry-run` | फ़ाइलें लिखे बिना अपडेट का पूर्वावलोकन करें। |

`update` टूल आउटपुट को पुनः-मटेरियलाइज़ करता है। यह Apothem CLI पैकेज को अपडेट
नहीं करता; पैकेज अपग्रेड के लिए उस पैकेज मैनेजर का उपयोग करें जिसने Apothem
इंस्टॉल किया था।

### `apothem uninstall`

किसी टूल अडैप्टर की नेटिव कॉन्फ़िग हटाएँ।

```bash
apothem uninstall --harness <name|all> [--project PATH] [--yes]
```

| विकल्प | विवरण |
|--------|-------------|
| `--harness <name>` | टूल अडैप्टर का नाम। आवश्यक। |
| `--project PATH` | प्रोजेक्ट-दायरे के टूल के लिए प्रोजेक्ट रूट। |
| `--yes` | पुष्टिकरण संकेत छोड़ें। |

### `apothem verify`

सत्यापित करें कि कोई टूल अडैप्टर इंस्टॉल है और उसका आउटपुट पथ मौजूद है।

```bash
apothem verify --harness <name|all> [--project PATH]
```

| विकल्प | विवरण |
|--------|-------------|
| `--harness <name>` | टूल अडैप्टर का नाम या `all`। आवश्यक। |
| `--project PATH` | प्रोजेक्ट-दायरे के टूल के लिए प्रोजेक्ट रूट। |

जब अडैप्टर इंस्टॉल होता है तो एग्ज़िट कोड `0` होता है, और जब नहीं होता तो `1`।

### `apothem profile`

साझा Apothem प्रोफ़ाइल का प्रबंधन करें।

```bash
apothem profile show [--profile PATH]
apothem profile init [--profile PATH] [--force]
apothem profile set <key> <value> [--profile PATH]
apothem profile edit [--profile PATH]
```

| उपकमांड | विवरण |
|------------|-------------|
| `profile init` | एक स्कीमा-वैध न्यूनतम प्रोफ़ाइल स्कैफ़ोल्ड बनाएँ। |
| `profile show` | हल की गई प्रोफ़ाइल (YAML) को stdout पर प्रिंट करें। |
| `profile set <key> <value>` | एक प्रोफ़ाइल फ़ील्ड सेट करें। मान YAML-पार्स किया जाता है (स्ट्रिंग, संख्याएँ, बूलियन, सूचियाँ और मैपिंग सभी स्वीकार किए जाते हैं)। |
| `profile edit` | `$EDITOR` में प्रोफ़ाइल खोलें (प्लेटफ़ॉर्म डिफ़ॉल्ट पर वापस गिरता है)। |

`--profile PATH` विकल्प प्रत्येक उपकमांड को एक वैकल्पिक प्रोफ़ाइल फ़ाइल की ओर
इंगित करता है। डिफ़ॉल्ट `~/.config/apothem/profile.yaml`।

### `apothem harnesses`

पंजीकृत टूल अडैप्टर की सूची बनाएँ और उनका निरीक्षण करें।

```bash
apothem harnesses list
apothem harnesses show <name>
```

| उपकमांड | विवरण |
|------------|-------------|
| `harnesses list` | प्रत्येक पंजीकृत अडैप्टर की एक तालिका उसके इंस्टॉल-स्थिति फ़्लैग और आउटपुट पथ के साथ प्रिंट करें। |
| `harnesses show <name>` | एक अडैप्टर के लिए नाम, इंस्टॉल स्थिति और आउटपुट पथ प्रिंट करें। |

### `apothem doctor`

Apothem इंस्टॉलेशन के लिए सिस्टम डायग्नोस्टिक्स चलाएँ।

```bash
apothem doctor
```

Apothem संस्करण, Python इंटरप्रेटर, प्लेटफ़ॉर्म, हल किया गया प्रोफ़ाइल पथ, और एक
प्रति-टूल इंस्टॉल-स्थिति तालिका प्रिंट करता है। जब हर पंजीकृत अडैप्टर इंस्टॉल की
रिपोर्ट करता है तो एग्ज़िट कोड `0` होता है; अन्यथा `1`।
