मेंटेनर के लिए संचालन प्रक्रियाएँ। प्रत्येक रनबुक एक अनुक्रमित, संदर्भ-मुक्त
प्रक्रिया है: यह एक ज्ञात आरंभिक स्थिति को एक सत्यापित अंतिम स्थिति तक ले जाती है,
इस तरह लिखी गई कि एक सक्षम योगदानकर्ता बिना किसी पूर्व संदर्भ के उसका अनुसरण कर सके।

## पृष्ठ

| पृष्ठ | विवरण |
|------|-------------|
| [Pages सक्षमीकरण](/docs/runbooks/pages-enablement) | `apothem.ahmedgad.com` को एक नई GitHub Pages कॉन्फ़िगरेशन से `200 OK` लौटाने वाले HTTPS लैंडिंग पृष्ठ तक ले जाएँ। |
| [रिलीज़ चक्र](/docs/runbooks/release-cycle) | एक `vX.Y.Z` रिलीज़ को एक साफ़ कार्य-वृक्ष से सत्यापित GitHub Release और npm सतहों तक ले जाएँ। |
| [पब्लिशर खाता सेटअप](/docs/runbooks/publisher-account-setup) | `@ahmed-g-gad/apothem` के लिए npmjs.com विश्वसनीय पब्लिशर और GitHub-पक्ष की रिलीज़ पूर्वापेक्षाएँ कॉन्फ़िगर करें। |
| [रिलीज़ पुनर्प्राप्ति](/docs/runbooks/release-recovery) | जब रिलीज़ कटओवर अनुक्रम बीच में विफल हो जाए तब `ahmed-g-gad/apothem` को कार्यशील स्थिति में पुनर्स्थापित करें। |
