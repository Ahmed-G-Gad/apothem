लक्ष्य: एक और टूल को सक्षम करें ताकि Apothem उस टूल की नेटिव
कॉन्फ़िगरेशन को आपकी साझा प्रोफ़ाइल से मटेरियलाइज़ करे।

## पूर्वापेक्षाएँ

- `~/.config/apothem/profile.yaml` पर एक साझा प्रोफ़ाइल (यदि अभी मौजूद नहीं है तो
  `apothem profile init` से एक बनाएँ)।
- आपके `PATH` पर `apothem` CLI। यदि आपने स्व-निहित
  स्रोत वृक्ष इंस्टॉल किया है, तो प्रत्येक कमांड के आगे `PYTHONPATH="$HOME/.apothem/src"`
  जोड़ें और `apothem` के स्थान पर `python -m apothem` चलाएँ — या
  `npx @ahmed-g-gad/apothem` का उपयोग करें।

## चरण

1. पंजीकृत टूल सूचीबद्ध करें और देखें कि कौन-से पहले से इंस्टॉल हैं:

   ```bash
   apothem harnesses list
   ```

   `apothem harnesses list` हर समर्थित id प्रिंट करता है; वही समुच्चय
   [टूल सूची](/docs/harnesses) और स्रोत-जनित
   [टूल रजिस्ट्री](/docs/reference/harness-registry) में है। यहाँ सूची हार्डकोड करने के बजाय
   अपने उपकरण के लिए id चुनें — यह जैसे-जैसे अडैप्टर जुड़ते हैं, बढ़ती है।

2. लक्ष्य टूल का निरीक्षण करें ताकि उसका दायरा और आउटपुट पथ पुष्ट हो:

   ```bash
   apothem harnesses show cursor
   ```

   एक `Scope: project` पंक्ति का अर्थ है कि अडैप्टर एक प्रोजेक्ट वृक्ष में मटेरियलाइज़ करता है
   और `--project PATH` की आवश्यकता रखता है; `Scope: user` एक उपयोगकर्ता-दायरे की
   कॉन्फ़िगरेशन निर्देशिका में मटेरियलाइज़ करता है और किसी प्रोजेक्ट फ़्लैग की आवश्यकता नहीं रखता।

3. फ़ाइलें लिखे बिना इंस्टॉल का पूर्वावलोकन करें:

   ```bash
   apothem install --harness cursor --dry-run
   ```

4. टूल इंस्टॉल करें। एक उपयोगकर्ता-दायरे के टूल के लिए:

   ```bash
   apothem install --harness claude-code
   ```

   एक प्रोजेक्ट-दायरे के टूल के लिए, प्रोजेक्ट रूट पास करें:

   ```bash
   apothem install --harness cursor --project /path/to/project
   ```

   `--harness all` के साथ एक साथ हर समर्थित टूल इंस्टॉल करें (प्रोजेक्ट-दायरे के
   टूल को अभी भी `--project` की आवश्यकता होती है; प्रोफ़ाइल में `exclude_harnesses`
   में सूचीबद्ध id छोड़ दिए जाते हैं)।

## सत्यापन

```bash
apothem verify --harness cursor
```

एक `✓ <harness-id> is verified` पंक्ति पुष्टि करती है कि प्रबंधित लक्ष्य मौजूद हैं और पार्स होते हैं।
`apothem doctor` हर टूल के आर-पार संपूर्ण-तंत्र का दृश्य देता है।

## संबंधित

- अडैप्टर क्या मटेरियलाइज़ करता है उसे बदलने के लिए [प्रोफ़ाइल संपादित करें](/docs/how-to/editing-the-profile),
  फिर `apothem update` पुनः चलाएँ।
- [इंस्टॉल करना](/docs/install) पहले-रन इंस्टॉल को कवर करता है।
