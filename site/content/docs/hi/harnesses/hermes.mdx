**विक्रेता:** Hermes
**इंस्टॉल नाम:** `hermes`
**स्थिति:** प्रीव्यू
**नेटिव कॉन्फ़िग:** `~/.hermes/config.yaml`

## इंस्टॉलेशन

```bash
apothem install --harness hermes
```

अडैप्टर साझा प्रोफ़ाइल को Hermes Agent की उपयोगकर्ता-वैश्विक कॉन्फ़िगरेशन फ़ाइल
में अनुवादित करता है और हार्नेस रूट के नीचे Apothem समर्थन कोहोर्ट इंस्टॉल करता
है।

**लिखी गई फ़ाइलें:** `~/.hermes/config.yaml` और `~/.hermes/.apothem/support/` के नीचे
समर्थन फ़ाइलें

## प्रोफ़ाइल-से-नेटिव-कॉन्फ़िग मैपिंग

अडैप्टर Apothem की साझा प्रोफ़ाइल पढ़ता है और नेटिव YAML कॉन्फ़िग रेंडर करता है।
Hermes की अपनी स्किल सतह `skills.config` है — इंस्टॉल करने योग्य रजिस्ट्री पैकेज
जिन्हें Hermes स्वचालित रूप से डायनामिक स्लैश कमांड के रूप में उजागर करता है —
जिसे Apothem नहीं लिखता। इसके बजाय Apothem साझा कमांड और स्किल सामग्री को
`~/.hermes/.apothem/support/` के नीचे समर्थन सामग्री के रूप में प्रदान करता है, जिसे नेटिव
निर्देश एंकर से संदर्भित किया जाता है। सहायक परिभाषाएँ, नियम, टेम्पलेट और हुक
प्रॉम्प्ट भी इसी तरह `~/.hermes/.apothem/support/` के नीचे समर्थन सामग्री बने रहते हैं।

## संगतता टिप्पणियाँ

प्रीव्यू अडैप्टर। नेटिव YAML कॉन्फ़िग सक्रिय Hermes सतह है; Apothem स्किल के लिए
प्रलेखित बाहरी स्किल-डायरेक्टरी हुक का उपयोग करता है और अन्य कोहोर्ट को इंस्टॉल
किए गए मार्गदर्शन के लिए संदर्भ सामग्री के रूप में रखता है।

## सत्यापन

```bash
apothem verify --harness hermes
```

verify कमांड पुष्टि करता है कि:

1. नेटिव कॉन्फ़िग अपेक्षित पथ पर मौजूद है।
2. साझा प्रोफ़ाइल से सभी अनिवार्य फ़ील्ड मौजूद हैं।
3. अडैप्टर-विशिष्ट सत्यापन रूटीन सफलता की रिपोर्ट करता है।

## अपडेट करना

```bash
apothem update --harness hermes
```

वर्तमान साझा प्रोफ़ाइल स्थिति से नेटिव कॉन्फ़िग को पुनः व्युत्पन्न करता है।
`~/.config/apothem/profile.yaml` संपादित करने या इंस्टॉल किए गए Apothem पैकेज को
अपग्रेड करने के बाद चलाएँ।

## अनइंस्टॉल करना

```bash
apothem uninstall --harness hermes
```

अडैप्टर द्वारा लिखी गई नेटिव कॉन्फ़िग फ़ाइलों को हटाता है।
साझा प्रोफ़ाइल YAML और Apothem इंजन अप्रभावित रहते हैं।

## कन्फ़ॉर्मिटी गेट

```bash
python -m apothem.conformity.gate --all .
```

## समस्या निवारण

| लक्षण | समाधान |
|---------|-----|
| कॉन्फ़िग फ़ाइल नहीं मिली | `apothem install --harness hermes` पुनः चलाएँ |
| सत्यापन विफल | `apothem update --harness hermes` चलाएँ, फिर पुनः सत्यापित करें |
| अप्रत्याशित कॉन्फ़िग सामग्री | `~/.config/apothem/profile.yaml` या `--profile PATH` जाँचें, फिर `apothem update --harness hermes` पुनः चलाएँ |
