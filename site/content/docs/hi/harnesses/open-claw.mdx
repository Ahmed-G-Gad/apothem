**विक्रेता:** Open-Claw
**इंस्टॉल नाम:** `open-claw`
**स्थिति:** पूर्वावलोकन
**नेटिव कॉन्फ़िग:** `~/.openclaw/openclaw.json`

## इंस्टॉलेशन

```bash
apothem install --harness open-claw
```

एडॉप्टर साझा प्रोफ़ाइल को OpenClaw की उपयोगकर्ता-वैश्विक कॉन्फ़िग फ़ाइल में अनुवादित करता है
और हार्नेस रूट के अंतर्गत Apothem समर्थन समूह स्थापित करता है। OpenClaw का नेटिव कॉन्फ़िग
JSON है; materializer उससे मेल खाने के लिए JSON रेंडर करता है।

**लिखी गई फ़ाइलें:** `~/.openclaw/openclaw.json` और `~/.openclaw/.apothem/support/` के अंतर्गत
समर्थन फ़ाइलें

## प्रोफ़ाइल-से-नेटिव-कॉन्फ़िग मैपिंग

एडॉप्टर Apothem की साझा प्रोफ़ाइल पढ़ता है। OpenClaw का नेटिव skills फ़ील्ड एक नाम
अनुमति-सूची है (डायरेक्टरी लोडर नहीं) और MCP एक CLI सतह है, इसलिए Apothem कोई कॉन्फ़िग कुंजी
नहीं लिखता। साझा कमांड, स्किल, नियम, टेम्पलेट, और हुक प्रॉम्प्ट `~/.openclaw/.apothem/support/` के
अंतर्गत समर्थन सामग्री के रूप में स्थापित किए जाते हैं।

## संगतता टिप्पणियाँ

पूर्वावलोकन एडॉप्टर। नेटिव JSON कॉन्फ़िग Open-Claw की सक्रिय सतह है; Apothem स्किल के लिए
दस्तावेज़ीकृत अतिरिक्त skill-directory हुक का उपयोग करता है और अन्य समूहों को स्थापित
मार्गदर्शन के लिए संदर्भ सामग्री के रूप में रखता है।

## सत्यापन

```bash
apothem verify --harness open-claw
```

verify कमांड पुष्टि करता है कि:

1. नेटिव कॉन्फ़िग अपेक्षित पथ पर मौजूद है।
2. साझा प्रोफ़ाइल के सभी अनिवार्य फ़ील्ड मौजूद हैं।
3. एडॉप्टर-विशिष्ट सत्यापन रूटीन सफलता की रिपोर्ट करता है।

## अपडेट करना

```bash
apothem update --harness open-claw
```

वर्तमान साझा प्रोफ़ाइल स्थिति से नेटिव कॉन्फ़िग को फिर से व्युत्पन्न करता है।
`~/.config/apothem/profile.yaml` को संपादित करने या स्थापित Apothem पैकेज को अपग्रेड करने
के बाद चलाएँ।

## अनइंस्टॉल करना

```bash
apothem uninstall --harness open-claw
```

एडॉप्टर द्वारा लिखी गई नेटिव कॉन्फ़िग फ़ाइलों को हटाता है। साझा प्रोफ़ाइल YAML और Apothem
इंजन अप्रभावित रहते हैं।

## कन्फ़ॉर्मिटी गेट

```bash
python -m apothem.conformity.gate --all .
```

## समस्या निवारण

| लक्षण | समाधान |
|---------|-----|
| कॉन्फ़िग फ़ाइल नहीं मिली | `apothem install --harness open-claw` को फिर से चलाएँ |
| सत्यापन विफल | `apothem update --harness open-claw` चलाएँ, फिर दोबारा सत्यापित करें |
| अप्रत्याशित कॉन्फ़िग सामग्री | `~/.config/apothem/profile.yaml` या `--profile PATH` जाँचें, फिर `apothem update --harness open-claw` को फिर से चलाएँ |
