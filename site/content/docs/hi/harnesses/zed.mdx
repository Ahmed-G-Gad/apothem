**विक्रेता:** Zed Industries
**इंस्टॉल नाम:** `zed`
**स्थिति:** GA
**नेटिव कॉन्फ़िग:** `<project>/.rules`

## इंस्टॉलेशन

```bash
apothem install --harness zed --project /path/to/project
```

एडॉप्टर साझा Apothem नियम और गवर्नेंस सतह से एक प्रोजेक्ट-स्कोप्ड Zed निर्देश फ़ाइल
लिखता है। Zed प्रोजेक्ट रूट में एक एकल सपाट `.rules` फ़ाइल (`AGENTS.md` / `CLAUDE.md`
परिवार के साथ) को निर्देशों के रूप में पढ़ता है; प्रति-टूल कोई नियम डायरेक्टरी नहीं
है, इसलिए संपूर्ण Apothem सतह इस एक फ़ाइल में आ जाती है।

**लिखी गई फ़ाइलें:** `<project>/.rules`

## प्रोफ़ाइल-से-नेटिव-कॉन्फ़िग मैपिंग

एडॉप्टर Apothem की साझा प्रोफ़ाइल पढ़ता है और प्रत्येक `apothem install` या
`apothem update` रन पर प्रोजेक्ट `.rules` फ़ाइल को रेंडर करता है। साझा प्रोफ़ाइल सत्य
का स्रोत है; किसी भी पूर्व-मौजूद `.rules` (या उत्पन्न फ़ाइल पर प्रोजेक्ट-स्थानीय
संपादनों) का बैकअप अगले सिंक द्वारा Apothem-प्रबंधित सामग्री को प्रतिस्थापित करने से
पहले लिया जाता है।

## संगतता टिप्पणियाँ

Zed की वर्तमान निर्देश सतह प्रोजेक्ट रूट में सपाट `.rules` फ़ाइल है। वैश्विक
`~/.config/zed/AGENTS.md` निर्देश फ़ाइल और MCP कॉन्टेक्स्ट-सर्वर ब्लॉक
(`.zed/settings.json` में `context_servers`) ऑपरेटर के स्वामित्व में हैं; Apothem
उन्हें नहीं लिखता।

## सत्यापन

```bash
apothem verify --harness zed --project /path/to/project
```

verify कमांड पुष्टि करता है कि:

1. नेटिव कॉन्फ़िग अपेक्षित पथ पर मौजूद है।
2. साझा प्रोफ़ाइल के सभी अनिवार्य फ़ील्ड मौजूद हैं।
3. एडॉप्टर-विशिष्ट सत्यापन रूटीन सफलता की रिपोर्ट करता है।

## अपडेट करना

```bash
apothem update --harness zed --project /path/to/project
```

वर्तमान साझा प्रोफ़ाइल स्थिति से प्रोजेक्ट `.rules` फ़ाइल को फिर से व्युत्पन्न करता
है।

## अनइंस्टॉल करना

```bash
apothem uninstall --harness zed --project /path/to/project
```

एडॉप्टर द्वारा लिखी गई नेटिव कॉन्फ़िग फ़ाइल को हटाता है, पहले इसे टाइमस्टैम्प किए गए
बैकअप में पुनर्नामित करता है। साझा प्रोफ़ाइल YAML और Apothem इंजन अप्रभावित रहते हैं।

## कन्फ़ॉर्मिटी गेट

```bash
python -m apothem.conformity.gate --all .
```

## समस्या निवारण

| लक्षण | समाधान |
|---------|-----|
| कॉन्फ़िग फ़ाइल नहीं मिली | `apothem install --harness zed --project /path/to/project` को फिर से चलाएँ |
| सत्यापन विफल | `apothem update --harness zed --project /path/to/project` चलाएँ, फिर दोबारा सत्यापित करें |
| अप्रत्याशित कॉन्फ़िग सामग्री | `~/.config/apothem/profile.yaml` या `--profile PATH` जाँचें, फिर `apothem update --harness zed --project /path/to/project` को फिर से चलाएँ |
