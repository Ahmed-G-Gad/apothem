**विक्रेता:** Devin Desktop (पूर्व में Codeium Windsurf)
**इंस्टॉल नाम:** `windsurf`
**स्थिति:** GA
**नेटिव कॉन्फ़िग:** `<project>/.devin/rules/apothem-rules.md`

Windsurf अब Devin Desktop है, और `.devin/rules/` पसंदीदा वर्कस्पेस-नियम स्थान है
(यह `.windsurf/rules/` पर प्राथमिकता लेता है)।

## इंस्टॉलेशन

```bash
apothem install --harness windsurf --project /path/to/project
```

अडैप्टर साझा Apothem नियमों और शासन सतह से प्रोजेक्ट-स्कोप वाली एक Windsurf नियम
फ़ाइल लिखता है।

**लिखी गई फ़ाइलें:** `<project>/.devin/rules/apothem-rules.md`

## प्रोफ़ाइल-से-नेटिव-कॉन्फ़िग मैपिंग

अडैप्टर Apothem की साझा प्रोफ़ाइल पढ़ता है और हर `apothem install` या
`apothem update` रन पर प्रोजेक्ट नियम फ़ाइल रेंडर करता है। साझा प्रोफ़ाइल सत्य
का स्रोत है; जनित फ़ाइल में किए गए प्रोजेक्ट-स्थानीय संपादनों का बैकअप अगली
सिंक द्वारा Apothem-प्रबंधित सामग्री को बदलने से पहले ले लिया जाता है।

फ़ाइल अपने `trigger: always_on` फ़्रंट मैटर से शुरू होती है, जो नियम का सक्रियण
मोड सेट करता है। Apothem-प्रबंधित ब्लॉक उसके बाद आता है; ब्लॉक के बाद आप जो
टेक्स्ट जोड़ते हैं, वह हर सिंक पर बना रहता है।

## संगतता टिप्पणियाँ

Windsurf की वर्तमान नियम सतह `.devin/rules/` के अंतर्गत प्रोजेक्ट-स्कोप वाली है
(पसंदीदा स्थान, जो `.windsurf/rules/` पश्च-संगतता फ़ॉलबैक पर प्राथमिकता लेता
है)। वर्कफ़्लो और मशीन-स्थानीय मेमोरी ऑपरेटर-स्वामित्व वाली हैं; Apothem उन्हें
नहीं लिखता। एकल-फ़ाइल `.windsurfrules` रूप जानबूझकर नहीं लिखा जाता।

## सत्यापन

```bash
apothem verify --harness windsurf --project /path/to/project
```

verify कमांड पुष्टि करता है कि:

1. नेटिव कॉन्फ़िग अपेक्षित पथ पर मौजूद है।
2. हर प्रबंधित टारगेट मौजूद है; प्रबंधित फ़ाइलें खाली नहीं हैं, और JSON या YAML
   कॉन्फ़िग पार्स होते हैं। `--profile PATH` जोड़ने पर यह भी पुष्टि होती है कि
   इंस्टॉल की गई फ़ाइलें उस प्रोफ़ाइल से मेल खाती हैं।
3. अडैप्टर-विशिष्ट सत्यापन रूटीन सफलता की रिपोर्ट करता है।

## अपडेट करना

```bash
apothem update --harness windsurf --project /path/to/project
```

वर्तमान साझा प्रोफ़ाइल स्थिति से प्रोजेक्ट नियम फ़ाइल को पुनः व्युत्पन्न करता है।

## अनइंस्टॉल करना

```bash
apothem uninstall --harness windsurf --project /path/to/project
```

अडैप्टर द्वारा लिखी गई नेटिव कॉन्फ़िग फ़ाइलों को हटाता है।
साझा प्रोफ़ाइल YAML और Apothem इंजन अप्रभावित रहते हैं।

## अनुरूपता गेट

```bash
python -m apothem.conformity.gate --all .
```

## समस्या निवारण

| लक्षण | समाधान |
|---------|-----|
| कॉन्फ़िग फ़ाइल नहीं मिली | `apothem install --harness windsurf --project /path/to/project` फिर से चलाएँ |
| सत्यापन विफल रहा | `apothem update --harness windsurf --project /path/to/project` चलाएँ, फिर दोबारा सत्यापित करें |
| अप्रत्याशित कॉन्फ़िग सामग्री | `~/.config/apothem/profile.yaml` या `--profile PATH` जाँचें, फिर `apothem update --harness windsurf --project /path/to/project` फिर से चलाएँ |
