**विक्रेता:** Anysphere
**इंस्टॉल नाम:** `cursor`
**स्थिति:** GA
**नेटिव कॉन्फ़िग:** प्रोजेक्ट रूट में `.cursor/rules/`

## इंस्टॉलेशन

```bash
apothem install --harness cursor --project /path/to/project
```

अडैप्टर साझा Apothem नियमों और शासन सतह से एक एकल प्रोजेक्ट-स्कोप `.mdc` नियम
फ़ाइल रेंडर करता है।

**लिखी गई फ़ाइलें:** `<project>/.cursor/rules/apothem-rules.mdc`

वही फ़ाइल पूरा इंस्टॉल है: उसके बगल में कोई नियम, स्किल, कमांड, टेम्पलेट, या हुक
फ़ाइल नहीं रखी जाती, इसलिए फ़ाइल प्रोजेक्ट में अनुपस्थित Apothem फ़ाइलों की ओर
इंगित करने के बजाय यही बात स्वयं बताती है।

## प्रोफ़ाइल-से-नेटिव-कॉन्फ़िग मैपिंग

अडैप्टर Apothem की साझा प्रोफ़ाइल पढ़ता है और प्रत्येक `apothem install` या
`apothem update` रन पर प्रोजेक्ट नियम फ़ाइल रेंडर करता है। सत्य का स्रोत साझा
प्रोफ़ाइल है; अगला सिंक Apothem-प्रबंधित सामग्री को बदले, उससे पहले उत्पन्न फ़ाइल
में किए गए प्रोजेक्ट-स्थानीय संपादनों का बैकअप लिया जाता है।

फ़ाइल अपने YAML फ़्रंटमैटर (`description`, `globs`, `alwaysApply: true`) से शुरू
होती है, क्योंकि Cursor किसी नियम का प्रकार केवल फ़ाइल की शुरुआत में स्थित
फ़्रंटमैटर से पढ़ता है। Apothem-प्रबंधित ब्लॉक उसके बाद आता है; ब्लॉक के बाद आपके
द्वारा जोड़ा गया पाठ हर सिंक पर बना रहता है।

## संगतता टिप्पणियाँ

Cursor 0.45+ `.cursor/rules/` के माध्यम से प्रोजेक्ट-स्तरीय निर्देशों का समर्थन
करता है। अडैप्टर डिफ़ॉल्ट रूप से प्रोजेक्ट-स्कोप वाली `.cursor/rules/` डायरेक्टरी
में लिखता है; Cursor के पास कोई प्रलेखित फ़ाइल-आधारित उपयोगकर्ता-वैश्विक नियम पथ
नहीं है जिसे यह अडैप्टर प्रबंधित कर सके।

## सत्यापन

```bash
apothem verify --harness cursor --project /path/to/project
```

verify कमांड पुष्टि करता है कि:

1. नेटिव कॉन्फ़िग अपेक्षित पथ पर मौजूद है।
2. हर प्रबंधित टारगेट मौजूद है; प्रबंधित फ़ाइलें खाली नहीं हैं, और JSON या YAML
   कॉन्फ़िग पार्स होते हैं। `--profile PATH` जोड़ने पर यह भी पुष्टि होती है कि
   इंस्टॉल की गई फ़ाइलें उस प्रोफ़ाइल से मेल खाती हैं।
3. अडैप्टर-विशिष्ट सत्यापन रूटीन सफलता की रिपोर्ट करता है।

## अपडेट करना

```bash
apothem update --harness cursor --project /path/to/project
```

वर्तमान साझा प्रोफ़ाइल स्थिति से प्रोजेक्ट नियम फ़ाइल को पुनः व्युत्पन्न करता है।

## अनइंस्टॉल करना

```bash
apothem uninstall --harness cursor --project /path/to/project
```

अडैप्टर द्वारा लिखी गई नेटिव कॉन्फ़िग फ़ाइलों को हटाता है।
साझा प्रोफ़ाइल YAML और Apothem इंजन अप्रभावित रहते हैं।

## अनुरूपता गेट

```bash
python -m apothem.conformity.gate --all .
```

## समस्या निवारण

| लक्षण | समाधान |
|---------|-----|
| कॉन्फ़िग फ़ाइल नहीं मिली | `apothem install --harness cursor --project /path/to/project` फिर से चलाएँ |
| सत्यापन विफल रहा | `apothem update --harness cursor --project /path/to/project` चलाएँ, फिर दोबारा सत्यापित करें |
| अप्रत्याशित कॉन्फ़िग सामग्री | `~/.config/apothem/profile.yaml` या `--profile PATH` जाँचें, फिर `apothem update --harness cursor --project /path/to/project` फिर से चलाएँ |
