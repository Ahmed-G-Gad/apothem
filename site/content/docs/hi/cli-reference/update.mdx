वर्तमान साझा प्रोफ़ाइल से एक हार्नेस अडैप्टर कॉन्फ़िगरेशन फिर से इंस्टॉल करें।

## सारांश

```
apothem update --harness NAME|all [--profile PATH] [--dry-run]
                [--project PATH]
                [--quiet|-q] [--verbose|-v]
                [--format plain|json] [--json] [--no-color]
```

`update` वर्तमान साझा प्रोफ़ाइल से हार्नेस आउटपुट को फिर से मूर्त रूप देता है।
यह `install` जैसा ही प्रोफ़ाइल सत्यापन, `--harness all` चयन, प्रोजेक्ट-स्कोप
जाँच, ड्राई-रन व्यवहार और JSON एनवेलप उपयोग करता है।

सतत-रूप उपनाम `apothem updating` उसी हैंडलर पर रिज़ॉल्व होता है।

## विकल्प

| विकल्प | विवरण |
|---|---|
| `--harness NAME` | अपडेट करने के लिए हार्नेस अडैप्टर, या रजिस्ट्री-व्यापी सेट के लिए `all` (आवश्यक)। |
| `--profile PATH` | साझा प्रोफ़ाइल YAML का पथ। डिफ़ॉल्ट `~/.config/apothem/profile.yaml` है। |
| `--dry-run` | फ़ाइलें लिखे बिना अपडेट का पूर्वावलोकन करें। |
| `--project PATH` | प्रोजेक्ट-स्कोप हार्नेसों के लिए प्रोजेक्ट रूट। तब आवश्यक जब चयनित हार्नेस सेट में प्रोजेक्ट-स्कोप अडैप्टर शामिल हों। |
| `--quiet`, `-q` | सूचनात्मक आउटपुट दबाएँ; केवल त्रुटियाँ उत्सर्जित होती हैं। |
| `--verbose`, `-v` | अतिरिक्त नैदानिक आउटपुट उत्सर्जित करें। |
| `--format plain\|json` | आउटपुट प्रारूप (डिफ़ॉल्ट: `plain`)। |
| `--json` | `--format json` का संक्षिप्त रूप। |
| `--no-color` | आउटपुट में ANSI रंग कोड अक्षम करें। |
| `-h`, `--help` | सहायता दिखाएँ और बाहर निकलें। |

## JSON आउटपुट

```json
{
  "schema_version": 1,
  "status": "success",
  "command": "update",
  "action": "updated",
  "harness": "claude-code",
  "profile_path": "C:\\Users\\Example\\.config\\apothem\\profile.yaml",
  "project": null,
  "files_written": [],
  "results": [],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

`--dry-run` `status: "dry_run"` और `files_written: []` लौटाता है।

## उदाहरण

```bash
apothem update --harness claude-code
apothem update --harness claude-code --dry-run
apothem update --harness all --project . --dry-run --json
apothem Updating --harness claude-code   # continuous-form alias
apothem updating --harness claude-code   # lowercase variant
```

## निकास कोड

| कोड | अर्थ |
|---|---|
| 0 | अडैप्टर सफलतापूर्वक अपडेट हुआ या ड्राई-रन की योजना त्रुटिरहित बनी |
| 1 | अपेक्षित सत्यापन, प्रोफ़ाइल, हार्नेस, प्रोजेक्ट या अडैप्टर त्रुटि |
| 2 | कम से कम एक लेखन के बाद आंशिक बैच मूर्तीकरण |
| 64 | उपयोग त्रुटि: एक अज्ञात विकल्प या कमांड, या एक लुप्त या अमान्य विकल्प मान। `--json` के अंतर्गत त्रुटि `cli.usage` कोड वाला एक JSON एनवेलप होती है। |

## यह भी देखें

- `apothem updating` — इस कमांड का सतत-रूप उपनाम (यहाँ प्रलेखित; CLI दोनों रूप स्वीकार करता है)
- [apothem install](/docs/cli-reference/install) — प्रारंभिक इंस्टॉल
- [अपडेट गाइड](/docs/install/updating) — प्रति-इंस्टॉलर अपडेट पथ
