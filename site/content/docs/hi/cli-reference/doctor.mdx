Apothem इंस्टॉलेशन के लिए सिस्टम डायग्नोस्टिक्स चलाता है।

## सारांश

```
apothem doctor [--quiet|-q] [--verbose|-v]
               [--format plain|json] [--json] [--no-color]
```

Apothem इंस्टॉलेशन की जाँच करता है और हर पंजीकृत हार्नेस अडैप्टर की स्थिति की
रिपोर्ट करता है। जब कोई साझा प्रोफ़ाइल मौजूद होती है, तो उसे पैकेज किए गए स्कीमा के
विरुद्ध मान्य किया जाता है — केवल अस्तित्व की जाँच नहीं की जाती — ताकि एक विकृत
प्रोफ़ाइल हरे "मिला" के बजाय एक डायग्नोस्टिक विफलता के रूप में सामने आए। JSON आउटपुट
में एक `profile_valid` फ़ील्ड (`true` / `false`, या प्रोफ़ाइल मौजूद न होने पर `null`)
और मान्यता विफल होने पर एक `profile_error` फ़ील्ड होती है। सभी जाँचें पास होने पर 0
के साथ बाहर निकलता है, और जब एक या अधिक हार्नेस इंस्टॉल नहीं होते या मौजूद प्रोफ़ाइल
स्कीमा मान्यता में विफल होती है तब 1 के साथ।

## विकल्प

| विकल्प | विवरण |
|---|---|
| `--quiet`, `-q` | सूचनात्मक आउटपुट दबाता है; केवल त्रुटियाँ उत्सर्जित होती हैं। |
| `--verbose`, `-v` | अतिरिक्त डायग्नोस्टिक आउटपुट उत्सर्जित करता है। |
| `--format plain\|json` | आउटपुट प्रारूप (डिफ़ॉल्ट: `plain`)। |
| `--json` | `--format json` का संक्षिप्त रूप। |
| `--no-color` | आउटपुट में ANSI रंग कोड अक्षम करता है। |
| `-h`, `--help` | सहायता दिखाकर बाहर निकलता है। |

## उदाहरण

```bash
apothem doctor
apothem doctor --json
```

## एग्ज़िट कोड

| कोड | अर्थ |
|---|---|
| 0 | सभी जाँचें पास हुईं |
| 1 | कोई हार्नेस इंस्टॉल नहीं है, या मौजूद प्रोफ़ाइल स्कीमा मान्यता में विफल हुई |
