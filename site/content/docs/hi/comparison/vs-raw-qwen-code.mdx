Qwen Code सेटिंग्स, हुक, `QWEN.md`, नेटिव Markdown कमांड, SKILL.md
डायरेक्टरी और Markdown सबएजेंट पढ़ता है। Apothem साझा प्रोफ़ाइल से प्रलेखित
सेटिंग कुंजियाँ रेंडर करता है, और जहाँ Qwen Code समर्थन करता है वहाँ साझा
कोहोर्ट को Qwen की नेटिव फ़ाइलसिस्टम आकृति में बदल देता है।

## प्रयास तुलना

| कार्य | हस्तचालित कॉन्फ़िग | Apothem-प्रबंधित |
| ---- | --------------- | --------------- |
| नियम लिखना | QWEN.md और सहायक फ़ाइलों को हाथ से बनाए रखें | साझा प्रोफ़ाइल से रेंडर या संदर्भित |
| हुक कॉन्फ़िगर करना | `settings.json` के हुक प्रविष्टियों को हाथ से संपादित करें | Qwen Code के नेटिव हुक मानचित्र के माध्यम से इंस्टॉल |
| कमांड, स्किल, एजेंट लिखना | प्रत्येक Qwen डायरेक्टरी को हाथ से बनाए रखें | साझा Apothem कोहोर्ट से रूपांतरित |
| कोहोर्ट को अन्य एनवायरनमेंट के साथ संरेखित रखना | मैनुअल, प्रति टूल | `apothem update` पर स्वचालित |
| सरफ़ेस इंस्टॉल / हटाना | मैनुअल | `apothem install` / `apothem uninstall` |
| कॉन्फ़िग सही है यह सत्यापित करना | मैनुअल निरीक्षण | `apothem verify --harness qwen-code` |

## Apothem क्या प्रबंधित करता है

qwen-code अडैप्टर `settings.json` लिखता है, `QWEN.md` इंस्टॉल करता है, Apothem
के स्लैश कमांड को Qwen के Markdown कमांड फ़ाइलों में बदलता है, स्किल को नेटिव
स्किल सरफ़ेस में कॉपी करता है, सहायक परिभाषाओं को Qwen सबएजेंट के रूप में
अनुकूलित करता है, और Apothem हुक डिस्पैचर पंजीकृत करता है। नियम, टेम्पलेट और हुक
स्रोत सामग्री Apothem के सहायक सबट्री के नीचे रहती है और नेटिव संदर्भ से संदर्भित
होती है।

## माइग्रेशन पथ

1. यदि आपके पास अभी तक नहीं है तो साझा प्रोफ़ाइल बनाने के लिए `apothem profile init` चलाएँ।
2. मौजूदा Qwen Code नियम, कमांड, स्किल और एजेंट को साझा कॉर्पस में ले जाएँ।
3. नेटिव सरफ़ेस रेंडर करने के लिए `apothem install --harness qwen-code` चलाएँ।
4. कॉन्फ़िग उतरी है यह पुष्टि करने के लिए `apothem verify --harness qwen-code` चलाएँ।
5. हर बाद के बदलाव के लिए `apothem update --harness qwen-code` का उपयोग करें।
