Claude Code (निर्माता Anthropic) अपना नेटिव कॉन्फ़िगरेशन `~/.claude/` के अंतर्गत
रखता है। Apothem का claude-code अडैप्टर पूर्ण-सतह अडैप्टर है: यह साझा कॉर्पस को सीधे
उस ट्री में प्रसारित करता है। यह पृष्ठ कॉन्फ़िग को हाथ से बनाए रखने की तुलना Apothem
से प्रबंधित करने से करता है।

## प्रयास तुलना

| कार्य | हस्तचालित कॉन्फ़िग | Apothem-प्रबंधित |
| ---- | --------------- | --------------- |
| नियम, एजेंट, कमांड, स्किल लिखना | `~/.claude/` में हर सतह को हाथ से संपादित करें | साझा कॉर्पस में एक बार लिखें |
| आउटपुट-स्टाइल और स्टेटसलाइन बनाए रखना | प्रति सतह हाथ से संपादित करें | साझा कॉर्पस से प्रसारित |
| हुक कॉन्फ़िगर करना | `settings.json` हुक प्रविष्टियाँ हाथ से संपादित करें | प्रसारित (PreToolUse/PostToolUse/Stop/SessionStart) |
| कॉन्फ़िग को अन्य एनवायरनमेंट के साथ संरेखित रखना | मैनुअल, प्रति टूल | `apothem update` पर स्वचालित |
| कॉन्फ़िग सही है यह सत्यापित करना | मैनुअल निरीक्षण | `apothem verify --harness claude-code` |

## Apothem क्या प्रबंधित करता है

अडैप्टर नियम, एजेंट, कमांड, स्किल, आउटपुट-स्टाइल, स्टेटसलाइन और `settings.json`
को `~/.claude/` में प्रसारित करता है। नेटिव PreToolUse, PostToolUse, Stop और
SessionStart हुक साझा कॉर्पस से कॉन्फ़िगर किए जाते हैं।

Apothem `CLAUDE.md` को प्रबंधित **नहीं** करता — वह फ़ाइल ऑपरेटर-स्वामित्व का
क्षेत्र है। `CLAUDE.md` में आपके प्रोजेक्ट और व्यक्तिगत निर्देश आपके ही रहते हैं;
Apothem उसके चारों ओर की प्रसारित सतहों को नियंत्रित करता है।

## माइग्रेशन पथ

1. यदि आपने अभी तक नहीं बनाया है तो साझा प्रोफ़ाइल बनाने के लिए
   `apothem profile init` चलाएँ।
2. अपने मौजूदा `~/.claude/` नियम, एजेंट, कमांड और स्किल को साझा कॉर्पस में ले जाएँ।
3. `CLAUDE.md` को यथास्थान छोड़ दें — Apothem इसे नहीं छुएगा।
4. कॉर्पस प्रसारित करने के लिए `apothem install --harness claude-code` चलाएँ।
5. कॉन्फ़िग पहुँच गया इसकी पुष्टि के लिए `apothem verify --harness claude-code` चलाएँ।
6. हर बाद के बदलाव के लिए `apothem update --harness claude-code` का उपयोग करें।
