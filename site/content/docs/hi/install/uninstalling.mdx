## पहले हार्नेस कॉन्फ़िग हटाएँ

Apothem को अनइंस्टॉल करने से पहले, अपने हार्नेस को स्वच्छ अवस्था में छोड़ने के लिए
प्रत्येक हार्नेस एडॉप्टर कॉन्फ़िग हटाएँ। यह देखने के लिए कि वर्तमान में कौन-से एडॉप्टर इंस्टॉल हैं,
`apothem harnesses list` चलाएँ, फिर उन्हें एक-एक करके हटाएँ या
रजिस्ट्री-व्यापी सेलेक्टर का उपयोग करें:

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness cursor --project /path/to/project
apothem uninstall --harness all --project /path/to/project --yes
```

प्रति-हार्नेस पुष्टिकरण प्रॉम्प्ट को छोड़ने के लिए `--yes` पास करें।

## इंजन हटाएँ

हटाना उस इंस्टॉल चैनल से मेल खाता है जिसका आपने उपयोग किया था:

- **Claude Code प्लगइन** — Claude Code के भीतर से प्लगइन हटाएँ:
  `/plugin uninstall apothem@apothem` (मार्केटप्लेस प्रविष्टि को
  `/plugin marketplace remove ahmed-g-gad/apothem` से हटाया जा सकता है)।
- **npx** — हटाने के लिए कुछ नहीं; `npx` अपने कैश से चलता है। यदि आप कैश की गई प्रति को हटाना चाहते हैं तो
  `npm cache clean --force` से इसे साफ़ करें।
- **वन-शॉट इंस्टॉलर** — चेकआउट से मेल खाने वाली अनइंस्टॉल स्क्रिप्ट चलाएँ:
  `scripts/installer/uninstall.sh` (POSIX) या
  `scripts/installer/uninstall.ps1` (PowerShell)। दोनों हटाने से पहले
  पुष्टि करते हैं और असुरक्षित लक्ष्यों को अस्वीकार करते हैं।
- **बैकअप और स्थिति** — इंस्टॉल बैकअप `~/.apothem/backups/` के अंतर्गत रहते हैं;
  जब आपको उनकी आवश्यकता न रह जाए तो `~/.apothem/` हटा दें।

## क्या नहीं हटाया जाता

- `~/.config/apothem/profile.yaml` या `--profile PATH` पर साझा प्रोफ़ाइल YAML को
  `apothem uninstall` कभी नहीं हटाता।
- हार्नेस निर्देशिकाओं में असंबंधित ऑपरेटर-रचित फ़ाइलें संरक्षित रहती हैं।
- `<project>/.apothem/plans/` (और लीगेसी `<project>/.plans/`) के अंतर्गत प्लान सूट अप्रभावित रहते हैं।

किसी हार्नेस रूट को पूरी तरह साफ़ करने के लिए, उन कस्टम नियमों, सहायकों या प्रोफ़ाइल फ़ाइलों का बैकअप लेने की पुष्टि करने के बाद
[हार्नेस संदर्भ पृष्ठों](/docs/harnesses) पर प्रलेखित हार्नेस-मूल पथ हटाएँ जिन्हें आप रखना चाहते हैं।
