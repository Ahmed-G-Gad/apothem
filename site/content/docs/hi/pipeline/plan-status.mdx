**भूमिका:** रिपोर्टर
**पाइपलाइन स्थिति:** केवल-पठन

केवल-पठन प्लान सूट प्रगति रिपोर्टर — किसी भी फ़ाइल को संशोधित किए बिना स्थिति उत्सर्जित करता है।

## विहित आह्वान

```bash
/plan-status
```

तर्कों के साथ:

```bash
/plan-status [path/to/plan-suite/] [--verbose]
```

## इनपुट

जीवनचक्र की किसी भी स्थिति में कोई भी प्लान सूट — `PROGRESS.md`, `PLAN-NOTES.md`, `MASTER-PLAN.md`, और `phases/` रिपोर्ट पढ़ता है।

## आउटपुट

ऑपरेटर की आउटपुट धारा पर लिखी एक रणनीतिक स्थिति रिपोर्ट। यह कमांड केवल-पठन है — यह कोई फ़ाइल नहीं बनाता और न ही संशोधित करता है।

## अनुप्रवाह

प्रगति निरीक्षण के लिए स्वतंत्र रूप से उपयोग किया जाता है — विहित अनुक्रम के लंबवत, किसी भी बिंदु पर केवल-पठन रूप से आह्वान-योग्य।

## वर्कफ़्लो फ़ेज़

यह कमांड केवल-पठन है — यह सूट की ट्रैकिंग फ़ाइलें पढ़कर रिपोर्ट करता है; यह कुछ नहीं लिखता:

1. **संदर्भ लोड करें** — `PROGRESS.md`, `PLAN-NOTES.md`, `MASTER-PLAN.md` पढ़ें, और मौजूदा रिपोर्ट के लिए `phases/` स्कैन करें।
2. **स्थिति का आकलन करें** — टास्क / फ़ेज़ / आर्टिफ़ैक्ट आयामों का सर्वेक्षण करें और पुनरारंभ अनुबंध पढ़ें।
3. **स्थिति रिपोर्ट उत्सर्जित करें** — पूर्णता स्थिति, फ़ेज़ ट्रैकर, और रणनीतिक विश्लेषण सीधे ऑपरेटर को प्रस्तुत करें।
4. **स्पॉट-चेक** — `--verbose` के साथ, सूट स्वास्थ्य का आकलन करें और किसी भी फ़ाइल को संशोधित किए बिना मौजूदा फ़ाइलों के विरुद्ध स्पॉट-चेक साक्ष्य (markdown लिंक, पंक्ति परास, कमिट SHA) उद्धृत करें।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| आवश्यक ट्रैकिंग फ़ाइल नदारद | प्लान सूट अपूर्ण | अंतराल को निष्कर्ष के रूप में सतह पर लाएँ; सूट बनाने के लिए `/plan-generate` चलाएँ |
| विकृत ट्रैकिंग फ़ाइल | अनुभाग छंटा हुआ या अपठनीय | रिपोर्ट में अनुपस्थिति / विरोधाभास का नाम दें; मरम्मत लेखन-कमांडों को मार्गित होती है |
| फ़ील्ड अनुपस्थित या फ़ाइलों में विरोधाभासी | ट्रैकिंग बहाव | विरोधाभास को स्पष्ट रूप से रिपोर्ट करें; गुम मान को संश्लेषित न करें |

## उदाहरण

```bash
# सबसे हाल के प्लान सूट पर रिपोर्ट करें
/plan-status

# एक नामित प्लान सूट के विरुद्ध विस्तृत स्वास्थ्य-आकलन
/plan-status path/to/plan-suite/ --verbose
```
