**भूमिका:** प्रधान अन्वेषक (विश्लेषण)
**पाइपलाइन स्थिति:** शृंखला-मध्य

पूर्व-पंजीकृत योजना के अनुसार कच्चे डेटा का विश्लेषण करता है — नियोजित सांख्यिकीय परीक्षण चलाता है, विश्वास अंतराल सहित प्रभाव आकार रिपोर्ट करता है (केवल p-मान नहीं), जहाँ लागू हो वहाँ बहु-तुलना सुधार लागू करता है, सुदृढ़ता / संवेदनशीलता जाँच चलाता है, और पूर्व-पंजीकरण से प्रत्येक विचलन को उद्घाटित करता है।

## विहित आह्वान

```bash
/research-analysis
```

तर्कों के साथ:

```bash
/research-analysis [path/to/research-suite/]
```

## इनपुट

प्रयोग चरण द्वारा अभिलेखित, होस्ट-स्वाभाविक स्थान पर कच्चा डेटा, साथ ही `_inputs/preregistration.md` (जमी हुई विश्लेषण योजना)।

## आउटपुट

`_outputs/analysis.md` (प्रभाव आकार और विश्वास अंतराल सहित पूर्व-पंजीकृत परीक्षण, बहु-तुलना सुधार, सुदृढ़ता जाँच, और उद्घाटित विचलन) ＋ होस्ट-स्वाभाविक स्थान पर आकृतियाँ / तालिकाएँ।

## अनुप्रवाह

/research-paper (अनुप्रवाह उपभोक्ता)

## कार्यप्रवाह चरण

यह कमांड मानक `/research` पाइपलाइन कार्यप्रवाह का अनुसरण करता है:

1. **संदर्भ लोड करें** — कच्चे डेटा और पूर्व-पंजीकरण को पढ़ें।
2. **अनुक्रम द्वार सत्यापित करें** — पुष्टि करें कि प्रयोग आउटपुट मौजूद हैं; अन्यथा `Blocked: run /research-experiment first` के साथ रुकें।
3. **विश्लेषण करें** — पूर्व-पंजीकृत परीक्षण चलाएँ; प्रभाव आकार ＋ विश्वास अंतराल रिपोर्ट करें; बहु-तुलना के लिए सुधार करें; सुदृढ़ता / संवेदनशीलता जाँच चलाएँ।
4. **विचलन उद्घाटित करें** — पूर्व-पंजीकृत योजना से प्रत्येक प्रस्थान को अभिलेखित करें।
5. **हैंडऑफ़ मैनिफ़ेस्ट अद्यतन करें** — विश्लेषण पथ और आकृतियाँ / तालिकाएँ अभिलेखित करें।
6. **विश्लेषण उत्सर्जित करें** — `_outputs/analysis.md` ＋ आकृतियाँ / तालिकाएँ।

## कठोरता की निचली सीमा

स्टोकैस्टिक परिणामों को पुनरावृत्तियों में सर्वोत्तम, माध्य, माध्यिका, मानक विचलन और सबसे ख़राब के रूप में रिपोर्ट किया जाता है, अभिसरण वक्रों और वितरण आलेखों के साथ। तुलनाएँ अप्राचलिक परीक्षणों का उपयोग करती हैं — जोड़ीदार तुलना के लिए एक युग्मित चिह्नित-रैंक परीक्षण, विधियों के आर-पार एक समग्र रैंक परीक्षण जिसमें पश्च-तदर्थ सुधार हो — जिन्हें एक स्टोकैस्टिक-श्रेष्ठता प्रभाव आकार और एक क्रांतिक-अंतर आरेख के साथ रिपोर्ट किया जाता है। कोई परिणाम शोधपत्र तक तभी पहुँचता है जब वह उन्नति द्वार को पार करता है: वह अपने तुलनित्रों को प्रत्ययकारी और सार्थक रूप से पछाड़ता है, और यह उत्तीर्णता एक अंकेक्षण-योग्य रनबुक में दर्ज होती है।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| Blocked: run /research-experiment first | कोई कच्चा डेटा नहीं | डेटा ＋ लॉग उत्पन्न करने के लिए `/research-experiment` चलाएँ |
| प्रभाव आकार के बिना p-मान रिपोर्ट किया गया | अपूर्ण सांख्यिकीय रिपोर्टिंग | प्रभाव आकार ＋ विश्वास अंतराल रिपोर्ट करें |
| अनुद्घाटित विश्लेषण विचलन | योजना चुपचाप विचलित हुई | पूर्व-पंजीकरण के विरुद्ध विचलन उद्घाटित करें |

```bash
/research-analysis path/to/research-suite/
```
