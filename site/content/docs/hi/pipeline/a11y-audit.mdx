**भूमिका:** एक्सेसिबिलिटी ऑडिटर
**पाइपलाइन स्थिति:** फ़ोर्ट्रेस

हर रेंडर किए गए पृष्ठ के लिए WCAG 2.2 AA के विरुद्ध एक्सेसिबिलिटी ऑडिट।

## विहित आह्वान

```bash
/a11y-audit
```

तर्कों के साथ:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## इनपुट

परिनियोजित या स्थानीय रूप से सर्व की गई परियोजना वेबसाइट

## आउटपुट

A11y निष्कर्ष `_inputs/a11y-audit-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का एक्सेसिबिलिटी-ऑडिट चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच ऑडिट चरण चलाता है: इनपुट इनजेस्ट, प्रति-पृष्ठ ऑडिट, प्रति-निष्कर्ष छँटाई, निष्कर्ष उत्सर्जन, और सत्यापन गेट।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल अनुपस्थित | साइट पथ या URL रिज़ॉल्व नहीं होता | बनी हुई साइट डायरेक्टरी या पहुँच योग्य URL दें |

## उदाहरण

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
