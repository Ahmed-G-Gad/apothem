**भूमिका:** UX समीक्षक
**पाइपलाइन स्थिति:** किला

CLI एर्गोनॉमिक्स, दस्तावेज़ीकरण, और ऑनबोर्डिंग की डेवलपर-अनुभव समीक्षा।

## विहित आह्वान

```bash
/ux-review
```

तर्कों के साथ:

```bash
/ux-review [path/to/repo/] [--focus SURFACE] [--dry-run]
```

## इनपुट

README, इंस्टॉल स्क्रिप्ट, और CLI एंट्री पॉइंट वाली तैनात होस्ट रिपॉज़िटरी

## आउटपुट

UX निष्कर्ष `_inputs/ux-review-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का UX समीक्षा चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच चरण चलाता है: इनपुट इनजेस्ट, CLI-एर्गोनॉमिक्स वॉक, इंस्टॉलेशन-फ़्लो और एरर-रिकवरी ऑडिट, दस्तावेज़ीकरण-खोज्यता स्वीप, और सत्यापन गेट के साथ निष्कर्ष उत्सर्जन।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| पूर्वापेक्षा अपूर्ण | निर्भर फ़ेज़ समाप्त नहीं हुआ | पहले अपस्ट्रीम फ़ेज़ पूरा करें |
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| लक्ष्य तैनात नहीं | लक्ष्य में ऑपरेटर-सम्मुख सतह नहीं है | तैनात रिपॉज़िटरी रूट दें |

## उदाहरण

```bash
# Dry-run to preview what would happen
/ux-review --dry-run

# Execute against a host repository
/ux-review path/to/repo/
```
