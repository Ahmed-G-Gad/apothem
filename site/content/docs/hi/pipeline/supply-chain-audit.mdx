**भूमिका:** आपूर्ति-श्रृंखला ऑडिटर
**पाइपलाइन स्थिति:** फ़ोर्ट्रेस

SLSA + Sigstore + SBOM मानकों के विरुद्ध आपूर्ति-श्रृंखला ऑडिट।

## विहित आह्वान

```bash
/supply-chain-audit
```

तर्कों के साथ:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## इनपुट

होस्ट रिपॉज़िटरी की रिलीज़ पाइपलाइन

## आउटपुट

आपूर्ति-श्रृंखला निष्कर्ष `_inputs/supply-chain-audit-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का supply-chain-audit चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच ऑडिट चरण चलाता है: इनपुट इनजेस्ट, प्रति-अक्ष वॉक, प्रति-निष्कर्ष छँटाई, निष्कर्ष उत्सर्जन, और सत्यापन गेट।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| पूर्वापेक्षा अपूर्ण | निर्भर फ़ेज़ समाप्त नहीं हुआ | पहले अपस्ट्रीम फ़ेज़ पूरा करें |
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| लक्ष्य अस्वीकृत | लक्ष्य में रिलीज़ सतह नहीं है | .github/workflows/, एक रिलीज़ स्क्रिप्ट, या एक build मैनिफ़ेस्ट वाली रिपॉज़िटरी रूट दें |

## उदाहरण

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
