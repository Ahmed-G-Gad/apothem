**भूमिका:** प्रधान अन्वेषक (प्रकाशन)
**पाइपलाइन स्थिति:** मध्य-शृंखला

पेपर को प्रकाशन-स्थल टेम्प्लेट में स्वरूपित करता है और सबमिशन पैकेज असेंबल करता है — पूरक सामग्री, डेटा / कोड उपलब्धता विवरण, कवर लेटर, नैतिकता और हित-टकराव घोषणाएँ — साथ में DOI के साथ प्रीप्रिंट / अभिलेखन योजना और एक सबमिशन चेकलिस्ट। ऑपरेटर पैकेज सबमिट करता है; टर्मिनल उत्तराधिकारी `/research-disseminate` है, जो प्रकाशित कार्य को उसके श्रोताओं तक ले जाता है।

## विहित आह्वान

```bash
/research-publish
```

तर्कों के साथ:

```bash
/research-publish [path/to/research-suite/]
```

## इनपुट

पेपर डिलिवरेबल और `_outputs/review-report.md` (सहकर्मी-समीक्षा संशोधन)।

## आउटपुट

होस्ट के लिए स्वाभाविक स्थान पर प्रकाशन-स्थल-स्वरूपित सबमिशन पैकेज (स्वरूपित पांडुलिपि + पूरक सामग्री + डेटा / कोड उपलब्धता विवरण + कवर लेटर + नैतिकता / हित-टकराव घोषणाएँ) + `_outputs/publication-record.md` + एक सबमिशन चेकलिस्ट।

## अनुप्रवाह

/research-disseminate (अनुप्रवाह उपभोक्ता) — ऑपरेटर सबमिशन करता है, फिर `/research-disseminate` प्रकाशित कार्य को उसके श्रोताओं तक ले जाता है। जब प्रकाशन-स्थल संशोधन लौटाता है, तो पैकेज पुनर्निर्मित करने से पहले संशोधित पेपर के विरुद्ध `/research-review` फिर से चलाएँ।

## वर्कफ़्लो चरण

यह कमांड मानक `/research` पाइपलाइन वर्कफ़्लो का अनुसरण करता है:

1. **संदर्भ लोड करें** — पेपर और समीक्षा रिपोर्ट पढ़ें।
2. **अनुक्रम गेट सत्यापित करें** — पुष्टि करें कि `_outputs/review-report.md` मौजूद है; अन्यथा `Blocked: run /research-review first` के साथ रुकें।
3. **स्वरूपित और पैकेज करें** — प्रकाशन-स्थल टेम्प्लेट लागू करें; पूरक सामग्री, डेटा/कोड उपलब्धता, कवर लेटर, नैतिकता / हित-टकराव घोषणाएँ असेंबल करें।
4. **प्रीप्रिंट / अभिलेखन की योजना बनाएँ** — प्रीप्रिंट और DOI योजना रिकॉर्ड करें; सबमिशन चेकलिस्ट बनाएँ।
5. **हैंडऑफ़ मैनिफ़ेस्ट अपडेट करें** — सबमिशन पैकेज और प्रकाशन रिकॉर्ड रिकॉर्ड करें।
6. **पैकेज जारी करें** — प्रकाशन-स्थल-स्वरूपित सबमिशन पैकेज + `_outputs/publication-record.md`।

## कठोरता की निचली सीमा

स्वरूपण चरणबद्ध प्रकटन का सम्मान करता है: एक द्वि-अंध प्रकाशन-स्थल के लिए, लेखक, संस्थान और तंत्र की पहचान को अलग से प्रस्तुत मेटाडेटा तक छाँट दिया जाता है और केवल निर्दिष्ट कैमरा-रेडी चरण पर बहाल किया जाता है। अभिलेखीय निक्षेप प्रकाशन-स्थल-अनुरूप पुनरुत्पादनीयता-साक्ष्य पैकेज (डेटा, कोड, पिन किया गया परिवेश, सीड, हार्डवेयर लॉग, प्रति-इंस्टेंस परिणाम और आकृतियाँ) वहन करता है।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| Blocked: run /research-review first | कोई समीक्षा रिपोर्ट नहीं | `_outputs/review-report.md` उत्पन्न करने के लिए `/research-review` चलाएँ |
| असंबोधित HIGH संशोधन | समीक्षा निष्कर्ष छोड़ दिया गया | संशोधन को संबोधित करें और `/research-review` फिर से चलाएँ |
| डेटा/कोड उपलब्धता गायब | पुनरुत्पादनीयता सतह अनुपस्थित | सबमिशन से पहले डेटा / कोड उपलब्धता विवरण जोड़ें |

## उदाहरण

```bash
# प्रकाशन-स्थल सबमिशन पैकेज असेंबल करें
/research-publish path/to/research-suite/
```
