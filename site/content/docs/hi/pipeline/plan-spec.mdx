**भूमिका:** फोर्ज
**पाइपलाइन स्थिति:** शीर्ष

मुक्त-रूप गद्य या कच्चे नोट्स को `/plan-generate` के लिए तैयार spec-स्तर की `_spec/spec.md` विशिष्टि में परिष्कृत करता है।

## विहित आह्वान

```bash
/plan-spec
```

तर्कों के साथ:

```bash
/plan-spec [path/to/prose-source] [--suite-name NAME] [--refine-existing] [--standalone] [--quick SLUG [--tag TAG]]
```

## इनपुट

मुक्त-रूप गद्य, कच्चे नोट्स, या तदर्थ आवश्यकताएँ (ऑपरेटर द्वारा इनलाइन या पथ के रूप में प्रदान की गई)।

## आउटपुट

`_spec/spec.md` (पदोन्नत स्पेक) + `_inputs/handoff-manifest.yml`। `--quick` इसके बजाय `<project-root>/.apothem/plans/<YYYY-MM-DD>--<kebab-slug>.md` पर एक एकल परियोजना-स्थानीय हल्की प्लान फ़ाइल लिखता है।

## अनुप्रवाह

/plan-generate (अनुप्रवाह उपभोक्ता)

## वर्कफ़्लो फ़ेज़

फोर्ज छह रूपांतरण फ़ेज़ चलाता है (स्पेक को G4 पर `_inputs/forge.md` से `_spec/spec.md` में पदोन्नत किया जाता है):

1. **खोज और निष्कर्षण** — गद्य / नोट्स पढ़ें और प्रत्येक आवश्यकता, निर्णय, और अड़चन निकालें।
2. **सूक्ष्म विचार** — प्रत्येक सतह पर तर्क करें; संरचित-पूछताछ चैनल के माध्यम से हर विरोधाभास को सतह पर लाएँ।
3. **सामर्थ्य मानचित्रण** — प्रत्येक आवश्यकता को उसके अनुप्रवाह लाभ से मानचित्रित करें।
4. **संरक्षण सत्यापन** — पदोन्नति से पहले उम्मीदवार स्पेक के विरुद्ध पंद्रह-बार पूर्व-उत्सर्जन गेट (G4) चलाएँ।
5. **विशेषज्ञता अनुप्रयोग** — डोमेन विशेषज्ञता लागू करें; विशेषज्ञता-अंतराल निष्कर्ष लॉग करें।
6. **प्रश्न-समाधान सर्वेक्षण** — G0–G5 गेटों में हर खुली पूछताछ को हल करें, फिर `_spec/spec.md` के साथ हैंडऑफ़ मैनिफ़ेस्ट उत्सर्जित करें।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुम गद्य इनपुट | कोई गद्य / नोट्स प्रदान नहीं किए गए | मुक्त-रूप गद्य को इनलाइन या पथ के रूप में प्रदान करें |
| अनसुलझा विरोधाभास | गद्य में परस्पर-विरोधी आवश्यकताएँ हैं | G3 (पूर्व-संशोधन) पर रुकें; संरचित पूछताछ के माध्यम से हल करें, कभी मौन रूप से नहीं |
| स्पेक गेट में विफल | G4 पर कोई पूर्व-उत्सर्जन बार विफल होता है | `_inputs/forge.md` से पदोन्नति से पहले विफल बार ठीक करें |

## उदाहरण

```bash
# कच्चे नोट्स को spec-स्तर की विशिष्टि में फोर्ज करें
/plan-spec ~/notes/feature.md --suite-name my-feature

# हल्की परियोजना-स्थानीय प्लान फ़ाइल (फोर्ज एलिसिटेशन को बायपास करती है)
/plan-spec --quick my-feature
```
