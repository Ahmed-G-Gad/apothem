**भूमिका:** समीक्षक
**पाइपलाइन स्थिति:** फ़ोर्ट्रेस

src/, scripts/ और tools/ में ऑपरेटर-संचालित प्रति-फ़ाइल कोड-गुणवत्ता समीक्षा पास।

## विहित आह्वान

```bash
/code-review
```

तर्कों के साथ:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## इनपुट

जीवनचक्र की किसी भी स्थिति में होस्ट रिपॉज़िटरी

## आउटपुट

प्रति-फ़ाइल निष्कर्ष `_inputs/code-review-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का पंक्ति-दर-पंक्ति समीक्षा चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच चरण चलाता है: इनपुट इनजेस्ट, प्रति-फ़ाइल वॉक, प्रति-निष्कर्ष छँटाई, निष्कर्ष उत्सर्जन, और सत्यापन गेट।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल अनुपस्थित | रिपॉज़िटरी में `src/`, `scripts/`, या `tools/` में से कोई नहीं है | ऐसी रिपॉज़िटरी रूट दें जिसमें इनमें से कम से कम एक हो |

## उदाहरण

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
