**भूमिका:** जनरेटर
**पाइपलाइन स्थिति:** मध्य

लिखित `_spec/spec.md` से एक पूर्ण मास्टर प्लान सूट जनरेट करता है।

## विहित आह्वान

```bash
/plan-generate
```

तर्कों के साथ:

```bash
/plan-generate [path/to/prose.md] [--mode NEW|OVERHAUL] [--seriousness LEVEL] [--context CONTEXT] [--mission MISSION] [--domain DOMAIN] [--dry-run]
```

## इनपुट

`/plan-spec` से लिखित `_spec/spec.md` + `_inputs/handoff-manifest.yml` (या ऑपरेटर-प्रदत्त गद्य)।

## आउटपुट

`PREAMBLE.md`, `MASTER-PLAN.md`, `PROGRESS.md`, `PLAN-NOTES.md`, और प्रति-फ़ेज़ `phases/**/PHASE.md` फ़ाइलें, साथ ही संवर्धित `_inputs/handoff-manifest.yml`।

## अनुप्रवाह

/plan-review या /plan-execute (अनुप्रवाह)

## वर्कफ़्लो फ़ेज़

यह कमांड लिखित स्पेक से एक पूर्ण मास्टर प्लान सूट जनरेट करता है:

1. **आवश्यकताएँ अंतर्ग्रहण करें** — `_spec/spec.md` और अपस्ट्रीम हैंडऑफ़ मैनिफ़ेस्ट पढ़ें; स्पेक अनुपस्थित होने पर `Blocked: run /plan-spec first` के साथ अस्वीकार करें।
2. **खोजें** — पाँच संज्ञानात्मक फ़िल्टरों के साथ गंभीरता-मापित खोज चलाएँ; हर अधिकार-डेटा अंतराल को संरचित-पूछताछ चैनल के माध्यम से हल करें।
3. **विघटित करें** — कार्य को एक स्पष्ट निर्भरता क्रम वाले अचक्रीय फ़ेज़ ग्राफ़ में तोड़ें।
4. **सूट उत्सर्जित करें** — `PREAMBLE.md`, `MASTER-PLAN.md`, `PROGRESS.md`, `PLAN-NOTES.md`, और प्रत्येक `phases/NN-topic/PHASE.md` रचें।
5. **पूर्व-उत्सर्जन गेट चलाएँ** — प्रत्येक उत्सर्जित आर्टिफ़ैक्ट के विरुद्ध पंद्रह-बार सर्वेक्षण चलाएँ; विफलता समाधान तक उपयोक्ता-अनुमोदन रोकती है।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| Blocked: run /plan-spec first | कोई लिखित `_spec/spec.md` नहीं | स्पेक रचने और मैनिफ़ेस्ट उत्सर्जित करने के लिए `/plan-spec` चलाएँ |
| `_inputs/` फ़ाइल के विरुद्ध जनरेशन | स्पेक अभी भी एलिसिटेशन-मध्य | पहले `/plan-spec` के माध्यम से `_inputs/forge.md` को `_spec/spec.md` में पदोन्नत करें |
| पूर्व-उत्सर्जन बार विफल | कोई उत्सर्जित आर्टिफ़ैक्ट गेट में विफल होता है | उपयोक्ता-अनुमोदन से पहले विफल बार ठीक करें |

## उदाहरण

```bash
# जनरेट किए गए फ़ेज़ ग्राफ़ का पूर्वावलोकन करने के लिए Dry-run
/plan-generate --dry-run

# लिखित गद्य से एक सूट जनरेट करें
/plan-generate path/to/prose.md --mode NEW
```
