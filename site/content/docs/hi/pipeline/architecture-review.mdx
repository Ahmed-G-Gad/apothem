**भूमिका:** आर्किटेक्चर समीक्षक
**पाइपलाइन स्थिति:** फ़ोर्ट्रेस

`_inputs/design.md` के डिज़ाइन आर्टिफ़ैक्ट के विरुद्ध आर्किटेक्चरल-अखंडता समीक्षा।

## विहित आह्वान

```bash
/architecture-review
```

तर्कों के साथ:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## इनपुट

होस्ट रिपॉज़िटरी + `_inputs/design.md`

## आउटपुट

आर्किटेक्चर निष्कर्ष `_inputs/architecture-review-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का आर्किटेक्चर-समीक्षा चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच ऑडिट चरण चलाता है: इनपुट इनजेस्ट, डिज़ाइन-से-कोड ट्रेसेबिलिटी वॉक, लेयर-सीमा अखंडता ऑडिट, क्रॉस-पैकेज युग्मन स्वीप, और सत्यापन गेट के साथ निष्कर्ष उत्सर्जन।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल अनुपस्थित | डिज़ाइन आर्टिफ़ैक्ट `_inputs/design.md` नहीं है | इसे बनाने के लिए `/plan-design` चलाएँ |

## उदाहरण

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
