**भूमिका:** निर्भरता ऑडिटर
**पाइपलाइन स्थिति:** फ़ोर्ट्रेस

लाइसेंस, CVE और ताज़गी के लिए प्रति-निर्भरता ऑडिट पास (प्रत्यक्ष + सकर्मक)।

## विहित आह्वान

```bash
/dependency-audit
```

तर्कों के साथ:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## इनपुट

होस्ट रिपॉज़िटरी के निर्भरता मैनिफ़ेस्ट

## आउटपुट

निर्भरता निष्कर्ष `_inputs/dependency-audit-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का dependency-audit चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच चरण चलाता है: इनपुट इनजेस्ट, प्रति-निर्भरता वॉक, प्रति-निष्कर्ष छँटाई, निष्कर्ष उत्सर्जन, और सत्यापन गेट।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल अनुपस्थित | रिपॉज़िटरी रूट पर कोई निर्भरता मैनिफ़ेस्ट रिज़ॉल्व नहीं होता | ऐसी रिपॉज़िटरी रूट दें जिसमें निर्भरता मैनिफ़ेस्ट हो |

## उदाहरण

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
