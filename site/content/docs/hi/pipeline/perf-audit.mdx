**भूमिका:** प्रदर्शन ऑडिटर
**पाइपलाइन स्थिति:** फ़ोर्ट्रेस

USE विधि का उपयोग करते हुए प्रति-वर्ग प्रदर्शन बजट के विरुद्ध ऑडिट करता है (हुक रनटाइम, verify-ecosystem, अनुरूपता गेट, टेस्ट, प्रत्यायोजित वर्कर, शेल, लिंट)।

## विहित आह्वान

```bash
/perf-audit
```

तर्कों के साथ:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## इनपुट

होस्ट रिपॉज़िटरी जिसमें `hooks/`, `src/apothem/benchmarks/`, `tests/`, और हुक बूटस्ट्रैप स्टब `hooks/lib/bootstrap.{sh,ps1}` हों

## आउटपुट

प्रदर्शन निष्कर्ष `_inputs/perf-audit-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का प्रदर्शन-ऑडिट चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच ऑडिट चरण चलाता है: इनपुट इनजेस्ट, प्रति-वर्ग बजट खोज, बेंचमार्क निष्पादन, USE विधि द्वारा हॉट-पाथ पहचान, और सत्यापन गेट के साथ निष्कर्ष उत्सर्जन।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल अनुपस्थित | रिपॉज़िटरी में `src/apothem/benchmarks/` नहीं है | बेंचमार्क ड्राइवर जोड़ें, फिर पुनः चलाएँ; ये मौजूद होने तक कमांड मना कर देता है |

## उदाहरण

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
