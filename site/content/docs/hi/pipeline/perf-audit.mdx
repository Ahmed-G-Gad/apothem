- **भूमिका:** प्रदर्शन ऑडिटर
- **पाइपलाइन स्थिति:** फ़ोर्ट्रेस

USE विधि का उपयोग करते हुए प्रति-वर्ग प्रदर्शन बजट के विरुद्ध ऑडिट करता है (हुक रनटाइम, verify-ecosystem, अनुरूपता गेट, टेस्ट, प्रत्यायोजित वर्कर, शेल, लिंट, इंस्टॉल रिज़ॉल्यूशन)।

## विहित आह्वान

```bash
/perf-audit
```

तर्कों के साथ:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## इनपुट

Apothem रिपॉज़िटरी की प्रति जिसमें `src/apothem/hooks/`, `src/apothem/benchmarks/`, `tests/`, और हुक बूटस्ट्रैप स्टब `src/apothem/hooks/lib/bootstrap.{sh,ps1}` हों

## आउटपुट

प्रदर्शन निष्कर्ष `_inputs/perf-audit-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का प्रदर्शन-ऑडिट चरण

## वर्कफ़्लो फ़ेज़

यह कमांड पाँच ऑडिट चरण चलाता है: इनपुट इनजेस्ट, प्रति-वर्ग बजट खोज, बेंचमार्क निष्पादन, USE विधि द्वारा हॉट-पाथ पहचान, और सत्यापन गेट के साथ निष्कर्ष उत्सर्जन।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| Apothem रिपॉज़िटरी की प्रति नहीं | रिपॉज़िटरी में `src/apothem/benchmarks/` नहीं है | कुछ ठीक करने की ज़रूरत नहीं: कमांड इस आयाम को लागू नहीं के रूप में रिपोर्ट करता है, और `/audit` इसे छोड़ देता है |

## उदाहरण

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
