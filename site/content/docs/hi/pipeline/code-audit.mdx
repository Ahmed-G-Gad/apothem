**भूमिका:** ऑडिटर
**पाइपलाइन स्थिति:** किला

रिपॉज़िटरी-कॉर्पस दायरे पर अंतर-फ़ाइल फोरेंसिक कोड ऑडिट।

## विहित आह्वान

```bash
/code-audit
```

तर्कों के साथ:

```bash
/code-audit [path/to/plan-suite/] [phase-id] [--dry-run]
```

## इनपुट

जीवन-चक्र की किसी भी स्थिति में परपोषी रिपॉज़िटरी

## आउटपुट

कॉर्पस-स्तरीय निष्कर्ष + REPORT.md

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का फोरेंसिक कोड ऑडिट चरण

## वर्कफ़्लो फ़ेज़

यह कमांड मानक `/plan` पाइपलाइन वर्कफ़्लो का अनुसरण करता है:

1. **संदर्भ लोड करें** — योजना सूट, नियम, और पुनरारंभ अनुबंध पढ़ें।
2. **पूर्वापेक्षाएँ सत्यापित करें** — पुष्टि करें कि निर्भर फ़ेज़ पूर्ण हैं।
3. **कार्य निष्पादित करें** — कमांड का मिशन पूरा करें।
4. **आउटपुट सत्यापित करें** — पुष्टि करें कि सभी घोषित आउटपुट मौजूद हैं और गुणवत्ता गेट पास करते हैं।
5. **PROGRESS.md अद्यतन करें** — सत्यापित आउटपुट को फ़ेज़ आउटपुट रजिस्ट्री में दर्ज करें।
6. **REPORT.md जारी करें** — पूर्व-उत्सर्जन गेट का रिलीज़ प्रमाण दर्ज किया गया।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| पूर्वापेक्षा अपूर्ण | निर्भर फ़ेज़ समाप्त नहीं हुआ | पहले ऊपरी-धारा फ़ेज़ पूरा करें |
| गुणवत्ता गेट FAIL | आउटपुट मानकों को पूरा नहीं करता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल लुप्त | योजना सूट फ़ाइल अनुपस्थित | इसे बनाने के लिए `/plan-generate` चलाएँ |

## उदाहरण

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a named plan suite
/code-audit path/to/plan-suite/
```
