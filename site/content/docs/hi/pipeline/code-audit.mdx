**भूमिका:** ऑडिटर
**पाइपलाइन स्थिति:** किला

रिपॉज़िटरी-कॉर्पस दायरे पर अंतर-फ़ाइल फोरेंसिक कोड ऑडिट।

## विहित आह्वान

```bash
/code-audit
```

तर्कों के साथ:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## इनपुट

अनुमोदित स्रोत लेआउट, एक टेस्ट-कवरेज बेसलाइन, और (SHARED+ पर) एक उत्तीर्ण CI गेट वाली होस्ट रिपॉज़िटरी

## आउटपुट

कॉर्पस-स्तरीय निष्कर्ष `_inputs/code-audit-findings.md` पर

## अनुप्रवाह

ऑडिट समीक्षा अनुक्रम का फोरेंसिक कोड ऑडिट चरण

## वर्कफ़्लो फ़ेज़

यह कमांड छह फ़ॉरेंसिक चरण चलाता है: इनपुट इनजेस्ट, क्रॉस-फ़ाइल निर्भरता वॉक, टाइप-हिंट और कवरेज ऑडिट, डेड-कोड और डुप्लिकेट पहचान, आर्किटेक्चरल-अखंडता ऑडिट, और सत्यापन गेट के साथ निष्कर्ष उत्सर्जन।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| गुणवत्ता गेट FAIL | आउटपुट मानकों पर खरा नहीं उतरता | आउटपुट ठीक करें और पुनः चलाएँ |
| इनपुट फ़ाइल अनुपस्थित | SHARED+ पर कोई CI गेट रन या टेस्ट-कवरेज बेसलाइन नहीं है | होस्ट की CI पाइपलाइन पहले चलाएँ, फिर पुनः चलाएँ |

## उदाहरण

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
