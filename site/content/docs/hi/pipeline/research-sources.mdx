**भूमिका:** प्रधान अन्वेषक (स्रोत संग्रह)
**पाइपलाइन स्थिति:** श्रृंखला-मध्य

व्यवस्थित स्रोत संग्रह — शोध स्पेक को उप-प्रश्नों में विघटित करता है, स्रोत खोज और प्रति-स्रोत निष्कर्षण को समानांतर में फैलाता है, अपवर्जित दोहराव हटाता है, प्राधिकार / नवीनता / प्रासंगिकता के अनुसार रैंक करता है, स्पेक के समावेशन मानदंडों के विरुद्ध छानता है, और प्रत्येक बचे हुए स्रोत के लिए उद्गम रिकॉर्ड करता है।

## विहित आह्वान

```bash
/research-sources
```

तर्कों के साथ:

```bash
/research-sources [path/to/research-suite/] [--depth N]
```

## इनपुट

`_inputs/theory.md` (`/research-theory`, पूर्ववर्ती चरण, से वैचारिक / सैद्धांतिक रूपरेखा) साथ ही `_spec/research-spec.md` (`/research-spec` से अनुमोदित शोध स्पेक)।

## आउटपुट

`sources/<id>.md` (प्रत्येक बचे हुए स्रोत के लिए एक उद्गम-वाहक निष्कर्षण) + `_inputs/source-ledger.md` (उद्धरण सूचकांक के साथ रैंक किया गया, छाना गया, अपवर्जित-दोहराव-हटाया गया स्रोत सूचकांक)।

## अनुप्रवाह

/research-synthesis (अनुप्रवाह उपभोक्ता)

## वर्कफ़्लो चरण

यह कमांड मानक `/research` पाइपलाइन वर्कफ़्लो का अनुसरण करता है:

1. **संदर्भ लोड करें** — शोध स्पेक और उसके समावेशन / अपवर्जन मानदंड पढ़ें।
2. **अनुक्रम गेट सत्यापित करें** — पुष्टि करें कि `_inputs/theory.md` (और अनुमोदित `_spec/research-spec.md`) मौजूद है; अन्यथा `Blocked: run /research-theory first` के साथ रुकें।
3. **खोजें और निष्कर्षित करें** — उप-प्रश्नों में विघटित करें, खोज फैलाएँ, दोहराव हटाएँ, रैंक करें, छानें, और प्रति स्रोत उद्गम के साथ निष्कर्षित करें।
4. **आउटपुट सत्यापित करें** — पुष्टि करें कि प्रत्येक बचा हुआ स्रोत उद्धृत और स्पेक मानदंडों के विरुद्ध छाना गया है।
5. **हैंडऑफ़ मैनिफ़ेस्ट अपडेट करें** — स्रोत बही और प्रति-स्रोत निष्कर्षण पथ रिकॉर्ड करें।
6. **बही जारी करें** — `sources/` निष्कर्षण साथ ही `_inputs/source-ledger.md`।

## कठोरता की निचली सीमा

स्रोत बही से परे, यह चरण एक तुलनित्र-उद्गम बही बनाता है: वे निकटतम-हालिया अत्याधुनिक आधाररेखाएँ जिनके विरुद्ध अध्ययन चलेगा, जिनमें से प्रत्येक की एक पुनर्प्राप्य स्रोत के रूप में पुष्टि की गई हो और जिसे उसके उद्गम तथा पहुँच-योग्यता के साथ रिकॉर्ड किया गया हो। जिस तुलनित्र की पुष्टि या प्राप्ति न हो सके उसे वैसा ही चिह्नित किया जाता है और कभी गढ़ा नहीं जाता (R1, R4)।

## विफलता मोड

| लक्षण | कारण | पुनर्प्राप्ति |
|---------|-------|----------|
| Blocked: run /research-theory first | कोई सैद्धांतिक आधार नहीं | `_inputs/theory.md` उत्पन्न करने के लिए `/research-theory` चलाएँ |
| स्रोत समावेशन मानदंड में विफल | दायरे-बाहर या निम्न-प्राधिकार स्रोत | छानकर बाहर करें; बही में अपवर्जन का तर्क रिकॉर्ड करें |
| गढ़ा गया उद्धरण | अनुमानित, न कि वास्तव में प्राप्त किया गया स्रोत | स्रोत कभी न गढ़ें; अनुमानित उद्धरण एक निष्कर्ष है |

## उदाहरण

```bash
# एक फ़्रेम किए गए शोध सूट के लिए स्रोत एकत्र करें
/research-sources path/to/research-suite/

# गहरा खोज फैलाव
/research-sources path/to/research-suite/ --depth N
```
