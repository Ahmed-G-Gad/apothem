हुक shell कमांड हैं जो हार्नेस इवेंट पर ट्रिगर होते हैं। वे ऑपरेटर के हस्तक्षेप के
बिना अनुरूपता लागू करते हैं, संदर्भ इंजेक्ट करते हैं, और गुणवत्ता गेट चलाते हैं।

## हुक इवेंट

| इवेंट | कब ट्रिगर होता है |
|-------|--------------|
| `PreToolUse` | हर टूल कॉल से पहले |
| `PostToolUse` | हर टूल कॉल के बाद |
| `SessionStart` | सत्र बूटस्ट्रैप पर |
| `PreCompact` | संदर्भ संघनन से पहले |
| `PostCompact` | संदर्भ संघनन के बाद |
| `Stop` | सत्र समाप्ति पर |

## हुक संदेश फ़ाइलें

प्रत्येक हुक की `src/apothem/hooks/messages/<event>-<name>.md` पर एक संगत संदेश
फ़ाइल होती है, जो हुक के ट्रिगर होने के क्षण पर सहायक को संदर्भ प्रदान करती है।

## हुक पंजीकृत करना

हुक कमांड को `settings.json` में जोड़ें:

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write",
        "hooks": [
          {
            "type": "command",
            "command": "python src/apothem/hooks/my-check.py"
          }
        ]
      }
    ]
  }
}
```

## हुक डिस्पैचर

सभी हुक `src/apothem/hooks/dispatch.py` के माध्यम से रूट होते हैं, जो किसी भी हुक
त्रुटि को fail-open लिफ़ाफ़े में बदल देता है ताकि हुक कभी हार्नेस को अवरुद्ध न करें।
