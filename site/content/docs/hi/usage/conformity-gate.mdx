`src/apothem/conformity/gate.py` पर स्थित अनुरूपता गेट ऑपरेटर द्वारा लिखे गए
हर आर्टिफ़ैक्ट के विरुद्ध पंद्रह यांत्रिक जाँचें चलाता है।

## गेट चलाना

```bash
python -m apothem.conformity.gate
```

| बार | जाँच | प्रकार |
|-----|-------|------|
| M1 | दायरा संरेखण | तर्कपूर्ण |
| M2 | योजना-आंतरिक पृथक्करण (CM-7) | यांत्रिक |
| M3 | मानक अनुपालन | तर्कपूर्ण |
| M4 | फ़्रंटमैटर वैधता | यांत्रिक |
| M5 | कोई निषिद्ध वाक्यांश नहीं | यांत्रिक |
| M6 | संपादकीय प्रकटीकरण | तर्कपूर्ण |
| M7 | आर्टिफ़ैक्ट में कोई योजना संदर्भ नहीं | यांत्रिक |
| M8 | लेखकत्व हेडर मौजूद | यांत्रिक |
| M9 | ईमानदार आकलन | तर्कपूर्ण |
| M10 | नामकरण अनुशासन | यांत्रिक |
| M11 | स्प्रिंट तंत्र | तर्कपूर्ण |
| M12 | विहित लेआउट | यांत्रिक |

## लक्षित जाँचें

```bash
# एकल जाँच चलाएँ
python -m apothem.conformity.gate --check multi-surface-coherence

# किसी विशिष्ट फ़ाइल के विरुद्ध चलाएँ
python -m apothem.conformity.gate src/apothem/rules/my-rule.md
```

## CI एकीकरण

गेट हर पुश पर `.github/workflows/conformity.yml` के माध्यम से CI में चलता है।
