Apothem प्रत्यायोजित वर्कर्स स्थायी, पुन: प्रयोज्य वर्कर परिभाषाएँ हैं जो `src/apothem/`
ट्री के अंतर्गत संग्रहीत होती हैं (विहित डायरेक्टरी नीचे दिखाई गई है — नाम रनटाइम
लोडर के साथ संगतता के लिए संरक्षित है):

```text
src/apothem/agents/
```

प्रत्येक प्रत्यायोजित वर्कर एक विशेषीकृत भूमिका, पहचान संकेत, और एक अनुमत-टूल सेट को एनकोड
करता है।

## प्रत्यायोजित वर्कर फ़ाइल संरचना

```markdown
---
name: "my-agent"
description: "..."
tools: "Read, Grep, Glob"
---

# My assistant

## Role
...

## Detection signals
Matched when: ...

## Workflow
...
```

## अंतर्निहित प्रत्यायोजित वर्कर्स

| प्रत्यायोजित वर्कर | उद्देश्य |
|-------|---------|
| `codebase-explorer` | गहन कोडबेस अन्वेषण |
| `convention-auditor` | नामकरण और फ़ॉर्मेटिंग सत्यापन |
| `memory-auditor` | मेमोरी सटीकता सत्यापन |
| `quality-gate` | lint, टेस्ट, टाइप-चेक, सुरक्षा स्कैन |

## प्रत्यायोजित वर्कर्स का आह्वान

प्रत्यायोजित वर्कर्स को ऑर्केस्ट्रेटर द्वारा होस्ट रनटाइम द्वारा उजागर
प्रत्यायोजन टूल के माध्यम से डिस्पैच किया जाता है। ऑर्केस्ट्रेटर कार्य विवरण और
पहचान संकेतों के आधार पर मिलान करने वाले प्रत्यायोजित वर्कर का चयन करता है।
