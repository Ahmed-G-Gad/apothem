यह रोडमैप बताता है कि Apothem किस दिशा में जा रहा है। यह इरादे का एक कथन है,
कोई प्रतिबद्धता नहीं; परियोजना और उसके उपयोगकर्ताओं के विकसित होने के साथ
प्राथमिकताएँ बदलती हैं। जो पहले ही शिप हो चुका है, उसके लिए
[चेंजलॉग](https://github.com/ahmed-g-gad/apothem/blob/main/CHANGELOG.md) देखें।
रिपॉज़िटरी की
[ROADMAP.md](https://github.com/ahmed-g-gad/apothem/blob/main/ROADMAP.md)
एकमात्र रोडमैप है; परियोजना वेबसाइट पर
[रोडमैप पृष्ठ](https://apothem.ahmedgad.com/docs/community/roadmap) उसी से
उत्पन्न होता है।

स्थिति संकेत: **नियोजित** · **प्रगति में** · **शिप किया गया**।

## वर्तमान रिलीज़

वर्तमान लाइन होस्ट-अज्ञेय हार्नेस कॉन्फ़िगरेशन प्रबंधक शिप करती है: एक साझा
प्रोफ़ाइल (`~/.config/apothem/profile.yaml`) जो पंजीकृत अडैप्टरों के लिए
हार्नेस-नेटिव कॉन्फ़िगरेशन में मूर्त रूप लेती है, और जिसे `apothem` कमांड लाइन
(`quickstart` · `install` · `update` · `uninstall` · `rollback` · `backups` ·
`verify` · `status` · `diff` · `harnesses` · `profile` · `doctor` ·
`migrate-workspace` · `completion`) संचालित करती है।

| आइटम | स्थिति | टिप्पणियाँ |
| ---- | ------ | ----- |
| सत्रह हार्नेस अडैप्टर | शिप किया गया | प्रत्येक में इंस्टॉल, अनइंस्टॉल, अपडेट और सत्यापन; [समर्थित हार्नेस](https://apothem.ahmedgad.com/docs/harnesses) पृष्ठ उन्हें सूचीबद्ध करते हैं |
| मैनिफ़ेस्ट-संचालित टेम्पलेट प्रसार | शिप किया गया | `src/apothem/lib/propagation-manifest.yaml` पर प्रसार के सत्य का एक स्रोत |
| दस्तावेज़ साइट | शिप किया गया | उत्पन्न संदर्भ सूचकांकों, ब्रांड एसेट, एक मशीन-पठनीय साइट सूचकांक और रिलीज़ रनबुक के साथ सार्वजनिक साइट |
| हस्ताक्षरित रिलीज़ | शिप किया गया | हर GitHub Release में हस्ताक्षरित आर्टिफ़ैक्ट, एक SBOM और बिल्ड प्रोवेनेंस होते हैं |
| `/plan` और `/research` पाइपलाइनें | शिप किया गया | विनिर्देश, जनन, समीक्षा और निष्पादन चरणों वाली योजना पाइपलाइन, साथ ही तेरह-चरणीय शोध पाइपलाइन |
| ऑडिट कमांड और `/fortress` लूप | शिप किया गया | माँग पर सुरक्षा, कोड, सुगम्यता, प्रदर्शन, निर्भरता, आपूर्ति-श्रृंखला, ख़तरा-मॉडल, आर्किटेक्चर, कोड-समीक्षा, दस्तावेज़-समीक्षा और UX ऑडिट, जिन्हें `/fortress` हार्डनिंग लूप लपेटता है |
| ऑडिट और ड्रिफ़्ट-समीक्षा अवसंरचना | शिप किया गया | ऑडिट कमांडों के पीछे इन्वेंटरी और ड्रिफ़्ट स्कैनर |
| अनुरूपता गेट | शिप किया गया | हर मूर्त सतह पर लेखकत्व हेडर, नामकरण, कोड शिल्प, हेजिंग और बाइंडिंग पारस्परिकता के लिए वैलिडेटर, साथ में व्यवहार-डिफ़ गोल्डन जो प्रत्येक अडैप्टर के आउटपुट को लॉक करते हैं |
| टिकाऊ स्मृति और ऑप्ट-इन सतत सीखना | शिप किया गया | एक स्थायी स्मृति स्तर और एक ऑप्ट-इन सीखने का लूप, जो पुष्ट परिपाटियों को सत्रों के पार ले जाते हैं |
| npm / npx वितरण | शिप किया गया | `@ahmed-g-gad/apothem` पैकेज `npx @ahmed-g-gad/apothem` के माध्यम से इंजन चलाता है |
| Claude Code प्लगइन लिस्टिंग | शिप किया गया | `/plugin marketplace add ahmed-g-gad/apothem` के साथ इंस्टॉल की जाती है |
| CI/CD पाइपलाइन और हस्ताक्षरित-रिलीज़ आपूर्ति श्रृंखला | शिप किया गया | रिलीज़ से पहले हर परिवर्तन lint, परीक्षणों, टाइप जाँचों, एक दस्तावेज़ बिल्ड और आपूर्ति-श्रृंखला जाँचों पर गेट किया जाता है |

## निकट अवधि

| आइटम | स्थिति | टिप्पणियाँ |
| ---- | ------ | ----- |
| दस्तावेज़ गाइड | प्रगति में | वास्तविक हार्नेस सेटअप के लिए अधिक कार्य-केंद्रित गाइड, डायग्राम और उदाहरण |
| npx प्लेटफ़ॉर्म कवरेज | नियोजित | `@ahmed-g-gad/apothem` npx एंट्री पॉइंट को हर रिलीज़ के साथ संरेखित रखना और उसकी प्लेटफ़ॉर्म कवरेज बढ़ाना |
| प्लगइन लिस्टिंग का विस्तार | नियोजित | मार्केटप्लेस सतह के स्थिर होने के साथ प्लगइन लिस्टिंग का विस्तार करना |
| और हार्नेस अडैप्टर | नियोजित | अतिरिक्त हार्नेस, जैसे-जैसे उनकी कॉन्फ़िगरेशन परिपाटियाँ स्थिर होती हैं और उपयोगकर्ता उनका अनुरोध करते हैं |
| प्रोफ़ाइल स्कीमा संवर्धन | नियोजित | अधिक समृद्ध प्रति-हार्नेस ओवरराइड सतहें और अधिक सख़्त सत्यापन निदान |
| अनुरूपता गेट में प्रोफ़ाइल सत्यापन | नियोजित | एक गेट जाँच के रूप में साझा प्रोफ़ाइल को उसके स्कीमा के विरुद्ध सत्यापित करना |
| प्रोफ़ाइल संस्करणन और माइग्रेशन | नियोजित | प्रोफ़ाइल प्रारूप को संस्करणित करना और पुरानी प्रोफ़ाइलों को आगे माइग्रेट करना |
| `apothem update --watch` | नियोजित | प्रोफ़ाइल बदलने पर हार्नेस कॉन्फ़िगरेशन को फिर से मूर्त रूप देना |

## दीर्घकालिक दृष्टि

Apothem का लक्ष्य वह डिफ़ॉल्ट तरीका बनना है जिससे कोई भी अपने उपयोग के हर टूल
में हार्नेस कॉन्फ़िगरेशन प्रबंधित करता है: परिपाटियाँ एक बार लिखें, उन्हें हर जगह
मूर्त रूप दें, और प्राथमिकताओं तथा हार्नेसों, दोनों के विकसित होने के साथ उन्हें
सिंक में रखें।
