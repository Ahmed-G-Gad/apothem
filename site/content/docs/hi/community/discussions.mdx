## GitHub Discussions

प्राथमिक समुदाय स्थल [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions) है।

श्रेणियाँ:

| श्रेणी | किसके लिए उपयोग करें |
|----------|---------|
| Q&A | उपयोग, कॉन्फ़िगरेशन, और व्यवहार के बारे में प्रश्न |
| Ideas | फ़ीचर अनुरोध और डिज़ाइन चर्चाएँ |
| Show and tell | साझा करें कि आप Apothem का उपयोग कैसे करते हैं |
| General | कुछ और |

## Issues

बग और ठोस फ़ीचर अनुरोधों के लिए,
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues) का उपयोग करें।

कोई issue खोलने से पहले, डुप्लिकेट से बचने के लिए मौजूदा issues और discussions खोजें।

## योगदान

कोड, डॉक्स, और हार्नेस अडैप्टर में योगदान कैसे करें इसके लिए
[योगदान](/docs/developer-guide) देखें। रिपॉज़िटरी की
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
और उसमें संदर्भित पुल-रिक्वेस्ट टेम्पलेट से आरंभ करें।
