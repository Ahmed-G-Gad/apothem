## गंभीरता सीढ़ी

गेट में गंभीर, महत्वपूर्ण या परामर्शी स्तर की कोई सीढ़ी नहीं है, और दो-निष्कर्ष की कोई सीमा नहीं है। `--strict` (या `APOTHEM_CONFORMITY_STRICT=1`) के बिना गेट निष्कर्ष रिपोर्ट करता है और `0` के साथ बाहर निकलता है। `--strict` के साथ, एकल-फ़ाइल या हुक जाँच किसी भी मैचर के विफल होने पर `2` के साथ बाहर निकलती है, और कॉर्पस रन (`--all-perwrite`) जब कोई ब्लॉकिंग मैचर विफल होता है तो `2` के साथ बाहर निकलता है; परामर्शी मैचर केवल रिपोर्ट किए जाते हैं। इंस्टॉल किया गया Write/Edit हुक `--strict` पास नहीं करता, इसलिए वह निष्कर्ष रिपोर्ट करता है और लेखन आगे बढ़ता है, जब तक उसके एनवायरनमेंट में `APOTHEM_CONFORMITY_STRICT=1` सेट न हो।

## वैलिडेटर

यांत्रिक अंश [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity) में रहता है, और [`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py) इसका संचालन करता है।
गेट प्रत्येक वैलिडेटर को तीन में से किसी एक तरीके से चलाता है:

- **per-write**: हर लंबित लेखन पर (`--hook`), या `--all-perwrite` के साथ हर ट्रैक की गई फ़ाइल पर।
- **standalone**: `--all` के साथ पूरी रिपॉज़िटरी पर, या `--check <name>` के साथ एक-एक करके।
- **change-set**: किसी स्टेज किए गए डिफ़ के विरुद्ध, गेट के स्वीप के बाहर।

नीचे दी गई तालिका वैलिडेटर मॉड्यूल से उत्पन्न होती है।

## गेट चलाना

इंस्टॉल किए गए हार्नेस पर गेट अपने आप चलता है: Claude Code की
`settings.json` इसे एक `PreToolUse` हुक के रूप में जोड़ती है, जो हर Write/Edit से
पहले `~/.claude/.apothem/support/conformity/gate.py` पर मटेरियलाइज़ की गई प्रति को
आह्वान करता है। स्रोत चेकआउट से, मॉड्यूल रूप वही कोड चलाता है। गेट डिफ़ॉल्ट रूप से
परामर्शी है: यह निष्कर्षों की रिपोर्ट करता है और `0` के साथ बाहर निकलता है। किसी
अवरोधक निष्कर्ष पर `2` के साथ बाहर निकलने के लिए `--strict` जोड़ें। अज्ञात वैलिडेटर
नाम `3` के साथ बाहर निकलता है।

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help` उपयोग-सारांश प्रिंट करता है।
पूरी प्रक्रिया के लिए [अनुरूपता गेट चलाना](/docs/usage/conformity-gate) देखें।
