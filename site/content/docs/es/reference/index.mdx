Referencia por clase de artefacto. Cada página describe el propósito de la clase, su disposición en disco, el contrato de frontmatter y el registro que lista cada instancia.

Abajo se muestran rutas relativas al repositorio; cada adaptador las materializa en su directorio de configuración nativo (p. ej. `~/.claude/` para el adaptador de Claude Code; consulta [`site/content/docs/harnesses/<harness>.mdx`](/docs/harnesses) para los destinos de cada harness).
