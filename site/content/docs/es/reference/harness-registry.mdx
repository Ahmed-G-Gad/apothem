El registro de entornos es el inventario de adaptadores que sirve como fuente de verdad
para la CLI, la documentación, las pruebas de fixtures y la validación de los anclajes de
convención. La fuente en tiempo de ejecución es `src/apothem/lib/harness_registry.py`; cada
fila de abajo es rastreable hasta ese registro, hasta el `capabilities.yml` de cada adaptador
y hasta el `STANDARD-CONVENTION-PIN.md` de cada adaptador.

`profile-projected`, `unsupported`, `not-applicable` y
`discovery-pending`.

## Hooks de validación

El registro se mantiene sincronizado mediante estas comprobaciones:

| Comprobación | Propósito |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | Confirma que cada adaptador tiene un anclaje de convención actual y que el registro sigue enumerando diecisiete adaptadores. |
| `python -m apothem.conformity.gate --all .` | Ejecuta las comprobaciones de conformidad de documentación e implementación. |
| `python -m pytest` | Ejercita las pruebas de fixtures del registro y las pruebas de contrato de los adaptadores. |
