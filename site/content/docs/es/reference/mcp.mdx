Los servidores Model Context Protocol (MCP) son **propiedad del operador**.
Apothem lleva el inventario MCP en el perfil compartido (`mcp_servers`). Un
adaptador cuya herramienta guarda sus servidores MCP en un archivo de
configuración que Apothem ya escribe proyecta ese inventario en el archivo;
cualquier otro adaptador no crea ninguna entrada de servidor, y registrar los
servidores mediante la herramienta sigue correspondiéndote a ti.

## Dónde se registran los servidores MCP

Cada herramienta registra los servidores MCP mediante su propio mecanismo
nativo, y Apothem respeta esa superficie en lugar de sobrescribirla.
En Claude Code, los servidores se registran con `claude mcp add` en `~/.claude.json`
(alcance de usuario o local) y en un `.mcp.json` a nivel de proyecto; el
adaptador de Claude Code no escribe ninguno de los dos archivos, y los ajustes
de Claude Code gestionados por Apothem nunca llevan un bloque `mcpServers`.

## Añadir un servidor

Registra un servidor mediante el mecanismo nativo de tu herramienta; la forma
canónica de la entrada es una clave bajo `mcpServers`:

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/some/path"]
    }
  }
}
```

El tiempo de ejecución de la herramienta carga los servidores registrados al
inicio de la sesión; reinicia la herramienta para que detecte los servidores
nuevos.

## Convención de nomenclatura

Las herramientas MCP se presentan al asistente como `mcp__<server>__<tool>`,
según la convención estándar de nomenclatura de herramientas MCP de la
herramienta.
