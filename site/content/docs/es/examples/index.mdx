Recorridos completos, de principio a fin. Cada ejemplo lleva una sola tarea
desde un punto de partida en blanco hasta un artefacto terminado, y muestra los
comandos, los archivos y el razonamiento de cada paso.

Los proyectos de ejemplo ejecutables que se incluyen con el repositorio residen
en el directorio
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) de la
raíz del repositorio. Las páginas siguientes narran cuatro de ellos de principio
a fin; el resto son autónomos y se leen directamente desde el repositorio, cada
uno con su propio README.

## Páginas

| Página | Descripción |
|------|-------------|
| [Crear un adaptador de entorno](/docs/examples/authoring-a-harness-adapter) | Guía paso a paso para construir un nuevo adaptador de entorno desde cero. |
| [Hook mínimo](/docs/examples/minimal-hook) | El hook de Apothem más pequeño posible — una comprobación PreToolUse que se dispara en cada escritura de archivo. |
| [Regla personalizada](/docs/examples/custom-rule) | Crear una regla permanente específica del proyecto que aplica una convención de nomenclatura. |
| [Recorrido de un plan](/docs/examples/plan-walkthrough) | Un recorrido de principio a fin de la canalización `/plan` para una tarea real. |
