**Rol:** Auditor de dependencias
**Posición en el pipeline:** fortaleza

Pasada de auditoría por dependencia (directas + transitivas) para licencia, CVE y frescura.

## Invocación canónica

```bash
/dependency-audit
```

Con argumentos:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## Entradas

Manifiestos de dependencias del repositorio anfitrión

## Salidas

Hallazgos de dependencias en `_inputs/dependency-audit-findings.md`

## Aguas abajo

La etapa dependency-audit de la Secuencia de Revisión de Auditoría

## Fases del flujo de trabajo

El comando ejecuta cinco fases: ingesta de entradas, recorrido por dependencia, clasificación por hallazgo, emisión de hallazgos y la puerta de validación.

## Modos de fallo

| Síntoma | Causa | Recuperación |
|---------|-------|----------|
| Puerta de calidad FAIL | La salida no cumple los estándares | Corrige la salida y vuelve a ejecutar |
| Falta un archivo de entrada | Ningún manifiesto de dependencias se resuelve en la raíz del repositorio | Indica una raíz de repositorio que contenga un manifiesto de dependencias |

## Ejemplos

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
