**Rol:** Revisor de arquitectura
**Posición en la canalización:** fortaleza

Revisión de integridad arquitectónica frente al artefacto de diseño en `_inputs/design.md`.

## Invocación canónica

```bash
/architecture-review
```

Con argumentos:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Entradas

Repositorio anfitrión + `_inputs/design.md`

## Salidas

Hallazgos de arquitectura en `_inputs/architecture-review-findings.md`

## Aguas abajo

La etapa de revisión de arquitectura de la Secuencia de Revisión de Auditoría

## Fases del flujo de trabajo

El comando ejecuta cinco fases de auditoría: ingesta de entradas, recorrido de trazabilidad del diseño al código, auditoría de integridad de los límites de capa, barrido de acoplamiento entre paquetes y emisión de hallazgos con la puerta de validación.

## Modos de fallo

| Síntoma | Causa | Recuperación |
|---------|-------|----------|
| Puerta de calidad FAIL | La salida no cumple los estándares | Corrige la salida y vuelve a ejecutar |
| Falta un archivo de entrada | Falta el artefacto de diseño `_inputs/design.md` | Ejecuta `/plan-design` para crearlo |

## Ejemplos

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
