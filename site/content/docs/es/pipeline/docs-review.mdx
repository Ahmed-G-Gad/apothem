**Rol:** Revisor de documentación
**Posición en la canalización:** fortaleza

Pasada de revisión de documentación frente a las convenciones de prosa y los estándares de calidad de diez dimensiones.

## Invocación canónica

```bash
/docs-review
```

Con argumentos:

```bash
/docs-review [path/to/repo/ or path/to/docs-source/] [--focus FILE_OR_DIR] [--dry-run]
```

## Entradas

Superficie de documentación del repositorio anfitrión

## Salidas

Hallazgos de documentación en `_inputs/docs-review-findings.md`

## Aguas abajo

La etapa de revisión de documentación de la Secuencia de Revisión de Auditoría

## Fases del flujo de trabajo

El comando ejecuta cinco fases: ingesta de entradas, recorrido por página, clasificación por hallazgo, emisión de hallazgos y la puerta de validación.

## Modos de fallo

| Síntoma | Causa | Recuperación |
|---------|-------|----------|
| Puerta de calidad FAIL | La salida no cumple los estándares | Corrige la salida y vuelve a ejecutar |
| Falta un archivo de entrada | No hay archivos de documentación accesibles en la ruta | Indica una raíz de repositorio o un directorio de fuente de documentación que contenga páginas Markdown |

## Ejemplos

```bash
# Dry-run to preview what would happen
/docs-review --dry-run

# Execute against a repository root
/docs-review path/to/repo/
```
