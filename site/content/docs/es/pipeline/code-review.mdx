**Rol:** Revisor
**Posición en la canalización:** fortaleza

Pasada de revisión de calidad de código por archivo, dirigida por el operador, a través de src/, scripts/ y tools/.

## Invocación canónica

```bash
/code-review
```

Con argumentos:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Entradas

Repositorio anfitrión en cualquier estado del ciclo de vida

## Salidas

Hallazgos por archivo en `_inputs/code-review-findings.md`

## Aguas abajo

La etapa de revisión línea por línea de la Secuencia de Revisión de Auditoría

## Fases del flujo de trabajo

El comando ejecuta cinco fases: ingesta de entradas, recorrido por archivo, clasificación por hallazgo, emisión de hallazgos y la puerta de validación.

## Modos de fallo

| Síntoma | Causa | Recuperación |
|---------|-------|----------|
| Puerta de calidad FAIL | La salida no cumple los estándares | Corrige la salida y vuelve a ejecutar |
| Falta un archivo de entrada | El repositorio no tiene ninguno de `src/`, `scripts/` ni `tools/` | Indica una raíz de repositorio que contenga al menos uno de ellos |

## Ejemplos

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
