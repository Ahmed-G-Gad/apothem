**Rol:** Auditor de cadena de suministro
**Posición en la canalización:** fortaleza

Auditoría de cadena de suministro frente a los estándares SLSA + Sigstore + SBOM.

## Invocación canónica

```bash
/supply-chain-audit
```

Con argumentos:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## Entradas

Canalización de publicación del repositorio anfitrión

## Salidas

Hallazgos de cadena de suministro en `_inputs/supply-chain-audit-findings.md`

## Aguas abajo

La etapa supply-chain-audit de la Secuencia de Revisión de Auditoría

## Fases del flujo de trabajo

El comando ejecuta cinco fases de auditoría: ingesta de entradas, recorrido por eje, clasificación por hallazgo, emisión de hallazgos y la puerta de validación.

## Modos de fallo

| Síntoma | Causa | Recuperación |
|---------|-------|----------|
| Prerrequisito incompleto | Fase dependiente no terminada | Completa primero la fase aguas arriba |
| Puerta de calidad FAIL | La salida no cumple los estándares | Corrige la salida y vuelve a ejecutar |
| Destino rechazado | El destino no tiene una superficie de lanzamiento | Indica una raíz de repositorio con .github/workflows/, un script de lanzamiento o un manifiesto de compilación |

## Ejemplos

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
