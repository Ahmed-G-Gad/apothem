Flujos de trabajo cotidianos. Estas guías cubren las cuatro capacidades
principales de Apothem — el perfil de gobernanza compartido, las reglas de
comportamiento, las canalizaciones `/plan` y `/research`, y la puerta de
conformidad — además de crear trabajadores delegados y hooks.
