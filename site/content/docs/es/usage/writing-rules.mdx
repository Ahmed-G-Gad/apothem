Las reglas son archivos Markdown en `src/apothem/rules/` con extensión `.md`.

## Frontmatter de regla

```yaml
---
name: "..."
description: "..."
pathFilter: ""            # empty string for always-on; a glob for path-filtered
alwaysApply: true         # true for always-on; false for path-filtered
---
```

## Ámbitos de regla

El ámbito de una regla se define con dos campos del frontmatter, `alwaysApply` y `pathFilter`:

| `alwaysApply` | `pathFilter` | Cuándo se aplica |
|---------------|--------------|--------------|
| `true` | `""` (vacío) | Siempre activa: cada sesión y cada archivo |
| `false` | un glob como `"**/*.py"` | Filtrada por ruta: solo cuando el archivo activo coincide con el glob |

## Regla de ejemplo

```markdown
---
name: "python-conventions"
description: "Python style conventions for this project"
pathFilter: "**/*.py"
alwaysApply: false
---

# Python conventions

- Use type annotations on all public functions.
- Maximum line length: 88 characters.
- Prefer explicit over implicit.
```

## Aplicar reglas a los entornos

Después de escribir una regla, actualiza cada adaptador de entorno instalado. Ejecuta `apothem harnesses list` para ver el conjunto instalado y después ejecuta la actualización una vez por cada entorno:

```bash
apothem update --harness claude-code
apothem update --harness cursor
```

## Validación de reglas

```bash
python -m apothem.conformity.gate --check frontmatter
```
