Apothem es de código abierto y da la bienvenida a quienes contribuyen. Esta sección
cubre cómo participar: dónde hacer preguntas, qué está planeado a continuación y los
estándares que la comunidad se exige a sí misma.

## Páginas

| Página | Descripción |
|--------|-------------|
| [Hoja de ruta](/docs/community/roadmap) | La hoja de ruta pública — próximas funcionalidades y mejoras planeadas. |
| [Debates](/docs/community/discussions) | Dónde hacer preguntas y compartir ideas con la comunidad. |
| [Código de conducta](/docs/community/code-of-conduct) | Los estándares para una comunidad acogedora e inclusiva. |

Para contribuir con código, consulta la [Guía para contribuir](/docs/developer-guide).
Para añadir soporte de un nuevo harness, el runbook [Creación de un adaptador de
harness nuevo](/docs/runbooks/new-harness-adapter-authoring) recorre el contrato del
adaptador de principio a fin.
