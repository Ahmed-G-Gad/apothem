## GitHub Discussions

El espacio principal de la comunidad es [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).

Categorías:

| Categoría | Úsala para |
|-----------|-----------|
| Q&A | Preguntas sobre uso, configuración y comportamiento |
| Ideas | Solicitudes de funcionalidades y debates de diseño |
| Show and tell | Comparte cómo usas Apothem |
| General | Cualquier otra cosa |

## Issues

Para errores y solicitudes de funcionalidades concretas, usa
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues).

Antes de abrir un issue, busca en los issues y debates existentes para evitar
duplicados.

## Contribuir

Consulta [Contribuir](/docs/developer-guide) para saber cómo contribuir con código,
documentación y adaptadores de harness. Empieza por el
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
del repositorio y la plantilla de pull request a la que hace referencia.
