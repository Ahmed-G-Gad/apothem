Windsurf lee las reglas desde un directorio `.devin/rules/`. El adaptador de
windsurf de Apothem renderiza las reglas basadas en directorio desde el perfil
compartido. Esta página contrasta el mantenimiento manual de esa configuración
frente a gestionarla con apothem.

## Comparación de esfuerzo

| Tarea | Configuración manual en bruto | Gestionada por Apothem |
| ---- | --------------- | --------------- |
| Escribir reglas | Escribir a mano cada archivo bajo `.windsurf/rules/` | Renderizadas desde el corpus compartido |
| Mantener un único formato de reglas | Elegir a mano entre `.windsurf/rules/` y un único archivo `.windsurfrules` | El adaptador escribe solo `.devin/rules/` |
| Mantener las reglas alineadas con otros entornos | Manual, por herramienta | Automático en `apothem update` |
| Verificar que la configuración es correcta | Inspección manual | `apothem verify --harness windsurf` |

## Qué gestiona apothem

El adaptador de windsurf renderiza las reglas compartidas en el directorio
`.devin/rules/`; no escribe un único archivo `.windsurfrules`. Windsurf no
tiene un hook PreToolUse, por lo que la intención de salvaguarda reside en la
prosa de las reglas y no en un punto de interceptación de llamadas a
herramientas. Cada cambio en las reglas compartidas vuelve a renderizar el
directorio en el siguiente `apothem update`.

## Ruta de migración

1. Ejecuta `apothem profile init` para crear el perfil compartido si aún no lo
   tienes.
2. Mueve las reglas de tu `.windsurf/rules/` existente (y de cualquier archivo
   único `.windsurfrules`) al corpus compartido.
3. Ejecuta `apothem install --harness windsurf` para renderizar el directorio
   `.devin/rules/`.
4. Ejecuta `apothem verify --harness windsurf` para confirmar que la
   configuración quedó instalada.
5. Usa `apothem update --harness windsurf` para cada cambio posterior.
