Open-Claw lee `~/.openclaw/openclaw.json`. Apothem instala cohortes
compartidas de comandos y skills bajo `~/.openclaw/.apothem/support/skills/` y
edita dos lugares de `~/.openclaw/openclaw.json`. Añade ese directorio a
`skills.load.extraDirs`, para que OpenClaw cargue las skills. Añade la ruta
`apothem/AGENTS.md` a la lista de rutas de la entrada de hook
`hooks.internal.entries.bootstrap-extra-files`, y crea la entrada con
`enabled: true` cuando no existe, para que OpenClaw cargue el archivo de reglas
de Apothem que escribe en cada espacio de trabajo. Su
`agents.defaults.skills` es una lista de nombres permitidos que te pertenece y
MCP es una superficie de CLI, así que Apothem no escribe ninguna de las dos.

## Estado

**Vista previa.** El adaptador de Open-Claw apunta al archivo de configuración
actualmente documentado, a la superficie adicional de directorio de skills y al
hook incluido `bootstrap-extra-files`. Las reglas se cargan a través del archivo
de espacio de trabajo `apothem/AGENTS.md`; las plantillas, los agents y el
material de hooks siguen siendo material de apoyo de Apothem.

## Comparación de esfuerzo

| Tarea | Config a mano en bruto | Gestionado por Apothem |
| ---- | --------------- | --------------- |
| Escribir skills reutilizables | Editar a mano la config y los directorios de skills | Escribir una vez en el corpus compartido |
| Mantener las cohortes alineadas con otros entornos | Manual, por herramienta | Automático con `apothem update` |
| Instalar / eliminar la config | Manual | `apothem install` / `apothem uninstall` |
| Verificar que la config es correcta | Inspección manual | `apothem verify --harness open-claw` |

## Qué gestiona Apothem

El adaptador de Open-Claw escribe `openclaw.json`, envuelve los comandos de barra
de Apothem como skills, copia las skills de Apothem en el directorio de apoyo
referenciado y mantiene las reglas, plantillas, agents y material de hooks bajo el
subárbol de soporte de Apothem.
También escribe `apothem/AGENTS.md` en cada espacio de trabajo y lo registra en
el hook incluido `bootstrap-extra-files`, de modo que OpenClaw carga las reglas
de Apothem sin ningún cambio en el propio `AGENTS.md` del espacio de trabajo.
OpenClaw lee `skills.load.extraDirs` después de sus fuentes del espacio de
trabajo, `~/.agents/skills` y `~/.openclaw/skills`, así que una skill con el
mismo nombre en cualquiera de ellas se usa en lugar de la copia de Apothem.

## Ruta de migración

1. Ejecuta `apothem profile init` para crear el perfil compartido si aún no lo
   has hecho.
2. Mueve las skills o los prompts de comandos reutilizables de Open-Claw al corpus
   compartido.
3. Ejecuta `apothem install --harness open-claw` para renderizar la configuración
   nativa y el directorio de skills de apoyo.
4. Ejecuta `apothem verify --harness open-claw` para confirmar que la
   configuración aterrizó.
