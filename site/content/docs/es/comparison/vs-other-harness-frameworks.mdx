Esta página sitúa a Apothem frente a las categorías de herramientas que los
operadores ya usan para gestionar la configuración de asistentes.
Nombra categorías de capacidades, no productos concretos:
la comparación es estructural y se aplica con independencia de la herramienta de
cada categoría a la que recurras.

## Las categorías

Los operadores que gestionan la configuración de asistentes con IA a través de
varias herramientas caen en uno de cuatro enfoques:

1. **Configuración manual por herramienta.** Editas a mano el archivo de
   configuración nativo de cada entorno — un archivo por herramienta, sin fuente
   compartida.
2. **Herramientas de configuración de un solo entorno.** Una herramienta
   dedicada a una plataforma de asistente que gestiona bien la configuración de
   esa plataforma pero no alcanza las demás herramientas que usas.
3. **Gestores de dotfiles de propósito general.** Una herramienta que controla
   versiones y sincroniza archivos de configuración entre máquinas pero trata
   cada archivo como texto opaco.
4. **Gestores de configuración multientorno.** Una herramienta que mantiene un
   único perfil compartido y renderiza a partir de él el formato nativo de cada
   entorno. Apothem está en esta categoría.

## Comparación de capacidades

| Capacidad | Manual por herramienta | Herramienta de un entorno | Gestor de dotfiles | Apothem |
| ---------- | --------------- | ------------------- | --------------- | ------- |
| Cubre muchos entornos | Sí (con esfuerzo) | No (un entorno) | Sí (a nivel de archivo) | Sí (diecisiete adaptadores) |
| Fuente de verdad única y compartida | No | No | No | Sí |
| Renderiza formatos nativos por entorno | Manual | Sí (un entorno) | No | Sí |
| Prevención de deriva entre entornos | Manual | N/D | Solo sincronización de archivos | Sí |
| Traducción de formato (`.mdc`, `.toml`, `.md` embebido) | Manual | Para su entorno | No | Sí |
| Comando de verificación | Ninguno | Varía | Ninguno | Sí |
| Añadir un entorno nuevo | Más trabajo manual | No es posible | Rastrear más archivos | Instalar un adaptador |

## Dónde encaja cada enfoque

**La configuración manual por herramienta** encaja con una sola herramienta cuya
configuración cambias rara vez. El coste crece con cada herramienta que añades y
cada regla que mantienes alineada entre ellas.

**Las herramientas de un solo entorno** encajan con operadores comprometidos con
una plataforma. No resuelven el problema multiherramienta: en el momento en que
añades un segundo asistente, vuelves a mantener dos configuraciones alineadas.

**Los gestores de dotfiles** encajan con la sincronización entre máquinas de
archivos arbitrarios. Mueven bytes entre máquinas pero no entienden los formatos
de entorno, así que no pueden renderizar un perfil en diecisiete formas nativas ni
verificar ninguna de ellas.

**Apothem** encaja con operadores que ejecutan varios asistentes con IA y
quieren una única fuente de verdad. Escribes el perfil una vez; Apothem renderiza,
instala, actualiza y verifica la configuración nativa de cada entorno.
