Antigravity es un entorno de propagación por manifiesto de Clase I: Apothem escribe el ancla de contexto global `~/.gemini/GEMINI.md` e instala un plugin de Apothem bajo `~/.gemini/antigravity-cli/plugins/apothem/`. Esta página contrasta mantener esa disposición a mano frente a gestionarla con Apothem.

## Estado

**Vista previa.** El adaptador de Antigravity apunta al ancla de contexto `GEMINI.md` documentada actualmente y a la superficie del plugin de la CLI de Antigravity. Las cohortes sin superficie nativa siguen siendo material de soporte de Apothem.

## Comparación de esfuerzo

| Tarea | Configuración a mano | Gestionada con Apothem |
| ---- | --------------- | --------------- |
| Escribir reglas | Escribir a mano cada archivo de regla del plugin | Escribir una vez en el corpus compartido |
| Conservar prompts reutilizables | Copiar a mano los prompts de comandos y las skills a los archivos del plugin | Convertidos o copiados a skills del plugin |
| Conservar el material de soporte de hooks | Copiar a mano las referencias de hooks sin cableado activo | Copiado bajo el subárbol de soporte del plugin de Apothem |
| Mantener las reglas alineadas con otros entornos | Manual, por herramienta | Automático con `apothem update` |
| Instalar / quitar la configuración | Copiar y borrar archivos a mano | `apothem install` / `apothem uninstall` |
| Verificar que la configuración es correcta | Inspección manual | `apothem verify --harness antigravity` |

## Qué gestiona Apothem

Apothem gestiona el archivo de contexto global de Antigravity, los metadatos del plugin, las skills de comando convertidas, las skills reutilizables, los agentes convertidos, las reglas, las plantillas y el material de soporte de hooks. Los archivos de hook se conservan como material de soporte; Apothem no registra eventos de hook activos de Antigravity hasta que el adaptador posea una capa de traducción de esquema para `hooks.json` de Antigravity.

## Ruta de migración

1. Ejecuta `apothem profile init` para crear el perfil compartido si aún no lo tienes.
2. Mueve tus reglas escritas a mano de Antigravity al corpus compartido.
3. Ejecuta `apothem install --harness antigravity` para propagar el corpus.
4. Ejecuta `apothem verify --harness antigravity` para confirmar que la configuración se instaló.
5. Usa `apothem update --harness antigravity` para cada cambio posterior.
