Reinstala la configuración de un adaptador de entorno a partir del perfil
compartido actual.

## Sinopsis

```
apothem update --harness NAME|all [--profile PATH] [--dry-run]
                [--project PATH]
                [--quiet|-q] [--verbose|-v]
                [--format plain|json] [--json] [--no-color]
```

`update` vuelve a materializar la salida del entorno a partir del perfil
compartido actual. Usa la misma validación del perfil, la misma selección con
`--harness all`, la misma comprobación del alcance de proyecto, el mismo
comportamiento de ejecución en seco y el mismo sobre JSON que `install`.

El alias en forma continua `apothem updating` se resuelve en el mismo manejador.

## Opciones

| Opción | Descripción |
|---|---|
| `--harness NAME` | Adaptador de entorno que se actualiza, o `all` para el conjunto de todo el registro (obligatorio). |
| `--profile PATH` | Ruta al YAML del perfil compartido. Valor predeterminado: `~/.config/apothem/profile.yaml`. |
| `--dry-run` | Previsualiza la actualización sin escribir archivos. |
| `--project PATH` | Raíz del proyecto para los entornos de alcance de proyecto. Obligatorio cuando el conjunto de entornos seleccionado incluye adaptadores de alcance de proyecto. |
| `--quiet`, `-q` | Suprime la salida informativa; solo se emiten errores. |
| `--verbose`, `-v` | Emite salida de diagnóstico adicional. |
| `--format plain\|json` | Formato de salida (predeterminado: `plain`). |
| `--json` | Abreviatura de `--format json`. |
| `--no-color` | Desactiva los códigos de color ANSI en la salida. |
| `-h`, `--help` | Muestra la ayuda y sale. |

## Salida JSON

```json
{
  "schema_version": 1,
  "status": "success",
  "command": "update",
  "action": "updated",
  "harness": "claude-code",
  "profile_path": "C:\\Users\\Example\\.config\\apothem\\profile.yaml",
  "project": null,
  "files_written": [],
  "results": [],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

`--dry-run` devuelve `status: "dry_run"` y `files_written: []`.

## Ejemplos

```bash
apothem update --harness claude-code
apothem update --harness claude-code --dry-run
apothem update --harness all --project . --dry-run --json
apothem Updating --harness claude-code   # continuous-form alias
apothem updating --harness claude-code   # lowercase variant
```

## Códigos de salida

| Código | Significado |
|---|---|
| 0 | Adaptador actualizado correctamente o ejecución en seco planificada sin problemas |
| 1 | Error previsto de validación, de perfil, de entorno, de proyecto o de adaptador |
| 2 | Materialización parcial del lote después de al menos una escritura |
| 64 | Error de uso: una opción o un comando desconocidos, o un valor de opción ausente o no válido. Con `--json`, el error es un sobre JSON con el código `cli.usage`. |
