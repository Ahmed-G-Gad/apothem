Lista e inspecciona los adaptadores de entorno registrados.

`harnesses` es un grupo de comandos con dos subcomandos: `list` y `show`.

## Sinopsis

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## Subcomandos

### `harnesses list`

Lista todos los adaptadores de entorno registrados.

| Opción | Descripción |
|---|---|
| `--quiet`, `-q` | Suprime la salida informativa; solo se emiten errores. |
| `--verbose`, `-v` | Emite salida de diagnóstico adicional. |
| `--format plain\|json` | Formato de salida (por defecto: `plain`). |
| `--json` | Abreviatura de `--format json`. |
| `--no-color` | Desactiva los códigos de color ANSI en la salida. |
| `-h`, `--help` | Muestra la ayuda y sale. |

### `harnesses show NAME`

Muestra los detalles de un adaptador de entorno específico. `NAME` es el
identificador del entorno en kebab-case; ejecuta `apothem harnesses list` para
ver los identificadores disponibles.

| Opción | Descripción |
|---|---|
| `NAME` | Adaptador de entorno que se inspecciona (argumento posicional obligatorio). |
| `--quiet`, `-q` | Suprime la salida informativa; solo se emiten errores. |
| `--verbose`, `-v` | Emite salida de diagnóstico adicional. |
| `--format plain\|json` | Formato de salida (por defecto: `plain`). |
| `--json` | Abreviatura de `--format json`. |
| `--no-color` | Desactiva los códigos de color ANSI en la salida. |
| `-h`, `--help` | Muestra la ayuda y sale. |

## Ejemplos

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

Los ID de entorno registrados son:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

## Códigos de salida

| Código | Significado |
|---|---|
| 0 | Éxito |
| 1 | Entorno no encontrado (`harnesses show` con un `NAME` desconocido), o todos los adaptadores fallaron al cargarse o al informar (`harnesses list`) |
| 2 | Se listó al menos un adaptador, pero al menos uno falló al informar (`harnesses list`) |
| 64 | Error de uso: una opción o un comando desconocidos, o un valor de opción ausente o no válido. Con `--json`, el error es un sobre JSON con el código `cli.usage`. |
