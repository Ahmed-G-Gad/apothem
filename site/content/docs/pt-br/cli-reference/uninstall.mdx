Remove a configuração de um adaptador de harness.

## Sinopse

```
apothem uninstall --harness NAME|all [--yes] [--project PATH]
                   [--quiet|-q] [--verbose|-v]
                   [--format plain|json] [--json] [--no-color]
```

Remove os destinos do harness gerenciados pelo adaptador e, em seguida, os
diretórios que a instalação criou, assim que estiverem vazios (um diretório que
contenha qualquer coisa sua permanece). Pede confirmação, a menos que `--yes`
seja fornecido. Quando nenhum prompt é possível — `--format json` (o texto do
prompt corromperia o documento JSON único) ou um shell não interativo (sem
TTY) — o comando recusa de antemão com um erro estruturado
`uninstall.confirmation_required` (saída 1), a menos que `--yes` seja
fornecido. Se um harness selecionado não estiver instalado, o comando é
concluído com sucesso (saída 0) com um aviso "nothing to remove".

Uma remoção com `--harness all` é deliberadamente exaustiva: ela abrange todos
os harnesses registrados, incluindo os que o `exclude_harnesses` do perfil pula
durante a instalação — a limpeza alcança o estado que uma instalação anterior
mais ampla possa ter deixado para trás. Os harnesses que nunca foram instalados
relatam "nothing to remove".

O alias na forma contínua `apothem uninstalling` resolve para o mesmo manipulador.

## Opções

| Opção | Descrição |
|---|---|
| `--harness NAME` | Adaptador de harness a remover, ou `all` para o conjunto de todo o registro (obrigatório). |
| `--yes` | Pula o prompt de confirmação. |
| `--project PATH` | Raiz do projeto para os harnesses com escopo de projeto. |
| `--quiet`, `-q` | Suprime a saída informativa; apenas os erros são emitidos. |
| `--verbose`, `-v` | Emite saída de diagnóstico adicional. |
| `--format plain\|json` | Formato de saída (padrão: `plain`). |
| `--json` | Abreviação de `--format json`. |
| `--no-color` | Desativa os códigos de cor ANSI na saída. |
| `-h`, `--help` | Mostra a ajuda e sai. |

## Saída JSON

Quando o adaptador está instalado e é removido com sucesso:

```json
{"schema_version": 1, "action": "uninstalled", "harness": "claude-code", "output_path": "..."}
```

Quando o adaptador não estava instalado:

```json
{"schema_version": 1, "status": "not_installed", "harness": "claude-code"}
```

## Exemplos

```bash
apothem uninstall --harness claude-code
apothem uninstall --harness claude-code --yes
apothem uninstall --harness cursor --project . --yes
apothem uninstall --harness all --project . --yes
apothem Uninstalling --harness cursor --project . --yes   # continuous-form alias
```

## Códigos de saída

| Código | Significado |
|---|---|
| 0 | Adaptador desinstalado, ou não estava instalado |
| 1 | Harness não encontrado, confirmação recusada ou indisponível (modo não interativo ou JSON sem `--yes`), ou todas as remoções falharam |
| 2 | Remoção parcial — pelo menos um harness foi removido antes de uma falha |
| 64 | Erro de uso: uma opção ou um comando desconhecido, ou um valor de opção ausente ou inválido. Com `--json`, o erro é um envelope JSON com o código `cli.usage`. |
