Passo a passos práticos, de ponta a ponta. Cada exemplo leva uma única tarefa de
um ponto de partida em branco até um artefato finalizado, mostrando os comandos,
os arquivos e o raciocínio em cada etapa.

Os projetos de exemplo executáveis distribuídos com o repositório ficam no
diretório [`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples)
na raiz do repositório. As páginas abaixo narram quatro deles de ponta a ponta;
os demais são autocontidos e podem ser lidos diretamente no repositório, cada um
com seu próprio README.

## Páginas

| Página | Descrição |
|------|-------------|
| [Criar um adaptador de harness](/docs/examples/authoring-a-harness-adapter) | Guia passo a passo para construir um novo adaptador de harness do zero. |
| [Hook mínimo](/docs/examples/minimal-hook) | O menor hook possível do Apothem — uma verificação PreToolUse que dispara a cada gravação de arquivo. |
| [Regra personalizada](/docs/examples/custom-rule) | Criar uma regra específica do projeto, sempre ativa, que impõe uma convenção de nomenclatura. |
| [Passo a passo de planejamento](/docs/examples/plan-walkthrough) | Um passo a passo de ponta a ponta do pipeline `/plan` para uma tarefa real. |
