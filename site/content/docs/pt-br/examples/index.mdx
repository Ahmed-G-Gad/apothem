Passo a passos trabalhados, de ponta a ponta. Cada exemplo leva uma única tarefa
de um ponto de partida em branco até um artefato finalizado, mostrando os
comandos, os arquivos e o raciocínio em cada etapa.

Os projetos de exemplo executáveis que acompanham o repositório vivem no
diretório
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples) na raiz
do repositório; as páginas abaixo são os guias narrados que os percorrem.

## Páginas

| Página | Descrição |
|------|-------------|
| [Criando um adaptador de harness](/docs/examples/authoring-a-harness-adapter) | Guia passo a passo para construir um novo adaptador de harness do zero. |
| [Hook mínimo](/docs/examples/minimal-hook) | O menor hook do Apothem possível — uma verificação PreToolUse que dispara em cada escrita de arquivo. |
| [Regra personalizada](/docs/examples/custom-rule) | Criar uma regra permanente específica do projeto que imponha uma convenção de nomenclatura. |
| [Passo a passo de plano](/docs/examples/plan-walkthrough) | Um passo a passo de ponta a ponta da pipeline `/plan` para uma tarefa real. |
