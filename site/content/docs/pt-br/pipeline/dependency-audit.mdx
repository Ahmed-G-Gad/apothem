**Papel:** Auditor de dependências
**Posição no pipeline:** fortaleza

Passagem de auditoria por dependência (diretas + transitivas) para licença, CVE e frescor.

## Invocação canônica

```bash
/dependency-audit
```

Com argumentos:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## Entradas

Manifestos de dependências do repositório anfitrião

## Saídas

Achados de dependências em `_inputs/dependency-audit-findings.md`

## Downstream

A etapa dependency-audit da Sequência de Revisão de Auditoria

## Fases do fluxo de trabalho

O comando executa cinco fases: ingestão de entrada, percurso por dependência, triagem por achado, emissão de achados e o portão de validação.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Portão de qualidade FAIL | A saída não atende aos padrões | Corrija a saída e execute novamente |
| Arquivo de entrada ausente | Nenhum manifesto de dependências é encontrado na raiz do repositório | Informe uma raiz de repositório que contenha um manifesto de dependências |

## Exemplos

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
