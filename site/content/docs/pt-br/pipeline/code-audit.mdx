**Papel:** Auditor
**Posição no pipeline:** fortaleza

Auditoria forense de código entre arquivos na escala do corpus do repositório.

## Invocação canônica

```bash
/code-audit
```

Com argumentos:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## Entradas

Repositório anfitrião com layout de fontes aprovado, uma linha de base de cobertura de testes e (no nível SHARED+) um portão de CI aprovado

## Saídas

Achados em nível de corpus em `_inputs/code-audit-findings.md`

## A jusante

A etapa de auditoria forense de código da Sequência de Revisão de Auditoria

## Fases do fluxo de trabalho

O comando executa seis fases forenses: ingestão de entrada, percurso de dependências entre arquivos, auditoria de type hints e cobertura, detecção de código morto e duplicado, auditoria de integridade arquitetural e emissão de achados com o portão de validação.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Portão de qualidade FAIL | A saída não atende aos padrões | Corrija a saída e execute novamente |
| Arquivo de entrada ausente | Nenhuma execução do portão de CI nem linha de base de cobertura de testes no nível SHARED+ | Execute antes o pipeline de CI do hospedeiro e, em seguida, execute novamente |

## Exemplos

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
