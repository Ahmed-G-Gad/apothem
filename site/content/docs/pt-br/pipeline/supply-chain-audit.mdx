**Papel:** Auditor da cadeia de suprimentos
**Posição no pipeline:** fortaleza

Auditoria da cadeia de suprimentos frente aos padrões SLSA + Sigstore + SBOM.

## Invocação canônica

```bash
/supply-chain-audit
```

Com argumentos:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## Entradas

Pipeline de publicação do repositório anfitrião

## Saídas

Achados da cadeia de suprimentos em `_inputs/supply-chain-audit-findings.md`

## Downstream

A etapa supply-chain-audit da Sequência de Revisão de Auditoria

## Fases do fluxo de trabalho

O comando executa cinco fases de auditoria: ingestão de entrada, percurso por eixo, triagem por achado, emissão de achados e o portão de validação.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Pré-requisito incompleto | Fase dependente não finalizada | Conclua primeiro a fase a montante |
| Portão de qualidade FAIL | A saída não atende aos padrões | Corrija a saída e execute novamente |
| Alvo recusado | O alvo não tem uma superfície de lançamento | Informe uma raiz de repositório com .github/workflows/, um script de lançamento ou um manifesto de build |

## Exemplos

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
