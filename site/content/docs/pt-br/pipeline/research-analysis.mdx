**Papel:** Investigador principal (análise)
**Posição no pipeline:** meio da cadeia

Analisa os dados brutos conforme o plano pré-registrado — executa os testes estatísticos planejados sobre a unidade de análise independente, reporta tamanhos de efeito com intervalos de confiança (intervalos de credibilidade sob um plano bayesiano; não apenas valores p), aplica correção para comparações múltiplas onde aplicável, declara como os dados ausentes foram tratados, executa verificações de robustez / sensibilidade e divulga cada desvio em relação ao pré-registro.

## Invocação canônica

```bash
/research-analysis
```

Com argumentos:

```bash
/research-analysis [--suite-name NAME] [--override] [--correction METHOD] [--alpha LEVEL]
```

## Entradas

Os dados brutos no local natural do host que a etapa de experimento registrou, mais `_inputs/preregistration.md` (o plano de análise congelado).

## Saídas

`_outputs/analysis.md` (os testes pré-registrados com tamanhos de efeito, ICs, unidade de análise e um julgamento de viés por domínio para cada resultado principal; a correção para comparações múltiplas; o tratamento de dados ausentes; as verificações de robustez; e os desvios divulgados) + figuras / tabelas em um local natural do host.

## A jusante

/research-paper (consumidor a jusante)

## Fases do fluxo de trabalho

O comando segue o fluxo de trabalho padrão do pipeline `/research`:

1. **Carregar o contexto** — Ler os dados brutos e o pré-registro.
2. **Verificar a Comporta de sequência** — Confirmar que as saídas do experimento existem; caso contrário, interromper com `Blocked: run /research-experiment first`.
3. **Analisar** — Executar os testes pré-registrados sobre a unidade de análise independente; diagnosticar os pressupostos sem deixar que os diagnósticos escolham o teste; reportar tamanhos de efeito + ICs; corrigir para comparações múltiplas; declarar o tratamento de dados ausentes; executar verificações de robustez / sensibilidade.
4. **Divulgar os desvios** — Registrar cada afastamento do plano pré-registrado. A passagem para uma alternativa que o pré-registro nomeia é registrada como uma adaptação planejada; qualquer outra substituição é um desvio.
5. **Atualizar o manifesto de transferência** — Registrar o caminho da análise e as figuras / tabelas.
6. **Emitir a análise** — `_outputs/analysis.md` + figuras / tabelas.

## Disciplina estatística

- **O teste segue o projeto.** O teste primário pré-registrado se mantém, a menos que o próprio gatilho de alternativa do pré-registro seja acionado; um teste de triagem que não rejeita não mostra que um pressuposto se sustenta.
- **n conta unidades independentes.** Medidas repetidas, subamostras, conglomerados e sementes são agregados à unidade ou modelados como dependência, nunca contados como réplicas independentes.
- **Um resultado nulo é lido de três formas.** O intervalo do tamanho de efeito, o resultado de equivalência frente ao menor efeito de interesse e uma declaração de sensibilidade (o menor efeito detectável no n analisado alcançado) são reportados juntos. O poder calculado a partir do efeito observado nunca é reportado.
- **Planos bayesianos em seus próprios termos.** Um plano bayesiano pré-registrado reporta o resumo da posterior com seu intervalo de credibilidade, executa verificações de sensibilidade à priori, de diagnóstico computacional e preditivas a posteriori antes que qualquer posterior seja reportada, e usa uma região de equivalência prática fixada de antemão para resultados nulos.
- **Viés no nível do resultado e figuras.** Cada resultado principal traz um julgamento baixo / algumas preocupações / alto por domínio, semeado a partir do livro-razão de ameaças à validade do projeto e nunca somado em uma pontuação única, e cada figura atende ao piso de codificação, divulgação de incerteza e acessibilidade.

## Piso de rigor

Um método estocástico é executado com pelo menos trinta repetições independentes
por instância ou condição, mais quando a dispersão entre as repetições é grande
em relação às diferenças testadas, até que as estatísticas resumidas sejam
estáveis. Seus resultados são reportados como melhor, média, mediana, desvio
padrão e pior entre as repetições, com curvas de convergência e gráficos de
distribuição. As comparações usam testes não paramétricos — um teste pareado de
postos com sinal, par a par, e um teste ômnibus de postos com correção post-hoc
entre os métodos — reportados com um tamanho de efeito de superioridade
estocástica e um diagrama de diferença crítica. Um resultado avança para o
artigo somente quando supera o portão de avanço: ele vence seus comparadores de
forma convincente e significativa, e a aprovação é registrada em um runbook
auditável.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Blocked: run /research-experiment first | Sem dados brutos | Execute `/research-experiment` para produzir os dados + o log |
| Valor p reportado sem tamanho de efeito | Relato estatístico incompleto | Reporte tamanhos de efeito + intervalos de confiança |
| Observações dependentes contadas como réplicas | Medidas repetidas, subamostras, conglomerados ou sementes tratados como independentes | Agregue à unidade independente ou modele a dependência; n conta unidades |
| Poder observado reportado para um resultado nulo | Poder calculado a partir do efeito observado | Remova-o; reporte o intervalo, o resultado de equivalência e a declaração de sensibilidade |
| Desvio de análise não divulgado | O plano se afastou silenciosamente | Divulgue o desvio em relação ao pré-registro |

```bash
# Analisar os dados brutos conforme o plano pré-registrado
/research-analysis --suite-name my-study
```
