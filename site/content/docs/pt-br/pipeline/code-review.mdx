**Papel:** Revisor
**Posição no pipeline:** fortaleza

Passagem de revisão de qualidade de código por arquivo, conduzida pelo operador, através de src/, scripts/ e tools/.

## Invocação canônica

```bash
/code-review
```

Com argumentos:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## Entradas

Repositório anfitrião em qualquer estado do ciclo de vida

## Saídas

Achados por arquivo em `_inputs/code-review-findings.md`

## Downstream

A etapa de revisão linha por linha da Sequência de Revisão de Auditoria

## Fases do fluxo de trabalho

O comando executa cinco fases: ingestão de entrada, percurso por arquivo, triagem por achado, emissão de achados e o portão de validação.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Portão de qualidade FAIL | A saída não atende aos padrões | Corrija a saída e execute novamente |
| Arquivo de entrada ausente | O repositório não tem nenhum dos diretórios `src/`, `scripts/` ou `tools/` | Informe uma raiz de repositório que contenha pelo menos um deles |

## Exemplos

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
