**Papel:** Revisor de arquitetura
**Posição no pipeline:** fortaleza

Revisão de integridade arquitetural frente ao artefato de design em `_inputs/design.md`.

## Invocação canônica

```bash
/architecture-review
```

Com argumentos:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## Entradas

Repositório anfitrião + `_inputs/design.md`

## Saídas

Achados de arquitetura em `_inputs/architecture-review-findings.md`

## Downstream

A etapa de revisão de arquitetura da Sequência de Revisão de Auditoria

## Fases do fluxo de trabalho

O comando executa cinco fases de auditoria: ingestão de entrada, percurso de rastreabilidade do design até o código, auditoria de integridade das fronteiras de camadas, varredura de acoplamento entre pacotes e emissão de achados com o portão de validação.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Portão de qualidade FAIL | A saída não atende aos padrões | Corrija a saída e execute novamente |
| Arquivo de entrada ausente | Artefato de design `_inputs/design.md` ausente | Execute `/plan-design` para criá-lo |

## Exemplos

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
