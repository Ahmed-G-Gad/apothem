**Papel:** Auditor de acessibilidade
**Posição no pipeline:** fortaleza

Auditoria de acessibilidade frente ao WCAG 2.2 AA para cada página renderizada.

## Invocação canônica

```bash
/a11y-audit
```

Com argumentos:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## Entradas

Site do projeto implantado ou servido localmente

## Saídas

Achados de acessibilidade (A11y) em `_inputs/a11y-audit-findings.md`

## Downstream

A etapa de auditoria de acessibilidade da Sequência de Revisão de Auditoria

## Fases do fluxo de trabalho

O comando executa cinco fases de auditoria: ingestão de entrada, auditoria por página, triagem por achado, emissão de achados e o portão de validação.

## Modos de falha

| Sintoma | Causa | Recuperação |
|---------|-------|----------|
| Portão de qualidade FAIL | A saída não atende aos padrões | Corrija a saída e execute novamente |
| Arquivo de entrada ausente | O caminho do site ou a URL não resolve | Informe um diretório de site já construído ou uma URL acessível |

## Exemplos

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
