## Escala de severidade

O portão não tem a escala Crítica, Importante ou Consultiva e não tem limite de dois achados. Sem `--strict` (ou `APOTHEM_CONFORMITY_STRICT=1`), o portão relata os achados e sai com `0`. Com `--strict`, uma verificação de arquivo único ou de hook sai com `2` quando qualquer matcher falha, e uma execução sobre o corpus (`--all-perwrite`) sai com `2` quando um matcher bloqueante falha; os matchers consultivos são apenas relatados. O hook de Write/Edit instalado não passa `--strict`, então ele relata os achados e a gravação prossegue, a menos que `APOTHEM_CONFORMITY_STRICT=1` esteja definido no ambiente do hook.

## Validadores

A fração mecânica fica em [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity), orquestrada por [`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py).
Cada validador é executado de uma de três maneiras:

- **per-write**: em cada gravação pendente (`--hook`), ou em cada arquivo rastreado com `--all-perwrite`.
- **standalone**: no repositório inteiro com `--all`, ou um de cada vez com `--check <name>`.
- **change-set**: contra um diff preparado (staged), executado diretamente como `python -m apothem.conformity.semver_stability_grep --staged`, e não por meio do portão.

## Executar o portão

Em um harness instalado, o portão é executado automaticamente: o
`settings.json` do Claude Code o conecta como um hook `PreToolUse` que invoca a
cópia materializada em `~/.claude/.apothem/support/conformity/gate.py` antes de
cada Write/Edit. A partir de um checkout do código-fonte, a forma de módulo
executa o mesmo código. O portão é consultivo por padrão: ele relata os achados
e sai com `0`. Adicione `--strict` para sair com `2` diante de um achado
bloqueante. Um nome de validador desconhecido sai com `3`.

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help` imprime o resumo de uso.
Consulte [Executar o portão de conformidade](/docs/usage/conformity-gate) para o procedimento completo.
