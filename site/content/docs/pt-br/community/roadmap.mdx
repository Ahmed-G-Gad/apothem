## Lançamento atual

- Estabilizar os dezessete adaptadores de ferramentas.
- Concluir a infraestrutura de auditoria de revisão.
- Estabilizar a superfície da CLI do Apothem.
- Estabelecer o pipeline de CI/CD do GitHub Actions.

## Curto prazo

- Amadurecer a distribuição npm / npx: manter o ponto de entrada
  `@ahmed-g-gad/apothem` alinhado a cada lançamento e ampliar sua cobertura de plataforma.
- Expandir a listagem do plugin do Claude Code conforme a superfície do marketplace estabiliza.
- Atualização automática de adaptadores de ferramentas via `apothem update --watch`.
- Versionamento de perfil e ferramentas de migração.
- Validação do esquema do perfil compartilhado no portão de conformidade.
- Adaptadores de ferramentas adicionais com base em solicitações da comunidade.

## Longo prazo

- Sincronização de perfil hospedada na nuvem (opcional, controlada pelo operador).
- Extensão do VS Code para feedback de conformidade em tempo real.
- Gerenciamento de perfil compartilhado por equipes.

## Solicitações e feedback

Envie solicitações de roteiro via
[GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).
O roteiro é informado pela comunidade; solicitações populares avançam mais rápido.
