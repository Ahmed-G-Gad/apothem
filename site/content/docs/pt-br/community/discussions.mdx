## GitHub Discussions

O principal espaço da comunidade é o [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).

Categorias:

| Categoria | Use para |
|----------|---------|
| Q&A | Perguntas sobre uso, configuração e comportamento |
| Ideias | Solicitações de recursos e discussões de design |
| Show and tell | Compartilhe como você usa o Apothem |
| Geral | Qualquer outra coisa |

## Issues

Para bugs e solicitações de recursos concretas, use
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues).

Antes de abrir uma issue, pesquise issues e discussões existentes para evitar
duplicatas.

## Contribuindo

Consulte [Contribuindo](/docs/developer-guide) para saber como contribuir com código, docs
e adaptadores de harness. Comece pelo
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
do repositório e pelo modelo de pull request que ele referencia.
