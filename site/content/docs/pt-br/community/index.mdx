O Apothem é código aberto e dá as boas-vindas a contribuidores. Esta seção cobre como
participar: onde fazer perguntas, o que está planejado a seguir e os padrões
que a comunidade adota para si mesma.

## Páginas

| Página | Descrição |
|------|-------------|
| [Roteiro](/docs/community/roadmap) | O roteiro público — recursos futuros e melhorias planejadas. |
| [Discussões](/docs/community/discussions) | Onde fazer perguntas e compartilhar ideias com a comunidade. |
| [Código de conduta](/docs/community/code-of-conduct) | Os padrões para uma comunidade acolhedora e inclusiva. |

Para contribuir com código, consulte o [Guia de contribuição](/docs/developer-guide).
Para adicionar suporte a um novo harness, o runbook [Autoria de adaptador de
novo harness](/docs/runbooks/new-harness-adapter-authoring) percorre o contrato
do adaptador de ponta a ponta.
