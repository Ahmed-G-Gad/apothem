O Apothem tem o compromisso de oferecer um ambiente acolhedor e inclusivo para
todos os contribuidores e usuários.

## Nossos padrões

- Usar linguagem acolhedora e inclusiva.
- Ser respeitoso com pontos de vista e experiências divergentes.
- Aceitar com cortesia críticas construtivas.
- Focar no que é melhor para a comunidade.
- Demonstrar empatia com outros membros da comunidade.

## Comportamento inaceitável

- Assédio de qualquer tipo.
- Linguagem ou ações discriminatórias.
- Provocações, insultos ou ataques pessoais.
- Publicar informações privadas de terceiros sem permissão.

## Denúncia

Denuncie violações para [me@ahmedgad.com](mailto:me@ahmedgad.com).

## Aplicação

Os mantenedores do projeto revisarão as denúncias e tomarão as medidas apropriadas,
incluindo banimentos temporários ou permanentes para violações graves.

Este código de conduta é adaptado do
[Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.
