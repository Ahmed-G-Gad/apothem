Fluxos de trabalho do dia a dia. Estes guias cobrem as quatro capacidades
principais do Apothem — o perfil de governança compartilhado, as regras de
comportamento, os pipelines `/plan` e `/research`, e o conformity gate —
além de criar trabalhadores delegados e hooks.

| [Escrevendo regras](/docs/usage/writing-rules) | Crie, defina o escopo e mantenha as regras de comportamento do Apothem. |
| [Criando planos](/docs/usage/authoring-plans) | Transforme requisitos em prosa bruta em suítes de planejamento executáveis com o pipeline `/plan`. |
| [Usando trabalhadores delegados](/docs/usage/using-agents) | Defina e invoque trabalhadores delegados persistentes para tarefas especializadas. |
| [Desenvolvimento de hooks](/docs/usage/hook-development) | Crie e registre hooks no pipeline de hooks do Apothem. |
| [Conformity gate](/docs/usage/conformity-gate) | Execute o conformity gate do Apothem para verificar a saúde do ecossistema. |
