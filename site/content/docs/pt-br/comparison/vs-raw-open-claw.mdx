O Open-Claw lê `~/.openclaw/openclaw.json`. O Apothem instala cohorts
compartilhados de comandos e skills sob `~/.openclaw/.apothem/support/skills/` e
escreve uma única chave ali, `skills.load.extraDirs`, que lista esse diretório
para que o OpenClaw carregue as skills. Seu `agents.defaults.skills` é uma lista
de nomes permitidos que pertence a você e o MCP é uma superfície de CLI, então o
Apothem não escreve nenhum dos dois.

## Status

**Prévia.** O adaptador do Open-Claw mira o arquivo de configuração atualmente
documentado e a superfície adicional de diretório de skills. Os cohorts que não
são de skills permanecem material de apoio do Apothem.

## Comparação de esforço

| Tarefa | Config à mão bruta | Gerenciado pelo Apothem |
| ---- | --------------- | --------------- |
| Escrever skills reutilizáveis | Editar à mão a config e os diretórios de skills | Escrever uma vez no corpus compartilhado |
| Manter os cohorts alinhados com outros harnesses | Manual, por ferramenta | Automático no `apothem update` |
| Instalar / remover a config | Manual | `apothem install` / `apothem uninstall` |
| Verificar se a config está correta | Inspeção manual | `apothem verify --harness open-claw` |

## O que o Apothem gerencia

O adaptador do Open-Claw escreve `openclaw.json`, envolve os comandos de barra do
Apothem como skills, copia as skills do Apothem para o diretório de apoio
referenciado e mantém as regras, modelos, agents e material de hooks sob a
subárvore de suporte do Apothem.
O OpenClaw lê `skills.load.extraDirs` com a menor precedência entre as suas fontes
de skills, então uma skill de mesmo nome no seu workspace, em `~/.agents/skills`
ou em `~/.openclaw/skills` é usada no lugar da cópia do Apothem.

## Caminho de migração

1. Execute `apothem profile init` para criar o perfil compartilhado se você ainda
   não o fez.
2. Mova as skills ou os prompts de comandos reutilizáveis do Open-Claw para o
   corpus compartilhado.
3. Execute `apothem install --harness open-claw` para renderizar a configuração
   nativa e o diretório de skills de apoio.
4. Execute `apothem verify --harness open-claw` para confirmar que a configuração
   aterrissou.
