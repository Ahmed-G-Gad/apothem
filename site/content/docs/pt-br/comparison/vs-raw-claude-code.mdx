O Claude Code (do fabricante Anthropic) mantém sua configuração nativa em
`~/.claude/`. O adaptador claude-code do Apothem é o adaptador de superfície
completa: ele propaga o corpus compartilhado diretamente para essa árvore. Esta
página contrasta manter a configuração à mão com gerenciá-la com o Apothem.

## Comparação de esforço

| Tarefa | Configuração manual | Gerenciada pelo Apothem |
| ---- | --------------- | --------------- |
| Escrever regras, agentes, comandos, skills | Editar cada superfície em `~/.claude/` à mão | Escrever uma vez no corpus compartilhado |
| Manter output-styles e statuslines | Editar à mão por superfície | Propagados do corpus compartilhado |
| Configurar hooks | Editar à mão as entradas de hook de `settings.json` | Propagados (PreToolUse/PostToolUse/Stop/SessionStart) |
| Manter a configuração alinhada com outros harnesses | Manual, por ferramenta | Automático no `apothem update` |
| Verificar se a configuração está correta | Inspeção manual | `apothem verify --harness claude-code` |

## O que o Apothem gerencia

O adaptador propaga regras, agentes, comandos, skills, output-styles,
statuslines e `settings.json` para `~/.claude/`. Os hooks nativos PreToolUse,
PostToolUse, Stop e SessionStart são configurados a partir do corpus
compartilhado.

O Apothem grava um único bloco gerenciado, delimitado por sentinelas, no seu `~/.claude/CLAUDE.md`, no escopo de usuário. O `apothem update` reescreve apenas esse bloco e mantém o seu texto fora dele. Os arquivos `CLAUDE.md` de projeto não são tocados. O Apothem governa as superfícies propagadas ao redor dele.

## Caminho de migração

1. Execute `apothem profile init` para criar o perfil compartilhado, caso ainda não o tenha.
2. Mova suas regras, agentes, comandos e skills existentes de `~/.claude/` para o corpus compartilhado.
3. Deixe o `CLAUDE.md` onde está. O Apothem mantém o seu texto fora do bloco gerenciado dele e reescreve apenas esse bloco.
4. Execute `apothem install --harness claude-code` para propagar o corpus.
5. Execute `apothem verify --harness claude-code` para confirmar que a configuração foi gravada.
6. Use `apothem update --harness claude-code` para cada mudança posterior.
