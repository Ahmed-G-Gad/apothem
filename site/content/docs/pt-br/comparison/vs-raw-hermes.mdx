O Hermes lê `~/.hermes/config.yaml`. O Apothem grava a configuração YAML nativa
(projetando o inventário de MCP do perfil em `mcp_servers`) e instala cohorts
compartilhados de comandos e de skills em `~/.hermes/.apothem/support/skills/`,
que ele lista em `skills.external_dirs` para que o Hermes os carregue. O próprio
`skills.config` do Hermes guarda configurações por skill, então o Apothem não o
redige.

## Status

**Prévia.** O adaptador do Hermes mira o arquivo de configuração documentado
atual e a superfície de descoberta de skills. Os cohorts que não são de skills
permanecem como material de suporte do Apothem.

## Comparação de esforço

| Tarefa | Configuração manual | Gerenciada pelo Apothem |
| ---- | --------------- | --------------- |
| Redigir skills reutilizáveis | Editar à mão a configuração e os diretórios de skills | Escrever uma vez no corpus compartilhado |
| Manter os cohorts alinhados com outros harnesses | Manual, por ferramenta | Automático no `apothem update` |
| Instalar / remover a configuração | Manual | `apothem install` / `apothem uninstall` |
| Verificar se a configuração está correta | Inspeção manual | `apothem verify --harness hermes` |

## O que o Apothem gerencia

O adaptador do Hermes grava `config.yaml`, encapsula os comandos de barra do
Apothem como skills, copia as skills do Apothem para o diretório de suporte e
mantém as regras, os templates, os agentes e o material de hooks na subárvore de
suporte do Apothem. Ele também adiciona `~/.hermes/.apothem/support/skills` a
`skills.external_dirs` em `config.yaml`, para que o Hermes carregue essas skills.
Essa lista vem por último na ordem de precedência documentada do Hermes, então
uma skill de mesmo nome no seu projeto ou em `~/.hermes/skills/` provavelmente
terá precedência sobre a cópia do Apothem; a documentação do Hermes consultada
não declara a regra de conflito.

## Caminho de migração

1. Execute `apothem profile init` para criar o perfil compartilhado, caso ainda
   não o tenha feito.
2. Mova as skills ou os prompts de comando reutilizáveis do Hermes para o
   corpus compartilhado.
3. Execute `apothem install --harness hermes` para renderizar a configuração
   nativa, que lista o diretório de skills de suporte em `skills.external_dirs`,
   e para instalar as skills. O `apothem update` mantém as chaves que você
   adiciona a `config.yaml`.
4. Execute `apothem verify --harness hermes` para confirmar que a configuração
   chegou ao destino.
