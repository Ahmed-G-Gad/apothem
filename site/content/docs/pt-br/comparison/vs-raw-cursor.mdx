O Cursor lê regras no formato MDC sob `.cursor/rules/`. O formato MDC exige
campos de frontmatter — `description`, `globs` e `alwaysApply`. O adaptador de
cursor do Apothem renderiza esses arquivos `.mdc` a partir do perfil
compartilhado. Esta página contrasta manter essa configuração à mão com
gerenciá-la com o Apothem.

## Comparação de esforço

| Tarefa | Configuração manual | Gerenciada pelo Apothem |
| ---- | --------------- | --------------- |
| Escrever regras | Escrever à mão cada arquivo `.mdc` em `.cursor/rules/` | Renderizadas a partir do corpus compartilhado |
| Escrever o frontmatter MDC | Redigir à mão `description` / `globs` / `alwaysApply` em cada arquivo | Gerado pelo adaptador |
| Manter um único formato de regras | Escolher à mão entre regras MDC e um único arquivo `.cursorrules` | O adaptador escreve apenas arquivos MDC em `.cursor/rules/` |
| Manter as regras alinhadas com outros harnesses | Manual, por ferramenta | Automático no `apothem update` |
| Verificar se a configuração está correta | Inspeção manual | `apothem verify --harness cursor --project <path>` |

## O que o Apothem gerencia

O adaptador de cursor renderiza as regras compartilhadas em arquivos `.mdc` sob
`.cursor/rules/`, gerando o frontmatter MDC exigido (`description`, `globs`,
`alwaysApply`) para cada arquivo. O adaptador escreve apenas o formato MDC
baseado em diretórios que o Cursor lê; ele não escreve um único arquivo
`.cursorrules`.
O Cursor não tem um hook PreToolUse, então a intenção das barreiras de proteção
vive na prosa das regras.

## Caminho de migração

1. Execute `apothem profile init` para criar o perfil compartilhado, caso ainda não o tenha.
2. Mova as regras do seu `.cursor/rules/` existente (e de qualquer `.cursorrules`) para o corpus compartilhado.
3. Execute `apothem install --harness cursor --project <path>` para renderizar os arquivos `.mdc` com o frontmatter MDC correto.
4. Execute `apothem verify --harness cursor --project <path>` para confirmar que a configuração foi gravada.
5. Use `apothem update --harness cursor --project <path>` para cada mudança posterior.
