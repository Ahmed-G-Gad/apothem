O Windsurf agora é o Devin Desktop e lê regras de um diretório `.devin/rules/`
(o local preferido, que tem precedência sobre o fallback `.windsurf/rules/`). O
adaptador windsurf do Apothem renderiza as regras baseadas em diretório a partir do perfil
compartilhado. Esta página contrasta a manutenção manual dessa configuração com
o gerenciamento dela pelo apothem.

## Comparação de esforço

| Tarefa | Configuração bruta à mão | Gerenciada pelo Apothem |
| ---- | --------------- | --------------- |
| Escrever regras | Escrever à mão cada arquivo em `.windsurf/rules/` | Renderizadas a partir do corpus compartilhado |
| Manter um único formato de regras | Escolher à mão entre `.windsurf/rules/` e um único arquivo `.windsurfrules` | O adaptador escreve apenas `.devin/rules/` |
| Manter as regras alinhadas com outros harnesses | Manual, por ferramenta | Automático no `apothem update` |
| Compartilhar skills e comandos reutilizáveis | Copiar à mão cada pasta de skill para `~/.agents/skills/` e manter as cópias atualizadas | Gravados em `~/.agents/skills/` pelo adaptador, uma cópia para todos os projetos, e atualizados no `apothem update` |
| Manter auxiliares reutilizáveis sincronizados | Escrever à mão cada arquivo de subagente do Devin Local em `.devin/agents/` e acompanhar os nomes de ferramentas do Devin | Onze auxiliares gravados em `.devin/agents/` com suas ferramentas traduzidas, e atualizados no `apothem update` |
| Verificar se a configuração está correta | Inspeção manual | `apothem verify --harness windsurf --project <path>` |

## O que o apothem gerencia

O adaptador windsurf renderiza as regras compartilhadas em um único arquivo,
`<project>/.devin/rules/apothem-rules.md`; ele não escreve um único arquivo
`.windsurfrules`. Ele também grava onze dos auxiliares do Apothem como subagentes
do Devin Local em `<project>/.devin/agents/`; os três que precisam de ferramentas
web aguardam até que o Devin documente os nomes dessas ferramentas. Ele registra
dois hooks do Devin Local, um bootstrap de sessão e um aviso de tamanho de
contexto, em `<project>/.devin/config.local.json`; o modo Cascade, mais antigo,
lê um formato de hook diferente (`hooks.json`), que o adaptador não grava. Ele
não registra nenhuma proteção de chamadas de ferramenta, então a intenção de
proteção reside na prosa das regras, e não em um ponto de interceptação de
chamadas de ferramenta. Cada mudança nas regras compartilhadas re-renderiza o
arquivo no próximo `apothem update`.

## Caminho de migração

1. Execute `apothem profile init` para criar o perfil compartilhado, caso ainda não o tenha.
2. Mova as regras do seu `.windsurf/rules/` existente (e de qualquer arquivo `.windsurfrules` único) para o corpus compartilhado.
3. Execute `apothem install --harness windsurf --project <path>` para renderizar o diretório `.devin/rules/`.
4. Execute `apothem verify --harness windsurf --project <path>` para confirmar que a configuração foi gravada.
5. Use `apothem update --harness windsurf --project <path>` para cada mudança posterior.
