O GitHub Copilot lê suas instruções de `.github/copilot-instructions.md`. O
adaptador github-copilot do Apothem renderiza esse arquivo a partir do perfil
compartilhado. Esta página contrasta a manutenção manual dessa configuração com
o gerenciamento dela pelo Apothem.

## Comparação de esforço

| Tarefa | Configuração bruta à mão | Gerenciada pelo Apothem |
| ---- | --------------- | --------------- |
| Escrever instruções | Editar à mão `.github/copilot-instructions.md` | Renderizadas: regras compartilhadas incorporadas ao arquivo |
| Manter as instruções alinhadas com outros harnesses | Manual, por ferramenta | Automático no `apothem update` |
| Instalar / remover a configuração | Escrever e excluir o arquivo à mão | `apothem install` / `apothem uninstall` |
| Compartilhar skills e comandos reutilizáveis | Copiar à mão cada pasta de skill para `~/.agents/skills/` e manter as cópias atualizadas | Gravados em `~/.agents/skills/` pelo adaptador, uma cópia para todos os projetos, e atualizados no `apothem update` |
| Verificar se a configuração está correta | Inspeção manual | `apothem verify --harness github-copilot --project <path>` |

## O que o Apothem gerencia

O adaptador github-copilot embute as regras compartilhadas em
`.github/copilot-instructions.md`. O Copilot documenta hooks em
`.github/hooks/*.json`, que o adaptador não grava, então a intenção de proteção é carregada
inteiramente nas instruções renderizadas. Cada mudança nas regras compartilhadas
re-renderiza o arquivo no próximo `apothem update`.

## Caminho de migração

1. Execute `apothem profile init` para criar o perfil compartilhado, caso ainda não o tenha.
2. Mova o conteúdo do seu `.github/copilot-instructions.md` existente para o corpus compartilhado.
3. Execute `apothem install --harness github-copilot --project <path>` para renderizar o arquivo de instruções.
4. Execute `apothem verify --harness github-copilot --project <path>` para confirmar que a configuração foi gravada.
5. Use `apothem update --harness github-copilot --project <path>` para cada mudança posterior.
