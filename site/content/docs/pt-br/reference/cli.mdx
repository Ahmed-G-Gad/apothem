A CLI `apothem` é a interface principal do operador para gerenciar o perfil
compartilhado e os adaptadores de ferramenta.

## Flags globais

| Flag | Descrição |
|------|-------------|
| `--version` | Imprime a versão do Apothem e sai |
| `--help` | Imprime a ajuda do comando |

## Subcomandos

### `apothem install`

Instala um adaptador de ferramenta a partir do perfil compartilhado.

```bash
apothem install --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| Opção | Descrição |
|--------|-------------|
| `--harness <name>` | Nome do adaptador de ferramenta (veja os valores canônicos abaixo). Obrigatório. |
| `--profile PATH` | Caminho para o YAML do perfil compartilhado. Padrão: `~/.config/apothem/profile.yaml`. |
| `--project PATH` | Raiz do projeto para ferramentas com escopo de projeto. |
| `--dry-run` | Pré-visualiza a instalação sem gravar arquivos. |

Valores canônicos de `--harness`:

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
hermes
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

Use `--harness all --project <path>` para selecionar o conjunto de todo o
registro. A lista `exclude_harnesses` do perfil é respeitada durante a seleção em
lote de instalação/atualização.

### `apothem update`

Re-deriva a configuração nativa de um adaptador de ferramenta a partir do perfil
compartilhado atual.

```bash
apothem update --harness <name|all> [--profile PATH] [--project PATH] [--dry-run]
```

| Opção | Descrição |
|--------|-------------|
| `--harness <name>` | Nome do adaptador de ferramenta. Obrigatório. |
| `--profile PATH` | Caminho para o YAML do perfil compartilhado. |
| `--project PATH` | Raiz do projeto para ferramentas com escopo de projeto. |
| `--dry-run` | Pré-visualiza a atualização sem gravar arquivos. |

`update` rematerializa a saída da ferramenta. Ele não atualiza o pacote da CLI do
Apothem; para atualizações de pacote, use o gerenciador de pacotes com o qual o
Apothem foi instalado.

### `apothem uninstall`

Remove a configuração nativa de um adaptador de ferramenta.

```bash
apothem uninstall --harness <name|all> [--project PATH] [--yes]
```

| Opção | Descrição |
|--------|-------------|
| `--harness <name>` | Nome do adaptador de ferramenta. Obrigatório. |
| `--project PATH` | Raiz do projeto para ferramentas com escopo de projeto. |
| `--yes` | Pula a confirmação. |

### `apothem verify`

Verifica se um adaptador de ferramenta está instalado e se seu caminho de saída
está presente.

```bash
apothem verify --harness <name|all> [--project PATH]
```

| Opção | Descrição |
|--------|-------------|
| `--harness <name>` | Nome do adaptador de ferramenta ou `all`. Obrigatório. |
| `--project PATH` | Raiz do projeto para ferramentas com escopo de projeto. |

O código de saída é `0` quando o adaptador está instalado e `1` quando não está.

### `apothem profile`

Gerencia o perfil compartilhado do Apothem.

```bash
apothem profile show [--profile PATH]
apothem profile init [--profile PATH] [--force]
apothem profile set <key> <value> [--profile PATH]
apothem profile edit [--profile PATH]
```

| Subcomando | Descrição |
|------------|-------------|
| `profile init` | Cria um esqueleto de perfil mínimo válido conforme o schema. |
| `profile show` | Imprime o perfil resolvido (YAML) no stdout. |
| `profile set <key> <value>` | Define um campo do perfil. O valor é analisado como YAML (strings, números, booleanos, listas e mapeamentos são todos aceitos). |
| `profile edit` | Abre o perfil no `$EDITOR` (recorre ao editor padrão da plataforma). |

A opção `--profile PATH` aponta cada subcomando para um arquivo de perfil
alternativo. Padrão: `~/.config/apothem/profile.yaml`.

### `apothem harnesses`

Lista e inspeciona os adaptadores de ferramenta registrados.

```bash
apothem harnesses list
apothem harnesses show <name>
```

| Subcomando | Descrição |
|------------|-------------|
| `harnesses list` | Imprime uma tabela de cada adaptador registrado com sua flag de status de instalação e o caminho de saída. |
| `harnesses show <name>` | Imprime o nome, o estado de instalação e o caminho de saída de um adaptador. |

### `apothem doctor`

Executa diagnósticos do sistema para a instalação do Apothem.

```bash
apothem doctor
```

Imprime a versão do Apothem, o interpretador Python, a plataforma, o caminho do
perfil resolvido e uma tabela de status de instalação por ferramenta. O código de
saída é `0` quando todo adaptador registrado relata estar instalado; caso
contrário, `1`.
