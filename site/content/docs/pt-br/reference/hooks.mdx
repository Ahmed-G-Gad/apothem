Os hooks disparam em eventos de ferramentas e carregam contextos de mensagem que
o assistente trata como prompts de sistema adicionais. A fiação fica no
bloco de hooks do `settings.json` do Claude Code, no arquivo de hooks `hooks.json` do Codex
e no mapa de hooks do `settings.json` do Qwen Code.

| Evento | Tempo limite | Propósito |
|-------|--------:|---------|
| SessionStart | 30 segundos | Ler memória, verificar o estado do plano, reportar a prontidão |
| PreCompact | 30 segundos | Verificar que o estado foi externalizado antes da compactação |
| PostCompact | 30 segundos | Restaurar o estado de trabalho após a compactação |
| Stop | 60 segundos | Externalização ao final da sessão |
| PreToolUse (Bash) | 10 segundos | Validação do Bash — isolamento de artefatos do git |
| PreToolUse (Write/Edit/NotebookEdit/apply_patch) | 10 segundos | Isolamento de referências a planos, verificações de frontmatter |

## Despachante

As entradas de hook instaladas invocam o despachante pelo caminho absoluto do script.
Os templates de configurações carregam o token `${HARNESS_ROOT}` —
`python "${HARNESS_ROOT}/apothem/hooks/dispatch.py" <event> [<message-name>]`
— que o instalador renderiza para o caminho real da raiz do harness no momento
da instalação (Claude Code e Qwen Code materializam o despachante sob
`<harness-root>/apothem/hooks/`; Codex sob `<harness-root>/hooks/`). O
despachante é um script autônomo da biblioteca padrão: ele inicializa seu próprio `sys.path`,
de modo que nenhum pacote `apothem` importável é necessário no host. A partir de um
checkout do código-fonte, a forma de módulo `python -m apothem.hooks.dispatch <event>` (com
`PYTHONPATH=src`) executa o mesmo código para desenvolvimento. O despachante carrega
`hooks/lib/resolve_root.py` para a resolução da raiz do ecossistema e delega para
`hooks/emit_hook_context.py` e `hooks/session_start_bootstrap.py`.

## Contextos de mensagem

Os contextos em Markdown por evento ficam sob `src/apothem/hooks/messages/`:

- `postcompact.md`, `precompact.md`, `stop.md`
- `pretooluse-bash.md`, `pretooluse-write.md`, `pretooluse-edit.md`,
  `pretooluse-notebookedit.md`

Cada arquivo de contexto é carregado pelo despachante quando seu evento dispara
e seu argumento de contexto está registrado no arquivo de configurações.
