O registro de ferramentas é o inventário de adaptadores que serve como fonte de verdade
para a CLI, a documentação, os testes de fixtures e a validação das âncoras de convenção.
A fonte em tempo de execução é `src/apothem/lib/harness_registry.py`; cada linha abaixo é
rastreável até esse registro, até o `capabilities.yml` de cada adaptador e até o
`STANDARD-CONVENTION-PIN.md` de cada adaptador.

## Hooks de validação

O registro permanece sincronizado por meio destas verificações:

| Verificação | Propósito |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | Confirma que cada adaptador tem uma âncora de convenção atual e que o registro ainda enumera dezessete adaptadores. |
| `python -m apothem.conformity.gate --all .` | Executa as verificações de conformidade de documentação e implementação. |
| `python -m pytest` | Exercita os testes de fixtures do registro e os testes de contrato dos adaptadores. |
