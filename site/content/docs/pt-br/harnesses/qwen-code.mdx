**Fornecedor:** Alibaba Cloud
**Nome de instalação:** `qwen-code`
**Status:** Beta
**Configuração nativa:** `~/.qwen/`

## Instalação

```bash
apothem install --harness qwen-code
```

O adaptador grava as configurações do Qwen Code, instala uma âncora de contexto
`QWEN.md`, registra os despachantes de hook do Apothem, converte os comandos do
Apothem em arquivos de comando Markdown do Qwen, instala as skills como
diretórios SKILL.md e adapta as definições de auxiliares como subagentes do
Qwen.

**Arquivos gravados:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

## Mapeamento do perfil para a configuração nativa

O adaptador renderiza as chaves documentadas de `settings.json` para contexto e
hooks, grava `QWEN.md` e distribui os comandos, as skills e as definições de
auxiliares do Apothem pelos diretórios de descoberta nativos do Qwen Code. As
regras, os templates e o material-fonte dos hooks permanecem como material de
suporte sob `~/.qwen/.apothem/support/`.

## Notas de compatibilidade

`~/.qwen/.apothem/support/` é material de suporte referenciado por `QWEN.md` e
pelos comandos de hook das configurações; não é um namespace de descoberta de
propriedade do fornecedor.
O bloco do Apothem em `QWEN.md` termina com uma seção de arquivos de suporte do
Apothem que nomeia o diretório absoluto sob `~/.qwen/.apothem/support/` em
relação ao qual cada citação no estilo do repositório (`rules/<name>.md`,
`templates/...`, `hooks/...`) é resolvida.

## Verificação

```bash
apothem verify --harness qwen-code
```

O comando verify confirma que:

1. A configuração nativa existe no caminho esperado.
2. Cada destino gerenciado existe; os arquivos gerenciados não estão vazios, e as configurações JSON ou YAML são analisadas sem erros. Adicione `--profile PATH` para também confirmar que os arquivos instalados correspondem a esse perfil.
3. A rotina de verificação específica do adaptador informa sucesso.

## Atualização

```bash
apothem update --harness qwen-code
```

Atualiza `settings.json`, `QWEN.md`, os comandos nativos, as skills, os
subagentes e a árvore de suporte do Apothem.

## Desinstalação

```bash
apothem uninstall --harness qwen-code
```

Remove os arquivos de configuração nativa gravados pelo adaptador.
O YAML do perfil compartilhado e o motor do Apothem não são afetados.

## Conformity gate

```bash
python -m apothem.conformity.gate --all .
```

## Solução de problemas

| Sintoma | Correção |
|---------|-----|
| Arquivo de configuração não encontrado | Execute novamente `apothem install --harness qwen-code` |
| Falha na verificação | Execute `apothem update --harness qwen-code` e depois verifique novamente |
| Conteúdo de configuração inesperado | Verifique `~/.config/apothem/profile.yaml` ou `--profile PATH` e depois execute novamente `apothem update --harness qwen-code` |
