**Fornecedor:** Alibaba Cloud
**Nome de instalação:** `qwen-code`
**Status:** Beta
**Configuração nativa:** `~/.qwen/`

## Instalação

```bash
apothem install --harness qwen-code
```

O adaptador grava as configurações do Qwen Code, instala uma âncora de contexto
`QWEN.md`, registra os despachantes de ganchos (hooks) do Apothem, converte os
comandos do Apothem em arquivos de comando Markdown do Qwen, instala as habilidades
como diretórios SKILL.md e adapta as definições de assistentes como subagentes do
Qwen.

**Arquivos gravados:**

```text
~/.qwen/settings.json
~/.qwen/QWEN.md
~/.qwen/commands/
~/.qwen/skills/
~/.qwen/agents/
~/.qwen/.apothem/support/{rules,templates,hooks}/
```

## Mapeamento do perfil para a configuração nativa

O adaptador renderiza as chaves documentadas de `settings.json` para o contexto e os
ganchos (hooks), grava `QWEN.md` e entrelaça os comandos, as habilidades e as
definições de assistentes do Apothem pelos diretórios de descoberta nativos do Qwen
Code. As regras, os modelos e o material-fonte dos ganchos (hooks) permanecem como
material de suporte sob `~/.qwen/.apothem/support/`.

## Notas de compatibilidade

`~/.qwen/.apothem/support/` é material de suporte referenciado por `QWEN.md` e pelos comandos
de ganchos (hooks) das configurações; não é um namespace de descoberta de
propriedade do fornecedor.

## Verificação

```bash
apothem verify --harness qwen-code
```

O comando verify confirma que:

1. A configuração nativa existe no caminho esperado.
2. Todos os campos obrigatórios do perfil compartilhado estão presentes.
3. A rotina de verificação específica do adaptador relata sucesso.

## Atualização

```bash
apothem update --harness qwen-code
```

Atualiza `settings.json`, `QWEN.md`, os comandos nativos, as habilidades, os
subagentes e a árvore de suporte do Apothem.

## Desinstalação

```bash
apothem uninstall --harness qwen-code
```

Remove os arquivos de configuração nativa gravados pelo adaptador.
O YAML do perfil compartilhado e o motor do Apothem não são afetados.

## Portão de conformidade

```bash
python -m apothem.conformity.gate --all .
```

## Solução de problemas

| Sintoma | Correção |
|---------|-----|
| Arquivo de configuração não encontrado | Reexecute `apothem install --harness qwen-code` |
| Verificação falhou | Execute `apothem update --harness qwen-code` e verifique novamente |
| Conteúdo de configuração inesperado | Verifique `~/.config/apothem/profile.yaml` ou `--profile PATH`, depois reexecute `apothem update --harness qwen-code` |
