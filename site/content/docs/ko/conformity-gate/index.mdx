## 심각도 단계

| 심각도 | 게이트에 미치는 영향 |
|---|---|
| **치명** | 게이트 FAIL — 방출이 무조건 차단됨 |
| **중요** | 중요 막대 2개 이상이 동시에 실패하면 게이트 FAIL |
| **권고** | 게이트 WARN — 서명 기록에 기록되며, 방출을 차단하지 않음 |

## 검증기

기계적 부분은 [`src/apothem/conformity/`](https://github.com/ahmed-g-gad/apothem/tree/main/src/apothem/conformity)에 있으며, [`src/apothem/conformity/gate.py`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/gate.py)가 이를 조율합니다.
게이트는 각 검증기를 다음 세 가지 방식 중 하나로 실행합니다.

- **per-write**: 보류 중인 모든 쓰기마다(`--hook`), 또는 `--all-perwrite`로 추적되는 모든 파일에 대해 실행합니다.
- **standalone**: `--all`로 저장소 전체에 걸쳐 실행하거나, `--check <name>`으로 하나씩 실행합니다.
- **change-set**: 게이트의 스윕과 별도로, 스테이징된 diff를 대상으로 실행합니다.

## 게이트 실행

설치된 하니스에서는 게이트가 자동으로 실행됩니다. Claude Code의
`settings.json`은 게이트를 `PreToolUse` 훅으로 연결하며, 이 훅은 모든
Write/Edit 전에 `~/.claude/.apothem/support/conformity/gate.py`에 머티리얼라이즈된
사본을 호출합니다. 소스 체크아웃에서는 모듈 형식이 같은 코드를 실행합니다.
게이트는 기본적으로 권고 모드입니다. 발견 사항을 보고하고 `0`으로 종료합니다.
차단 수준의 발견 사항이 있을 때 `2`로 종료하려면 `--strict`를 추가하세요. 알 수
없는 검증기 이름은 `3`으로 종료합니다.

```shell
# Every standalone validator across the repository:
python -m apothem.conformity.gate --all .

# The same sweep, failing on a blocking finding (the CI form):
python -m apothem.conformity.gate --all --strict .

# Every per-write validator against every tracked file:
python -m apothem.conformity.gate --all-perwrite .

# One validator by name (names come from --list):
python -m apothem.conformity.gate --check naming-grep .

# List every registered validator as JSON:
python -m apothem.conformity.gate --list

# Single-file dispatch (mimics the PreToolUse hook):
echo '{"tool_input": {"file_path": "path/to/file", "content": "..."}}' \
    | python -m apothem.conformity.gate --hook
```

`python -m apothem.conformity.gate --help`는 사용법 요약을 출력합니다.
전체 절차는 [적합성 게이트 실행](/docs/usage/conformity-gate)을 참조하세요.
