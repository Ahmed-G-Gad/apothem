하니스 레지스트리는 CLI, 문서, 픽스처 테스트, 규약 핀 검증에서 사용하는 신뢰할 수 있는
단일 출처(source-of-truth) 어댑터 인벤토리입니다. 런타임 소스는
`src/apothem/lib/harness_registry.py`이며, 아래의 모든 행은 해당 레지스트리, 각 어댑터의
`capabilities.yml`, 그리고 각 어댑터의 `STANDARD-CONVENTION-PIN.md`까지 추적 가능합니다.

## 검증 훅

레지스트리는 다음 검사를 통해 동기화 상태를 유지합니다.

| 검사 | 목적 |
| --- | --- |
| `python scripts/dev/validate_harness_convention_pins.py --today YYYY-MM-DD` | 각 어댑터가 최신 규약 핀을 가지고 있고 레지스트리가 여전히 열일곱 개의 어댑터를 열거하는지 확인합니다. |
| `python -m apothem.conformity.gate --all .` | 문서 및 구현 적합성 검사를 실행합니다. |
| `python -m pytest` | 레지스트리 픽스처 테스트와 어댑터 계약 테스트를 실행합니다. |
