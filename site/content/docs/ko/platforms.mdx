Apothem은 두 개의 설치 프로그램 스크립트를 제공하며, 이 둘이 함께 현대
개발자의 데스크톱 및 서버 매트릭스를 포괄합니다. 플랫폼별 빌드는 없습니다.
엔진은 벤더링된 의존성과 함께 소스 트리에서 실행되는
[자체 포함 런타임](/docs/architecture/self-contained-runtime)이므로, 플랫폼
지원은 정확히 두 설치 프로그램 중 하나가 그 트리를 배치하고 실행할 수 있는
호스트의 집합입니다. 나머지 설치 경로는 매트릭스를 더 넓힙니다. 도구 네이티브
플러그인과 확장은 해당 호스트 도구가 실행되는 어디서나 실행되고, npx 형식
(`npx @ahmed-g-gad/apothem`)은 Node.js 18+가 있는 모든 OS에서 실행됩니다.

## 운영 체제 및 셸 매트릭스

| OS 계열 | 지원 셸 | 설치 프로그램 스크립트 |
| --------- | ---------------- | ---------------- |
| macOS | POSIX `bash`(시스템 bash 또는 사용자가 설치한 더 최신 bash) | `install.sh` |
| Linux | POSIX `bash` | `install.sh` |
| Windows Subsystem for Linux (WSL2) | POSIX `bash` | `install.sh` |
| BSD (FreeBSD, OpenBSD, NetBSD) | POSIX `bash` | `install.sh` |
| Termux (Android) | POSIX `bash` | `install.sh` |
| ChromeOS Linux 컨테이너 (Crostini) | POSIX `bash` | `install.sh` |
| Windows | Windows PowerShell 5.1+ | `install.ps1` |
| PowerShell 7+가 있는 모든 플랫폼 | PowerShell 7+ (크로스 플랫폼) | `install.ps1` |

두 스크립트는 서로 기능적으로 동등합니다. `install.sh`는 POSIX `bash`를
요구합니다. `install.ps1`은 Windows PowerShell 5.1 이상, 또는 PowerShell 7
자체가 지원하는 모든 플랫폼의 PowerShell 7+를 요구합니다 — macOS와 Linux를
포함하며, 그곳에서는 `install.sh`의 대안이 됩니다.

## 단 하나의 사전 요건: 시스템 Python

Apothem은 어떤 Python 패키지도 설치하지 않습니다. 엔진 임포트는 이미 가지고
있는 인터프리터에 대해 실행되며, 번들된 소스가 `PYTHONPATH` 앞에 추가됩니다.
각 설치 프로그램은 다른 작업을 하기 전에 사전 요건을 검사합니다:

- **CPython 3.10 이상.** 설치 프로그램은 `python3`, `python`, 그리고 버전이
  명시된 이름(`python3.14`부터 `python3.10`까지)을 탐색하여, 버전 ≥ 3.10을
  보고하는 첫 번째 것을 수용합니다. Windows에서는 Microsoft Store 런처 심을
  거부하며, 번들된 `find-python` 로케이터도 동일한 하한을 적용합니다.
- **런타임 라이브러리 임포트 가능.** 엔진은 시스템 인터프리터에서 `click`과 `rich`를 임포트합니다. 나머지 서드파티 의존성은 소스 트리에 포함(vendored)되어 있습니다. 설치 프로그램은 두 라이브러리가 임포트 가능한지 확인하고, 누락된 것을 알려 주며, 누락된 전제 조건을 대신 설치하도록 제안합니다 — 확인을 거치거나 `--yes` / `APOTHEM_AUTO_INSTALL_DEPS=1`로 자동으로.
- **`git`**은 네트워크 설치(스크립트가 소스 트리를 복제함)에만 필요합니다.
  체크아웃으로부터의 로컬 설치는 `git`을 요구하지 않습니다.

인터프리터, 라이브러리, 또는 `git`이 없으면, 설치 프로그램은 추측하거나
환경을 변경하는 대신 무엇을 제공해야 하는지 정확히 명시한 진단과 함께
종료합니다.

## 플랫폼이 지원되는 방식

다음 두 가지가 모두 성립할 때 플랫폼이 지원됩니다:

1. 두 설치 프로그램 중 하나가 그 위에서 실행됨 — 즉 호스트에 POSIX
   `bash`(`install.sh`) 또는 지원되는 PowerShell(`install.ps1`)이 있음.
2. `click`과 `rich`를 임포트 가능한 CPython 3.10+ 인터프리터가 그 위에서
   실행됨.

컴파일된 구성 요소도, 네이티브 확장도, 플랫폼별 바이너리도 없습니다. 동일한
소스 트리가 인터프리터가 실행되는 모든 곳에서 실행되므로, 위 매트릭스가 지원에
대한 완전하고 정확한 진술입니다 — 그 이상은 주장하지 않습니다.

## 권장 다음 단계

**플랫폼에 맞는 설치 프로그램을 실행하십시오** — CPython 3.10+ 인터프리터가
PATH에 있는지 확인한 뒤, POSIX 셸에서는
`curl -fsSL https://apothem.ahmedgad.com/install.sh | bash`, PowerShell에서는
`irm https://apothem.ahmedgad.com/install.ps1 | iex`.
