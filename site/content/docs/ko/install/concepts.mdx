Apothem 문서 전반에서 마주치게 될 용어에 대한 빠른 참조 자료입니다.

## 공유 프로필

`~/.config/apothem/profile.yaml`에 있는 스키마 검증된 YAML 파일입니다(`--profile PATH`로 재정의). 이 파일은 당신의 정체성, 선호, 구성에 대한 단일 진실 공급원입니다. 모든 하니스 어댑터는 설치 시 이를 읽어 그 하니스의 네이티브 구성을 도출합니다.

## 하니스 어댑터

공유 프로필을 특정 하니스의 네이티브 구성 형식으로 변환하는 플랫폼별 어댑터입니다. 지원되는 런타임은 다음과 같습니다.

```text
Claude Code, Cursor, Gemini CLI, etc.
```

Apothem 설치는 항상 다음을 의미합니다. 공유 프로필을 설치한 다음, 하나 이상의 어댑터를 머티리얼라이즈합니다.

## 행위 규칙

모든 상호작용에서 로드되거나(상시 적용) 특정 경로 아래의 파일을 편집할 때만 로드되는(경로 필터링) src/apothem/rules/ 아래의 Markdown 파일입니다. 규칙은 하니스가 어떻게 동작해야 하는지를 성문화합니다.

## 훅

하니스 수명 주기 이벤트(PreToolUse, PostToolUse, SessionStart, PreCompact, Stop, PostCompact)에서 실행되도록 settings.json에 등록된 Python 스크립트입니다. 훅은 출력이 디스크에 도달하기 전에 실시간으로 적합성 의무를 강제합니다. 훅 이벤트 모델은 현재 Claude Code 표면입니다. 훅 메커니즘이 없는 하니스용 어댑터는 단순히 이를 생략합니다.

## 적합성 게이트

15개 막대 사전 방출 게이트(M1-M15)의 기계적 부분 — 어떤 아티팩트가 방출되기 전에 통과해야 하는 독립형 검증기들입니다. 사전 방출 게이트는 품질의 하한선입니다. 적합성 게이트는 기계 검사 가능한 막대들을 실행하고, 훅은 개별 막대를 실시간으로 강제합니다.

## 플랜 스위트

스펙, 마스터 플랜, 단계별 PHASE.md 파일, 출력 아티팩트를 담고 있는 &lt;project-root&gt;/.apothem/plans/&lt;suite-name&gt;/의 구조화된 디렉터리입니다. /plan 파이프라인이 플랜 스위트를 관리합니다.

## 스킬

src/apothem/skills/&lt;name&gt;/ 아래에 SKILL.md 파일로 번들된, 슬래시 명령으로 호출 가능한 재사용 기법입니다. 스킬은 내장 /plan 파이프라인 너머로 슬래시 명령 표면을 확장합니다.

## 위임 작업자

다음의 표준 경로에 정의된 영속적이고 목적 범위가 지정된 어시스턴트입니다.

```text
src/apothem/agents/<name>.md
```

위임 작업자는 리서치, 감사, 품질 검사, 메모리 관리를 처리합니다.
