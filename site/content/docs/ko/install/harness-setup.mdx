## 하니스 어댑터 설치

```bash
apothem install --harness <name>
```

사용 가능한 이름은 [지원 하니스 목록](/docs/harnesses)을 참조하세요.
프로젝트 범위 어댑터에는 프로젝트 경로가 필요합니다.

```bash
apothem install --harness cursor --project /path/to/project
apothem install --harness gemini-cli --project /path/to/project
apothem install --harness github-copilot --project /path/to/project
apothem install --harness windsurf --project /path/to/project
```

## 여러 하니스 설치

지원되는 모든 어댑터를 원할 때는 레지스트리 전체 선택자를 사용하세요. 등록된 집합에는 프로젝트 범위 어댑터가 포함되어 있으므로 프로젝트 루트를 전달합니다.

```bash
apothem install --harness claude-code
apothem install --harness cursor --project /path/to/project
apothem install --harness all --project /path/to/project
```

## 하니스 설정 검증

```bash
apothem verify --harness <name>
apothem verify --harness all --project /path/to/project
```

등록된 모든 어댑터를 한 번에 확인하려면 `apothem doctor`를 실행하세요. 이 명령은 하니스별 설치 상태 표를 출력하며, 점검이 실패할 때에만 0이 아닌 코드로 종료합니다. 예를 들면 검증되지 않는 설치된 하니스, 시작할 수 없는 훅 명령, 또는 존재하지만 유효성 검사를 통과하지 못하는 프로필입니다. 설치되지 않은 하니스는 목록에 표시되지만 `doctor`를 실패시키지 않습니다.

## 설치된 하니스 보기

```bash
apothem harnesses list
```

어댑터별 세부 정보(이름, 설치 상태, 출력 경로)를 보려면 `apothem harnesses show <name>`를 전달하세요.
