**역할:** 공급망 감사자
**파이프라인 위치:** 포트리스

SLSA + Sigstore + SBOM 표준에 대한 공급망 감사.

## 표준 호출

```bash
/supply-chain-audit
```

인수와 함께:

```bash
/supply-chain-audit [path/to/repo/] [--focus AXIS] [--dry-run]
```

## 입력

호스트 리포지토리의 릴리스 파이프라인

## 출력

공급망 발견 사항: `_inputs/supply-chain-audit-findings.md`

## 하류

감사 검토 시퀀스의 supply-chain-audit 단계

## 워크플로 페이즈

이 명령은 다섯 단계를 실행합니다. 입력 수집, 축별 순회, 발견 사항별 분류, 발견 사항 출력, 그리고 검증 게이트입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 전제 조건 미완료 | 의존 페이즈가 끝나지 않음 | 먼저 상류 페이즈를 완료한다 |
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 대상 거부 | 대상에 릴리스 표면이 없음 | .github/workflows/, 릴리스 스크립트 또는 빌드 매니페스트가 있는 저장소 루트를 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/supply-chain-audit --dry-run

# Execute against a host repository
/supply-chain-audit path/to/repo/
```
