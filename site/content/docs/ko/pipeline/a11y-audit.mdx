**역할:** 접근성 감사자
**파이프라인 위치:** 포트리스

렌더링되는 모든 페이지에 대한 WCAG 2.2 AA 접근성 감사.

## 표준 호출

```bash
/a11y-audit
```

인수와 함께:

```bash
/a11y-audit [path/to/site/ or URL] [--focus PAGE_OR_DIR] [--dry-run]
```

## 입력

배포되었거나 로컬에서 제공되는 프로젝트 웹사이트

## 출력

A11y 발견 사항: `_inputs/a11y-audit-findings.md`

## 하류

감사 검토 시퀀스의 접근성 감사 단계

## 워크플로 페이즈

이 명령은 다섯 개의 감사 단계를 실행합니다. 입력 수집, 페이지별 감사, 발견 사항별 분류, 발견 사항 출력, 그리고 검증 게이트입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | 사이트 경로 또는 URL을 해석할 수 없음 | 빌드된 사이트 디렉터리 또는 접근 가능한 URL을 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/a11y-audit --dry-run

# Execute against a built site directory
/a11y-audit path/to/site/
```
