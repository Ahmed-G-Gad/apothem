**역할:** 검토자
**파이프라인 위치:** 포트리스

src/, scripts/, tools/ 전반에 걸친 운영자 주도의 파일별 코드 품질 검토 패스.

## 표준 호출

```bash
/code-review
```

인수와 함께:

```bash
/code-review [path/to/repo/] [--focus FILE_OR_DIR] [--dry-run]
```

## 입력

수명 주기의 어떤 상태에 있든 호스트 리포지토리

## 출력

파일별 발견 사항: `_inputs/code-review-findings.md`

## 하류

감사 검토 시퀀스의 한 줄 한 줄 검토 단계

## 워크플로 페이즈

이 명령은 다섯 단계를 실행합니다. 입력 수집, 파일별 순회, 발견 사항별 분류, 발견 사항 출력, 그리고 검증 게이트입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | 저장소에 `src/`, `scripts/`, `tools/` 중 어느 것도 없음 | 이들 중 하나 이상을 포함한 저장소 루트를 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/code-review --dry-run

# Execute against a repository root
/code-review path/to/repo/
```
