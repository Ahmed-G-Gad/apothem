**역할:** 책임 연구자(저술)
**파이프라인 위치:** 중간

종합, 설계, 분석으로부터 최상위 논문 초안을 조립합니다 — 초록, 서론, 관련 연구, 방법, 결과, 논의, 한계, 결론, 참고문헌. 모든 인용은 실제 출처로 해석되는지 검증됩니다. 가짜 인용은 없습니다.

## 표준 호출

```bash
/research-paper
```

인수와 함께:

```bash
/research-paper [path/to/research-suite/]
```

## 입력

`_inputs/synthesis.md`(SOTA 지도 + 격차), `_inputs/study-design.md`(방법), 그리고 `_outputs/analysis.md`(결과).

## 출력

호스트에 자연스러운 위치(`paper/`)의 논문 산출물 — 초록, 서론, 관련 연구, 방법, 결과, 논의, 한계, 결론, 참고문헌.

## 다운스트림

/research-review(다운스트림 소비자)

## 워크플로 단계

이 명령은 표준 `/research` 파이프라인 워크플로를 따릅니다.

1. **컨텍스트 로드** — 종합, 연구 설계, 분석을 읽습니다.
2. **시퀀스 게이트 검증** — `_outputs/analysis.md`가 존재하는지 확인합니다. 그렇지 않으면 `Blocked: run /research-analysis first`로 중단합니다.
3. **초안 조립** — 초록부터 결론까지 작성합니다. 서론과 관련 연구는 종합에, 방법은 설계에, 결과는 분석에 기반합니다.
4. **인용 검증** — 모든 참고문헌이 실제 출처로 해석됩니다.
5. **핸드오프 매니페스트 갱신** — 논문 산출물 경로를 기록합니다.
6. **논문 산출** — 호스트에 자연스러운 `paper/` 위치의 원고.

## 최저 엄밀성 기준

이중 맹검 게재처에서는 원고가 익명성 정책이 허용하는 것만 담습니다. 저자, 소속 기관, 연구비 지원, 그리고 대상 시스템은 이름을 밝히지 않고 자연스러운 도메인 언어로 기술되며, 지정된 익명 해제 단계를 위해 별도로 제출되는 메타데이터로 보류됩니다. 재현성 및 통계 보고의 깊이는 목표 게재처의 야심에 따라 조정됩니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| Blocked: run /research-analysis first | 분석 없음 | `/research-analysis`를 실행해 `_outputs/analysis.md`를 생성합니다 |
| 가짜 인용 | 참고문헌이 해석되지 않음 | 해당 인용을 제거하거나 정정합니다. 절대 출처를 날조하지 마세요 |
| 결과 과장 | 논의가 분석을 초과함 | 주장을 분석된 효과 크기 + 신뢰 구간으로 제한합니다 |

## 예시

```bash
# 종합 + 설계 + 분석으로부터 논문 초안 조립
/research-paper path/to/research-suite/
```
