**역할:** 감사자
**파이프라인 위치:** 요새

저장소 코퍼스 범위의 교차 파일 포렌식 코드 감사.

## 정규 호출

```bash
/code-audit
```

인자와 함께:

```bash
/code-audit [path/to/repo/] [--focus AREA] [--dry-run]
```

## 입력

승인된 소스 레이아웃, 테스트 커버리지 기준선, 그리고 (SHARED 이상에서) 통과한 CI 게이트를 갖춘 호스트 저장소

## 출력

코퍼스 수준 발견 사항: `_inputs/code-audit-findings.md`

## 하류

감사 검토 시퀀스의 포렌식 코드 감사 단계

## 워크플로 페이즈

이 명령은 여섯 개의 포렌식 단계를 실행합니다. 입력 수집, 파일 간 의존성 순회, 타입 힌트 및 커버리지 감사, 죽은 코드와 중복 탐지, 아키텍처 무결성 감사, 그리고 검증 게이트를 거친 발견 사항 출력입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | SHARED 이상에서 CI 게이트 실행 기록이나 테스트 커버리지 기준선이 없음 | 호스트의 CI 파이프라인을 먼저 실행한 뒤 다시 실행한다 |

## 예시

```bash
# Dry-run to preview what would happen
/code-audit --dry-run

# Execute against a repository root
/code-audit path/to/repo/
```
