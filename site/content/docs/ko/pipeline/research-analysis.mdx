**역할:** 책임 연구자(분석)
**파이프라인 위치:** 체인 중간

사전 등록된 계획에 따라 원시 데이터를 분석합니다 — 계획된 통계 검정을 실행하고, 신뢰 구간이 포함된 효과 크기를 보고하며(p 값만이 아니라), 해당하는 경우 다중 비교 보정을 적용하고, 견고성 / 민감도 검사를 실행하며, 사전 등록으로부터의 모든 이탈을 공개합니다.

## 표준 호출

```bash
/research-analysis
```

인수와 함께:

```bash
/research-analysis [path/to/research-suite/]
```

## 입력

실험 단계가 기록한, 호스트에 자연스러운 위치의 원시 데이터, 그리고 `_inputs/preregistration.md`(고정된 분석 계획).

## 출력

`_outputs/analysis.md`(효과 크기와 신뢰 구간이 포함된 사전 등록 검정, 다중 비교 보정, 견고성 검사, 공개된 이탈) + 호스트에 자연스러운 위치의 그림 / 표.

## 하류

/research-paper(하류 소비자)

## 워크플로 단계

이 명령은 표준 `/research` 파이프라인 워크플로를 따릅니다:

1. **컨텍스트 로드** — 원시 데이터와 사전 등록을 읽습니다.
2. **시퀀스 게이트 검증** — 실험 출력이 존재하는지 확인합니다. 그렇지 않으면 `Blocked: run /research-experiment first`로 중단합니다.
3. **분석** — 사전 등록된 검정을 실행합니다. 효과 크기 + 신뢰 구간을 보고합니다. 다중 비교를 보정합니다. 견고성 / 민감도 검사를 실행합니다.
4. **이탈 공개** — 사전 등록된 계획으로부터의 모든 이탈을 기록합니다.
5. **핸드오프 매니페스트 업데이트** — 분석 경로와 그림 / 표를 기록합니다.
6. **분석 발행** — `_outputs/analysis.md` + 그림 / 표.

## 최저 엄밀성 기준

확률적 결과는 반복에 걸친 최선, 평균, 중앙값, 표준 편차, 최악으로 보고하며, 수렴 곡선과 분포 플롯을 함께 제시합니다. 비교에는 비모수 검정을 사용합니다 — 쌍별로는 짝지은 부호 순위 검정을, 여러 방법에 걸쳐서는 사후 보정을 동반한 옴니버스 순위 검정을 사용하며, 확률적 우월성 효과 크기와 임계 차이(critical-difference) 도표와 함께 보고합니다. 결과는 진출 게이트를 통과할 때만 논문으로 넘어갑니다. 즉, 그 비교 대상들을 설득력 있고 유의하게 능가하며, 그 통과가 감사 가능한 런북에 기록될 때입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| Blocked: run /research-experiment first | 원시 데이터 없음 | `/research-experiment`를 실행하여 데이터 + 로그를 생성합니다 |
| 효과 크기 없이 p 값이 보고됨 | 통계 보고가 불완전함 | 효과 크기 + 신뢰 구간을 보고합니다 |
| 공개되지 않은 분석 이탈 | 계획이 조용히 이탈함 | 사전 등록에 대한 이탈을 공개합니다 |

## 예제

```bash
# 사전 등록된 계획에 따라 원시 데이터 분석
/research-analysis path/to/research-suite/
```
