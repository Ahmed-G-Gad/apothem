**역할:** 의존성 감사자
**파이프라인 위치:** 포트리스

라이선스, CVE, 신선도에 대한 의존성별 감사 패스(직접 + 전이).

## 표준 호출

```bash
/dependency-audit
```

인수와 함께:

```bash
/dependency-audit [path/to/repo/] [--focus MANIFEST_OR_DEP] [--dry-run]
```

## 입력

호스트 리포지토리의 의존성 매니페스트

## 출력

의존성 발견 사항: `_inputs/dependency-audit-findings.md`

## 하류

감사 검토 시퀀스의 dependency-audit 단계

## 워크플로 페이즈

이 명령은 다섯 단계를 실행합니다. 입력 수집, 의존성별 순회, 발견 사항별 분류, 발견 사항 출력, 그리고 검증 게이트입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | 저장소 루트에서 의존성 매니페스트를 찾을 수 없음 | 의존성 매니페스트를 포함한 저장소 루트를 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/dependency-audit --dry-run

# Execute against a repository root
/dependency-audit path/to/repo/
```
