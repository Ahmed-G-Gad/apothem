**역할:** 책임 연구자(종합)
**파이프라인 위치:** 체인 중간

수집된 출처를 최신 기술 지도 + 문헌 행렬로 조정하고, 이 작업이 다루는 명시적 연구 공백을 진술합니다. 모든 핵심 주장은 기본 반박 방식으로 두 개 이상의 독립 출처에 대해 적대적으로 검증됩니다.

## 표준 호출

```bash
/research-synthesis
```

인수 사용:

```bash
/research-synthesis [path/to/research-suite/]
```

## 입력

`_inputs/source-ledger.md`(순위화·선별된 출처 색인)와 `sources/` 아래의 출처별 추출.

## 출력

`_inputs/synthesis.md` — 최신 기술 지도, 문헌 행렬, 논쟁 중인 발견 원장, 그리고 한 문장의 명시적 공백 진술.

## 하류

/research-proposal(하류 소비자)

## 워크플로 단계

이 명령은 표준 `/research` 파이프라인 워크플로를 따릅니다.

1. **컨텍스트 로드** — 출처 원장과 출처별 추출을 읽습니다.
2. **시퀀스 게이트 검증** — 출처 원장이 존재하는지 확인합니다. 그렇지 않으면 `Blocked: run /research-sources first`로 중단합니다.
3. **종합** — 최신 기술 지도 + 문헌 행렬을 구축합니다. 일치와 모순을 조정합니다. 명시적 공백을 진술합니다.
4. **적대적 검증** — 모든 핵심 주장을 기본 반박 방식으로 두 개 이상의 독립 출처에 대해 검증합니다.
5. **핸드오프 매니페스트 업데이트** — 종합 경로와 논쟁 중인 주장 원장을 기록합니다.
6. **종합 발행** — `_inputs/synthesis.md`.

## 최저 엄밀성 기준

공백 진술이 확정되기 전에, 종합은 그 용어, 발견, 권고를 관련된 형제 코퍼스와 대조하여 조정합니다(교차 코퍼스 정합성). 충돌은 논쟁 중인 발견 원장에 기록되며 결코 조용히 조화시키지 않습니다. 공백은 뚜렷하고 간명한 기여로 해소되어야 합니다 — 이미 입증된 주장으로 닫힌 것이 아니고, 겹치는 비고유 요소들로 분해되지도 않아야 합니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| Blocked: run /research-sources first | 출처 원장 없음 | `/research-sources`를 실행하여 `_inputs/source-ledger.md`를 생성 |
| 주장이 출처 2개 미만으로 살아남음 | 입증 불충분 | 논쟁 중 또는 검증 불가로 표시하고 단정하지 마세요 |
| 명시적 공백 진술 없음 | 종합에 목표가 없음 | 연구가 다루는 한 문장의 공백을 다시 도출 |

## 예시

```bash
# 수집된 출처를 최신 기술 지도 + 공백으로 종합
/research-synthesis path/to/research-suite/
```
