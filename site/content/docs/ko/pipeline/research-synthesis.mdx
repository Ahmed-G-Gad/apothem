**역할:** 책임 연구자(종합)
**파이프라인 위치:** 체인 중간

수집된 출처를 최신 기술 지도 + 문헌 행렬로 조정하고, 이 작업이 다루는 명시적 연구 공백을 진술합니다. 모든 핵심 주장은 기본 반박 방식으로 두 개 이상의 독립 출처에 대해 적대적으로 검증됩니다.

## 표준 호출

```bash
/research-synthesis
```

인수 사용:

```bash
/research-synthesis [--suite-name NAME]
```

## 입력

`_inputs/source-ledger.md`(순위화·선별된 출처 색인)와 `sources/` 아래의 출처별 추출.

## 출력

`_inputs/synthesis.md` — 최신 기술 지도, 문헌 행렬, 논쟁 중인 발견 원장, 그리고 그 근거가 되는 검색 범위를 갖춘 한 문장의 명시적 공백 진술. 보고서 수와 연구 수를 모두 보고합니다.

## 하류

/research-proposal(하류 소비자)

## 워크플로 단계

이 명령은 표준 `/research` 파이프라인 워크플로를 따릅니다.

1. **컨텍스트 로드** — 출처 원장과 출처별 추출을 읽습니다.
2. **시퀀스 게이트 검증** — 출처 원장이 존재하는지 확인합니다. 그렇지 않으면 `Blocked: run /research-sources first`로 중단합니다.
3. **종합** — 원장에서 각 출처의 연구 id, 증거 등급, 무결성 상태를 가져와 최신 기술 지도 + 문헌 행렬을 구축합니다. 일치와 모순을 조정합니다. 명시적 공백을 진술하고 그 근거가 되는 검색 범위를 명시합니다.
4. **적대적 검증** — 모든 핵심 주장을 기본 반박 방식으로 두 개 이상의 독립 연구에 대해 검증합니다.
5. **핸드오프 매니페스트 업데이트** — 종합 경로와 논쟁 중인 주장 원장을 기록합니다.
6. **종합 발행** — `_inputs/synthesis.md`.

## 최저 엄밀성 기준

공백 진술이 확정되기 전에, 종합은 그 용어, 발견, 권고를 관련된 형제 코퍼스와 대조하여 조정합니다(교차 코퍼스 정합성). 충돌은 논쟁 중인 발견 원장에 기록되며 결코 조용히 조화시키지 않습니다. 공백은 뚜렷하고 간명한 기여로 해소되어야 합니다 — 이미 입증된 주장으로 닫힌 것이 아니고, 겹치는 비고유 요소들로 분해되지도 않아야 합니다.

## 증거 계수

- **보고서가 아니라 연구.** 원장에서 연구 id를 공유하는 보고서, 수집된 표본을 공유하는 연구, 서로를 인용하는 출처는 하나의 출처로 셉니다. 한 저자 그룹의 두 논문은 먼저 데이터 공유 여부를 점검합니다. 확실성 등급도 같은 방식으로 독립 연구를 셉니다.
- **무결성.** 철회되거나 취하된 출처는 입증에 포함되지 않으며, 무결성 상태가 `concern`인 출처는 결코 주장의 유일한 근거가 되지 않습니다.
- **반대 증거와 범위.** 검색에서 발견된 선행 종합은 1차 연구를 찾는 데 쓰일 뿐 그것들과 나란히 계수되지 않습니다. 반대 증거 등급에 남은 것이 없으면 그 발견은 합의가 아니라 `none found in the searches recorded`로 기록되며, 공백 문장은 같은 용어로 그 범위를 명시합니다: 색인, 검색어와 기간, 마지막 실행 날짜, 그리고 `incomplete`로 표시된 모든 패스.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| Blocked: run /research-sources first | 출처 원장 없음 | `/research-sources`를 실행하여 `_inputs/source-ledger.md`를 생성 |
| 주장이 독립 연구 2개 미만으로 살아남음 | 입증이 불충분하거나, 출처들이 연구 또는 표본을 공유함 | 논쟁 중 또는 검증 불가로 표시하고 단정하지 마세요 |
| 공백이 분야 내의 부재로 진술됨 | 공백 문장 뒤에 검색 범위가 없음 | 기록된 검색을 범위로 명시하고, 그 너머의 부재는 결코 단정하지 마세요 |
| 명시적 공백 진술 없음 | 종합에 목표가 없음 | 연구가 다루는 한 문장의 공백을 다시 도출 |

## 예시

```bash
# 수집된 출처를 SOTA 지도와 공백으로 종합합니다
/research-synthesis --suite-name <name>
```
