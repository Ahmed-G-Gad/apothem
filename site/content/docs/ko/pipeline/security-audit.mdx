**역할:** 보안 감사자
**파이프라인 위치:** 포트리스

현행 OWASP ASVS 릴리스와 OWASP Top 10에 대한 포괄적인 보안 태세 감사.

## 표준 호출

```bash
/security-audit
```

인수와 함께:

```bash
/security-audit [path/to/repo/] [--focus CATEGORY] [--dry-run]
```

## 입력

고정된 git 커밋 상태의 호스트 저장소

## 출력

보안 발견 사항: `_inputs/security-audit-findings.md`

## 하류

감사 검토 시퀀스의 security-audit 단계

## 워크플로 페이즈

이 명령은 여섯 개의 감사 단계를 실행합니다. 입력 수집, 시크릿 및 권한, 입력 검증 및 인젝션, 역직렬화 및 경로 순회, 의존성 CVE 및 CodeQL, 그리고 검증 게이트를 거친 발견 사항 출력입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 전제 조건 미완료 | 의존 페이즈가 끝나지 않음 | 먼저 상류 페이즈를 완료한다 |
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 대상 거부 | 경로가 git 작업 트리가 아님 | 저장소 루트를 경로로 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/security-audit --dry-run

# Execute against a host repository
/security-audit path/to/repo/
```
