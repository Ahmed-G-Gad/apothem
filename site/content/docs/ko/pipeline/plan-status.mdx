**역할:** 리포터
**파이프라인 위치:** 읽기 전용

읽기 전용 플랜 스위트 진행 리포터 — 어떤 파일도 수정하지 않고 상태를 발행합니다.

## 표준 호출

```bash
/plan-status
```

인수와 함께:

```bash
/plan-status [path/to/plan-suite/] [--verbose]
```

## 입력

생명 주기의 어떤 상태에 있는 임의의 플랜 스위트 — `PROGRESS.md`, `PLAN-NOTES.md`, `MASTER-PLAN.md`, 그리고 `phases/` 리포트를 읽습니다.

## 출력

운영자의 출력 스트림에 기록되는 전략적 상태 리포트. 이 명령은 읽기 전용으로, 어떤 파일도 생성하거나 수정하지 않습니다.

## 하류

진행 점검을 위해 단독으로 사용 — 표준 시퀀스에 직교하며, 어느 시점에서든 읽기 전용으로 호출 가능합니다.

## 워크플로 페이즈

이 명령은 읽기 전용입니다 — 스위트의 추적 파일을 읽고 리포트하며, 아무것도 쓰지 않습니다:

1. **컨텍스트 로드** — `PROGRESS.md`, `PLAN-NOTES.md`, `MASTER-PLAN.md`를 읽고 기존 리포트를 위해 `phases/`를 스캔합니다.
2. **상태 평가** — 태스크 / 페이즈 / 아티팩트 차원을 살피고 재개 계약을 읽습니다.
3. **상태 리포트 발행** — 완료 상태, 페이즈 추적기, 전략적 분석을 운영자에게 직접 제시합니다.
4. **스폿 체크** — `--verbose`를 사용하면, 어떤 파일도 수정하지 않고 기존 파일에 대해 스위트 상태를 등급화하고 스폿 체크 증빙(마크다운 링크, 라인 범위, 커밋 SHA)을 인용합니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 필수 추적 파일 누락 | 플랜 스위트 미완성 | 공백을 발견 사항으로 표면화; `/plan-generate`를 실행해 스위트를 생성 |
| 잘못된 형식의 추적 파일 | 섹션이 잘리거나 파싱 불가 | 리포트에서 부재 / 모순을 명시; 복구는 쓰기 명령으로 라우팅 |
| 파일 간 필드 부재 또는 모순 | 추적 드리프트 | 모순을 명시적으로 리포트; 누락된 값을 합성하지 않음 |

## 예시

```bash
# 가장 최근 플랜 스위트에 대해 리포트
/plan-status

# 지정한 플랜 스위트에 대한 자세한 상태 등급
/plan-status path/to/plan-suite/ --verbose
```
