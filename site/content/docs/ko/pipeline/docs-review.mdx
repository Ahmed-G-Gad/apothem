**역할:** 문서 검토자
**파이프라인 위치:** 포트리스

산문 규약과 10차원 품질 표준에 대한 문서 검토 패스.

## 표준 호출

```bash
/docs-review
```

인수와 함께:

```bash
/docs-review [path/to/repo/ or path/to/docs-source/] [--focus FILE_OR_DIR] [--dry-run]
```

## 입력

호스트 리포지토리의 문서 표면

## 출력

문서 발견 사항: `_inputs/docs-review-findings.md`

## 하류

감사 검토 시퀀스의 문서 검토 단계

## 워크플로 페이즈

이 명령은 다섯 단계를 실행합니다. 입력 수집, 페이지별 순회, 발견 사항별 분류, 발견 사항 출력, 그리고 검증 게이트입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | 경로에서 문서 파일에 접근할 수 없음 | Markdown 페이지를 포함한 저장소 루트 또는 문서 소스 디렉터리를 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/docs-review --dry-run

# Execute against a repository root
/docs-review path/to/repo/
```
