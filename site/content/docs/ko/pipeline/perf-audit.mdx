**역할:** 성능 감사자
**파이프라인 위치:** 포트리스

USE 메서드를 사용하여 클래스별 성능 예산(훅 런타임, verify-ecosystem, 적합성 게이트, 테스트, 위임된 워커, 셸, 린트)에 대해 감사합니다.

## 표준 호출

```bash
/perf-audit
```

인수와 함께:

```bash
/perf-audit [path/to/repo/] [--focus CLASS] [--dry-run]
```

## 입력

`hooks/`, `src/apothem/benchmarks/`, `tests/`, 그리고 훅 부트스트랩 스텁 `hooks/lib/bootstrap.{sh,ps1}`를 포함한 호스트 저장소

## 출력

성능 발견 사항: `_inputs/perf-audit-findings.md`

## 하류

감사 검토 시퀀스의 성능 감사 단계

## 워크플로 페이즈

이 명령은 다섯 개의 감사 단계를 실행합니다. 입력 수집, 클래스별 예산 탐색, 벤치마크 실행, USE 메서드에 의한 핫 패스 식별, 그리고 검증 게이트를 거친 발견 사항 출력입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | 저장소에 `src/apothem/benchmarks/`가 없음 | 벤치마크 드라이버를 추가한 뒤 다시 실행한다. 드라이버가 있을 때까지 명령은 실행을 거부한다 |

## 예시

```bash
# Dry-run to preview what would happen
/perf-audit --dry-run

# Execute against a repository root
/perf-audit path/to/repo/
```
