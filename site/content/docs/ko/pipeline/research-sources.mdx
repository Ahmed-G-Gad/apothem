**역할:** 책임 연구자(출처 수집)
**파이프라인 위치:** 체인 중간

체계적 출처 수집 — 연구 명세를 하위 질의로 분해하고, 출처 발견과 출처별 추출을 병렬로 팬아웃하며, 중복을 제거하고, 권위/최신성/관련성으로 순위화하며, 명세의 포함 기준에 대해 선별하고, 살아남은 각 출처에 대해 출처 정보를 기록합니다.

## 표준 호출

```bash
/research-sources
```

인수 사용:

```bash
/research-sources [path/to/research-suite/] [--depth N]
```

## 입력

`_inputs/theory.md`(`/research-theory`, 이전 단계에서 나온 개념적/이론적 프레임워크)와 `_spec/research-spec.md`(`/research-spec`에서 승인된 연구 명세).

## 출력

`sources/<id>.md`(살아남은 출처마다 출처 정보가 포함된 추출 하나) + `_inputs/source-ledger.md`(인용 색인이 포함된, 순위화·선별·중복 제거된 출처 색인).

## 하류

/research-synthesis(하류 소비자)

## 워크플로 단계

이 명령은 표준 `/research` 파이프라인 워크플로를 따릅니다.

1. **컨텍스트 로드** — 연구 명세와 그 포함/제외 기준을 읽습니다.
2. **시퀀스 게이트 검증** — `_inputs/theory.md`(및 승인된 `_spec/research-spec.md`)가 존재하는지 확인합니다. 그렇지 않으면 `Blocked: run /research-theory first`로 중단합니다.
3. **발견 및 추출** — 하위 질의로 분해하고, 발견을 팬아웃하며, 중복을 제거하고, 순위화하고, 선별하며, 출처별로 출처 정보와 함께 추출합니다.
4. **출력 검증** — 살아남은 각 출처가 인용되고 명세 기준에 대해 선별되었는지 확인합니다.
5. **핸드오프 매니페스트 업데이트** — 출처 원장과 출처별 추출 경로를 기록합니다.
6. **원장 발행** — `sources/` 추출과 `_inputs/source-ledger.md`.

## 최저 엄밀성 기준

출처 원장을 넘어, 이 단계는 비교 대상 출처 원장을 구축합니다. 즉, 연구가 대조할 가장 최근의 최신 기술 기준선을 각각 검색 가능한 출처로 검증하고, 그 출처 정보와 접근 가능성을 함께 기록합니다. 확인하거나 가져올 수 없는 비교 대상은 그렇게 표시되며 결코 날조되지 않습니다(R1, R4).

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| Blocked: run /research-theory first | 이론적 근거 없음 | `/research-theory`를 실행하여 `_inputs/theory.md`를 생성 |
| 출처가 포함 기준에 미달 | 범위 밖이거나 권위가 낮은 출처 | 선별하여 제외하고, 원장에 제외 근거를 기록 |
| 날조된 인용 | 가져오지 않고 추측한 출처 | 출처를 절대 지어내지 마세요. 추측한 인용은 하나의 발견 사항입니다 |

## 예시

```bash
# 틀이 잡힌 연구 스위트를 위한 출처 수집
/research-sources path/to/research-suite/

# 더 깊은 발견 팬아웃
/research-sources path/to/research-suite/ --depth N
```
