**역할:** 아키텍처 리뷰어
**파이프라인 위치:** 포트리스

`_inputs/design.md`의 설계 산출물에 대한 아키텍처 무결성 검토.

## 표준 호출

```bash
/architecture-review
```

인수와 함께:

```bash
/architecture-review [path/to/repo/] [--focus LAYER] [--dry-run]
```

## 입력

호스트 리포지토리 + `_inputs/design.md`

## 출력

아키텍처 발견 사항: `_inputs/architecture-review-findings.md`

## 하류

감사 검토 시퀀스의 아키텍처 검토 단계

## 워크플로 페이즈

이 명령은 다섯 개의 감사 단계를 실행합니다. 입력 수집, 설계-코드 추적성 순회, 레이어 경계 무결성 감사, 패키지 간 결합 점검, 그리고 검증 게이트를 거친 발견 사항 출력입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 입력 파일 누락 | 설계 아티팩트 `_inputs/design.md`가 없음 | `/plan-design`을 실행해 생성한다 |

## 예시

```bash
# Dry-run to preview what would happen
/architecture-review --dry-run

# Execute against a repository root
/architecture-review path/to/repo/
```
