**역할:** UX 검토자
**파이프라인 위치:** 요새

CLI 인체공학, 문서, 온보딩에 대한 개발자 경험 검토.

## 정규 호출

```bash
/ux-review
```

인자와 함께:

```bash
/ux-review [path/to/repo/] [--focus SURFACE] [--dry-run]
```

## 입력

README, 설치 스크립트, CLI 진입점을 갖춘 배포된 호스트 저장소

## 출력

UX 발견 사항: `_inputs/ux-review-findings.md`

## 하류

감사 검토 시퀀스의 UX 검토 단계

## 워크플로 페이즈

이 명령은 다섯 단계를 실행합니다. 입력 수집, CLI 사용성 순회, 설치 흐름 및 오류 복구 감사, 문서 발견 가능성 점검, 그리고 검증 게이트를 거친 발견 사항 출력입니다.

## 실패 모드

| 증상 | 원인 | 복구 |
|---------|-------|----------|
| 전제 조건 미완료 | 의존 페이즈가 끝나지 않음 | 먼저 상류 페이즈를 완료한다 |
| 품질 게이트 FAIL | 출력이 기준을 충족하지 않음 | 출력을 수정하고 다시 실행한다 |
| 대상 미배포 | 대상에 운영자 대면 표면이 없음 | 배포된 저장소 루트를 전달한다 |

## 예시

```bash
# Dry-run to preview what would happen
/ux-review --dry-run

# Execute against a host repository
/ux-review path/to/repo/
```
