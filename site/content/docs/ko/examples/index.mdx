처음부터 끝까지 따라 하는 실습 안내입니다. 각 예제는 하나의 작업을 빈 상태에서
시작해 완성된 아티팩트까지 진행하며, 각 단계의 명령, 파일, 판단 근거를 보여
줍니다.

저장소와 함께 제공되는 실행 가능한 예제 프로젝트는 저장소 루트의
[`examples/`](https://github.com/ahmed-g-gad/apothem/tree/main/examples)
디렉터리에 있습니다. 아래 페이지들은 그중 네 개를 처음부터 끝까지 설명합니다.
나머지는 자체 완결형이며, 각자 README를 갖추고 있어 저장소에서 직접 읽습니다.
