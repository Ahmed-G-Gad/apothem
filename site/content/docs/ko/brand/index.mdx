Apothem은 두 형태의 브랜드 규율을 사용합니다:

| 형태 | 용도 | 예시 |
|---|---|---|
| **Apothem** | 표시 형태 -- 모든 산문, 제목, UI, 문서 | Apothem vX.Y.Z, Install Apothem |
| **apothem** | 식별자 형태 -- CLI 명령, 패키지 이름, 파일 경로 | npx @ahmed-g-gad/apothem, apothem install |

절대 사용하지 마세요: Apothem(첫 글자만 대문자), apothem(하이픈 포함), APOTHEM(전부 대문자).

## 태그라인

> 하나의 공유 프로파일. 열일곱 가지 프로그래밍 보조 도구. 재발명 없음.

## 로고

Apothem 마크는 apothem 엮음 모티프를 사용합니다. 밝은 변형과 어두운 변형은
`assets/logo.svg`와 `assets/logo-dark.svg`에서 제공됩니다. 가로형 록업은
`assets/logo-wordmark.svg`와 `assets/logo-wordmark-dark.svg`에 있습니다.

브라우저 파비콘은 전체 엮음 마크 대신 의도적으로 컴팩트한 `assets/favicon.svg`
모노그램을 사용합니다. 16px에서는 모노그램이 브라우저 탭과 고정된 표면에서 더
선명합니다.

허용된 용도와 여백 요건은 [로고 사용](/docs/brand/logo-usage)을 참조하세요.

## 팔레트

전체 색상 명세는 [팔레트](/docs/brand/palette)를 참조하세요.

## 환경 색상

mermaid 다이어그램, 환경 페이지, 어댑터 상태 표시기에서 사용되는 환경별 브랜드
색상 표는 [환경 색상](/docs/brand/harness-colors)을 참조하세요.

## 에셋 팔레트 근거

Apothem 마크의 주변 노드는 장식적 기하 형상입니다 — 환경 수를 부호화하지 않고
허브-앤-스포크 아키텍처를 연상시키므로, 어댑터가 추가되어도 마크는 안정적으로
유지됩니다. 환경 팔레트의 색상 할당은 [환경 색상](/docs/brand/harness-colors)에
있으며, 접근성 자세와 표면별 전파 규칙은 그 페이지에 문서화되어 있습니다.

## 에셋 재빌드

마스터 SVG에서 래스터 에셋을 재생성하는 방법은 [재빌드 레시피](/docs/brand/rebuild-recipe)를
참조하세요.
