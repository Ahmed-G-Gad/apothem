Apothem은 두 형태의 브랜드 규율을 사용합니다:

| 형태 | 용도 | 예시 |
|---|---|---|
| **Apothem** | 표시 형태 -- 모든 산문, 제목, UI, 문서 | Apothem vX.Y.Z, Install Apothem |
| **apothem** | 식별자 형태 -- CLI 명령, 패키지 이름, 파일 경로 | npx @ahmed-g-gad/apothem, apothem install |

절대 사용하지 마세요: ApoThem(카멜 케이스), Apo-them(하이픈 포함), APOTHEM(전부 대문자), 또는 산문에서의 소문자 `apothem`. `Apothem`이 유일한 표시 형태입니다.

## 태그라인

> one profile, every harness

태그라인은 워드마크 록업과 소셜 카드에 실린 그대로 소문자로
표기합니다.

## 로고

Apothem 마크는 윗변이 평평한 정육각형으로, 공유된 중심에서 모든 변의 중점까지
부채꼴로 뻗은 여섯 개의 apothem, 그 여섯 중점을 지나는 내접원, 그리고 중심의 소스
노드로 이루어집니다. 윗변으로 향하는 apothem은 emerald이고 나머지 다섯 개는
slate이며, 기하 구조는
[`assets/DESIGN-SYSTEM.md`](https://github.com/ahmed-g-gad/apothem/blob/main/assets/DESIGN-SYSTEM.md)에 명세되어 있습니다.
밝은 변형과 어두운 변형은 `assets/logo.svg`와
`assets/logo-dark.svg`에서 제공됩니다. 가로형 록업은 `assets/logo-wordmark.svg`와
`assets/logo-wordmark-dark.svg`에 있습니다.

브라우저 파비콘은 전체 마크 대신 의도적으로 컴팩트한 `assets/favicon.svg`
모노그램을 사용합니다. 16px에서는 모노그램이 브라우저 탭과 고정된 표면에서 더
선명합니다.

허용된 용도와 여백 요건은 [로고 사용](/docs/brand/logo-usage)을 참조하세요.

## 팔레트

전체 색상 명세는 [팔레트](/docs/brand/palette)를 참조하세요.

## 하니스 색상

mermaid 다이어그램, 하니스 페이지, 어댑터 상태 표시기에서 사용되는 하니스별 브랜드
색상 표는 [하니스 색상](/docs/brand/harness-colors)을 참조하세요.

## 에셋 팔레트 근거

Apothem 마크의 주변 노드는 장식적 기하 형상입니다 — 하니스 수를 부호화하지 않고
허브-앤-스포크 아키텍처를 연상시키므로, 어댑터가 추가되어도 마크는 안정적으로
유지됩니다. 하니스 팔레트의 색상 할당은 [하니스 색상](/docs/brand/harness-colors)에
있으며, 접근성 자세와 표면별 전파 규칙은 그 페이지에 문서화되어 있습니다.

## 에셋 재빌드

마스터 SVG에서 래스터 에셋을 재생성하는 방법은 [재빌드 레시피](/docs/brand/rebuild-recipe)를
참조하세요.
