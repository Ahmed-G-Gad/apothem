Apothem은 거버넌스 부담을 참여 수준에 맞춰 조정합니다. 빠른 탐색에는 서명된
커밋이 필요 없지만, 프로덕션 출시에는 필요합니다.

## 네 가지 등급

| 등급 | 사용 시점 | 거버넌스 하한 |
|------|-------------|-----------------|
| **EXPLORING** | 프로토타입, 일회성 실험 | 린트 + 테스트 + 핵심 의무(비판적 평가, 최선의 해법 추론, 직설적 정직성) |
| **PERSONAL_USE** | 개인 도구, 로컬 스크립트 | + 타입 검사 + 단계별 커밋 + PROGRESS.md |
| **SHARED** | 팀 프로젝트, 오픈소스 | + 실패한 검사가 실행을 차단 + 작업별 커밋 + 전체 문서 + 병렬 검토 |
| **PUBLIC_LAUNCH** | 프로덕션 서비스, 게시된 패키지 | + 보안 스캔 + 서명된 커밋 + semver + 필수 재검토 |

## 임시 기본값

진지도 등급이 지정되지 않은 경우 Apothem은 **PERSONAL_USE**를 기본값으로 합니다.

## 최소 실행 가능 거버넌스

EXPLORING에서는 등급과 무관하게 세 가지 교차 의무가 항상 적용됩니다:
- CM-1 (비판적 평가)
- CM-5 (최선의 해법)
- CM-10 (가차 없는 정직성)

## 등급 상향

진지도 등급은 프로젝트 진행 중에 상향할 수 있습니다. PERSONAL_USE 프로젝트가
SHARED로 승격될 때, 낮은 등급에서 누적된 거버넌스 공백을 잡아내기 위해 전체
로컬 릴리스 준비 스윕을 실행하십시오.
