## GitHub Discussions

주요 커뮤니티 공간은 [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions)입니다.

범주:

| 범주 | 용도 |
|----------|---------|
| Q&A | 사용, 구성, 동작에 관한 질문 |
| Ideas | 기능 요청 및 설계 논의 |
| Show and tell | Apothem을 사용하는 방식 공유 |
| General | 그 외 모든 것 |

## Issues

버그와 구체적인 기능 요청은
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues)를 사용하십시오.

이슈를 열기 전에 중복을 피하기 위해 기존 이슈와 토론을 검색하십시오.

## 기여하기

코드, 문서, 하니스 어댑터를 기여하는 방법은 [기여하기](/docs/developer-guide)를
참조하십시오. 저장소의
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)와
거기서 참조하는 풀 리퀘스트 템플릿부터 시작하십시오.
