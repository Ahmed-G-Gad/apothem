## 현재 릴리스

- 열일곱 개 도구 어댑터를 안정화합니다.
- 감사 검토 인프라를 완성합니다.
- Apothem CLI 표면을 안정화합니다.
- GitHub Actions CI/CD 파이프라인을 구축합니다.

## 단기

- npm / npx 배포를 성숙시킵니다: `@ahmed-g-gad/apothem` 엔트리 포인트를 각
  릴리스와 정렬 유지하고 플랫폼 커버리지를 넓힙니다.
- 마켓플레이스 표면이 안정화됨에 따라 Claude Code 플러그인 등재를 키웁니다.
- `apothem update --watch`를 통한 도구 어댑터 자동 업데이트.
- 프로파일 버저닝 및 마이그레이션 도구.
- 적합성 게이트에서의 공유 프로파일 스키마 검증.
- 커뮤니티 요청에 기반한 추가 도구 어댑터.

## 장기

- 클라우드 호스팅 프로파일 동기화(선택, 운영자 제어).
- 실시간 적합성 피드백을 위한 VS Code 확장.
- 팀 공유 프로파일 관리.

## 요청 및 피드백

[GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions)를 통해
로드맵 요청을 제출하십시오. 로드맵은 커뮤니티 의견을 반영하며, 인기 있는 요청이
더 빨리 진행됩니다.
