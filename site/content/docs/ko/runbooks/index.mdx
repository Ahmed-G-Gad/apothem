메인테이너를 위한 운영 절차입니다. 각 런북은 순서가 정해진, 맥락에 의존하지 않는
절차입니다. 알려진 시작 상태를 검증된 종료 상태로 이끌며, 유능한 기여자가 사전
맥락 없이 따라 할 수 있도록 작성되었습니다.

## 페이지

| 페이지 | 설명 |
|------|-------------|
| [Pages 활성화](/docs/runbooks/pages-enablement) | `apothem.ahmedgad.com`을 새로 만든 GitHub Pages 구성에서 `200 OK`를 반환하는 HTTPS 랜딩 페이지까지 이끕니다. |
| [릴리스 사이클](/docs/runbooks/release-cycle) | `vX.Y.Z` 릴리스를 깨끗한 작업 트리에서 검증된 GitHub Release 및 npm 표면까지 이끕니다. |
| [퍼블리셔 계정 설정](/docs/runbooks/publisher-account-setup) | `@ahmed-g-gad/apothem`을 위한 npmjs.com 신뢰 퍼블리셔와 GitHub 측 릴리스 사전 요건을 구성합니다. |
| [릴리스 복구](/docs/runbooks/release-recovery) | 릴리스 전환 시퀀스가 도중에 실패할 때 `ahmed-g-gad/apothem`을 동작하는 상태로 복원합니다. |
| [새 환경 어댑터 작성](/docs/runbooks/new-harness-adapter-authoring) | 퍼스트파티 포함을 위해 새 환경 어댑터를 작성하고 게시합니다. |
