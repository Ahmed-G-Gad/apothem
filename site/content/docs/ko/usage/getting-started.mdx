Apothem은 네 가지 핵심 기능을 제공합니다. 공유 거버넌스 프로파일, 규칙 코퍼스,
구조화된 계획 파이프라인, 그리고 실시간 적합성 게이트입니다.

  [시작하기 튜토리얼](/docs/tutorials/getting-started)부터 시작하세요. 이 페이지는
  설정을 마친 뒤 네 가지 핵심 워크플로를 빠르게 참고하기 위한 것입니다.
</Callout>

## 공유 프로파일

`--profile PATH`를 전달하지 않는 한, Apothem 프로파일은
`~/.config/apothem/profile.yaml`에 있습니다. 이는 모든 환경 어댑터가 네이티브
구성을 도출하는 단일 진실 공급원입니다.

```yaml
identity:
  name: "Example User"
preferences:
  style: "concise"
rules:
  - "Validate external input before writing files."
```

프로파일을 생성하고 확인합니다.

```bash
apothem profile init
apothem profile show --json
```

## 첫 규칙

프로파일 YAML에 공유 규칙을 추가한 다음, 선택한 환경을 다시 물화합니다. 그 규칙에
예제 데이터를 포함할 때는 실제 신원이나 자격 증명이 공유 프로파일이나 CI 실행에
들어가지 않도록 가짜 자리표시자를 사용하세요.

```bash
apothem profile set rules '["Always include a brief summary at the end of every response."]'
apothem update --harness claude-code
apothem verify --harness claude-code
```

## 첫 계획

`/plan` 파이프라인은 `apothem` 바이너리가 아니라 프로그래밍 도구 안에서 슬래시
명령으로 실행됩니다. 환경을 설치한 뒤에는 도구의 채팅에서 계획을 시작하세요.

```text
/plan-spec
```

`/plan-spec`은 산문을 명세로 다듬고, `/plan-generate`는
`<project-root>/.apothem/plans/{suite}/` 아래에 계획 스위트를 물화합니다. 전체 흐름은
[파이프라인 명령 참조](/docs/pipeline)를 보세요.

## 적합성 게이트

리포지토리 루트에서 실행합니다.

```bash
python -m apothem.conformity.gate --all .
```

모든 기계적 적합성 검사를 실행하고 바마다 통과/실패를 보고합니다.
