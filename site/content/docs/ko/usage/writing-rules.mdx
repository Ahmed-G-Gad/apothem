규칙은 `src/apothem/rules/` 아래에 있는 `.md` 확장자의 Markdown 파일입니다.

## 규칙 프런트매터

```yaml
---
name: "..."
description: "..."
pathFilter: ""            # empty string for always-on; a glob for path-filtered
alwaysApply: true         # true for always-on; false for path-filtered
---
```

## 규칙 범위

규칙의 범위는 두 프런트매터 필드인 `alwaysApply`와 `pathFilter`로 설정됩니다:

| `alwaysApply` | `pathFilter` | 적용 시점 |
|---------------|--------------|--------------|
| `true` | `""`(빈 값) | 항상 적용: 모든 세션, 모든 파일 |
| `false` | `"**/*.py"` 같은 glob | 경로 필터: 활성 파일이 glob과 일치할 때만 |

## 예시 규칙

```markdown
---
name: "python-conventions"
description: "Python style conventions for this project"
pathFilter: "**/*.py"
alwaysApply: false
---

# Python conventions

- Use type annotations on all public functions.
- Maximum line length: 88 characters.
- Prefer explicit over implicit.
```

## 규칙을 하니스에 적용

규칙을 작성한 뒤에는 설치된 각 하니스 어댑터를 업데이트하십시오. `apothem harnesses list`를 실행하여 설치된 집합을 확인한 다음, 하니스마다 한 번씩 update 명령을 실행하십시오:

```bash
apothem update --harness claude-code
apothem update --harness cursor
```

## 규칙 검증

```bash
python -m apothem.conformity.gate --check frontmatter
```
