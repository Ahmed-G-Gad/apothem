> **열다섯 항목 사전 발행 게이트의 정규 레지스트리.** 이 문서는 완전한 열다섯 항목 게이트 표와 릴리스 증명 스키마 YAML 블록을 담습니다. 실질적인 표와 스키마는 여기에 있으며, `src/apothem/rules/pre-emission-gate.md`에 의해 운용됩니다.

의미 있는 범위의 아티팩트 발행 이전에(`site/content/docs/governance/outward-conformity-registry.mdx` §1의 사소함 대 비사소함 임계값에 따라) 열다섯 항목 사전 발행 게이트를 실행하라. 가능한 곳에서는 PreToolUse 훅으로 기계화하고(`src/apothem/conformity/gate.py`가 편성하는 `src/apothem/conformity/*-grep.py`의 기계적 grep), 기계화가 불가능한 곳에서는 추론한다. **단 한 항목의 실패도 발행을 차단한다; 모든 항목이 통과할 때까지 수정하라; 게이트 릴리스 증명을 기록하여 발행하라.**

## 1. 릴리스 증명 스키마

각 게이트 실행은 아티팩트의 작업 자취(숨김 주석, 메타데이터 블록, 별도의 발행 로그 파일 — 호스트의 관례가 허용하는 것)에 결과를 기록합니다:

```yaml
conformity-attestation:
  artifact: <path-or-identifier>
  ecosystem-version: <git-commit-sha-or-equivalent ratifying the rule set in force>
  bars:
    M1-host-agnosticism:        pass | n/a (with reason)
    M2-editorial-disclosure:    pass | n/a
    M3-ten-dimensions:          pass | n/a
    M4-self-application:        pass
    M5-authority:               pass
    M6-expertise:               pass | n/a
    M7-option-annotation:       pass | n/a (no option set)
    M8-definitiveness:          pass
    M9-visual-leverage:         pass | n/a (subject not structural)
    M10-bidirectional-binding:  pass
    M11-agile-sprints:          pass | n/a (trivial work)
    M12-phase-layout:           pass | n/a
    M13-code-craft:             pass | n/a (not code)
    M14-systemicity:            pass
    M15-production-ready:       pass | n/a (no host-public-surface change)
  surfaced-gaps: []
  unresolved-inquiries: []
  amendments-disclosed: []
  date: <ISO-8601>
```

`n/a` 표시는 명시적이고 추론된 것입니다 — 결코 침묵하는 생략이 아닙니다. `ecosystem-version` 필드는 릴리스 증명을 사용자 범위 생태계의 재현 가능한 상태(게이트가 실행될 때 활성이던 Apothem 소스 트리의 git 커밋 — 예컨대 Claude Code 어댑터의 `~/.claude/` 체크아웃)에 고정하여, 향후 감사가 동일한 규칙 본문에 대해 게이트를 재현할 수 있게 합니다.
