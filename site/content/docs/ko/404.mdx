이 페이지는 존재하지 않는 harness로 길을 잃었습니다.

## 필요한 것 찾기

- **[빠른 시작](/docs/install/quickstart)** — 설치하고, 프로파일을 설정하고, 첫 harness를 구성합니다.
- **[튜토리얼](/docs/tutorials)** — 깨끗한 머신에서 물화된 harness까지 안내하는 첫걸음.
- **[가이드](/docs/usage)** — 일상 워크플로: 규칙, 계획, 헬퍼, 훅, 컨포미티 게이트.
- **[Harness](/docs/harnesses)** — 지원되는 17개의 harness, 각각 고유한 어댑터와 물화 루트를 가집니다.
- **[참조](/docs/reference)** — 모든 하위 명령, 플래그, 스키마, 레지스트리, 규약.
- **[FAQ](/docs/faq)** — 흔한 질문과 빠른 답변.

헤더의 검색 상자를 사용해 색인된 페이지를 찾으세요.

Apothem 문서 내부의 링크를 따라왔다면, 수정될 수 있도록 [issue를 여세요](https://github.com/ahmed-g-gad/apothem/issues/new?labels=docs&title=Broken+link%3A+).
