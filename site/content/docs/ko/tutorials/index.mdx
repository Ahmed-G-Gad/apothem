튜토리얼은 처음부터 끝까지 안내하는 엔드투엔드 레슨입니다. 각 레슨을 처음부터
끝까지 따라가면, 끝날 때 여러분의 머신에서 실제로 동작하는 무언가가 손에 들어옵니다.
Apothem에 대한 사전 지식을 전제하지 않으며, 진행하면서 모든 단계를 설명합니다.

원하는 것을 이미 알고 있고 정확한 명령만 필요하다면,
[하우투 가이드](/docs/how-to)와 [참조](/docs/harnesses)가 더 빠른
길입니다.

## 여기서 시작하기

- [시작하기](/docs/tutorials/getting-started) — Apothem을 설치하고, 공유
  프로파일을 작성하고, 어떤 harness의 네이티브 구성을 물화하고, 검증합니다.
  빈 머신에서 동작하는 첫 실행까지 대략 15분입니다.
