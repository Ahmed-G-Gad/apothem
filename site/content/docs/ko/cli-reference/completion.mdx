요청한 shell의 셸 자동완성 스크립트를 표준 출력으로 인쇄합니다. 자동완성 활성화는 **선택 사항(opt-in)**입니다. 이 명령은 스크립트를 인쇄만 할 뿐 — shell 시작 파일을 절대 편집하지 않습니다. 출력을 shell의 자동완성 파일에 추가하는 것은 사용자 본인입니다.

## 개요

```
apothem completion bash|zsh|fish|powershell
```

발생된 스크립트는 `apothem` 하위 명령, 플래그, 그리고 — `--harness` 옵션의 경우 — 등록된 harness id와 `all`에 대한 `<TAB>` 자동완성을 활성화합니다.

## 지원되는 shell

| Shell | 스크립트 생성 방식 |
|---|---|
| `bash` | Click의 네이티브 bash 자동완성 스크립트. |
| `zsh` | Click의 네이티브 zsh 자동완성 스크립트. |
| `fish` | Click의 네이티브 fish 자동완성 스크립트. |
| `powershell` | Click의 자동완성 프로토콜로 연결되는 `Register-ArgumentCompleter` 스니펫(Click은 네이티브 PowerShell 스크립트를 제공하지 않으므로, 이 스니펫이 동일한 프로토콜을 PowerShell에 연결합니다). |

그 외 shell을 요청하면 지원 shell 목록과 함께 `64`로 종료됩니다.

## shell별 자동완성 활성화

먼저 `apothem` 명령이 `PATH`에 있어야 합니다(원샷 설치 프로그램이 그곳에 배치합니다). 그런 다음 스크립트를 shell의 자동완성 파일에 추가하고 shell을 다시 시작하여 자동완성을 활성화합니다.

```bash
# bash — bashrc에 추가
apothem completion bash >> ~/.bashrc

# zsh — zshrc에 추가
apothem completion zsh >> ~/.zshrc

# fish — fish 자동완성 디렉터리에 작성
apothem completion fish > ~/.config/fish/completions/apothem.fish
```

```powershell
# PowerShell — 완성기 등록을 프로필에 추가
apothem completion powershell >> $PROFILE
```

파일을 편집하지 않고 현재 세션에서만 자동완성을 시험해 보려면 스크립트를 직접 source 합니다(bash/zsh): `source <(apothem completion bash)`.

## 선택 사항인 이유

Apothem은 운영자의 shell 시작 파일을 조용히 편집하지 않습니다. 설치 프로그램은 이 명령을 가리키는 한 줄 힌트를 인쇄합니다. 자동완성을 활성화할지, 어느 파일에 추가할지는 운영자가 결정합니다. 이로써 설치 흔적이 예측 가능하고 되돌릴 수 있게 됩니다 — 추가한 블록을 제거하면 자동완성이 비활성화됩니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| `SHELL` | `bash`, `zsh`, `fish`, `powershell` 중 하나(필수 위치 인수). |
| `-h`, `--help` | 도움말을 표시하고 종료. |

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 자동완성 스크립트 발생됨 |
| 2 | 지원되지 않는 shell 요청됨 |
