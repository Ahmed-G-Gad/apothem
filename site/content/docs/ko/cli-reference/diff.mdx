단일 하니스의 대기 중인 구성 변경 사항을 미리 봅니다.

## 개요

```
apothem diff --harness NAME [--profile PATH] [--project PATH]
             [--quiet|-q] [--verbose|-v]
             [--format plain|json] [--json] [--no-color]
```

`diff`는 읽기 전용 검사 명령입니다. `install` 명령이 실행할 것과 동일한 구체화를
실행하지만 드라이런 모드에서 동작합니다 — 디스크에는 아무것도 기록되지 않습니다. 그런
다음 계획된 대상별로 작업, 대상 경로, 결과, 그리고 (병합될 운영자 소유 앵커에 대해서는)
변경의 통합 diff를 렌더링합니다. 이는 변경을 수행하지 않고 "지금 이 순간
`apothem install`이 이 하니스에 무엇을 할 것인가?"에 대한 답입니다.

운영자 소유 대상 — 자신의 콘텐츠와 Apothem 관리 블록을 모두 담는 파일 — 에 대해 diff는
변경될 정확한 줄을 보여줍니다. 다른 대상에 대해서는 계획된 작업과 결과가 요약됩니다.

`diff`는 단일 하니스에 대해 동작합니다. `status`와 달리 `all`을 받아들이지
않습니다. 하나의 하니스 이름을 전달하세요.

## 옵션

| 옵션 | 설명 |
|---|---|
| `--harness NAME` | 미리 볼 하니스 어댑터(필수; `all`이 아닌 단일 어시스턴트). |
| `--profile PATH` | 공유 프로필 YAML의 경로. 기본값은 `~/.config/apothem/profile.yaml`. |
| `--project PATH` | 프로젝트 범위 하니스의 프로젝트 루트. 선택한 어시스턴트가 프로젝트 범위일 때 필수. |
| `--quiet`, `-q` | 정보성 출력을 억제하고 오류만 발행합니다. |
| `--verbose`, `-v` | 추가 진단 출력을 발행합니다. |
| `--format plain\|json` | 출력 형식(기본값: `plain`). |
| `--json` | `--format json`의 단축형. |
| `--no-color` | 출력에서 ANSI 색상 코드를 비활성화합니다. |
| `-h`, `--help` | 도움말을 표시하고 종료합니다. |

## JSON 출력

`--json` 봉투는 드라이런 install 봉투를 반영합니다. `status`는 `dry_run`,
`files_written`은 항상 비어 있으며, `materialization` 블록과 `results` 목록이 계획된
대상의 전체 세부 정보를 담습니다. 각 운영자 소유 결과 행의 `detail.diff` 필드는 통합
diff 문자열을 담습니다.

```json
{
  "status": "dry_run",
  "command": "diff",
  "action": "dry_run",
  "harness": "claude-code",
  "files_written": [],
  "results": [
    {
      "harness": "claude-code",
      "outcome": "updated",
      "operation": "sentinel_merge",
      "path": "C:\\Users\\Example\\.claude\\CLAUDE.md",
      "message": "dry run: no filesystem changes made",
      "detail": {
        "ownership_class": "operator-owned",
        "diff": "--- a/CLAUDE.md\n+++ b/CLAUDE.md\n@@ ..."
      }
    }
  ],
  "warnings": [],
  "error": null,
  "materialization": { "...": "..." }
}
```

## 예시

```bash
apothem diff --harness claude-code
apothem diff --harness cursor --project .
apothem diff --harness claude-code --json
```

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | diff 보고됨(대기 중인 변경 사항은 보고되며 오류가 아님) |
| 1 | 예상된 검증, 프로필, 하니스 또는 프로젝트 오류 |
