Apothem 설치에 대한 시스템 진단을 실행합니다.

## 개요

```
apothem doctor [--quiet|-q] [--verbose|-v]
               [--format plain|json] [--json] [--no-color]
```

Apothem 설치를 점검하고 등록된 각 하네스 어댑터의 상태를 보고합니다. 공유 프로필이
있으면 단순히 존재 여부만 확인하는 것이 아니라 패키지에 포함된 스키마에 대해
검증되므로, 잘못된 프로필은 녹색 "발견" 대신 진단 실패로 드러납니다. JSON 출력에는
`profile_valid` 필드(`true` / `false`, 프로필이 없으면 `null`)와 검증이 실패할 때의
`profile_error` 필드가 포함됩니다. 모든 점검이 통과하면 0으로 종료하고, 하나 이상의
하네스가 설치되지 않았거나 존재하는 프로필이 스키마 검증에 실패하면 1로 종료합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| `--quiet`, `-q` | 정보성 출력을 억제하고 오류만 내보냅니다. |
| `--verbose`, `-v` | 추가 진단 출력을 내보냅니다. |
| `--format plain\|json` | 출력 형식(기본값: `plain`). |
| `--json` | `--format json`의 약어. |
| `--no-color` | 출력의 ANSI 색상 코드를 비활성화합니다. |
| `-h`, `--help` | 도움말을 표시하고 종료합니다. |

## 예제

```bash
apothem doctor
apothem doctor --json
```

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 모든 점검 통과 |
| 1 | 하네스가 설치되지 않았거나, 존재하는 프로필이 스키마 검증에 실패함 |
