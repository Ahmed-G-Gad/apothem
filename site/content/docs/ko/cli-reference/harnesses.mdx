등록된 하니스 어댑터를 나열하고 검사합니다.

`harnesses`는 `list`와 `show`라는 두 하위 명령을 가진 명령 그룹입니다.

## 개요

```
apothem harnesses list [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
apothem harnesses show NAME
                       [--quiet|-q] [--verbose|-v]
                       [--format plain|json] [--json] [--no-color]
```

## 하위 명령

### `harnesses list`

등록된 모든 하니스 어댑터를 나열합니다.

| 옵션 | 설명 |
|---|---|
| `--quiet`, `-q` | 정보성 출력을 억제하고 오류만 내보냅니다. |
| `--verbose`, `-v` | 추가 진단 출력을 내보냅니다. |
| `--format plain\|json` | 출력 형식(기본값: `plain`). |
| `--json` | `--format json`의 단축형. |
| `--no-color` | 출력에서 ANSI 색상 코드를 비활성화합니다. |
| `-h`, `--help` | 도움말을 표시하고 종료합니다. |

### `harnesses show NAME`

특정 하니스 어댑터의 세부 정보를 표시합니다. `NAME`은 kebab-case 하니스
식별자입니다. 사용 가능한 식별자를 보려면 `apothem harnesses list`를 실행하세요.

| 옵션 | 설명 |
|---|---|
| `NAME` | 검사할 하니스 어댑터(필수 위치 인수). |
| `--quiet`, `-q` | 정보성 출력을 억제하고 오류만 내보냅니다. |
| `--verbose`, `-v` | 추가 진단 출력을 내보냅니다. |
| `--format plain\|json` | 출력 형식(기본값: `plain`). |
| `--json` | `--format json`의 단축형. |
| `--no-color` | 출력에서 ANSI 색상 코드를 비활성화합니다. |
| `-h`, `--help` | 도움말을 표시하고 종료합니다. |

## 예시

```bash
apothem harnesses list
apothem harnesses list --json
apothem harnesses show claude-code
apothem harnesses show claude-code --json
```

등록된 하니스 ID는 다음과 같습니다.

```text
antigravity
claude-code
codebuddy
codex
cursor
gemini-cli
github-copilot
glm
hermes
kimi-code
kiro
open-claw
opencode
qwen-code
trae
windsurf
zed
```

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 성공 |
| 1 | 하니스를 찾을 수 없음(알 수 없는 `NAME`을 사용한 `harnesses show`), 또는 모든 어댑터가 로드나 보고에 실패함(`harnesses list`) |
| 2 | 하나 이상의 어댑터가 나열되었지만, 하나 이상의 어댑터가 보고에 실패함(`harnesses list`) |
| 64 | 사용법 오류: 알 수 없는 옵션이나 명령, 또는 누락되었거나 잘못된 옵션 값. `--json`에서는 오류가 코드 `cli.usage`를 담은 JSON 봉투로 반환됩니다. |
