하니스를 기록된 설치 직전 상태로 복원합니다.

## 개요

```
apothem rollback --harness NAME|all [--install-id ULID | --last] [--yes]
                 [--project PATH]
                 [--quiet|-q] [--verbose|-v]
                 [--format plain|json] [--json] [--no-color]
```

`rollback`은 선택한 각 하니스의 설치 전 바이트를 Apothem 백업 루트에서 재구성합니다. 기록된 설치 패스 — 기본적으로 가장 최근 패스, 또는 `--install-id`로 지정한 패스 — 를 해석하여 해당 설치가 캡처한 모든 백업을 복원한 다음, 하니스 원장에 `rollback` 기록을 추가합니다.

`--yes`가 제공되지 않는 한 하니스별로 확인을 요청합니다. `--install-id`와 `--last`는 설치 패스를 선택하며 상호 배타적입니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| `--harness NAME` | 롤백할 하니스 어댑터, 또는 레지스트리 전역 집합을 나타내는 `all`(필수). |
| `--install-id ULID` | 지정한 설치 패스를 롤백합니다. 기본값은 가장 최근에 기록된 설치입니다. |
| `--last` | 가장 최근에 기록된 설치를 롤백합니다(기본값의 명시적 형식). `--install-id`와 상호 배타적입니다. |
| `--yes` | 하니스별 확인 프롬프트를 건너뜁니다. |
| `--project PATH` | 프로젝트 범위 하니스의 프로젝트 루트. 선택한 집합에 프로젝트 범위 어댑터가 포함되면 필수입니다. |
| `--quiet`, `-q` | 정보성 출력을 억제하고 오류만 발생시킵니다. |
| `--verbose`, `-v` | 추가 진단 출력을 발생시킵니다. |
| `--format plain\|json` | 출력 형식(기본값: `plain`). |
| `--json` | `--format json`의 약식. |
| `--no-color` | 출력에서 ANSI 색상 코드를 비활성화합니다. |
| `-h`, `--help` | 도움말을 표시하고 종료합니다. |

## JSON 출력

```json
{
  "status": "success",
  "command": "rollback",
  "action": "rolled_back",
  "harness": "claude-code",
  "profile_path": null,
  "project": null,
  "files_written": [],
  "results": [],
  "warnings": [],
  "error": null,
  "output_path": "C:\\Users\\Example\\.claude\\settings.json"
}
```

복원된 각 대상은 `"operation": "rollback"`과 `created` 또는 `updated`의 `outcome`으로 `results`에 표시됩니다(그리고 `files_written`에도 포함됩니다). 설치가 새로 생성한 대상 — 복원할 이전 바이트가 없는 경우 — 은 `"outcome": "skipped"`로 보고되며, 실패한 복원은 `"outcome": "error"`입니다. 일치하는 설치 기록이 없으면, 명령은 `"status": "error"`와 함께 `rollback.no_record` 오류를 보고합니다.

## 예시

```bash
apothem rollback --harness claude-code --last
apothem rollback --harness claude-code --install-id 01J9Z… --yes
apothem rollback --harness cursor --project . --last --json
```

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 성공적으로 롤백됨, 또는 복원할 것이 없음(설치가 백업을 캡처하지 않음) |
| 1 | 예상되는 오류 — 설치 기록 없음, 선택자 충돌, 알 수 없는 하니스, 프로젝트 루트 누락, 또는 확인 중단 |
| 2 | 최소 한 번의 대상이 롤백된 후 부분 복원 |
