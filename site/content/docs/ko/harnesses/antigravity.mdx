**공급업체:** Antigravity
**설치 이름:** `antigravity`
**상태:** 미리 보기
**네이티브 구성:** `~/.gemini/GEMINI.md` 및
`~/.gemini/antigravity-cli/plugins/apothem/`

## 설치

```bash
apothem install --harness antigravity
```

어댑터는 공유 프로필을 `~/.gemini/GEMINI.md`에 렌더링하고 Apothem 지원
세트를 Antigravity CLI 플러그인으로 설치합니다.

**작성되는 파일:** `~/.gemini/GEMINI.md`,
`~/.gemini/antigravity-cli/plugins/apothem/plugin.json`,
`~/.gemini/antigravity-cli/plugins/apothem/skills/`,
`~/.gemini/antigravity-cli/plugins/apothem/rules/`,
플러그인 내부에 변환된 로컬 도우미 정의,
`~/.gemini/antigravity-cli/plugins/apothem/apothem/templates/` 및
`~/.gemini/antigravity-cli/plugins/apothem/apothem/hooks/`.

**공유 사용자 앵커.** `~/.gemini/GEMINI.md`는 Gemini 계열 도구의 사용자 범위
앵커이기도 합니다. Antigravity 어댑터는 추가 Apothem 자료를
`~/.gemini/antigravity-cli/plugins/` 아래의 `apothem` 플러그인 안에 보관하므로
일반적인 Gemini CLI 프로젝트 디렉터리를 점유하지 않습니다.

## 프로필에서 네이티브 구성으로의 매핑

어댑터는 Apothem의 공유 프로필을 읽고 `apothem install` 또는 `apothem update`를
실행할 때마다 지시 앵커와 지원 세트를 렌더링합니다.

## 호환성 참고 사항

미리 보기 어댑터. `GEMINI.md` 앵커는 활성 지시 콘텐츠입니다. Antigravity
플러그인은 변환된 명령 스킬, 재사용 가능한 스킬, 로컬 도우미 정의, 규칙, 템플릿,
그리고 후크 지원 자료를 명확한, Apothem 소유의 네임스페이스에 보존합니다.
어댑터가 Antigravity의 `hooks.json`에 대한 스키마 변환 계층을 갖추기 전까지
후크 파일은 활성 Antigravity 후크 이벤트로 등록되지 않습니다.

## 검증

```bash
apothem verify --harness antigravity
```

verify 명령은 다음을 확인합니다:

1. 네이티브 컨텍스트 파일이 예상 경로에 존재합니다.
2. Apothem Antigravity CLI 플러그인 메타데이터가 존재하며 `apothem` 플러그인
   이름을 선언합니다.

## 업데이트

```bash
apothem update --harness antigravity
```

현재 공유 프로필 상태에서 네이티브 구성을 다시 도출합니다.
`~/.config/apothem/profile.yaml`을 편집한 후 또는 설치된 Apothem 패키지를
업그레이드한 후에 실행하세요.

## 제거

```bash
apothem uninstall --harness antigravity
```

어댑터가 작성한 네이티브 구성 파일을 제거합니다.
공유 프로필 YAML과 Apothem 엔진은 영향을 받지 않습니다.

## 적합성 게이트

```bash
python -m apothem.conformity.gate --all .
```

## 문제 해결

| 증상 | 수정 |
|---------|-----|
| 구성 파일을 찾을 수 없음 | `apothem install --harness antigravity`를 다시 실행 |
| 검증 실패 | `apothem update --harness antigravity`를 실행한 후 다시 검증 |
| 예기치 않은 구성 내용 | `~/.config/apothem/profile.yaml` 또는 `--profile PATH`를 확인한 후 `apothem update --harness antigravity`를 다시 실행 |
