**벤더:** Open-Claw
**설치 이름:** `open-claw`
**상태:** 미리 보기
**네이티브 구성:** `~/.openclaw/openclaw.json`

## 설치

```bash
apothem install --harness open-claw
```

어댑터는 OpenClaw의 사용자 전역 구성 파일을 작성하고, 공유 프로필을 프로필
문서로 투영하며, 하니스 루트 아래에 Apothem 지원 코호트를 설치합니다.
OpenClaw의 네이티브 구성은 JSON이며, 머티리얼라이저는 빈 JSON 객체를
렌더링하고 기존 파일은 자신의 키를 유지합니다.

**작성되는 파일:** `~/.openclaw/openclaw.json`, 프로필 문서
`~/.openclaw/apothem/rules/00-apothem-profile.md`, 그리고
`~/.openclaw/.apothem/support/` 아래의 지원 파일

프로필 문서는 Apothem 지원 파일 섹션으로 끝납니다. 이 섹션은 저장소 스타일의 각
인용(`rules/<name>.md`, `templates/...`, `hooks/...`)이 해석되는 기준인
`~/.openclaw/.apothem/support/` 아래의 절대 디렉터리를 명시합니다.

## 프로필에서 네이티브 구성으로의 매핑

어댑터는 Apothem의 공유 프로필을 읽지만 구성 키는 작성하지 않습니다. 새 파일이거나
비어 있는 `openclaw.json`은 빈 객체로 작성되고, 기존 파일은 자신의 키를
유지합니다. 프로필의 신원, 선호, 규칙은 프로필 문서에 들어갑니다. 공유 커맨드,
스킬, 규칙, 템플릿, 훅 프롬프트는 `~/.openclaw/.apothem/support/` 아래에 지원
자료로 설치됩니다.

## 호환성 참고 사항

미리 보기 어댑터입니다. OpenClaw는 지원 트리나 프로필 문서를 스스로 로드하지
않습니다. OpenClaw의 스킬 위치, 워크스페이스 지침 파일, 구성 중 어느 것도 그곳을
가리키지 않으므로, 설치 후 OpenClaw는 Apothem의 규칙, 스킬, MCP 서버 없이
실행됩니다. OpenClaw는 워크스페이스의 `skills/` 및 `.agents/skills/` 폴더,
`~/.agents/skills`, 자신의 상태 디렉터리, 그리고 `skills.load.extraDirs`에 나열된
모든 폴더에서 스킬을 읽습니다. Apothem 스킬을 사용하려면
`~/.openclaw/.apothem/support/skills`를 그 목록에 직접 추가하세요.
`apothem update`는 여러분이 `openclaw.json`에 추가한 키를 유지합니다. MCP 서버는
OpenClaw 구성의 `mcp.servers` 블록에 있으며, 이 블록은 `openclaw mcp add`와 관련
하위 명령으로 여러분이 관리합니다. 어댑터는 그곳에 어떤 항목도 작성하지
않습니다. (OpenClaw의 동작은 [스킬](https://docs.openclaw.ai/tools/skills) 및
[MCP CLI](https://docs.openclaw.ai/cli/mcp) 문서에 따른 것이며, 2026-10-02에
확인했습니다.)

## 검증

```bash
apothem verify --harness open-claw
```

verify 명령은 다음을 확인합니다.

1. 네이티브 구성이 예상 경로에 존재합니다.
2. 각 관리 대상이 존재하고, 관리되는 파일은 비어 있지 않으며, JSON 또는 YAML
   구성은 파싱됩니다. 설치된 파일이 그 프로필과도 일치하는지 확인하려면
   `--profile PATH`를 추가하세요.
3. 어댑터별 검증 루틴이 성공을 보고합니다.

## 업데이트

```bash
apothem update --harness open-claw
```

현재 공유 프로필 상태에서 프로필 문서를 다시 도출하고 지원 파일을 새로 고칩니다.
`openclaw.json`은 이미 가지고 있는 키를 유지합니다.
`~/.config/apothem/profile.yaml`을 편집하거나 설치된 Apothem 패키지를
업그레이드한 후에 실행하세요.

## 제거

```bash
apothem uninstall --harness open-claw
```

어댑터가 추가한 항목, 즉 프로필 문서와 지원 트리를 제거합니다. `openclaw.json`에
있는 여러분의 키는 그대로 남으며, 이 파일은 Apothem이 직접 만들었고 여러분의
항목이 하나도 남아 있지 않은 경우에만 삭제됩니다. 공유 프로필 YAML과 Apothem
엔진은 영향을 받지 않습니다.

## 적합성 게이트

```bash
python -m apothem.conformity.gate --all .
```

## 문제 해결

| 증상 | 해결 방법 |
|---------|-----|
| 구성 파일을 찾을 수 없음 | `apothem install --harness open-claw`를 다시 실행 |
| 검증 실패 | `apothem update --harness open-claw`를 실행한 후 다시 검증 |
| 예기치 않은 구성 내용 | `~/.config/apothem/profile.yaml` 또는 `--profile PATH`를 확인한 후 `apothem update --harness open-claw`를 다시 실행 |
