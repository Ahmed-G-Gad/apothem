각 레시피는 하나의 구체적인 목표와 그것에 도달하는 순서대로의 단계를
제시합니다. 단계는 복사-붙여넣기로 실행 가능하며 실제 지원되는 워크플로에
대응합니다.

## 레시피

- [도구 추가하기](/docs/how-to/adding-a-harness) — 도구 어댑터를 활성화하여 공유
  프로파일로부터 그 네이티브 구성이 머티리얼라이즈되도록 합니다.
- [프로파일 편집하기](/docs/how-to/editing-the-profile) — 공유 프로파일을
  변경하고 설치된 모든 도구를 다시 머티리얼라이즈합니다.
- [설치 프로그램 환경 변수](/docs/how-to/installer-environment-variables)
  — 스크립트를 편집하지 않고 스크립트 설치 프로그램(대상, 소스, 도구, 프로파일,
  검증)을 제어합니다.

## 관련 가이드

- [설치하기](/docs/install)와 [업데이트하기](/docs/install/updating)는 최초 실행
  설치와 업그레이드 경로를 다룹니다.
- [사용법](/docs/usage) 섹션은 일상적인 CLI 커맨드를 다룹니다.
