## GitHub Discussions

The primary community venue is [GitHub Discussions](https://github.com/ahmed-g-gad/apothem/discussions).

Categories:

| Category | Use for |
|----------|---------|
| Q&A | Questions about usage, configuration, and behavior |
| Ideas | Feature requests and design discussions |
| Show and tell | Share how you use Apothem |
| General | Anything else |

## Issues

For bugs and concrete feature requests, use
[GitHub Issues](https://github.com/ahmed-g-gad/apothem/issues).

Before opening an issue, search existing issues and discussions to avoid
duplicates.

## Contributing

See [Contributing](/docs/developer-guide) for how to contribute code, docs,
and harness adapters. Start with the repository's
[`CONTRIBUTING.md`](https://github.com/ahmed-g-gad/apothem/blob/main/CONTRIBUTING.md)
and the pull-request template it references.
