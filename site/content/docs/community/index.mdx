Apothem is open source and welcomes contributors. This section covers how to
participate: where to ask questions, what is planned next, and the standards
the community holds itself to.

## Pages

| Page | Description |
|------|-------------|
| [Roadmap](/docs/community/roadmap) | The public roadmap — upcoming features and planned improvements. |
| [Discussions](/docs/community/discussions) | Where to ask questions and share ideas with the community. |
| [Code of conduct](/docs/community/code-of-conduct) | The standards for a welcoming and inclusive community. |

To contribute code, see the [Contributing guide](/docs/developer-guide). To add
support for a new harness, the [New harness adapter
authoring](/docs/runbooks/new-harness-adapter-authoring) runbook walks through the
adapter contract end to end.
