Per-artifact-class reference. Each page describes the class's purpose,
on-disk layout, frontmatter contract, and the registry that lists every
instance.

Repo-relative paths are shown below; each adapter materializes these
into its native configuration directory (e.g. `~/.claude/` for the
Claude Code adapter — see [`site/content/docs/harnesses/<harness>.mdx`](/docs/harnesses)
for per-harness destinations).

registry in a navigable form.
