`*.md` suffix. Each rule is self-contained — Purpose,
Obligations, Seriousness Scaling, Anti-Patterns, Enforcement, Bindings — and
either always-on or path-filtered.

## Frontmatter contract

Every rule file carries:

```yaml
---
name: <rule name>
description: <one-line role>
pathFilter: <glob list; empty string "" on always-on rules>
alwaysApply: <true | false>
---
```

On an always-on rule `pathFilter` is the empty string (`""`) and `alwaysApply`
is `true`; on a path-filtered rule `pathFilter` carries the glob list and
`alwaysApply` is `false`. The machine-readable contract is
[`frontmatter_grep`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/conformity/frontmatter_grep.py)
(`{name, description, pathFilter, alwaysApply}`); the validator's
`frontmatter-cohort` check verifies it on every rule file.

## Authoring discipline

- **Self-contained.** Each rule has its own Purpose, Obligations, Anti-Patterns,
  and Enforcement sections.
- **Bindings block.** Every rule ends with the canonical five-direction
  Bindings block (Drives → / Satisfies → / Established by ↑ / Gated by ← /
  Cross-bound with ↔).
- **Domain language only.** No plan-internal references — see
  `CLAUDE.md` CM-7.
