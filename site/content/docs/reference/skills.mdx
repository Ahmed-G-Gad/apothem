Skills live as folders under `src/apothem/skills/`, each with a `SKILL.md` entry
point. Skills capture reusable detectable techniques — they have a
detection signal, a procedure, and an enforcement hook.

The full skill catalog is generated below in the [Generated Skill
Inventory](#generated-skill-inventory).

## Frontmatter contract

`SKILL.md` carries the canonical eight-key frontmatter. The machine-readable
contract is [`skill.schema.json`](https://github.com/ahmed-g-gad/apothem/blob/main/src/apothem/schemas/skill.schema.json)
(`additionalProperties: false`); this block mirrors it:

```yaml
---
name: <skill name>
version: <semver>
updated: <YYYY-MM-DD>
description: <one-line role>
archetype: <class-template, e.g. workflow-template>
userInvocable: <true | false>
disable-model-invocation: <true | false>
allowed-tools: <comma-separated read-only tools and scoped rules, e.g. "Read, Glob, Grep" or "Read, Bash(git log *)">
---
```

## Per-harness emission

Source skills use the keys above. Some harnesses read different keys, so the
install translates them for that harness only:

| Harness | What the install changes |
| --- | --- |
| Claude Code (install and plugin) | Renames `userInvocable` to `user-invocable`, the key Claude Code reads. Claude Code ignores the camelCase key, so without the rename a skill marked `userInvocable: false` would still show in the `/` menu. |
| Codex | Leaves `SKILL.md` as is and writes `agents/openai.yaml` with `policy.allow_implicit_invocation: false` beside every skill whose source sets `disable-model-invocation: true`, because Codex ignores that key. |
| Other harnesses | No change. |

`skill.schema.json` accepts either spelling of the user-invocability flag and
requires exactly one of them.

## Authoring discipline

- **Folder-per-skill.** Every skill is its own folder with the entry
  point at `SKILL.md`.
- **Detection signal.** Skill bodies open with the detection signal that
  triggers the technique.
- **Procedure + enforcement.** Skills carry both the procedure to apply
  and the enforcement signal that closes the loop.
- **Description length.** `description` is at most 1,024 characters, the
  [Agent Skills](https://agentskills.io/specification) limit. Stricter tools
  reject or cut off a longer one, and the schema enforces the limit.
