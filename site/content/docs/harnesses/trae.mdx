**Install name:** `trae`
**Status:** GA
**Native config:** `<project>/.trae/rules/apothem-rules.md`

## Installation

```bash
apothem install --harness trae --project /path/to/project
```

The adapter writes one project-scope Trae rules file from the shared
Apothem rules and governance surface.

**Files written:** `<project>/.trae/rules/apothem-rules.md`

## Profile-to-native-config mapping

The adapter reads Apothem's shared profile and renders the project rules file
on every `apothem install` or `apothem update` run. The shared profile is the
source of truth; project-local edits to the generated file are backed up before
the next sync replaces the Apothem-managed content.

The file opens with YAML frontmatter that sets `alwaysApply: true` and a
`description`, which is Trae's Always Apply mode per the
[Trae rules documentation](https://docs.trae.ai/ide/rules). The Apothem-managed
block follows it; text you add after the block is kept on every sync.

## Compatibility notes

Trae's current rules surface is project-scoped under `.trae/rules/`; global
rules live under `~/.trae/user_rules`. The adapter writes a dedicated
`apothem-rules.md` file and never clobbers the other rule files in that
directory or your global rules. The
`.trae/mcp.json` tool-server surface and `.trae/skills/` skill surface are
operator-owned; Apothem does not write them.

## Verification

```bash
apothem verify --harness trae --project /path/to/project
```

The verify command confirms that:

1. The native config exists at the expected path.
2. All mandatory fields from the shared profile are present.
3. The adapter-specific verification routine reports success.

## Updating

```bash
apothem update --harness trae --project /path/to/project
```

Re-derives the project rules file from the current shared profile state.

## Uninstalling

```bash
apothem uninstall --harness trae --project /path/to/project
```

Removes the native config files written by the adapter.
The shared profile YAML and Apothem engine are unaffected.

## Conformity gate

```bash
python -m apothem.conformity.gate --all .
```

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Config file not found | Re-run `apothem install --harness trae --project /path/to/project` |
| Verification failed | Run `apothem update --harness trae --project /path/to/project`, then verify again |
| Unexpected config content | Check `~/.config/apothem/profile.yaml` or `--profile PATH`, then re-run `apothem update --harness trae --project /path/to/project` |
