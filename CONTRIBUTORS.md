# Contributors

**Purpose:** the roster of *everyone* who has contributed to Apothem, derived
from git history. This is one of three related rosters, each with a distinct
purpose:

- **[AUTHORS](AUTHORS)** — the copyright record (copyright holders, for
  licensing and attribution).
- **CONTRIBUTORS.md** (this file) — everyone who has contributed, regenerated
  from git history.
- **[MAINTAINERS.md](MAINTAINERS.md)** — the governance owners who review pull
  requests, cut releases, and handle security response.

Thank you to everyone who has contributed to Apothem.

## How to add yourself

You do not need to add yourself manually — this roster is regenerated from
git history. Once your pull request merges, your authored commits place you
on the list at the next regeneration. To regenerate locally:

```bash
git shortlog -sne
```

If you contributed in a way that git history does not capture (documentation
feedback, design input, issue triage), open a pull request adding yourself
to a dedicated acknowledgements section, or mention it in your PR so a
maintainer can credit you.
