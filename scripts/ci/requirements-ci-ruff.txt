# Hash-locked requirements for CI: ruff, the linter and formatter, at the exact
# version of the dev extra.
# Installed by conformity.yml (conformity-fixture-sweep). Install command:
#   python -m pip install --require-hashes -r scripts/ci/requirements-ci-ruff.txt
#
# ruff is pinned exactly in five places that must agree: the dev extra of
# pyproject.toml, the ruff-pre-commit rev in .pre-commit-config.yaml, the spec
# in scripts/dev/ci_lock_table.py, the dev lock and this lock;
# tests/scripts/test_ci_tool_locks.py fails when they differ. To move ruff,
# change the first three together, then refresh every lock.
#
# One universal lock for Python 3.10 and later on every platform: a line that
# carries an environment marker applies only where the marker is true. Every
# package carries the hashes of all its files, wheels and sdist, so an
# interpreter without a wheel yet (the advisory pre-release cell) builds from
# the hashed sdist; pip prefers a wheel wherever one exists. pip checks hashes
# only when it downloads: a runner that already has a version reports
# "Requirement already satisfied" and verifies nothing.
#
# The lock holds only files uploaded before the cutoff below, the lock date
# minus the cooldown, so a release younger than the cooldown is not installed
# until a later refresh. Only requirements-ci-pip.txt pins pip.
#
# Do not edit by hand and do not bump a single pin: every lock in this folder is
# a closure, regenerated whole from the table in scripts/dev/ci_lock_table.py.
# To refresh them all:
#   python scripts/dev/refresh_ci_locks.py
# A security fix younger than the cooldown needs --cooldown-days 0, which takes
# files uploaded before 00:00 UTC of the lock date, or, for a fix uploaded on
# that day, a cooldown exception for its package in the table.
# To verify a committed lock against its recorded dates (needs uv and network):
#   python scripts/dev/refresh_ci_locks.py --check
# tests/scripts/test_ci_locks_fresh.py fails when a lock drifts from its inputs.
#
# Locked as of: 2026-10-29T00:00:00Z
# Cooldown: 7 days
# Cutoff: 2026-10-22T00:00:00Z
