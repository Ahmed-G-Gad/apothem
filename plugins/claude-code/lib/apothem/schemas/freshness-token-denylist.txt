# Freshness-token denylist loaded by freshness_token_grep.
#
# The freshness-facade mandate (rules/freshness-facade.md) keeps every
# shipped public surface a current-version-only facade: no backward / legacy
# replacement narrative, no placeholder / deferral, no fix-and-refinement
# story-of-becoming. This file enumerates the high-precision narrative PHRASES
# that mark those classes — never bare common words.
#
# Two boundaries keep this set precise:
#
#   1. Bare words such as "legacy", "deprecated", "retired", "placeholder",
#      and "backward" have legitimate uses (a Keep-a-Changelog `Deprecated`
#      heading, a documented deprecation policy, a "placeholder identity"
#      product feature, a "future clarity backward" idiom) and are absent.
#      Present-tense facts that are not story-of-becoming — "backward-compatible
#      with v1", "X is no longer supported" — are also absent: a truthful
#      current-version surface may state them.
#   2. The AI-disclosure token-class (the bare "AI" token in "AI-generated",
#      "generated by AI") is already forbidden on this exact README + site
#      scope by `plain-language-grep`. To stay strictly non-overlapping, this
#      denylist carries none of it; AI-disclosure enforcement is plain-language's.
#
# Only unambiguous story-of-becoming / replacement / deferral phrases remain,
# so the matcher flags the narrative without flagging the dictionary word or
# double-flagging what plain-language already owns.
#
# The matcher (conformity/freshness_token_grep.py) scans README.md plus the
# site documentation tree, case-insensitively, outside fenced code blocks. Each
# non-empty, non-comment line below is one forbidden phrase, matched literally.
#
# This file carries its SPDX line as a hash comment (the matcher skips comment
# lines), mirroring schemas/reference-token-denylist.txt; it is not a header
# exemption.
