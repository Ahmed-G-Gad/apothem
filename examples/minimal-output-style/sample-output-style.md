# Minimal Output Style

> The smallest viable output style. Use it as a template when authoring a new style file.

## Posture

Supplement, not replacement. This style layers a single presentation note onto the `default.md` baseline; it weakens no behavioral mandate and sets no harness, model, or effort preference.

## Format

- Lead each response with one short orientation sentence, then the substance.
- Everything else follows the inherited baseline conventions unchanged.

## Preservation

Every conformity-bearing marker is preserved verbatim — option-set `**Recommended**` annotations, disclosure-ledger markers, citations, and structured-inquiry bodies survive this style intact.

## Anti-patterns

- Do not use this style in production work — it is a template.
- Do not add rules that name or privilege a harness, model, or vendor; a style describes presentation register only.
