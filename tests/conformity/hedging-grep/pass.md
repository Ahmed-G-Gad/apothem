# Sample Artifact — Definitive Prose

This fixture is the PASS case for `hedging-grep`. Every prescription is
unconditional or carries explicit branches.

## Behavior

The function returns `null` when the key is missing. When the value is the
sentinel `None`, the function returns the empty string. When the input is
malformed, the function raises `ValueError` with the offending input
attached.

The build completes within five minutes when the cache is warm; up to
twelve minutes on a cold start (criterion: cache directory size below the
ratified threshold).

```text
Note: this fenced block intentionally contains the word "usually" — it is
inside a code fence and the grep skips it.
```

Inline-code citations are also skipped: a doc naming the closed hedging
vocabulary — `usually`, `typically`, `should probably` — quotes each word
inside backticks, a meta-linguistic citation rather than a prescription that
hedges.

## Conclusion

The artifact ships clean. Every binding prescription is stated; every
conditional names its branches.
